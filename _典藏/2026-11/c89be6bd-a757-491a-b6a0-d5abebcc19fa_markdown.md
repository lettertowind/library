## 2. 查看缺失值

### 2.1 `isnull()`：判断是否为空值

- 代码：`data.isnull()`
- 作用：逐个元素判断是否为空值。
- 返回结果：与原数据形状相同的布尔型表。
  - 空值显示为 `True`
  - 非空值显示为 `False`
- 用途：定位数据中哪些位置是空值。
- 易混点：与 `notnull()` 判断结果相反。

### 2.2 `notnull()`：判断是否非空

- 代码：`data.notnull()`
- 作用：判断是否不是空值。
- 返回结果：
  - 非空值显示为 `True`
  - 空值显示为 `False`
- 用途：查看非空值位置，或与 `isnull()` 互补使用。
- 讲师说明：查看缺失值主要使用这两个函数，概念上不难；真正的工作重点不是“光看”，而是后续删除和填充。

## 3. 删除缺失值：`dropna()`

### 3.1 `dropna()` 的基本作用

- 函数：`dropna()`
- 作用：删除包含缺失值的行或列。
- 默认行为：
  - 默认 `axis=0`，即按行操作。
  - 默认 `how='any'`，即只要这一行出现一个空值/缺失值，就删除这一行。
- 示例：`data.dropna()`
  - 运行后，所有包含空值的行都会被删除。
- 如果要对列操作：
  - 设置 `axis=1`。
  - 示例：`data.dropna(axis=1)`
  - 因为默认 `how='any'`，所以只要某一列有一个空值，该列就会被删除。
  - 讲师演示数据中每一列都有空值，因此 `axis=1` 后大量列被删除，最后只留下姓名列。

### 3.2 参数 `axis`

- `axis=0`：默认值，按行处理。
- `axis=1`：按列处理。
- 讲师强调：前面课程一直在讲轴的问题，这里同样适用。
- 删除列时必须设置 `axis=1`；否则默认按行删除。
- 易错点：`dropna()` 默认删除的是“含空值的行”，不是列。

### 3.3 参数 `how`

- 默认值：`how='any'`
  - 只要行或列中有一个缺失值，就删除该行或该列。
- 可选值：`how='all'`
  - 只有整行或整列全部为空时，才删除。
- 示例：`data.dropna(how='all')`
  - 讲师运行后没有变化。
  - 原因：当前数据中每一行都有姓名等信息，不是彻底全空的行。
  - 只有一行中所有字段都为空，才会被删除。
- 示例：`data.dropna(axis=1, how='all')`
  - 按列操作，并且只删除整列全空的列。
- 讲师强调：
  - 一般业务中，不建议“一有空值就删整行/整列”，否则容易造成数据损失。
  - 更常见的需求是：整行或整列全是空时才删除。
  - 因此 `how='all'` 是重要参数。

### 3.4 参数 `thresh`

- 参数名：`thresh`
- 作用：指定该行或该列“非空值数量”的阈值。
- 运行逻辑：
  - 如果该行/列的非空值数量小于 `thresh` 指定的值，则删除该行/列。
- 示例：`data.dropna(thresh=2)`
  - 表示至少保留 2 个非空值。
  - 非空值数量少于 2 的行会被删除。
- 讲师特别纠正/强调：
  - 这里的判断依据是“非空值数量”，不是“空值数量”。
  - 讲师口述中出现“至少保留两个空值”的说法，应理解为“至少保留两个非空值”。
- 使用频率：
  - 讲师表示这个参数并不常用，自己用得也不多。
  - 但仍需知道其含义：控制非空值最少保留数量。

### 3.5 参数 `subset`

- 参数名：`subset`
- 作用：只在指定的列中检查缺失值。
- 使用场景：不能对整个表直接操作，只希望根据某些关键列判断是否删除行。
- 示例：`data.dropna(subset=['语文', '数学'])`
  - 只在“语文”和“数学”这两列中检查空值。
  - 如果这两列中存在空值，则删除对应的行。
  - 其他列不参与判断。
- 讲师强调：`subset` 是重点参数，很重要。
- 讲师演示说明：因为数据中英语列也有空值，所以看起来相关行都被删除了；但判断范围实际由 `subset` 指定。

### 3.6 参数 `inplace`

- `inplace` 用于控制是否在原数据上直接修改。
- 讲师说明：上节课已经重点讲过并做过测试，本节不再重复。
- 如果不知道 `inplace` 是什么，可查看 10.1.2 的笔记或上节课视频。
- 在删除缺失值、填充缺失值等操作中，`inplace` 都需要注意。

### 3.7 `dropna()` 小结

- `data.dropna()`：默认删除含空值的行。
- `data.dropna(axis=1)`：删除含空值的列。
- `data.dropna(how='all')`：只删除整行全空的行。
- `data.dropna(axis=1, how='all')`：只删除整列全空的列。
- `data.dropna(thresh=2)`：非空值数量少于 2 的行删除。
- `data.dropna(subset=['语文', '数学'])`：只在指定列中检查缺失并删除对应行。
- 易错点：
  - `how='all'` 不是“有空就删”，而是“整行/整列全空才删”。
  - `thresh` 判断的是非空值数量。
  - 对列操作必须设置 `axis=1`。
  - 默认 `axis=0`、`how='any'`，容易误删数据。

## 4. 填充缺失值：`fillna()`

### 4.1 `fillna()` 的基本作用

- 函数：`fillna()`
- 作用：将缺失值/空值替换为指定内容。
- 讲师说明：处理缺失值的主要办法包括查看、删除、填充；本节最后一个重点是填充。

### 4.2 常量填充

- 示例：`data.fillna(520)`
- 作用：把数据中所有空值都填充为 `520`。
- 讲师演示说明：所有空值都被替换成 `520`。
- 使用方式：如果希望所有缺失值统一填充为某个常量，直接把常量写在 `fillna()` 中即可。
- 注意：讲师口述中可能出现“所有非空值都被替换成 520”的说法，按函数逻辑应理解为“所有空值被替换成 520”。

### 4.3 字典填充：按列指定不同填充值

- 示例：`data.fillna({'语文': 0.1, '数学': 0.2, '英语': 0.3})`
- 作用：
  - “语文”列的空值填充为 `0.1`
  - “数学”列的空值填充为 `0.2`
  - “英语”列的空值填充为 `0.3`
- 字典的键：列名。
- 字典的值：该列要填充的值。
- 讲师演示时先写英文列名，再敲中文“语文、数学、英语”，最终形成按列填充的字典。
- 讲师强调：这体现了 Pandas 在数据处理上的优势。
  - 在 Excel 或 VBA 中做类似批量、按列不同的填充，通常不如 Pandas 快。
  - Pandas 提供了强大的批量处理功能。

### 4.4 参数 `method`：按方向填充

- 参数名：`method`
- 作用：指定填充方式，用前一个值或后一个值进行填充。
- 讲师列出四个可选项：
  - `ffill`
  - `bfill`
  - `pad`
  - `backfill`

#### `ffill`

- 示例：`data.fillna(method='ffill')`
- 作用：用前面的值进行填充。
- 默认 `axis=0` 时，表现为向下填充：
  - 空值使用它上方最近的非空值填充。
- 讲师演示现象：
  - 前面的 `1` 会被向下填充到其后的空值。
  - 后面某列空值前的 `2` 会被填充为 `2`。
  - 空值前的 `3` 会被填充为 `3`。
- 理解：按列向下传播上一个有效值。

#### `bfill`

- 示例：`data.fillna(method='bfill')`
- 作用：用后面的值进行填充。
- 默认 `axis=0` 时，表现为向上填充：
  - 空值使用它下方最近的非空值填充。
- 讲师演示现象：
  - 空值后面的 `5` 会向上填充，空值被填成 `5`。
  - 空值后面的 `6` 会向上填充，空值被填成 `6`。
- 理解：按列向上传播下一个有效值。

#### `pad`

- 示例：`data.fillna(method='pad')`
- 讲师说明：很多教程称 `pad` 与 `ffill` 功能一样，都是用前面的值填充。
- 讲师表示：自己也认为二者表现相似，但 Pandas 为什么保留四个参数，可能还有未研究到的差异。
- 结论：先知道 `pad` 常被视作与 `ffill` 类似；具体差异可继续研究。

#### `backfill`

- 示例：`data.fillna(method='backfill')`
- 讲师说明：很多教程称 `backfill` 与 `bfill` 功能一样。
- 讲师表示：从演示看，`backfill` 与 `bfill` 类似；但四个参数为何同时存在，建议后续研究。
- 讲师态度：既存在就有其道理，希望高手进一步讲解或自己研究。

### 4.5 横向填充：修改 `axis`

- 默认 `axis=0` 时，是竖着看“前和后”，即向上/向下填充。
- 如果要实现向左/向右填充，需要把 `axis` 改为 `1`。
- 示例形式：`data.fillna(method='ffill', axis=1)`
- 作用：按行横向填充，前一个值/后一个值变为左、右方向。
- 讲师解释：
  - 现在默认是竖着看，所以讲“前和后”。
  - 把轴改成 `1` 后，前和后就变成左和右。
- 易错点：`axis=1` 不是删除列的意思，在 `fillna()` 中表示横向填充方向。

### 4.6 参数 `limit`：限制填充数量

- 参数名：`limit`
- 作用：限制一次填充中最多填充多少个缺失值。
- 示例场景：
  - 当前使用从下往上填充的方式。
  - 只想填充两个空值，而不是把所有连续空值都填满。
  - 在填充方法后加 `limit=2`。
- 示例形式：`data.fillna(method='bfill', limit=2)`
- 运行效果：
  - 只填充两个空值。
  - 第三个空值不再填充，仍保持为空。
- 讲师类比：类似 MySQL 中控制一页显示几条数据，`limit` 是控制数量的事情。
- 使用场景：当连续缺失较多时，不希望全部按同一方向填充，可用 `limit` 限制填充个数。

### 4.7 `fillna()` 小结

- `data.fillna(520)`：所有空值填充为常量 `520`。
- `data.fillna({'语文': 0.1, '数学': 0.2, '英语': 0.3})`：按列使用字典指定不同填充值。
- `data.fillna(method='ffill')`：用前面的值向下填充。
- `data.fillna(method='bfill')`：用后面的值向上填充。
- `data.fillna(method='pad')`：常被教程视为与 `ffill` 类似。
- `data.fillna(method='backfill')`：常被教程视为与 `bfill` 类似。
- `axis=1`：从上下填充改为左右填充。
- `limit=2`：限制填充数量，只填两个。
- `inplace`：同样可控制是否原地修改，参考上节课和 10.1.2 笔记。

## 5. Excel 填充类比与 Pandas 优势

- 讲师用 Excel 做类比：
  - 在 Excel 中选中单元格后按 `Ctrl+D` 可以向下填充。
  - Excel 中还有向左、向右等填充方式。
  - 讲师表示自己不太会在 Excel 中向上填充，但 Pandas 中可以非常简单地实现向上填充。
- Pandas 的优势：
  - 可以向下填充、向上填充。
  - 可以通过 `axis=1` 做横向填充。
  - 可以按列使用字典填充不同值。
  - 可以用 `limit` 限制填充数量。
  - 批量处理效率高，在 Excel 或 VBA 中做同类操作往往不如 Pandas 快。

## 6. 本节关键结论与易错点

- 缺失值初步可理解为空值，但缺失值不只等于空值；高级内容后续再讲。
- 查看缺失值：
  - `isnull()`：空值为 `True`，非空为 `False`。
  - `notnull()`：非空为 `True`，空值为 `False`。
- 删除缺失值：
  - `dropna()` 默认 `axis=0`、`how='any'`，删除含空值的行。
  - `axis=1` 用于删除含空值的列。
  - `how='all'` 只删除整行/整列全空的情况。
  - `thresh` 判断非空值数量，少于阈值才删除。
  - `subset` 只检查指定列，按指定列中的空值删除对应行。
  - 不要轻易见到一个空值就删除整行/整列，避免数据损失。
- 填充缺失值：
  - `fillna(常量)` 统一填充。
  - `fillna(字典)` 按列指定不同填充值。
  - `method='ffill'` 用前面的值填充。
  - `method='bfill'` 用后面的值填充。
  - `method='pad'` 与 `ffill` 常被认为类似。
  - `method='backfill'` 与 `bfill` 常被认为类似。
  - `axis=1` 可实现左右方向的横向填充。
  - `limit` 可限制填充数量。
- 讲师最后总结本节学习内容：
  - 查看缺失值
  - 删除缺失值的行和列
  - 填充缺失值
  - 限制填充缺失值的数量
