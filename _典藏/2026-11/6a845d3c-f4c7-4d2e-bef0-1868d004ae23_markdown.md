# 孙兴华 Python 数据分析入门：Pandas DataFrame 数据结构

## 1. DataFrame 的定义与结构

- `DataFrame` 是一种**表格型数据结构**，可以理解为类似 Excel 表格的二维数据表。
- 每一列可以是不同的数据类型，例如：
  - 数值型
  - 字符型
  - 布尔型
- `DataFrame` 同时具有：
  - **行索引**：每一行对应的索引，例如表格左侧的 `1,2,3,4,5,6,7`，或默认的 `0,1,2...`
  - **列索引**：通常就是字段名、列名，例如 `姓名`、`年龄`、`功夫`
- 在 Pandas 中，`DataFrame` 可以看作是由多个 `Series` 组成的字典：
  - 字典的键：列名
  - 字典的值：一列 `Series`
- 因此，之前学习的 `Series` 方法在 `DataFrame` 中也会经常用到。
- 课程中提到：读取 `CSV`、`Excel`、`MySQL` 等数据来创建 `DataFrame` 的方法，在第一节课中已有讲解。

## 2. 创建 DataFrame

### 2.1 由列表创建 DataFrame

- 可以通过“列表中嵌套列表”的方式创建多行多列数据。
- 例如创建一个三行三列的数据：

`data = pd.DataFrame([[1,2,3],[4,5,6],[7,8,9]], columns=['a','b','c'])`

- 外层列表包含三个内层列表，表示三行数据。
- `columns` 用于指定列名，也就是字段名。
- 打印结果：
  - 行索引为 `0,1,2`
  - 列索引为 `a,b,c`
  - 数据为 `1` 到 `9`
- 注意：
  - `columns` 指定的是列名、字段名，不属于数据索引。
  - `DataFrame` 的索引默认从 `0` 开始。

### 2.2 由字典创建 DataFrame

- 使用字典创建 `DataFrame` 时：
  - 字典的键作为列名
  - 字典的值作为该列的数据，通常使用列表
- 示例数据结构：

`data = { '姓名': ['孙兴华','李小龙','叶问'], '年龄': [20,80,127], '功夫': ['健身','截拳道','咏春'] }`

`df = pd.DataFrame(data)`

- 每个键对应一列，每个值列表对应这一列的数据。
- 列表长度应保持一致。
- 字符型数据需要加引号，数值型数据不需要加引号。
- 注意：字典中每个键值对之后必须用逗号隔开，漏写逗号会导致报错。

### 2.3 查看列类型、列名与索引

- 查看每一列的数据类型：

`df.dtypes`

- 示例结果：
  - `姓名` 列为 `object`
  - `年龄` 列为 `int64`
  - `功夫` 列为 `object`
- 查看列索引、字段名：

`df.columns`

- 查看行索引：

`df.index`

- 示例中行索引为从 `0` 开始、到 `3` 结束、步长为 `1` 的索引范围。

### 2.4 由多个 Series 创建 DataFrame

- 可以先分别创建多个 `Series`，再组合成 `DataFrame`。
- 示例思路：
  - 第一个 `Series`：姓名数据，`index=[1,2,3]`，`name='姓名'`
  - 第二个 `Series`：性别数据，`index=[1,2,3]`，`name='性别'`
  - 第三个 `Series`：年龄数据，`index=[1,2,3]`，`name='年龄'`
- 通过字典方式组合：

`table = pd.DataFrame({ data1.name: data1, data2.name: data2, data3.name: data3 })`

- 也可以使用列表方式组合多个 `Series`：

`pd.DataFrame([data1, data2, data3])`

- 使用列表方式时，行列方向可能与字典方式不同，结果看起来像把一维数据转换成了二维数据，类似数据透视表的感觉。
- `Series` 组合成 `DataFrame` 时具有**索引对齐功能**：
  - 如果不同 `Series` 的 `index` 不完全一致，Pandas 会自动按索引对齐。
  - 对不上的位置会显示 `NaN`。
- 示例：
  - 原索引为 `1,2,3`
  - 将某个 `Series` 的索引改为 `2,3,4`
  - 则索引 `1` 对应的该列没有数据，显示 `NaN`
  - 索引 `4` 对应的其他列没有数据，也显示 `NaN`
- `NaN` 表示缺失值，不是一个有效数字。

## 3. DataFrame 的数据查询与索引

### 3.1 查询单个元素

- 可以通过“先列后行”的方式查询单个元素。
- 例如查询 `a` 列 `0` 行：

`df['a'][0]`

- 返回结果为 `1`。
- 视频中强调：前面是列，后面是行。

### 3.2 使用 loc 按标签查询

- `loc` 根据行列的**标签**进行查询。
- 语法形式：

`df.loc[行标签, 列标签]`

- 例如：

`df.loc[0, 'a']`

- 表示查询行标签为 `0`、列标签为 `a` 的数据，返回 `1`。
- 视频建议：如果习惯使用标签查询，可以优先使用 `loc`。
- 行标签默认是 `0,1,2...`，列标签是 `a,b,c...`。
- 如果手动设置了 `index`，例如设置为 `A,B,C`，那么 `loc` 查询时也要使用新的行标签，例如 `A`。

### 3.3 使用 iloc 按位置查询

- `iloc` 根据行列的**数字位置**进行查询。
- 语法形式：

`df.iloc[行位置, 列位置]`

- 例如：

`df.iloc[0, 0]`

- 返回第 `0` 行、第 `0` 列的数据，即 `1`。
- `iloc` 与 `loc` 的区别：
  - `loc`：根据标签查询，如行标签、列标签。
  - `iloc`：根据位置查询，不管索引标签被设置成什么，位置始终从 `0` 开始。
- 如果给 `DataFrame` 设置了自定义索引，`loc` 需要使用新的索引标签，而 `iloc` 仍然使用 `0,1,2...` 这样的位置编号。

### 3.4 查询多列

- 查询多列时，需要在 `DataFrame` 后面的中括号中再套一个列表。
- 例如查询 `a` 列和 `b` 列：

`df[['a', 'b']]`

- 注意：中括号里面必须是列表形式。
- 查询单列时返回 `Series`；查询多列时返回新的 `DataFrame`。
- 例如查询姓名和年龄：

`df[['姓名', '年龄']]`

- 返回姓名和年龄两列数据。

### 3.5 查询单行与行、列组合

- 查询一行数据可以使用 `loc`：

`df.loc[1]`

- 示例中返回索引为 `1` 的行数据：
  - 姓名：李小龙
  - 年龄：80
  - 功夫：截拳道
- 查询指定行的指定列：

`df.loc[1]['姓名']`

或：

`df.loc[1, '姓名']`

- 返回结果：李小龙。
- 视频中说明：查询多列时可以直接在 `DataFrame` 后写列名列表；查询行时通常使用 `loc` 或 `iloc`。

### 3.6 查询多行

- 使用 `loc` 查询多行：
  
`df.loc[0:3]`

- 视频演示中返回索引 `0,1,2`，即前三行。
- 视频讲解中强调：
  - 从 `0` 开始
  - 结束值为 `3`
  - 不包含结束值
  - 步长默认为 `1`，可以省略
- 注意：实际使用 Pandas 时，`loc` 的切片行为与索引类型有关，后续数据查询课程会详细介绍。视频此处主要演示按行查询的基本思路。

### 3.7 查询一列时返回 Series

- 如果只查询一列，例如：

`df['姓名']`

- 返回的是一个 `Series`。
- 使用 `type()` 查看类型时，返回的是 `pandas` 的 `Series` 类型。
- 这一点需要区分：
  - 单列查询返回 `Series`
  - 多列查询返回 `DataFrame`

## 4. DataFrame 的常用属性与方法

视频后半部分重点介绍了 `DataFrame` 常用方法和属性，并强调这些内容非常重要，是后续数据处理的基础。

### 4.1 查看前几行：head

- `df.head()` 默认返回前五行。
- `df.head(3)` 返回前三行。
- 视频示例中使用了 `head(3)`，得到前三行数据。

### 4.2 查看后几行：tail

- `df.tail()` 默认返回后五行。
- `df.tail(n)` 返回后 `n` 行。
- 如果表中只有七行数据，使用默认 `tail()` 会返回后五行。

### 4.3 查看索引、值与形状

- 查看行索引：

`df.index`

- 查看数据值：

`df.values`

- 查看表格形状：

`df.shape`

- `shape` 返回一个元组，表示几行几列。
- 例如视频示例中表格为七行五列，则 `shape` 为 `(7, 5)`。

### 4.4 空值填充：fillna

- `df.fillna(value)` 可以将空值填充为指定值。
- 示例：
  - 数据中赵敏的年龄被清空，读取后显示为 `NaN`
  - 使用 `df.fillna(0)` 后，空值被填充为 `0`
  - 使用 `df.fillna(1)` 后，空值被填充为 `1`
- 注意：`fillna` 只对空值进行填充，不会修改非空值。

### 4.5 替换值：replace

- `df.replace(old, new)` 可以将指定值替换为新值。
- 示例：
  
`df.replace('杨过', '孙兴华')`

- 结果：所有“杨过”都会被替换为“孙兴华”。
- 如果数据中有多个“杨过”，也会全部替换。

### 4.6 判断空值：isnull 与 notnull

- `df.isnull()`：
  - 判断数据是否为空
  - 空值位置返回 `True`
  - 非空值位置返回 `False`
- `df.notnull()`：
  - 判断数据是否不为空
  - 非空值位置返回 `True`
  - 空值位置返回 `False`
- `isnull()` 与 `notnull()` 的判断结果正好相反。
- 这两个方法在上一节 `Series` 中已经介绍过，此处是对 `DataFrame` 的应用复习。

### 4.7 查询唯一值：unique

- `unique()` 用于查询唯一值，也就是去重。
- 视频提到：`Excel 365` 中新增了 `UNIQUE` 函数，用于去重。
- Pandas 中也有类似功能。
- 本课程中暂时只做提及，后续用到时会再详细介绍。

### 4.8 重置索引：reset_index

- `reset_index()` 用于重置索引。
- 关键参数是 `drop`。
- `df.reset_index(drop=True)`：
  - 删除原来的索引
  - 生成新的默认索引 `0,1,2...`
- `df.reset_index(drop=False)`：
  - 不删除原索引
  - 将原来的索引恢复成普通列
  - 同时生成新的默认索引
- 视频示例中：
  - 读取数据后原索引为 `0,1,2,3...`
  - 使用 `drop=True` 后，原索引被删除，恢复默认索引
  - 使用 `drop=False` 后，原索引被保留为普通列

### 4.9 索引排序与值排序

- `Series` 部分已经介绍过索引排序和值排序。
- 在 `DataFrame` 中也有相应操作，但视频此处没有重复展开。

### 4.10 合并操作

- 视频最后提到 `DataFrame` 的合并操作非常重要，包括：
  - 内连接
  - 左连接
  - 右连接
  - 全外连接

## 5. 本节重点总结

- `DataFrame` 是 Pandas 中的二维表格型数据结构。
- 每列可以是不同数据类型，并且同时具有行索引和列索引。
- `DataFrame` 可以理解为由多个 `Series` 组成的字典。
- 创建方式包括：
  - 由列表创建
  - 由字典创建
  - 由多个 `Series` 创建
  - 从 `CSV`、`Excel`、`MySQL` 等数据源读取创建
- 查询方式重点区分：
  - `loc`：按标签查询
  - `iloc`：按位置查询
  - 单列查询返回 `Series`
  - 多列查询返回 `DataFrame`
  - 多列查询必须使用列表形式，如 `df[['a','b']]`
- 常用方法包括：
  - `head()`、`tail()`
  - `index`、`values`、`shape`
  - `dtypes`、`columns`
  - `fillna()`、`replace()`
  - `isnull()`、`notnull()`
  - `unique()`
  - `reset_index(drop=True/False)`
- 后续重点是 `DataFrame` 的合并操作，包括内连接、左连接、右连接和全外连接，类似于 `SQL` 连接查询。
