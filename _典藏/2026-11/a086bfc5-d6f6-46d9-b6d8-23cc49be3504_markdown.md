## 2. `pivot_table` 的基本调用形式
- 视频强调：调用 `pivot_table` 时，首先要告诉函数“数据是什么”。
- 可理解为：
  - `pd.pivot_table(data, index=..., values=..., columns=..., aggfunc=...)`
  - 也可以写成 `data.pivot_table(...)` 的形式。
- 参数顺序依次介绍：
  - `index`
  - `values`
  - `columns`
  - `aggfunc`
- 后面再补充：
  - `fill_value`
  - `dropna`（视频口述近似“dpa”）
  - `margins`

## 3. 参数 `index`：按谁进行透视
- `index` 是需要聚合、分组的列名，也是结果透视表中的行标签，即“按谁来进行透视”。
- 如果不额外指定 `values`，视频说明默认会聚合所有数值列。
- 示例：按 `部门` 和 `销售人员` 两个条件进行透视。
  - `df2 = pd.pivot_table(df, index=['部门', '销售人员'])`
- 多个分组条件时，`index` 要写成列表。
- 运行结果：
  - 首先按部门分组，再在部门下列出销售人员。
  - 例如办公室下有郑浪；客服下有蒋波、赵文江；财务下有熊木；销售下有李平、王松、正浪等（示例数据）。
  - 不同部门可以有重名，重名没有关系，因为不在同一部门。
- 讲师结论：用过 Excel 数据透视表的人一听就明白，本节重点不是解释数据透视表概念，而是说明如何在 Pandas 中实现数据透视。

## 4. 参数 `values`：指定结果中显示哪些数值列
- `values` 用于指定透视结果中要显示哪些列，即选择参与显示的数值列。
- 讲师用通俗方式解释：已经分好透视表后，想让结果列显示哪些列，就用 `values` 告诉它要哪些列。
- 示例：数据中有 `成本`、`数量`、`金额`，如果只想显示 `数量` 和 `金额`：
  - `df2 = pd.pivot_table(df, index=['部门', '销售人员'], values=['数量', '金额'])`
- 结果只显示 `数量` 和 `金额`，不显示 `成本`。
- 如果未来大数据有几十列，不可能全部显示出来，也看不过来，因此要用 `values` 指定显示的列。
- 易混点：
  - `values` 管“选择哪些数值列显示/聚合”。
  - `columns` 管“在列方向增加分组字段”。

## 5. 参数 `columns`：在列方向进行分组
- `columns` 是在结果透视表的列方向上进行分组。
- 示例：在已经按 `部门`、`销售人员` 透视后，再按 `所属区域` 进行列分组：
  - `df2 = pd.pivot_table(df, index=['部门', '销售人员'], values=['数量', '金额'], columns='所属区域')`
- 结果会在上方增加按所属区域划分的列。
- 例如办公室郑浪：
  - 在四川区域销售/统计了多少；
  - 在山东区域销售/统计了多少；
  - 在河北区域销售/统计了多少；
  - 其他区域类似。
- 讲师总结：
  - `values` 是“我想显示哪些列”。
  - `columns` 是“我增加一个透视表的列分组/下一级分类”。
  - 用过数据透视表的人对这些操作没有问题。

## 6. 参数 `aggfunc`：指定聚合函数
- `aggfunc` 是聚合函数，非常重要。
- 必须告诉 Pandas：以什么方式来进行透视计算，例如求和、求平均、计数等。
- 视频提醒：数据透视表默认可能是求和或计数，但不能完全依赖默认方式，使用时应明确设置 `aggfunc`。
- 演示中可在 `aggfunc` 后写列表，指定聚合函数。
  - 例如：`aggfunc=['sum', np.mean]`
- 讲师举例：数量求和、金额计数或求平均；同时说明一般实际业务中要求和就都求和，这里只是假设演示。
- Python 自带的聚合函数：
  - `sum` 是 Python 自带的聚合函数，直接写 `sum` 即可，编辑器中会自动变色。
  - `sum` 也可以写成 `np.sum`，两者都可以，结果一样。
- NumPy 中的聚合函数：
  - `mean` 不是 Python 自带的，而是 NumPy 中的函数，不能直接使用。
  - 使用前必须先导入 NumPy：`import numpy as np`。
  - 使用时加 `np.` 前缀，例如 `np.mean`。
- 特殊函数 `len`：
  - `len` 不能加 `np.`，写成 `np.len` 会报错。
  - 正确写法是直接写 `len`。
- 讲师建议：除了 `len` 之外，如果记不清某个聚合函数是否 Python 自带，可以统一写成 `np.聚合函数`，一般不会出问题；但 `len` 必须例外。
- 踩坑记录：
  - 演示中曾把 NumPy 别名 `np` 写错成 `pd`，导致运行报错。
  - 改正为 `np` 后运行成功。
  - 因此使用 NumPy 聚合函数时，要检查 `import numpy as np` 和 `np.` 前缀是否正确。
- 参数总结：
  - `aggfunc` 指定前边列上如何聚合计算。
  - 例如第一个聚合方式求和，第二个聚合方式求平均。
  - 如果使用 Python 自带函数，不必写 `np.`；如果使用 NumPy 函数，需要写 `np.`；`len` 是特殊例外。

## 7. 参数 `fill_value`：替换缺失值
- `fill_value` 用于在结果中替换缺失值。
- 示例：
  - `fill_value=0`
- 作用：如果表中有空值/缺失值，把缺失值替换成 0，避免影响正常计算。
- 讲师强调：
  - 缺失值参与计算后，结果往往还是缺失值。
  - 如果确定数据中有缺失值，一定要加这个参数。
  - 加上后，所有缺失值在运行结果中都会被替换成 0，不影响正常计算。
- 演示数据中讲师说没有缺失值，但为了说明参数用法仍然加上了 `fill_value=0`。

## 8. 参数 `dropna`：删除全空列
- 视频口述近似“dpa”，对应 `dropna` 参数。
- 作用：如果为 `True`，结果中将不包含“所有条目均为空”的列。
- 视频说明：默认值为 `False`。
- 使用场景：
  - 如果某一列全部为空，可以设置 `dropna=True`，把这类空列移除，不再显示。
  - 移除全空列不会影响正常计算。
- 示例：
  - `dropna=True`

## 9. 参数 `margins`：添加行列小计
- `margins` 用于添加行、列的小计/总计。
- 默认值为 `False`，即默认没有小计。
- 设置为 `True` 后：
  - 行上会有小计；
  - 列上也会有极小计。
- 关键注意：
  - 它不是单纯对一整行或一整列求和。
  - 小计的计算方式取决于 `aggfunc`：如果聚合函数是求和，小计也按求和计算；如果聚合函数是求平均，小计也按求平均计算。
- 示例：
  - `margins=True`

## 10. `pivot_table` 参数总结
| 参数 | 作用 | 示例 | 注意事项 |
|---|---|---|---|
| `index` | 行方向分组字段，指定按谁透视，结果中的行标签 | `index=['部门', '销售人员']` | 多条件用列表；不同部门可重名 |
| `values` | 指定结果中显示/聚合的数值列 | `values=['数量', '金额']` | 不指定时视频说明默认聚合所有数值列；大数据中应筛选 |
| `columns` | 列方向分组字段，增加列层级/分类 | `columns='所属区域'` | 与 `values` 易混：`columns` 是列分组，不是选数值列 |
| `aggfunc` | 指定聚合方式，如求和、平均、计数 | `aggfunc=['sum', np.mean]` | 不要依赖默认；NumPy 函数加 `np.`；`len` 不能加 `np.` |
| `fill_value` | 替换结果中的缺失值 | `fill_value=0` | 有缺失值时建议加上，避免计算受影响 |
| `dropna` | 是否删除所有条目均为空的列 | `dropna=True` | 视频说明默认 `False`；删除全空列，不影响计算 |
| `margins` | 添加行列小计/总计 | `margins=True` | 小计遵循 `aggfunc`，不是单纯整行/整列求和 |

## 11. 交叉表 `pd.crosstab`
- 交叉表函数是：`pd.crosstab`。
- 讲师强调：
  - 交叉表其实就是数据透视表的一部分。
  - 网上有些资料把交叉表讲得特别复杂，其实很简单。
  - 数据透视表可以进行加法、计数、求和、求平均等多种运算。
  - 交叉表主要就是计数；需要计数时可以用交叉表。
- 基本形式：
  - `pd.crosstab(index, columns, margins=True)`
- 演示准备：
  - 讲师在数据中临时新增一列日期，作为测试数据。
  - 日期示例从 `2019-01-01` 到 `2022` 左右，用于测试月份统计。
  - 添加后打印 `df`，确认数据中已有日期列。
- 演示目标：
  - 根据日期中的月份和所属区域，对部门进行计数统计。
  - 即统计每个月、每个所属区域下，各部门有多少条记录。
- 日期取值方法：
  - 取月份：`df['日期'].dt.month`
  - 取年份：`df['日期'].dt.year`
  - 取天：`df['日期'].dt.day`
- 讲师说明：这些 `.dt` 方法很方便做日期相关统计。
- 两个分组条件时，交叉表的第一个参数要用列表：
  - `df2 = pd.crosstab([df['日期'].dt.month, df['所属区域']], df['部门'], margins=True)`
- 参数解释：
  - 第一个参数：按日期中的月份和所属区域分组。
  - 第二个参数：统计部门。
  - `margins=True`：添加小计。
- 交叉表没有 `aggfunc` 那样的多聚合函数，它主要就是计数。
- 运行结果示例：
  - 行按月份和所属区域排列。
  - 例如 1 月份下出现四川、山东、河北、河南、湖北等区域。
  - 列显示办公室、客服、财务、销售等部门。
  - 单元格中的数字是各区域、各部门的记录条数。
  - 讲师举例时出现办公室、客服、财务 16、销售 30 等示例计数。
- 重要注意：
  - 这里统计的是记录条数/订单笔数，不是人数。
  - 讲师特别说明：“它不是人，是订单的笔数/记录的条数。”

## 13. 踩坑与结论汇总
- 多条件分组时优先考虑数据透视表 `pivot_table`。
- 数据透视表四个核心参数要熟记：`index`、`values`、`columns`、`aggfunc`。
- 三个补充参数要会用于数据清洗和展示：`fill_value`、`dropna`、`margins`。
- `values` 和 `columns` 容易混淆：
  - `values`：选择结果中显示哪些数值列。
  - `columns`：在列方向增加分组字段，形成列层级分类。
- `aggfunc` 不要用默认，要明确指定聚合方式。
- `sum` 可直接写，也可写 `np.sum`。
- `mean` 需要 `import numpy as np` 后写 `np.mean`。
- `len` 特殊：不能写 `np.len`，否则报错；直接写 `len`。
- 使用 NumPy 聚合函数时，必须正确导入 NumPy，并注意别名 `np` 不要写错成 `pd`。
- 有缺失值时加 `fill_value=0`，避免缺失值参与计算导致结果异常。
- 全空列可用 `dropna=True` 删除。
- 需要行列小计时设置 `margins=True`；小计遵循 `aggfunc` 的计算方式，不是单纯整行/整列求和。
- 交叉表 `pd.crosstab` 只做计数；多条件时第一个参数用列表。
- 日期统计常用：
  - `df['日期'].dt.month`
  - `df['日期'].dt.year`
  - `df['日期'].dt.day`
- 交叉表统计结果是记录条数/订单笔数，不是人数。
- 结果可以导出到 Excel 新地址查看，例如 `C:\123.xlsx`。
