# 组合图：柱形图 + 折线图（Matplotlib 双轴图）

## 1. 本课目标与总体思路

- 本课以“柱形图 + 折线图”的组合图为例，讲解如何将两种图形画在同一张图中。
- 图一：柱形图表示“销售量”，使用左侧 y 轴。
- 图二：折线图表示“毛利率”，使用右侧副 y 轴。
- x 轴表示“班级”，由柱形图和折线图共享。
- 学会“柱形图 + 折线图”后，其他图形组合可按照同样思路类推。

```python
import pandas as pd

# 字体设置：按视频环境设置中文字体
# from matplotlib import font_manager

```

数据中主要包含以下列：

- `班级`
- `销售量`
- `毛利率`
- `毛利率2`

其中“毛利率”相关列会存在两种常见情况：

- 第一种：数据是小数形式，例如 `0.38`，需要乘以 `100%` 后才表示 `38%`。
- 第二种：数据已经是百分数数值，例如 `38.25`，只需要在显示时补一个 `%`，即显示为 `38.25%`。

对应公式：

\[
\text{百分比} = \text{原始小数} \times 100\%
\]

视频中特别强调：这两种情况在真实数据中都会遇到，后面分别演示处理方式。

## 3. 创建画布与图一柱形图

先创建画布并添加子图：

```python
fig = plt.figure()
ax1 = fig.add_subplot(1, 1, 1)
```

`fig.add_subplot(1, 1, 1)` 表示创建“一行一列中的第一个图”，也可以理解为当前只有一个图。

在图一中先绘制柱形图，表示班级与销售量：

```python
data.plot.bar(x='班级', y='销售量', ax=ax1)
```

- `x='班级'`：x 轴使用班级列。
- `y='销售量'`：柱形高度使用销售量。
- `ax=ax1`：将图形画到图一坐标轴上。

绘制后运行检查图形是否正常显示。

## 4. 图例设置与顶部留白

因为图中同时有柱形图和折线图，必须通过图例说明颜色和图形含义。

图例需要显式打开，例如：

```python
ax1.legend(loc='upper left')
```

- `legend()`：显示图例。
- `loc`：图例位置，例如上角、左上角、右上角等。
- 视频中先放在上角，随后发现图例距离图太紧。

为了给图例留出空间，需要调整 y 轴范围或刻度。视频中的数据上限约为 `12000`，再额外加 `500`，给图例留出上方空间：

```python
ax1.set_ylim([0, 12500])
```

- 原上限约为 `12000`。
- 再加 `500`，得到 `12500`。
- 范围参数需要使用列表形式，例如 `[0, 12500]`。
- 这样图例不会紧贴图形顶部。

## 5. 使用 `twinx()` 创建共享 x 轴的副坐标轴

柱形图使用左侧 y 轴，折线图需要使用右侧 y 轴，因此要创建副坐标轴。

```python
ax2 = ax1.twinx()
```

- `twinx()`：创建一个新的 y 轴，并与原图共享 x 轴。
- 这里的 x 轴“班级”同时控制柱形图和折线图。
- 柱形图看左侧 y 轴。
- 折线图看右侧副 y 轴。

视频中说明：

- 如果未来想共享 y 轴，可以把 `twinx()` 中的 `x` 改成 `y`，即使用 `twiny()`。
- `twinx()`：共享 x 轴，新增 y 轴。
- `twiny()`：共享 y 轴，新增 x 轴。

## 6. 绘制折线图并设置左右 y 轴标签

使用图二副坐标轴绘制折线图：

```python
ax2.plot(data['班级'], data['毛利率'], color='blue', label='毛利率')
```

- 第一个参数：x 轴数据，即班级。
- 第二个参数：y 轴数据，即毛利率。
- `color='blue'`：折线颜色为蓝色。
- `label='毛利率'`：给折线设置图例标签。

设置左右 y 轴标签，一边一个：

```python
ax1.set_ylabel('销售量')
ax2.set_ylabel('毛利率')
```

视频中说明：

- 图一的标签在左边。
- 图二的标签不能也放左边，应设置到右边。
- 左右各一个 y 轴标签，分别说明左右坐标轴含义。

图二也需要补全图例，例如：

```python
ax1.legend(loc='upper left')
ax2.legend(loc='upper right')
```

实际位置可根据图形遮挡情况调整，关键是不能让图例与图形混在一起。

## 7. 百分比坐标轴：两种数据形态分别处理

### 7.1 情况一：数据已经是百分数数值，只需要补 `%`

如果数据本身已经是 `38.25`、`55.96`、`61.58` 这种百分数数值，只需要在坐标轴上补一个百分号。

导入：

```python
import matplotlib.ticker as mtick
```

设置副 y 轴格式：

```python
ax2.yaxis.set_major_formatter(mtick.FormatStrFormatter('%.2f%%'))
```

- `ax2.yaxis`：设置图二的 y 轴。
- `set_major_formatter(...)`：设置主刻度标签格式。
- `FormatStrFormatter('%.2f%%')`：格式化字符串。
- `%.2f`：保留两位小数。
- `%%`：在格式字符串中转义为一个实际的百分号 `%`。

例如：

```python
'%.2f%%' % 38.25
```

显示结果类似：

```text
38.25%
```

但需要特别注意：`FormatStrFormatter` 只负责按格式显示，不会自动把 `0.38` 乘成 `38%`。

因此如果原始数据是 `0.38`，继续使用：

```python
mtick.FormatStrFormatter('%.2f%%')
```

会显示为：

```text
0.38%
```

这不是我们想要的 `38%`。视频中特意演示了这个“错误效果”，用于说明不能混用两种方案。

### 7.2 情况二：数据是 `0~1` 小数，需要自动乘以 `100%`

如果数据是 `0.38`、`0.62` 这种小数，希望显示成 `38%`、`62%`，需要使用 `PercentFormatter`。

导入：

```python
import matplotlib.ticker as ticker
```

设置副 y 轴格式：

```python
ax2.yaxis.set_major_formatter(ticker.PercentFormatter(xmax=1, decimals=2))
```

参数说明：

- `xmax=1`：表示 `100%` 对应原始数据值 `1`。
- `decimals=2`：百分比保留两位小数。
- 默认 `xmax` 为 `100`，所以如果直接对 `0.38` 使用默认设置，可能得到 `0.38%`。
- 当数据是 `0~1` 小数时，要把 `xmax` 设置为 `1`。

公式关系：

\[
\text{显示百分比} = \frac{y}{\text{xmax}} \times 100\%
\]

当 `xmax=1` 时：

\[
0.62 \rightarrow 62.00\%
\]

视频中还说明：

- 如果数据最高只到 `20%` 或 `30%`，也可根据实际数据设置 `xmax=0.2` 或 `0.3` 等。
- 但本课常规演示是 `0~1` 数据对应 `0%~100%`，因此使用 `xmax=1`。

## 8. 设置副 y 轴范围

使用 `PercentFormatter(xmax=1, decimals=2)` 后，如果坐标轴只显示到 `90%`，可以手动设置范围：

```python
ax2.set_ylim(0, 1)
```

- `0` 对应 `0%`。
- `1` 对应 `100%`。
- 这样副 y 轴完整显示 `0%~100%`。

如果使用“已经是百分数数值”的数据，如 `38.25`，则坐标轴范围应与之匹配，例如：

```python
ax2.set_ylim(0, 100)
```

核心原则：数据尺度、`formatter` 设置和 `ylim` 范围要一致。

## 9. 添加折线图数据标签

### 9.1 对已经是百分数数值的数据添加标签

如果 `毛利率2` 已经是 `38.25` 这种数值，只需要在标签后拼接 `%`：

```python
for x, y in zip(data['班级'], data['毛利率2']):
    plt.text(x, y, str(y) + '%', c='b', fontsize=20)
```

说明：

- `zip(data['班级'], data['毛利率2'])`：把班级和对应毛利率配对。
- `for x, y in ...`：循环取出每个点的横坐标和纵坐标。
- `plt.text(x, y, s)`：在坐标 `(x, y)` 处添加文本。
- `str(y) + '%'`：把数值转成字符串后拼接百分号。
- `c='b'`：颜色为蓝色，`c` 是 `color` 的简写。
- `fontsize=20`：字体大小为 20。

视频中说明：这里先不重点美化，重点是掌握数据标签的添加方法。

### 9.2 对 `0~1` 小数数据添加标签

如果使用小数形式的毛利率，需要在标签中先乘以 `100`，再四舍五入保留两位，再拼接 `%`：

```python
for x, y in zip(data['班级'], data['毛利率']):
    plt.text(x, y, str(round(y * 100, 2)) + '%', c='b', fontsize=20)
```

说明：

- `y * 100`：把小数转换成百分数数值。
- `round(y * 100, 2)`：对转换后的数值四舍五入，保留两位小数。
- `str(...)`：转换成字符串。
- `+ '%'`：拼接百分号。
- `c='b'`：蓝色。
- `fontsize=20`：字号为 20。

例如：

```text
0.6158 -> 61.58%
```

## 10. 两种百分比处理方案对比

| 数据情况 | 坐标轴格式化方法 | 数据标签处理方法 | 关键点 |
|---|---|---|---|
| 数据已经是 `38.25` 这种百分数数值 | `mtick.FormatStrFormatter('%.2f%%')` | `str(y) + '%'` | 只补 `%`，不再乘 100 |
| 数据是 `0.3825` 这种小数 | `ticker.PercentFormatter(xmax=1, decimals=2)` | `str(round(y * 100, 2)) + '%'` | 自动或手动乘以 100 |

## 11. 关键结论与踩坑记录

- 组合图必须有图例，否则无法区分柱形图、折线图及颜色含义。
- 图例离图形太紧时，可通过调整 y 轴范围留出顶部空间，例如 `set_ylim([0, 12500])`。
- 双 y 轴组合图使用 `ax1.twinx()`。
- `twinx()` 共享 x 轴、新增 y 轴；`twiny()` 共享 y 轴、新增 x 轴。
- 左侧 y 轴标签和右侧副 y 轴标签要分别设置，做到“一边一个”。
- `FormatStrFormatter('%.2f%%')` 只添加 `%` 和格式化小数位，不会自动把 `0.38` 变成 `38%`。
- `PercentFormatter(xmax=1, decimals=2)` 用于处理 `0~1` 小数，可自动将 `0.38` 显示为 `38.00%`。
- `xmax` 表示“100% 对应的原始数据值”，默认常为 `100`；小数数据通常设为 `1`。
- `decimals=2` 表示百分比保留两位小数。
- 副 y 轴范围要与数据尺度一致：小数数据常用 `ax2.set_ylim(0, 1)`，已是百分数数值的数据常用 `ax2.set_ylim(0, 100)`。
- 数据标签要与坐标轴的数据尺度保持一致：坐标轴显示百分比，标签也应拼接 `%`；小数数据标签需先 `y * 100`，再用 `round(..., 2)` 保留两位。
- 若实际工作中遇到更复杂的数据形态，应先弄清数据本身含义、坐标系尺度和格式化函数之间的关系，再决定使用哪种格式化方式。
