## 一、四个统计概念：平均数、加权平均、中位数、众数

### 1. 平均数

- 平均数是最常见的统计量。
- 计算方法：把所有数加在一起，再除以数据个数。  
  \[
  \bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i
  \]
- 讲师强调：做数据分析时不要“动不动就求平均数”，平均数很容易被极端值拉偏。
- 例子：新闻中常说“某城市平均工资多少”，很多人会说自己“给城市拉后腿了”。这是因为平均工资会被少数高收入者拉高，不能很好代表大多数普通人的收入水平。
- 中国移动工资例子：
  - 老总年薪上千万，经理年薪几百万，底层员工月薪可能只有两千。
  - 如果只看平均数，会显得“中国移动工资很高”，但底层员工的实际收入与平均数差距很大。
  - 因此，存在极端值或分布偏斜时，平均数不一定合适。

### 2. 加权平均

- 加权平均不是简单把每个值同等看待，而是每个值有不同权重或占比。
- 设数据为 \(x_i\)，权重为 \(w_i\)，加权平均公式为：  
  \[
  \bar{x}_w=\frac{\sum_{i=1}^{n}w_i x_i}{\sum_{i=1}^{n}w_i}
  \]
- 如果权重已经表示为百分比且总和为 1，则：  
  \[
  \bar{x}_w=\sum_{i=1}^{n}w_i x_i
  \]
- 讲师用 \(x、y、z、n\) 的占比举例：某个值占百分之多少、另一个值占百分之多少，最后按权重计算平均值。
- NumPy 中可用 `np.average()` 并传入 `weights` 参数计算加权平均。

### 3. 中位数

- 中位数不是直接取数组中间位置的元素，而是先排序，再取中间值。
- 可以从小到大排序，也可以从大到小排序，结果本质一致。
- 奇数个数据：取排序后最中间的那个数。
- 偶数个数据：取排序后中间两个数，相加后除以 2。
- 讲师举例：
  - 马云、孙兴华、马化腾三个人，如果按财富排序，中位数是排序后中间的那个人，而不是随便从中间拿一个。
  - 三个人中可能存在两个特别有钱、一个相对普通的情况，这种数据分布下直接取中位数不一定合适，求平均也可能更合适。
  - 五个人时，排序后取中间那个；六个人时，取中间两个数的平均值。
- 中位数的意义：当数据中有极端值、平均数容易被拉偏时，中位数更能代表“中间水平”。
- 讲师强调：不要动不动求平均数，很多时候应该用中位数。

### 4. 众数

- 众数：一组数据中出现次数最多的数。
- 例子：班里筹办毕业会，班长调查全班同学爱吃的水果。
  - 统计所有人提交的水果名称。
  - 如果 40 个学生中有 20 个人选择苹果，苹果出现次数最多，那么苹果就是众数。
  - 此时应买苹果，因为少数服从多数。
  - 这种问题不应求平均数，也不应求中位数，而应关注众数。
- 众数适合处理分类数据、投票选择、出现频率最高项等问题。

## 二、一维数组的数学和统计方法

先导入 NumPy 并创建一维数组：

    import numpy as np

    arr = np.array([1, 2, 3, 4, 3, 5, 3, 6])
    print(arr)

### 1. 求和：`sum`

- 使用 `arr.sum()` 或 `np.sum(arr)`。
- 作用：把一维数组中所有元素相加。
- 一维数组只有一个轴，即 0 轴，因此求和时就是从左到右依次累加。
- 示例数组求和：  
  \[
  1+2+3+4+3+5+3+6=27
  \]
- 一维数组的求和不存在复杂的轴向问题。

### 2. 乘积：`prod`

- 使用 `arr.prod()`。
- 作用：把数组中所有元素相乘。
- 计算过程为：先算 \(1\times 2\)，再乘 3，再乘 4，一直乘到最后一个元素。
- 示例结果：  
  \[
  1\times2\times3\times4\times3\times5\times3\times6=6480
  \]

### 3. 累积和：`cumsum`

- 使用 `arr.cumsum()`。
- 作用：从第一个元素开始，计算元素的累积之和，返回与原数组长度相同的数组。
- 如果第一个元素是 0，则第一个累积和就是 0；之后依次为：
  - 第 1 个位置：0
  - 第 2 个位置：0 + 下一个数
  - 第 3 个位置：前面累积结果 + 下一个数
- 讲师说明：设置数组时如果首元素是 0 也没关系，因为 `cumsum` 可以从 0 开始累积。
- 对示例数组 `[1,2,3,4,3,5,3,6]`，累积和为：  
  \[
  [1,\ 1+2=3,\ 3+3=6,\ 6+4=10,\ 10+3=13,\ 13+5=18,\ 18+3=21,\ 21+6=27]
  \]

### 4. 累积积：`cumprod`

- 使用 `arr.cumprod()`。
- 作用：从第一个元素开始，计算元素的累积乘积。
- 注意：累积积必须从 1 开始，不能从 0 开始。
  - 如果首元素是 0，则 \(0\times 任何数=0\)，后面所有累积积都会变成 0。
- 对示例数组 `[1,2,3,4,3,5,3,6]`，累积积为：  
  \[
  [1,\ 1\times2=2,\ 2\times3=6,\ 6\times4=24,\ 24\times3=72,\ 72\times5=360,\ 360\times3=1080,\ 1080\times6=6480]
  \]
- 讲师特别提醒：做累积积时，数组首元素要注意不要设成 0。

### 5. 最大值：`max`

- 使用 `arr.max()`。
- 作用：返回数组中的最大值。
- 示例中最大值为 `6`。

### 6. 最小值：`min`

- 使用 `arr.min()`。
- 作用：返回数组中的最小值。
- 示例中最小值为 `1`。

### 7. 最大值下标：`argmax`

- 使用 `arr.argmax()`。
- 作用：返回最大值所在的下标/位置。
- NumPy 下标从 0 开始计数。
- 示例中最大值 `6` 在索引 `7` 上，因此 `arr.argmax()` 返回 `7`。
- 注意区分：
  - `max()` 返回最大值本身。
  - `argmax()` 返回最大值所在的位置。

### 8. 最小值下标：`argmin`

- 使用 `arr.argmin()`。
- 作用：返回最小值所在的下标/位置。
- 示例中最小值 `1` 在索引 `0` 上，因此返回 `0`。
- 注意区分：
  - `min()` 返回最小值本身。
  - `argmin()` 返回最小值所在的位置。

### 9. 平均数：`mean`

- 使用 `arr.mean()`。
- 作用：计算一维数组的算术平均数。
- 计算方式：所有数加在一起，再除以元素个数。
- 一维数组中 `mean()` 不涉及轴向问题。

### 10. 中位数：`median`

- 使用 `np.median(arr)`。
- 作用：先排序，再取中间值。
- 如果数组长度为奇数，取中间那一个数。
- 如果数组长度为偶数，取中间两个数相加后除以 2。
- 讲师示例中的数组长度为偶数，因此中位数由中间两个数取平均得到。

### 11. 加权平均：`average`

- 使用 `np.average()`。
- 可以通过 `weights` 参数传入权重：  
  `np.average(arr, weights=weights)`
- 作用：按照权重公式计算加权平均数。
- 讲师没有在课堂上逐项口算，而是说明其计算依据就是前面的加权平均公式：  
  \[
  \bar{x}_w=\frac{\sum_{i=1}^{n}w_i x_i}{\sum_{i=1}^{n}w_i}
  \]

### 12. 众数：NumPy 中不推荐直接计算

- 讲师强调：NumPy 里不能直接、方便地计算众数，也不建议在 NumPy 里重点计算众数。
- 一维数组可以用 `np.bincount()` 配合 `argmax()` 求众数：
  
      counts = np.bincount(arr)
      mode_value = counts.argmax()
  
  - `np.bincount(arr)`：统计每个非负整数出现的次数。
  - `counts.argmax()`：找到出现次数最多的那个下标。
  - 对于非负整数数组，这个下标通常就是出现次数最多的值。
- 限制和踩坑：
  - `np.bincount()` 只能统计非负整数。
  - 不能统计浮点数。
  - 不能应用于二维数组。
- 更推荐使用 Pandas 计算众数：
  
      import pandas as pd

      # 一维数组
      pd.Series(arr).mode()

      # 二维数组
      pd.DataFrame(arr2).mode()
  
  - Pandas 中一维数据用 `Series`。
  - 二维数据用 `DataFrame`。
  - 调用 `.mode()` 方法即可求众数。
- 结论：NumPy 里不建议专门看重数，Pandas 里一条语句就能完成，后期讲 Pandas 时会更方便。

## 三、二维数组的数学和统计方法

二维数组涉及轴向问题，比一维数组复杂一些。视频中的三行三列示例，按轴向演示可复现为：

    arr2 = np.array([
        [1, 3, 6],
        [9, 2, 3],
        [1, 5, 2]
    ])
    print(arr2)

### 1. 二维数组求和：`sum`

- 使用 `arr2.sum()`。
- 不带 `axis` 参数时，求和是把所有元素从头到尾全部加起来。
- 示例所有元素相加：  
  \[
  1+3+6+9+2+3+1+5+2=32
  \]
- 二维数组的总和不涉及轴向，直接全部元素求和。

### 2. 二维数组乘积：`prod`

- 使用 `arr2.prod()`。
- 作用：把所有元素从头到尾乘一遍。
- 与一维数组类似，只是二维数组会按照展平顺序依次相乘。

### 3. 二维数组累积和：`cumsum`

- 使用 `arr2.cumsum()`。
- 注意：二维数组的 `cumsum()` 返回的是一维数组，而不是二维数组。
- 计算顺序：按数组展平顺序进行，先第一行，再第二行，再第三行。
- 对示例数组展平顺序为：  
  \[
  1,\ 3,\ 6,\ 9,\ 2,\ 3,\ 1,\ 5,\ 2
  \]
- 累积和计算过程：
  - 第 1 个：1
  - 第 2 个：1 + 3 = 4
  - 第 3 个：4 + 6 = 10
  - 第 4 个：10 + 9 = 19
  - 第 5 个：19 + 2 = 21
  - 后续继续依次累加
- 结果形如：  
  \[
  [1,\ 4,\ 10,\ 19,\ 21,\ 24,\ 25,\ 30,\ 32]
  \]

### 4. 二维数组累积积：`cumprod`

- 使用 `arr2.cumprod()`。
- 与 `cumsum()` 类似，只是把“加”换成“乘”。
- 返回值也是一维数组，按展平顺序累积。
- 同样必须从 1 开始，不能从 0 开始，否则后面全部变成 0。

### 5. 二维数组最大值、最小值

- `arr2.max()`：返回整个二维数组中的最大值。
- `arr2.min()`：返回整个二维数组中的最小值。
- 示例中最大值为 `9`，最小值为 `1`。

### 6. 二维数组最大值、最小值下标

- `arr2.argmax()`：返回最大值在展平后的下标。
- `arr2.argmin()`：返回最小值在展平后的下标。
- 二维数组的下标顺序按展平顺序走：
  - 先走完第 1 行：索引 0、1、2
  - 再走第 2 行：索引 3、4、5
  - 再走第 3 行：索引 6、7、8
- 示例中最大值 `9` 在索引 `3`，因此 `argmax()` 返回 `3`。
- 示例中最小值 `1` 在索引 `0`，因此 `argmin()` 返回 `0`。
- 注意：二维数组的 `argmax()` / `argmin()` 返回的是展平后的位置，而不是行列坐标。

### 7. 二维数组平均数：`mean`

- 使用 `arr2.mean()`。
- 作用：把所有元素加起来，再除以元素总数。
- 不带 `axis` 时，是全局平均，不区分行和列。

### 8. 二维数组中位数：`median`

- 使用 `np.median(arr2)`。
- 作用：把所有元素排序后取中间值。
- 示例为 3×3 共 9 个数，9 是奇数个，因此取排序后中间的那个数。
- 示例中排序后中位数为 `3`。

### 9. 二维数组加权平均：`average`

- 使用 `np.average(arr2, weights=...)`。
- 按照权重公式计算，和前面加权平均公式一致。

### 10. 二维数组众数

- 讲师再次强调：不建议在 NumPy 中计算二维数组众数。
- 二维数组可用 Pandas：
  
      pd.DataFrame(arr2).mode()
  
- Pandas 一行语句即可完成，后期讲 Pandas 时会详细使用。

## 四、`axis` 参数：按行还是按列计算

### 1. 基本结论

- 所有数学和统计函数都有 `axis` 参数，可以指定按行或按列计算。
- 讲师给出的核心记忆：
  - 0 轴代表行。
  - 1 轴代表列。
- 如果按 0 轴计算，就是行与行之间对应位置相加。
- 如果按 1 轴计算，就是列与列之间对应位置相加。
- 矩阵中很容易把行、列弄混，建议结合 Excel 理解。

### 2. `axis=0`：行与行之间相加

- 对三行三列数组，`axis=0` 表示把三行同一位置的数加在一起，最后变成一行。
- 示例：
  
      arr2.sum(axis=0)
  
  按视频轴向演示，结果为：
  
      [11, 10, 11]
  
- 解释：第一列三个数相加、第二列三个数相加、第三列三个数相加。
- 讲师强调：不要把“行与行之间相加”和“列与列之间相加”混淆。`axis=0` 是行方向上的聚合，即把多行压缩成一行。

### 3. `axis=1`：列与列之间相加

- `axis=1` 表示把每一行内部的各列元素相加，得到每一行的和。
- 示例：
  
      arr2.sum(axis=1)
  
  按视频轴向演示，结果为：
  
      [10, 14, 8]
  
- 解释：
  - 第一行：\(1+3+6=10\)
  - 第二行：\(9+2+3=14\)
  - 第三行：\(1+5+2=8\)
- 注意：视频字幕中可能出现“18”等识别误差，按示例数组实际计算结果为 `8`。

### 4. 用 Excel 辅助理解

- 行相加：同一行内各列横向相加。
  - 例如第一行：\(1+3+6=10\)。
  - 这对应 `axis=1` 的效果。
- 列相加：同一列内各行纵向相加。
  - 例如第一列：\(1+9+1=11\)。
  - 这对应 `axis=0` 的效果。
- 讲师总结：
  - 零轴是行。
  - 一轴是列。
  - 按零轴加，是行和行之间的对应元素相加。
  - 按一轴加，是列和列之间的对应元素相加。
- 实际写代码时的记忆方式：
  - `axis=0`：纵向压缩行，得到每一列的结果。
  - `axis=1`：横向压缩列，得到每一行的结果。

## 五、数组与现实数据：行是样本，列是特征

- 数组在现实数据中可以这样理解：
  - 行：对应一条样本数据、一条记录。
  - 列：对应样本中的各个特征。
- 例如 Excel 中常见产品单价、销售数量：
  - 产品单价一列。
  - 销售数量一列。
- 产品单价和销售数量没有直接可比性：
  - 单价可能是 1 元、1.5 元、2 元。
  - 销售数量可能是 100 个、250 个、160 个、140 个。
  - 两者不是同一量纲，直接比较没有意义。
- 但两者可以相乘，得到销售金额：
  \[
  \text{销售金额}=\text{单价}\times\text{销售数量}
  \]
- 做数据分析时，通常需要进行标准化，使不同特征具有可比性。
- 讲师提到的标准化思路：
  - 数组减去平均值数组。
  - 按 0 轴计算平均值。
  - 再除以方差数组或标准差数组。
  - 后续课程会详细讲标准化。
- 标准化的一般形式可写为：
  \[
  z=\frac{x-\mu}{\sigma}
  \]
  按列标准化时可写为：
  \[
  z_{ij}=\frac{x_{ij}-\bar{x}_j}{s_j}
  \]
- 标准化的目的：消除量纲影响，让不同特征可以比较，后续再深入讲解。

## 六、本节关键结论与易错点

- 四个统计概念必须区分：
  - 平均数：所有数求和后除以个数，容易受极端值影响。
  - 加权平均：每个值按权重计算，公式为  
    \[
    \bar{x}_w=\frac{\sum w_i x_i}{\sum w_i}
    \]
  - 中位数：排序后取中间；奇数取中间一个，偶数取中间两个平均。
  - 众数：出现次数最多的值，适合分类数据和投票统计。
- `max()` / `min()` 返回最值本身。
- `argmax()` / `argmin()` 返回最值所在的下标，下标从 0 开始。
- `cumsum()` 是累积和。
- `cumprod()` 是累积积，必须从 1 开始，不能从 0 开始。
- 一维数组只有一个轴，求和、乘积等操作就是从前往后依次计算。
- 二维数组的 `cumsum()`、`cumprod()` 返回一维数组，按展平顺序计算。
- 二维数组的 `argmax()`、`argmin()` 返回展平后的索引，不是行列坐标。
- NumPy 中计算众数不方便：
  - `np.bincount()` 只适合非负整数。
  - 不能统计浮点数。
  - 不能用于二维数组。
  - 更推荐 Pandas 的 `Series.mode()`、`DataFrame.mode()`。
- `axis` 参数是二维数组的核心：
  - 0 轴代表行。
  - 1 轴代表列。
  - `axis=0`：行与行对应位置相加，把多行压成一行。
  - `axis=1`：每一行内部各列相加，得到每行的结果。
  - 用 Excel 记忆：横向同一行相加对应 `axis=1`；纵向同一列相加对应 `axis=0`。
- 数据分析中不要盲目求平均数，遇到极端值或偏态分布时要考虑中位数、众数、加权平均等更合适的统计量。
