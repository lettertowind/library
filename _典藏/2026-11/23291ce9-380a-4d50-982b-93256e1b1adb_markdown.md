## 2. 按行索引的奇偶性分组

- 目标：按索引行是奇数行还是偶数行进行分组。
- 判断奇偶：
  - 余数为 0：偶数。
  - 余数不为 0：奇数。
- 取索引：`data.index`
- 按偶数行分组示例：
  - `data.groupby(data.index % 2 == 0)[['语文', '数学', '英语']].sum()`
- 解释：
  - `data.index % 2 == 0` 返回布尔 Series。
  - `True` 表示偶数行，`False` 表示奇数行。
  - `groupby` 按这个布尔结果分组。
  - `[['语文', '数学', '英语']]` 选择需要聚合的列。
  - `.sum()` 对分组后的成绩求和。
- 输出结果中会显示 `True` / `False` 分组，分别对应不同索引奇偶性的统计结果。
- 若改为不等于 0：
  - `data.groupby(data.index % 2 != 0)[['语文', '数学', '英语']].sum()`
  - 分组结果会反过来。
- 关键口诀：
  - 用 `groupby` 时一定要明确“按谁分组、按谁聚合”。
  - 选择聚合列时使用双层列表：`[['列1', '列2', ...]]`，不要写错。
- 示例代码结构：
  - `data.groupby(分组条件)[[聚合列列表]].聚合函数()`

## 4. 按序号阈值分组

- 目标：按 `序号` 是否大于等于 5 进行分组。
- 示例代码：
  - `data.groupby(data['序号'] >= 5)[['语文', '数学', '英语']].sum()`
- 解释：
  - `data['序号'] >= 5` 返回布尔 Series。
  - `True` 表示序号大于等于 5 的行。
  - `False` 表示不满足该条件的行，即序号小于 5 的行。
- 输出同样显示 `True` / `False` 分组结果。
- 讲师口述中提到“大于等于 5”和“小于等于 5”，但按布尔条件 `>= 5` 实际互斥分组应为：
  - `True`：`>= 5`
  - `False`：`< 5`
- 注意边界：若要严格分组，应明确使用 `>=5` 与 `<5`，避免 `<=5` 与 `>=5` 在 5 处重叠。
- 讲师结论：这种按索引号或“几个一组”的方式在实际工作中使用不多，了解即可。

## 5. 按姓名首字或第二个字分组

- 目标：按姓名第一个字，也就是姓氏，进行分组汇总。
- 示例场景：
  - 姓丁、姓卢各有一个。
  - 姓张、姓李、姓王等有多个。
  - 按姓氏汇总后，多个同姓人员的成绩会相加。
- 取姓名首字：
  - `data['姓名'].str[0]`
- 按姓氏分组并聚合：
  - `data.groupby(data['姓名'].str[0])[['语文', '数学', '英语']].sum()`
- 解释：
  - `data['姓名']` 是字符串列。
  - `.str` 是 Pandas 的字符串访问器。
  - `[0]` 取第一个字符。
- 按姓名第一个字和第二个字同时分组：
  - `data.groupby([data['姓名'].str[0], data['姓名'].str[1]])[['语文', '数学', '英语']].sum()`
- 解释：
  - `groupby` 可传入多个分组键的列表。
  - 第一个键为姓氏首字，第二个键为姓名第二个字。
  - 这样会把同姓但第二个字不同的人进一步拆成不同组。
- 视频示例结果：
  - 姓丁的第二个字如“智”，单独成组。
  - 姓卢的第二个字如“海”，单独成组。
  - 姓张的会按第二个字继续拆分，如“一”“荣”等。
  - 姓李的有多个，第二个字分别为“平”“永”“超”等，会分成不同组。
  - 姓王的也会按第二个字继续细分。
- 切片尝试与结论：
  - 讲师尝试用切片范围一次取两个字，但结果只显示一个，未达到预期。
  - 当前示例采用分别取 `str[0]` 和 `str[1]` 的方式。
- 复姓限制：
  - 对于“司马”“诸葛”等复姓，目前这种按首字、第二字切分的方法无法正确识别复姓。
  - 讲师明确表示当前没有解决复姓问题。
  - 后续可期待通过编写小程序或更复杂规则处理。

## 6. 按指定班级分组：`isin`

- 目标：只对指定班级进行分组，例如只包括“一班”和“二班”。
- 使用 `isin` 判断列中元素是否在列表中：
  - `data['班级'].isin(['一班', '二班'])`
- 按该条件分组：
  - `data.groupby(data['班级'].isin(['一班', '二班']))[['语文', '数学', '英语']].sum()`
- 解释：
  - `isin([...])` 返回布尔 Series。
  - `True`：该行班级在指定列表中。
  - `False`：该行班级不在指定列表中。
- 输出为 `True` / `False` 两组统计：
  - 包括一班和二班的人员归入 `True`。
  - 不包括其他班级的人员归入 `False`。
- 易错点：
  - 这里不是用 Python 的 `in`，而是 Pandas Series 的 `isin`。
  - 不存在 `is not in` 这样的函数。
  - 不要写 `is not in`。
- 取反写法：
  - 在 `isin` 表达式前加 `~`：
  - `~data['班级'].isin(['一班', '二班'])`
- 讲师提示：
  - `~` 可通过 Shift + 数字 1 左侧的键输入。
  - 取反符号应加在 `data['班级'].isin(...)` 这个表达式前面，而不是写成不存在的 `is not in`。

## 7. 按日期、月份、小时分组

- 目标：从“日期 + 时间”列中提取年、月、小时，进行分组统计。
- 取年份：
  - `data['时间'].dt.year`
- 按年份分组汇总：
  - `data.groupby(data['时间'].dt.year)[['数学', '语文', '英语']].sum()`
- 解释：
  - `data['时间']` 选择时间列。
  - `.dt` 是 Pandas 的日期时间访问器。
  - `.year` 取出年份。
- 视频示例数据只有 2020 年，因此按年分组只显示 2020 年。
  - 若数据中还包含 2019、2018 等年份，可按年分别汇总。
- 取月份：
  - `data['时间'].dt.month`
- 按年和月分组：
  - `data.groupby([data['时间'].dt.year, data['时间'].dt.month])[['数学', '语文', '英语']].sum()`
- 注意：
  - 多个分组键要用列表形式 `[...]`。
  - 视频示例数据只有 5 月，因此按月分组只显示 2020 年 5 月，无法展示多月分组效果。
- 取小时：
  - `data['时间'].dt.hour`
- 按年和小时分组：
  - `data.groupby([data['时间'].dt.year, data['时间'].dt.hour])[['数学', '语文', '英语']].sum()`
- 视频示例输出包括 8 点、9 点、17 点、18 点等不同小时段。
- 实际应用：
  - 订单、流水号中常包含日期和时间。
  - 若要查看 2020 年 17 点的销售情况，可用 `dt.year` 和 `dt.hour` 组合分组。
  - 销售部门可据此统计不同时段的销售表现。
- 与 Excel 对比：
  - Excel 中需要分列、提取、再统计，步骤较多。
  - Pandas 中用 `dt` 访问器可直接提取年、月、小时并分组，效率更高。

## 8. `pipe`、`apply`、`map` 三个重要方法

- 讲师介绍：Pandas 中有三个重要方法：
  - 表格函数/表函数：`pipe`
  - 行列函数：`apply`
  - 元素函数：`map`
- 本课只初步接触 `pipe`。
- 讲师强调：`pipe` 不是一句话两句话能讲清楚的，后续会有专门课程详细介绍。
- `pipe` 分组示例：
  - `data.pipe(pd.DataFrame.groupby, '班级').sum()`
- 解释：
  - `pd.DataFrame.groupby` 是 DataFrame 的 `groupby` 方法引用。
  - `pipe` 会把 `data` 作为第一个参数传入 `groupby`。
  - `'班级'` 是传给 `groupby` 的分组字段。
  - 最后调用 `.sum()` 进行聚合。
- 运行效果：按 `班级` 分组并聚合。
- 讲师结论：
  - `pipe` 可用于链式调用和函数式组织代码。
  - 本课只做介绍，重点仍是 `groupby` 的分组键创建。

## 9. 学习建议与关键结论

- 分组聚合的核心结构：
  - `data.groupby(分组键)[[聚合列]].聚合函数()`
- 必须明确“按谁分组、按谁聚合”。
- 聚合列选择用双层列表：
  - `[['语文', '数学', '英语']]`
- 常见分组键类型：
  - 布尔条件：如 `data.index % 2 == 0`、`data['序号'] >= 5`
  - 单列：如 `data['姓名'].str[0]`、`data['班级'].isin([...])`
  - 多列/多条件：如 `[data['姓名'].str[0], data['姓名'].str[1]]`、`[data['时间'].dt.year, data['时间'].dt.hour]`
- 日期时间分组关键：
  - 年：`.dt.year`
  - 月：`.dt.month`
  - 小时：`.dt.hour`
- 指定集合判断：
  - 用 `isin([...])`
  - 没有 `is not in`
  - 取反用 `~data['列'].isin([...])`
- 复姓问题：
  - 当前按首字、第二字分组无法处理“司马”“诸葛”等复姓。
- 实战建议：
  - 活学活用，将示例套用到自己的业务数据中。
  - 实际数据通常比示例复杂，会遇到多种问题。
  - 技术问题可通过搜索引擎查询。
  - 报错时复制完整报错信息到搜索引擎检索。
