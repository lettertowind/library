## 2. 使用 `get_dummies` 拆分字符串

### 2.1 基本用途

`Series.str.get_dummies(sep=...)` 可以按照指定分隔符把字符串拆开，并将拆分后的元素转换为哑变量列。

视频示例中的“距离”列包含类似以下取值：

- 近距离
- 中距离
- 远距离
- 中远距离

使用字符 `距` 作为分隔符：

`df['距离'].str.get_dummies(sep='距')`

拆分逻辑：

- `近距离` 按 `距` 分割为 `近`、`离`。
- `中距离` 按 `距` 分割为 `中`、`离`。
- `远距离` 按 `距` 分割为 `远`、`离`。
- `中远距离` 按 `距` 分割为 `中远` 或相关 token，并继续产生 `中`、`远`、`离` 等标记效果。

结果中会出现拆分后 token 对应的列，例如 `中`、`远`、`近`、`离`。每一行在对应 token 列上标记是否出现。视频以第 0 行“近距离”为例：该行没有“中”、没有“远”，只包含“近”和“离”，因此对应标记为 0/1 形式。

### 2.2 使用场景

- 处理一个字段中包含多个标签、多个分类值的情况。
- 类似多值字段的 one-hot 编码。
- 视频评价：这种操作平时可能用得不多，但需要用时往往“无可替代”。

## 3. 使用 `translate` 进行指定字符替换

### 3.1 创建映射表

视频示例要将“距离”中的“距”和“离”替换成汉语拼音。做法是先创建字符映射字典，再使用 `translate` 替换。

关键方法：

- `str.maketrans(...)`：创建字符映射表。
- `Series.str.translate(table)`：按照映射表逐字符替换。

示例思路：

`table = str.maketrans({'距': 'ju', '离': 'li'})`

`df['距离'].str.translate(table)`

这样可以把指定的字符映射为指定内容。视频说明这种方式和普通 `replace` 有点像，但它更适合按字符建立映射关系进行替换。

### 3.2 注意

- `translate` 更偏向逐字符映射。
- 如果要做整段字符串或复杂模式替换，应使用 `replace` 或正则替换。
- 映射表中写哪些字符，就替换哪些字符，未指定的字符保持不变。

## 4. 查找字符位置：`find`、`rfind`、`index`、`rindex`

### 4.1 日期列示例

视频使用日期列演示查找横杠 `-` 的位置。日期列类似：

`2020-05-01`

先转换为字符串：

`df['日期'].astype(str).str.find('-')`

在 `2020-05-01` 中，索引从 0 开始：

- `0`：`2`
- `1`：`0`
- `2`：`2`
- `3`：`0`
- `4`：`-`

因此 `str.find('-')` 返回 `4`。

### 4.2 指定起始位置

可以指定查找起始位置，例如从第 5 个位置开始查找：

`df['日期'].astype(str).str.find('-', 5)`

这样会跳过第一个横杠，找到第二个横杠。示例中返回 `7`。

视频还说明可以指定结束位置，用于控制查找范围。

### 4.3 找不到时的返回值

- `find` 找不到指定字符时返回 `-1`。
- 视频示例中查找一个不存在的内容，返回 `-1`。
- `rfind` 从右边开始查找。
- `index` 与 `find` 类似，但找不到时会报错。
- `rindex` 从右边开始查找，找不到也会报错。

记忆要点：

| 方法 | 方向 | 找不到时 |
|---|---|---|
| `find` | 从左往右 | 返回 `-1` |
| `rfind` | 从右往左 | 返回 `-1` |
| `index` | 从左往右 | 报错 |
| `rindex` | 从右往左 | 报错 |

视频建议：需要先掌握 Python 基础，再学习 Pandas；如果要深入 Pandas，也建议先了解 Numpy，因为 Numpy 是科学计算的基础。

## 5. 大小写转换方法

视频在字符串操作收尾部分集中介绍了常见大小写方法。

| 方法 | 作用 |
|---|---|
| `lower()` | 将所有英文字符转为小写 |
| `upper()` | 将所有英文字符转为大写 |
| `title()` | 将每个单词的首字母转为大写 |
| `capitalize()` | 将字符串第一个字符转为大写；视频强调它不同于 `title`，不会把每个单词首字母都大写 |
| `swapcase()` | 大写变小写，小写变大写 |

重点区分：

- `title()` 处理“每个单词”的首字母。
- `capitalize()` 只处理整段字符串的首字符。Python 实际行为中，`capitalize()` 会把首字符大写，其余字符转为小写；使用时要注意与 `title()` 的区别。

## 6. 字符串内容判断方法

视频列出并解释了若干判断方法。

| 方法 | 作用 |
|---|---|
| `isalpha()` | 判断是否全是字母 |
| `isdigit()` | 判断是否全是数字 |
| `isalnum()` | 判断是否全是字母或数字 |
| `isspace()` | 判断是否全是空格/空白字符 |
| `islower()` | 判断是否全是小写 |
| `istitle()` | 判断是否为标题格式，即每个单词首字母大写 |

视频还特别讨论了“数字判断”的差异：

- 有的方法主要识别 Unicode 数字。
- 有的方法可识别罗马数字。
- 有的方法可识别汉字数字。
- 对普通阿拉伯数字，多种方法通常都可以判断。
- 实际项目中很少在同一列同时混用阿拉伯数字、罗马数字、汉字数字等不同数字体系。
- 技术场景中通常更倾向使用阿拉伯数字，因为中文数字在排序等方面不方便。
- 具体使用哪个方法，应根据数据实际情况选择。

视频建议不必死记所有方法，用到时查阅笔记或视频即可。

## 7. 在 Pandas 字符串操作中使用正则表达式

### 7.1 学习前提

视频明确说明：本节不系统讲解正则表达式本身，只讲如何在 Pandas 的字符串操作中使用正则表达式。

学习建议：

- 正则表达式非常重要，建议先学习 Python 基础中的正则表达式课程。
- 正则表达式不仅用于 Python，在 VBA、Excel 等场景中也很有用。
- 如果不掌握正则表达式，后续很多文本处理工作会受限。
- 视频提到其正则表达式内容在 Python 基础/进阶爬虫相关课程的前几节中，建议先学习再回来使用。

### 7.2 `str.match` 判断是否匹配

视频使用“状态”列演示。状态列示例值包括：

- 满血激活
- NA

使用 `Series.str.match(pattern)` 可以判断字符串是否匹配指定正则表达式，返回 `True` 或 `False`。

视频示例中，模式大致表达：

- 前两位为任意数字或指定数量的字符。
- 后面跟着“激”等固定字符。
- 若匹配，则返回 `True`；否则返回 `False`。

示例表达类似：

`df['状态'].str.match(r'\d{2}激')`

其中：

- `\d` 表示数字。
- `{2}` 是数量词，表示前面内容出现两次。
- `激` 是固定字符。

视频还演示了将 `NA` 替换成 `False`，也可以替换成 `True` 或任意想显示的内容。注意中英文符号切换可能导致正则表达式或替换内容出错。

### 7.3 `str.extract` 分组捕获

分组捕获使用：

`Series.str.extract(pattern)`

视频以日期列为例，提取年、月、日等信息。

日期列操作前必须先转换：

`df['日期'].astype(str).str.extract(...)`

正则表达式中的括号表示捕获组。例如日期模式可以写成类似：

`(\d{4})-(\d{2})-(\d{2})`

含义：

- `\d{4}`：四位数字，表示年份。
- `(\d{2})`：两位数字，表示月份。
- `(\d{2})`：两位数字，表示日期。
- 括号中的内容会被提取为结果列。

视频演示效果：

- 只给月份和日期加括号时，提取结果主要显示月和日。
- 给年份也加括号时，会分成三组，可得到年、月、日三列。
- 只保留中间一个括号时，就只提取月份这一组。
- 因此用正则表达式提取年月日非常方便。

注意：视频中的日期数据可能显示为 `2020-05-01` 这类格式；如果实际数据是 `2020年05月01日`，则正则需相应写成 `(\d{4})年(\d{2})月(\d{2})日`。核心思想是：用括号分组，`extract` 只提取括号中的组。

### 7.4 `str.replace` 正则替换与日期格式重排

视频演示使用正则替换把日期格式改为类似国外常见的“日-月-年”顺序。

原始日期示例：

`2020-05-01`

目标思路：把年、月、日分成三组，再按第 3 组、第 2 组、第 1 组的顺序重排：

- 第 1 组：年
- 第 2 组：月
- 第 3 组：日
- 替换顺序：`\3-\2-\1`

正则模式类似：

`(\d{4})-(\d{2})-(\d{2})`

替换内容类似：

`r'\3-\2-\1'`

结果可得到：

`01-05-2020`

视频强调：

- 替换字符串中的 `\1`、`\2`、`\3` 是反向引用，分别代表第 1、2、3 个捕获组。
- 反斜杠在普通字符串中可能被转义，因此建议使用原始字符串 `r'...'`。
- 使用原始字符串后，`\1`、`\2`、`\3` 会按正则反向引用的含义处理。
- 可以自定义各组之间的连接符，例如使用 `-` 或其他字符。
- 如果使用 Pandas 的 `str.replace` 做正则替换，应确保按正则模式处理；必要时显式设置 `regex=True`。
- 日期列仍然要先 `.astype(str)`，然后才能使用 `.str.replace`。

示例表达：

`df['日期'].astype(str).str.replace(r'(\d{4})-(\d{2})-(\d{2})', r'\3-\2-\1', regex=True)`

## 8. 本节重点总结

- `str.get_dummies(sep=...)` 可按分隔符拆分字符串并生成哑变量列，适合多标签字段。
- `str.maketrans` 配合 `str.translate` 可实现指定字符映射替换。
- `find` 查找第一次出现位置，找不到返回 `-1`；`index` 找不到会报错。
- `rfind`、`rindex` 从右往左查找。
- 日期等非字符串类型在调用 `.str` 方法前必须 `.astype(str)`。
- `lower`、`upper`、`title`、`capitalize`、`swapcase` 分别处理不同大小写转换需求。
- `isalpha`、`isdigit`、`isalnum`、`isspace`、`islower`、`istitle` 用于字符串内容判断。
- `str.match` 返回是否匹配正则的布尔结果。
- `str.extract` 通过括号分组提取目标内容。
- `str.replace` 可配合正则和反向引用完成复杂格式重排。
- 正则表达式是文本处理的重要基础，建议系统学习后再深入使用 Pandas 字符串正则功能。
