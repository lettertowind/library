# S03E29 树状图（Treemap）课程笔记

## 1. 本节目标与树状图概念

- 本节讲解如何用 Python 绘制**树状图（Treemap）**，对应课程标题中的“树状图”。
- 树状图通过**矩形块面积大小**表示数值大小，适合展示分类数据的销售数量、占比等情况。
- 讲师对比了 **Power BI**：
  - 在 Power BI 中制作树状图非常简单。
  - Power BI 的树状图还支持**下钻功能**，例如从“联想电脑”“方正电脑”等品牌下钻到具体型号；手机分类也可以用同样方式下钻。
  - 在 Python 中直接实现这种交互式下钻功能较难，因此本节先讲清楚如何画出基础树状图。
- 本节使用的核心组合：
  - `squarify`：负责计算并绘制树状图矩形布局。
  - `matplotlib`：负责图像显示、坐标轴、标题、字体等样式。
  - `pandas`：负责组织数据。
  - `numpy`：可用于随机生成颜色等辅助操作。

## 2. 安装树状图所需模块

- 绘制树状图前需要先安装一个新库，视频中对应的是 `squarify` 模块。
- 安装方式与安装 `matplotlib` 类似：把原来命令中的包名替换成本节需要的库名。
- 视频中给出的安装思路：

```bash
pip3 install squarify
```

- 安装成功后需要验证是否可用：
  - 在编译器中输入：

```python
import squarify
```

  - 按回车运行，如果没有报错，就说明安装成功。
- 易混点：
  - `matplotlib` 是通用可视化库，不是树状图专用库。
  - `squarify` 才是本节绘制树状图所用的模块。
  - 安装命令中的包名必须替换正确，不能仍然写成 `matplotlib`。

plt.rcParams['font.sans-serif'] = ['SimHei']

  - `plt`：用于设置坐标轴、标题、显示图像等。

  - `pd`：用于构造和读取数据表。

  - `font.sans-serif`：指定中文字体，避免中文乱码。

## 4. 准备数据

- 视频中的数据很简单：一列是名称，一列是销售数量。
- 名称包括“手机”“电脑”等分类。
- 销售数量用于决定树状图中每个矩形块的大小。
- 讲师建议先打印数据，确认数据内容，再绘图；调试时可先注释掉绘图代码，只保留 `print()`。
- 示例数据结构：

```python
data = pd.DataFrame({
    '名称': ['手机', '电脑', '平板', '耳机'],
    '销售数量': [120, 80, 50, 30]
})

print(data)
```

- 数据说明：
  - `名称` 列对应树状图上的分类标签。
  - `销售数量` 列对应矩形块面积大小，也用于在块上显示具体数值。
  - 示例数据仅用于说明结构，实际数据以视频或自己的数据为准。
- 易混点：
  - 分类名称决定“显示什么字”。
  - 销售数量决定“方块有多大”和“显示什么数值”。
  - 树状图不是按行号平均分块，而是按 `sizes` 指定数值比例分配面积。

## 5. 自定义颜色

- 树状图有几个类别/几个方块，就需要准备几个颜色。
- 颜色可以自己定义在一个列表中，例如：

```python
colors = ['#4E79A7', '#F28E2B', '#E15759', '#76B7B2']
```

- 也可以使用 NumPy 随机生成颜色。
- 讲师建议：
  - 一般自定义颜色更好看。
  - 颜色审美需要自己调整；讲师自谦说自己颜色搭配水平一般，不要完全照搬。
- 易混点：
  - 颜色列表长度应与分类数量匹配。
  - 如果类别数量多于颜色数量，可能导致颜色分配不完整或显示异常。
  - `color` 控制方块填充色，`edgecolor` 控制边框颜色，两者不要混淆。

## 6. 调用 `squarify.plot()` 绘制树状图

- 基本绘图形式：

```python
squarify.plot(...)
```

- 视频中逐个说明了 `squarify.plot()` 的常用参数。

### 6.1 `sizes`：指定矩形块大小

```python
sizes=data['销售数量']
```

- `sizes` 是决定每个方块面积大小的关键参数。
- 数据越大，对应矩形块越大。
- 易混点：
  - `sizes` 决定方块大小。
  - `value` 只是在方块上显示数值，不决定方块大小。
  - 视频口述中的“s s e s”对应实际参数名 `sizes`。

### 6.2 `label`：指定分类标签

```python
label=data['名称']
```

- `label` 用于显示数据点名称/分类名称。
- 视频中说明标签名称百分之百来自“名称”列。
- 易混点：
  - `label` 显示分类文字。
  - `value` 显示具体数值。
  - 两者可以同时设置，使树状图既显示分类名，也显示销售数量。

### 6.3 `color`：指定自定义颜色

```python
color=colors
```

- 将前面定义的颜色列表传给 `color`。
- 每个分类块使用对应颜色。
- 如果没有自定义颜色，也可以使用其他方式生成颜色；讲师课上主要演示自定义列表。

### 6.4 `alpha`：设置透明度

```python
alpha=0.8
```

- `alpha` 用于设置颜色透明度。
- 视频中说明透明度可以自己设置，课上没有强制写具体数值。
- 使用时可根据背景和视觉效果调整，通常取值在 `0` 到 `1` 之间。

### 6.5 `value`：在方块上显示数值

```python
value=data['销售数量']
```

- 只有 `label` 时，方块上只显示分类名称。
- 若希望同时显示具体销售数量，需要设置 `value`。
- 讲师说明：方块大小由数据决定，但若要在标签下方显示数据值，就要把销售数据传给 `value`。
- 易混点：
  - `sizes` 决定面积大小。
  - `value` 决定是否在图上显示数值。
  - `label` 决定显示哪个名称。

### 6.6 `edgecolor`：设置外边框颜色

```python
edgecolor='white'
```

- `edgecolor` 用于设置矩形块边框颜色。
- 视频中将外边框设置为白色。
- 易混点：
  - `color` 是填充色。
  - `edgecolor` 是边框色。
  - 边框色常用于区分相邻矩形块。

### 6.7 `linewidth`：设置边框宽度

```python
linewidth=3
```

- `linewidth` 用于设置矩形块边框宽度。
- 讲师演示：
  - 设置为 `10` 时，方块之间的间隔会明显变大，效果过于夸张。
  - 一般设置为 `3` 左右比较合适。
- 易混点：
  - `linewidth` 不是方块大小。
  - `sizes` 才决定方块面积。
  - `linewidth` 过大时，视觉上矩形块会被边框“挤开”。

### 6.8 `text_kwargs`：设置文字样式

```python
text_kwargs={'fontsize': 20, 'color': 'white'}
```

- `text_kwargs` 用于设置树状图内部文字样式。
- 视频中说明其参数使用**字典格式**。
- 可以设置的键值对包括：
  - `fontsize`：字号。
  - `color`：文字颜色。
  - `fontweight`：是否加粗。
  - `fontstyle`：是否斜体。
  - `fontfamily`：字体族。
  - 下划线等文字样式。
- 讲师演示：
  - 设置 `fontsize=20` 后文字明显变大。
  - 字号过大会显得拥挤，实际使用时应按图幅调整。
  - 文字颜色设置为黑色不好看，建议根据背景设置为白色或其他更协调的颜色。
- 易混点：
  - `text_kwargs` 控制方块内部标签文字。
  - `plt.title()` 中的 `fontdict` 控制标题文字。
  - 两者格式类似，但作用对象不同。

## 7. 综合绘图代码

- 将上述参数组合起来，示例代码如下：

```python
import matplotlib.pyplot as plt
import squarify
import pandas as pd
import numpy as np

# 字体设置：按需选择字体；无负号时负号设置可不写
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 示例数据：按视频结构构造
data = pd.DataFrame({
    '名称': ['手机', '电脑', '平板', '耳机'],
    '销售数量': [120, 80, 50, 30]
})

print(data)

# 自定义颜色，数量与分类数量对应
colors = ['#4E79A7', '#F28E2B', '#E15759', '#76B7B2']

# 绘制树状图
squarify.plot(
    sizes=data['销售数量'],
    label=data['名称'],
    color=colors,
    alpha=0.8,
    value=data['销售数量'],
    edgecolor='white',
    linewidth=3,
    text_kwargs={'fontsize': 20, 'color': 'white'}
)

plt.show()
```

- 该代码实现了：
  - 按销售数量分配矩形块面积。
  - 在矩形块上显示分类名称。
  - 在矩形块上显示销售数量。
  - 使用自定义颜色。
  - 使用白色边框区分矩形块。
  - 设置边框宽度为 `3`。
  - 设置方块内文字字号为 `20`、颜色为白色。

## 8. 去掉坐标轴

- 树状图通常不需要坐标轴。
- 视频中说明要“整体去掉坐标轴”，对应代码为：

```python
plt.axis('off')
```

- 作用：
  - 关闭当前图像的坐标轴、刻度和边框。
  - 让树状图只保留矩形块和文字。
- 易混点：
  - `plt.axis('off')` 不是删除数据，也不是删除图像，只是隐藏坐标轴。
  - 如果不关闭坐标轴，图像周围会保留默认的刻度和边框。

## 9. 添加标题并设置标题字体

- 添加标题使用：

```python
plt.title('销售情况')
```

- 设置标题字体时，使用字典形式，常用参数名为 `fontdict`：

```python
plt.title(
    '销售情况',
    fontdict={'fontsize': 20, 'color': 'black'}
)
```

- 视频中说明：
  - 标题字体可以复制前面文字样式的字典来设置。
  - 字典中可设置字号、颜色、粗细、字体等。
  - 如果标题背景为白色，标题文字颜色不要盲目设置成白色，否则可能看不见；应按背景调整。
- 易混点：
  - `plt.title()` 的 `fontdict` 控制标题。
  - `squarify.plot()` 的 `text_kwargs` 控制方块内部文字。
  - 两者都使用字典，但作用对象不同。

## 10. 完整流程图示意

```python
import matplotlib.pyplot as plt
import squarify
import pandas as pd
import numpy as np

# 字体设置
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 数据
data = pd.DataFrame({
    '名称': ['手机', '电脑', '平板', '耳机'],
    '销售数量': [120, 80, 50, 30]
})

print(data)

# 颜色
colors = ['#4E79A7', '#F28E2B', '#E15759', '#76B7B2']

# 绘图
squarify.plot(
    sizes=data['销售数量'],
    label=data['名称'],
    color=colors,
    alpha=0.8,
    value=data['销售数量'],
    edgecolor='white',
    linewidth=3,
    text_kwargs={'fontsize': 20, 'color': 'white'}
)

# 去除坐标轴
plt.axis('off')

# 添加标题
plt.title('销售情况', fontdict={'fontsize': 20, 'color': 'black'})

# 显示图像
plt.show()
```

## 11. 关键点与踩坑清单

- 安装库时，不要把包名继续写成 `matplotlib`，要替换成 `squarify`。
- 安装成功后，用 `import squarify` 检测；不报错即成功。
- 先打印数据，确认名称列和销售数量列，再绘图。
- `sizes` 决定矩形块面积，数值越大，方块越大。
- `label` 决定方块上显示的分类名称。
- `value` 决定方块上是否显示具体数值；不设置时通常只显示分类名。
- `color` 是填充色，`edgecolor` 是边框色，二者不要混用。
- 颜色列表数量应与分类块数量对应；也可以用 NumPy 随机生成颜色。
- `linewidth` 控制边框宽度，设置为 `10` 会显得间隔过大，一般 `3` 左右较合适。
- `text_kwargs` 使用字典设置方块内部文字样式，例如 `fontsize`、`color`、`fontweight`、`fontstyle` 等。
- 方块内部文字颜色要根据背景调整，黑色不一定好看，白色也需视背景而定。
- `plt.axis('off')` 用于整体去掉坐标轴。
- 标题使用 `plt.title()`，字体设置用 `fontdict` 字典。
- Power BI 的树状图支持交互下钻；Python 基础树状图主要做静态展示，交互下钻实现难度更高，本节不展开。
- 树状图适合表示分类占比和数量对比；类别过多时文字可能拥挤，需要调整字号、颜色和边框宽度。
