## 查看缺失值

- 查看是否为空值可使用：
  - `isna()` / `isnull()`：判断是否为缺失值，返回 `True` 表示该位置为空/缺失，返回 `False` 表示非空。
  - `notna()` / `notnull()`：判断是否为非缺失值，返回 `True` 表示非空，返回 `False` 表示缺失。
- 视频中老师发音类似“is now”“not”，对应到 Pandas 中就是上述缺失值判断函数。
- 通过布尔结果可以快速定位数据中的空值分布。

## 删除缺失值：`dropna()`

### 基本用法

- 使用 `dropna()` 删除缺失值。
- 默认情况下，`dropna()` 相当于：
  - `axis=0`：按行处理。
  - `how='any'`：只要该行出现一个空值/缺失值，就删除这一行。
- 示例：运行 `df.dropna()` 后，所有包含空值的行都会被删除。

### `axis` 参数

- `axis` 控制删除方向。
- 默认 `axis=0`：按行处理，删除含缺失值的行。
- 如果要对列操作，可设置 `axis=1`。
- 示例中设置 `axis=1` 后，因为每一列都有空值，所以含空值的列都被删除，最后只留下没有空值的“姓名”列等。
- 视频中说明：`axis` 是之前一直讲的内容，理解起来没有问题。

### `how` 参数

- `how` 默认值为 `'any'`：
  - 只要这一行或这一列有一个空值，就删除该行或该列。
- `how='all'`：
  - 只有这一行或这一列全部为空时，才删除。
- 视频示例中直接把 `how` 改为 `'all'` 后运行没有效果，原因是数据中每一行并不是彻底全空，例如每行还有姓名等非空值。
- 如果要删除全空列，可以在设置 `axis=1` 的同时使用 `how='all'`。
- 老师强调：必须彻彻底底整行全空，才删除这一行；或者整列全空，才删除这一列。

### `thresh` 参数

- `thresh` 用于指定非缺失值数量阈值。
- 其含义是：如果某一行或某一列的非空值数量小于指定值，则删除该行或该列。
- 视频中老师口述时出现“至少保留两个空值”的说法，但实际应理解为：至少保留指定数量的非缺失值；低于该数量才删除。
- 示例中 `thresh=2` 表示保留至少两个非缺失值的行/列，低于两个非缺失值的行/列会被删除。
- 老师说明该参数一般使用不多。

### `subset` 参数

- `subset` 是一个重点参数，用于指定在哪些列/列表中查看缺失值。
- 如果不想对整个表判断，而只想根据某几列判断缺失值，就可以使用 `subset`。
- 示例：

`df.dropna(subset=['语文', '数学'])`

- 上述操作表示只检查“语文”和“数学”两列中的缺失值，并据此删除相关行，其他列不参与判断。
- 视频示例中，由于英语列也存在空值，所以最终相关行也被删除了。

### `inplace` 参数

- `inplace` 表示是否直接在原对象上修改。
- 该参数在上节课已经重点讲解并做过测试，本节不再重复。
- 如果不了解 `inplace`，可以查看 10.1.2 的笔记或上节课视频。

## 填充缺失值：`fillna()`

### 常量填充

- 使用 `fillna()` 填充缺失值。
- 如果要把所有空值都替换成同一个常量，可以直接传入该值：

`df.fillna(520)`

- 示例中所有空值都被替换成 `520`。
- 视频中老师发音类似“fiona”，对应函数为 `fillna()`。

### 按列使用字典填充

- 如果不同列需要填充不同的值，可以使用字典。
- 示例：

`df.fillna({'语文': 0.1, '数学': 0.2, '英语': 0.3})`

- 上述操作表示：
  - “语文”列中的空值填充为 `0.1`。
  - “数学”列中的空值填充为 `0.2`。
  - “英语”列中的空值填充为 `0.3`。
- 视频中老师用这些数值是为了方便观察不同列的填充效果。
- 这种按列批量填充体现了 Pandas 在数据处理上的优势，在 Excel 或 VBA 中处理类似任务通常没有这么方便快捷。

### `method` 参数与填充方向

- `fillna()` 中有一个容易绕晕但很重要的参数：`method`。
- 它用于控制填充方式，视频中介绍了四个相关可选项/别名：
  - `pad`：用前面的值填充。
  - `ffill`：用前面的值填充，功能与 `pad` 类似。
  - `backfill`：用后面的值填充。
  - `bfill`：用后面的值填充，功能与 `backfill` 类似。
- 视频示例中：
  - 使用前面的值填充时，如果空值前面的值为 `1`，则下方空值会被填成 `1`。
  - 后续区域按照其前面的有效值进行向下填充，例如前面的值是 `2`，就填 `2`；前面的值是 `3`，就填 `3`。
  - 使用后面的值填充时，如果空值后面的值为 `5`，则上方空值会被填成 `5`；后面的值为 `6`，则上方空值会被填成 `6`。
- 老师提到：很多教程说 `pad` 与用前面的值填充功能一样，`backfill` 与向后填充功能一样；老师也认为它们看起来相似，并建议进一步研究 Pandas 为什么提供四个选项，是否存在细微差别。
- 实际学习时可以先掌握：
  - `ffill` / `pad`：用前一个有效值填充。
  - `bfill` / `backfill`：用后一个有效值填充。

### 结合 `axis` 控制左右填充

- 默认 `axis=0`，填充方向主要体现为上下方向。
- 如果将 `axis` 改为 `1`，则填充方向变为左右方向。
- 原来按行看是“前和后”，把轴改为列方向后，就对应“左和右”。
- 因此通过 `axis` 可以让填充方向从上下变为左右。

### `limit` 参数限制填充数量

- `limit` 用于限制填充数量。
- 示例中从某个方向填充空值时，可以只填充两个空值，第三个及之后保持为空。
- 例如设置 `limit=2` 后，只会填充两个缺失值，第三个不再填充。
- 视频中提到 MySQL 中的 `limit` 也有控制显示数量/条数的概念，可以类比理解：这里就是控制填充数量。

## 本节小结

- 本节开始处理 Pandas 中的缺失值，暂时先按“空值”理解。
- 查看缺失值：
  - `isna()` / `isnull()`：`True` 表示缺失。
  - `notna()` / `notnull()`：`True` 表示非缺失。
- 删除缺失值使用 `dropna()`：
  - `axis` 控制按行或按列删除。
  - `how` 控制是“有一个就删”还是“全部为空才删”。
  - `thresh` 控制非缺失值数量阈值。
  - `subset` 指定只在某些列中检查缺失值。
  - `inplace` 控制是否修改原数据。
- 填充缺失值使用 `fillna()`：
  - 可以直接填充常量。
  - 可以用字典按列填充不同值。
  - 可以通过 `method` 使用前值或后值填充。
  - 可以通过 `axis` 控制上下或左右方向。
  - 可以通过 `limit` 限制填充数量。
- 老师强调 Pandas 在批量数据处理方面非常强大，很多操作比 Excel 和 VBA 更高效。
