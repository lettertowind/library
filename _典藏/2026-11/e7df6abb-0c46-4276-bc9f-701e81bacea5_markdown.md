# Python数据分析三部曲入门篇：安装 pandas、numpy、xlrd

## 1. 本节目标
- 学习在 Windows 环境下安装 `pandas`、`numpy`、`xlrd` 三个 Python 库。
- 掌握通过 `cmd` 命令行进入 `pip3.exe` 所在目录的方法。
- 使用 `pip install` 完成库安装。
- 学会通过 `import` 语句验证三个库是否安装成功。

## 2. 安装前说明
- 本节需要安装的库包括：`pandas`、`numpy`、`xlrd`。
- 安装过程需要从网络下载，因此安装速度与网速、网络运营商等因素有关。
- 安装可能失败，失败后不必着急，可以重复执行安装命令，多次尝试直到成功。
- 讲师提到自己安装了很多遍才成功，说明安装失败是常见情况，需要耐心重试。
- 不同电脑的 Python 安装位置可能不同，因此需要先找到 `pip3.exe` 文件所在目录。
- 如果 Python 是默认安装且不清楚安装路径，需要自行查找 `pip3.exe` 所在的文件夹。

## 3. 打开命令行窗口
- 在键盘上同时按下 `Windows` 键和 `R` 键。
- 弹出“运行”对话框后，在输入框中输入 `cmd` 三个字母。
- 点击“确定”，打开命令行窗口。

## 4. 进入 pip3.exe 所在目录
- 需要先确认本机 `pip3.exe` 文件所在位置。
- 该文件通常位于 Python 安装目录下，但具体路径因电脑而异。
- 在命令行中输入：
  - `cd 空格 + pip3.exe所在文件夹路径`
- 例如输入形式为：`cd 你的实际路径`
- 输入后按回车，即可进入对应目录。
- `cd` 是 DOS 中用于进入目录的命令。
- 注意：路径必须替换成自己电脑上的真实路径，不能直接照搬讲师的路径。

## 5. 安装 pandas
- 进入 `pip3.exe` 所在目录后，在命令行中输入：
  - `pip install pandas`
- 按回车执行安装。
- 等待程序从网络下载并安装 `pandas`。
- 如果安装失败，可以再次执行同一命令，反复尝试直到成功。

## 6. 安装 numpy
- 安装完 `pandas` 后，重复前面的命令行操作。
- 在命令行中输入：
  - `pip install numpy`
- 按回车执行安装。
- 如果安装失败，同样继续重试。
- 如果之前已经安装过 `numpy`，则不会影响后续操作。

## 7. 安装 xlrd
- 继续在同一命令行环境中安装 `xlrd`。
- 输入：
  - `pip install xlrd`
- 按回车执行安装。
- 如果失败，重复安装命令，直到安装成功。

## 8. 验证安装是否成功
- 打开 Python 的编译器/解释器环境。
- 依次输入以下语句并按回车：

  - `import pandas`
  - `import numpy`
  - `import xlrd`

- 判断标准：
  - 输入 `import pandas` 后没有报错，说明 `pandas` 安装成功。
  - 输入 `import numpy` 后没有报错，说明 `numpy` 安装成功。
  - 输入 `import xlrd` 后没有报错，说明 `xlrd` 安装成功。
- 如果三个 `import` 语句执行后都没有报错，说明三个库均已安装成功。
- 安装成功后，即可继续后续 `pandas` 的学习。

## 9. 操作命令汇总

| 操作环节 | 操作或命令 |
|---|---|
| 打开运行窗口 | 按 `Windows` 键 + `R` 键 |
| 打开命令行 | 输入 `cmd`，点击“确定” |
| 进入目录 | `cd 空格 + pip3.exe所在文件夹路径` |
| 安装 pandas | `pip install pandas` |
| 安装 numpy | `pip install numpy` |
| 安装 xlrd | `pip install xlrd` |
| 验证 pandas | `import pandas` |
| 验证 numpy | `import numpy` |
| 验证 xlrd | `import xlrd` |

## 10. 注意事项
- 安装前必须准确定位 `pip3.exe` 所在目录，否则可能无法正常执行 `pip` 命令。
- 路径因人而异，需要根据自己电脑的 Python 安装位置进行替换。
- 安装失败并不代表环境损坏，可以多次重试。
- 网络状况会影响下载速度和安装成功率。
- 验证安装是否成功时，以执行 `import` 后是否报错为准。
- 三个库都需要安装并验证：`pandas`、`numpy`、`xlrd`。

## 11. 本节小结
- 核心安装流程为：打开 `cmd` → 进入 `pip3.exe` 所在目录 → 使用 `pip install` 安装 `pandas`、`numpy`、`xlrd` → 使用 `import` 验证。
- 安装过程中可能因网络原因失败，需要耐心重复尝试。
- 三个库均能成功 `import` 且不报错后，即可进入后续 `pandas` 学习。
