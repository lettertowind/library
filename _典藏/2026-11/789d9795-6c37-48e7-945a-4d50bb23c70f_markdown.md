## 2. 坐标轴分段：把坐标轴分成若干份

### 方法一：直接对整个图使用 `plt.locator_params`

- 目标：将 x 轴划分成 5 份，使 x 轴上显示 5 个分段刻度值。
- 使用函数：`plt.locator_params`
- 参数说明：
  - `axis='x'`：指定对 x 轴操作
  - `nbins=5`：指定希望分成 5 份/显示 5 个刻度值
- 示例代码：

`plt.locator_params(axis='x', nbins=5)`

- 运行后 x 轴出现 5 个刻度值。
- 如果不指定 `axis`，则会对 x 轴和 y 轴统一进行分割。
- 该方法是“把数据轴分成几份”的意思，不等同于设置固定刻度列表。

### 方法二：先获取轴对象，再调用 `locator_params`

- 可以先通过 `plt.gca()` 获取当前坐标轴对象，再对轴对象进行操作。
- 示例代码：

`plt.gca().locator_params(axis='x', nbins=5)`

或者写成：

`ax = plt.gca()`  
`ax.locator_params(axis='x', nbins=5)`

- 该方式与直接使用 `plt.locator_params` 效果一致。
- 先获取轴再操作的好处是：可以先对某个轴进行设置，再进行其他轴相关操作。
- 如果想让 x 轴和 y 轴都进行分割，两种方法都可以不指定 `axis`。

## 3. 将刻度指定为某个数的倍数

### 需求示例

- 想让 x 轴刻度按照 7 的倍数排列，例如：
  - 7、14、21、28、35、42 等
- 需要使用 `ticker` 中的刻度定位器。

### 导入刻度定位器

- 需要从 `matplotlib.ticker` 中导入 `MultipleLocator`。
- 示例：

`from matplotlib.ticker import MultipleLocator`

- 如果使用 `ticker` 模块方式，也可以导入后使用 `ticker.MultipleLocator`。

### 对 x 轴设置主刻度定位器

- 先获取当前坐标轴：

`ax = plt.gca()`

- 对 x 轴设置主刻度定位器：

`ax.xaxis.set_major_locator(MultipleLocator(7))`

- 如果要对 y 轴设置，则改为：

`ax.yaxis.set_major_locator(MultipleLocator(7))`

- `MultipleLocator(7)` 表示主刻度按照 7 的倍数生成。
- 想按几的倍数排列，就把参数改成几。

### 负号显示问题与解决

- 直接运行时出现错误或显示异常。
- 原因：前面数据中存在负号，负号显示问题没有解决。
- 表现：
  - 报错
  - 屏幕上的负数如 `-4`、`-17` 等负号可能显示为方块
  - 如果屏幕不够大，也可能看不清楚
- 解决方法：设置 `axes.unicode_minus=False`。
- 常用实现代码：

`plt.rcParams['axes.unicode_minus'] = False`

- 视频中也口述为设置 `axes.unicode_minus` 为 `False`。
- 运行后：
  - 不再报错
  - 负数可以正常显示
  - 刻度按照 7 的倍数显示，所有倍数都可以被 7 整除

## 4. 设置主刻度格式：保留小数与百分比

### 关键方法

- 对 x 轴主刻度进行格式化，需要使用：

`ax.xaxis.set_major_formatter(...)`

- 视频中特别提醒：如果方法没有改成 `set_major_formatter`，设置不会生效。
- 先获取轴：

`ax = plt.gca()`

### 保留小数点后两位

- 使用 `FormatStrFormatter`。
- 导入：

`from matplotlib.ticker import FormatStrFormatter`

- 示例代码：

`ax.xaxis.set_major_formatter(FormatStrFormatter('%.2f'))`

- `'%.2f'` 表示保留小数点后两位。

### 设置为百分比形式

- 如果希望显示为百分比，需要在格式字符串后面再加两个百分号。
- 示例：

`ax.xaxis.set_major_formatter(FormatStrFormatter('%.2f%%'))`

- 说明：
  - 其中一个百分号用于转义
  - 最终显示为百分比形式

### 保留一位或三位小数

- 保留一位小数：

`FormatStrFormatter('%.1f')`

- 保留三位小数：

`FormatStrFormatter('%.3f')`

- 需要保留几位，就把 `f` 前面的数字改成几。

## 5. 在坐标轴上格式化日期

### 场景准备

- 删除前面演示用的设置代码，重新运行日期数据，确认数据没有问题。
- 使用日期数据作为 x 轴，销售数据作为 y 轴，绘制折线图。
- 视频中使用类似 `plt.plot(日期数据, 销售数据)` 的方式作图。
- 日期标签不再倾斜显示，而是直接水平放置。

### 使用轴对象设置日期格式

- 先获取当前坐标轴：

`ax = plt.gca()`

- 对 x 轴主刻度设置日期格式器：

`ax.xaxis.set_major_formatter(...)`

- 使用 matplotlib 的日期格式器 `DateFormatter`。
- 可以使用 `matplotlib.dates`：

`import matplotlib.dates as mdates`  
`ax.xaxis.set_major_formatter(mdates.DateFormatter('%Y*%m*%d'))`

- 也可以使用 `mpl.dates.DateFormatter` 的形式，例如先导入：

`import matplotlib as mpl`

然后：

`ax.xaxis.set_major_formatter(mpl.dates.DateFormatter('%Y*%m*%d'))`

### 日期格式符号说明

- `%Y`：年，使用大写 `Y`
- `%m`：月，使用小写 `m`
- `%d`：日，使用小写 `d`
- 原日期可能使用横杠表示，可以改成星号：
  - `'%Y*%m*%d'`
- 也可以改成中文年月日，例如：
  - `'%Y年%m月%d日'`
- 还可以根据需要只保留：
  - 年
  - 月
  - 日
  - 月日
  - 年月日等不同组合

### 方法对比

- 日期格式化既可以使用之前讲过的方法直接格式化，也可以使用本节讲的轴对象方法：
  - `ax.xaxis.set_major_formatter(...)`
- 日期刻度使用 `DateFormatter`，普通数字刻度使用 `FormatStrFormatter`。

## 6. 设置 x 轴与 y 轴区间

### 分别设置 x 轴和 y 轴区间

- 先获取当前轴：

`ax = plt.gca()`

- 设置 x 轴显示范围：

`ax.set_xlim(0, 10)`

- 表示 x 轴从 0 到 10。
- 设置 y 轴显示范围：

`ax.set_ylim(0, 5)`

- 如果数据显示不全，可以把 y 轴范围改大。
- 视频示例中曾把 y 轴上限调整到 20 或 30，使数据完整显示。
- 例如：

`ax.set_ylim(0, 30)`

### 同时设置 x 轴和 y 轴区间

- 如果不想分两步设置，可以使用 `axis` 一次性设置。
- 示例：

`ax.axis([0, 10, 0, 20])`

- 列表参数顺序必须严格为：
  - x 轴最小值
  - x 轴最大值
  - y 轴最小值
  - y 轴最大值
- 即：

`[xmin, xmax, ymin, ymax]`

- 该方式与分别调用 `set_xlim`、`set_ylim` 效果相同。

## 7. 设置轴的下限、上限、左边界、右边界

### 设置 y 轴下限

- 先观察默认图：
  - x 轴大约从 0 到 9
  - y 轴大约从 0 到 20
- 获取当前轴：

`ax = plt.gca()`

- 设置 y 轴下限：

`ax.set_ylim(bottom=-10)`

- `bottom=-10` 表示 y 轴的底部/下限从 `-10` 开始。
- 也就是说，`bottom` 控制 y 轴从哪个值开始显示。

### 设置 y 轴上限

- 设置 y 轴顶部：

`ax.set_ylim(top=...)`

- `top` 表示 y 轴的顶部/上限。
- 可以分别设置 `bottom` 和 `top`。

### 设置 x 轴左边界

- x 轴不使用 `top`、`bottom`，而使用 `left`、`right`。
- 设置 x 轴左边界：

`ax.set_xlim(left=5)`

- 运行后 x 轴从 5 开始显示。
- 视频中曾尝试把 `left` 设置为 25，后发现不合适，又改为 5。

### 设置 x 轴右边界

- 设置 x 轴右边界：

`ax.set_xlim(right=25)`

- 运行后 x 轴右边界显示到 25。

### 参数对应关系总结

- y 轴底部：`bottom`
- y 轴顶部：`top`
- x 轴左边：`left`
- x 轴右边：`right`
- 这些参数可以配合 `set_xlim`、`set_ylim` 分别设置。

## 8. 本节关键函数与易混点总结

- `plt.locator_params(axis='x', nbins=5)`：设置坐标轴希望分成几份/显示几个刻度值。
- `plt.gca()`：获取当前坐标轴对象。
- `ax.locator_params(...)`：先获取轴，再设置刻度分段。
- 不指定 `axis` 时，可对 x 轴和 y 轴统一进行分割。
- `MultipleLocator(7)`：将主刻度设置为 7 的倍数。
- `ax.xaxis.set_major_locator(...)`：设置 x 轴主刻度定位器。
- `ax.yaxis.set_major_locator(...)`：设置 y 轴主刻度定位器。
- `plt.rcParams['axes.unicode_minus'] = False`：解决负号显示问题。
- `ax.xaxis.set_major_formatter(...)`：设置 x 轴主刻度文本格式。
- `FormatStrFormatter('%.2f')`：保留两位小数。
- `FormatStrFormatter('%.2f%%')`：显示为百分比形式。
- `DateFormatter('%Y*%m*%d')`：格式化日期刻度。
- `ax.set_xlim(0, 10)`：设置 x 轴显示范围。
- `ax.set_ylim(0, 30)`：设置 y 轴显示范围。
- `ax.axis([xmin, xmax, ymin, ymax])`：一次设置 x、y 轴区间。
- y 轴边界参数是 `bottom`、`top`。
- x 轴边界参数是 `left`、`right`。
