# 孙兴华 Python 数据分析三部曲·可视化图表篇开篇寄语 笔记

## 课程信息与本节性质
- 视频标题：p47 S03E00.开篇寄语
- 所属课程：孙兴华中文讲 Python 数据分析三部曲入门篇，包含 Numpy 教程、Pandas 教程、Matplotlib 教程。
- 本节是 Python 数据分析第三步“可视化图表篇”的开篇寄语，主要讲课程设计思路、观众市场分析、目标受众定位和中文命名策略。
- 本节未出现具体代码、函数、参数、命令、快捷键或数学公式；后续才进入可视化图表的具体教学。

## 课程节奏与系列安排
- 讲师此前讲过 Python 爬虫。
- 讲师安排课程的“套路”是：一个没有做过数据分析的人，要具备基本数据分析能力，需要学习 Numpy、Pandas、可视化图表。
- 时间安排对应为：
  - 年初讲 Numpy；
  - 年中讲 Pandas；
  - 年末讲可视化图表，即 Matplotlib 相关内容。
- 讲师也用 VBA 课程举例：
  - 年初讲 VBA 第一、二季；
  - 年末讲 VBA 第三、四季；
  - 思路是“春天播种，秋天收割”，春天开篇，秋天收尾，然后把合集发布出来。
- 不一口气讲完课程的原因：讲课前要先分析观众市场，明确要分享给谁，并采用从简单到难的节奏。

## 观众市场分析：以超市为例
- 做课程和做产品一样，要先分析观众市场，问自己“要分享给谁”。
- 民用超市案例：
  - 民用超市主要客户群体是中老年人，不可能是年轻人。
  - 原因是年轻人下班晚，大城市如北上广通勤堵车，回家晚；周末好不容易休息，也不一定愿意逛超市；年轻人一般选择网购。
  - 因此民用超市面向的人群就是中老年人。
  - 如果觉得中老年人利润低，就想把民用超市换成年轻人群体，讲师认为这是“脑子进水”，不可能成功。
- 年轻化超市反例：
  - 有超市专门做年轻人市场，装修特别繁华，还做试吃，甚至能买水产吃。
  - 但效益并不好。
  - 结论：没有跟市场对接，分析失败。
- 奢侈品案例：
  - 做奢侈品一定面向年轻人群。
  - 中老年人群基本很少去买奢侈品。
- 讲师由此推导自己的课程定位：观众应是零基础人群，课程要从简单到难。

## 目标观众：零基础人群与循序渐进
- 讲师明确：我的观众应该是零基础人群。
- 如果一个人一下看到 100 集的合集视频，即使有求知欲望，大多也会退却。
- 这种大合集视频通常容易变成“收藏家吃灰的干活”，很少有人真正拿来学习。
- 如果课程从简单到难慢慢讲，效果就不一样。
- 最好的老师是兴趣：
  - 课程能听懂，学习者才有兴趣；
  - 听懂了、学会了但不去用而忘记，是学习者自己的事情，他自己心里明白；
  - 如果一开始什么都听不懂，学习者就不愿再浪费时间听其他课程。
- 有小伙伴评论讲师课程是“越来越难系列”。讲师解释：
  - 学习本来就是从小学一年级到大学四年级，再到研究生、博士、博士后，逐渐增加难度；
  - 这条路上有很多人中途下车；
  - 中途下车并不意味着没有能力，可能是因为考试问题、考试不合理造成；
  - 考试上也许不行，但并非能力不行，讲师从未否认这一点。

## 面向什么基础的人分享知识：英语水平分析
- 讲师把中国人分成两类：英语好的和英语不好的。
- 英语不好的人中，“水平一般”和“不会”没有区别。
- “水平一般”的例子：
  - 给一篇新闻，比如“美国总统说什么了”；
  - 如果看不懂大概意思，即使是因为专业单词不认识，也属于水平一般；
  - 这种水平和“不会”没有区别。
- 发音准但不会应用的情况：
  - 可能发音比小学生准，也比中学生准；
  - 能认识一些单词，能读对发音；
  - 但应用不到工作中去，仍然还是不会。
- 英语好的人：
  - 一般可以看国外文献；
  - 可以看 To B 类的英文“生肉”视频；
  - 国外专业领域的大神讲出的课程，可能比孙兴华好百万倍；
  - 这不是崇洋媚外，而是“要脸”；
  - 类似 AE 特效领域，没有人敢说自己比 AK 大神厉害。
- 英语好的人具备一定自学能力，大多是研究生、本科生；也有学历不高但英语比较好的人，例如马云差一点没考上大学，但英语特别好；若当时没有保送或没考上大学，就属于英语好但有一门不好影响考大学。

## B站播放数据与主力观众
- 从 B站播放数据看：
  - 30 岁以下的人占 20%；
  - 30 岁到 45 岁之间的人占 79%；
  - 也就是说，观众基本集中在 30～45 岁。
- 需要排除极少数情况：有些人岁数很大了，但频繁参加高考，可能 40、50、60 岁才考上大学或研究生。
- 按正常上学考试路径看，光看视频的人基本上都已经参加工作了。
- 因此讲师的主力观众是已经参加工作的人。
- 这类观众一般想多学一点知识，在竞争中站住脚。
- 确定主力观众后，再分析这部分群体：
  - 这部分群体中，英语不好的人占 99% 以上。
  - 原因是国内用到英语好的行业，在所有行业中占比非常低。

## 英语好的行业为何较少来看视频
- 第一类：科研单位。
  - 这样的人根本不会来听讲师课程。
  - 因为他们属于“一门深入”，比如医生不去研究医学，不会来研究编程；搞航天的来研究编程，恐怕得给讲师当老师。
  - 搞科研的人一般不会来听这类课程。
- 第二类：搞翻译的、涉外导游。
  - 他们也不会来。
  - 就算今天想学编程、想学数据分析，也不一定来听讲师课程。
  - 因为他们不必来浪费这个时间。
- 第三类：外企的人。
  - 他们有一定独立学习能力。
  - 能进外企的门，英语水平就错不了。
  - 就算不听国外视频，也往往能在网上找相关资料，看英文版书籍、原版书籍。
- 第四类：计算机相关专业的人。
  - 这种人更不会来看视频。
  - 对他们来说，看视频是耽误时间；
  - 更快的做法是拿一本书看，遇到不会的用搜索引擎搜索；
  - 看视频讲得根本不全面，比不上搜索引擎；
  - 但如果没有基础，用书加搜索引擎搜索可能更麻烦。

## 竞争策略：讲中国话、用中国字
- 面对铺天盖地的 Python 视频，讲师要让自己的视频在众多大神级别和教育平台老师的课程中脱颖而出。
- 涉及课程包括：Python 基础入门篇、Python 办公自动化合集、之前讲的 Pandas 等。
- 讲师最后总结的答案是：讲中国话，用中国字。
- 具体策略：
  - 英语不好的人能听懂；
  - 英语好的人学完之后，可以自己把中文改成自己用的英文；
  - 使用者自己决定自己用什么样的语言。
- 变量名例子：
  - 设置变量名为 `tb`；
  - 内行知道这是“表格”；
  - 外行不知道，可能以为 `tb` 是“淘宝”。
- 公园流量例子：
  - 国外和国内两家公园都免费；
  - 其中一家公园如果晋级，要考英语水平才让进，免费但英语答不上来不让进；
  - 另一家公园谁都可以进；
  - 哪家流量高？老百姓中不会英语的肯定多于会英语的；
  - 如果把这个考试放在清华北大校门里边，估计 99% 都没问题。
- 关于中文变量名的争议：
  - 自私地讲：就是为了增加关注；
  - 这是分析主力观众群体之后得出的结果；
  - 无私地讲：讲师口语很差，极个别人嘲笑口语不好，讲师要证明给他们看；
  - 用中国话一样可以学会知识；
  - 要缩短英语好与英语不好两类人群学习能力上的差距；
  - 讲师能力有限，但会尽力缩短它；
  - 如果有一天全世界的知识不再有语言障碍，英语也就不再有优越感。

## 抬杠与辩论的观点
- 抬杠例子：
  - 如果说从十几层往下跳肯定会摔死；
  - 对方说摔不死；
  - 讲师说“你说摔不死，你跳啊”；
  - 对方不跳，这叫抬杠；
  - 如果对方说摔不死，并且真跳下去还没事，那就不叫抬杠。
- 讲师认为，自己这种人辩论时一定要拿出证明来给人看。
- 搞医学、搞科研的人，辩论可能比网上辩论更可怕，有时拍桌子瞪眼辩论一件事情，但人家会把问题说清楚，说明为什么是这样，会说出自己的意见。
- 不会只敲个键盘说“就是这样的”“就是这么着”，那叫键盘侠。

## 本节结论与后续
- 本节核心结论：课程按照观众市场分析来设计，面向零基础、已参加工作、英语不佳的主力人群，采用中文表达降低学习门槛，并从简单到难逐步推进。
- 讲师强调：用中国话一样可以学会知识，并希望缩短英语好与不好人群的学习能力差距。
- 本节结束后，课程进入 Python 数据分析第三步：可视化图表篇。
- 本节没有代码、函数、参数、命令、快捷键或数学公式需要记录。
