# Python 数据分析：给柱形图添加平均线（p57 S03E09）

## 1. 本节目标

- 学习如何给柱形图添加一条平均线。
- 示例数据为“班级 + 销售量”，柱形图表示销售量，平均线表示销售量的平均值。
- 视频强调：不要手工把数据加在一起，再新增一列“辅助列”来画平均线；这种传统做法被称为“太 out”。
- 本节采用的方式是：用 `numpy` 计算平均值，再用 `matplotlib` 的 `axhline` 画水平平均线。

## 2. 场景区分：毛利率折线图与销售量平均线

视频先对比了另一种常见图表需求：

- 如果柱形图表示“销售量”，折线表示“毛利率”，通常需要设置主次坐标。
- 原因是两类数据量级不同：
  - 主坐标管理销售量，数值可能是几千、几万；
  - 次坐标管理毛利率，数值可能是零点几。
- 如果不设置主次坐标，把毛利率折线和销售量柱形图直接放在同一坐标轴上，图表效果不合适。
- 本节要画的“平均线”与上述毛利率折线不同：平均线表示销售量的均值，和柱形图属于同一量纲，可以直接画在同一个坐标轴上，不需要主次坐标。

## 3. 数据准备与柱形图绘制

视频中的数据结构很简单：

- 一个字段是“班级”；
- 一个字段是“销售量/销量”。

示例横轴为 A、B、C、D、E、F 等班级。视频先用 `print` 打印数据，然后绘制柱形图。

柱形图使用 `plt.bar`，核心思路：

- x 轴数据：班级；
- 柱高数据：销售量；
- 颜色设置为红色；
- 标签设置为“销售量”；
- 透明度设置为约 `0.6`，红色会呈现偏粉的效果；
- 最后调用 `plt.show()` 显示图表。

按视频讲解逻辑整理的代码结构如下：

`import matplotlib.pyplot as plt`

`plt.bar(班级, 销售量, color='red', label='销售量', alpha=0.6)`

`plt.show()`

参数说明：

- `plt.bar(...)`：绘制柱形图。
- `x` 数据：班级。
- `height` 数据：销售量，即每根柱子的高度。
- `color='red'`：柱子颜色设置为红色。
- `label='销售量'`：为图例提供标签文本。
- `alpha=0.6`：设置透明度，使红色变为偏粉颜色。
- `plt.show()`：显示图像。

视频中柱形图绘制完成后，横轴显示 A、B、C、D、E、F 等班级。

## 4. 显示图例

在画平均线之前，视频先显示图例，目的是说明：

- 粉色柱子表示销售量；
- 后面添加的蓝色线表示平均线。

调用：

`plt.legend()`

运行后图例出现。图例文本来自绘图时设置的 `label` 参数。

## 5. 计算平均线

平均线需要先计算销售量的平均值。

视频中导入 NumPy：

`import numpy as np`

使用 `np.mean` 求平均值：

`平均线 = np.mean(销售量)`

如果数据存储在 DataFrame 中，按视频语义可写为：

`平均线 = np.mean(data['销售量'])`

其中 `data['销售量']` 表示从数据中取出“销售量”列。

平均值公式为：

\[
\bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i
\]

视频中打印平均线，得到：

`7450.8333`

讲师说明该结果与自行求平均数一致。

关键结论：

- 平均线数值应通过 `np.mean` 从数据中计算得到。
- 虽然直接在绘图函数中写 `7450.8333` 也能画线，但这是“写死”的做法。
- 更好的做法是让平均线来源于数据计算，即“写活”，这样数据变化后平均线也能自动更新。

## 6. 使用 `plt.axhline` 绘制平均线

计算平均值后，使用水平线函数绘制平均线：

`plt.axhline(y=平均线, color='blue', linestyle=':')`

视频中对应函数为 `plt.axhline`，用于绘制水平参考线。

参数说明：

- `y=平均线`：水平线所在的 y 轴位置，即销售量的平均值。
- `color='blue'`：平均线颜色设置为蓝色。
- `linestyle=':'`：线型设置为冒号风格，即虚线。
- 讲师建议：平均线一般使用虚线效果更好。

也可以直接写死数值，例如：

`plt.axhline(y=7450.8333, color='blue', linestyle=':')`

但不推荐，因为数值被固定，不能随数据自动变化。

运行后，蓝色平均线会横贯图表。

## 7. 平均线与普通折线的区别

视频重点比较了 `plt.axhline` 和 `plt.plot` 两种画线方式。

### 7.1 用 `plt.axhline` 画平均线

- `axhline` 是坐标轴水平参考线。
- 平均线根据“图表”走，会横贯整个图表/坐标轴。
- 只需要设置 y 轴位置，即平均值。
- 更适合画“平均线”“阈值线”“参考线”。

### 7.2 用 `plt.plot` 画折线

视频说明，也可以用折线方式画平均线：

- 把 `plt.axhline` 改成 `plt.plot`；
- 设置 x 轴数据和 y 轴数据即可。

伪代码结构：

`plt.plot(x轴数据, y轴数据, color='blue', linestyle=':')`

但两者范围不同：

- 折线是“根据你的数据走”的，线段通常只覆盖传入的数据点范围，例如从第一个数据点到最后一个数据点。
- 平均线是“根据你的图表走”的，作为坐标轴参考线横贯整个图表。

核心结论：

- 画平均线优先使用 `plt.axhline`。
- 如果使用 `plt.plot`，必须同时设置 x 轴、y 轴数据，且线条范围受数据点限制。
- 折线和平均线虽然视觉上都可能是水平线，但语义和覆盖范围不同。

## 9. 完整流程总结

按视频讲解顺序，给柱形图添加平均线的步骤如下：

1. 准备数据：包含“班级”和“销售量”字段。
2. 打印数据，确认数据内容。
3. 使用 `plt.bar` 绘制销售量柱形图。
4. 设置柱子颜色、标签和透明度：
   - `color='red'`
   - `label='销售量'`

5. 使用 `plt.legend()` 显示图例。
6. 导入 NumPy：`import numpy as np`。
7. 使用 `np.mean` 计算销售量平均值：
   - `平均线 = np.mean(销售量)`
8. 打印平均值，视频结果为 `7450.8333`。
9. 使用 `plt.axhline` 绘制平均线：
   - `y=平均线`
   - `color='blue'`
   - `linestyle=':'`
10. 调用 `plt.show()` 显示最终图表。

## 10. 易错点与结论

- 不要手工求和再新增辅助列来画平均线，应使用 `np.mean` 自动计算。
- 平均线数值不要写死，应来源于数据。
- 平均线与毛利率折线不是同一类需求；毛利率折线常需主次坐标，平均线不需要。
- 平均线通常使用虚线，视觉上更符合参考线语义。
- `plt.axhline` 画的是坐标轴水平参考线，横贯整个图表。
- `plt.plot` 画的是折线，线条范围受数据点控制，不等于自动横贯图表的平均线。
- 图例需要先通过 `label` 设置文本，再调用 `plt.legend()` 显示。
