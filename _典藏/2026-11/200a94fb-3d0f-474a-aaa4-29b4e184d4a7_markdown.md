# Pandas 数据结构之 Series 学习笔记

## 1. 课程定位与核心概念

- 本节是 pandas 课程的第五节课，开始讲解 pandas 的数据结构。
- pandas 中两个重要的数据结构：
  - **Series**：一维数据结构，表示一行或一列数据。
  - **DataFrame**：二维数据表，表示多行多列的数据。
- 一行数据可以看作一个 Series，一列数据也可以看作一个 Series。
- 二维数据 DataFrame 可以由多个 Series 组成。
- 在编程中，DataFrame 常简写为 `df`；视频中为了便于初学者理解，讲师习惯使用中文变量名。
- 需要注意：转录中的“service”应为 **Series**，“deframe”应为 **DataFrame**。

## 2. Series 的基本构成

- Series 是一维数据，由两部分组成：
  - **索引 index**
  - **数据 values**
- 默认情况下，Series 会自动生成从 0 开始的整数索引。

示例：

```python
import pandas as pd

数据 = pd.Series(["孙兴华", "男", "20岁", "2000-01-01"])
print(数据)
```

- 上述数据包含：
  - 姓名：孙兴华
  - 性别：男
  - 年龄：20岁
  - 出生日期：2000-01-01
- 左侧会自动生成索引列。
- 默认索引从 0 开始，例如 `0, 1, 2, 3`。
- 查看索引：

```python
数据.index
```

- 默认索引类似 `RangeIndex(start=0, stop=4, step=1)`，实际包含 `0, 1, 2, 3`，不包括结束值 4。
- 查看值：

```python
数据.values
```

- 返回 Series 中自定义的数据内容。

## 3. 创建 Series 的常见方式

### 3.1 使用列表创建 Series

```python
数据 = pd.Series(["孙兴华", "男", "20岁", "2000-01-01"])
```

- 只传入数据时，pandas 会自动创建默认整数索引。
- 注意类名 `Series` 首字母必须大写；写成小写 `series` 是不正确的。

### 3.2 创建时指定索引

可以在 `pd.Series()` 中通过 `index` 参数指定索引：

```python
数据 = pd.Series(
    ["孙兴华", "男", "20岁", "2000-01-01"],
    index=["a", "b", "c", "d"]
)
print(数据)
```

- `index` 参数接收一个列表。
- 通过这种方式可以将默认的 `0, 1, 2, 3` 替换为自定义索引，例如 `a, b, c, d`。

### 3.3 使用字典创建 Series

实际工作中常见“数组 + 字典”配合使用。使用字典创建 Series 时：

```python
字典 = {
    "姓名": "孙兴华",
    "性别": "男",
    "年龄": 20,
    "地址": "某某某"
}

数据 = pd.Series(字典)
print(数据)
```

- 字典的键 `key` 会自动成为 Series 的索引。
- 字典的值 `value` 会成为 Series 的数据值。
- 例如索引为：`姓名、性别、年龄、地址`。
- 查看索引：

```python
数据.index
```

- 返回结果就是字典中的键。
- 通过标签索引查询值：

```python
数据["姓名"]
```

- 返回：`孙兴华`。
- 查询性别：

```python
数据["性别"]
```

- 返回：`男`。
- 查询年龄：

```python
数据["年龄"]
```

- 返回：`20`。

### 3.4 同时查询多个键对应的值

如果要查询多个键对应的值，不能把多个键直接并列写在方括号中：

```python
# 错误写法
数据["姓名", "性别"]
```

原因：Series 的方括号中默认接收一个键；如果要查询多个键，需要将多个键组成一个列表：

```python
数据[["姓名", "性别"]]
```

- 返回结果的数据类型仍然是 pandas 中的 **Series**。
- 这一点需要注意：查询多个键后返回的不是普通列表或普通字典，而是 Series 类型。

### 3.5 使用两个列表创建 Series

如果索引和数据分别存放在两个列表中，也可以创建 Series。

示例：

```python
列表1 = ["姓名", "性别", "年龄"]
列表2 = ["孙兴华", "男", 20]

数据 = pd.Series(列表2, index=列表1)
print(数据)
```

- `列表2` 作为 Series 的值。
- `列表1` 通过 `index` 参数指定为索引。
- 创建结果中：
  - 索引为：姓名、性别、年龄
  - 值为：孙兴华、男、20
- 关键点：`pd.Series()` 中先放值，再通过 `index=` 指定索引。

## 4. Series 与 DataFrame 的关系

- Series 本身是一个序列，可以表示一行，也可以表示一列。
- 单独看 Series 时，无法确定它一定是行还是列。
- 将 Series 加入 DataFrame 后，它可以根据加入方式成为 DataFrame 中的一行或一列。
- 视频中说明：Series 加入 DataFrame 后可以作为行；反过来也可以作为列，具体会在后续课程详细介绍。
- 当前阶段需要掌握：
  - Series 是一维数据。
  - Series 可以表示一行或一列。
  - 学会创建、查询和使用 Series 即可。

## 5. Series 常用方法

### 5.1 `index`：查看索引

```python
数据.index
```

- 用于查看 Series 的索引。
- 默认索引为整数索引，也可以通过 `index=` 指定自定义索引。

### 5.2 `values`：查看数据值

```python
数据.values
```

- 用于查看 Series 中的数据值。

### 5.3 `sort_index()`：按索引排序

视频中通过读取 Excel 文件演示排序。假设读取后的索引顺序被打乱，例如：

```text
1, 2, 4, 3, 5, 6, 7
```

使用：

```python
数据.sort_index()
```

- 会按照索引从小到大排序。
- 示例中排序后恢复为 `1, 2, 3, 4, 5, 6, 7`。

### 5.4 `sort_values()`：按值排序

按值排序使用：

```python
数据.sort_values()
```

- 视频示例中按“入职日期”进行排序，排序后日期按顺序排列。
- 如果是在 DataFrame 中按某一列排序，通常写作：

```python
df.sort_values(by="入职日期")
```

- 该功能与 Excel 中的排序功能类似。
- 视频中提到 Excel 中也有排序公式 `SORT`，pandas 中对应使用 `sort_index()` 和 `sort_values()`。

### 5.5 `isnull()`：判断是否为空

```python
数据.isnull()
```

- 用于判断数据是否为空。
- 返回结果为布尔值：
  - 不为空：显示 `False`
  - 为空：显示 `True`
- 视频示例中，读取数据后发现“赵敏”的年龄为空，因此对应位置显示 `True`。
- pandas 中空值常用 `NaN` 表示，`NaN` 表示 **Not a Number**，即“不是数字”，在数据分析中常作为缺失值处理。

### 5.6 `notnull()`：判断是否不为空

```python
数据.notnull()
```

- 用于判断数据是否不为空。
- 返回结果为布尔值：
  - 不为空：显示 `True`
  - 为空：显示 `False`

## 6. 常用方法总结表

| 方法 | 作用 | 示例 |
|---|---|---|
| `index` | 查看索引 | `数据.index` |
| `values` | 查看数据值 | `数据.values` |
| `sort_index()` | 按索引排序 | `数据.sort_index()` |
| `sort_values()` | 按值排序 | `数据.sort_values()` |
| `isnull()` | 判断是否为空 | `数据.isnull()` |
| `notnull()` | 判断是否不为空 | `数据.notnull()` |

## 7. 关键注意事项

- pandas 中类名 `Series` 首字母必须大写。
- 默认索引从 0 开始，结束值不包含在 `RangeIndex` 中，步长默认为 1。
- 使用字典创建 Series 时，字典的键自动成为索引，字典的值成为数据。
- 查询单个键使用：

```python
数据["键名"]
```

- 查询多个键必须使用列表：

```python
数据[["键1", "键2"]]
```

- 多键查询返回的数据类型仍然是 Series。
- 使用两个列表创建 Series 时，第一个位置放值，`index=` 后面放索引列表。
- `NaN` 表示缺失值或非数字值。
- `isnull()` 中空值返回 `True`；`notnull()` 中非空值返回 `True`。
