## 1. 本节定位与学习目标

- 本节讲解 **Matplotlib 极坐标**，是下一节“雷达图”的基础。
- 讲师用直观方式解释极坐标，不展开复杂数学证明；核心结论是：只要理解极点、极轴、极角、极径，并知道 \(\pi = 180^\circ\)，就能绘制极坐标图。
- 雷达图可类比游戏中的雷达图；在 Python 中画雷达图，需要先掌握极坐标。
- 背景对比：Power BI 中拖拽即可完成简单图形，但可设置项较少；Python 更适合处理大数据和专业绘图，例如研究生论文中要求较高自定义程度的图。视频中的小数据示例只是为了便于看清。

## 2. 极坐标核心概念

| 概念 | 含义 | 易混点 / 使用说明 |
|---|---|---|
| 极点 | 极坐标圆盘的中心点，类似飞镖盘十环中心 | 相当于极坐标图的“原点” |
| 极轴 | 从极点指向 \(x\) 方向的固定射线，即 \(0^\circ\) 方向 | 极轴不是极径；极轴是一条方向基准线 |
| 极角 | 目标点与极轴之间的夹角，通常用 \(\theta\) 表示 | Matplotlib 中使用弧度，不是直接写角度 |
| 极径 | 从极点到目标点的距离，通常用 \(r\) 表示 | 视频中有时口述为“极轴/极境”，按极坐标定义应理解为极径 \(r\) |

- 示例：目标点与极轴成一半直角，即 \(45^\circ\)；若与极轴垂直，则为 \(90^\circ\)。
- 极角通常从极轴开始按逆时针方向旋转。
- 极径单位不限，示例中使用数值 \(20、40、60、80\) 等。

## 3. 角度与弧度换算

- 讲师强调必须知道：
  \[
  \pi = 3.1415926 = 180^\circ
  \]
- 因此：
  \[
  0.25\pi = 45^\circ
  \]
  \[
  0.75\pi = 135^\circ
  \]
  \[
  \pi = 180^\circ
  \]
  \[
  1.5\pi = 270^\circ
  \]
- 在 Numpy 中 \(\pi\) 写作：
  ```python
  np.pi
  ```
- 想得到 \(45^\circ\)，写：
  ```python
  theta = 0.25 * np.pi
  ```
- 不需要关心 \(0.25\pi\) 最终算出的数值约为 \(0.785\)，只要知道它代表 \(45^\circ\) 即可。

## 4. 创建极坐标圆盘

- 先什么都不画，只创建极坐标圆盘：
  ```python
  import matplotlib.pyplot as plt

  plt.polar()
  plt.show()
  ```
- 运行后显示极坐标圆盘：中心是极点，右侧水平方向是极轴。
- 此时还没有极角对应的点，因为尚未传入极角和极径数据。
- `plt.polar()` 用于创建极坐标图；调用 `plt.polar(theta, r)` 时会自动创建极坐标轴并绘制数据。

## 5. `plt.polar()` 的参数与基本用法

- 基本形式：
  ```python
  plt.polar(theta, r)
  ```
- 参数说明：
  - 第一个参数 `theta`：极角。
  - 第二个参数 `r`：极径。视频口述为“极轴”，按极坐标语义应理解为极径。
  - 后续参数可传入格式字符串，例如标记、颜色、连线样式。
- 设置极径范围：
  ```python
  plt.ylim(0, 100)
  ```
  - 该语句控制极径坐标范围，示例中显示 \(0\) 到 \(100\)。
  - 径向刻度会出现 \(20、40、60、80、100\)。
  - 零点位于极点。
- 显示图像：
  ```python
  plt.show()
  ```

## 6. 单点绘制示例：\(45^\circ\)、极径 \(20\)

- 极角：
  ```python
  theta = 0.25 * np.pi
  ```
  因为 \(0.25\pi = 45^\circ\)。
- 极径：
  ```python
  r = 20
  ```
- 绘制点：
  ```python
  plt.polar(theta, r, 'o')
  ```
  - `'o'` 表示用圆点标记。
  - 默认颜色为蓝色。
  - 该点位于 \(45^\circ\) 射线与极径 \(20\) 对应的环线交点。
- 完整示例：
  ```python
  import numpy as np
  import matplotlib.pyplot as plt

  theta = 0.25 * np.pi
  r = 20
  plt.polar(theta, r, 'o')
  plt.ylim(0, 100)
  plt.show()
  ```
- 设置极径范围后，图中径向刻度显示 \(20、40、60、80、100\)，零点在极点。

## 7. 修改点的颜色与样式

- 颜色与标记可以组合写在格式字符串中。
- 红色圆点：
  ```python
  plt.polar(theta, r, 'ro')
  ```
  - `r` 表示红色。
  - `o` 表示圆点标记。
- 绿色圆点：
  ```python
  plt.polar(theta, r, 'go')
  ```
  - `g` 表示绿色。
  - `o` 表示圆点标记。
- 易混点：格式字符串中的 `r` 是颜色 red；变量 `r` 是极径。二者含义不同。

## 8. 多个极角与多个极径绘制多个点

- 准备多个角度，先写成以 \(\pi\) 为单位的数组，再统一乘以 \(\pi\)：
  ```python
  theta = np.array([0.25, 0.75, 1, 1.5]) * np.pi
  ```
- 准备对应的极径数组：
  ```python
  r = np.array([20, 60, 40, 80])
  ```
- 绘制多个点：
  ```python
  plt.polar(theta, r, 'o')
  plt.ylim(0, 100)
  plt.show()
  ```
- 各点位置说明：
  - \(0.25\pi = 45^\circ\)，极径 \(20\)。
  - \(0.75\pi = 135^\circ\)，极径 \(60\)，位于 \(60\) 环。
  - \(\pi = 180^\circ\)，极径 \(40\)，位于 \(40\) 环。
  - \(1.5\pi = 270^\circ\)，极径 \(80\)，位于 \(80\) 环。
- 点的排列按逆时针方向旋转。
- 视频中讲师口述“三个点”，但随后按多个角度和极径逐一说明；按数组写法应能绘制出对应的多个点。

## 9. 连接各点：形成雷达图雏形

- 雷达图的本质是把极坐标中的多个点按顺序用线连接起来。
- 在标记后增加连线样式 `-`，例如：
  ```python
  plt.polar(theta, r, 'o-')
  ```
- 若同时设置颜色，可组合为：
  ```python
  plt.polar(theta, r, 'ro-')
  ```
  或：
  ```python
  plt.polar(theta, r, 'go-')
  ```
- 只加 `-` 后，点会按数组顺序连接，但最后一点不会自动连回第一点。
- 不闭合的原因：Matplotlib 按数组顺序连接相邻点，不会自动重复首点。
- 闭合方法：在极角数组和极径数组末尾重复第一个点的值。
  - 第一个点的角度是 \(0.25\pi\)。
  - 第一个点的极径是 \(20\)。
  - 因此在数组末尾追加 `0.25` 和 `20`；若角度数组已经乘以 \(\pi\)，追加的应是 `0.25 * np.pi`。

## 10. 闭合图形示例代码

```python
import numpy as np
import matplotlib.pyplot as plt

theta = np.array([0.25, 0.75, 1, 1.5, 0.25]) * np.pi
r = np.array([20, 60, 40, 80, 20])

plt.polar(theta, r, 'o-')
plt.ylim(0, 100)
plt.show()
```

- 最后追加的 `0.25` 和 `20` 使最后一个点回到第一个点，从而闭合多边形。
- 闭合后的图形就是雷达图的雏形。
- 讲师结论：不需要掌握很多数学知识，只要知道 \(\pi = 180^\circ\)、极角与极径如何对应即可。

## 11. 函数与格式字符串速查

| 代码 / 表达式 | 作用 |

| `plt.polar()` | 创建极坐标圆盘/极坐标图 |
| `plt.polar(theta, r)` | 按极角 `theta`、极径 `r` 绘制极坐标数据 |
| `plt.polar(theta, r, 'o')` | 绘制圆点，默认蓝色 |
| `plt.polar(theta, r, 'ro')` | 绘制红色圆点 |
| `plt.polar(theta, r, 'go')` | 绘制绿色圆点 |

| `plt.polar(theta, r, 'ro-')` | 红色圆点并连线 |
| `plt.ylim(0, 100)` | 设置极径范围为 \(0\) 到 \(100\) |
| `plt.show()` | 显示图像 |
| `np.pi` | 表示 \(\pi\)，即 \(180^\circ\) |
| `np.array([...])` | 创建角度或极径数组 |

## 12. 易混点与踩坑记录

- **极轴与极径易混**：极轴是 \(0^\circ\) 方向基准线；极径是从极点到目标点的距离 \(r\)。视频口述中有时把极径说成“极轴/极境”，需要按极坐标定义理解。
- **角度单位易错**：Matplotlib 极坐标使用弧度，不直接写 \(45\)；应写 `0.25 * np.pi`。
- **`plt.ylim` 不是角度范围**：`plt.ylim(0, 100)` 控制极径范围，不是极角范围。
- **默认点颜色**：只写 `'o'` 时默认蓝色。
- **颜色字母与变量名易混**：格式字符串 `'ro'` 中的 `r` 是红色，不是极径变量 `r`。
- **闭合需要手动处理**：Matplotlib 不会自动把最后一点连回第一点，需要在数组末尾重复首点。
- **旋转方向**：默认按逆时针方向排列点。
- **下节衔接**：本节完成极坐标点、线、闭合图形，下一节继续学习雷达图。

## 13. 本节结论

- 极坐标四要素：极点、极轴、极角、极径。
- 绘制极坐标图的核心函数：`plt.polar(theta, r, fmt)`。
- 极角用弧度表示，\(\pi = 180^\circ\)，\(0.25\pi = 45^\circ\)。
- 用 `plt.ylim(0, 100)` 设置极径范围。
- 用格式字符串控制样式：`'o'` 圆点、`'-'` 连线、`'ro'` 红色圆点、`'go'` 绿色圆点、`'o-'` 点线。
- 多个点通过极角数组和极径数组一一对应绘制。
- 将最后一点连回第一点的方法：在数组末尾重复首点的极角和极径，如追加 `0.25` 和 `20`。
- 闭合后的极坐标连线图就是雷达图的基础形态。
