## 2. 热身：`replace` 的特殊情况——去单位并转数值

- 场景：温度列中是 `36℃` 这类文本，需要提取数字 `36`，并把它转成数值类型。
- 处理思路：先用 `str` 访问器把该列按字符串处理，再用 `replace` 去掉单位，最后用 `astype` 转换类型。
- 示例表达式：

`df['温度'].str.replace('℃', '')`

`df['温度'].str.replace('℃', '').astype('int64')`

- 说明：
  - `df['温度']`：选中温度列。
  - `.str`：把该列按字符串格式处理，之后才能进行字符串替换。
  - `.str.replace('℃', '')`：把摄氏度符号 `℃` 替换为空字符串，得到类似 `"36"` 的文本。
  - `.astype('int64')`：把替换后的结果转换为 64 位整数类型。
- 运行结果：温度列变为整数型，显示为 `int64` 类型。
- 讲师特别强调：
  - `astype` 是类型转换方法，基础篇中已经学过。
  - Pandas 基于 NumPy，建议补充 NumPy 课程和笔记中关于 `int32`、`int64`、`float32`、`float64` 等数据类型的介绍。
  - 如果不会 NumPy，只把 Pandas 当 VBA 用，不如直接使用 VBA 方便。

## 3. `cat`：与指定字符进行拼接

- 作用：`Series.str.cat` 用于把字符串与指定字符或其他序列进行拼接。
- 记忆点：方法名是 `cat`，不是 `kat`。

### 3.1 不带参数拼接整列

示例：

`df['姓名'].str.cat()`

- 效果：把姓名列中的所有姓名像“穿糖葫芦”一样平行拼接成一整串。
- 示例中的姓名有丁志敏、李婷婷等，直接拼接后不便区分。

### 3.2 使用 `sep` 添加分隔符

示例：

`df['姓名'].str.cat(sep='、')`

- `sep` 参数用于指定拼接时的分隔符。
- 运行后每个人名之间用指定符号分开，例如中文顿号 `、`。

### 3.3 给每个姓名后追加固定内容

目标：在每个姓名后面都加上“变身”两个字。

关键做法：追加的内容必须与姓名列等长，即有多少个姓名，就要提供多少个“变身”。

示例思路：

`df['姓名'].str.cat(['变身'] * len(df))`

或再添加分隔符：

`df['姓名'].str.cat(['变身'] * len(df), sep='▲')`

- `['变身'] * len(df)`：构造一个长度等于数据行数的列表。
- `len(df)`：获取数据行数，避免手工数行。
- 讲师先用 `* 5`、`* 6` 做测试，说明如果数据有 6 行，就必须乘 6；数量不相等会不对齐或报错。
- 添加 `sep='▲'` 后，每个“姓名+变身”之间再用上三角符号分隔。

### 3.4 使用 `na_rep` 处理空值

- 将原表中某个姓名清空后，再运行 `cat`，结果中会出现 `NaN`。
- 使用 `na_rep` 参数可以把空值替换为指定内容。

示例：

`df['姓名'].str.cat(['变身'] * len(df), na_rep='@')`

- 结果中空姓名位置显示为 `@变身`。
- 也可以写成 `na_rep='没有'`、`na_rep='无名'` 等。
- 讲师提醒：空值不能直接参与拼接，需要给它一个替代文本。

### 3.5 `cat` 关键结论

- `cat` 用于和指定字符进行连接。
- 给每个元素追加内容时，追加序列必须与原始数据等宽、等长、数量相等。
- `sep` 用于添加分隔符。
- `na_rep` 用于替换空值。
- `cat` 与后面的 `join` 容易混淆：`cat` 更偏向整列多个元素之间的拼接；`join` 是把每个字符串内部字符之间连接起来。

## 4. `split`：按指定字符拆分

- 作用：`Series.str.split` 按指定字符拆分字符串，结果通常是列表形式。
- 它和 Python 内置的 `split` 类似。

### 4.1 基本拆分

示例：

`df['状态'].str.split('血')`

- 以“血”作为分隔符进行拆分。
- 与 Python 内置 `split` 一样，分隔符本身不会保留在结果中。
- 例如“满血激活”按“血”拆分后，前一部分是“满”，后一部分是“激活”。

### 4.2 不指定分隔符

示例：

`df['状态'].str.split()`

- 结果以列表形式显示。
- 空值仍然显示为空值。
- 讲师用该示例说明 `split` 会把每个元素拆成列表形式，便于后续按位置访问。

### 4.3 参数 `n`：指定拆分次数

- `split` 可以指定参数 `n`，表示拆分几次。
- 默认值为 `n=-1`，表示全部分离。
- 如果字符串中有多个“血”，只想替换或拆分前一个，可以传入指定数字。
- 示例“满血激活”只有一个“血”，所以不指定 `n` 也可以。

### 4.4 参数 `expand=True`：拆成多列

示例：

`df['状态'].str.split('血', expand=True)`

- `expand` 默认为 `False`，结果是列表。
- `expand=True` 时，会把拆分后的列表展开成多列。
- 以“血”拆分就把一列分成两列，效果类似 Excel 中的“分列”。

### 4.5 `rsplit`

- `rsplit` 表示从右向左拆分。
- 它与 `split` 的方向相反：`split` 从左向右，`rsplit` 从右向左。
- 讲师说明这里不展开演示，了解即可。

## 5. `partition`：按指定字符分割并保留分隔符

- 作用：`Series.str.partition` 按指定字符进行分割。
- 与 `split` 的最大区别：`partition` 会保留分隔符本身。
- 返回结果包含三部分：
  - 第一个分隔符之前的部分。
  - 分隔符本身。
  - 分隔符之后的内容。

示例：

`df['状态'].str.partition('血')`

- 结果不是简单去掉“血”，而是把“血”单独作为中间部分保留下来。

### 5.1 多个分隔符时只按第一个分割

- 重要结论：如果字符串中有多个分隔符，`partition` 只按照第一个分隔符进行分割。
- 讲师用含多个 `b` 的字符串做示例：设置字符串后调用 `partition('b')`，结果第一个元素是第一个分隔符前的内容，第二个元素是第一个分隔符本身，第三个元素是剩余内容。
- 后续出现的分隔符不会再继续拆分。
- 这一点与 `split` 不同，`split` 默认可以全部拆分。

### 5.2 找不到分隔符时

示例：

`df['状态'].str.partition('苹果的屏')`

- 如果指定字符不存在，返回结果中：
  - 第一个元素是原字符串。
  - 后两个元素为空。
- 如果不写分隔符，效果与写一个不存在的分隔符类似：原字符串作为第一列，后两列为空。
- 如果原数据为空值，结果仍然为空值。

### 5.3 `rpartition`

- `rpartition` 从右向左查找分隔符。
- 不加 `r` 的 `partition` 默认从左到右。
- 讲师说明了解即可，需要时查笔记。

## 6. `get`：获取指定位置的字符

- 作用：`Series.str.get` 获取指定位置的字符。
- 只能获取一个字符。

示例：

`df['状态'].str.get(2)`

- 索引从 `0` 开始。
- 以“满血激活”为例：
  - 索引 0：满
  - 索引 1：血
  - 索引 2：激
  - 索引 3：活
- 因此 `get(2)` 取到索引 2 对应的字符，即第三个字符。

### 6.1 参数类型要求

- `get` 中只能传 `int` 型，即整数。
- 不能传浮点型等其他类型。
- 必须传整数索引。

### 6.2 越界情况

示例：

`df['状态'].str.get(8)`

- 如果索引越界，返回 `NaN`。
- 如果全部越界，整体 dtype 会显示为 `float64`。

### 6.3 重要踩坑：整数列因空值变成 `float64`

- 讲师提醒：使用 Pandas 时间长了，一定会遇到类似问题。
- 从 Excel、数据库、CSV 等读取数据时，原本是整数类型的列，读成 DataFrame 后可能变成 `float64`。
- 原因：列中存在空值，导致整数列被提升为浮点型。
- 例如原本 Excel 中是 `1`，读入后可能显示为 `1.0`。
- `object` 类型可以理解为字符串型或字符型。
- 空值类型：
  - 非时间类型的空值通常是 `NaN`。
  - 时间类型的空值通常是 `NaT`。
- 如果想把 `NaN` 和 `NaT` 转成空，需要专门转换；讲师提到之前课件和 CSDN 中有相关方法。

## 7. `slice`：获取指定范围的字符

- 作用：`Series.str.slice` 获取指定范围内的字符，类似 Python 切片。
- 与 `get` 的区别：
  - `get` 获取单个位置。
  - `slice` 获取一个范围。

### 7.1 只传一个数字

示例：

`df['状态'].str.slice(0)`

- 只传一个数字时，相当于从该数字开始，一直到字符串结束。
- `slice(0)` 表示从索引 0 开始到末尾，因此显示全部内容。

### 7.2 指定起止范围

示例：

`df['状态'].str.slice(0, 3)`

- Python 切片规则：包含起始索引，不包含结束索引。
- `slice(0, 3)` 返回索引 0、1、2，共三个字符。

### 7.3 指定步长

示例思路：

`df['状态'].str.slice(0, None, 2)`

- 第三个参数是步长。
- 步长为 2 表示隔一个取一个，例如取索引 0、2……。
- 讲师说明 `slice` 支持步长。

### 7.4 越界情况

- 如果指定范围越界：
  - 原来有字符的位置显示为空字符串。
  - 原来就是空值的位置仍然显示为空值。
- 与 `get` 全部越界返回 `NaN` 并变成 `float64` 的情况要区分。

## 8. `slice_replace`：筛选出指定范围后替换

- 作用：先按范围筛选出子串，再把该子串替换为指定内容。
- 示例：

`df['状态'].str.slice_replace(1, 3, '520')`

- 含义：取索引 1 到索引 3 之前的内容，即索引 1、2 两个字符，然后替换成 `520`。
- 以“满血激活”为例：
  - 索引 1 是“血”
  - 索引 2 是“激”
  - 将“血激”替换为 `520`。
- 重要结论：`slice_replace` 本质是替换，因此不支持步长。
- 讲师强调：因为它是在替换，所以不能像 `slice` 那样传入步长。

## 9. `join`：把每个字符之间用指定字符相连

- 作用：`Series.str.join` 将每个字符串内部每个字符之间用指定字符连接起来。
- 示例：

`df['状态'].str.join('a')`

或：

`df['状态'].str.join('502')`

- 效果：每个字符串的字符之间都插入指定连接符。
- 例如“满血激活”会在“满”“血”“激”“活”之间插入连接符。
- 与 `cat` 的区别：
  - `cat`：把整列多个元素拼接成一串。
  - `join`：对每个元素内部字符进行连接，像“胶水”一样粘在每个字符之间。
- 连接符可以是一个字符，也可以是多字符，如 `502`。

## 10. `contains`：判断是否包含指定字符串

- 作用：`Series.str.contains` 判断每个字符串是否包含指定子串。
- 返回布尔型结果：`True` 或 `False`。

示例：

`df['状态'].str.contains('血')`

- 包含“血”的位置返回 `True`。
- 不包含的位置返回 `False`。
- 空值默认显示为 `NaN`。

### 10.1 使用 `na` 处理空值

- `contains` 可以通过 `na` 参数处理空值。

示例：

`df['状态'].str.contains('血', na=False)`

- 空值位置显示为 `False`。

也可以：

`df['状态'].str.contains('血', na=True)`

- 空值位置显示为 `True`。

还可以：

`df['状态'].str.contains('血', na='没有')`

- 空值位置显示为指定字符串“没有”。
- 讲师说明 `na` 想设置成什么都可以，按需求写。

## 11. `startswith` / `endswith`：判断开头和结尾

### 11.1 `startswith`

示例：

`df['状态'].str.startswith('满')`

- 判断每个字符串是否以“满”开头。
- “满血激活”返回 `True`。
- “零血销毁”返回 `False`。
- 返回结果为布尔型。
- 也支持 `na=False`、`na=True`、`na='没有'` 等空值处理参数。

### 11.2 `endswith`

示例思路：

`df['状态'].str.endswith('...')`

- 判断是否以指定内容结尾。
- 把 `startswith` 改成 `endswith`，并传入结尾字符即可。
- 讲师说明这里不逐一演示，参数与 `startswith` 类似。
- 这类判断在 Excel 操作中经常使用。

- 作用：`Series.str.repeat` 重复字符串。

## 13. `pad`：用指定字符填充到指定宽度

- 作用：`Series.str.pad` 将每个元素用指定字符填充到指定宽度。
- 参数 `fillchar` 只能是一个字符。

示例：

`df['姓名'].str.pad(5, fillchar='*')`

- 将每个姓名填充到宽度 5。
- 如果姓名为 3 个字符，则补 2 个字符；如果姓名为 2 个字符，则补 3 个字符。
- 默认 `side='left'`，即从左边填充。

### 13.1 指定填充方向

- 右侧填充：

`df['姓名'].str.pad(5, side='right', fillchar='*')`

- `side='right'` 表示在右边补齐。
- 左侧填充是默认值，不需要写 `side='left'`。

- 两端填充：

`df['姓名'].str.pad(5, side='both', fillchar='*')`

- `side='both'` 表示两端补齐。
- 自动判断左右各补多少，尽量保持平衡，一般优先向左补，再补右边。

### 13.2 衍生方法：`center`、`ljust`、`rjust`

讲师说明 `pad` 的左右和两端填充又演变出三个方法：

- `str.center(width, fillchar='*')`
  - 等价于两端补齐，相当于 `pad(..., side='both')`。
  - 直接告诉它宽度和用于填充的字符即可，默认两端补齐。

- `str.ljust(width, fillchar='*')`
  - 左对齐，在右侧填充。
  - 相当于 `pad(..., side='right')`。
  - 改成 `ljust` 后不需要再写 `side`。

- `str.rjust(width, fillchar='*')`
  - 右对齐，在左侧填充。
  - 相当于 `pad(..., side='left')`。

- 讲师建议：脑容量有限，不推荐记这么多方法，记住 `pad` 即可；其他方法知道含义，需要时查笔记。

## 14. `zfill`：用零从左边填充

- 作用：`Series.str.zfill` 用零从左边填充到指定宽度。
- 特点：只能填充 `0`，且只能从左边填充。

示例：

`df['姓名'].str.zfill(10)`

- 将姓名填充到 10 位。
- 不足部分在左边用 `0` 补齐。
- 与 `pad` 的区别：`pad` 可以指定任意单字符和方向；`zfill` 固定用零、固定左填。

## 15. `encode` / `decode`：编码与解码

### 15.1 编码 `encode`

示例思路：

`df['列名'].str.encode('utf-8')`

- 用于编码转换。
- 常见场景：CSV 文件整体是英文，但某一列含中文，可能出现乱码，需要转换成 `utf-8`。
- 编码方法是 `encode`。

### 15.2 解码 `decode`

示例思路：

`df['列名'].str.decode('utf-8')`

- 用于解码。
- 解码方法是 `decode`。
- 讲师强调要弄清楚：
  - 编码：`encode`
  - 解码：`decode`
- 这部分了解即可，实际遇到转码问题时再查笔记。

## 16. `strip` / `lstrip` / `rstrip`：按指定内容去除两端字符

- 作用：`Series.str.strip` 按指定内容从两边去除字符。
- 示例先查看里程列原值：

`print(df['里程'])`

- 里程列示例值包括：近距离、远距离、中远距离、近距离、空值等。
- 使用 `strip`：

`df['里程'].str.strip('中远近离')`

- 效果：从字符串两端去除参数中出现的字符。
- 注意：`strip` 的参数应按字符集合理解，不是简单按完整子串去除。
- 示例中参数为“中远近离”，不包含“距”字，因此“近距离”去掉两端的“近”和“离”后，中间的“距”会保留下来。
- 空值仍为空值。

### 16.1 `lstrip` 与 `rstrip`

- `str.lstrip(...)`：从左边去除指定字符。
- `str.rstrip(...)`：从右边去除指定字符。
- `str.strip(...)`：从两边去除。
- 讲师说明这三个方法都写在笔记中，需要时自行测试。

- `replace` 可用于去单位并配合 `astype` 转数值，例如 `df['温度'].str.replace('℃', '').astype('int64')`。
- `cat`：整列拼接；`sep` 加分隔符；追加序列必须与数据等长；`na_rep` 替换空值。
- `split`：按分隔符拆分，默认 `n=-1` 全部拆分；`expand=True` 可拆成多列；`rsplit` 从右向左。
- `partition`：保留分隔符，返回“前、分隔符、后”三部分；多个分隔符只按第一个拆；`rpartition` 从右向左。
- `get`：取单个位置字符，参数必须是整数；越界返回 `NaN`，全部越界时 dtype 可能为 `float64`。
- `slice`：范围切片；支持步长；越界时有字符位置显示为空字符串。
- `slice_replace`：范围替换；本质是替换，不支持步长。
- `join`：在每个字符串内部字符之间插入指定连接符，和 `cat` 的整列拼接不同。
- `contains`、`startswith`、`endswith`：返回布尔型判断结果；空值可用 `na` 参数处理。
- `repeat`：重复字符串；`na` 参数通用。
- `pad`：按指定宽度和单字符填充；默认左侧，`side='right'` 右侧，`side='both'` 两端；`center`、`ljust`、`rjust` 是衍生方法，讲师建议优先记 `pad`。
- `zfill`：只能用 `0` 从左边填充到指定宽度。
- `encode` / `decode`：编码和解码，遇到 CSV 中文乱码或转码时使用。
- `strip` / `lstrip` / `rstrip`：从两边、左边、右边去除指定字符集合中的字符。
- 重要踩坑：Pandas 读入 Excel、CSV、数据库时，原本整数列若含空值可能变成 `float64`；非时间空值为 `NaN`，时间空值为 `NaT`；需要专门处理才能变成空。
