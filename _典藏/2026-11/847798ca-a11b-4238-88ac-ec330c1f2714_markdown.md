## 1. Series 的基本组成

- `Series` 是一维数据，可以是一行，也可以是一列。
- `Series` 由两部分组成：
  - 索引列，即 `index`。
  - 用户自定义的一列数据，即值，即 `values`。
- 示例中创建的数据包括：
  - 姓名：孙兴华
  - 性别：男
  - 年龄：20 岁 / 20
  - 出生日期：2000 年某一天
- 打印 `Series` 后可以看到：
  - 左侧为索引列。
  - 右侧为自定义数据列。
- 这说明 `Series` 是由索引列和数据列共同组成的一维数据结构。

示例代码：

```python
import pandas as pd

数据 = pd.Series(["孙兴华", "男", "20岁", "2000-某日"])
print(数据)
```

关键点：

- `pd.Series` 中的 `Series` 首字母必须大写。
- 不能用小写 `series`，小写形式不是正确用法。
- 讲师示例中使用变量名 `数据`，便于初学者理解。

## 2. 查看 Series 的索引和值

### 查看索引：`.index`

示例：

```python
数据.index
```

运行结果说明：

- 默认索引从 `0` 开始。
- 示例中有 4 个元素，索引为 `0、1、2、3`。
- 转录中描述为“到四，其实是到三，最大值不包括它本身，不包括结束值，步长为 1”。
- 对应 `RangeIndex` 的含义：从 `0` 开始，到结束值之前停止，步长为 `1`。

### 查看值：`.values`

示例：

```python
数据.values
```

结果：

- 返回 `Series` 中的数据值。
- 例如返回“孙兴华、男、20岁、出生日期”等内容。
- 转写中的 `videos` 应理解为 `values`。

## 3. 自定义索引

- 默认索引是 `0、1、2、3`。
- 如果不想使用默认数字索引，可以在创建 `Series` 时通过 `index=` 参数指定索引。
- 示例：指定索引为 `a、b、c、d`。

示例代码：

```python
数据 = pd.Series(
    ["孙兴华", "男", "20岁", "2000-某日"],
    index=["a", "b", "c", "d"]
)
print(数据)
```

关键点：

- 在 `pd.Series()` 后加上关键字参数 `index=`。
- `index` 的值通常用列表形式给出。
- 讲师指出，在实际工作中，这种直接指定索引的方式相对少见，更常见的是数组/列表与字典配合使用。

## 4. 使用字典创建 Series

### 字典基础回忆

字典使用大括号 `{}` 表示，内部是键值对形式：

```python
字典 = {
    "姓名": "孙兴华",
    "性别": "男",
    "年龄": 20,
    "地址": "某某某"
}
```

注意：

- 键和值之间使用冒号 `:`。
- 不同键值对之间使用逗号 `,`。
- 转录中讲师提醒“这里写错标点了”，说明字典创建时冒号、逗号必须写正确。

### 用字典生成 Series

示例：

```python
数据 = pd.Series(字典)
print(数据)
```

运行结果与结论：

- 用字典生成的 `Series`，索引列默认是字典的键。
- 索引为：`姓名、性别、年龄、地址`。
- 对应的值为字典中每个键对应的值。
- 字典的键自动成为 `Series` 的索引。
- 字典的值自动成为 `Series` 的数据值。

查看索引：

```python
数据.index
```

返回结果就是字典的键。

## 5. 按标签索引查询数据

- 查询整个 `Series` 时，直接打印变量即可：

```python
print(数据)
```

- 如果想通过索引键查询对应值，可以在中括号中写键名：

```python
数据["姓名"]
```

返回：

```text
孙兴华
```

示例：

```python
数据["性别"]
```

返回：

```text
男
```

```python
数据["年龄"]
```

返回：

```text
20
```

### 查询多个键的值

- 想同时查询多个键时，不能直接在中括号中并列写多个键。
- 错误写法示例：

```python
数据["姓名", "性别"]
```

讲师强调：

- 这样运行是错的。
- `Series` 的中括号默认接收一个键。
- 如果传入多个键，必须把多个键组合成一个列表。
- 也就是说，要把多个键放在一个列表中，再把这个列表传给中括号。

正确写法：

```python
数据[["姓名", "性别"]]
```

结论：

- 单个键查询：`数据["姓名"]`
- 多个键查询：`数据[["姓名", "性别"]]`
- 多个键必须用列表形式表现，不能直接写成两个分开的键参数。

### 多键查询的返回类型

- 多个键查询返回的数据类型不是普通值类型。
- 返回结果仍然是 pandas 中的 `Series` 类型。
- 讲师特别强调：运行结果会告诉你这是一个 `Series`，而不是简单告诉你某个单值类型。
- 这一点需要注意，因为多键查询后得到的仍是一个一维数据结构。

## 6. 使用两个列表分别提供值和索引

- 如果键和值分别存放在不同列表中，也可以创建 `Series`。
- 示例结构：
  - 列表一存放索引：`["姓名", "性别", "年龄"]`
  - 列表二存放值：`["孙兴华", "男", 20]`

示例代码：

```python
列表一 = ["姓名", "性别", "年龄"]
列表二 = ["孙兴华", "男", 20]

数据 = pd.Series(列表二, index=列表一)
print(数据)
```

关键点：

- `pd.Series()` 的第一个位置放的是“值”。
- 通过 `index=` 参数指定“索引”。
- 讲师强调：这里放的是值，后边指定它的索引。
- 使用两个列表时，要让哪个列表做索引必须明确指定，另一个列表作为值。

## 7. Series 与行、列的关系

- `Series` 只是一个序列，可以是一行，也可以是一列。
- 在未加入 `DataFrame` 时，无法确定它到底作为行还是列。
- 将 `Series` 加入 `DataFrame` 后，根据添加方式不同，它可以成为行或列。
- 讲师说明：本节只需要知道 `Series` 是一维数据，可以是一行或者一列，并掌握如何创建、查询即可。
- 关于 `Series` 如何加入 `DataFrame`、如何确定行或列，会在之后详细讲。

## 8. Series 常用方法：排序

### 读取 Excel 数据准备

- 讲师将示例文件改为“数据结构”，用于后续两节课共用。
- 并打乱索引顺序，示例中索引变为 `1、2、4、3、5、6、7`。
- 读取 Excel 数据，沿用上节课学过的 Excel 读取方法。

示例代码：

```python
import pandas as pd

数据 = pd.read_excel("数据结构.xlsx")
print(数据)
```

读取后得到表格，索引顺序为打乱状态，例如 `1、2、4、3、5、6、7`。

### 按索引排序：`sort_index()`

示例：

```python
数据.sort_index()
```

说明：

- `sort_index()` 用于按照索引排序。
- 转录中的“shot 下划线 index”应理解为 `sort_index()`。
- 该方法后面要跟括号。
- 运行后，索引会由 `1、2、4、3、5、6、7` 排成 `1、2、3、4、5、6、7`。
- Excel 中也有排序公式 `SORT`，讲师用其帮助理解排序概念。

### 按值排序：`sort_values()`

示例：

```python
数据.sort_values("入职日期")
```

说明：

- `sort_values()` 用于按照值进行排序。
- 转录中的 `valuv`、`a l u e s` 应理解为与 `sort_values` 相关。
- 参数中可以写要排序的列名，例如 `"入职日期"`。
- 运行后，数据会按照入职日期从早到晚排序。
- 示例结果为 `1 月 1 日、1 月 2 日、1 月 3 日、1 月 4 日、1 月 5 日、1 月 6 日、1 月 7 日`。

## 9. 空值判断方法

### 查看是否为空：`isnull()`

示例：

```python
数据.isnull()
```

说明：

- `isnull()` 用于查看数据是否为空。
- 函数名后面要跟括号。
- 运行后：
  - 不为空的位置显示 `False`。
  - 为空的位置显示 `True`。

示例结论：

- 数据中第七行“赵敏”的年龄被删除，该位置为空。
- `isnull()` 在第七行年龄处显示 `True`。
- 其他不为空的位置显示 `False`。

### 查看是否不为空：`notnull()`

示例：

```python
数据.notnull()
```

说明：

- `notnull()` 用于判断是否不为空。
- 转录中“nn u l l 就是不为空”应理解为 `notnull()`。
- 运行结果与 `isnull()` 相反：
  - 不为空的位置显示 `True`。
  - 为空的位置显示 `False`。

### NaN 的含义

- 讲师联系之前 NumPy 中学习的内容说明：`NaN` 代表 Not a Number，即“不是一个数字”。
- 在数据中，空值常用 `NaN` 表示。
- 示例中“赵敏”的年龄被删掉后，读取数据时该位置为空，可用 `isnull()` 和 `notnull()` 判断。

## 10. 本节关键结论与易错点

- `Series` 是 pandas 中的一维数据结构，可以是一行或一列。
- `DataFrame` 是二维数据结构，多行多列，可以由多个 `Series` 组成。
- `DataFrame` 可简写为 `df`。
- `Series` 由索引 `index` 和值 `values` 组成。
- `pd.Series` 中的 `Series` 必须大写首字母。
- 默认索引从 `0` 开始，步长为 `1`，结束值不包含在内。
- 使用 `index=` 参数可以指定自定义索引。
- 用字典创建 `Series` 时，字典的键会自动成为索引，值会自动成为数据值。
- 单个键查询使用 `数据["键名"]`。
- 多个键查询必须写成列表形式：`数据[["键1", "键2"]]`。
- 多个键直接写成 `数据["键1", "键2"]` 是错误的。
- 多键查询返回的结果类型仍然是 pandas 的 `Series`。
- 使用两个列表分别提供值和索引时，第一个参数放值，`index=` 放索引。
- `sort_index()` 按索引排序。
- `sort_values("列名")` 按指定列的值排序。
- `isnull()` 判断是否为空，空为 `True`，不为空为 `False`。
- `notnull()` 判断是否不为空，不为空为 `True`，空为 `False`。
- `NaN` 表示 Not a Number，是空值常见表示之一。
