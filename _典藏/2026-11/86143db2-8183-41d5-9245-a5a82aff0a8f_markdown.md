## 一、课程主题与总体说明

- 本节主题：`pandas` 数据筛选。
- 讲师强调：筛选这节课很重要，而且比较简单、实用。
- 课程主线：从最简单的行范围筛选开始，逐步扩展到条件筛选、`query` 多条件筛选、文本筛选、正则表达式筛选、日期筛选。
- 学习建议：筛选方法很多，网上搜索会有大量写法；本节优先讲工作中常用、相对简单的写法，避免一开始被过多方法淹没。

## 二、Excel 多工作表读取：`sheet_name` 参数

- `csv` 文件不涉及“一个工作簿里有多张表”的问题；Excel 的 `.xlsx` 工作簿可能包含多张工作表。
- 如果 Excel 里有多个工作表，不需要先用 VBA 拆成多个工作簿；`pandas` 读取时设置 `sheet_name` 参数即可。
- 导入模块：
  - `import pandas as pd`
- 设置文件路径，例如：
  - `路径 = r'C:\...\筛选.xlsx'`
- 读取 Excel：
  - `数据 = pd.read_excel(路径)`
  - 课程口述中可能说成 `pd.excel`，实际函数是 `pd.read_excel`。
- 打印查看数据：
  - `print(数据)`
- 按老规矩把“序号”设置为索引：
  - `数据 = 数据.set_index('序号')`
- 指定工作表读取：
  - `数据 = pd.read_excel(路径, sheet_name='1')`
  - `sheet_name` 用来指定工作表名称。
  - 如果写 `sheet_name='sheet3'` 但工作簿中没有该表，运行会报错，提示找不到这张表。
- 如果工作表名是数字，如工作表名为 `1`，可写 `sheet_name='1'`。
- 结论：
  - 读取多工作表时，关键是 `sheet_name` 参数。
  - 一般工作中很少直接在一个工作簿里反复操作多张表；常见做法是先做多表连接、合并、重塑，把多张表整理成一张表后再筛选。相关方法在之前的课程中已经讲过。

## 三、按索引/行范围筛选：`loc`

- 目标：筛选序号第 2 行到第 4 行。
- 使用 `loc`：
  - `结果 = 数据.loc[2:4]`
- `loc[2:4]` 使用中括号，按索引标签切片，且包含右端点 `4`。
- 重要坑：
  - 只写 `数据.loc[2:4]` 只是返回一个临时结果并显示出来，不会改变原来的 `数据`。
  - 必须定义一个变量接收筛选结果，例如 `结果 = 数据.loc[2:4]`，后续使用 `结果` 才能看到筛选后的数据。
  - 讲师强调：一定要先定义变量并赋值，再运行。
- `loc` 的括号特点：
  - `loc` 使用中括号：`数据.loc[2:4]`
  - `query` 使用小括号：`数据.query(条件)`
  - 视频中曾因忘记把中括号改成小括号导致报错。

## 四、按列值进行条件筛选

- 目标：筛选“性别”列中所有男性。
- 不推荐的直接写法：
  - `数据[数据['性别'] == '男']`
  - 这种写法虽然能运行，但多条件时代码会变得很长、很乱。
- 推荐写法：先定义条件变量，再把条件放入数据筛选。
  - `条件 = 数据['性别'] == '男'`
  - `数据[条件]`
- 解释：
  - `数据` 是从 Excel 或 CSV 读出来的 `DataFrame`，是一张二维数据表。
  - `数据['性别']` 取出的是 `Series`，即一列数据。
  - `数据['性别'] == '男'` 会生成一个布尔条件。
  - `数据[条件]` 表示把满足该条件的行筛选出来。
- 结论：
  - 简单条件可以这样写。
  - 条件多时建议先写条件变量，代码更干净。

## 五、多条件筛选与 `query`

### 5.1 多条件目标示例

- 目标：筛选“性别为男”且“总分大于等于 150”的记录。
- 数据中男性有三人：
  - 王松：总分 `162`
  - 陆海军：总分 `153`
  - 王刚：总分 `142`
- 因为要求总分 `>= 150`，所以王刚会被过滤掉，最终应保留王松、陆海军。

### 5.2 普通布尔条件组合思路

- 也可以把多个条件拼起来，例如类似：
  - `数据[(数据['性别'] == '男') & (数据['总分'] >= 150)]`
- 但讲师指出：每次都写 `数据['列名']` 很麻烦，条件一多更乱。
- 因此引入 `query`，它可以通过字符串进行查询。

### 5.3 `query` 的基本用法

- 写法：
  - `数据.query(条件)`
- 先构造条件字符串：
  - `条件 = "性别 == '男' and 总分 >= 150"`
  - `数据.query(条件)`
- `query` 的特点：
  - 可以直接识别字符串中的列名，不需要反复写 `数据['列名']`。
  - 可以在字符串中使用 `and`、`or`。
  - 类似 SQL 的查询写法。
- 引号规则：
  - 外层用双引号，内层就用单引号。
  - 外层用单引号，内层就用双引号。
  - 例如：`条件 = "性别 == '男' and 总分 >= 150"`。
  - 这个规则来自 Python 字符串基础，引号不能混用。
- 结论：
  - 条件越多，`query` 越方便。
  - `query` 中可直接写 `and` 和 `or`。
  - `loc` 用中括号，`query` 用小括号，注意不要写错。

## 六、`query` 中的 `in` 筛选

- 目标：一次筛选多个离散值，例如筛选姓名“李婷婷”和“王刚”。
- 写法示例：
  - `条件 = "姓名 in ['李婷婷', '王刚']"`
  - `数据.query(条件)`
- 作用：
  - 类似 SQL 中的 `IN`。
  - 例如 SQL 中可写：电号 `in (1, 3, 5, 7)`，就会把 1、3、5、7 电号都查出来。
- 结论：
  - `query` 支持 `in`。
  - 适合从某一列中筛选多个指定值。
  - 注意区分：`in` 是“值属于列表”，不是文本包含。

## 七、文本开头与结尾筛选

### 7.1 开头筛选：`str.startswith`

- 目标：筛选姓名以“王”开头的记录。
- 需要先通过 `.str` 访问字符串方法：
  - `条件 = 数据['姓名'].str.startswith('王')`
  - `数据[条件]`
- 函数名：
  - `startswith`，表示判断字符串是否以某个内容开头。
- 参数：
  - 可以是一个字符、两个字符或多个字符。
  - 例如查地址开头是“北京市”，可写 `startswith('北京市')`。
- 使用场景：
  - 查姓氏开头。
  - 查地址、编号、名称等是否以指定字符串开头。

### 7.2 结尾筛选：`str.endswith`

- 目标：筛选姓名以“松”结尾的记录。
- 写法：
  - `条件 = 数据['姓名'].str.endswith('松')`
  - `数据[条件]`
- 函数名：
  - `endswith`，表示判断字符串是否以某个内容结尾。
- 与 `startswith` 的区别：
  - `startswith` 看开头。
  - `endswith` 看结尾。

### 7.3 文本方法注意事项

- 使用 `.str` 表示对字符串列进行操作。
- 视频中提到，做开头、结尾判断时一般是针对字符串类型，需要先保证该列按字符串处理。
- `startswith`、`endswith` 是文本方法，不是日期方法，也不是数值方法。

## 八、文本包含筛选：`str.contains`

### 8.1 为什么需要 `contains`

- 目标：筛选地址中包含“信阳市”的记录。
- 数据中的地址可能写成：
  - `河南省信阳市`
  - `信阳市`
- 如果用 `startswith('信阳市')`，那么“河南省信阳市”就不一定能匹配到，因为开头不是“信阳市”。
- 因此需要使用“包含”筛选：
  - `条件 = 数据['地址'].str.contains('信阳市')`
  - `数据[条件]`
- 结论：
  - `startswith` 只匹配开头。
  - `endswith` 只匹配结尾。
  - `contains` 匹配任意位置，适合地址、备注、描述等长文本字段。

### 8.2 `contains` 的参数说明

- 函数：
  - `Series.str.contains(pat, case=True, ...)`
- 第一个参数 `pat`：
  - 可以是字符串。
  - 也可以是正则表达式。
- `case` 参数：
  - 默认 `True`，表示大小写敏感。
  - 设置为 `False` 时，表示大小写不敏感。
  - 视频中口述“匹配一个敏感信息”，实际指大小写是否敏感。
- 其他参数：
  - 视频表示暂时用处不多，用到时再讲。
- 注意：
  - `pandas` 的 `str.contains` 默认按正则表达式处理模式，写普通文本时若包含正则特殊字符要留意。
  - 讲师建议系统学习正则表达式。

### 8.3 正则表达式筛选示例

- 目标：筛选地址中包含 `a座`、`b座`、`c座` 的记录，同时兼容大小写。
- 数据中可能出现：
  - 大写 A 座
  - 小写 a 座
  - 大写 C 座
  - 小写 c 座
  - B 座、F 座等
- 正则写法：
  - `条件 = 数据['地址'].str.contains('[a-c]', case=False)`
  - `数据[条件]`
- 说明：
  - `[a-c]` 表示匹配 `a` 到 `c` 范围内的字符。
  - `case=False` 表示不区分大小写，因此 A、B、C 和 a、b、c 都能匹配。
  - 如果 `case=True`，则只匹配指定大小写形式。
- 也可以直接在正则里写大小写范围：
  - `[a-cA-C]`
- 讲师个人建议：
  - 学会正则表达式后，直接用正则表达更简单。
  - 不必过度依赖 `case` 等参数；脑容量有限，优先学有用的内容。
  - 正则表达式在 Python、VBA 等语言中都通用，在 `pandas` 中也通用。
  - 如果不会正则，可参考 B 站 Python 爬虫教程前三节课，讲师称那里专门讲了正则表达式。

## 九、`query` 复习：数值范围 + 性别条件

- 目标：筛选语文分数在 `60` 至 `100` 之间的女性。
- 条件写法：
  - `条件 = "语文 >= 60 and 语文 <= 100 and 性别 == '女'"`
  - `数据.query(条件)`
- 说明：
  - `query` 中列名直接写，不需要写成 `数据['语文']`。
  - 字符串值要加引号，如 `'女'`。
  - 数值范围用 `>=`、`<=` 连接。
  - 多个条件用 `and`。
- 结论：
  - `query` 很适合“数值范围 + 分类条件”的组合筛选。
  - 注意字符串引号嵌套。

## 十、日期筛选基础与“日期筛选三部曲”

### 10.1 日期筛选的典型场景

- 场景：按出生日期、订单日期、创建日期等筛选某年、某月、某区间。
- 视频以“出生日期”为例。
- 讲师强调：不同行业的数据表差异很大，但日期筛选方法是通用的。

### 10.2 日期筛选三部曲

- 第一步：将日期列设置为索引。
  - `数据 = 数据.set_index('出生日期')`
- 第二步：将日期列转换为日期型格式。
  - 如果日期已经是索引：
    - `数据.index = pd.to_datetime(数据.index)`
  - 如果日期仍在列中：
    - `数据['出生日期'] = pd.to_datetime(数据['出生日期'])`
  - 视频强调：可用一行代码完成转换；如果有多个日期字段，可在列表中用逗号分隔处理。读取阶段也可使用 `parse_dates` 思路指定日期列。
- 第三步：对日期进行排序。
  - 如果日期是索引：
    - `数据 = 数据.sort_index()`
  - 如果日期是列：
    - `数据 = 数据.sort_values(by='出生日期')`
  - 讲师强调：使用 `truncate` 这类按日期截取的函数前，必须先排序；升序、降序都不要紧，只要排序即可。
- 结论：
  - 只要涉及日期查询、筛选，尽量把这三步写全。
  - 如果记不住，就每次都写“设索引、转日期、排序”三部曲。

## 十一、按年、月、日期区间直接筛选

- 当“出生日期”已经设置为日期索引后，可以直接用字符串进行部分索引筛选。
- 查询某一年：
  - `数据['1989']`
  - 表示筛选 1989 年的数据。
- 查询某年某月：
  - `数据['1983-10']`
  - 表示筛选 1983 年 10 月的数据。
- 查询年份区间：
  - `数据['1983':'1990']`
  - 表示筛选 1983 年到 1990 年的数据。
- 查询具体日期区间：
  - `数据['1983-01-01':'1990-01-01']`
  - 中间加冒号表示区间。
- 大数据建议：
  - 查询时加 `.head()`，例如 `数据['1989'].head()`。
  - `head()` 默认显示前 5 条。
  - 原因：大数据文件直接输出大量结果可能导致内存吃不消或机器卡死。
  - 讲师强调这是工作中的习惯：先 `head()` 看几条，再决定下一步。

## 十二、`truncate`：截取某日期之前或之后的数据

- 函数：
  - `DataFrame.truncate(before=None, after=None, axis=None, copy=True)`
- 作用：
  - 获取某个日期之前或之后的时间区间内的数据。
  - 是 `DataFrame` 的方法。
- 使用前注意：
  - 必须先将日期设置为索引，并完成日期转换。
  - 必须对索引进行排序，否则不能正常使用。
- 参数说明：
  - `before`：起始下界，保留该日期及之后的数据。
  - `after`：结束上界，保留该日期及之前的数据。
  - `axis`：指定轴。
  - `copy`：视频中表示暂时不用介绍。
  - `before` 和 `after` 不是必须同时使用，可单独使用。
- 示例：
  - 查 1980 年以后：
    - `数据.truncate(before='1980')`
  - 查 1990 年 12 月以前：
    - `数据.truncate(after='1990-12')`
  - 查 1990 年 2 月以后：
    - `数据.truncate(before='1990-02')`
  - 查 1984 年 1 月 1 号以前：
    - `数据.truncate(after='1984-01-01')`
  - 查 1984 年 1 月 1 号以后：
    - `数据.truncate(before='1984-01-01')`
- 结论：
  - 按日期截取时，`truncate` 很方便。
  - 记住：使用前先排序。

## 十三、`query` 中写日期范围 + 性别多条件

### 13.1 目标

- 目标：筛选 1980 年到 1990 年之间出生的男性。
- 视频中使用 `query` 的“语法糖”写法。

### 13.2 条件写法

- 先构造条件字符串：
  - `条件 = "@数据.出生日期.dt.year > 1980 and @数据.出生日期.dt.year < 1990 and 性别 == '男'"`
- 再执行：
  - `数据.query(条件)`
- 说明：
  - `@` 用于在 `query` 字符串中引用外部 Python 对象。
  - `数据` 是外部 `DataFrame` 变量名。
  - `数据.出生日期` 引用“出生日期”列。
  - `.dt` 是日期时间访问器。
  - `.dt.year` 返回日期对应的年份。
  - `dt.year` 可用于年份比较，如大于某年、小于某年。
- 视频中还说：
  - 附件里有时间日期相关函数说明，例如 `dt.year`。
  - 这里不需要额外导入模块，因为条件最终是字符串，`query` 会解析。

### 13.3 重要坑：使用 `query` 日期条件时不要将日期设为索引

- 视频中先按“日期三部曲”把出生日期设置成索引，然后执行 `query` 报错。
- 原因：
  - `query` 中写的是 `@数据.出生日期.dt.year`，它需要“出生日期”仍然作为列存在。
  - 如果把出生日期设置为索引，列就不在普通列中，`query` 条件无法按预期解析。
- 解决：
  - 使用 `query` 写日期条件时，索引应保持默认，或设置为“序号”。
  - 不要把出生日期设置为索引。
  - 此时数据排序也不是必须的。
- 视频演示结果：
  - 改回序号/默认索引后运行成功，筛选出 1980 年到 1990 年之间出生且性别为男的记录。

### 13.4 条件连接注意事项

- 日期型条件之间用 `and` 连接，例如：
  - `@数据.出生日期.dt.year > 1980 and @数据.出生日期.dt.year < 1990`
- 日期条件与字符型条件之间也要用 `and` 分隔：
  - `... and 性别 == '男'`
- 讲师提醒：
  - 不要把 `and` 放错位置。
  - 日期型和字符型类型不同，不能随意混写在一起导致比较类型错误。
  - 条件顺序要清楚：日期年份条件、`and`、性别条件。

## 十四、本节筛选方法总结

- 按行范围筛选：
  - `数据.loc[2:4]`
  - 需要用变量接收结果。
- 按列值条件筛选：
  - `条件 = 数据['性别'] == '男'`
  - `数据[条件]`
- 多条件筛选：
  - 普通布尔条件组合。
  - 更推荐 `query`。
- `query` 基本用法：
  - `条件 = "性别 == '男' and 总分 >= 150"`
  - `数据.query(条件)`
- `query` 支持：
  - `and`
  - `or`
  - `in`
- 文本开头/结尾：
  - `数据['姓名'].str.startswith('王')`
  - `数据['姓名'].str.endswith('松')`
- 文本包含：
  - `数据['地址'].str.contains('信阳市')`
- 正则筛选：
  - `数据['地址'].str.contains('[a-c]', case=False)`
- `case` 参数：
  - `case=True`：默认大小写敏感。
  - `case=False`：大小写不敏感。
- 日期筛选三部曲：
  - 设日期为索引。
  - 转日期格式 `pd.to_datetime`。
  - 日期排序。
- 按年/月/区间直接筛选：
  - `数据['1989']`
  - `数据['1983-10']`
  - `数据['1983':'1990']`
  - `数据['1983-01-01':'1990-01-01']`
- 按日期截取：
  - `数据.truncate(before=..., after=...)`
- `query` 日期范围：
  - `@数据.出生日期.dt.year > 1980`
  - `@数据.出生日期.dt.year < 1990`
  - `性别 == '男'`
- 大数据查询建议：
  - 加 `.head()` 只查看前几条，避免一次性输出过多导致机器卡死。

## 十五、讲师补充提醒

- 引号问题必须掌握：
  - 外层双引号，内层单引号。
  - 外层单引号，内层双引号。
- `query` 中的条件本质是字符串，所以可用 `and`、`or`、`in` 等。
- `loc` 后面用中括号；`query` 后面用小括号。
- 日期筛选时：
  - 直接按日期索引查询时，需要设置索引、转日期型。
  - 使用 `truncate` 时，还必须排序。
  - 使用 `query` 写日期条件时，不要设置日期索引，要保留“出生日期”列。
- 如果日期包含具体时间，可以在日期后加空格写时间，24 小时制，例如“9 点几分几秒”“16 点几分几秒”。
- 正则表达式建议系统学习，它在不同编程语言中通用。
- 多工作表读取只需 `sheet_name`，不必用 VBA 拆表；但实际工作更常见的是先做多表连接、合并、重塑，再筛选。
