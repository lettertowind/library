## 课程笔记：Matplotlib 填充与参考线绘制

本课围绕 Matplotlib 中在图中任意位置插入线、线段和填充区域展开，承接前面用 `axhline` 制作平均线的内容。核心函数包括 `plt.axhline`、`plt.axvline`、`plt.axhspan`、`plt.axvspan`，以及坐标轴范围设置 `plt.axis`。

## 1. 环境准备与导入

- 打开 Python 编辑器（视频中口述为“排查”，结合上下文应为 PyCharm 类编辑器）。
- 导入可视化库：
  - `import matplotlib.pyplot as plt`
- 画图后需要显示图像，视频中提到“把它打开”，对应使用：
  - `plt.show()`

## 2. 绘制横线：`plt.axhline`

- `plt.axhline` 用于绘制一条横向参考线。
- 前面课程中制作“平均线”时，就是先取得平均值，再让 `y` 等于该平均值，从而画出一条贯穿全图的横线。
- 基本用法：指定 `y` 轴位置。
  - `plt.axhline(y=0.2)`
- 运行效果：在 `y=0.2` 的位置绘制一条横线。
- 该线默认从头到尾贯穿整个绘图区域。

### 2.1 设置线宽

- 使用 `linewidth` 参数设置线宽。
- 视频中先设置为 30：
  - `plt.axhline(y=0.2, linewidth=30)`
- 讲师提到“少了一个 e”的拼写问题，说明参数名拼写错误会导致设置失败；正确参数为 `linewidth`。
- 线宽过粗后，可改小，例如改成 8 左右：
  - `plt.axhline(y=0.2, linewidth=8)`
- 运行后横线粗细正常。

### 2.2 设置颜色

- 可使用 `color` 或简写 `c` 设置线条颜色。
  - `plt.axhline(y=0.2, color='red')`
  - `plt.axhline(y=0.2, c='red')`
- 视频中改为红色，运行效果正常。

## 3. 绘制竖线：`plt.axvline`

- 竖线使用 `plt.axvline`，与 `axhline` 对应：
  - `axhline` 画横线；
  - `axvline` 画竖线。
- 画竖线时需要指定 `x` 轴位置。
  - `plt.axvline(x=0.4)`
- 运行效果：在 `x=0.4` 的位置绘制一条竖线。
- 结论：画竖线时，只要告诉函数 `x` 轴坐标即可。
- 竖线后续的设置方式与横线类似，例如线宽、颜色等；视频中说明后面设置不再重复操作。

## 4. 绘制线段

- 线段不是从坐标轴起点一直画到终点，而是在中间指定区间内显示。
- 视频中继续使用 `axhline` 的思路，通过指定起止范围来绘制横向线段。
- 示例目标：在 `y=0.5` 的位置画一条线，但只显示 `0.2` 到 `0.6` 这一段。
  - `y=0.5`：确定线段的纵向位置。
  - `xmin=0.2`：指定线段在 x 轴方向上的最小值。
  - `xmax=0.6`：指定线段在 x 轴方向上的最大值。
- 对应写法可表示为：
  - `plt.axhline(y=0.5, xmin=0.2, xmax=0.6)`
- 再设置颜色为绿色：
  - `plt.axhline(y=0.5, xmin=0.2, xmax=0.6, color='green')`
- 运行效果：只在 `0.2` 到 `0.6` 的区间内显示一条绿色横线，即线段。
- 关键点：`axhline` 除了 `y` 位置外，还可以通过 `xmin`、`xmax` 控制横向显示区间。

## 5. 水平区域填充：`plt.axhspan`

- 填充使用新的方法，不再是 `axhline`，而是 `axhspan`。
- 函数：
  - `plt.axhspan`
- 作用：在 y 轴指定范围内进行水平区域填充。
- 示例：
  - `plt.axhspan(1, 1.3)`
- 含义：在 y 轴上从 `1` 到 `1.3` 进行填充。
- 视频中解释：`axhspan` 中的 `h` 对应水平方向，因此填充范围是 y 轴上的 `1` 到 `1.3`。

### 5.1 设置填充颜色

- 使用 `facecolor` 参数设置填充颜色。
- 示例：
  - `plt.axhspan(1, 1.3, facecolor='yellow')`
- 视频中设置为黄色。
- 讲师经验：Python 中 `yellow` 的显示效果偏色，看起来“颜色不正”；即使调整透明度，也没有调成理想效果。
- 该问题作为实际使用中的颜色显示踩坑记录。

### 5.2 设置透明度

- 使用 `alpha` 参数设置透明度。
- 示例：
  - `plt.axhspan(1, 1.3, facecolor='yellow', alpha=0.5)`
- 视频中尝试将透明度设置为 `0.5`，但认为黄色显示仍不理想。
- 结论：`alpha=0.5` 可以控制填充透明度，但视频中未能解决黄色偏色问题。

## 6. 垂直区域填充：`plt.axvspan`

- 与 `axhspan` 对应，使用 `plt.axvspan` 进行垂直区域填充。
- 函数：
  - `plt.axvspan`
- 作用：在 x 轴指定范围内进行垂直区域填充。
- 示例：
  - `plt.axvspan(1, 1.3)`
- 含义：在 x 轴上从 `1` 到 `1.3` 进行填充。
- 设置填充颜色为蓝色：
  - `plt.axvspan(1, 1.3, facecolor='blue')`
- 运行效果：在 x 轴 `1` 到 `1.3` 的范围内进行蓝色填充。
- 对比记忆：
  - `axhspan`：填充 y 轴范围，对应水平带状区域；
  - `axvspan`：填充 x 轴范围，对应垂直带状区域。

## 7. 设置坐标轴范围：`plt.axis`

- 视频提醒不要忘记设置坐标轴范围。
- 使用函数：
  - `plt.axis`
- 统一设置 x 轴和 y 轴范围时，可以传入一个列表。
- 示例：
  - `plt.axis([-1, 2, -1, 2])`
- 含义：
  - x 轴范围为 `-1` 到 `2`；
  - y 轴范围为 `-1` 到 `2`。
- 设置后，再在 `1` 到 `1.3` 范围内进行填充时，填充区域可以正常显示。
- 结论：`plt.axis([xmin, xmax, ymin, ymax])` 可以统一控制坐标轴显示范围。

## 8. 本课函数与参数速查

- `plt.axhline(y=...)`：绘制横向参考线。
- `plt.axvline(x=...)`：绘制纵向参考线。
- `plt.axhline(y=..., xmin=..., xmax=...)`：绘制指定区间的横向线段。
- `plt.axhspan(ymin, ymax)`：在 y 轴指定范围内填充水平区域。
- `plt.axvspan(xmin, xmax)`：在 x 轴指定范围内填充垂直区域。
- `linewidth`：设置线条宽度。
- `color` 或 `c`：设置线条颜色。
- `facecolor`：设置填充区域颜色。
- `alpha`：设置透明度。
- `plt.axis([xmin, xmax, ymin, ymax])`：统一设置坐标轴范围。

## 9. 关键结论与踩坑记录

- `axhline` 最初用于制作平均线：取得平均值后，将该值传给 `y`，即可画一条贯穿全图的平均线。
- 横线用 `axhline`，竖线用 `axvline`，二者命名中的 `h` 和 `v` 分别对应 horizontal 和 vertical。
- 线段可以通过在 `axhline` 中增加 `xmin` 和 `xmax` 来控制显示区间。
- `axhspan` 填充的是 y 轴范围，`axvspan` 填充的是 x 轴范围。
- 设置线宽时参数名是 `linewidth`，注意拼写完整，避免漏写字母。
- 设置颜色时 `color` 和 `c` 都可以使用。
- 填充颜色使用 `facecolor`，透明度使用 `alpha`。
- 视频中 `yellow` 的显示效果偏色，调整 `alpha` 也未能调至理想效果，这是实际绘图时的颜色显示现象。
- 使用 `plt.axis([-1, 2, -1, 2])` 可以统一设置 x 轴和 y 轴范围，便于配合填充区域观察效果。
