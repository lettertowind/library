# Numpy 数组计算学习笔记

## 1. 课程定位与内容回顾

- 本节主题：NumPy 数组计算。
- 回顾多维数组概念：三维数组可以理解为“分成几块”，每一块是一个二维数组；更高维数组也可按类似方式理解。
- 当前内容属于 NumPy 中较基础的部分，后续会继续讲解更复杂的数组操作。

## 2. 使用 `reshape` 改变数组形状

### 2.1 `np.arange` 创建一维数组

- `np.arange(10)` 会创建一维数组，元素为 `0` 到 `9`。
- `arange` 的区间规则是左闭右开：包含起始值，不包含结束值。
- 示例中打印数组 `a`，可以看到元素为 `0~9`。

### 2.2 使用 `reshape` 变形为二维数组

- 通过 `.reshape()` 可以把一维数组变形为二维数组或三维数组。
- 示例：  
  `a = np.arange(10).reshape(2, 5)`  
  得到形状为 `2` 行 `5` 列的二维数组。

### 2.3 `reshape` 的严格要求：元素总数必须一致

- `reshape` 前后元素总数必须相等，即各维度长度乘积必须等于原数组元素个数。
- 示例：
  - `np.arange(10).reshape(2, 5)` 合法，因为  
    \[
    2 \times 5 = 10
    \]
    原数组正好有 `10` 个元素。
  - `np.arange(10).reshape(2, 4)` 会报错，因为  
    \[
    2 \times 4 = 8 \ne 10
    \]
  - 如果写成 `20` 或其他与原元素个数不一致的维度，也会报错。
- `reshape` 的本质是“在不改变元素值的情况下改变数组形状”，不是重新生成随机数或重新提供数据。
- 对已有数组做 `reshape` 时，必须保证形状乘积等于原元素总数。

补充说明：对于 `np.random` 这类随机数生成函数，括号中的参数通常表示生成数组的形状，函数会直接按该形状生成随机数；这与对已有数组进行 `reshape` 的要求不是同一个操作。

## 3. 数组与标量进行计算

- 数组加上一个数字时，相当于对数组中的每一个元素都加上这个数字。
- 示例：`a + 1` 等价于构造一个与 `a` 形状相同、所有元素都是 `1` 的数组，然后与 `a` 逐元素相加。
- 同理：
  - `a + 2`：所有元素都加 `2`。
  - `a - 1`：所有元素都减 `1`。
  - `a * 3`：所有元素都乘 `3`。
- 核心规律：标量与数组运算时，标量会“广播”到数组的每一个元素上。

## 4. 形状相同的数组之间计算

- 如果两个数组形状完全相同，则可以直接进行加、减、乘、除。
- 运算规则：对应位置的元素进行对应运算。
- 示例：
  - `a = np.arange(10).reshape(2, 5)`
  - `b = np.random.random((2, 5))` 或类似方式生成形状为 `(2, 5)` 的数组
  - `a + b` 会将 `a` 和 `b` 中对应位置的元素相加。
- 对应关系包括：
  - 第一行第一列与第一行第一列计算；
  - 第一行第二列与第一行第二列计算；
  - 第二行第一列与第二行第一列计算，依此类推。
- 标量运算可以看作“形状相同数组运算”的特例：标量相当于一个所有元素都相同的数组。

## 5. 形状不同时的数组计算：广播机制

### 5.1 二维数组与一维数组计算

- 假设二维数组 `a` 的形状为 `(2, 5)`，一维数组 `b` 的形状为 `(5,)`。
- 此时可以进行加减乘除，因为一维数组长度 `5` 与二维数组的列数 `5` 相同。
- 计算时，一维数组 `b` 会广播到二维数组的每一行：
  - 先与第一行的每个元素逐元素计算；
  - 再与第二行的每个元素逐元素计算。
- 可以理解为：把一维数组复制成多行，形成一个与二维数组形状相同的二维数组，然后逐元素计算。
- 如果一维数组需要按“列方向”广播，例如长度等于行数，则需要将其显式转换为列向量，例如使用 `b.reshape(-1, 1)`，使其形状变为 `(m, 1)`，再与形状 `(m, n)` 的二维数组计算。
- 实际计算由 NumPy 自动完成，学习者需要理解广播原理。

### 5.2 广播原则

广播兼容的基本判断规则：

- 从数组的“后缘维度”开始比较，也就是从最右边的维度开始向左比较。
- 两个数组的对应维度满足以下条件之一时，可以广播：
  - 维度长度相等；
  - 其中一个维度长度为 `1`，可以扩展为另一方的长度；
  - 缺失的维度可以视为长度为 `1`。
- 如果两个维度既不相等，也没有一方为 `1`，则不兼容，不能进行数组计算，通常会报错。

简单记忆方法：

- 先看最后一个维度，也就是列数或后缘维度。
- 最后一维相同，通常可以计算。
- 如果最后一维不同，但其中一方为 `1`，也可能可以广播。
- 如果最后一维不同且都不为 `1`，则不能计算。

### 5.3 形状判断示例

| 数组 A 形状 | 数组 B 形状 | 是否可计算 | 原因 |
|---|---|---|---|
| `(4, 3)` | `(3,)` | 可以 | 后缘维度都是 `3` |
| `(4, 3)` | `(4, 1)` | 可以 | 最后一维 `3` 与 `1`，其中一方为 `1`；第一维 `4` 与 `4` 相同 |
| `(2, 3)` | `(2, 4)` | 不可以 | 后缘维度 `3` 与 `4` 不相等，且都不为 `1` |
| `(4, 3)` | `(4, 3)` | 可以 | 形状完全相同 |

关键结论：

- 相同形状的数组一定可以进行数组计算。
- 形状不同时，不能只看前面的维度是否相同，必须先检查后缘维度。
- 例如 `(2, 3)` 与 `(2, 4)`，虽然第一维都是 `2`，但最后一维 `3` 和 `4` 不兼容，因此不能计算。
- 如果后缘维度中有一方为 `1`，则可以扩展到另一方的长度；如果后缘维度更大且不是 `1`，不能强行计算。

## 6. 三维数组的广播计算

- 三维数组可以理解为多个二维数组堆叠而成。
- 例如形状 `(3, 4, 2)` 表示有 `3` 块，每块是 `4` 行 `2` 列的二维数组。
- 如果另一个二维数组形状为 `(4, 2)`，它可以与三维数组的每一块分别计算：
  - 先与第一块逐元素计算；
  - 再与第二块逐元素计算；
  - 再与第三块逐元素计算。
- 也就是说，二维数组会广播到三维数组的每一个二维切片上。

### 6.1 三维数组广播判断题

- 三块二行三列，形状 `(3, 2, 3)`，与二行三列，形状 `(2, 3)`：  
  可以计算。后缘维度 `(2, 3)` 完全匹配。

- 三块二行三列，形状 `(3, 2, 3)`，与一维数组三个元素，形状 `(3,)`：  
  可以计算。最后一维长度 `3` 匹配。

- 三块两行两列，形状 `(3, 2, 2)`，与两行一列，形状 `(2, 1)`：  
  可以计算。按右对齐比较：
  - 最后一维：`2` 与 `1`，其中一方为 `1`，兼容；
  - 中间维度：`2` 与 `2`，相等；
  - 第一维：`3` 与缺失维度，缺失维度视为 `1`，可扩展。

- 三块两行两列，形状 `(3, 2, 2)`，与两行四列，形状 `(2, 4)`：  
  不可以计算。最后一维 `2` 与 `4` 不相等，且没有一方为 `1`，超出广播兼容范围；即使前面部分维度相同，也不能计算。

### 6.2 示例演示

- 创建形状为 `(3, 2, 2)` 的三维数组，以及形状为 `(2, 1)` 的二维随机数组，先打印查看形状和数值，再进行运算，验证可以广播。
- 创建形状为 `(2, 3)` 与 `(2, 4)` 的数组进行运算，用于验证最后一维不兼容时不能计算。
- 广播扩展由计算机自动完成，不需要手动复制数据；理解“从右往左比较维度”的规则即可。

## 7. 本节重点与易错点总结

- `np.arange(10)` 生成一维数组，元素为 `0~9`，不包含 `10`。
- `reshape` 只改变形状，不改变元素值；各维度乘积必须等于原数组元素总数。
- 数组与标量运算时，标量作用于每一个元素。
- 形状相同的数组之间，按对应位置逐元素计算。
- 形状不同的数组之间，需要满足广播规则：
  - 从后缘维度开始比较；
  - 维度相等，或其中一方为 `1`，才兼容；
  - 否则不能计算。
- 二维数组与一维数组计算时，一维数组长度通常对应二维数组的列数；如需按列广播，可使用 `reshape(-1, 1)` 转为列向量。
- 三维数组与二维数组计算时，二维数组会广播到三维数组的每一块。
- 易错点：不能只看前面的维度是否相同，必须优先检查后缘维度是否兼容。
- 易错点：后缘维度如 `3` 与 `4` 这样既不相等、也不包含 `1` 的情况，不能广播。
