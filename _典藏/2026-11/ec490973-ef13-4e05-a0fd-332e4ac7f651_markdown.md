## 2. 建立 MySQL 连接对象

### 2.1 连接对象是什么

- 连接对象可以理解为：登录 MySQL 数据库所需要的一组连接信息。
- 使用 `pymysql` 建立连接对象，函数为 `pymysql.connect()`。
- 转录中出现的 `py mysql.content` 属于识别偏差，实际应使用 `pymysql.connect()`。

### 2.2 连接参数逐项说明

使用 `pymysql.connect()` 时需要填写以下关键参数：

- `host`：主机名称。
  - 要填写自己的数据库主机名称。
  - 讲师本机示例为 `localhost`。
- `user`：用户名。
  - 讲师示例为 `root`。
- `password`：密码。
  - 讲师本机示例为 `1234`。
  - 该密码是讲师本机数据库的演示密码，实际使用时应替换为自己的密码。
- `database`：数据库名称。
  - 讲师示例数据库名为 `test`。
  - 转录中提到 `test` 是默认的数据库名称。
- `charset`：编码。
  - MySQL 中编码参数应写 `utf8`。
  - 注意：不是写成 `utf-8`，MySQL 中通常以 `utf8` 这种形式表示。

### 2.3 连接对象示例代码

```python
import pandas as pd
import pymysql

conn = pymysql.connect(
    host='localhost',
    user='root',
    password='1234',
    database='test',
    charset='utf8'
)
```

说明：

- `import pandas as pd`：导入 `pandas` 库，并简写为 `pd`。
- `import pymysql`：导入 `pymysql` 模块，用于连接 MySQL 数据库。
- `pymysql.connect(...)`：创建数据库连接对象。
- `host='localhost'`：连接本机数据库。
- `user='root'`：使用 `root` 用户登录。
- `password='1234'`：使用讲师演示密码登录，实际应替换。
- `database='test'`：连接名为 `test` 的数据库。
- `charset='utf8'`：设置字符编码为 `utf8`。

讲师特别说明：

- 因为数据库建立在讲师本机上，所以使用 `localhost`，别人无法直接登录。
- 连接参数必须根据自己的数据库环境填写，不能直接照搬讲师的用户名、密码和数据库名。

## 3. 使用 pandas 读取 MySQL 数据

### 3.1 导入库

读取 MySQL 数据前需要导入两个库：

```python
import pandas as pd
import pymysql
```

- `pandas` 用于数据读取和数据分析。
- `pymysql` 用于建立 Python 与 MySQL 之间的连接。

### 3.2 读取函数对比

- 读取 CSV 文件使用：`pd.read_csv()`。
- 读取 SQL 数据库使用：`pd.read_sql()`。
- 转录中出现的 `read_circle` 等属于识别偏差，实际函数为 `pd.read_sql()`。

### 3.3 `pd.read_sql()` 的两个关键参数

`pd.read_sql()` 示例：

```python
读取文件 = pd.read_sql(sql, con=conn)
```

参数说明：

- 第一个参数：SQL 语句。
  - 需要填写要执行的查询语句。
  - 例如查询某张表的数据。
- 第二个参数：关键字参数 `con`。
  - `con` 表示连接对象。
  - 这里传入前面创建好的 `conn`。
  - 连接对象中已经包含了主机、用户名、密码、数据库等登录信息。
  - 因此传入连接对象，就相当于完成了数据库登录连接。

### 3.4 SQL 语句示例与说明

讲师强调：

- 在大数据分析中，SQL 查询语句是必须要学的。
- 如果没有学过 SQL 基础，应先学习 SQL 基础篇。
- 读取数据时需要写 SQL 查询语句。

示例 SQL 结构：

```sql
select * from 表名
```

说明：

- `select *`：查询表中的数据。
- `from 表名`：指定从哪张表中读取。
- 讲师演示中查询了某张表中的数据，示例数据涉及“杨过、小龙女”等内容。
- 转录中出现的 `circle`、“一般”等词存在识别偏差，实际应以自己的数据库表名为准，替换 `表名`。

### 3.5 完整读取示例

```python
import pandas as pd
import pymysql

conn = pymysql.connect(
    host='localhost',
    user='root',
    password='1234',
    database='test',
    charset='utf8'
)

sql = "select * from 表名"

读取文件 = pd.read_sql(sql, con=conn)

print(读取文件)
```

说明：

- `sql = "select * from 表名"`：定义 SQL 查询语句。
- `读取文件 = pd.read_sql(sql, con=conn)`：使用 `pandas` 读取 SQL 查询结果，并赋值给变量 `读取文件`。
- `print(读取文件)`：打印读取结果。
- 讲师说明运行后读取成功，运行过程可能稍微慢一点。
- 讲师还提到，`read_sql()` 也可以设置索引等参数，用法与上一节读取文件的知识相差不多。

## 4. 关键对比与易混点

- `pd.read_csv()`：用于读取 CSV 文件。
- `pd.read_sql()`：用于读取 SQL 数据库查询结果。
- `pymysql.connect()`：用于建立 MySQL 连接对象。
- `con=conn`：`read_sql()` 中传入连接对象的关键字参数。
- `charset='utf8'`：MySQL 中应写 `utf8`，不要写成 `utf-8`。
- 连接对象不是数据本身，而是包含登录数据库所需信息的连接通道。
- SQL 语句是第一个参数，连接对象通过 `con` 参数传入。

## 5. 踩坑与结论

- 如果 `pymysql` 导入失败或无法使用，先检查是否安装 `pymysql`。
- 安装和导入 `pymysql` 的方法在 Python 基础课程第 18 节课中讲解。
- MySQL 连接参数必须使用自己的主机名、用户名、密码和数据库名。
- 讲师示例中的 `host='localhost'`、`user='root'`、`password='1234'`、`database='test'` 仅用于本机演示。
- MySQL 编码参数写 `charset='utf8'`，不是 `utf-8`。
- 使用 `pandas` 读取 MySQL 的核心步骤为：
  - 导入 `pandas`。
  - 导入 `pymysql`。
  - 使用 `pymysql.connect()` 建立连接对象。
  - 使用 `pd.read_sql(sql, con=conn)` 执行 SQL 查询并读取数据。
- SQL 查询语句是数据分析中的必备基础，实际读取时需要根据数据库中的表名和字段编写 SQL。

## 6. 本课小结

本节课程完成了从 Python 连接 MySQL 到使用 pandas 读取 MySQL 数据的完整流程：

- 先安装并导入 `pymysql`。
- 使用 `pymysql.connect()` 创建连接对象。
- 连接对象中配置 `host`、`user`、`password`、`database`、`charset` 等参数。
- 使用 `pd.read_sql(sql, con=conn)` 读取 SQL 查询结果。
- 第一个参数是 SQL 语句，第二个参数 `con` 是数据库连接对象。
- 读取结果可以赋值给变量并打印查看。
- 其他索引等参数可与上一节读取文件的知识结合使用。
