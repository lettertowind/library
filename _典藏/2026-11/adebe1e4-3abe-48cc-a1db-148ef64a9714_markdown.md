# 孙兴华中文讲 Python 数据分析：Pandas 数据查询（loc）笔记

## 1. 本节主题：查询数据与筛选数据

- 本节学习 **查询数据** 和 **筛选数据**。
- 讲师认为“查询”和“筛选”在结果上很相似：例如从一张表中把“孙兴华”查出来或筛出来，结果差别不大；但两者操作方法不同。
- 下节课专门讲 **筛选**，本节讲 **查询**，两者共用一个课件。
- 查询更偏向精确、小范围地取数据；筛选更偏向大范围、条件式地取数据。
- 示例：查某几个日期、某几个字段，属于查询；查 1983 年到 1989 年这种大的日期区间，更接近筛选。
- 复杂条件、更多“如果我想怎样”的情况，后面放到筛选里讲。

## 2. 导入模块与读取 Excel 数据

- 首先导入 Pandas 模块：

```python
import pandas as pd
```

- 讲师个人习惯：先把文件路径写好，再传给 `read_csv` 或 `read_excel`。
- 也可以不单独定义路径，直接把路径写到 `read_csv` 或 `read_excel` 中。
- 示例文件位于 `C` 盘 `pandas` 目录下，本节读取的是“筛选”文件。
- 读取 Excel 的基本写法：

```python
路径 = r"C:\pandas\筛选文件.xlsx"   # 路径示意，实际按课件文件
数据 = pd.read_excel(路径)
print(数据)
```

- 读取后可以看到数据列包括：
  - 序号
  - 姓名
  - 性别
  - 出生日期
  - 语文
  - 数学
  - 英语
  - 总分
  - 地址
- 后续几节课会陆续使用这些列的数据。

## 3. 日期查询前必须先设置日期索引

- 关键结论：**如果数据查询涉及日期查询，一定要把日期设置为索引再进行查询**。
- 这是 Pandas 中进行日期查询最方便的方法。
- 转录中讲师口语说“index call”，对应 Pandas 中设置索引的相关参数/操作，例如 `index_col`；目标是把 `出生日期` 指定为索引。
- 设置后，数据的索引会从默认索引变为 `出生日期`。
- 示例思路：

```python
数据 = pd.read_excel(路径, index_col="出生日期")
```

或先读取数据，再对已读取的数据设置索引。课程重点是：查询日期前，先让 `出生日期` 成为索引。

- `loc` 的基本参数有两个：
  - 第一个参数：**行标签**
  - 第二个参数：**列标签**
- 通俗理解：
  - 行标签可理解为“行号/索引号”
  - 列标签可理解为“字段名/列名”
- `loc` 的语法形式：

```python
数据.loc[行标签, 列标签]
```

## 4. 单条件查询：按日期查某一科成绩

- 需求：查询 `1983-10-27` 这一天的语文成绩。
- 因为已经把 `出生日期` 设置为索引，所以可以直接把日期字符串作为行标签。
- 示例代码：

```python
数据.loc["1983-10-27", "语文"]
```

- 运行结果为 `61` 分。
- 说明：
  - 第一个参数 `"1983-10-27"` 是行标签，即索引中的日期。
  - 第二个参数 `"语文"` 是列标签，即字段名。
- 易错点：日期查询前没有把日期设置为索引，查询会不方便或不符合本课讲法。
- 术语对应：
  - 高大上的说法：行标签、列标签。
  - 通俗说法：行号、字段名。

## 5. 多列查询：用列表选择多个字段

- 需求：查询 `1983-10-27` 这一天的语文、英语、数学三科成绩。
- 在 Pandas 中，多列用列表表示：

```python
数据.loc["1983-10-27", ["语文", "英语", "数学"]]
```

- 列的顺序可以由自己决定，例如：
  - `["语文", "英语", "数学"]`
  - `["数学", "语文", "英语"]`
- 多列查询的关键点：列标签位置传入一个列表。

## 6. 多日期查询：行标签也可以用列表

- 如果一次想查多个日期，可以把多个日期放进列表中，用逗号隔开：

```python
数据.loc[["1983-10-27", "1983-12-06"], ["语文", "英语", "数学"]]
```

- 示例说明：多个日期写在行标签位置的列表里，多个列写在列标签位置的列表里。
- 查询几个明确日期属于“查询”；如果要查一个很大的日期范围，更像“筛选”。

## 7. 日期区间查询：用英文冒号表示范围

- `loc` 中可以用英文冒号表示范围。
- 需求：查询 `1983-10-27` 到 `1990-12-31` 之间、表中存在的日期，并取语文、数学、英语成绩。
- 示例代码：

```python
数据.loc["1983-10-27":"1990-12-31", ["语文", "数学", "英语"]]
```

- 语法含义：
  - `"开始日期":"结束日期"` 表示日期区间。
  - 中间必须使用 **英文冒号** `:`。
  - 运行后会把该区间内、表中存在的所有日期对应行的语文、数学、英语取出。
- 重要踩坑提醒：
  - 如果照着视频敲代码报错，要检查标点符号。
  - 英文括号、英文引号、英文冒号等必须是英文半角符号。
  - 有时输入法切换成中文符号就会报错。

## 8. 列区间查询：按原表列顺序选择连续列

- 如果字段很多，也可以按列的范围查询，例如从“语文”到“英语”。
- 示例代码：

```python
数据.loc["1983-10-27":"1990-12-31", "语文":"英语"]
```

- 该写法表示从“语文”列到“英语”列，包含起止列。
- 按示例原表列顺序，`语文:"英语"` 会包含：
  - 语文
  - 数学
  - 英语
- 如果只想从“语文”到“数学”，则写成：

```python
数据.loc["1983-10-27":"1990-12-31", "语文":"数学"]
```

- 结果包含：
  - 语文
  - 数学
- 关键结论：
  - 列区间按原表列的顺序排。
  - 原表中列的顺序怎么写，列区间就按这个顺序取。
  - 列列表查询可以自定义顺序；列区间查询按原表顺序。

## 9. 条件表达式查询：使用 `&` 组合多个条件

- 需求示例：查询语文大于等于 `60` 分，且英语小于等于 `60` 分的数据。
- 讲师口述语境是“语文及格了，英语不及格”，示例代码中使用的是 `<= 60`，因此结果可能包含 60 分。
- `loc` 后面必须跟 **中括号** `[]`，不要跟小括号。
- 多个条件之间要分别用小括号括起来，中间用 `&` 表示“并且”。

示例代码：

```python
数据.loc[(数据["语文"] >= 60) & (数据["英语"] <= 60)]
```

- 说明：
  - `数据["语文"] >= 60`：语文成绩大于等于 60。
  - `数据["英语"] <= 60`：英语成绩小于等于 60。
  - 两个条件分别用小括号扩展。
  - 中间用 `&` 连接，表示两个条件都满足。
  - `&` 的输入方式：按住 `Shift`，再按数字键 `7`。
- 易混点：
  - 在 Pandas/Python 的条件筛选中，讲师使用 `&` 表示逻辑与。
  - 不要写成口语里的 `and` 单词。
  - 判断“等于”要用两个等号 `==`，赋值才用一个等号 `=`。
- 完整 `loc` 写法应加逗号和冒号：

```python
数据.loc[(数据["语文"] >= 60) & (数据["英语"] <= 60), :]
```

- 其中：
  - 逗号前是行条件。
  - 逗号后的 `:` 表示所有列。
- 讲师个人习惯省略 `,:`，直接写：

```python
数据.loc[(数据["语文"] >= 60) & (数据["英语"] <= 60)]
```

- 两种写法运行结果相同。
- 但讲师明确说明：**正确的完整写法应该加上 `,:`**，省略只是个人习惯。
- 该写法类比 MySQL 中条件查询的书写方式。
- 运行结果会显示语文满足条件、英语也满足条件的行；示例中英语使用 `<= 60`，所以 60 分也会被包含。

## 10. 条件赋值：用 `loc` 新建“称呼”列

- 讲师打开“条件判断”文件，路径同样在 `C` 盘 `pandas` 目录下。
- 大数据通常不能直接双击打开，先读取查看数据结构，可用 `head()` 打印前五条：

```python
数据 = pd.read_excel(路径)
数据.head()
```

- 查看数据后可见：
  - 默认索引为 `0,1,2...`
  - 序号列为 `1,2,3...`
  - 还有姓名、性别、语文、数学、英语等列。
  - 字体显示可能有错位，但不影响数据。
- 先把“序号”设置为索引：

```python
数据 = 数据.set_index("序号")
```

- 设置后，默认索引被序号替换。
- 需求：根据性别新增“称呼”列：
  - 性别为“男”：称呼为“先生”
  - 性别为“女”：称呼为“女士”
- 该案例类似王佩丰老师在 VBA/Excel 中常用的“男性返回先生、女性返回女士”的案例。
- 使用 `loc` 条件赋值，不需要写 `if` 条件判断。

示例代码：

```python
数据.loc[数据["性别"] == "男", "称呼"] = "先生"
数据.loc[数据["性别"] == "女", "称呼"] = "女士"
```

- 代码解释：
  - `数据["性别"] == "男"`：判断性别列是否等于“男”，注意用 `==`。
  - 第一个参数位置是行标签/行条件，即定位到性别为男的行。
  - 第二个参数 `"称呼"` 是列标签；因为原表中没有“称呼”列，所以会新建这一列。
  - `= "先生"` 是赋值。
  - 同理，性别为女的行赋值为“女士”。
- 运行后生成“称呼”列，显示“先生”“女士”。
- 关键理解：
  - `loc` 左边是行上的定位条件。
  - 右边是列名。
  - 如果列名不存在，`loc` 赋值会直接创建新列。
  - 判断相等用 `==`；赋值用 `=`。
  - 字符串“男”“女”“先生”“女士”都要加引号。

## 11. 本节关键结论与易错点汇总

- 查询涉及日期时，先设置日期索引，再进行 `loc` 查询。
- `loc` 接收两个核心参数：`loc[行标签, 列标签]`。
- 行标签可理解为索引号/行条件，列标签可理解为字段名。
- `loc` 后面必须使用中括号 `[]`，不要用小括号。
- 单条件查询：

```python
数据.loc["1983-10-27", "语文"]
```

- 多列查询用列表：

```python
数据.loc["1983-10-27", ["语文", "英语", "数学"]]
```

- 多日期查询也把日期放进列表：

```python
数据.loc[["1983-10-27", "1983-12-06"], ["语文", "英语", "数学"]]
```

- 日期区间用英文冒号：

```python
数据.loc["1983-10-27":"1990-12-31", ["语文", "数学", "英语"]]
```

- 列区间也用英文冒号，并按原表列顺序：

```python
数据.loc["1983-10-27":"1990-12-31", "语文":"英语"]
```

- 多条件查询要用小括号包住每个条件，并用 `&` 连接：

```python
数据.loc[(数据["语文"] >= 60) & (数据["英语"] <= 60), :]
```

- 完整 `loc` 条件查询应带 `,:`；省略列选择是讲师个人习惯，但要知道完整写法。
- 如果代码报错，优先检查标点符号是否为英文半角，尤其是冒号、括号、引号。
- 条件赋值新建列：

```python
数据.loc[数据["性别"] == "男", "称呼"] = "先生"
数据.loc[数据["性别"] == "女", "称呼"] = "女士"
```

- `loc` 条件赋值可直接根据条件给新列赋值，不需要写 `if`。
- 查询偏精确、小范围；筛选偏范围、复杂条件。更多复杂查询放到下节课“筛选”中讲。
