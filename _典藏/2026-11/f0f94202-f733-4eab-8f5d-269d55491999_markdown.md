## 4. 读取数据与索引设置

### 4.1 先读取数据并打印

- 使用 Pandas 读取 Excel 数据，例如：
  - `df = pd.read_excel(...)`
- 讲师先不设置索引，直接打印数据检查：
  - `print(df)`
- 可以正常打印出数据。

### 4.2 初始不设置索引时的问题

- 如果直接使用原始索引，`a01` 的分数索引可能是 `0～4`。
- 但 `a02` 的分数索引可能不是从 `0` 开始，例如从 `5` 开始。
- 这时如果统一写 `a02[0]`，取到的不是 `a02` 的第一个分数，而是原始 DataFrame 的第 0 行数据或错误位置。
- 讲师强调：不能手工去看每个对象的索引在哪里，容易出错。

### 4.3 读取时设置 `index_col`

- 解决方案：读取 Excel 时设置索引为姓名列：
  - `pd.read_excel(..., index_col='姓名')`
- 设置后，每个姓名筛选出来的数据索引从 `0` 开始。
- 这样 `a01[0]`、`a02[0]` 都表示对应对象的第一项分数。
- 结论：为了让首尾闭合时统一取第一个值，建议读取数据时把姓名设为索引。

## 5. 使用 `query` 筛选数据

### 5.1 条件写法

- 使用 Pandas 的 `query()` 筛选姓名。
- 条件一：
  - `条件一 = "姓名 == 'a01'"`
- 条件二：
  - `条件二 = "姓名 == 'a02'"`
- 引号使用技巧：外层用双引号，内层姓名用单引号，避免引号冲突。
- 注意：
  - `==` 表示等于。
  - `=` 表示赋值。
  - 不要混淆。

### 5.2 测试筛选结果

- 使用：
  - `print(df.query(条件一))`
- 讲师演示运行后得到 `a01` 的数据，分数为 `75` 到 `55` 范围，结果正确。
- 条件二同理：
  - `print(df.query(条件二))`

### 5.3 提取分数列表

- 先筛选姓名，再取分数列：
  - `a01 = df.query(条件一)['分数']`
- 运行后得到 `a01` 的分数列表。
- 同理：
  - `a02 = df.query(条件二)['分数']`
- 讲师强调：雷达图中各对象的科目必须相同，所以科目可以取 `a01` 或 `a02` 的任意一个。

## 6. 首尾闭合：使用 `np.concatenate`

### 6.1 为什么需要首尾闭合

- 雷达图最后一条线需要回到第一个数据点。
- 因此分数列表末尾要再拼接第一个分数。
- 例如 `a01` 原分数：
  - `[75, 40, 79, 91, 55]`
- 拼接后：
  - `[75, 40, 79, 91, 55, 75]`

### 6.2 拼接函数

- 使用 NumPy 的连接函数：
  - `np.concatenate(...)`
- 示例写法：
  - `a01 = np.concatenate((a01, [a01[0]]))`
- 参数含义：
  - 第一个参数是一个元组/序列，里面放待连接的对象。
  - `a01` 是原分数列表。
  - `[a01[0]]` 是把第一个分数包装成列表，便于和原列表连接。
- 讲师演示时少写括号导致连接失败，补上括号后成功。
- 结果：列表末尾多了一个 `75`。
- 讲师补充：也可以用 Python 列表的切片、列表连接方式完成；这里用 `np.concatenate` 是为了多学 Numpy 知识。

## 7. 提取并闭合科目列表

- 科目取任意一个人的即可：
  - `科目 = df.query(条件一)['科目']`
- 为闭合雷达图，科目也需要首尾重复：
  - `科目 = np.concatenate((科目, [科目[0]]))`
- 运行输出示例：
  - 数学、语文、英语、物理、化学、数学。
- 说明科目顺序与分数顺序必须一一对应。
- 科目列表长度与分数列表长度保持一致，才能正确绘制雷达图。

## 8. 生成雷达图角度

### 8.1 使用 `np.linspace`

- 使用：
  - `angles = np.linspace(0, 2 * np.pi, len(科目), endpoint=False)`
- 参数说明：
  - 开始值：`0` 度。
  - 结束值：`2 * np.pi`，即 `360°`。
  - 数量：`len(科目)`，即数据点个数。
  - `endpoint=False`：不包括结束值，避免首尾角度重复。
- 数学关系：
  - `np.pi = 180°`
  - `2 * np.pi = 360°`
- 作用：为每个科目生成一个极角。

### 8.2 角度首尾闭合

- 生成的角度从 `0` 开始，但末尾还没有回到 `0`。
- 需要再拼接第一个角度：
  - `angles = np.concatenate((angles, [angles[0]]))`
- 结果：角度从 `0` 开始，最后也回到 `0`，形成完整一圈。
- 讲师强调：如果没指定数量，`np.linspace` 会生成很多值；加入 `len(科目)` 后，才只生成与数据点对应的角度。
- 角度数组长度也要与闭合后的分数、科目长度一致。

### 9.2 设置样式

- 设置后极坐标图背景变为中性灰风格。

## 10. 绘制第一个对象的折线

### 10.1 使用 `plot` 绘制雷达图折线

- 使用折线图方式在极坐标上绘制数据点：

- 参数说明：

- 运行后可以看到雷达图折线已经出现。

### 10.2 设置标记点

### 10.3 设置线宽

### 10.4 设置线条透明度

- 作用：让线条和填充更柔和。

### 10.5 设置标签

- 使用：

## 14. 设置科目标签：`thetagrids`

### 14.1 角度转度数

- 角度是弧度值，标签网格需要度数。
- 使用：
  - `np.degrees(angles)`
- 等价公式：
  - \[
  \text{degrees} = \text{angles} \times \frac{180}{\pi}
  \]
- 视频中写法类似：
  - `角度 * 180 / np.pi`

### 14.2 设置标签文字

- 使用：
  - `ax.set_thetagrids(np.degrees(angles), 科目)`
- 或：
  - `plt.thetagrids(np.degrees(angles), 科目)`
- 参数说明：
  - 第一个参数：角度转成度数。
  - 第二个参数：每个角度对应的科目名称。
- 运行后雷达图外圈显示数学、语文、英语、物理、化学等科目标签。
- 讲师说明：如果不想绕公式，可以直接写 `np.degrees(angles)` 和科目列表。

## 15. 设置 y 轴范围

  - `ax.set_ylim(0, 100)`
- 或使用：
  - `plt.ylim(0, 100)`
- 设置后雷达图刻度范围从 `0` 到 `100`，图形比例正确。
- 运行后图形达到完整雷达图效果。

## 17. 关键坑点与结论

- `==` 是判断等于，`=` 是赋值，Pandas 条件筛选不要写错。
- `np.concatenate` 需要把待连接对象放在元组/列表中；少写括号会报错或连接失败。
- 不设置姓名索引时，`a02` 的索引可能从 `5` 开始，`a02[0]` 不能取到第一个分数；读取时设置 `index_col='姓名'` 可解决。
- 角度生成时必须加入 `len(科目)`，否则会生成过多角度。
- 角度要手动拼接首角度，分数和科目也要拼接首项，三者长度一致才能闭合。
- `marker='o'` 是标记点，`fill` 的第三个位置参数是颜色，不是标记。
- `linewidth=20` 太粗，改成 `2` 较合适。
- 雷达图数据对象不要太多，1～2 个最清晰，最多不超过 3 个。
- 科目必须一致，科目列表取任意一个对象即可。
- `ggplot` 样式适合雷达图，背景为中性灰，视觉更协调。
- 图例需要调用 `plt.legend()` 才会显示；`label` 只负责提供文字。
- 最后可用 `fontsize`、颜色、加粗等继续修饰标签文字。
