# NumPy 数组的轴和转置——学习笔记

## 1. 轴（axis）的基本概念

- 轴（axis）是 NumPy 基础部分中非常重要的内容，理解轴的关键是看数组的维度。
- 轴的数量由数组维度决定：数组有几维，就有几个轴。
- 轴的编号从 `0` 开始，依次为 `0`、`1`、`2`……
- 轴编号与数组 shape 元组的索引一一对应。也就是说，可以把轴编号理解为高维数组产生的元组索引。
- 记忆方法：凡提到轴，先看数组维度；有几位就有几个轴；具体哪个轴是哪个，就看索引 `0,1,2` 的顺序。

### 一维数组

- 一维数组只有一个轴，即 `0` 轴。
- 例如一维数组包含 4 个元素：`[7, 2, 9, 10]`，其 shape 可理解为 `(4,)`，只有一个 `0` 轴。
- 一维数组不存在行、列的二维区分，只需要理解为“沿唯一方向”的轴。

### 二维数组

- 二维数组有两个轴：`0` 轴和 `1` 轴。
- 以 2 行 3 列数组为例，shape 为 `(2, 3)`：
  - `0` 轴：行方向。
  - `1` 轴：列方向。
- 例如“两行三列”的数组，行对应 `0` 轴，列对应 `1` 轴。

### 三维数组

- 三维数组有三个轴：`0` 轴、`1` 轴、`2` 轴。
- 视频中以“四块、三行、两列”的三维数组为例，shape 可表示为 `(4, 3, 2)`：
  - `0` 轴：块方向，即最外层的四块。
  - `1` 轴：每块内部的行方向，即三行。
  - `2` 轴：每块内部的列方向，即两列。
- 具体结构为：最外层包含 4 个二维数组；每个二维数组为 3 行 2 列。
- 视频特别说明：有些教材会写“零是行，一是列，二是纵深”，这种说法容易让初学者混淆。结合三维数组的实际结构，更清晰的理解是：
  - 块是 `0` 轴；
  - 行是 `1` 轴；
  - 列是 `2` 轴。

### 轴编号总结表

| 数组维度 | 示例 shape | 轴数量 | 轴的编号与含义 |
|---|---|---|---|
| 一维数组 | `(4,)` | 1 个轴 | `0` 轴：唯一方向 |
| 二维数组 | `(2, 3)` | 2 个轴 | `0` 轴：行；`1` 轴：列 |
| 三维数组 | `(4, 3, 2)` | 3 个轴 | `0` 轴：块；`1` 轴：行；`2` 轴：列 |

- 在三维数组中，`0` 轴对应最高层/最外层的块，`1` 轴对应每块内部的行，`2` 轴对应最低层的一维列。
- 轴编号和元组索引是对等的：一维数组索引为 `0`；二维数组索引为 `0,1`；三维数组索引为 `0,1,2`。

## 2. 沿轴切片

- 沿轴切片就是沿着指定的轴取数组的一部分。
- 切片参数与轴的关系：
  - 第一个参数默认对应 `0` 轴。
  - 如果有逗号，第二个参数对应 `1` 轴。
  - 没有逗号时，表示只有一个参数，该参数沿 `0` 轴进行切片。
- 切片和索引一样，不包含结束值。

### 无逗号切片：沿 0 轴切

- 例如三行三列数组，形状为 `(3, 3)`，有两个轴：`0` 轴为行，`1` 轴为列。
- 使用 `arr[:2]`：
  - 只有一个参数 `:2`，没有逗号，因此默认沿 `0` 轴切片。
  - 表示从第 0 行开始，到第 2 行之前，即取第 0 行和第 1 行，不包含第 2 行。
  - 若数组为 `[[1,2,3],[4,5,6],[7,8,9]]`，则结果是前两行，即 `[[1,2,3],[4,5,6]]`。
  - 从一维数组的角度看，相当于取出了两个一维数组：`[1,2,3]` 和 `[4,5,6]`。

### 有逗号切片：同时指定行和列

- 例如使用 `arr[:2, 1:]`：
  - 逗号前 `:2` 对应 `0` 轴，表示行：从第 0 行到第 1 行，不包含第 2 行。
  - 逗号后 `1:` 对应 `1` 轴，表示列：从第 1 列到最后一列。
  - 对于 `[[1,2,3],[4,5,6],[7,8,9]]`，结果是 `[[2,3],[5,6]]`。
- 规则总结：
  - 无逗号：一个参数，沿 `0` 轴切。
  - 有逗号：第一个参数对应 `0` 轴，第二个参数对应 `1` 轴，依次类推。
  - 切片结束值不包含在结果中。

## 3. 转置与轴顺序

- 转置可以理解为改变数组的轴顺序。
- 二维数组原来的轴顺序为 `(0,1)`，转置后变为 `(1,0)`。
- 对于形状为 `(m,n)` 的二维数组，转置后形状变为 `(n,m)`。
- 转置改变的是元素排布和形状/轴顺序，元素值本身不发生变化。
- 视频提到，之前学过 reshape 可以改变形状；转置也是改变形状和排布的一种方式，但转置是通过交换轴顺序实现的。

### 行列转置

- 二维数组的行列转置可以通过 NumPy 提供的转置属性或方法完成。
- 常用的行列转置写法：
  - `arr.T`：最常用的二维数组转置属性。
  - `arr.transpose()`：使用方法形式进行转置；方法调用时需要带括号。
- 示例：
  - 先生成 0 到 23 共 24 个数，再 reshape 为 4 行 6 列的二维数组。
  - 对该数组进行转置后，原来的行变成列，原来的列变成行。
  - 原数组为 4 行 6 列，转置后变为 6 行 4 列。
- 视频强调：二维数组行列转置只需要记住数组后面的转置方法/属性即可，例如 `arr.T`，就可以把每一行转成一列，实现行列互换。

### 轴转置

- 轴转置需要指定新的轴顺序，通常使用 `transpose` 方法并传入轴顺序。
- 二维数组原轴顺序为 `(0,1)`，若要转置，则传入 `(1,0)`：
  - `arr.transpose((1,0))`，或按实际写法传入轴号参数。
  - 这样就把原来的 `0` 轴和 `1` 轴交换，实现行列转置。
- 对于二维数组，轴转置结果与 `arr.T` 的行列转置效果一致。
- 对于三维数组，也可以传入轴顺序来改变轴排列。例如原轴顺序为 `(0,1,2)`，可以按需要改变为其他顺序。
- 视频中提到一个三维示例：16 个数从 0 到 15，reshape 成“两块、两行、四列”的数组，shape 为 `(2,2,4)`，对应轴为 `0,1,2`。可以通过传入轴号改变轴顺序，从而改变数组的排列方式。
- 轴转置的核心：
  - 原轴顺序可以看作一个元组，例如 `(0,1)` 或 `(0,1,2)`。
  - 传入新的轴顺序元组，就可以按新顺序重新排列轴。
  - 二维数组将 `(0,1)` 改为 `(1,0)`，即可完成行列转置。

## 4. 本节重点总结

- 轴的数量等于数组维度数，轴编号从 `0` 开始。
- 一维数组只有 `0` 轴；二维数组有 `0` 轴和 `1` 轴；三维数组有 `0`、`1`、`2` 轴。
- 二维数组中：`0` 轴是行，`1` 轴是列。
- 三维数组中：`0` 轴是块，`1` 轴是行，`2` 轴是列。
- 轴编号与 shape 元组索引对应，理解轴时先看数组维度，再看索引顺序。
- 切片时：
  - 无逗号，默认沿 `0` 轴切片。
  - 有逗号，第一个参数对应 `0` 轴，第二个参数对应 `1` 轴。
  - 切片不包含结束值。
- 二维行列转置：
  - 常用 `arr.T`。
  - 也可使用 `arr.transpose()`。
- 轴转置：
  - 使用 `arr.transpose((1,0))` 等方式传入新的轴顺序。
  - 二维数组中把轴顺序从 `(0,1)` 改为 `(1,0)`，即实现行列互换。
- 转置改变轴顺序和元素排布，不改变元素值本身。
