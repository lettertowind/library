# 安装 pandas、numpy、xlrd 课程笔记

## 1. 课程目标

本节课程讲解如何在 Windows 环境下安装后续数据分析所需的三个 Python 库：

- `pandas`
- `numpy`
- `xlrd`

安装完成后，需要验证三个库均能正常导入，才能继续后续 Pandas 学习。

## 2. 打开 Windows 命令行

操作步骤：

- 同时按下键盘上的 `Windows` 键和 `R` 键。
- 系统会弹出“运行”对话框。
- 在运行对话框中输入 `cmd` 三个字母。
- 点击“确定”，打开命令行窗口。

后续的 `pip` 安装操作都在该命令行窗口中完成。

## 3. 进入 pip3.exe 所在目录

在命令行中，需要使用 `cd` 命令进入目标目录。

命令格式：

- `cd 空格 + 你的路径`
- 也就是：`cd <你的路径>`

操作说明：

- 每个人 Python 的安装路径可能不同，需要先找到 `pip3.exe` 文件所在位置。
- 视频中提到，该文件一般会在 Python 的目录下边，但具体安装位置需要根据自己电脑确认。
- 如果当时采用默认安装，可能不记得 Python 安装在哪里，需要自行查找 `pip3.exe` 所在文件夹。
- 找到对应文件夹后，在命令行输入 `cd`，加一个空格，再粘贴路径，按回车即可进入该目录。
- 视频强调：`cd` 是 DOS/Windows 中用于进入指定目录的命令。

示例命令形式：

- `cd <pip3.exe所在目录>`

进入正确目录后，才能继续使用 `pip` 安装相关库。

## 4. 安装 pandas

在进入 `pip3.exe` 所在目录后，输入以下命令安装 `pandas`：

- `pip install pandas`

命令说明：

- `pip` 是 Python 的包管理工具。
- `install` 表示安装。
- `pandas` 是要安装的库名。

视频中特别说明：

- 安装过程需要从网上下载，因此安装速度和成功率与网速有关。
- 安装也可能和网络运营商有关。
- 讲师本人表示自己安装了六遍才成功。
- 安装时不要着急。
- 如果失败，就重新安装；失败再装，反复尝试直到成功。

## 5. 安装 numpy

安装完 `pandas` 后，重复前面的步骤，在同一个命令行环境中继续安装 `numpy`。

安装命令：

- `pip install numpy`

视频对应说明：

- 转录中提到的“南派”即 `numpy`，拼写为 `n u m p y`。
- 如果之前已经安装过 `numpy`，则没有问题。
- 但仍需确保 `numpy` 已经安装。
- 如果安装失败，也按照前面的方式继续重试。

## 6. 安装 xlrd

继续安装 `xlrd`。

安装命令：

- `pip install xlrd`

视频对应说明：

- 安装完 `pandas` 和 `numpy` 后，还需要安装 `xlrd`。
- 安装失败时同样继续尝试，直到安装成功。

## 7. 验证安装是否成功

安装完成后，需要打开 Python 的编译器/IDE 进行验证。

依次输入以下导入命令，并分别按回车：

- `import pandas`
- `import numpy`
- `import xlrd`

判断标准：

- 输入 `import pandas` 后回车，如果没有报错，说明 `pandas` 安装成功。
- 输入 `import numpy` 后回车，如果没有报错，说明 `numpy` 安装成功。
- 输入 `import xlrd` 后回车，如果没有报错，说明 `xlrd` 安装成功。
- 三个导入命令均无报错，即表示安装成功，可以继续进行后续 `pandas` 学习。

## 8. 关键点与踩坑总结

- 打开命令行：`Windows + R`，输入 `cmd`，点击确定。
- 进入目录命令：`cd <路径>`。
- 必须进入 `pip3.exe` 所在目录，路径因电脑安装情况而异，需要自行查找。
- `cd` 是 Windows/DOS 中进入目录的命令。
- 安装 `pandas`：`pip install pandas`。
- 安装 `numpy`：`pip install numpy`。
- 安装 `xlrd`：`pip install xlrd`。
- 安装依赖网络，可能因网速或网络运营商导致失败。
- 失败后的处理方式：不要着急，重新执行安装命令，失败再装，反复尝试。
- 验证方式：在 Python 编译器中执行 `import pandas`、`import numpy`、`import xlrd`，无报错即安装成功。
- 安装成功并完成验证后，即可开始后续 `pandas` 的学习。
