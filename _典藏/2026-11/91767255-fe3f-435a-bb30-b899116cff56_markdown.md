# 孙兴华 Python 数据分析：数据透视表与交叉表

## 一、课程主题与核心结论

- 本节课讲解 Pandas 中的数据透视表与交叉表。
- 数据透视表在 Pandas 中主要使用 `pivot_table` 实现。
- 数据透视表特别适合处理**分组统计**问题，尤其是**多条件分组**时，应优先考虑使用数据透视表。
- 数据透视表的思路与 Excel 中的数据透视表基本一致；如果完全不理解 Excel 数据透视表，学习 Pandas 数据分析和后续大数据分析会比较吃力。
- 交叉表可以看作数据透视表的一种特例或组成部分，核心用途是**计数**。

`import pandas as pd`

## 三、`pivot_table` 的四个核心参数

`pivot_table` 的常见调用形式为：

`pd.pivot_table(数据, index=..., values=..., columns=..., aggfunc=...)`

其中四个重要参数分别是：

- `index`
- `values`
- `columns`
- `aggfunc`

### 1. `index`：指定透视表的行标签

- `index` 用于指定按哪些列进行透视，也就是结果透视表中的行标签。
- 可以传入单个列名，也可以传入列名列表。
- 视频示例中希望按照“部门”和“销售人员”进行透视，因此写法类似：

`pd.pivot_table(数据, index=['部门', '销售人员'])`

- 运行后，透视表首先按部门分组，再在部门内部按销售人员分组。
- 示例结果中可以看到：
  - 办公室下有郑浪；
  - 客服下有蒋波、赵文江；
  - 财务下有熊木；
  - 销售下有李平、王松等。
- 不同部门下允许出现重名，因为分组层级中包含部门，重名不会造成混淆。
- 视频强调：`index` 决定“按谁透视”，最终体现为行方向的分类标签。
- 如果没有显式指定聚合值列，Pandas 会对可聚合的数值列进行处理；视频强调实际使用时应明确指定聚合方式，不要完全依赖默认值。

### 2. `values`：指定结果中显示的值列

- `values` 用于指定透视结果中需要显示和聚合的列。
- 示例数据中有成本、数量、金额等数值列。
- 如果只想显示“数量”和“金额”，不显示“成本”，可以写：

`values=['数量', '金额']`

- 这样透视表中只保留数量和金额相关的聚合结果。
- 视频指出，实际大数据分析中可能有几十列，如果全部显示会非常混乱，也不方便查看。
- 因此应通过 `values` 明确指定需要展示的列。

### 3. `columns`：指定列方向的分类字段

- `columns` 用于在透视表的列方向上进行分组。
- 它会在已有行分组的基础上，增加列方向的分类层级。
- 视频示例中，在按“部门”和“销售人员”透视后，又加入“所属区域”作为列分组：

`columns='所属区域'`

- 运行后，透视表上方会增加多个列，例如四川、山东、河北等区域。
- 这样可以看到：
  - 某个部门、某个销售人员；
  - 在不同所属区域下的数量、金额等统计结果。
- 例如可以看到办公室的郑浪在四川区域销售了多少、在山东区域销售了多少、在河北区域销售了多少。
- 可以简单理解为：
  - `values` 决定显示哪些数值列；
  - `columns` 决定在列方向增加哪一级分类。

### 4. `aggfunc`：指定聚合函数

- `aggfunc` 用于指定数据透视时采用什么聚合方式。
- 视频强调该参数很重要，不能含糊，应明确告诉 Pandas 是求和、求平均、计数还是其他运算。
- 常见聚合方式包括：
  - `sum`：求和
  - `mean`：求平均
  - `count`：计数
  - `len`：统计长度/数量
- 可以传入单个函数，也可以传入函数列表，生成多种聚合结果。
- 如果需要对不同值列分别指定不同聚合方式，实际可以使用字典形式，例如：

`aggfunc={'数量': 'sum', '金额': 'mean'}`

- 视频中举例说明：数量可以求和，金额可以计数或求平均；一般业务中如果数量、金额都表示金额类指标，常见做法是都求和。
- 使用 Python 内置聚合函数时，例如 `sum`，可以直接写入。
- 使用 NumPy 中的聚合函数时，需要先导入 NumPy：

`import numpy as np`

- 例如求平均应写：

`np.mean`

- 视频特别提醒：`sum` 既可以使用 Python 内置的 `sum`，也可以使用 `np.sum`，但使用 NumPy 函数前必须正确导入 NumPy。
- 视频中口述的“lin/烂”实际指 Python 内置函数 `len`。
- `len` 是一个特殊函数：
  - 可以直接使用 Python 内置的 `len`；
  - 不能写成 `np.len`；
  - NumPy 中没有 `np.len`，这样写会报错。
- 除 `len` 外，其他聚合函数如果不确定，可以统一写成 `np.函数名`，但前提是正确导入 NumPy。

## 四、`pivot_table` 的三个实用参数

除了四个核心参数外，视频还介绍了三个常用参数：

- `fill_value`
- `dropna`
- `margins`

### 1. `fill_value`：替换缺失值

- `fill_value` 用于替换结果中的缺失值。
- 如果透视结果中存在空值，后续计算时任何数与缺失值参与计算都可能得到缺失值，影响统计。
- 可以将缺失值替换为 `0`，例如：

`fill_value=0`

- 这样结果中的空值在运行后都会被替换成零，不影响正常计算。
- 视频示例数据中不一定存在缺失值，但实际数据中如果确定可能有空值，应加上该参数。

### 2. `dropna`：删除全空列

- `dropna` 默认为 `False`。
- 当 `dropna=True` 时，将不包含所有条目均为空的列。
- 也就是说，如果某一列全部为空，可以将该空列从结果中移除，不再显示。
- 该参数不会影响正常有值数据的计算。

### 3. `margins`：添加行列小计/总计

- `margins` 用于添加行和列方向的小计、总计。
- 默认值为 `False`，即不显示小计。
- 设置为 `True` 后，结果中会在行和列上增加小计。
- 视频强调：`margins` 的小计方式不是固定求和，而是依据 `aggfunc` 指定的聚合方式。
  - 如果前面使用求和，小计就是求和；
  - 如果前面使用平均，小计就是按相应聚合逻辑得到的结果；
  - 如果前面使用计数，小计就是计数。
- 因此不能简单理解为“无论如何都对一行或一列求和”。

## 五、交叉表 `crosstab`

### 1. 交叉表的定位

- 交叉表是数据透视表的一部分或一种特例。
- 网上一些资料会把交叉表讲得很复杂，但核心可以简化为：
  - 数据透视表可以进行加法、计数、求和、求平均等多种运算；
  - 交叉表主要用于**计数**。
- 记忆重点：**交叉表就是计数**。
- 当需求是统计频数、记录条数、订单笔数等计数类结果时，可以使用交叉表。

### 2. 交叉表示例目标

- 视频中为演示交叉表，额外加入日期列。
- 日期示例从 2019 年 1 月 1 日开始，一直到 2022 年，仅作为测试数据使用。
- 目标是根据日期中的月份和所属区域，对部门进行计数统计。
- 也就是统计每个月、每个所属区域下，各部门出现了多少条记录。
- 视频说明该示例本身业务意义不是重点，重点是掌握交叉表的使用方法。

### 3. 日期字段处理

- 从日期列中提取月份可以使用：

`数据['日期'].dt.month`

- 类似地：
  - 提取年份使用 `.dt.year`
  - 提取日期中的天使用 `.dt.day`
- 这样可以方便地按年、月、日进行统计。

### 4. 交叉表写法

交叉表使用 Pandas 中的 `crosstab`：

`pd.crosstab(...)`

示例思路为：

`pd.crosstab(index=[数据['日期'].dt.month, 数据['所属区域']], columns=数据['部门'], margins=True)`

- 第一个参数 `index` 指定行方向分组条件。
- 当有两个分组条件时，需要用列表传入，例如：
  - 日期中的月份；
  - 所属区域。
- 第二个参数 `columns` 指定统计对象，即对“部门”进行计数。
- 交叉表默认就是计数，不需要像 `pivot_table` 那样额外指定复杂聚合函数。
- 可以加入 `margins=True` 得到小计或总计。

### 5. 交叉表输出示例说明

- 结果按月份分组，例如 1 月份下会列出四川、山东、河北、河南、湖北等所属区域。
- 每个区域下再统计各部门的数量。
- 示例结果中可能出现：
  - 四川 1 月份办公室有 1 条记录；
  - 客服有 1 条；
  - 财务有 16 条；
  - 销售有 30 条。
- 视频特别说明，这里的数字是记录条数、订单笔数等计数结果，不一定是“人数”。
- 交叉表的重点是计数，适合统计出现次数和频数。

## 六、数据透视表与交叉表的区别

- `pivot_table`
  - 支持多种聚合方式；
  - 可进行求和、平均、计数等操作；
  - 适合多条件分组统计；
  - 参数更丰富，可控制行、列、值、聚合函数、缺失值和小计。
- `crosstab`
  - 更偏向于计数；
  - 可以看作数据透视表的简化特例；
  - 当需求只是统计频数、记录条数时，使用交叉表更直接。

## 八、学习总结

- 数据透视表的核心参数：
  - `index`：按谁进行透视，决定行标签；
  - `values`：结果显示哪些值列；
  - `columns`：列方向的分类字段；
  - `aggfunc`：使用什么方式聚合。
- 常用补充参数：
  - `fill_value`：替换缺失值，例如替换为 0；
  - `dropna`：删除全空列；
  - `margins`：添加行列小计或总计，小计方式跟随聚合函数。
- 多条件分组时优先考虑 `pivot_table`。
- 只需计数时优先考虑 `crosstab`。
- 使用 NumPy 聚合函数前必须导入 NumPy；`len` 要使用 Python 内置的 `len`，不能写 `np.len`。
- 实际分析中应根据需求明确指定显示列和聚合方式，避免结果列过多、含义不清。
