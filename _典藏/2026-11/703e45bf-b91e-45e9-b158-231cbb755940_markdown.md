## 二、导入模块并读取数据
- 首先导入 `pandas`，后续使用别名 `pd`。
- 视频中把文件路径单独写好，再传给 `read_excel`；也可以直接把路径写进 `read_excel`。
- 示例文件位于 `C:\pandas` 下的“筛选”文件。
- 使用 `pd.read_excel()` 读取数据并打印查看。

```python
import pandas as pd

path = r"C:\pandas\筛选.xlsx"
df = pd.read_excel(path)
print(df)
```

读取后可以看到数据包含以下列：
- 序号
- 姓名
- 性别
- 出生日期
- 语文
- 数学
- 英语
- 总分
- 地址

后续几节课会继续使用这些列的数据。

## 三、日期查询前必须设置索引
- 如果查询涉及日期，必须先把日期设置为索引，再进行查询。
- 可以通过 `read_excel(..., index_col='出生日期')` 在读取时指定索引，也可以在读取后使用 `set_index('出生日期')`。
- 设置完成后，`出生日期` 会成为行标签，便于用 `loc` 查询。

```python
df = pd.read_excel(path, index_col='出生日期')

# 或者读取后再设置索引
# df = df.set_index('出生日期')
```

`loc` 的核心结构：
```python
df.loc[行标签, 列标签]
```

其中：
- 行标签：可以理解为行号或索引；
- 列标签：可以理解为字段名、列名。

特别注意：
- `loc` 后面必须跟 **中括号 `[]`**；
- 不要写成小括号 `loc(...)`。

## 四、单条件查询
- 查询 `1983-10-27` 这一天的语文成绩：

```python
df.loc['1983-10-27', '语文']
```

- 视频中查询结果为 `61` 分。
- 这里左边 `1983-10-27` 是行标签，右边 `语文` 是列标签。
- 使用日期查询时，日期字符串格式要尽量与数据中的格式一致。

## 五、多列查询与多日期查询
### 1. 查询某一天的多个科目
- 多列查询用列表表示：

```python
df.loc['1983-10-27', ['语文', '英语', '数学']]
```

- 列表中的列顺序可以由自己决定，例如：

```python
df.loc['1983-10-27', ['数学', '语文', '英语']]
```

输出列的顺序会按照列表中写的顺序显示。

### 2. 查询多个日期
- 多日期查询时，行标签也用列表表示，日期之间用逗号隔开：

```python
df.loc[['1983-10-27', '1983-12-06'], ['语文', '英语', '数学']]
```

- 少量日期属于“查询”；
- 如果是 `1983` 年到 `1989` 年这种大范围日期，更偏向“筛选”。

## 六、日期范围查询
- 在 `loc` 中可以使用英文冒号 `:` 表示日期范围：

```python
df.loc['1983-10-27':'1990-12-31', ['语文', '数学', '英语']]
```

含义：
- 查询从 `1983-10-27` 到 `1990-12-31` 之间的数据；
- 返回表中实际存在的该日期区间内的记录；
- 冒号必须是英文冒号。

易错点：
- 如果照着视频敲代码却报错，要检查标点符号是否为英文；
- 包括冒号、括号、引号等，中文标点可能导致报错。

## 七、列范围查询
- 列也可以使用冒号进行范围切片：

```python
df.loc['1983-10-27':'1990-12-31', '语文':'英语']
```

- 这会取出从 `语文` 到 `英语` 的列。
- 如果写成：

```python
df.loc['1983-10-27':'1990-12-31', '语文':'数学']
```

则只取 `语文` 到 `数学` 的列。

注意：
- 列范围按照 **原表中的列顺序** 排列；
- 不是按照查询时临时写的顺序；
- 原表中列顺序是：语文、数学、英语，所以 `'语文':'英语'` 会包含这三列。

## 八、条件表达式查询
需求示例：
- 语文大于等于 60 分；
- 英语小于等于 60 分；
- 即语文及格、英语不及格或等于 60 分的人。

在 Pandas 中，多条件之间不能直接用 Python 的 `and`，而要用 `&` 表示“且”。
- `&` 可以通过 `Shift + 7` 输入。
- 每个条件建议用小括号括起来。
- `loc` 后仍然必须使用中括号。

```python
df.loc[(df['语文'] >= 60) & (df['英语'] <= 60)]
```

完整写法可以加上逗号和冒号，表示选择所有列：

```python
df.loc[(df['语文'] >= 60) & (df['英语'] <= 60), :]
```

说明：
- 视频中个人习惯省略后面的 `, :`；
- 加与不加结果一样；
- 但完整语法更规范，建议理解 `loc[行条件, 列选择]` 的结构。
- 视频中提到“或”的符号是两个竖线 `|`，在 Python 基础课程中已经讲过相关逻辑运算符。

## 九、用 `loc` 做条件判断并新建列
视频打开“条件判断”文件进行演示。

### 1. 查看数据
- 先不设置索引，先查看数据长什么样。
- 大数据场景下通常不能直接双击打开文件，而是读取后查看前几行。
- 可以使用 `head()` 查看前五条：

```python
df = pd.read_excel(path2)
print(df.head())
```

数据中包含：
- 默认索引；
- 序号列；
- 姓名、性别、语文、数学、英语等列。

### 2. 将序号设置为索引
```python
df = df.set_index('序号')
```

设置后，序号成为索引。

### 3. 根据性别新建“称呼”列
需求：
- 性别为男，称呼为“先生”；
- 性别为女，称呼为“女士”。

使用 `loc` 进行条件赋值：

```python
df.loc[df['性别'] == '男', '称呼'] = '先生'
df.loc[df['性别'] == '女', '称呼'] = '女士'
```

解释：
- `df['性别'] == '男'` 是行条件；
- `'称呼'` 是列标签；
- 如果 `'称呼'` 列不存在，Pandas 会新建该列并赋值；
- 这样就生成了“称呼”列，男性显示“先生”，女性显示“女士”。

这个案例类似于 Excel/VBA 中常见的“根据性别生成称呼列”的操作，但这里使用 Pandas 的 `loc` 完成。

## 十、关键语法与易错点总结
- `loc` 的基本形式：
  ```python
  df.loc[行标签, 列标签]
  ```
- `loc` 后必须使用中括号 `[]`，不能使用小括号。
- 日期查询前要将日期设置为索引。
- 多列、多日期使用列表表示。
- 日期范围、列范围使用英文冒号 `:`。
- 列范围按照原表列顺序切片。
- 多条件使用 `&` 表示“且”，每个条件用括号包裹。
- `|` 表示“或”。
- 所有标点符号要使用英文，避免中文冒号、括号、引号导致报错。
- 精确少量值用查询；复杂范围、复杂条件用筛选。
