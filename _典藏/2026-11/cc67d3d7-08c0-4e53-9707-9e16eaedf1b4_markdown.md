## 2. 画布 Figure 的常用设置

### 2.1 设置画布名称：`num`

- 画布顶部/窗口名称可以通过 `num` 参数设置。
- 讲师强调：`num` 要写在 `plt.figure()` 的参数里，而不是写到显示区域里。
- 示例：

```python
plt.figure(num="孙兴华")
```

- 运行后，画布名称显示为“孙兴华”。
- 作用：修改画布/窗口的名称。

### 2.2 设置画布宽高：`figsize`

- 画布宽高通过 `figsize` 设置。
- 默认单位是**英寸（inch）**。
- 中国常用厘米、米；西方国家常用英寸，使用时需要自行转换。
- 宽是水平方向长度，高是竖直方向长度。
- `figsize` 使用元组形式，例如：

```python
fig = plt.figure(figsize=(12, 13))
```

- 参数含义：宽 `12`，高 `13`，单位为英寸。
- 运行后，画布会按照指定宽高显示。
- 讲师演示时口述“12 不好，13”，最终用类似 `(12, 13)` 的宽高元组说明设置方法。

### 2.3 设置画布分辨率：`dpi`

- 通过 `dpi` 参数设置画布分辨率。
- 示例：

```python
plt.figure(dpi=200)
```

- 关键结论与踩坑提醒：
  - 网络上显示时，`dpi` 最低不能低于 `75`。
  - 低于 `75` 会太模糊；例如设置成 `30`、`20`，图会看不清。
  - `75` 也不够。
  - 至少建议 `200` 或 `300`。
  - 现代显示设备与过去不同：过去 15 寸 CRT 显示器可能只有 `800x600` 分辨率，`200` 可能够用。
  - 现在显示器常见 24 寸起步，甚至 32 寸、37 寸，`200` 可能不够。
  - 一般可以设置到 `400`、`500` 甚至更多。
  - 笔记本上 `200` 差不多；如果要放大显示，`200` 可能也不够。
  - 最终根据个人显示器情况设置。
- 讲师演示时将 `dpi` 设置为 `200`。转录中“我的 cd 设置成 200”对应的是 `dpi=200`。

### 2.4 设置背景颜色：`facecolor`

- 画布背景色通过 `facecolor` 设置，默认是白色。
- 示例：

```python
plt.figure(facecolor="blue")
```

- 也可以简写颜色值，例如：

```python
plt.figure(facecolor="b")
```

- 运行后背景色变成蓝色。
- 讲师说明：设置蓝色只是演示“可以调色”，实际颜色可以自行决定。
- 也可以使用十六进制颜色值，例如 `#xxxxxx`，之前的课程中已经讲过。

### 2.5 边框颜色与是否显示边框

- 边框颜色参数是 `edgecolor`，例如：

```python
plt.figure(edgecolor="b")
```

- 讲师说明：一般情况下不设置边框颜色，因为看不出来，意义不大。
- 笔记中还提到“是否有边框”的参数，视频未重点演示；感兴趣可以查看笔记。
- 当前演示中边框看不到，因此不必重点设置。
- 本节重点掌握：**背景色 `facecolor` 怎么设置**即可。

### 2.6 画布参数综合示例

```python
import matplotlib.pyplot as plt

plt.figure(
    num="孙兴华",
    figsize=(12, 13),
    dpi=200,
    facecolor="blue"
    # edgecolor="b"  # 边框颜色，一般不需要设置
)
```

- 画布部分到这里基本够用。

## 3. 创建单个子图：`plt.subplot`

### 3.1 为什么需要子图：组合图与双坐标轴

- 讲师先说明：不要觉得“学这个没用，一个图只画一个东西”。
- 实际工作中会遇到**组合图**问题。
- 示例场景：
  - 柱形图表示销售金额。
  - 折线图表示毛利率，毛利率是零点几。
  - 此时需要附坐标轴：一边坐标轴是 `0~1000`，另一边是 `0%~100%`。
  - 这种图必须使用子图/双坐标轴方式实现。
- 讲师说明：不要着急，后面会慢慢讲。

### 3.2 使用 `plt.subplot` 创建单个子图

- 上节课用的是 `add_subplot`，往画布上添加子图。
- 本节讲用 `plt.subplot` 创建图，效果一样，只是方法不同。
- 参数与上节课类似：行、列、第几个。
- 示例：创建 2 行 2 列中的第 1 个图：

```python
plt.subplot(221)
```

- 创建第 2 个图：

```python
plt.subplot(222)
```

- 创建第 3 个图：

```python
plt.subplot(223)
```

- 创建第 4 个图：

```python
plt.subplot(224)
```

- 最后显示：

```python
plt.show()
```

- 运行后与上节课用 `add_subplot` 方法完全一样。
- 多学一种方法没有坏处；读别人程序时能看懂不同写法。

### 3.3 只创建部分子图

- 可以只使用部分位置。
- 例如删除 `222`，只保留 `221`、`223`、`224`。
- 运行后，第二个图位置为空，与不画第二个图的效果一致。

### 3.4 在单个子图中分别画图

- 在第一个子图画柱形图：

```python
plt.subplot(221)
plt.bar(data["班级"], data["销售量"])
```

- 在第三个子图画饼图：

```python
plt.subplot(223)
plt.pie(data["销售量"], labels=data["班级"])
```

- 讲师提醒：饼图要注意参数形式，`labels` 相关参数要注意传入元组/列表等结构。演示中使用班级数据作为标签。
- 在第四个子图画折线图：

```python
plt.subplot(224)
plt.plot(data["班级"], data["销售量"])
```

- 运行后，第 1、3、4 个子图都画出来了。
- 与上节课方法达到的效果一样，只是调用方法不同。
- 使用时可按照自己喜欢的方式选择。

## 4. 一次性创建多个子图：`plt.subplots`

### 4.1 `plt.subplots` 的基本用法

- 一次性创建多个子图，使用 `plt.subplots`，比 `subplot` 多一个 `s`，是复数形式。
- 返回画布和子图数组：

```python
fig, axes = plt.subplots(2, 2)
```

- 参数 `(2, 2)` 表示 2 行 2 列。
- 也可以不是方阵：
  - 2 行 1 列。
  - 2 行 3 列。
  - 3 行 3 列。
  - 4 行 4 列。
- 只要是矩阵形式即可。
- 运行 `plt.subplots(2, 2)` 会显示 2x2 的子图布局。
- 改成 4x4：

```python
fig, axes = plt.subplots(4, 4)
```

- 运行后显示 4x4 子图。
- 如果矩阵太多，一定要修改画布尺寸或 `dpi` 等参数，避免图太小或显示不清。
- 讲师演示后改回 2x2，避免太大。

### 4.2 子图索引从 0 开始

- 对 `axes` 设置子图时，可以使用二维数组索引。
- 2x2 布局对应：
  - 图 1：`axes[0, 0]`，第 0 行第 0 列。
  - 图 2：`axes[0, 1]`，第 0 行第 1 列。
  - 图 3：`axes[1, 0]`，第 1 行第 0 列。
  - 图 4：`axes[1, 1]`，第 1 行第 1 列。
- 示例：

```python
图1 = axes[0, 0]
图2 = axes[0, 1]
图3 = axes[1, 0]
图4 = axes[1, 1]
```

- 讲师强调：编程/计算机从 0 开始，所以是 `00`、`01`、`10`、`11`。
- 这与线性代数中的 `a11`、`a12` 表示不同，要区分好。

### 4.3 在 `axes` 子图上画图

- 在图 1 上画柱形图：

```python
图1.bar(data["班级"], data["销售量"])
```

- 在图 2 上画饼图：

```python
图2.pie(data["销售量"], labels=data["班级"])
```

- 运行后，图 1、图 2 等子图都能画好。
- 讲师演示时只做了两个图作为示例，说明其他子图同理。

### 4.4 与循环结合

- 因为 `plt.subplots` 返回的 `axes` 具有 `00`、`01`、`10`、`11` 这种规律索引，所以可以使用 `for` 循环和 `range` 形式批量生成若干张图。
- 如果图特别多，写成循环会方便应用。
- 如果只有四个图，不写循环也可以。
- 讲师建议：如果 `for` 循环还不过关，可以去看基础篇。

## 5. 关键对比与易混点

- `figure`：画布，是承载子图的整体容器。
- `subplot`：创建并激活单个子图，例如 `plt.subplot(221)`。
- `subplots`：一次性创建多个子图，返回 `fig, axes`，例如 `fig, axes = plt.subplots(2, 2)`。
- `add_subplot`：上节课使用的往画布上添加子图的方法。
- `plt.subplot(221)` 与 `fig.add_subplot(221)` 效果一致，只是写法不同。
- `figsize` 设置画布宽高，单位是英寸。
- `dpi` 设置分辨率，影响清晰度。
- `facecolor` 设置背景色。
- `edgecolor` 设置边框色，一般不必设置。
- `num` 设置画布名称。
- 子图索引从 `0` 开始：`[0,0]`、`[0,1]`、`[1,0]`、`[1,1]`。
- 组合图、双坐标轴场景需要子图方法支撑，后续课程会继续展开。

## 6. 本节结论

- 画布 `figure` 常用参数：`num`、`figsize`、`dpi`、`facecolor`，以及不常用的 `edgecolor`、是否显示边框等。
- `dpi` 不要低于 `75`，实际建议至少 `200` 或 `300`；大屏显示器可设 `400`、`500` 甚至更高。
- 单个子图可以用 `plt.subplot(行, 列, 位置)` 创建。
- 多个子图可以用 `plt.subplots(行, 列)` 一次性创建，并通过 `axes[行索引, 列索引]` 操作。
- 子图索引从 `0` 开始，不要与线性代数下标混淆。
- 不同子图创建方法效果相同，学习多种方法有助于阅读他人代码。
- 图特别多时可结合 `for` 循环和 `range` 批量处理。
