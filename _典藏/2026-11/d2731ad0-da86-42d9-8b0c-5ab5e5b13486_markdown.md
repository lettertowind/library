## 2. 参考书籍与学习建议

### 2.1 参考书籍

- 学习数据分析时，大家一般参考一本最权威的入门书。
- 讲师建议：**先别买书**。
- 原因：数据分析并不像大家想象的像 **Excel**、**Power BI** 等工具那么简单。
- 数据分析中会掺杂大量数学内容，包括：
  - 微积分；
  - 线性代数；
  - 概率论等。
- 因此，需要数学能力较强的人才能读懂这类书。
- 讲师建议先看一看、判断自己能否理解和接受，再决定是否买书。

### 2.2 数学基础与编程进阶的关系

- 讲师观点：在高级阶段，英语不再是编程的重点。
- 但在最早学习编程时，编程资料很多都是英文；如果英语不好，可能连文字都看不懂，因此早期英语很重要。
- 很多人学编程到初级、中级后，再向高级转折时停滞不前。
- 讲师认为其中一部分原因是：数学不好。
- 过去学习数学常见方式是：
  - 套公式；
  - 背题型；
  - 多做题。
- 讲师强调要理解道理和原理：
  - 明白原理后，题型怎么变化都不是问题；
  - 如果不明白道理，只记住某种题型的解法，题型一换、思路一换就不会做。
- 讲师提到国内教育存在“重语言而轻科学”的问题：
  - 英语常被用来评价一个人；
  - 数学、物理、化学等科学考试有时考得太简单、太死板；
  - 讲师认为不应只是“用功就能考好”，而应是“理解后才应该考好”。
- 讲师也说明：社会上行业很多，不是每个人都必须学数学；每个人有各自的行业选择。
- 英语好的人翻译书籍和资料，能让英语不好的人学习数据分析；大家是相互贡献的。

## 3. NumPy 安装与验证

### 3.1 安装思路

- 视频中说明：**NumPy** 的安装方法与此前的 **py mysql** 安装方法一样。
- 核心思路：先找到 `pip3.exe` 所在文件夹，再在命令行中进入该路径，使用 `pip3` 安装 **NumPy**。
- 安装过程需要联网，从网上下载安装包。
- 安装命令需要等待执行完成。

### 3.2 找到 pip3.exe 并复制路径

- 第1步：找到 `pip3.exe` 这个文件在哪个文件夹里。
- 第2步：复制该文件所在文件夹的路径。
- 视频中讲师先复制好路径，准备在命令行中使用。

### 3.3 打开命令行并切换到 pip3.exe 所在目录

- 第3步：在电脑上按 `Win + R`。
- 第4步：在运行窗口中输入 `cmd`，打开命令提示符。
- 第5步：在命令行中输入 `cd`，后面加空格，再输入刚才复制的路径。

命令形式如下：

```cmd
cd 你复制的pip3.exe所在文件夹路径
```

说明：

- `cd` 用于切换当前目录；
- 必须先进入 `pip3.exe` 所在目录，再执行后面的 `pip3` 安装命令；
- 视频中讲师强调要在这个路径下执行安装。

### 3.4 使用 pip3 安装 NumPy

- 第6步：在当前路径下输入安装命令：

```cmd
pip3 install numpy
```

命令说明：

- `pip3`：调用 Python 3 的包管理工具；
- `install`：安装子命令；
- `numpy`：要安装的包名，即 **NumPy**。
- 视频中讲师演示时已经安装完成，所以没有再次回车执行。
- 实际安装时需要：
  - 按回车执行；
  - 保持联网；
  - 等待从网上下载并安装完成。

### 3.5 验证 NumPy 是否安装成功

- 第7步：安装完成后，进入 Python 的编译器/交互环境。
- 第8步：输入导入命令并回车：

```python
import numpy
```

- 判断标准：
  - 如果**没有报错**，证明安装成功；
  - 如果**报错**，回到安装步骤，把 `pip3 install numpy` 重新安装一遍。

### 3.6 安装流程总结

- 步骤一：找到 `pip3.exe` 所在文件夹。
- 步骤二：复制该文件夹路径。
- 步骤三：按 `Win + R`，输入 `cmd`。
- 步骤四：输入 `cd 空格 路径`，进入 `pip3.exe` 所在目录。
- 步骤五：执行 `pip3 install numpy`。
- 步骤六：联网等待安装完成。
- 步骤七：进入 Python 环境，执行 `import numpy`。
- 步骤八：无报错即成功；有报错则重新安装。
