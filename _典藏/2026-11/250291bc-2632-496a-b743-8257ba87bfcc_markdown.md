## 3. 读取 Excel 文件并观察问题

- 导入 Pandas：

`import pandas as pd`

- 定义路径，示例：

`路径 = 'C:/pandas/自动填充.xlsx'`

- 读取 Excel：

`数据 = pd.read_excel(路径)`

- 打印数据：

`print(数据)`

- 观察结果：
  - Excel 上方空行、左侧空列被读取进来。
  - 表格显示不正常，需要跳过空行并选择有效列区域。

## 4. 参数 `skiprows`：跳过空行

- `skiprows` 用于跳过指定行。
- 关键点：
  - Pandas 行索引从 0 开始计数。
  - 列名/表头行不能算作普通数据行，需要正确处理。
- 视频中 Excel 前部有多行空行，需要设置：

`skiprows=8`

- 为什么是 `8` 而不是 `7`：
  - 从 0 开始数，第 6 行实际上对应第 7 行。
  - 列索引行不能算作数据。
  - 写 `skiprows=8` 后，下一行才会被当作列名，数据从第 9 行开始。
  - 如果写成 `skiprows=7`，列名行会被读进数据，导致“姓名”等表头进入数据区，表头错位。
- 结论：`skiprows` 跳过的是空行，同时必须保证表头行被 Pandas 识别为列名。

## 5. 参数 `usecols`：选择列区域

- `usecols` 用于选择指定列区域，写法类似 Excel 的列区域。
- 例如只想保留 F 到 I 列：

`usecols='F:I'`

- 类比 Excel：
  - Excel 中 `A:B` 表示 A 到 B 列。
  - Pandas 中 `usecols='F:I'` 表示只读取 F 到 I 列。
- 完整读取示例：

`数据 = pd.read_excel(路径, skiprows=8, usecols='F:I')`

- 参数总结：
  - `skiprows`：跳过几行。
  - `usecols`：选择列区域，和 Excel 中列区域类似。
- 运行后数据恢复为正常表格。
- 空单元格会显示为 `NaN`，后续需要自动填充。

## 6. 自动填充序号：`for` 循环 + `.at`

### 6.1 利用索引生成序号

- 读取后的数据索引是 `0、1、2……`。
- 目标是把序号填充为 `1、2、3……`。
- 可以用 `for` 循环遍历索引：

`for i in 数据.index:`

- 说明：
  - `数据.index` 是数据的索引序列。
  - `i` 依次取 `0、1、2……`。
  - Python 的 `for` 循环末尾必须有冒号 `:`。
  - 如果从 VBA 转过来，要特别注意 Python 的 `for`、`if` 等后面都有冒号。

### 6.2 `.at` 方法：定位某行某列

- `.at` 方法用于获取或设置某个位置的值。
- 格式：

`数据.at[行索引, 列名]`

- 例如取第 0 行 A 列，可理解为：

`数据.at[0, 'A']`

- 对序号列填充：

`数据.at[i, '序号'] = i + 1`

- 解释：
  - 第一次 `i = 0`，写入 `0 + 1 = 1`。
  - 第二次 `i = 1`，写入 `1 + 1 = 2`。
  - 第三次 `i = 2`，写入 `2 + 1 = 3`。
- 如果已经单独取出列，例如 `数据['序号']`，则只涉及行位置：

`数据['序号'].at[i] = i + 1`

- 运行后序号可能显示为：

`1.0、2.0、3.0`

- 原因是列中存在空值，Pandas 自动使用浮点型。

### 6.3 关键坑：自动填充前统一转成字符型

- 视频中强调：自动填充时不要把类型设置成整型 `int`，否则会报错。
- 所有参与填充的列，最好统一设置为字符型 `str`。
- 使用 `dtype` 字典一次性设置：

`数据 = pd.read_excel(路径, skiprows=8, usecols='F:I', dtype={'序号': str, '性别': str, '日期': str})`

- 三个关键列：
  - `序号`
  - `性别`
  - `日期`
- 全部设为 `str` 后，序号显示为 `123`，不再是 `1.0、2.0、3.0`。
- 如果不转字符型，后续做性别判断、日期填充时都可能出问题。

## 7. 自动填充性别：奇偶判断与三目运算

### 7.1 填充规律

- 目标效果：

`男、女、男、女、男、女……`

- 观察索引：
  - `0` 对应男。
  - `1` 对应女。
  - `2` 对应男。
  - `3` 对应女。
- 数学规律：
  - 偶数索引为男。
  - 奇数索引为女。
  - 即判断 \(i \bmod 2 = 0\)。
- 取余运算：

`i % 2`

- 当 `i % 2 == 0` 时为偶数，返回“男”；否则返回“女”。

### 7.2 三目运算复习

- 三目运算格式：

`c = a if a > b else b`

- 含义：
  - 如果条件 `a > b` 成立，返回 `a`。
  - 否则返回 `b`。
- 视频提示：三目运算可复习 Python 基础 PPT 第 51 页。

### 7.3 性别填充代码思路

- 先取出“性别”列再操作，避免每次都在整张表上改，减少内存浪费：

`数据['性别']`

- 循环填充：

`for i in 数据.index:`

`    数据['性别'].at[i] = '男' if i % 2 == 0 else '女'`

- 注意：
  - `=` 是赋值。
  - `==` 是判断相等。
  - 不要漏掉 `for` 后面的冒号。
- 运行后得到“男、女、男”。
- 如果有 100 行、1 万行、10 万行甚至更多，也可以按同样逻辑填充。

## 8. 日期填充与 `datetime` 模块

### 8.1 `datetime` 模块简介

- Python 提供多个处理日期和时间的内置模块：
  - `time`
  - `datetime`
  - 另一个不常用模块（视频未重点展开）
- `time` 模块：
  - 通过调用 C 库实现。
  - 有些方法在某些平台上可能不能调用。
  - 大部分接口与 C 标准库 `time.h` 基本一致。
- `datetime` 模块：
  - 相比 `time`，接口更直观易用。
  - 功能更强大。
- 本节重点使用：
  - `datetime.date`：表示日期，常用属性有 `year`、`month`、`day`，即年、月、日。
  - `datetime.timedelta`：表示两个日期时间之间的间隔，可精确到微秒。

### 8.2 导入日期模块并建立起始日期

- 导入示例：

`import datetime as 日期模块`

- 说明：别名可以自定义，中英文均可。
- 建立起始日期：

`起始日期 = 日期模块.date(2020, 5, 26)`

- 参数顺序：年、月、日。
- 日期模块中 `date` 需要传入年、月、日三个参数。

### 8.3 按天自动填充日期

- 使用 `timedelta(days=i)` 按天递增：

`数据['日期'].at[i] = 起始日期 + 日期模块.timedelta(days=i)`

- 解释：
  - `i = 0`：起始日期本身，即 2020-05-26。
  - `i = 1`：加 1 天，即 2020-05-27。
  - `i = 2`：加 2 天，即 2020-05-28。
- `timedelta` 常用参数：
  - `days`
  - `seconds`
  - `microseconds`
  - `milliseconds`
  - `minutes`
  - `hours`
  - `weeks`
- 关键坑：
  - `timedelta` 没有 `months` 参数，不能直接按月递增。
  - 天、秒、微秒、毫秒、分钟、小时、周可以直接用。
  - 涉及“月”的累加时，需要自己写算法处理进位。

## 9. 按年自动填充日期

- 如果想让年份依次变为 2020、2021、2022……
- 可以用 `date` 重新构造日期，保留起始日期的月和日：

`数据['日期'].at[i] = 日期模块.date(起始日期.year + i, 起始日期.month, 起始日期.day)`

- 解释：
  - 年：`起始日期.year + i`。
  - 月：`起始日期.month`。
  - 日：`起始日期.day`。
- 运行后年份依次递增。
- 踩坑记录：
  - 视频中曾出现同一位置赋值两次，最后一次为准。
  - 编程中如果不需要某段代码，一定要注释掉，避免覆盖结果或报错。

## 10. 按月自动填充：自定义“累加月”算法

### 10.1 为什么需要算法

- `timedelta` 没有月参数，所以不能直接加月份。
- 月累加必须处理“满 12 个月进 1 年”的问题。
- 例如：
  - 2019 年 12 月之后是 2020 年 1 月。
  - 不能简单把月份一直加到 13、14。

### 10.2 定义函数 `累加月(日期, 月份)`

- 函数接收两个参数：
  - `日期`：起始日期。
  - `月份`：要累加的月份数，例如行号 `i`。
- 函数定义：

`def 累加月(日期, 月份):`

- 第一步计算进位年数，使用地板除：

`    年 = 月份 // 12`

- 地板除解释：
  - `//` 是向下取整的除法。
  - 例如 \(3 // 2 = 1\)。
  - 传入 30 个月：\(30 // 12 = 2\)，表示 30 个月中包含 2 个整年。
- 第二步先计算月份：

`    月 = 日期.month + 月份 % 12`

- `%` 是取余：
  - \(30 \bmod 12 = 6\)。
  - 如果原日期是 5 月，则 \(5 + 6 = 11\) 月。
- 第三步判断月份是否需要再次进位：

`    if 月 != 12:`

`        年 = 年 + 月 // 12`

`        月 = 月 % 12`

- 判断逻辑：
  - 如果 `月 == 12`，说明刚好是 12 月，不需要再调整。
  - 如果 `月 != 12`：
    - 当 `月 < 12` 时，`月 // 12 = 0`，年不增加，`月 % 12` 仍为原月份。
    - 当 `月 > 12` 时，需要再进一年，余数才是实际月份。
- 返回构造好的日期：

`    return 日期模块.date(日期.year + 年, 月, 日期.day)`

- 完整函数示意：

`def 累加月(日期, 月份):`

`    年 = 月份 // 12`

`    月 = 日期.month + 月份 % 12`

`    if 月 != 12:`

`        年 = 年 + 月 // 12`

`        月 = 月 % 12`

`    return 日期模块.date(日期.year + 年, 月, 日期.day)`

### 10.3 算法示例

- 假设起始日期为 2020 年 5 月，传入 30 个月：
  - 年：\(30 // 12 = 2\)。
  - 月：\(5 + 30 \bmod 12 = 5 + 6 = 11\)。
  - 11 不等于 12，继续处理：
    - 年：\(2 + 11 // 12 = 2 + 0 = 2\)。
    - 月：\(11 \bmod 12 = 11\)。
  - 结果：2022 年 11 月。
- 传入 31 个月：
  - 年：\(31 // 12 = 2\)。
  - 月：\(5 + 31 \bmod 12 = 5 + 7 = 12\)。
  - 月等于 12，不再调整。
  - 结果：2022 年 12 月。
- 传入 32 个月：
  - 年：\(32 // 12 = 2\)。
  - 月：\(5 + 32 \bmod 12 = 5 + 8 = 13\)。
  - 13 不等于 12：
    - 年：\(2 + 13 // 12 = 2 + 1 = 3\)。
    - 月：\(13 \bmod 12 = 1\)。
  - 结果：2023 年 1 月。

### 10.4 调用 `累加月` 填充日期列

- 循环中调用函数：

`for i in 数据.index:`

`    数据['日期'].at[i] = 累加月(起始日期, i)`

- 传入实参：
  - 第一个实参：`起始日期`。
  - 第二个实参：行号 `i`。
- 运行后日期会按月递增。
- 视频演示结果表现为：2020 年 5 月、6 月、7 月依次递增；到 12 月后会进到下一年 1 月。
- 关键结论：
  - 月累加必须处理“满 12 进 1 年”。
  - 日期算法比按天、按年复杂，需要理解地板除和取余。

## 11. 设置索引：`set_index`

- 填充后，数据前仍有默认索引 `0、1、2……`。
- 很多情况下不希望保留这个默认索引，而希望把“序号”列设为索引。
- 不能在 `for` 循环之前或循环内部直接设置索引：
  - 因为 `for i in 数据.index:` 使用的是原始索引。
  - 如果先把“序号”设为索引，循环逻辑会改变，容易报错或结果错误。
- 正确做法：所有填充完成后，在 `for` 循环外设置索引：

`数据.set_index('序号', inplace=True)`

- 参数说明：
  - `'序号'`：指定“序号”列作为索引。
  - `inplace=True`：只在原数据索引上修改，不生成新的数据对象。
- 运行后：
  - “序号”降一级，成为行索引。
  - 其他列正常显示。
- 注意：设置索引与 `for` 循环无关，必须放在循环外面。

## 13. CSV/TXT 大数据场景

### 13.1 为什么实际工作常用 CSV

- 老师强调：实际工作中，大数据常见格式是 TXT 或 CSV，尤其 CSV 较多。
- Excel 小数据操作用 VBA、Power Query、Power BI 等往往更直接。
- 如果 Excel 文件达到几个 G，双击打开很容易卡死。
- 这种打不开的大数据场景，才更适合用 Pandas 处理。
- 结论：
  - 小数据 Excel：Python 操作 Excel 有“炫技”成分，流程复杂、费脑子。
  - 大数据 CSV/TXT：Pandas 才真正体现价值。

### 13.2 准备 CSV 文件

- 可以在 Excel 中右键“另存为 CSV”。
- 视频中使用逗号分隔的 CSV 格式保存。
- CSV 文件特点：
  - 没有 Excel 上方空行、左侧空列那种复杂结构。
  - 数据通常从头开始。
  - 因此不需要 `skiprows`、`usecols`。

### 13.3 读取 CSV

- 路径改为 CSV 文件：

`路径 = 'C:/pandas/自动填充.csv'`

- 使用 `read_csv` 读取：

`数据 = pd.read_csv(路径)`

- 与 Excel 读取的差异：
  - 从 `read_excel` 改为 `read_csv`。
  - 删除 `skiprows`。
  - 删除 `usecols`。
  - CSV 不需要跳过空行空列。
- 如果 CSV 是 Tab 键分隔而不是逗号分隔，读取时需要指定分隔符，例如：

`数据 = pd.read_csv(路径, sep='\t')`

- 视频示例以逗号分隔 CSV 为主，因此默认 `read_csv` 即可。

### 13.4 CSV 中的自动填充逻辑

- 序号、性别、日期的填充逻辑与 Excel 完全一致。
- 仍然使用：
  - `for i in 数据.index:`
  - `数据['序号'].at[i] = i + 1`
  - `数据['性别'].at[i] = '男' if i % 2 == 0 else '女'`
  - 日期填充或 `累加月` 函数。
- 设置索引同样使用：

`数据.set_index('序号', inplace=True)`

### 13.5 写回 CSV

- 写回 CSV 用：

`数据.to_csv(路径)`

- 不要误用 `to_excel` 写 CSV。
- 总结：
  - Excel：`read_excel` / `to_excel`。
  - CSV：`read_csv` / `to_csv`。
  - 读取函数和写回函数改变，自动填充核心逻辑不变。

## 15. 关键结论与易错点汇总

- `skiprows` 行号从 0 开始，表头行不能被当成数据行。
- `usecols='F:I'` 用于选择列区域，类似 Excel 的列区间。
- `.at` 用于定位某行某列，适合逐单元格填充。
- 自动填充时，参与填充的列必须统一设为字符型 `str`，不要设为 `int`，否则可能报错。
- `for`、`if` 等 Python 语句末尾不要漏冒号。
- `=` 是赋值，`==` 是判断相等。
- 性别填充规律：偶数索引为男，奇数索引为女，即 \(i \bmod 2 = 0\) 时为男。
- `timedelta` 支持天、秒、微秒、毫秒、分钟、小时、周，但没有“月”。
- 月累加必须自己写算法，处理满 12 个月进 1 年。
- `set_index` 必须放在 `for` 循环外，不能提前设置索引。
- Excel 写入用 `to_excel`，CSV 写入用 `to_csv`。
- Pandas 操作 Excel 适合复杂/大数据场景；普通 Excel 自动化用 VBA、Power Query、Power BI 往往更简单。
