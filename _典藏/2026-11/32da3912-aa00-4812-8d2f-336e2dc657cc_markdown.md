## 显示网格线

### 基本用法

显示网格线使用：

`plt.grid()`

讲师演示：写上 `plt.grid()` 后运行，图形中就会出现默认网格线。

### 第一个参数：布尔值

`plt.grid()` 的第一个参数是一个布尔值，表示是否显示网格线。

讲师观点：

- 这个参数没有太大实际意义。
- 如果不想显示网格线，不写 `plt.grid()` 即可。
- 没有必要特意写一个 `False` 来关闭网格线。
- 如果想显示网格线，第一个参数就不用管它。

### 第二个参数

讲师表示第二个参数不建议在本节深入研究。

如果想了解，可以自行查看 matplotlib 的帮助文档。本节从第三个参数开始讲解。

## 第三个参数：`axis` 轴设置

### `axis` 参数的作用

第三个参数是轴参数，用于控制：

- x 轴方向的网格线
- y 轴方向的网格线

也就是说，x 轴网格线和 y 轴网格线可以分开设置。

### 默认情况

如果不写 `axis` 参数，默认会同时设置/显示 x 和 y 两个方向的网格线。

例如：

`plt.grid()`

默认同时作用于 x 轴和 y 轴。

### 单独设置 x 轴

如果只想设置 x 轴方向的网格线，可以指定：

`axis='x'`

示例：

`plt.grid(axis='x', color='red')`

讲师先设置 x 轴网格线颜色为红色，用于观察效果。

### x 轴网格线的方向容易混淆

讲师特别强调一个易错点：

- 竖直方向的网格线，看起来像是在 y 轴上，但在 matplotlib 的命名中，它属于 x 轴网格线。
- 理解方式是：这些竖直线从 x 轴上的位置开始向上延伸，因此按 x 轴来设置。
- 要设置竖直网格线时，应使用 `axis='x'`。
- 要设置横向网格线时，应使用 `axis='y'`。

当只设置 `axis='y'` 时，竖直方向的网格线会消失，只剩下与 y 轴设置相关的横向网格线。

结论：

- `axis='x'`：控制竖直网格线
- `axis='y'`：控制横向网格线
- 不写 `axis`：x、y 两个方向一起控制

## 设置网格线颜色：`color`

在指定 `axis='x'` 后，可以通过 `color` 修改网格线颜色。

示例：

`plt.grid(axis='x', color='red')`

运行后，x 轴方向的网格线颜色变为红色。

## 设置网格线线型：`linestyle`

### 冒号表示虚线

讲师接着演示设置网格线的线型。

使用参数：

`linestyle`

示例：

`plt.grid(axis='x', linestyle=':')`

其中：

- `':'` 表示虚线。
- 运行后，x 轴方向的网格线会变成虚线。

讲师提到可以参考之前提供的线型表格笔记。本节重点演示用冒号 `:` 表示虚线。

## 设置网格线粗细：`linewidth`

### 尝试设置较粗的线宽

设置网格线粗细使用参数：

`linewidth`

示例：

`plt.grid(axis='x', linewidth=10)`

讲师先尝试将线宽设置为 `10`。

结果：

- 线条明显变粗。
- 讲师认为太粗，看起来别扭。

### 调整线宽为 3

之后改为：

`plt.grid(axis='x', linewidth=3)`

运行后效果比较合适。

讲师在演示过程中还提到参数名拼写问题，例如 `line` 相关单词少写字母会导致写错，修正后即可正常运行。

结论：

- `linewidth` 控制网格线粗细。
- 线宽不要设置过大，否则视觉上不协调。
- 示例中 `linewidth=3` 的效果比较合适。

## 设置 y 轴网格线

学会设置 x 轴网格线后，y 轴网格线同理。

只设置 y 轴方向：

`plt.grid(axis='y', ...)`

例如可设置颜色、线型、线宽：

`plt.grid(axis='y', color='red')`

`plt.grid(axis='y', linestyle=':')`

`plt.grid(axis='y', linewidth=3)`

说明：`axis='y'` 控制的是横向网格线。

## x 轴和 y 轴一起设置

如果希望 x 轴和 y 轴网格线一起设置，就不要单独指定 `axis`。

即使用：

`plt.grid()`

或传入样式参数但不指定单独轴，例如：

`plt.grid(color='red', linestyle=':', linewidth=3)`

这样会同时对 x、y 两个方向的网格线生效。

## 本节关键参数总结

- `plt.grid()`：显示网格线。
- 第一个参数：布尔值，控制是否显示网格线；讲师认为实际意义不大，不想显示就不写 `plt.grid()`。
- 第二个参数：讲师不建议本节深入研究，可自行查看帮助文档。
- `axis`：第三个参数，控制网格线作用轴。
  - `axis='x'`：设置 x 轴方向网格线，即竖直网格线。
  - `axis='y'`：设置 y 轴方向网格线，即横向网格线。
  - 不写 `axis`：默认同时作用于 x 和 y。
- `color`：设置网格线颜色，例如 `color='red'`。
- `linestyle`：设置网格线线型，例如 `linestyle=':'` 表示虚线。
- `linewidth`：设置网格线线宽，例如 `linewidth=3`。

## 易错点与讲师结论

- x 轴网格线不是按视觉方向命名的，而是按“从 x 轴起点向上延伸”来理解。
- 竖直网格线应通过 `axis='x'` 设置，横向网格线应通过 `axis='y'` 设置。
- 只设置 `axis='y'` 时，竖直网格线会消失。
- 不想显示网格线时，直接不调用 `plt.grid()`，不必特意写 `False`。
- 设置样式时参数拼写要准确，例如 `linestyle`、`linewidth`。
- 线宽过大会显得别扭，示例中线宽 `3` 效果较合适。
