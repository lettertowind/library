## 3. NumPy 安装方法
安装思路与安装 PyMySQL 类似：先找到 `pip3.exe` 所在目录，再在命令行中进入该目录并执行安装命令。

### 3.1 找到 pip3.exe 所在文件夹
- 在电脑中找到 `pip3.exe` 文件所在的文件夹。
- 复制该文件夹路径。

### 3.2 打开命令行并进入目标路径
- 按 `Win + R` 打开“运行”窗口。
- 输入 `cmd`，打开命令提示符。
- 输入 `cd`，加一个空格，再粘贴刚才复制的路径。
- 回车后进入包含 `pip3.exe` 的目录。

### 3.3 执行 NumPy 安装命令
- 在目标路径下输入：
  - `pip3 install numpy`
- 命令含义为使用 `pip3` 安装 NumPy。
- 回车后等待安装完成。
- 安装过程必须联网，因为需要从网络下载 NumPy 安装包。
- 视频中讲师电脑已安装完成，因此没有再次执行回车安装。

## 4. 验证 NumPy 是否安装成功
- 安装完成后，进入 Python 编译器。
- 输入以下语句并回车：
  - `import numpy`
- 如果没有报错，说明 NumPy 安装成功。
- 如果出现报错，应返回安装步骤，重新安装一遍。
