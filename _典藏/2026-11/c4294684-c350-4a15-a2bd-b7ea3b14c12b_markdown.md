# Pandas 数据删除：drop 函数学习笔记

## 1. 课程目标

- 本节聚焦 `pandas` 中的 `drop` 函数，用于删除 `DataFrame` 中的行和列。
- 前面课程涉及如何新建数据，本节补充如何删除数据。
- 核心内容包括：删除单行、删除多行、删除单列、删除多列，以及 `inplace` 参数的作用。

## 2. 环境与数据准备

- 导入 `pandas` 模块：

  `import pandas as pd`

- 定义文件路径。视频中将数据放在 `C` 盘的 `pandas` 目录下；实际练习时应根据自己的课件目录或文件位置修改路径。

  `path = 'C:/pandas/...'`

- 读取数据：

  `df = pd.read_excel(path)`

- 如果使用 `CSV` 文件，只需要把 `read_excel` 改为 `read_csv`，其他参数使用思路一致。

- 先打印数据查看结构：

  `print(df)`

- 示例数据结构：
  - 数据带有序号索引。
  - 列包括：`姓名`、`语文`、`数学`、`英语`。
  - 后续删除操作都基于该示例数据演示。

- 视频中特别说明：大数据通常用 `CSV` 或 `TXT` 存档，本节用 Excel 只是演示；换成 `CSV` 后参数逻辑相同。

## 3. 删除单行

- `drop` 删除行时使用默认的 `axis=0`。
- 删除单行时，可以直接在 `drop` 中写入行标签。

  示例：

  `df.drop(2)`

- 该操作表示删除行标签为 `2` 的行。视频示例中删除第二行，对应某位姓名的记录，转录中姓名可能为“李平/李平定”等，实际以数据文件为准。
- 删除后，原数据的索引序号不会自动重排，其他行的序号保持不变。
- 需要特别注意：`drop` 中写的是行标签，不是普通意义上的行号。示例数据带有序号，因此看起来与行号对应。

## 4. 删除多行

- 删除多行时，需要使用 `labels` 参数，并把多个行标签写成列表。
- 语法示例：

  `df.drop(labels=[1, 3])`

- 该操作表示删除行标签为 `1` 和 `3` 的行。视频示例中对应删除“丁志敏、王刚”等记录，具体姓名以实际数据为准。
- 多个标签之间用逗号隔开。
- 删除后保留未删除的行，例如原数据中的 `2、4、5、6` 等行仍然保留。
- 关键区别：
  - 删除单行：直接写行标签。
  - 删除多行：使用 `labels=[...]`，列表中写多个行标签。

## 5. 删除单列

- 删除列时，需要把轴设置为列方向，即 `axis=1`。
- `drop` 的 `axis` 默认是 `0`，表示按行操作；删除列必须改为 `axis=1`。
- 删除单列的语法示例：

  `df.drop('语文', axis=1)`

- 该操作表示删除列标签为 `语文` 的列。
- 运行后，`语文` 列被删除，只保留 `数学`、`英语` 等未删除列。

## 6. 删除多列

- 删除多列时，同样使用 `labels` 参数，并结合 `axis=1`。
- 语法示例：

  `df.drop(labels=['语文', '英语'], axis=1)`

- 该操作表示同时删除 `语文` 和 `英语` 两列。
- 视频示例中运行后只留下 `数学` 列，其他被指定删除的列消失。
- 多个列标签写在列表中，用逗号分隔。

## 7. inplace 参数

- `drop` 中包含 `inplace` 参数，用于控制是在原数据上修改，还是生成一个新的数据对象。
- `inplace` 默认值为 `False`，表示默认返回一个新的对象，原数据不发生变化。
- 如果按照如下写法直接打印：

  `print(df.drop(...))`

  此时相当于生成了一个新对象并直接打印，原 `df` 不变，但打印结果没有问题。

- 这等价于：

  `df2 = df.drop(...)`

  `print(df2)`

- 如果只写：

  `df.drop(...)`

  `print(df)`

  则删除操作没有赋值给新对象，也没有修改原数据，因此最后打印的仍然是原始数据，删除不生效。

- 若希望在原数据上直接修改，需要添加：

  `df.drop(..., inplace=True)`

  然后打印：

  `print(df)`

  此时原数据会被修改，打印结果才是删除后的数据。

- `inplace` 参数对比：

| 写法 | 效果 |
|---|---|
| `print(df.drop(...))` | 直接打印删除后的新对象，原 `df` 不变 |
| `df2 = df.drop(...); print(df2)` | 将删除后的结果保存为新对象 |
| `df.drop(...); print(df)` | 删除没有生效，仍然打印原始数据 |
| `df.drop(..., inplace=True); print(df)` | 在原数据上修改，打印删除后的数据 |

## 8. 方法总结

- 删除行使用默认 `axis=0`：
  - 删除单行：`df.drop(行标签)`
  - 删除多行：`df.drop(labels=[行标签1, 行标签2])`

- 删除列需要设置 `axis=1`：
  - 删除单列：`df.drop(列标签, axis=1)`
  - 删除多列：`df.drop(labels=[列标签1, 列标签2], axis=1)`

- 删除单个标签时，可以直接写入标签。
- 删除多个标签时，需要使用 `labels` 参数，并将多个标签放入列表中，用逗号分隔。
- 删除行或列后，原索引/序号不会自动重排。
- `inplace=False` 是默认行为，表示生成新对象，原数据不变。
- `inplace=True` 表示直接在原数据上修改。
- 如果执行 `drop` 后没有接收返回值，也没有设置 `inplace=True`，则原数据不会发生变化，删除操作相当于无效。
