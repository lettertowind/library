## 一、分组聚合的核心概念

`groupby` 可以理解为“先分组，再对每一组做聚合计算”。

### 与 Excel、SQL 的类比

- 类似 Excel 中的 `SUMIF` 条件求和，但聚合不只是求和。
- 还可以求：
  - 平均值
  - 中位数
  - 最大值、最小值
  - 计数
  - 方差、标准差等
- 如果学过 SQL/MySQL，`groupby` 与 SQL 中的 `GROUP BY` 思路相似：按某个字段分组后分别计算。

### 分组聚合三步理解

以“国家、魅力值”表为例，国家有重复值：中国、美国、日本。

- 拆分：把中国的数据放一堆，美国的数据放一堆，日本的数据放一堆。
- 聚合：分别对中国、美国、日本进行求和或其他计算。
- 合并结果：得到类似中国 300、美国 30、日本 60 的结果。

在 pandas 中，`DataFrame` 可以在行或列方向分组，并把函数应用到各分组，产生新的结果。

## 二、常用聚合函数

视频中总结了常用聚合函数：

- `count`：统计分组中非空值的数量。
- `sum`：计算非空值的和。
- `mean`：计算平均值，相当于 average。
- `median`：计算中位数。奇数个数据取中间值；偶数个数据取中间两个值的平均。
- `var`：方差。
- `std`：标准差。
- `max`：最大值。
- `min`：最小值。
- `prod`：乘积。
- `first`、`last`：取分组内第一个/最后一个非空值等。

实际工作中最常用的是：

- 计数：`count`
- 求和：`sum`
- 平均：`mean`
- 最大、最小：`max`、`min`
- 中位数：`median`

方差、标准差更多用于专业统计或特殊分析场景；涉及这些概念时，需要进一步学习概率论与统计学。

## 三、示例数据 1：遍历分组

课件数据包含以下列：

- 城市
- 区域
- 人数
- 金额

其中城市列故意写成不统一的形式，例如：

- 北京市
- 北京
- 天津
- 等

这是为了模拟真实数据中命名不统一的情况。区域与城市对应，例如：

- 北京市下对应东城区、西城区
- 天津市下对应南开区、和平区

视频先演示如何遍历各个分组：

```python
for i, j in data.groupby(["城市", "区域"]):
    print(i)
```

说明：

- `i` 是分组键，可能是元组，例如 `("北京", "东城区")`。
- `j` 是该分组对应的子 `DataFrame`。
- 通过打印 `i` 可以看到各个分组。
- 城市会有多个分组，是因为一个城市对应多个区。
- 这种方式可以做出带层级表头的展示效果，但实际工作中并不常用。
- pandas 中应尽量避免 `for` 循环，除非万不得已。

## 四、基础分组聚合写法

基础语法：

```python
data.groupby(按谁分组)[对谁聚合].聚合函数()
```

例如：

```python
data.groupby(["城市", "区域"])[["人数"]].sum()
```

再增加金额列：

```python
data.groupby(["城市", "区域"])[["人数", "金额"]].sum()
```

要点：

- `groupby()` 括号中写按谁分组。
- 一个分组条件可以直接写字符串。
- 多个分组条件写成列表。
- 对谁聚合写在 `groupby()` 后面的中括号里。
- 建议统一写成“列表套列表”的形式，例如 `[["人数"]]`，避免分组条件多时忘记格式。
- 后面的 `.sum()` 表示聚合方式。

控制台中输出可能看起来比较乱，这是显示问题；导出到 Excel 后格式正常，并且会自动合并单元格。例如：

- 北京市下显示东城区、西城区
- 天津市下显示南开区、和平区
- 每个区对应的人数和金额正确显示

这种基础写法是大多数人最常用的方式，日常分析基本够用；但如果涉及大数据分析，还需要继续学习更复杂的聚合方式。

## 五、`agg` 与不同列使用不同聚合方式

示例数据 2 包含：

- 电号/店号：有一位数、两位数、三位数，例如 1 店、2 店、3 店、25 店、35 店、105 店、225 店等。
- 月份列：1 月、2 月、3 月、4 月等。

需求：不同列使用不同聚合方式。

- 1 月：计数 `count`
- 2 月：求和 `sum`
- 3 月：最大值 `max`
- 4 月：平均值 `mean`

此时建议使用字典配合 `agg`：

```python
agg_dict = {
    "1月": "count",
    "2月": sum,
    "3月": max,
    "4月": "mean",
}

data.groupby("电号").agg(agg_dict)
```

注意：

- `sum`、`max` 是 Python 自带函数，可以不加引号。
- `count`、`mean` 不是 Python 自带函数，而是 pandas 聚合方式，需要加引号，例如 `"count"`、`"mean"`。
- 在编辑器中写 `sum`、`max` 时通常会变色；写 `count` 不变色，说明它不是 Python 内置函数。

### `agg` 与 `groupby` 的区别

- `groupby`：主要针对行进行分组。
- `agg`：基于列进行聚合。
- 当分组聚合涉及“不同列使用不同聚合函数”时，适合使用 `agg`。

示例理解：某店某列有 3 条销售数量记录，则：

- `count` 得到 3
- `sum` 得到总和，例如 60
- `max` 得到最大值，例如 30
- `min` 得到最小值，例如 10

重点是理解：`agg` 能对每一列指定不同的聚合方式。

## 六、使用字典与 `axis=1` 按列汇总季度

当数据包含 1 月、2 月、3 月、4 月等月份列时，常见需求是把月份汇总成季度。

在 VBA、Power BI 中计算季度可能相对麻烦，例如 Power BI 需要时间表、度量值等；在 pandas 中可以通过字典映射完成。

可建立月份到季度的对应关系：

```python
季度映射 = {
    "1月": "一季度",
    "2月": "一季度",
    "3月": "一季度",
    "4月": "二季度",
}
```

说明：视频中口述季度时有口误，按正常季度含义应为：

- 1、2、3 月属于一季度
- 4、5、6 月属于二季度

核心是建立“月份 → 季度”的映射字典。

然后使用 `axis=1` 表示按列方向分组聚合：

```python
data.groupby(季度映射, axis=1).sum()
```

要点：

- `axis=1` 表示对列进行操作。
- 字典把多个月份列映射到同一个季度。
- 聚合后会把 1、2、3 月横向合并成一季度，把 4 月等合并到二季度。
- `sum()` 可以写在 `groupby(...)` 后面，也可以结合 `agg` 或在打印时指定聚合方式。
- 工作中可以提前准备常用映射字典，例如月份到季度、地区名称标准化等；具体内容要按自己单位的数据语言和规范整理。

### 索引显示问题

如果电号没有显示为行索引，原因通常是读取数据时没有指定索引列。

可以在读取文件时设置：

```python
pd.read_csv(..., index_col="电号")
```

或读取 Excel 时设置相应索引列。这样聚合结果中才会以电号作为索引显示。

### 分组对象的复用建议

- 如果只是求和，可以直接写 `.sum()`。
- 如果后续还要做平均、中位数等多种聚合，建议先保存 `groupby` 对象，最后再调用聚合函数，避免重复分组。
- 例如：先分组，再在 `print` 或 `agg` 中指定 `sum`、`mean`、`median` 等。

## 七、通过函数分组

视频介绍了通过函数进行分组的方法，但明确表示：

- 不常用
- 不建议作为主要写法
- 只做介绍，了解即可

示例：按城市名称字数长度进行分组聚合。

前提是把城市名称设置为索引：

```python
df = pd.read_excel(path, index_col="城市")
df.groupby(len).sum()
```

或使用函数形式对索引长度分组。输出结果会按城市名称长度分类，例如：

- 两个字的城市
- 三个字的城市

并分别统计人数、金额等。这个思路类似连续值离散分箱。

还可以结合函数和列表进行多条件分组。例如为 6 家店指定所在城市列表：

```python
s1 = ["北京", "北京", "北京", "北京", "天津", "天津"]

df.groupby([len, s1]).sum()
```

输出可得到：

- 两个字的店铺且在北京的汇总
- 三个字店铺且在北京的汇总
- 四个字店铺的情况
- 天津店铺的情况
- 例如对应 1 月份的汇总结果

视频说明：这种功能不算特别实用，只有对函数和分组机制比较了解时才建议扩展使用；基础学习中了解即可。

## 八、按索引层级分组：`level`

这是本节重点内容之一。示例数据包含：

- 班级
- 性别
- 语文
- 数学

可以理解为每个班男生、女生的语文和数学成绩。目标是按班级求中位数或其他聚合结果。

### 正确做法：先设置索引

```python
df = df.set_index(["班级", "性别"])
df.groupby(level="班级").median()
```

也可以显式选择数值列：

```python
df.groupby(level="班级")[["语文", "数学"]].median()
```

要点：

- `level` 表示按索引层级分组。
- 必须先把“班级”“性别”等列设置为索引，提升为索引层级。
- 设置索引后，`班级`、`性别` 成为索引层，后续聚合只对数值列“语文”“数学”进行计算。
- 如果未设置索引，直接使用 `level="班级"` 可能报错或结果异常。
- 如果只对某一列聚合，可以显式指定列；如果对后面所有剩余列聚合，则所有参与聚合的列都必须是数值列。

### 排错建议

当分组聚合出现问题时，应优先检查：

- 索引是否正确设置
- 是否将文本列设置成了索引
- 参与聚合的列是否都是数值列
- 是否显式选择了聚合列

视频通过对比“设置索引前”和“设置索引后”的结果，说明必须先把文本列提为索引，才能安全地对剩余数值列做中位数等计算。

## 九、多层列索引与按列层级聚合

最后一个案例使用双层表头的 Excel 数据：

- 第一层表头：季度
  - 一季度：1 月、2 月、3 月
  - 二季度：4 月、5 月
- 第二层表头：月份

读取时设置多层表头：

```python
df = pd.read_excel(path, header=[0, 1])
```

这样可以得到多层列索引。

### 构造多层列索引

视频先创建两个列表，分别表示季度和月份，然后使用 `pd.MultiIndex.from_arrays` 构造多层列索引：

```python
l1 = ["一季度", "一季度", "一季度", "二季度", "二季度"]
l2 = ["1月", "2月", "3月", "4月", "5月"]

df.columns = pd.MultiIndex.from_arrays(
    [l1, l2],
    names=["季度", "月份"]
)
```

说明：

- 多层索引常见构造方式有三种：
  - 数组方式：一一对应
  - 元组方式：一一对应
  - 笛卡尔积方式：适合各层取值数量一致的情况
- 本案例不能用笛卡尔积，因为：
  - 一季度对应 3 个月：1、2、3 月
  - 二季度对应 2 个月：4、5 月
- 两组月份数量不同，所以应使用数组或元组方式一一对应。
- 更详细的多层索引内容可参考课程笔记 15.2。

### 按季度列层级汇总

```python
result = df.groupby(level="季度", axis=1).sum()
```

要点：

- `axis=1` 表示对列方向操作。
- `level="季度"` 表示按列索引中的“季度”层级分组。
- `sum()` 表示汇总求和。
- 结果会把 1、2、3 月横向合并为一季度，把 4、5 月横向合并为二季度。
- 相当于在列方向上完成季度汇总。
