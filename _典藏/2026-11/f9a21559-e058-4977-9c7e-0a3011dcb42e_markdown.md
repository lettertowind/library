## 3. 读取 MySQL 的完整流程

### 3.1 导入所需模块

首先导入 `pandas` 和 `pymysql`：

```python
import pandas as pd
import pymysql
```

说明：

- `pandas` 用于读取和整理数据。
- `pymysql` 用于连接 MySQL 数据库。

### 3.2 建立数据库连接对象

使用 `pymysql.connect()` 建立连接对象。连接对象可以理解为：**登录 MySQL 数据库所需要的一组连接信息**。

示例代码：

```python
conn = pymysql.connect(
    host='localhost',
    user='root',
    password='1234',
    database='test',
    charset='utf8'
)
```

连接参数说明：

| 参数 | 含义 | 视频示例 |
|---|---|---|
| `host` | 主机名称，需要填写自己的 MySQL 主机地址 | `localhost` |
| `user` | 用户名 | `root` |
| `password` | 密码 | `1234` |
| `database` | 数据库名称 | `test` |
| `charset` | 字符编码 | `utf8` |

关键细节：

- `host` 要填写自己的主机名称；视频中数据库建立在本机，因此使用 `localhost`。
- `user` 示例为 `root`。
- `password` 示例为 `1234`，仅用于本机演示，实际使用时应替换为自己的密码。
- `database` 示例为 `test`。
- MySQL 中编码通常写为 `utf8`，不是 `utf-8`。
- 转录中的 `py mysql.content` 对应正确代码为 `pymysql.connect()`。

### 3.3 编写 SQL 查询语句

建立连接后，需要编写要执行的 SQL 查询语句。

示例形式：

```python
sql = "select * from 表名"
```

说明：

- 视频示例中从一张表中查询数据。
- 示例数据涉及“杨过、小龙女”等内容。
- 实际使用时需要将 `表名` 替换为自己的数据库表名。
- 若尚未学习 SQL 基础，视频建议先学习 SQL 基础篇，掌握查询语句。

### 3.4 使用 pandas 读取 MySQL 数据

读取 CSV 文件使用 `pd.read_csv()`，读取 SQL 数据使用 `pd.read_sql()`。

示例代码：

```python
df = pd.read_sql(sql, con=conn)
```

`pd.read_sql()` 的核心参数：

- 第一个参数：`sql`，即要执行的 SQL 查询语句。
- 第二个参数：`con`，即数据库连接对象，此处传入前面创建的 `conn`。

视频中将读取结果赋给一个变量，并打印查看。可写成：

```python
print(df)
```

说明：

- `con` 是关键字参数，等号后接连接对象。
- 连接对象中已经包含了主机、用户名、密码、数据库等信息。
- `read_sql()` 还支持其他参数，例如索引相关设置，与上一节读取文件的知识相近。
- 本课重点掌握：**连接对象 + SQL 语句 + `pd.read_sql()`**。

### 3.5 运行与检查结果

- 视频中右键运行代码，读取过程可能会稍微慢一点。
- 运行成功后，通过打印读取结果变量查看数据。
- 若执行成功，即可在 pandas 中得到来自 MySQL 数据库表的数据。

## 4. 示例完整代码

```python
import pandas as pd
import pymysql

# 建立 MySQL 连接对象
conn = pymysql.connect(
    host='localhost',
    user='root',
    password='1234',
    database='test',
    charset='utf8'
)

# 编写 SQL 查询语句
sql = "select * from 表名"

# 使用 pandas 读取 SQL 查询结果
df = pd.read_sql(sql, con=conn)

# 打印读取结果
print(df)
```

## 5. 关键细节与注意事项

- `pymysql` 必须先安装并导入，否则无法连接 MySQL。
- 连接对象使用 `pymysql.connect()` 创建。
- `host`、`user`、`password`、`database` 需要根据自己的数据库环境填写。
- 本机数据库的 `host` 通常为 `localhost`。
- MySQL 编码参数使用 `charset='utf8'`。
- `pd.read_sql()` 的两个核心参数是：
  - `sql`：SQL 查询语句
  - `con`：数据库连接对象
- `read_csv()` 用于读取 CSV 文件；`read_sql()` 用于读取 SQL 数据库查询结果。
- SQL 查询语句是数据分析中的基础能力，需要重点掌握。
- 视频示例中的密码、数据库名和表名仅作演示，实际使用时应替换为自己的配置。
