## 3. map：针对整列逐元素映射

### 3.1 map 的基本概念

- `map` 针对一整列进行操作。
- 作用是把该列中的值逐个作为参数传入字典或函数中，得到映射后的值。
- 映射结果会按原行位置返回到新列或原列中。
- 也就是说：性别列中凡是“男”的位置返回“先生”，凡是“女”的位置返回“女士”。

### 3.2 字典映射示例：性别转换为称呼

目标：把“男”改成“先生”，把“女”改成“女士”，并新建“称呼”列。

```python
dic = {
    "男": "先生",
    "女": "女士"
}

df["称呼"] = df["性别"].map(dic)
```

说明：

- `df["性别"]` 是 Series，表示性别这一整列。
- `.map(dic)` 会把性别列中的每个值拿到字典中查找对应值。
- 结果写入新列 `df["称呼"]`。
- 运行后，“男”对应“先生”，“女”对应“女士”。

### 3.3 直接覆盖原列

如果不想新建列，也可以直接覆盖原列：

```python
df["性别"] = df["性别"].map(dic)
```

视频中用变量反复赋值举例说明：

```python
a = 1
a = 2
a = 3
print(a)
```

最后输出 `3`，因为取最后一次赋值的结果。类似地，对同一列多次赋值时，最终保留最后一次赋值结果。

### 3.4 函数映射示例

`map` 不仅可以接收字典，也可以接收函数。

```python
def 替换吧(x):
    称呼 = "先生" if x == "男" else "女士"
    return 称呼

df["称呼"] = df["性别"].map(替换吧)
```

说明：

- `x` 接收性别列中的每一个值。
- 使用三目表达式：`"先生" if x == "男" else "女士"`。
- 函数必须有 `return`，返回映射后的称呼。
- 最后通过 `.map(替换吧)` 把函数应用到性别列的每个值上。

等价写法可以理解为：

```python
df["称呼"] = df["性别"].map(lambda x: "先生" if x == "男" else "女士")
```

### 3.5 map 与 replace 的区别

讲师明确对比了 `map` 和 `replace`：

- `map` 针对整列操作。
- `replace` 是针对“替换值”的问题。
- 如果遇见整列整列的操作，可以用 `map`。
- 如果要替换某个具体值，例如整个表里有很多“孙兴华”，现在要把所有“孙兴华”都替换成“新华”，用 `replace` 更方便。
- 用 `map` 做这种全表值替换就不方便。
- 没有一种方法可以把所有情况全部代替，应根据实际需要选择。
- 实际工作中常见组合是 `map`、`apply` 再加 `replace`。

示例场景：

```python
df.replace("孙兴华", "新华")
```

上述代码表达的是全表值替换场景；视频强调这种需求更适合 `replace`。

## 4. apply：针对 Series 或 DataFrame 的灵活函数应用

### 4.1 apply 的两种主要使用方式

`apply` 针对两种对象：

- 对 `Series` 进行数据处理：也就是对一行或一列进行操作。
- 对 `DataFrame` 进行操作：也就是对整个表按行或按列进行操作。

`apply` 的一个重要优势是：可以在一个函数中传入多个参数，这一点非常方便。

### 4.2 Series.apply 示例：修改分数

场景：判卷答案出错或题目出错，需要给每个同学的语文成绩加 5 分。

定义修改分数的函数：

```python
def 修改分数(x, 误差值):
    return x + 误差值
```

说明：

- `x` 将来接收传入的整列数据中的每个值，例如语文成绩。
- `误差值` 是额外传入的参数。
- 函数只负责计算 `x + 误差值`。

对语文列应用：

```python
df["语文"] = df["语文"].apply(修改分数, args=(5,))
```

说明：

- `df["语文"]` 是 Series。
- `.apply(修改分数, args=(5,))` 表示把语文列中的每个值传给 `修改分数` 的 `x`，同时把 `5` 作为 `误差值` 传入。
- `args` 接收的是一个元组。
- 只传一个参数时，必须写成 `(5,)`，逗号不能省；否则不是元组。
- 如果要给每个人减 5 分：

```python
df["语文"] = df["语文"].apply(修改分数, args=(-5,))
```

- 如果要加 3 分：

```python
df["语文"] = df["语文"].apply(修改分数, args=(3,))
```

视频举例查看了语文成绩前几个值，例如 `90、62、68`，加 5 或减 3 后会得到相应变化。核心不是具体数值，而是掌握 `apply` 通过 `args` 传入多个参数的方式。

关键结论：

- 单个参数时，用 `map` 就可以解决。
- 多个参数时，应首选 `apply`。
- `apply` 适合对单行、单列进行函数处理，并能携带额外参数。

### 4.3 DataFrame.apply 与 axis 轴概念

对 DataFrame 使用 `apply` 时，必须理解 `axis`。

视频反复强调：

- 索引 `0、1、2、3...` 管的是“行”，叫行标签。
- 管列的叫列标签。
- 行标签对应零轴，即 `axis=0`。
- 列标签对应一轴，即 `axis=1`。
- “横着手走”是零轴。
- “竖着走”是一轴。
- 从 NumPy 课程到 pandas 课程一直强调轴的问题，不能混淆。

#### 4.3.1 axis=0 示例：按列求和

目标：把语文、数学、英语按列做汇总。

```python
data2 = df[["语文", "数学", "英语"]].apply(sum, axis=0)
```

说明：

- 选出语文、数学、英语三列。
- `.apply(sum, axis=0)` 表示按零轴执行求和。
- 结果是每一列分别做汇总。
- 零轴相加是“一行一行向下加”，不是横向把 `90 + 100 + 10` 这样加。
- 对于语文列，就是第一行、第二行、第三行……逐行向下累加，得到该列汇总。
- 对于数学列、英语列同理。
- `axis=0` 相当于对某个列执行指定函数。
- 具体是求和、求平均还是其他聚合方式，取决于 `apply` 中传入的函数。

#### 4.3.2 axis=1 示例：计算 BMI

BMI 公式：

\[
\mathrm{BMI} = \frac{\text{体重}}{\text{身高}^{2}}
\]

代码中用 `**2` 表示平方。

定义 BMI 函数：

```python
def bmi(data):
    身高 = data["身高"]
    体重 = data["体重"]
    bmi = 体重 / 身高 ** 2
    return bmi
```

对每一行应用：

```python
df["bmi指数"] = df.apply(bmi, axis=1)
```

说明：

- `axis=1` 表示按行执行。
- pandas 默认会把每一行的数据以一个 `Series` 形式传入函数。
- 这个 `Series` 的索引是列名，因此函数中可以用 `data["身高"]`、`data["体重"]` 取值。
- `体重 / 身高 ** 2` 计算该行对应的 BMI。
- 最后 `return bmi` 返回结果。
- `df.apply(bmi, axis=1)` 会把每一行计算出的 BMI 整合起来，赋值给新列 `df["bmi指数"]`。
- 这样就能计算每个人的 BMI 指数。

### 4.4 apply 总结与注意事项

讲师总结 `apply` 时强调：

- 当 `axis=0` 时，相当于对某个列执行指定函数。
  - 例如对语文列、数学列、英语列分别执行汇总函数。
- 当 `axis=1` 时，相当于对每一行执行指定函数。
  - 例如 BMI 示例中，对每一行的身高、体重进行计算。
- 对每个 `Series` 执行的结果，会整合在一起返回。
- 如果想有返回值，定义函数时必须写 `return` 相关结果。
- 如果忘记写 `return`，就无法得到期望的返回结果。
- `DataFrame.apply` 和 `Series.apply` 的原理一致，也都能接收更复杂的参数。
- 如果传入参数较多，实现原理仍然一样。
- 想更详细了解 `apply`，应参考 pandas 官方文档。
- 课堂只能讲一两个例子，pandas 教程所讲内容不到 pandas 的 10%，更多内容需要自学。
- 除了数理统计方面知识，其他方面知识也要自学。

## 5. applymap：对 DataFrame 每个单元格执行函数

`applymap` 的用法相对简单：

- 对 DataFrame 的每个单元格执行指定函数。
- 用途没有 `apply` 广泛，但在某些场合下比较有用。

视频示例：

- 数据二中有 `a、b、c、d、e` 五列。
- 五列中生成了一些随机数字。
- 现在想把每个数字保留指定的小数位数。
- 如果是整数，也显示成带小数点的形式，例如保留三位时显示类似 `.000`。

示例代码：

```python
数据 = 数据.applymap(lambda x: f"{x:.3f}")
```

说明：

- `applymap` 会逐个处理 DataFrame 中的每个单元格。
- `lambda x: f"{x:.3f}"` 是格式化字符串表达式，表示保留三位小数。
- 如果保留两位小数，把 `3` 改成 `2`：

```python
数据 = 数据.applymap(lambda x: f"{x:.2f}")
```

视频说明：

- `applymap` 并不是很常用，所以这里只做简单演示。
- 实际工作中，`map` 和 `apply` 已经足够使用。
- 再加上 `replace`，大多数常见数据处理需求完全可以应对。

## 6. 三个方法对比与使用建议

| 方法 | 主要作用对象 | 典型用途 | 关键点 |
|---|---|---|---|
| `map` | `Series` 整列 | 字典映射、函数映射、整列逐元素转换 | 针对整列操作；适合单列映射；与 `replace` 容易混淆 |
| `apply` | `Series` 或 `DataFrame` | 单行/单列函数处理；DataFrame 按 `axis=0` 或 `axis=1` 计算 | 可传多个参数；`args` 是元组；`axis=0` 按列、`axis=1` 按行；函数需要 `return` |
| `applymap` | `DataFrame` 每个单元格 | 对整张表所有单元格统一格式化或处理 | 逐单元格执行；用途不如 `apply` 广泛；某些格式化场景方便 |
| `replace` | `Series` / `DataFrame` 中的值 | 替换具体值，例如全表把“孙兴华”替换成“新华” | 针对值替换；整表批量替换具体值时比 `map` 方便 |

选择建议：

- 需要按整列做映射转换时，用 `map`。
- 需要给函数传多个参数，或需要对整行/整列做计算时，用 `apply`。
- 需要对 DataFrame 每个单元格统一处理时，用 `applymap`。
- 需要替换具体值时，用 `replace`。
- 没有一种方法能完全代替其他方法，应根据实际需求选择。
- 实际工作中 `map + apply + replace` 已经能覆盖大多数常见操作。
