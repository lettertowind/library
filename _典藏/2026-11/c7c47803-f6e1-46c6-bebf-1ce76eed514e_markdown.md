# Pandas 连接查询之 `merge` 详细笔记

## 1. 课程定位与前置知识

- 本节主题是 Pandas 中的连接查询：`merge`。视频开头转录中的“range”应为识别误差或口误，实际讲解的是 `merge`。
- `merge` 是 Pandas 中最常用的表连接方法之一，用法与 SQL 中的 `JOIN` 连接查询大同小异。
- 课程默认学习者已经掌握 SQL 查询篇基础知识，理解以下连接概念：
  - 内连接：`inner`
  - 左连接：`left`
  - 右连接：`right`
  - 全外连接：`outer`
- 课程观点：在大数据分析中，可以对 Excel 一无所知，但不能不学 SQL。后期涉及数据库编程、Python 与 SQL 结合时，还会继续讲 SQL 高级篇；当前只需掌握 SQL 查询基础即可。
- `merge` 操作的两个表本质上都是 DataFrame，它们根据一些共有列连接起来。`merge` 可以理解为把两个表合并在一起。
- 内连接在视频中被类比为 Excel 的 `VLOOKUP`。实际场景中共有列通常是 `id`、索引列、序号等。
- 连接方式很多，`merge` 默认是内连接；其他连接方式需要显式指定。

## 2. 四种连接方式概念

| 连接方式 | 含义 | `merge` 参数 | 结果特点 |
|---|---|---|---|
| 内连接 | 两个表相交的部分，即“你也有、我也有” | `how='inner'` | 只保留连接键在两表中都能匹配的行 |
| 左连接 | 以左表为标准，保留左表全部记录，并连接右表匹配数据 | `how='left'` | 左表全保留，右表无匹配处为 `NaN` |
| 右连接 | 以右表为标准，保留右表全部记录，并连接左表匹配数据 | `how='right'` | 右表全保留，左表无匹配处为 `NaN` |
| 全外连接 | 两张表都保留，相当于两个表的联合 | `how='outer'` | 左右表所有记录都保留，无匹配处为 `NaN` |

- 左连接可以理解为 `VLOOKUP` 的思路：谁在左边，就以谁为标准。
- 右连接与左连接相反，以右表为基准。
- 全外连接会把两张表的数据都合并进来，没有匹配的地方显示为空值 `NaN`。

## 3. 示例一：单键连接

### 3.1 导入库与构造数据

- 导入模块：
  - `import pandas as pd`
  - `import numpy as np`
- 导入 NumPy 是为了使用 `np.arange` 生成序列。视频中提到随机数，但示例主要使用 `arange`。
- 构造数据一 `data1`：
  - 使用 `pd.DataFrame` 和字典构造。
  - `姓名` 列包含重复值，例如：叶问、李小龙、孙兴华、李小龙、叶问、叶问。
  - `出手次数一` 使用 `np.arange` 生成 0 到 5 的序列。
  - 数据一体现了一对多、多对一关系，因此连接时可能出现重复匹配。
- 构造数据二 `data2`：
  - `姓名` 列包含：黄飞鸿、孙兴华、李小龙等。
  - `出手次数二` 为 1、2、3 等数值。
- 视频通过 `print` 打印数据一、数据二，并用星号分隔线区分输出内容。

示例数据大致如下：

- 数据一：
  - 姓名：叶问、李小龙、孙兴华、李小龙、叶问、叶问
  - 出手次数一：0、1、2、3、4、5
- 数据二：
  - 姓名：黄飞鸿、孙兴华、李小龙
  - 出手次数二：1、2、3

> 视频转录中部分姓名如“孙金发”“孙一华”应为识别误差，按上下文应指“孙兴华”。

### 3.2 默认内连接

调用方式：

- `pd.merge(data1, data2)`
- 默认使用两个 DataFrame 的共有列进行连接。
- 默认连接方式是内连接 `inner`。

结果特点：

- 只保留两个表中都存在的姓名。
- 叶问只出现在数据一，不出现。
- 黄飞鸿只出现在数据二，不出现。
- 李小龙和孙兴华在两个表中都存在，因此保留。
- 数据一中的李小龙出现多次，出手次数一分别为 1、3；数据二中的李小龙匹配后，会按匹配关系展开。
- 孙兴华在数据一中的出手次数一为 2，在数据二中的出手次数二为 2，形成匹配。
- 视频总结：默认内连接就是“你有我也有”，即两个表相交的部分。

显式写法：

- `pd.merge(data1, data2, on='姓名', how='inner')`
- `on='姓名'`：指定用 `姓名` 列连接。
- `how='inner'`：指定连接方式为内连接。
- 显式写法和默认写法结果一致。
- 内连接时，`how='inner'` 可以省略；`on` 也可以在同名列情况下由 Pandas 自动识别，但显式写更清楚。

### 3.3 左连接

调用方式：

- `pd.merge(data1, data2, on='姓名', how='left')`

结果特点：

- 以左表 `data1` 为标准，保留左表全部姓名。
- 左表中的叶问、李小龙、孙兴华、李小龙、叶问、叶问都会保留。
- 右表中能匹配到的数据被连接过来。
- 右表没有匹配的地方显示为 `NaN`。
- 视频解释：左连接类似 `VLOOKUP`，从右表把需要的数据“V”过来。
- 若左表某个姓名在右表没有数据，例如叶问，则对应的出手次数二等列为空值 `NaN`。

### 3.4 右连接

调用方式：

- `pd.merge(data1, data2, on='姓名', how='right')`

结果特点：

- 以右表 `data2` 为基准。
- 右表中的黄飞鸿、孙兴华、李小龙等都会保留。
- 左表中能匹配的数据被连接过来。
- 左表没有匹配的地方显示为 `NaN`。
- 视频强调：左连接和右连接的区别就是“以谁为基准”。

### 3.5 全外连接

调用方式：

- `pd.merge(data1, data2, on='姓名', how='outer')`

结果特点：

- 两张表的所有数据都保留。
- 首先保留左表全部姓名，再把右表中左表没有的姓名也合并进来。
- 例如黄飞鸿只出现在右表，也会出现在全外连接结果中。
- 无匹配的一侧显示为 `NaN`。
- 视频总结：全外连接相当于两张表的一个联合。

## 4. 示例二：基于多个键连接

### 4.1 示例数据

清空前面的数据后，视频构造了两个新表。

数据一：

| 姓名 | 班级 | 分数 |
|---|---|---|
| 张三 | 一班 | 10 |
| 张三 | 二班 | 20 |
| 王五 | 一班 | 30 |

数据二：

| 姓名 | 班级 | 分数 |
|---|---|---|
| 张三 | 一班 | 40 |
| 张三 | 一班 | 50 |
| 王五 | 一班 | 60 |
| 王五 | 二班 | 70 |

- 两个表都有 `姓名`、`班级`、`分数` 列。
- 需求是同时用 `姓名` 和 `班级` 两个条件进行连接，而不是只用 `姓名`。
- 例如：用数据一的“张三 + 一班”去匹配数据二的“张三 + 一班”。

### 4.2 多键内连接

调用方式：

- `pd.merge(data1, data2, on=['姓名', '班级'])`
- `on` 参数可以传列表，表示基于多个键连接。
- 不写 `how` 时默认仍是内连接。

结果特点：

- 只有 `姓名` 和 `班级` 同时匹配的行才会保留。
- 数据一中的“张三 + 一班”与数据二中的“张三 + 一班”匹配。
- 数据二中有两个“张三 + 一班”，因此结果中会出现两行张三一班。
- 数据一中的“王五 + 一班”与数据二中的“王五 + 一班”匹配。
- 数据一中的“张三 + 二班”在数据二中没有同时匹配的“张三 + 二班”，默认内连接下不显示。
- 两个表都有 `分数` 列，Pandas 会自动给同名列加后缀：
  - `分数_x`：来自数据一
  - `分数_y`：来自数据二

视频解释：

- “张三一班”两个表里都有，所以匹配出来。
- “王五一班”两个表里也都有，所以匹配出来。
- 表二里有两个“张三一班”，所以结果中对应写出两行。
- `分数_x` 是数据一里的分数，`分数_y` 是数据二里的分数。

### 4.3 多键全外连接

调用方式：

- `pd.merge(data1, data2, on=['姓名', '班级'], how='outer')`

结果特点：

- 在多键连接基础上改为全外连接。
- 没有匹配的地方显示为空值。
- 左连接、右连接同理，只需把 `how` 改为 `left` 或 `right`。
- 视频总结：多键连接只要把 `on` 后面的单个字段改成列表即可。

## 5. 示例三：基于索引连接

### 5.1 示例数据

删除前面的数据后，重新构造两个表。

数据一：

| 姓名 | 次数 |
|---|---|
| 张三 | 0 |
| 李四 | 1 |
| 王五 | 2 |
| 张三 | 3 |
| 李四 | 4 |

- `姓名` 列包含张三、李四、王五、张三、李四。
- `次数` 使用 `np.arange(5)` 生成 0 到 4。
- 数据一默认索引为 0 到 4。

数据二：

| index | 数据 |
|---|---|
| 张三 | 10 |
| 李四 | 20 |

- 数据二使用 `张三`、`李四` 作为索引列。
- 数据二有一列数据，值为 10、20。

### 5.2 用左表列连接右表索引

需求：

- 数据一的姓名在普通列 `姓名` 中。
- 数据二的姓名在索引 `index` 中。
- 希望用数据一的 `姓名` 列去连接数据二的索引列。

调用方式：

- `pd.merge(data1, data2, left_on='姓名', right_index=True)`

参数说明：

- `left_on='姓名'`：指定左表使用 `姓名` 列作为连接键。
- `right_index=True`：指定右表使用索引作为连接键。
- `right_index` 默认是 `False`，需要手工改为 `True`。
- 不写 `how` 时默认仍是内连接。

结果特点：

- 用左表 `姓名` 列匹配右表索引。
- 数据一中的张三、李四可以匹配到数据二索引中的张三、李四。
- 王五在右表索引中没有匹配，默认内连接下不显示。
- 如果左表有重复姓名，匹配时也会按匹配关系展开。
- 视频强调：如果右表本来就用姓名作为索引，不必先把索引改回普通列，直接通过 `right_index=True` 连接即可。
- 对大数据而言，改索引可能非常不方便，因此这种索引连接方式很实用。

### 5.3 索引连接的其他连接方式

- 默认仍是内连接。
- 可以改为全外连接：
  - `pd.merge(data1, data2, left_on='姓名', right_index=True, how='outer')`
- 改为左连接、右连接同理，只需修改 `how` 参数。
- 视频提醒：默认内连接可以不写 `how`；其他连接方式一定要手工写上 `how`。

## 6. `merge` 关键参数与注意事项

| 参数/现象 | 作用与说明 |
|---|---|
| `pd.merge(left, right)` | 合并两个 DataFrame，默认内连接 |
| `on` | 指定两个表同名的连接列，可传单列名或列名列表 |
| `on=['姓名', '班级']` | 基于多个键连接 |
| `how='inner'` | 内连接，默认值，可省略 |
| `how='left'` | 左连接，以左表为基准 |
| `how='right'` | 右连接，以右表为基准 |
| `how='outer'` | 全外连接，两张表都保留 |
| `left_on` | 指定左表用于连接的列 |
| `right_on` | 指定右表用于连接的列，视频中未展开 |
| `left_index=True` | 使用左表索引作为连接键，视频中未展开 |
| `right_index=True` | 使用右表索引作为连接键，默认 `False` |
| `_x` / `_y` 后缀 | 两个表有同名列时自动添加，`_x` 通常来自左表，`_y` 通常来自右表 |
| `NaN` | 连接后无匹配数据时的空值表示 |
| 多对多匹配 | 连接键重复时，结果会按匹配组合展开为多行 |
| 高级用法 | `merge` 还有很多高级用法，视频表示后续用到时再介绍 |

## 7. 总结

- 本节学习了 Pandas 中用于连接查询的 `merge`，其思想与 SQL 的 `JOIN` 基本一致。
- 四种连接方式：
  - 内连接 `inner`：两表交集，默认方式。
  - 左连接 `left`：以左表为准，类似 `VLOOKUP`。
  - 右连接 `right`：以右表为准。
  - 全外连接 `outer`：两表联合，都保留。
- 单键连接使用 `on='列名'`。
- 多键连接使用 `on=['列名1', '列名2']`。
- 用左表列连接右表索引时使用 `left_on='列名', right_index=True`。
- 默认是内连接，其他连接方式必须显式指定 `how`。
- 无匹配数据会显示为 `NaN`；同名列会自动加 `_x`、`_y` 后缀。
- `merge` 是数据分析中非常常用的表连接工具，后续还会涉及更多高级用法。
