# Numpy 神奇索引（Fancy Indexing）学习笔记

## 1. 概念与核心规则
- 神奇索引也叫花式索引（Fancy Indexing），是指使用**整数数组**进行数据索引，而不是只使用单个整数或连续切片。
- 作用：按照指定的整数下标取出原数组中对应位置的数据，返回一组数。
- 一维数组：`a[[i1, i2, i3]]` 表示取出下标 `i1、i2、i3` 对应的元素。
- 二维数组：
  - 只给一个整数数组时，默认按“行”取数，返回指定的整行。
  - 给两个整数数组时，一个表示行索引，一个表示列索引，按位置一一配对取元素。
- 索引从 0 开始。
- 神奇索引不要求下标连续，可以任意指定，适合从数组中“点菜式”抽取数据。
- 返回结果的形状与索引数组的形状有关，视频中主要演示了一维数组和二维数组场景。

## 2. 一维数组中的神奇索引
- 示例数组可理解为：

`a = np.array([3, 6, 7, 9, 5, 2, 7])`

其下标与元素对应关系为：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 元素 | 3 | 6 | 7 | 9 | 5 | 2 | 7 |

- 使用整数数组作为索引：

`index = [2, 3, 5]`

- 执行：

`a[index]` 或 `a[[2, 3, 5]]`

- 取出的是下标 2、3、5 对应位置的元素，即：

`[7, 9, 2]`

- 视频中口语提到“235”，核心含义是使用整数数组 `[2, 3, 5]` 指定要取哪些下标；实际返回的是这些下标位置上的数组元素。
- 结论：神奇索引和切片不同，切片通常取连续区间，而神奇索引可以按照任意整数下标数组取数。

## 3. 二维数组：单个索引数组按行取
- 先生成 0 到 35 共 36 个数，再转换为 9 行 4 列的二维数组：

`b = np.arange(36).reshape(9, 4)`

- 使用整数数组索引行：

`b[[4, 3, 0, 6]]`

- 表示取出第 4 行、第 3 行、第 0 行、第 6 行。
- 对应的行数据为：
  - 第 4 行：`[16, 17, 18, 19]`
  - 第 3 行：`[12, 13, 14, 15]`
  - 第 0 行：`[0, 1, 2, 3]`
  - 第 6 行：`[24, 25, 26, 27]`
- 结论：二维数组中只给一个整数数组作为索引时，默认取的是整行；索引值表示第几行，并且从 0 开始计数。

## 4. 二维数组：两个索引数组按坐标配对取
- 示例数组为 8 行 4 列：

`c = np.arange(32).reshape(8, 4)`

- 行索引数组：

`row_idx = [1, 5, 7, 2]`

- 列索引数组：

`col_idx = [0, 3, 1, 2]`

- 执行：

`c[[1, 5, 7, 2], [0, 3, 1, 2]]`

- 取数规则是行、列索引逐一配对：
  - 第 1 行第 0 列，取值为 `4`
  - 第 5 行第 3 列，取值为 `23`
  - 第 7 行第 1 列，取值为 `29`
  - 第 2 行第 2 列，取值为 `10`
- 因此结果为：

`[4, 23, 29, 10]`

- 这里不是行索引和列索引做笛卡尔积，而是按位置一一配对。
- 课程反复强调：二维索引中，逗号前是行，逗号后是列。

## 5. 取所有行的指定列
- 仍然使用 9 行 4 列的数组：

`d = np.arange(36).reshape(9, 4)`

- 如果要取所有行，并只取第 1 列和第 2 列，可以写：

`d[:, [1, 2]]`

也可以利用连续切片写为：

`d[:, 1:3]`

- 解释：
  - 逗号前的 `:` 表示取所有行。
  - 逗号后的 `[1, 2]` 表示取第 1 列和第 2 列。
  - 第 0 列不取。
- 结果相当于保留所有行中的第 1、2 列，例如第一行取 `[1, 2]`，第二行取 `[5, 6]`，依次类推。
- 该用法常用于从二维数组或表格数据中抽取指定列子集。

## 6. 一维数组配合二维索引数组的返回形状
- 先生成 0 到 9 的一维数组：

`e = np.arange(10)`

- 再定义一个二维整数索引数组，例如：

`idx = np.array([[0, 1], [2, 3]])`

- 执行：

`e[idx]`

- 返回结果的形状与索引数组 `idx` 一致，仍然是二维结构。
- 由于示例原数组 `e` 本身就是 0 到 9，所以取出的结果看起来可能与索引数组相同，容易让人误以为“取出了索引自身”。
- 关键理解：
  - 一维数组没有二维意义上的“行”和“列”坐标。
  - 使用二维索引数组时，Numpy 会按照索引数组的形状组织返回结果。
  - 返回的数据仍然来自原数组对应下标位置，而不是凭空返回索引数组。
- 记忆要点：如果对一维数组使用多维整数索引数组，返回值会按索引数组的形状组织，不能直接套用二维数组“行列坐标”的理解方式。

## 7. 拓展示例：取数组中最大的前 n 个元素
- 先生成 10 个 1 到 100 之间的随机整数：

`arr = np.random.randint(1, 100, size=10)`

- 使用 `argsort()` 获取排序后的下标：

`idx = arr.argsort()`

- `argsort()` 返回的是“排序后的下标”，默认按升序排列，并不会直接返回排序后的值。
- 因为默认升序，所以最大值会对应排序后下标数组的末尾部分。
- 取最大的 3 个元素时，可以从倒数第 3 个下标开始取到末尾：

`top_idx = idx[-3:]`

- 再通过神奇索引取出原数组中的最大值：

`arr[top_idx]`

- 视频示例中取出的最大三个数为：

`85、89、91`

- 整体思路：
  - 先用 `argsort()` 得到排序后的下标。
  - 再用 `[-n:]` 取出最大的 n 个元素对应的下标。
  - 最后用神奇索引从原数组中取出这些下标位置的值。
- 该部分属于拓展知识，涉及此前尚未系统学习的方法，不要求完全掌握，但有助于理解神奇索引的实际应用。

## 8. 课堂小技巧
- 打印分隔横线可以使用字符串乘法：

`print('-' * 30)`

- 在 Python 中，字符串乘以整数表示重复该字符串，因此 `'-' * 30` 会生成 30 个横线，用于分隔输出结果。

## 9. 易错点与总结
- 神奇索引使用整数数组进行索引，不是连续切片。
- 一维数组：`a[[2, 3, 5]]` 取出下标 2、3、5 对应的元素。
- 二维数组只给一个索引数组时，默认取整行。
- 二维数组给两个索引数组时，一个表示行，一个表示列，按位置一一配对，不是笛卡尔积。
- 二维索引中要牢记：逗号前是行，逗号后是列。
- 取所有行的指定列可以使用 `数组[:, [列索引]]`。
- 使用 `argsort()` 配合 `[-n:]` 可以取出最大的前 n 个元素对应的下标，再用神奇索引取出原值。
- 一维数组使用二维索引数组时，返回结果按索引数组形状组织，不要误认为一定是在按二维行列坐标取数。
- 所有索引均从 0 开始计数。
