# Numpy 多维数组学习笔记

## 1. 本课主题与前置知识

- 本课主题：**多维数组**，重点理解一维数组、二维数组、三维数组及更高维数组的概念与创建方式。
- 前置要求：需要具备 Python 基础；视频中强调，如果没有学过基础课程，本课内容可能听不懂。
- 术语说明：
  - Python 相关书籍中常称为“**下标**”或“**索引**”。
  - 数据分析类书籍中更多称为“**索引**”。
  - 两者叫法不同，但本质相同，都是指数组元素对应的位置编号。

## 2. 一维数组回顾

- 一维数组是最基础的数组形式，由一组元素按顺序排列构成。
- 一维数组的特点：
  - 每个元素都有对应的下标/索引。
  - 下标通常从 `0` 开始。
  - 例如视频中用类似 `0, 1, 2, 3, 4, 5, ...` 的序列说明一维数组，元素分别对应 `0, 1, 2, ...` 等索引。
- 创建方式示例：`a = np.array([...])`。
- 打印一维数组时，可以看到数组中的每个数字及其排列顺序。

## 3. 二维数组

### 3.1 概念

- 二维数组常被理解为“行列式”或“矩阵”。
- 本质定义：**以数组作为数组元素的数组**，即“数组中的数组”。
- 一维数组中的元素通常是数字；二维数组中的元素可以是一维数组。
- 视频中用 `520`、`1314` 等一维数组元素举例，说明二维数组可以把一维数组作为元素组织起来。

### 3.2 创建方式

- 一维数组创建方式：`np.array([...])`。
- 二维数组创建方式：在 `np.array` 中传入多个一维数组，例如：
  - `np.array([[1, 2, 3], [4, 5, 6]])`
- 视频中演示的二维数组 `b` 为 **2 行 3 列**，即形状为 `(2, 3)`。

### 3.3 二维数组属性

视频中对二维数组 `b` 进行了属性查看：

- 形状 `shape`：`(2, 3)`，表示 2 行 3 列。
- 维度 `ndim`：`2`，表示二维数组。
- 元素个数 `size`：`6`，因为 `2 × 3 = 6`。
- 数据类型 `dtype`：视频示例中显示为 `int32`，即 32 位整型。

### 3.4 使用 ones、zeros、full 创建二维数组

视频回顾并扩展了上一节课的 `ones`、`zeros`、`full` 方法：

- `np.ones((3, 3))`：创建 3 行 3 列、元素全为 `1` 的二维数组。
- `np.zeros((3, 3))`：创建 3 行 3 列、元素全为 `0` 的二维数组。
- `np.full((3, 3), 520)`：创建 3 行 3 列、所有元素都填充为指定值 `520` 的二维数组。

注意：

- 创建形状时应传入元组，例如 `(3, 3)`。
- `np.full` 的第二个参数用于指定要填充的数值。

## 4. 三维数组与多维数组

### 4.1 概念

- 三维数组可以理解为：**由多块二维数组组成**。
- 理解方式：
  - 先看它由多少块二维数组组成。
  - 再看每一块二维数组是几行几列。
- 视频中用“几块几行几列”的方式帮助理解三维数组。
- 更高维数组可以在此基础上继续扩展。

### 4.2 创建三维数组

使用 `np.ones` 创建三维数组示例：

- `np.ones((2, 3, 3))`
  - 表示创建 **2 块** 二维数组。
  - 每一块都是 **3 行 3 列**。
  - 整体是一个三维数组。

视频中打印后可以看到两块 `3 × 3` 的数组。

### 4.3 三维数组属性

对 `np.ones((2, 3, 3))` 创建的数组进行查看：

- 形状 `shape`：`(2, 3, 3)`。
- 维度 `ndim`：`3`，表示三维数组。
- 元素个数 `size`：
  - 计算公式为：块数 × 行数 × 列数。
  - 即 `2 × 3 × 3 = 18`。
  - 用 LaTeX 表示：`\text{size} = 2 \times 3 \times 3 = 18`。
- 数据类型 `dtype`：
  - 视频中 `np.ones` 和 `np.zeros` 创建的多维数组显示为 `float64`。
  - 即使数组元素看起来是 `0` 或 `1`，默认也可能显示为浮点型。
  - 视频指出可以手动指定数据类型；实际使用中可通过 `dtype` 参数指定，例如 `dtype=int`。

### 4.4 多维数组元素数计算

- 元素总数为各维度长度的乘积。
- 三维数组：`size = 块数 × 行数 × 列数`。
- 更高维数组同理：`size = d_1 \times d_2 \times \cdots \times d_n`。

## 5. 基于现有数组形状创建：ones_like、zeros_like、full_like

### 5.1 作用

`ones_like`、`zeros_like`、`full_like` 的作用是：

- 根据已有数组的形状创建新数组。
- **不改变原数组形状**。
- 仅将新数组中的元素填充为指定内容。

### 5.2 示例说明

视频中先创建一个二维数组 `a`，形状为 2 行 3 列。然后用它演示 `_like` 系列方法。

- `b = np.ones_like(a)`
  - 创建一个与 `a` 形状相同的数组。
  - 新数组的所有元素都填充为 `1`。
  - 如果 `a` 是 2 行 3 列，则 `b` 也是 2 行 3 列，但元素全为 `1`。

- `np.zeros_like(a)`
  - 创建一个与 `a` 形状相同的数组。
  - 所有元素都填充为 `0`。

- `np.full_like(a, 520)`
  - 创建一个与 `a` 形状相同的数组。
  - 所有元素都填充为指定值 `520`。
  - 语法重点：`full_like` 后面需要加逗号，再写上要填充的数字。

### 5.3 与 ones、zeros、full 的区别

- `np.ones((2, 3))`、`np.zeros((2, 3))`、`np.full((2, 3), 520)`：需要手动指定形状。
- `np.ones_like(a)`、`np.zeros_like(a)`、`np.full_like(a, 520)`：根据已有数组 `a` 的形状自动创建。
- 视频演示时曾出现打印变量错误：原本想打印 `b`，却打印了 `a`；需要注意打印的是新创建的数组。
- 代码中也不要漏写 `np` 前缀，例如应写 `np.ones_like(a)`。

## 6. Numpy 中的随机数：np.random

### 6.1 基本说明

- 以前使用 Python 标准库随机数时，通常需要 `import random`。
- Numpy 中也有自己的随机数模块：`np.random`。
- 视频指出 Numpy 的随机数功能比标准 `random` 更强大。
- 使用 Numpy 随机数时，不需要再导入标准 `random` 模块，直接使用 `np.random` 即可。
- 本节先做了解，后续会专门讲解随机数。

### 6.2 np.random.rand 的用法

视频演示了 `np.random.rand` 根据参数个数生成不同维度的数组：

- `np.random.rand()`
  - 不传入参数。
  - 生成一个随机小数。

- `np.random.rand(3)`
  - 传入一个数字。
  - 生成包含 3 个随机数的一维数组。

- `np.random.rand(2, 3)`
  - 传入两个数字。
  - 生成二维数组。
  - 视频中演示为 2 行 3 列的随机数数组。

- `np.random.rand(2, 3, 3)`
  - 传入三个数字。
  - 生成三维数组。
  - 表示 2 块 3 行 3 列的随机数数组。

规律总结：

- 参数个数决定生成数组的维度。
- 不传参数：单个随机数。
- 传 1 个参数：一维数组。
- 传 2 个参数：二维数组。
- 传 3 个参数：三维数组。
- 随机数默认通常为浮点型。

## 8. 关键结论与易错点

- 一维数组的每个元素都有下标/索引，通常从 `0` 开始。
- “下标”和“索引”是不同教材中的不同叫法，本质相同。
- 二维数组本质是“数组中的数组”，可以理解为矩阵或行列式。
- 三维数组由多块二维数组组成，理解方式为“几块 × 几行 × 几列”。
- 数组元素总数等于各维度长度的乘积，例如 `2 × 3 × 3 = 18`。
- `ones`、`zeros` 创建数组时，即使元素显示为 `0` 或 `1`，默认数据类型也可能是 `float64`；可以手动指定数据类型。
- `ones_like`、`zeros_like`、`full_like` 不改变原数组形状，只根据其形状生成新数组并填充。
- `full_like` 需要传入第二个参数指定填充值，例如 `np.full_like(a, 520)`。
- Numpy 中可直接使用 `np.random` 生成随机数，不必再导入标准 `random` 模块。
- `np.random.rand` 的参数个数决定数组维度：不传参数为单个数，传一个参数为一维，传两个参数为二维，传三个参数为三维。
