# p25 S02E10 各种数据自动填充学习笔记

## 一、本节目标与自动填充概念

- 本节主题：使用 `pandas` 实现类似 Excel 的“自动填充”。
- 自动填充的直观含义：
  - 数字序列：在 Excel 中输入 `1,2,3` 后向下拖动，自动生成连续序号。
  - 文本循环：输入“男、女”后向下拖动，生成“男、女、男、女……”循环。
  - 日期序列：输入 `2020-05-01` 后向下拖动，日期按天递增。
- 本节先用 Excel 文件讲解复杂场景，再将方法迁移到 `CSV` 大数据文件。
- 涉及文件：
  - `自动填充.xlsx`
  - `自动填充.csv`
- 重要观点：
  - 使用 `pandas` 操作 Excel 相对麻烦：可能存在空行、空列、表头位置不固定等问题。
  - 操作 `CSV` 相对简单：通常没有空行空列，表头和数据从文件开头开始。
  - 实际工作中，大数据常用 `CSV` 或 `TXT`，因为几个 GB 的 Excel 文件很难直接打开。

## 二、Excel 中自动填充的直观示例

- 数字填充：
  - 在 Excel 中输入 `1,2,3`，下拉后自动生成后续数字。
- 文本填充：
  - 输入“男、女”，下拉后生成“男、女、男、女……”的循环。
- 日期填充：
  - 输入日期，例如 `2020-05-01`，下拉后日期自动递增。
- 本节任务：在 `pandas` 中复现这些自动填充操作，并处理 Excel 中空行、空列造成的数据读取问题。

## 三、使用 pandas 读取带空行空列的 Excel

- 首先导入 `pandas`：
  - `import pandas as pd`
- 设置 Excel 文件路径：
  - `path = 'C:/.../自动填充.xlsx'`
- 最初直接读取：
  - `data = pd.read_excel(path)`
- 观察读取结果：
  - Excel 上方存在空行，左侧存在空列。
  - 直接读取后，空白行列会被读入，数据表中出现 `NaN`，表头位置也不正确。
- 需要回顾前面笔记中“从文件开始处跳过几行或几列”的知识：
  - `skiprows`：跳过指定行数。
  - `usecols`：选择指定列区域，写法与 Excel 类似，例如 `F:I`。
- 行号从 `0` 开始计数，需要注意“行索引”和“Excel 行号”的差别：
  - 视频中最终使用 `skiprows=8`。
  - 原因：前面存在空行和列名行，数据实际从第 9 行开始；如果写 `skiprows=7`，会把列名行当成数据，导致“姓名”等表头出现在数据中，不正确。
  - 需要把列名行正确保留为列名，因此跳过前 8 行。
- 列选择：
  - 只保留 `F` 到 `I` 列，使用 `usecols='F:I'`。
- 读取代码形式：
  - `data = pd.read_excel(path, skiprows=8, usecols='F:I')`
- 运行后：
  - 表格结构恢复正常。
  - 空单元格显示为 `NaN`，后续需要进行自动填充。
- 参数总结：
  - `skiprows=8`：跳过前 8 行。
  - `usecols='F:I'`：只读取 Excel 中 F 到 I 列的区域。

## 四、填充序号列

- 读取后的数据索引为 `0,1,2,...`。
- 目标是将“序号”列填充为 `1,2,3,...`。
- 可以使用 `for` 循环遍历数据索引：
  - `for i in data.index:`
- `DataFrame.at` 方法：
  - 作用：获取或设置某个位置的值。
  - `DataFrame` 用法为 `data.at[行索引, 列名]`。
  - 视频中先切出“序号”这一列，再对 `Series` 使用 `.at[i]`，只按行索引定位。
- 填充逻辑：
  - 原始索引为 `i`，目标序号为 `i + 1`。
  - 第一次 `i=0`，填入 `1`。
  - 第二次 `i=1`，填入 `2`。
  - 第三次 `i=2`，填入 `3`。
- 代码逻辑示例：
  - `for i in data.index:`
  - `    data['序号'].at[i] = i + 1`
- 运行后序号显示为 `1.0,2.0,3.0`，变成浮点型。
- 虽然业务上希望是整数，但在自动填充场景中不能简单设置为 `int`，否则后续操作可能报错。
- 关键原则：
  - 做自动填充时，先把相关列统一设置为字符型 `str`。
  - 无论填充序号、性别还是日期，只要涉及填充，都应先把相关列设置为字符串类型，避免类型错误。
- 在读取时通过 `dtype` 指定类型：
  - `dtype={'序号': str, '性别': str, '日期': str}`
- 读取代码可扩展为：
  - `data = pd.read_excel(path, skiprows=8, usecols='F:I', dtype={'序号': str, '性别': str, '日期': str})`
- 设置字符型后重新运行：
  - 序号显示为 `1,2,3`，不再是 `1.0,2.0,3.0`。
  - 后续进行性别判断、日期填充时不会因类型问题报错。

## 五、填充性别列：男、女循环

- 目标：按照行索引生成“男、女、男、女……”循环。
- 观察规律：
  - 行索引 `0`：男
  - 行索引 `1`：女
  - 行索引 `2`：男
  - 行索引 `3`：女
- 数学规律为奇偶判断：
  - 当 \( i \% 2 = 0 \) 时，填入“男”。
  - 当 \( i \% 2 \ne 0 \) 时，填入“女”。
- 可以使用 Python 三目运算：
  - `c = a if a > b else b`
  - 条件成立返回前面的值，否则返回后面的值。
- 视频中先取出“性别”这一列再操作：
  - 不直接在整张表上反复修改，而是先取出一列操作，可以节省内存。
- 填充代码逻辑：
  - `for i in data.index:`
  - `    data['性别'].at[i] = '男' if i % 2 == 0 else '女'`
- 运行结果：
  - 性别列自动填充为“男、女、男”。
  - 如果数据有 100 行、1 万行、10 万行甚至 1 亿行，同样可以按此逻辑填充。

## 六、日期填充基础：datetime 模块

- 日期填充涉及 Python 的 `datetime` 模块。
- Python 中常见时间相关模块：
  - `time` 模块：通过调用 C 库实现，部分方法在某些平台上可能不可用；大部分接口与 C 标准库 `time.h` 基本一致。
  - `datetime` 模块：接口更直观、易用，功能更强大。
- 本节重点使用 `datetime` 中的两个类：
  - `datetime.date`：表示日期，常用属性为 `year`、`month`、`day`，即年、月、日。
  - `datetime.timedelta`：表示两个日期或时间之间的间隔，可精确到微秒。
- `timedelta` 常用参数：
  - `days`：天
  - `seconds`：秒
  - `microseconds`：微秒
  - `milliseconds`：毫秒
  - `minutes`：分钟
  - `hours`：小时
  - `weeks`：周
- 重要限制：
  - `timedelta` 没有“月”和“年”参数。
  - 因此加天、秒、微秒、毫秒、分钟、小时、周可以直接使用 `timedelta`。
  - 加年、加月需要额外算法，尤其是加月比较麻烦。
- 导入方式示例：
  - `import datetime as 日期模块`
- 建立起始日期：
  - `起始日期 = 日期模块.date(2020, 5, 26)`
- 日期加天：
  - \( \text{新日期} = \text{起始日期} + \text{timedelta}(days=i) \)
  - 代码逻辑：
    - `data['日期'].at[i] = 起始日期 + 日期模块.timedelta(days=i)`
- 当 `i=0,1,2` 时，结果为：
  - `2020-05-26`
  - `2020-05-27`
  - `2020-05-28`
- 日期加年：
  - 通过 `date` 重新构造日期：
    - \( \text{date}(\text{起始日期}.year + i, \text{起始日期}.month, \text{起始日期}.day) \)
  - 代码逻辑：
    - `data['日期'].at[i] = 日期模块.date(起始日期.year + i, 起始日期.month, 起始日期.day)`
  - 当 `i=0,1,2` 时，结果为：
    - `2020`
    - `2021`
    - `2022`
- 注意：
  - 自动填充时，`for` 循环、`if` 判断等 Python 语法后面必须有冒号。
  - 不需要的多余赋值应注释掉，避免后一次赋值覆盖前一次结果或引发错误。

## 七、累加月份算法

- 需求：按月份自动递增，并处理 12 月进位到下一年。
- 例如从 `2020-05-26` 开始，连续填充月份，应得到：
  - `2020-05-26`
  - `2020-06-26`
  - `2020-07-26`
- 由于 `timedelta` 不支持“月”，需要自己实现“累加月”函数。
- 定义函数：
  - `def 累加月(日期, 月份):`
- 核心思路：
  - 每满 12 个月，年份进 1。
  - 月份对 12 取余，得到剩余月份。
  - 如果月份加完后等于 12，则不需要再进位。
  - 如果月份加完后小于 12，则整除 12 得 0，年份不变。
  - 如果月份加完后大于 12，则整除 12 的部分进位到年份，余数作为新月份。
- 年进位计算：
  - \( \text{年} = \lfloor \text{月份} / 12 \rfloor \)
  - 表示传入月份中包含多少个完整年度。
  - 例如 `30 // 12 = 2`，表示 30 个月包含 2 个完整年度。
- 月份初始计算：
  - \( \text{月} = \text{日期}.month + (\text{月份} \% 12) \)
  - 例如起始日期为 2020 年 5 月，传入 30 个月，30 对 12 取余为 6，则初始月为 `5 + 6 = 11`。
- 当 \( \text{月} \ne 12 \) 时，继续处理月份进位：
  - \( \text{年} = \text{年} + \lfloor \text{月} / 12 \rfloor \)
  - \( \text{月} = \text{月} \% 12 \)
- 当 \( \text{月} = 12 \) 时，不需要再处理，直接表示当年 12 月。
- 返回新的日期：
  - \( \text{日期模块.date}(\text{日期}.year + \text{年}, \text{月}, \text{日期}.day) \)
- 函数结构可理解为：
  - 先计算需要进位的年数。
  - 再计算起始月份加余数后的月份。
  - 若月份不等于 12，则处理超过 12 的部分。
  - 最后用 `date(year, month, day)` 构造新日期。
- 视频中的口述例子：
  - 传入 30 个月时，`30 // 12 = 2`，先得到 2 年进位。
  - `30 % 12 = 6`，剩余 6 个月。
  - 结合起始日期的月份，再按算法得到最终年月。
  - 若起始日期为 2020 年 5 月，则示例中最终调用后能看到 5 月、6 月、7 月连续递增的结果。
- 调用函数填充日期：
  - `data['日期'].at[i] = 累加月(起始日期, i)`
- 当 `i=0,1,2` 时，得到：
  - `2020-05-26`
  - `2020-06-26`
  - `2020-07-26`
- 关键点：
  - 累加月到 12 月后要向上进位到年。
  - 12 月本身不再继续拆分。
  - 小于 12 月时 `月 // 12` 为 0，不会错误增加年份。
  - 大于 12 月时才会产生年份进位。

## 八、设置索引与写回 Excel

- 自动填充完成后，数据框仍有默认索引 `0,1,2,...`。
- 通常不希望保留默认索引，希望把“序号”列设置为索引。
- 不能在 `for` 循环之前直接设置索引：
  - `for` 循环使用的是原始索引 `data.index`。
  - 如果提前把“序号”设置为索引，循环中的 `i` 会变成序号列的值，后续 `i + 1`、`i % 2` 等运算会出错或报错。
- 设置索引应在循环结束之后进行：
  - `data.set_index('序号', inplace=True)`
- `inplace=True` 的含义：
  - 只在原 `DataFrame` 上修改。
  - 不生成新的数据对象。
- 设置后：
  - “序号”列成为索引。
  - 显示层级发生变化，序号作为索引出现。
  - 其他数据列正常显示。
- 写回 Excel：
  - `data.to_excel(path)`
- 说明：
  - 视频中为避免修改课件文件，没有实际执行写回。
  - 实际完整流程为：读取 Excel → 自动填充 → `set_index` 设置索引 → `to_excel` 写回。

## 九、CSV 大数据文件的自动填充

- 实际工作中，大数据文件通常是 `TXT` 或 `CSV`，其中 `CSV` 更常见。
- 原因：
  - 几个 GB 的 Excel 文件双击打开容易卡死。
  - `CSV` 是纯文本格式，更适合程序读取和处理。
- 示例中 `CSV` 文件可由 Excel 右键“另存为 CSV”生成，使用逗号分隔。
- 读取 CSV：
  - `data = pd.read_csv(path_csv)`
- CSV 与 Excel 操作的主要区别：
  - CSV 通常没有空行、空列问题。
  - 不需要设置 `skiprows`。
  - 不需要设置 `usecols`。
  - CSV 文件从表头开始，直接读取即可。
- 读取代码中需把文件路径改成 `.csv`，并改用 `read_csv`。
- 其他自动填充逻辑与 Excel 场景相同：
  - 序号填充。
  - 性别奇偶循环。
  - 日期填充。
  - 累加月算法。
- 设置索引同样使用：
  - `data.set_index('序号', inplace=True)`
- 写回 CSV：
  - `data.to_csv(path_csv)`
- 如果使用 Tab 键分隔的文件，需要按 Tab 分隔方式读取，例如使用 `read_csv` 时指定分隔符，或使用 `read_table`；本节示例为逗号分隔，因此直接使用 `read_csv`。
- CSV 场景简化总结：
  - Excel 读取需要处理 `skiprows`、`usecols`。
  - CSV 读取直接 `read_csv`。
  - 写回时 Excel 用 `to_excel`，CSV 用 `to_csv`。
  - 自动填充逻辑完全复用。

## 十、本节流程总结

- 完整 Excel 自动填充流程：
  - 导入 `pandas`。
  - 设置 Excel 路径。
  - 使用 `pd.read_excel` 读取。
  - 使用 `skiprows` 跳过空行和表头前的无关行。
  - 使用 `usecols` 选择目标列区域。
  - 使用 `dtype` 将序号、性别、日期等列统一设置为 `str`。
  - 使用 `for i in data.index:` 遍历索引。
  - 使用 `Series.at[i]` 或 `DataFrame.at[i, 列名]` 按位置赋值。
  - 序号列填充：`i + 1`。
  - 性别列填充：`'男' if i % 2 == 0 else '女'`。
  - 日期加天：使用 `timedelta(days=i)`。
  - 日期加年：使用 `date(year + i, month, day)`。
  - 日期加月：使用自定义“累加月”算法，处理 12 月进位。
  - 循环结束后使用 `data.set_index('序号', inplace=True)` 设置索引。
  - 使用 `data.to_excel(path)` 写回 Excel。
- CSV 自动填充流程：
  - 使用 `pd.read_csv(path_csv)` 读取。
  - 不需要处理空行空列。
  - 复用相同填充逻辑。
  - 使用 `data.set_index('序号', inplace=True)` 设置索引。
  - 使用 `data.to_csv(path_csv)` 写回 CSV。
- 重要原则：
  - 自动填充前先将相关列设置为字符型，避免类型报错。
  - `for`、`if` 等语句末尾不要忘记冒号。
  - 设置索引必须放在 `for` 循环之后，不能放在循环之前。
  - `timedelta` 不能直接加月、加年，年可用 `date` 重新构造，月需要自行算法。
- 使用建议：
  - 日常小型 Excel 办公自动化，使用 VBA、Power Query、Power BI 等方式通常更简单。
  - `pandas` 操作 Excel 的代码较繁琐，更适合大数据 `CSV`、`TXT` 等 Excel 难以直接打开的场景。
  - 不应把 `pandas` 处理小 Excel 当作首选“炫技”方案；应结合数据规模和业务场景选择工具。
