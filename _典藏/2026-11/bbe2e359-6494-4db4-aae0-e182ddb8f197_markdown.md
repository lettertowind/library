# Matplotlib 数据标签添加（p51 S03E04）

## 一、课程定位与目标

- 本节接上节课的柱形图程序继续讲解，因上节课内容较长而拆分为两节。
- 目标是：在柱形图上显示每个柱子的具体数值，即添加**数据标签**。
- 讲师强调：普通柱形图的上方、内部加标签相对简单；真正复杂的是**叠加图表**，因为位置和数值计算更困难。
- 本节以“第1年有天下五绝加林朝英，共六个人，因此有六根柱子”的数据为例，演示如何逐根柱子添加标签。

## 二、核心方法：`plt.text`

### 2.1 作用

- 使用 `plt.text` 在图表指定坐标位置显示文字。
- 添加柱形图数值标签时，需要为每一根柱子分别调用一次 `plt.text`，因此通常写在 `for` 循环中。

### 2.2 参数说明

课堂讲解的 `plt.text` 关键参数如下：

- 第一个参数：x 轴上的坐标值。
- 第二个参数：y 轴上的坐标值。
- 第三个参数：要显示的文字内容。
- `fontsize`：设置字号，课堂示例设置为 `20`。
- `rotation`：设置文字旋转角度，课堂示例设置为 `0`。
- `ha`：水平对齐方式，horizontal alignment。
- `va`：垂直对齐方式，vertical alignment。
- `color`：设置标签文字颜色。

讲师在口述时先说“一个是 h，一个是 y/哈/挖”，随后纠正：

- `ha` 是**水平对齐方式**。
- `va` 是**垂直对齐方式**。
- 水平对齐可设置为居中、右对齐、左对齐等。
- 垂直对齐可设置为居中、顶部、底部等。
- 这些对齐方式可以逐一测试。

课堂示例中使用的设置为：

- `ha='center'`：水平居中。
- `va='bottom'`：垂直方向靠底部。
- `fontsize=20`
- `rotation=0`

## 三、前置知识：`enumerate`

### 3.1 课程回顾位置

- 讲师让回忆 Python 基础篇中“第六课 for 循环公共操作与推导”讲过的 `enumerate`。
- 在基础篇资料中可用 `Ctrl+F` 搜索 `enumerate` 找到相关内容。

### 3.2 功能说明

- `enumerate` 可以遍历一个对象。
- 如果给它一个列表名，它可以把列表中的元素逐个遍历出来。
- 如果在前面给两个变量，它可以同时遍历出：
  - 第一个参数：下标。
  - 第二个参数：列表里的数据。
- 示例列表：`孙悟空`、`猪八戒`、`沙和尚`、`白龙马`、`唐僧`。
- 遍历时，第一个变量得到下标 `0, 1, 2, 3, 4`，第二个变量得到列表中的数据。
- 讲师指出：用 `enumerate` 操作柱形图标签非常方便。

## 四、添加第一年数据标签

### 4.1 编写循环

课堂讲解的循环思路：

- 使用 `for` 循环遍历第一年数据。
- 变量 `x` 表示下标，也就是每根柱子在 x 轴上的位置。
- 变量 `y` 或课堂中记作 `y1` 的变量表示柱子的数值，也就是 y 轴高度。

示意代码结构：

- `for x, y in enumerate(...):`
- `plt.text(x, y1, str(y1), fontsize=20, rotation=0, ha='center', va='bottom')`

说明：以上代码按课堂讲解整理，Matplotlib API 拼写按实际名称还原。

### 4.2 x 轴位置

- `plt.text` 的第一个参数使用 `x`。
- 因为 `x` 来自 `enumerate` 的下标，所以第一根柱子的 x 位置是 `0`，第二根是 `1`，第三根是 `2`，依此类推。
- 讲师强调：这个位置实际上就是下标的位置。

### 4.3 y 轴位置

- `plt.text` 的第二个参数先写柱子的数值变量，课堂中第一组数据使用 `y1`。
- 先写在柱子顶部位置，后续再调整。

### 4.4 显示文字内容

- 第三个参数用于设置显示的文字。
- 因为柱子的数值是数值类型，不能直接作为文字显示，需要用 `str()` 转成字符串。
- 课堂示例：`str(y1)`。
- 如果原始数据本身就是文字，则可以不转换。

### 4.5 样式设置

第一组标签的样式设置为：

- `fontsize=20`：字号为 20。
- `rotation=0`：不旋转。
- `ha='center'`：水平居中。
- `va='bottom'`：垂直方向靠底部。

### 4.6 运行与位置调整

- 运行后，标签出现在柱子顶部附近。
- 如果希望标签再往上一点，可以在 y 坐标后加 1，例如使用：
  - \(y1 + 1\)
- 这样标签就会与柱子保持一点距离。
- 如果希望标签放在柱子中间，可以将 y 坐标除以 2，例如使用：
  - \(y1 / 2\)
- 这样标签会落在每根柱子高度的一半位置。
- 讲师说明：这是数学计算问题，需要根据实际位置慢慢调整。

## 五、添加第二年数据标签

### 5.1 复制第一组代码并修改

- 将第一组添加标签的代码复制过来。
- 改为第二年数据。
- 将相关变量改为 `y2`，包括 y 轴位置和显示文字等。
- 课堂口述中多次强调改为 `y2`。

### 5.2 出现标签重叠问题

- 直接运行后，第二年数据的标签与第一年数据的标签发生重叠。
- 原因：第一年标签在 `x` 位置放置，第二年标签仍然在同一个 `x` 位置放置，所以两组标签重叠。
- 上节课设置柱子的宽度为 `0.3`。
- 第一组柱子（课堂口述红色条）宽度是 `0.3`。
- 第二组柱子（课堂口述蓝色条）需要在原始位置基础上再偏移一个柱宽，即加上 `0.3`。

### 5.3 解决方法

- 第二年标签的 x 坐标应改为：
  - \(x + 0.3\)
- 修改后再运行，标签即可对齐到第二组柱子上，不再与第一组标签重叠。

示意代码：

- `plt.text(x + 0.3, y2, str(y2), fontsize=20, rotation=0, ha='center', va='bottom')`

## 六、颜色设置

- `plt.text` 还支持通过 `color` 参数设置标签颜色。
- 课堂示例中，将某一组柱子上的标签设置为蓝色。
- 可设置的颜色包括白色、黄色、紫色等。
- 参数形式示例：`color='blue'`。
- 讲师说明：颜色可以自己随意设置。

## 七、关键点与易错点总结

- 添加柱形图数据标签使用 `plt.text`。
- `plt.text` 必须写在循环中，因为每一根柱子都需要单独添加一个标签。
- 第一个参数是 x 轴坐标。
- 第二个参数是 y 轴坐标。
- 第三个参数是要显示的文字，数值需用 `str()` 转为字符串。
- `fontsize` 控制字号。
- `rotation` 控制旋转角度。
- `ha` 控制水平对齐方式。
- `va` 控制垂直对齐方式。
- 第一年数据有六个人，因此有六根柱子，循环中分六次写入标签。
- 标签默认可以放在柱子顶部；若想上移，使用 \(y1 + 1\)；若想放在柱子中间，使用 \(y1 / 2\)。
- 第二组柱子的标签不能仍使用原始 `x`，否则会与第一组标签重叠。
- 第二组柱子的 x 坐标需要加上柱宽 `0.3`，即使用 \(x + 0.3\)。
- 标签颜色可通过 `color` 参数设置。
- 对齐方式 `ha` 和 `va` 可选值较多，可分别测试居中、左对齐、右对齐、顶部、底部等效果。
- 讲师最后提醒：要记住 `plt.text` 中 x 值、y 值、显示文字、字号、旋转角度、水平对齐、垂直对齐和颜色等设置。
