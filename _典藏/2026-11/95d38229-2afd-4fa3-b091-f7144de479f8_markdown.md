## 2. 导入可视化模块并创建默认图形

- 首先导入可视化模块：
```python
import matplotlib.pyplot as plt
```
- 创建一个画布和坐标轴，讲师口述“布和图”，对应 `figure` 与 `axes`。
- 创建一个一行一列的子图，可用：
```python
fig, ax = plt.subplots(1, 1)
plt.show()
```
- 默认图形有四条边框：上、下、左、右都有框。
- 一般图表习惯：不要上边框和右边框，只保留左边框和下边框。
- 概念说明：
  - `figure`：画布，承载整个图形。
  - `axes`：具体绘图区域/子图，坐标轴、刻度、线条等都在 `axes` 上操作。
  - `plt.subplots()`：创建画布和子图；以后做多子图时常用。
  - 易混点：`plt.plot()` 是面向当前坐标轴的快捷绘图；使用 `subplots()` 后通常用 `ax.plot()` 在指定子图上绘图。

## 3. 隐藏和设置坐标轴边框颜色：`spines`

### 3.1 `spines` 是什么

- `ax.spines` 是坐标轴边框集合。
- 四个方向分别对应：
  - `top`：上边框
  - `right`：右边框
  - `left`：左边框
  - `bottom`：下边框
- 使用 `.set_color()` 设置某条边框的颜色。
- `'none'` 表示“无颜色”，不是白色。
- 踩坑结论：不要设置成白色。若背景是蓝色，白色仍然能看到；设置为 `'none'` 才是真正隐藏。

### 3.2 隐藏上边框和右边框

- 隐藏上边框：
```python
ax.spines['top'].set_color('none')
```
- 隐藏右边框：
```python
ax.spines['right'].set_color('none')
```
- 运行后顶部和右侧边框消失。
- 使用场景：常见统计图、趋势图只保留左边和下边，使图表更简洁。

### 3.3 设置左边框和下边框颜色

- 设置左边框颜色：
```python
ax.spines['left'].set_color('red')
```
- 设置下边框颜色：
```python
ax.spines['bottom'].set_color('green')
```
- 讲师用“红配绿”演示，说明颜色可以自行设置。
- 结论：已经知道怎么隐藏边框，也就知道怎么设置边框颜色；后续移动坐标轴位置时，还需要把“边框线颜色”和“刻度位置”配套修改。

## 4. 坐标轴翻转

- 默认坐标轴通常从小到大，例如 x 轴、y 轴都从 0 到 1。
- 目标：让坐标轴从大到小显示，例如从 1 到 0。
- 先获取当前坐标轴：
```python
ax = plt.gca()
```
- `plt.gca()` 的含义是 get current axes，即获取当前坐标轴对象。
- 反转 y 轴：
```python
ax.invert_yaxis()
```
- 运行后 y 轴从 1 到 0，实现从大到小显示。
- 反转 x 轴：
```python
ax.invert_xaxis()
```
- 运行后 x 轴也从 1 到 0。
- x、y 都翻转后，两个轴都从大到小显示。
- 可以简化写法，不必先定义变量：
```python
plt.gca().invert_yaxis()
plt.gca().invert_xaxis()
```
- 易混点：
  - 轴翻转是改变坐标轴显示方向，不改变原始数据本身。
  - `invert_xaxis()` 管 x 轴，`invert_yaxis()` 管 y 轴，不要混用。
- 使用场景：需要从大到小展示、或希望视觉方向符合特定表达习惯时。

## 5. 隐藏坐标轴和刻度

- 只把边框颜色设置为 `'none'` 是不够的，刻度仍然会显示。
- 隐藏 x 轴刻度：给 `xticks` 传空列表。
```python
plt.xticks([])
```
- 隐藏 y 轴刻度：给 `yticks` 传空列表。
```python
plt.yticks([])
```
- 先演示设置刻度：例如让 x 轴刻度从 0 到 3 显示，可用列表或范围控制。
```python
plt.xticks([0, 1, 2, 3])
```
- 运行后 x 轴会显示 0~3 的刻度。
- 当传入空列表 `[]` 后，刻度消失。
- 易混点：
  - 隐藏边框：操作 `ax.spines[...]`。
  - 隐藏刻度：操作 `plt.xticks([])`、`plt.yticks([])`。
  - 两者需要分别处理，不能认为隐藏边框就等于隐藏刻度。
- 使用场景：只想让观众看到图形趋势，不想显示坐标轴和刻度时，可同时隐藏边框与刻度。

## 6. 移动坐标轴位置：x 轴到顶部，y 轴到右边

- 目标：x 轴刻度显示到顶部，y 轴刻度显示到右边。
- 移动 x 轴刻度位置到顶部：
```python
ax.xaxis.set_ticks_position('top')
```
- 移动 y 轴刻度位置到右边：
```python
ax.yaxis.set_ticks_position('right')
```
- 关键踩坑：只移动刻度位置还不够，因为边框线颜色也要同步修改。
  - 原来顶部边框设置成了 `'none'`，刻度移到顶部后，顶部线看不到。
  - 原来底部边框设置成了红色，需要把底部改为 `'none'`。
  - 需要把顶部边框设置为可见颜色，例如红色。
- x 轴到顶部时的配套设置示例：
```python
ax = plt.gca()

ax.xaxis.set_ticks_position('top')

ax.spines['bottom'].set_color('none')
ax.spines['top'].set_color('red')
```
- y 轴到右边时同理：
  - 把右边边框设置为绿色等可见颜色。
  - 把左边边框设置为 `'none'`。
```python
ax.yaxis.set_ticks_position('right')

ax.spines['left'].set_color('none')
ax.spines['right'].set_color('green')
```
- 结论：
  - “移动刻度位置”和“设置边框线颜色”是两件事，要一起考虑。
  - 上/下、左/右的对应关系要理解；参数记不住可以查笔记，但逻辑要懂。
- 易混点：
  - `set_ticks_position()` 设置刻度位置。
  - `set_color()` 设置边框线颜色。
  - 二者作用对象不同，不能只改一个。

## 8. 特殊刻度标签样式：突出显示某个坐标值

- 目标：把某个刻度标签的字体变大、颜色变红，使其特别醒目。
- 使用场景：例如要重点讲解某个身高值、某个异常值或某个关键坐标时，可突出显示对应刻度标签。
- 先获取当前坐标轴：
```python
ax = plt.gca()
```
- 获取 x 轴刻度标签对象：
```python
labels = ax.get_xticklabels()
```
- 如果要对 y 轴操作，则使用：
```python
labels = ax.get_yticklabels()
```
- 通过中括号索引选择要修改的标签。
- 讲师口述：
  - “我们要对这个第二个数进行更改”
  - “这里写一个中括号，写一个二就可以了”
- 注意：Python 索引从 0 开始，通常“第二个标签”应使用 `[1]`；如果照口述写 `[2]`，则指向第三个标签。实际编码时要核对到底想改哪一个。
- 选择标签后设置颜色和字号。讲师口述 `se`、`c='red'`、`fontsize=30`，对应标准写法可用：
```python
labels[1].set_color('red')
labels[1].set_fontsize(30)
```
- 也可以用 `plt.setp()` 批量/统一设置属性：
```python
plt.setp(labels[1], color='red', fontsize=30)
```
- 运行后该刻度标签会放大到 30 号字并变成红色，实现突出显示某个坐标值。
- 概念说明：
  - `get_xticklabels()`：取得 x 轴刻度标签的文本对象列表。
  - `get_yticklabels()`：取得 y 轴刻度标签的文本对象列表。
  - `.set_color()`：设置文字颜色。
  - `.set_fontsize()`：设置文字字号。
- 易混点：
  - `get_xticklabels()` 改的是刻度文字标签，不是刻度线本身。
  - `get_yticklabels()` 用于 y 轴。
- 讲师补充：也可以用注释的方式实现突出显示，注释以后课程再讲。




- 移动刻度后必须同步修改边框线颜色：

  - 颜色要使用 `'none'` 表示无颜色，不能误用白色。
  - 参数不需要死记，理解“改哪个轴、哪条边框、哪个刻度标签”即可，忘记时查资料。
