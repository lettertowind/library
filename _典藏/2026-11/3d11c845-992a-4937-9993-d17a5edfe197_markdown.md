# 孙兴华 Python 数据分析入门：多维数组（Numpy）

## 1. 一维数组回顾与基础术语

- 一维数组：数组元素排成一行。课程示例中一维数组可写作 `np.array([520, 1314])`，打印后得到一行两个数。
- 一维数组的特点：每个元素都有对应的下标，例如数组元素依次为 `0,1,2,3,4,5` 时，下标从 `0` 开始，对应为 `0,1,2,3,4,5`。
- 术语说明：Python 相关教材中有的叫“下标”，有的叫“索引”；数据分析类书中常叫“索引”。两者指的是同一个东西。
- 课程强调：如果没学过 Python 基础课，本课程可能听不懂，因为会直接使用数组、下标/索引等基础概念。

## 2. 二维数组：数组中的数组

- 二维数组可以理解为“行列式/矩阵”，但本质上是“数组中的数组”，即以数组作为数组元素的数组。
- 创建方式仍使用 `numpy.array`，形式上是把多个一维数组作为元素放进外层数组中，例如：`np.array([[...], [...]])`。
- 一维数组创建示例：`np.array([520, 1314])`，打印结果是一行两列的一维数组。
- 二维数组示例中，原来的数字元素会变成一个个数组，显示在外层数组里。
- 课程中查看了一个二维数组 `b`：
  - 形状：`2 × 3`，即两行三列。
  - 维度：二维数组。
  - 元素数：`6`。
  - 数据类型：`int32`，即 32 位整型。
- 对应 NumPy 中常用于查看的属性包括：`ndim`（维度）、`size`（元素数）、`dtype`（数据类型）、`shape`（形状）。
- 二维数组元素数计算：`行数 × 列数`，例如 `2 × 3 = 6`。

## 3. 用 `ones`、`zeros`、`full` 创建二维数组

- `np.ones((3,3))`：传入元组 `(3,3)`，创建三行三列、全部为 `1` 的二维数组。
- `np.zeros((3,3))`：创建三行三列、全部为 `0` 的二维数组。
- `np.full((3,3), 520)`：创建三行三列、全部填充为指定值 `520` 的二维数组。
- 形状参数需要使用元组，如 `(行, 列)`；这是创建多维数组时的重要写法。
- 上一节学过的 `ones`、`zeros`、`full` 主要用于按指定形状创建数组；本节继续用它们创建二维和多维数组。

## 4. 多维数组：三维数组就是“多块二维数组”

- 多维数组概念：可以理解为由多个二维数组组成。三维数组就是“分成几块二维数组”。
- 课程举例：一个由四块 `3 × 2` 二维数组组成的结构，就是多维数组。
- 创建三维数组示例：`np.ones((2,3,3))`。
  - 第一个维度 `2`：表示分为 `2` 块。
  - 后面 `(3,3)`：表示每一块是 `3 × 3` 的二维数组。
  - 所以整体是“两块 3×3 的数组”，即三维数组。
- 查看该三维数组：
  - 维度：三维。
  - 元素数：`2 × 3 × 3 = 18`。
  - 数据类型：示例显示为 `float64`。
- 课程中测试 `np.zeros((2,3,3))` 时，数据类型同样显示为 `float64`。
- 结论：`ones`、`zeros` 创建出的数组在课程环境中默认显示为浮点型 `float64`；不要靠猜，应直接查看 `dtype`。如果需要固定类型，可以显式指定数据类型。
- 多维数组元素数计算：各维度大小相乘。例如 `(2,3,3)` 的元素数为 `2 × 3 × 3 = 18`。
- 判断几维：看形状中有几个维度；`(2,3,3)` 是三维数组，`(3,3)` 是二维数组。
- 课程强调：现阶段先理解“三维数组 = 几块二维数组、每块几行几列”即可。

## 5. `_like` 系列：保持形状不变，替换数组中的值

- `ones_like`、`zeros_like`、`full_like` 的作用：已有数组形状不变，只改变数组中的数值。
- 先创建一个二维数组 `a`，课程示例为两行三列，值类似 `0~5`，如：
  - `a = np.array([[0,1,2],[3,4,5]])`
  - 打印 `a` 得到 `0,1,2,3,4,5`。
- `np.ones_like(a)`：
  - 语法：`np.ones_like(a)`。
  - 作用：按照数组 `a` 的形状生成新数组，形状不变，所有元素填充为 `1`。
  - 示例中生成结果应全部为 `1`。
- 踩坑记录：
  - 课程中一开始打印的是 `a`，所以看到的是 `0~5`，不是全 `1`；应打印新数组 `b`。
  - 代码中不要漏写 `np`，否则会报错或无法使用 NumPy 函数。
- `np.zeros_like(a)`：
  - 作用：按照 `a` 的形状生成新数组，所有元素填充为 `0`。
- `np.full_like(a, 520)`：
  - 作用：按照 `a` 的形状生成新数组，所有元素填充为指定值 `520`。
  - 语法重点：在数组参数后面加逗号，再写要填充的数字，即 `np.full_like(a, 520)`。
- 对比记忆：
  - `np.ones((3,3))`、`np.zeros((3,3))`、`np.full((3,3), 520)`：需要手动传入形状。
  - `np.ones_like(a)`、`np.zeros_like(a)`、`np.full_like(a, 520)`：直接复用已有数组 `a` 的形状。
  - `_like` 系列不改变形状，只改变其中的数值。

## 6. NumPy 随机数：`np.random`

- 以前使用 Python 标准库随机数时，需要 `import random`。
- NumPy 中也有随机数模块：`np.random`，不需要再导入标准库 `random`。
- 课程说明：NumPy 的 `random` 比标准库的 `random` 更强大；随机数后续会专门讲解，本节先做了解。
- 生成单个随机小数：
  - `a = np.random.rand()`
  - `print(a)`
  - 结果是单个随机小数。
- 生成多个随机数：
  - `np.random.rand(3)`：传入一个数字，生成一维数组，包含 3 个随机数。
- 生成二维随机数组：
  - `np.random.rand(3,3)`：生成 `3 × 3` 的二维随机数组。
  - 课程口述“传入两个数时得到二维数组”，示例为三行三列。
- 生成三维随机数组：
  - `np.random.rand(2,3,3)`：生成“两块 3×3”的三维随机数组。
  - 课程口述“传入三个数时就是两个三行三列”，对应三维数组。
- 参数规律：
  - 不写参数：得到一个随机数。
  - 传入一个数：得到一维数组。
  - 传入两个数：得到二维数组。
  - 传入三个数：得到三维数组。
- 注意：视频中讲的是 `numpy.random` 下的随机数方法，核心是使用 `np.random.rand(...)` 按指定维度生成随机数组；后续课程会继续详细讲随机数。
