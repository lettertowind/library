## 课程目标与整体流程

- 本课学习 Matplotlib 中最简单的图：柱形图/柱状图。
- 整体流程：安装 `matplotlib` → 用 `pandas` 读取 Excel 数据 → 按分数排序 → 导入 `pyplot` → 用 `plt.bar()` 画柱状图 → 添加中文支持、图例、坐标轴标题、刻度旋转、y 轴范围、负号显示、大标题、紧凑布局 → 保存图片。
- 示例数据：`PLT` 文件夹下的“01柱形图”Excel 文件，包含两列：姓名、分数。数据中有中文。
- 本课只讲柱状图基础修饰，后续还会继续讲柱形图/条形图的更多内容。

- 使用 `cd` 命令进入 `pip3` 所在目录。
- 安装命令为：`pip3 install matplotlib`。转录中口述为 `pip 3点空格 ...`，实际命令是安装 `matplotlib`。

- 安装踩坑：

  - 讲师大概安装了三次才成功。

  - 如果会使用 PyCharm，也可以在 PyCharm 中安装 `matplotlib`。

## 2. 用 pandas 读取 Excel 数据

- 在 PyCharm 中新建文件，例如 `s03e01.py`。
- 导入 pandas：`import pandas as pd`。
- 读取 Excel 数据：`数据 = pd.read_excel(r'C:\plt\01.柱状图.xlsx')`。
  - 变量名沿用转录中口述的“数据”。
  - `r` 用于路径前防止转义，转录中称为“加一个 r 转移”。
  - 实际路径应根据自己的 `PLT` 文件夹位置调整。
- 读取后可以查看两列数据：`数据.姓名` 取姓名列，`数据.分数` 取分数列。
- pandas 读取数据的优势：
  - 到这一季应该能体会到 pandas 有多方便。
  - 如果使用 `openpyxl` 读取同一个数据，可能会很麻烦，因为拿到数据需要循环两次。
  - pandas 不需要循环，直接就能拿到数据列。
- 取列方法不止一种：除了 `数据.姓名`，也可以用 `loc` 等命令取列。

## 3. 作图前的准备与排序

- 作图前要考虑两个问题：
  - 数据中是否有中文。如果有中文，需要设置中文字体；否则中文会显示为小方块。讲师先故意不加字体设置，让学员观察问题。
  - 数据是否需要排序。排序与业务有关，正常情况可以先排序；排序知识可复习 pandas 笔记 7.1“数据排序”。
- 按分数降序排序，并直接在原数据上修改：
  - `数据.sort_values(by='分数', ascending=False, inplace=True)`
  - `by='分数'`：按照“分数”这一列排序。
  - `ascending=False`：降序排序；默认是升序。
  - `inplace=True`：在原数据上修改，不生成新的变量。
- 如果不加 `inplace=True`，排序结果会生成/返回到一个新变量中；如果只想保留排序后的原数据，就使用 `inplace=True`。
- 运行后打印 `数据`，可以看到数据已经按分数降序排列，并且原数据被修改。

## 4. 导入 Matplotlib 并画基础柱状图

- 导入 Matplotlib 的 pyplot 模块：`import matplotlib.pyplot as plt`。
- 命名惯例：
  - Numpy 约定使用 `np`。
  - Pandas 约定使用 `pd`。
  - Matplotlib.pyplot 约定使用 `plt`。
  - 可以自己改名，但改完后别人可能读不懂程序，因此遵循国际惯例。
- 画柱状图使用：`plt.bar(数据.姓名, 数据.分数)`。
  - 第一个参数是 x 轴上的值：姓名。
  - 第二个参数是 y 轴上的值：分数。
  - `bar` 的参数很多，本课先使用最简单形式，复杂参数后续再学。
- 只写 `plt.bar(...)` 运行后不会显示图形，必须调用：`plt.show()`。
  - `plt.show()` 用于显示图形窗口。
  - 不调用 `plt.show()`，图虽然已经创建，但不会显示出来。
- 初始运行结果：
  - 英文和数字显示正常。
  - 中文姓名、中文标签显示成两个小方块，说明 Matplotlib 默认对中文支持不好，需要设置中文字体。

## 5. 解决中文显示：设置字体

- 在作图前增加中文字体设置，例如：`plt.rcParams['font.sans-serif'] = ['SimHei']`。
  - 转录中讲师说设置为“国际黑体”，并说明字体可以上网查，查到可用字体都可以使用。
  - 该设置属于全局参数设置，用于指定无衬线字体，解决中文显示为方块的问题。
- 设置后重新运行，中文显示正常，不再出现小方块。
- 注意：中文字体设置与后面的负号显示设置是两个不同问题，需要分别处理。

## 6. 添加图例

- 在 `plt.bar()` 中增加 `label` 参数：`plt.bar(数据.姓名, 数据.分数, label='成绩')`。
- 只写 `label`，图例不会自动出现，还需要调用：`plt.legend()`。
- 踩坑：讲师演示时曾因为参数写反/位置写错导致报错；`label` 必须正确传给 `plt.bar()`。
- `plt.legend()` 默认将图例显示在右上角。
- 修改图例位置：`plt.legend(loc='upper left')`，图例显示在左上角。
  - `loc` 还可以改成中间、右边、下边等位置。
  - 图例位置表后续会提供，不需要死记。

## 7. 设置 x 轴、y 轴标题

- 设置 x 轴标题：`plt.xlabel('姓名')`。
- 设置 y 轴标题：`plt.ylabel('分数')`。
- x 轴和 y 轴标题需要分别设置，不能只设置一个就让两个标题都出现。
- 运行后 x 轴显示“姓名”，y 轴显示“分数”。

## 8. 刻度标签倾斜：防止姓名重叠

- 当柱子较多、项目较多时，例如有二三十个人，x 轴上的姓名会重叠在一起。
- 使用 `plt.xticks(数据.姓名, rotation=45)` 让刻度标签倾斜：
  - `plt.xticks()` 用于设置 x 轴刻度标签。
  - 标签内容为 `数据.姓名`，因为 x 轴就是姓名。
  - `rotation=45` 表示旋转 45 度，约 45 度较合适。
- 运行后，即使人数很多，姓名标签也不会互相重叠。
- 实际参数名是 `rotation`，不是转录口述中的 `rot`。

## 9. y 轴刻度范围与负号显示

- 设置 y 轴刻度范围：`plt.ylim(-30, 120)`。
  - 该示例把 y 轴范围设置为 -30 到 120。
  - 代码书写顺序没有先后要求。
- 观察负号问题：
  - 当 y 轴出现负数时，负号可能显示不正常。
  - 转录中描述：从 -30 开始时，`-30` 在零点起点未显示；到 `-20` 时负号变成方块/20。
  - 说明 Matplotlib 默认对负号字符的显示也有问题。
- 解决负号显示：`plt.rcParams['axes.unicode_minus'] = False`。
  - 有负号时才加这句话；没有负号时不要写。
  - 加上后重新运行，负号即可正常显示。
- 区分：
  - `plt.ylim()` 控制 y 轴刻度范围。
  - `plt.rcParams['axes.unicode_minus'] = False` 控制负号字符是否正常显示。

## 10. 添加图表大标题

- 使用 `plt.title()` 添加大标题：`plt.title('三年二班学生成绩', fontsize=16, fontweight='bold')`。
  - 第一个参数是标题文本，转录中口述为“3年二班学生成绩”。
  - `fontsize=16` 设置字体大小。
  - `fontweight='bold'` 设置粗体。
- 运行后大标题显示正常。

## 11. 紧凑布局

- 图形元素可能互相遮挡或布局不紧凑，可以使用：`plt.tight_layout()`。
- 该函数用于自动适应布局、生成紧凑型布局。
- 运行后图形布局会自动处理，减少元素重合问题。

## 12. 保存图片

- 图形窗口显示出来后，可以手动点击保存按钮，将图片保存到电脑硬盘。
- 也可以使用代码保存：`plt.savefig('C:/孙兴华')`。
  - 参数为保存路径，讲师示例保存到 C 盘根目录。
  - 运行成功后可以在 C 盘找到该图片。
- 实际使用建议：
  - 显式写扩展名，例如 `plt.savefig('C:/孙兴华.png')`。
  - 保存代码通常放在 `plt.show()` 之前，避免图形窗口关闭后保存出空白图片。
