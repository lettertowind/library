## 三、`drop` 函数的基本概念

`drop` 是 Pandas 中用于删除行或列的函数。

视频中涉及的核心参数包括：

- `labels`：要删除的行标签或列标签。
- `axis`：指定按行删除还是按列删除。
  - `axis=0`：按行操作，默认值。
  - `axis=1`：按列操作。
- `inplace`：是否在原数据上直接修改。

基本理解：

- 删除行时，默认 `axis=0`，所以可以省略不写。
- 删除列时，需要设置 `axis=1`。
- 删除单个标签时，可以直接写标签。
- 删除多个标签时，需要使用 `labels=[...]` 列表形式。

注意：`drop` 删除时依据的是“行标签/列标签”，不是简单的行号位置。删除后，原来的索引不会自动重排。

## 四、删除行

### 删除单行

如果要删除某一行，可以直接在 `drop` 中写入该行的行标签。

示例：删除行标签为 `1` 的行：

```python
print(data.drop(1))
```

视频中演示删除“第二行”的数据，例如姓名列中的某个学生。具体行标签以实际数据为准。

关键结论：

- `drop(1)` 中的 `1` 是行标签，不是普通意义上的行号。
- 删除之后，被删除的行消失。
- 其他行的索引/序号不会发生变化，不会自动重新编号。
- 直接写在 `print()` 里面，输出的是删除后的新对象，原数据默认不变。

### 删除多行

删除多行时，需要使用 `labels` 参数，并把多个行标签放进列表中。

示例：删除行标签 `1` 和 `3`：

```python
print(data.drop(labels=[1, 3]))
```

视频中示例删除某些学生对应的行，例如丁志敏、王刚等。具体姓名以实际数据为准，转录中姓名存在识别误差。

运行结果：

- 行标签 `1` 和 `3` 对应的行被删除。
- 其他行标签，例如 `2`、`4`、`5`、`6` 等保留。
- 多个标签之间用逗号隔开。

关键结论：

- 删除单行：直接写行标签，例如 `data.drop(1)`。
- 删除多行：使用 `labels=[...]`，例如 `data.drop(labels=[1, 3])`。
- 转录中出现的“levels”“lab”“level”等均为识别误差，正确参数名是 `labels`。

## 五、删除列

删除列和删除行的思路相似，但需要修改 `axis` 参数。

- `axis=0`：默认，表示行。
- `axis=1`：表示列。

因此，删除列时必须设置 `axis=1`。

### 删除单列

示例：删除“语文”列：

```python
print(data.drop('语文', axis=1))
```

运行结果：

- “语文”列被删除。
- 数学、英语等未被删除的列保留。
- 视频口述结果为保留数学和英语相关列，具体以实际数据结构为准。

关键结论：

- 删除单列时，可以直接写列标签，例如 `'语文'`。
- 必须加上 `axis=1`，否则 Pandas 会按行标签查找，容易出错。

### 删除多列

删除多列时，同样使用 `labels` 参数，并把多个列标签放入列表。

示例：删除“语文”和“英语”两列：

```python
print(data.drop(labels=['语文', '英语'], axis=1))
```

运行结果：

- “语文”和“英语”列被删除。
- 视频演示中最终只保留“数学”列，其他未保留列被删除。
- 多个列标签之间用逗号隔开。

关键结论：

- 删除多列：`labels=['列1', '列2']` 加 `axis=1`。
- 删除多行和删除多列都要用 `labels` 参数接收列表。
- 删除行时默认 `axis=0`，删除列时显式设置 `axis=1`。

## 六、`drop` 删除行、列的参数总结

删除行：

```python
data.drop(1)
data.drop(labels=[1, 3])
```

删除列：

```python
data.drop('语文', axis=1)
data.drop(labels=['语文', '英语'], axis=1)
```

总结规则：

- 删除行使用默认轴 `axis=0`，可省略。
- 删除列需要设置 `axis=1`。
- 删除一个标签时，可以直接把行标签或列标签传给 `drop`。
- 删除多个标签时，使用 `labels=[标签1, 标签2, ...]`。
- 行标签和列标签都用逗号分隔在列表中。
- 删除后默认返回新对象，原数据默认不改变。

## 七、`inplace` 参数

### `inplace` 的作用

`inplace` 参数控制：

- 是在原数据上直接修改；
- 还是生成一个新的数据对象。

默认情况：

```python
inplace=False
```

也就是默认生成新对象，不修改原数据。

### 直接写入 `print()` 的写法

例如：

```python
print(data.drop(1))
```

这种写法没有问题。

原因：

- `data.drop(1)` 会生成一个删除后的新对象。
- `print()` 打印的是这个新对象。
- 相当于隐式地做了类似下面的操作：

```python
data2 = data.drop(1)
print(data2)
```

只是省略了中间变量 `data2`。

### 错误写法：只写 `drop` 再打印原数据

例如：

```python
data.drop(1)
print(data)
```

这种写法中：

- `data.drop(1)` 默认返回新对象。
- 但没有把返回值赋值给任何变量。
- `inplace` 默认又是 `False`。
- 所以原数据 `data` 并没有被修改。
- 最后 `print(data)` 打印的仍然是原始数据。
- 这一句 `data.drop(1)` 相当于白写，删除不生效。

### 正确写法：设置 `inplace=True`

如果希望直接在原数据上删除，需要设置：

```python
data.drop(1, inplace=True)
print(data)
```

删除多行示例：

```python
data.drop(labels=[1, 3], inplace=True)
print(data)
```

关键结论：

- `inplace=True` 表示在原数据上修改。
- 设置后，再直接打印 `data` 就可以看到删除后的结果。
- `inplace=False` 是默认值，表示生成新对象。
- 如果不接收返回值，也不设置 `inplace=True`，删除结果不会保存到原数据。

### 讲师表格说明的结论

讲师用表格总结了 `inplace` 参数的几种情况：

- 按照“直接写进 `print()`”的方法写，没有问题。
- 下面几种写法在效果上是等同的，都是围绕“生成新对象”或“赋值保存结果”。
- 唯独“只写 `data.drop(...)`，不接收返回值，也不加 `inplace=True`”不行。
- 因为此时没有生成并保存单独对象。
- `inplace` 默认是 `False`，表示默认生成新对象。
- 没有保存新对象，再打印原数据，删除操作对原数据无效。

## 八、易混点与注意事项

- `drop` 是函数名，转录中“多p函数”“多少普函数”“段函数”等均为识别误差，正确写法是 `drop`。
- `labels` 是参数名，转录中“levels”“lab”“level”等均为识别误差，正确写法是 `labels`。
- `inplace` 是参数名，转录中“input 参数”“raint”等均为识别误差，正确写法是 `inplace`。
- `axis=0` 表示行，`axis=1` 表示列，二者容易混淆。
- 删除行时默认 `axis=0`，可省略。
- 删除列时必须写 `axis=1`。
- 删除单个标签时，直接写标签即可。
- 删除多个标签时，必须用 `labels=[...]` 列表形式。
- `drop` 删除依据的是行标签/列标签，不是删除后自动重排的行号。
- 删除单行后，原索引不会自动变化。
- 如果只写 `data.drop(...)`，既没有赋值给新变量，也没有设置 `inplace=True`，原数据不会改变。
- 使用 `read_csv` 时，`drop` 的参数与 `read_excel` 完全一致，只需要改读取函数和文件格式。

## 九、完整示例代码整合

```python
import pandas as pd

# 按自己的实际路径修改
path = 'C:/Pandas/chalice.xlsx'

# 读取 Excel 数据
data = pd.read_excel(path)
print(data)

# 删除单行：删除行标签为 1 的行
print(data.drop(1))

# 删除多行：删除行标签 1 和 3
print(data.drop(labels=[1, 3]))

# 删除单列：删除“语文”列，必须设置 axis=1
print(data.drop('语文', axis=1))

# 删除多列：删除“语文”和“英语”列
print(data.drop(labels=['语文', '英语'], axis=1))

# 在原数据上删除多行
data.drop(labels=[1, 3], inplace=True)
print(data)
```

如果数据文件是 CSV，则读取方式改为：

```python
data = pd.read_csv(path)
```

后续所有 `drop` 删除行、列的写法保持不变。
