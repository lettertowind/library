# Matplotlib 文本注释（annotate）课程笔记

## 1. 本节主题与应用场景

- 本节讲解 Matplotlib 中的**文本注释**，重点函数是 `plt.annotate()`。
- 文本注释指：在图表上写一段说明文字，并可用箭头指向某个具体数据点或对象。
- 讲师用公司业绩图举例：在一群人的业绩图里，用文本和箭头指出“某个人在这里”，这就是文本注释。
- 文本注释与**数据标签**不同：
  - 数据标签：主要标明某个点的数据值是什么，常用 `plt.text()` 直接加文字。
  - 文本注释：用文字解释某个点，并常配合箭头、边框等，让说明更醒目。
- 本节还会讲两种常见形式：
  - 用 `plt.annotate()` 添加文字和箭头。
  - 用 `plt.text()` 配合 `bbox` 给文本加边框，形成醒目的标签。
  - 用 `arrowprops` 中的 `connectionstyle` 设置变形箭头。

## 2. 基础折线图示例

讲师先建立一个简单折线图作为后续注释对象。

- x 轴数据为类别：`'a'`, `'b'`, `'c'`
- y 轴数据为：`5`, `2`, `3`
- 使用红色圆圈并连线。

示例代码可表示为：

```python
import matplotlib.pyplot as plt

x = ['a', 'b', 'c']
y = [5, 2, 3]

plt.plot(x, y, 'ro-')  # r：红色，o：圆点，-：连线
plt.show()
```

说明：

- `'ro-'` 中 `r` 表示红色，`o` 表示圆点标记，`-` 表示实线连线。
- 该图是后续 `annotate` 文本注释和 `bbox` 边框标签的基础图。

## 3. 文本注释的基本概念

- 文本注释不是简单显示数据值，而是对图形中的某个位置进行解释说明。
- 典型结构：
  - 文本内容：例如某人的英文缩写 `'sxh'`（视频中用孙兴华的缩写）。
  - 箭头：从文本位置指向被说明的数据点。
  - 文本位置：文本可以放在目标点旁边、上方、左下角等位置。
- 讲师强调：
  - 文本注释和数据标签不一样。
  - 数据标签只说明“这个点的数据是什么”。
  - 文本注释用于“指出某个对象/解释某个点”，可以带箭头。
  - 如果只想加普通数据标签，可以直接用 `plt.text()`；如果要带箭头，则用 `plt.annotate()`。

## 4. `plt.annotate()` 基本用法

### 4.1 基本函数形式

```python
plt.annotate(text, xy=(x, y))
```

- 第一个参数 `text`：要写入的注释内容。
- `xy`：被注释的目标点坐标，也就是箭头最终指向的位置。
- 如果只给 `xy`，注释文字会显示在目标点附近/目标点上。
- 如果需要移动文本显示位置，需要设置 `xytext`。

### 4.2 示例：在点 `('b', 2)` 上添加注释

讲师先直接写：

```python
plt.annotate('sxh', xy=('b', 2))
```

说明：

- `'sxh'` 是注释文字，视频中使用英文缩写避免中文报错。
- `xy=('b', 2)` 表示箭头/注释指向 x 轴类别 `'b'`、y 轴数值 `2` 的数据点。
- 运行后文字显示在点 `('b', 2)` 附近。

### 4.3 中文报错问题

- 讲师尝试使用中文文本时出现报错/显示问题。
- 原因是当前环境没有导入中文字体库，Matplotlib 默认中文字体支持未配置。
- 本节处理方式：
  - 先使用英文内容，例如 `'sxh'`。
  - 避免因中文显示问题打断课程。
- 结论：使用中文注释前需要先配置中文字体支持；本节暂不展开中文字体设置。

### 4.4 使用 `xytext` 调整文本位置

- `xy` 控制箭头指向哪个点。
- `xytext` 控制文本显示在哪个坐标位置。
- 示例：把文本从 y=2 上移到 y=2.5。

```python
plt.annotate('sxh',
             xy=('b', 2),
             xytext=('b', 2.5))
```

效果：

- 箭头仍指向 `('b', 2)`。
- 文本显示在 `('b', 2.5)` 的位置。
- 运行后可以看到文本向上移动。

### 4.5 文本位置与坐标类型的关系

讲师特别强调 x 轴坐标使用字符串类别时的限制：

- 如果 x 轴直接使用 `'a'`, `'b'`, `'c'` 这样的字符串：
  - 不能直接进行加减乘除来微调位置。
  - 例如不能方便地写 `'b' + 0.1`。
  - 可调整程度较小。
- 更推荐先用 NumPy 方式生成数值索引：
  - 例如用 `0, 1, 2, ...` 作为 x 轴坐标。
  - 数值坐标可以做加减乘除，方便调整文本偏移。
  - 画完后再把刻度标签替换成“张三、李四、王五”等类别名称。
- 这样做的优点：
  - 文本位置调整更灵活。
  - 后期替换标签更方便。
  - 可改变程度更大。
- 如果已经直接用了字符串坐标，仍然可以调 y 轴坐标，例如把 `xytext` 的 y 从 `2` 改成 `2.5`，但 x 方向微调不如数值索引方便。

数值索引思路示例：

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.arange(3)
y = [5, 2, 3]

plt.plot(x, y, 'ro-')
plt.xticks(x, ['a', 'b', 'c'])

plt.annotate('sxh', xy=(1, 2), xytext=(1, 2.5))
plt.show()
```

## 5. `arrowprops` 设置箭头样式

### 5.1 基本用法

- 只写 `plt.annotate()` 时默认可能只有文字，没有箭头。
- 要画箭头，需要添加 `arrowprops` 参数。
- `arrowprops` 使用字典形式设置箭头样式，比较方便。

基本形式：

```python
plt.annotate('sxh',
             xy=('b', 2),
             xytext=('b', 2.5),
             arrowprops=dict())
```

### 5.2 设置箭头颜色

讲师在 `arrowprops` 字典中设置箭头颜色为红色。

示例形式：

```python
plt.annotate('sxh',
             xy=('b', 2),
             xytext=('b', 2.5),
             arrowprops=dict(color='red'))
```

说明：

- `arrowprops=dict(...)` 用于设置箭头外观。
- 视频中把箭头颜色设置为红色。
- 箭头颜色、线宽、头部大小等都可以通过字典参数调整。

### 5.3 设置箭头缩放/收缩比例 `shrink`

视频中重点演示了箭头缩放百分比参数，效果与箭头尾巴长短有关。

示例：

```python
arrowprops=dict(shrink=0.05)
```

讲师演示的数值与效果：

- `shrink=0.8`：箭头基本看不到。
- `shrink=0.1`：约 10%，箭头可见但比较短。
- `shrink=0.05`：箭头变得较长、较细。
- `shrink=5`：仍能看到一点箭头。

结论：

- `shrink` 数值越大，箭头后边的尾巴越短。
- `shrink` 数值越小，箭头后边的尾巴越长。
- 该参数用于控制箭头两端的收缩/缩放比例，影响箭头与文本、目标点之间的距离感。

### 5.4 设置箭头线宽 `width`

- `arrowprops` 中可设置 `width`，控制箭头线条宽度。
- 讲师演示：
  - `width=1`：正常线宽。
  - `width=100`：非常宽，视觉上“有点吓人”。
- 结论：`width` 过大会导致箭头非常粗，应根据图形尺寸选择合适值。

示例：

```python
arrowprops=dict(width=1)
```

### 5.5 设置箭头头部宽度与长度

讲师说明还有箭头头部相关参数：

- `headwidth`：箭头头部的宽度，即“尖”的宽度。
- `headlength`：箭头头部的长度。
- 这些参数都在配套资料中列出，可按需设置。
- 视频中称：
  - `width` 设置箭头线条宽度；
  - `headwidth` 设置箭头头部宽度；
  - `headlength` 设置箭头头部长度；
  - 还有缩放百分比 `shrink` 等参数。

综合示例形式：

```python
plt.annotate('sxh',
             xy=('b', 2),
             xytext=('b', 2.5),
             arrowprops=dict(
                 color='red',   # 箭头颜色
                 shrink=0.05,   # 收缩/缩放比例，影响尾巴长短
                 width=1,       # 箭头线宽
                 headwidth=10,  # 箭头头部宽度（示例值，可按资料调整）
                 headlength=10  # 箭头头部长度（示例值，可按资料调整）
             ))
```

### 5.6 文本对齐位置

- 讲师资料中还准备了文本位置/对齐参数。
- 可以把文本放在目标点的左下角等位置。
- 视频中示例将文本放在左下角附近，再用箭头指向目标点。
- 具体可选位置和对齐参数在配套笔记资料中列出，使用时直接选择即可。
- 除了箭头之外，文本本身的位置也可以继续调整；字体大小等也可另行设置。

## 6. 使用 `bbox` 制作带边框的文本标签

### 6.1 需求与效果

- 视频展示另一种文本注释效果：
  - 文字外面套一个边框。
  - 边框可以是圆角等样式。
  - 背景有灰度或颜色。
  - 文字更醒目。
- 讲师说明：这种效果可以用 `bbox` 实现。
- 本质是：先用 `plt.text()` 加数据标签，再通过 `bbox` 给文字加边框和背景。

### 6.2 定义 `bbox` 字典

基本形式：

```python
bbox = dict(
    boxstyle='round',  # 边框样式
    fc='0.8',          # 背景灰度/填充色
    ec='red',          # 边框线条颜色
    lw=2               # 边框线宽
)
```

参数说明：

- `boxstyle`：边框外形样式。
  - 视频中展示多种边框样式，名称在资料中列出。
  - 使用时直接把样式名称写进字典即可。
  - 示例中可用 `'round'` 表示圆角边框。
- `fc`：`facecolor` 的缩写，设置边框背景颜色/灰度。
  - 视频中设置背景灰度为 `0.8`。
- `ec`：`edgecolor` 的缩写，设置边框线条颜色。
- `lw` / `linewidth`：设置边框线条大小/宽度。
  - 视频资料中给出该参数，可按需设置。

### 6.3 使用 `plt.text()` 传入 `bbox`

示例：

```python
plt.text('b', 2, 'sxh', bbox=bbox)
```

说明：

- 前两个参数是坐标 `x='b'`, `y=2`。
- 第三个参数是文本内容 `'sxh'`。
- `bbox=bbox` 把前面定义的边框字典应用到文本上。
- 运行后，在点 `('b', 2)` 处显示带边框的文字标签。

### 6.4 调整位置与字号

- 可以把文本位置从 y=2 上提到 y=2.5，使标签不遮挡数据点。
- 可以设置字号，例如 `size=20`，让标签更大更清楚。
- 讲师最后把位置恢复到 y=2，并设置字号后运行，效果更清楚。
- 结论：用 `bbox` 加边框比普通数据标签更醒目，适合强调某个点。

示例：

```python
plt.text('b', 2, 'sxh', bbox=bbox, size=20)
```

### 6.5 常见坑：只定义字典不会显示

- 讲师强调：只创建 `bbox` 字典，不会在图上显示任何东西。
- 必须把 `bbox` 作为参数传给 `plt.text()`，才会出现边框标签。
- 即必须写：

```python
plt.text('b', 2, 'sxh', bbox=bbox)
```

- 如果只写 `bbox = dict(...)` 而不传入 `plt.text()`，图上没有任何显示。

### 6.6 边框样式说明

- `boxstyle` 的样式不用自己找，讲师资料中列出了可用名称。
- 直接用资料中的样式名复制到 `boxstyle` 中即可。
- 视频中展示了多种边框样式，可根据需求选择。
- 讲师评价：这种带边框的注释比普通数据标签更好看、更醒目。

## 7. `connectionstyle` 变形箭头

### 7.1 需求

- 除了直线箭头，还可以设置“变形箭头”：
  - 箭头可以拐弯。
  - 可以是弧线。
  - 可以是条形连接等。
- 这通过 `arrowprops` 中的 `connectionstyle` 参数实现。

### 7.2 基本示例

讲师使用 `plt.annotate()`，设置：

- `xy=('b', 2)`：箭头指向 `b, 2`。
- `xytext=('c', 5)`：文本显示在 x 轴 `'c'`、y 轴 `5` 的位置。
- `arrowprops=dict(connectionstyle='angle')`：设置连接样式为拐弯箭头。

示例：

```python
plt.annotate('sxh',
             xy=('b', 2),
             xytext=('c', 5),
             arrowprops=dict(connectionstyle='angle'))
```

效果：

- 文本显示在 `('c', 5)`。
- 箭头从文本位置出发，拐弯后指向 `('b', 2)`。
- 不是默认的直线箭头，而是折线/拐弯箭头。

### 7.3 常见连接样式

讲师说明变形箭头有很多种，并演示/列出：

- `connectionstyle='angle'`：拐弯箭头。
- `connectionstyle='arc'`：弧线/普通弧形连接。
- `connectionstyle='bar'`：条形连接样式。

视频中提到变形箭头共有五种方式，可逐个尝试；配套资料中列出了完整样式。使用时根据需求选择。

示例：

```python
plt.annotate('sxh',
             xy=('b', 2),
             xytext=('c', 5),
             arrowprops=dict(connectionstyle='arc'))
```

```python
plt.annotate('sxh',
             xy=('b', 2),
             xytext=('c', 5),
             arrowprops=dict(connectionstyle='bar'))
```

### 7.4 参数归属

- `connectionstyle` 是 `arrowprops` 字典中的键。
- 它控制箭头的连接路径形状，不控制文本内容本身。
- `xy` 仍然控制箭头指向点。
- `xytext` 仍然控制文本显示位置。

## 8. 关键结论与建议

- 文本注释使用 `plt.annotate()`，基本参数为：
  - `text`：注释文字。
  - `xy`：箭头指向的目标点。
  - `xytext`：文本显示位置。
  - `arrowprops`：箭头样式字典。
- 只写 `xy` 时文本在目标点附近；加 `xytext` 可移动文本位置。
- 没有设置 `arrowprops` 通常没有箭头；设置后才有箭头。
- 箭头常用参数：
  - 颜色：设置红色等。
  - `shrink`：缩放/收缩比例；数值越大，箭头尾巴越短；数值越小，尾巴越长。
  - `width`：箭头线宽；过大会非常粗。
  - `headwidth`：箭头头部宽度。
  - `headlength`：箭头头部长度。
- 推荐 x 轴先用数值索引（如 `0, 1, 2`）再替换成类别标签：
  - 便于对文本位置做加减乘除微调。
  - 直接用字符串类别时，x 方向不易偏移。
- 中文注释需要先配置中文字体；本节先用英文 `'sxh'` 避免报错。
- `plt.text()` 配合 `bbox` 可制作带边框的醒目标签：
  - `boxstyle`：边框样式。
  - `fc`：`facecolor`，背景色/灰度。
  - `ec`：`edgecolor`，边框颜色。
  - `lw` / `linewidth`：边框线宽。
  - 只定义 `bbox` 字典不传入 `plt.text()` 不会显示。
- 变形箭头使用 `arrowprops=dict(connectionstyle=...)`：
  - 可尝试 `angle`、`arc`、`bar` 等样式。
  - 完整样式和参数在讲师配套资料中列出，可直接查阅下载。
