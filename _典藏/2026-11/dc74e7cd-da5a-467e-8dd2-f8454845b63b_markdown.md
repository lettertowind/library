## 1. 条形图与柱形图的关系

- 条形图和柱形图没有本质区别，可以理解为把柱形图旋转一下。
- 变换方式：
  - 原来在 x 轴上的内容移到 y 轴位置；
  - 原来条形向上生长，现在改为向右生长。
- 本节继续使用上节课的课件“01柱形图”。

## 3. 条形图常用参数与核心概念

讲师展示了常用参数表，并提示可以截图或课后下载笔记。条形图需要重点理解以下参数：

- **x 轴坐标 / 水平起点**
  - 条形图是从 x 轴的什么位置开始画。
  - 基础条形图从 x 轴的 `0` 位置开始。
  - 也就是说，水平条从左侧根部向右生长。

- **`bottom` 参数**
  - 讲师口述该参数表示条形图的起始位置，即 y 轴的起始坐标。
  - 在横向条形图中，条形底部视觉上对应条形的左侧/根部。
  - 这个起始位置由数据中的“姓名”列决定。
  - 也就是说，y 轴上代表的是姓名：张三多少分、李四多少分、王五多少分。

- **`height` 参数**
  - 表示条形的高度/粗细。
  - 可以自己设置，例如 `0.5`、`0.6`。
  - 也可以使用默认值。

- **`width` 参数**
  - 表示条形的长度/宽度。
  - 条形长度由“分数”决定。
  - 例如分数为 30、50、80、90，对应的条长不同：分数越高，条形越长。
  - 讲师强调：条的长度由数据中的分数列决定。

- **`color` 参数**
  - 用于设置条形颜色。
  - 颜色必须写英文，例如 `red`、`yellow`、`blue`、`green`。
  - 写中文“红色”不生效。
  - 默认颜色可能因 Matplotlib 版本不同而不同：上节课可能默认蓝色，本节课运行后默认红色，也可能是橘红色，这属于正常版本差异。

- **`alpha` 参数**
  - 用于设置透明度。
  - `alpha=0.5` 表示 50% 透明度。
  - 设置后颜色会变浅，例如红色会有点发粉。
  - 讲师用“颜色多洗几水掉色了”来比喻透明度变浅。

- **必须显式声明“做条形图”**
  - Matplotlib 默认是柱形图。
  - 上节课做柱形图时不用特别说明。
  - 本节课做条形图时，必须告诉程序当前做的是条形图，否则会按默认柱形图处理。
  - 讲师口述为“偶尔i”/设置条形图函数，实际对应横向条形图函数 `barh` 的思路。
  - 这一点是本节课最重要的注意事项之一，不能忘记。

## 4. 绘图流程与运行踩坑

- 先确定 x 轴坐标，基础条形图从水平 `0` 位置开始。
- 设置 `bottom`，表示每个条形左侧起点对应的数据，即“姓名”列。
- 设置条的高度，例如 `0.5`。
- 设置条的长度，由“分数”列决定。
- 设置颜色，例如 `red`。
- 设置透明度，例如 `alpha=0.5`。
- 调用 `plt.show()` 显示图像。
- 从本节课开始，部分简单内容不再逐一重复演示，后续按前两节课的方法添加即可。

**踩坑记录：**

- 第一次按照条形图方式绘图时出现错误，原因是只按条形图方式写了参数，却没有显式告诉程序“我要做条形图”。
- 加上声明条形图的语句后，再次运行成功，条形图正常生成。
- 这验证了：做条形图时必须明确指定图表类型，不能依赖默认柱形图。

## 5. 添加轴标签、标题与字体

- 使用 `plt.xlabel()` 设置 x 轴标签。
- 使用 `plt.ylabel()` 设置 y 轴标签。
- 初始演示时把 x 轴和 y 轴标签写反了：
  - 错误情况：x 轴写成“姓名”，y 轴写成“分数”。
  - 原因：条形图中 x 轴和 y 轴与柱形图相比发生了交换。
- 修改方式：
  - x 轴标签改为“分数”；
  - y 轴标签改为“姓名”。
- 重要结论：
  - 不管图形如何旋转，图表下方永远是 x 轴，上方永远是 y 轴。
  - 条形图中：x 轴表示分数，y 轴表示姓名。
- 字体大小可以设置，例如 `fontsize=20`。
- 粗体设置按上节课方法处理。
- 标题设置示例：`plt.title('3年二班', fontsize=16)`。
- 运行后标题显示正常。
- 文字旋转问题：
  - 本节课条形图不涉及影响旋转的问题。
  - 如果需要旋转，按上节课方法自行设置。

## 6. 图例使用时机

- 单个条形系列不需要添加图例。
- 如果只有一个颜色，再写图例说明“红色代表分数”属于多此一举。
- 只有在多系列、多颜色时才有必要添加图例。
- 示例：小王语文、数学、英语三科分别用三种颜色：
  - 红色代表语文；
  - 黄色代表数学；
  - 蓝色代表英语。
- 这种情况下才需要用图例说明颜色含义。

## 7. 本节总结与关键步骤

- 第一步：确定 x 轴起始位置。
  - 基础条形图从 x 轴的 `0` 位置开始。
  - 以后学习旋风图时，可能从 x 轴中间开始、向左右两个方向生长；当前先掌握最基础的条形图。

- 第二步：确定每个条形的起始数据。
  - 条形底部/左侧对应的数据是“姓名”列。
  - 讲师用 `bottom` 来描述这个起始位置概念。

- 第三步：设置条的高度/粗细。
  - 例如 `height=0.5`，可以自由调整。

- 第四步：设置条的长度。
  - 由“分数”列决定。
  - 分数高的条更长，分数低的条更短。

- 第五步：设置颜色和透明度。
  - 颜色使用英文，如 `red`。
  - 透明度使用 `alpha`，如 `0.5`。

- 第六步：不要忘记显式声明当前绘制的是条形图。
  - 这是本节最容易忘、也最容易导致错误的点。

- 第七步：按前两节课方法添加轴标签、标题、字体等细节。
  - x 轴标签为“分数”；
  - y 轴标签为“姓名”；
  - 标题示例为“3年二班”；
  - 字体大小、粗体、旋转等按需设置。

- 最后，讲师要求课后一定自己动手试一遍。
