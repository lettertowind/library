# 课程笔记：NumPy 数组的轴和转置

## 课程定位与核心问题

- 本课讲 NumPy 中的“轴（axis）”，是 NumPy 基础部分最重要的内容之一。
- 很多初学者不理解“轴是什么意思”，本课目标是讲清：
  - 轴号如何确定；
  - 一维、二维、三维数组中分别谁是 0 轴、1 轴、2 轴；
  - 如何沿轴切片；
  - 如何按轴号进行轴转置；
  - 直接数组转置与轴转置的区别。
- 讲师强调：如果学完仍不理解轴，需要说明“为什么不理解”，以便定位问题。

## 轴的基本结论：轴号就是维度索引

- 轴不是抽象方向，轴号可以理解为高维数组的“元组索引”。
- 判断轴的第一步：先看数组的维度。
  - 数组有几位维度，就有几个轴。
  - 轴号从 `0` 开始编号：`0, 1, 2, ...`
- 轴号与元组索引对等：
  - 一维数组：只有一个轴，即 `0` 轴。
  - 二维数组：有两个轴，即 `0` 轴、`1` 轴。
  - 三维数组：有三个轴，即 `0` 轴、`1` 轴、`2` 轴。
- 在多维数组中：
  - `0` 轴对应最高维，也就是最外层结构；
  - `1` 轴对应下一层结构；
  - `2` 轴对应最低的一维数据，也就是最内层结构。
- 关键记忆法：凡是提到轴，先看数组维度；有几位就有几个轴；具体哪个是哪个轴，看索引 `0, 1, 2...`。

## 用示例理解不同维度的轴

### 一维数组

- 示例：一维数组中写四个数。转录中数字识别为“729 十”，按讲师意思是一个包含四个元素的一维数组。
- 一维数组只有一个轴，即 `0` 轴。
- 原因：一维数组的索引只有 `0`，没有行、列等多层结构。

### 二维数组

- 示例：二维数组为“两行三列”。
- 维度对应两个轴：
  - 行是 `0` 轴；
  - 列是 `1` 轴。
- 下标理解：
  - 行索引为 `0, 1`；
  - 列索引为 `0, 1, 2`。
- 因此二维数组有两个轴：`0` 轴和 `1` 轴。

### 三维数组

- 示例：三维数组为“四块、每块三行两列”。
- 其维度元组可理解为 `(4, 3, 2)`：
  - 第一维：`4` 块；
  - 第二维：每块 `3` 行；
  - 第三维：每块 `2` 列。
- 对应三个轴：
  - `0` 轴：块，即最外层四块；
  - `1` 轴：行，即每块中的三行；
  - `2` 轴：列，即每块中的两列。
- 结构层级：
  - 最内层的一维数组：一行中的两个数；
  - 中间层二维数组：每块由三个一维数组组成，即三行两列；
  - 最外层三维数组：由四块二维数组组成。
- 讲师特别指出：书上常说“0 是行、1 是列、2 是纵深”，但如果对三维没有空间概念，这种记法容易听不懂。本课按嵌套层级理解更直观：
  - 块是 `0` 轴；
  - 行是 `1` 轴；
  - 列是 `2` 轴。

## 沿轴切片

### 二维数组的轴与切片前提

- 示例数组为三行三列。
- 它是二维数组，因此有两个轴：
  - 三行在 `0` 轴上；
  - 三列在 `1` 轴上。
- 切片的核心规则：
  - 切片第一个参数约定俗成代表 `0` 轴；
  - 如果索引中没有逗号，就只有一个参数，表示沿 `0` 轴切片；
  - 如果有逗号，逗号前代表行，逗号后代表列；
  - 切片和索引都不包含结束值。

### 示例一：`arr[:2]`

- 表达式：`[:2]`
- 这里没有逗号，只有一个参数，因此默认作用于 `0` 轴，也就是行。
- 含义：从第 `0` 行开始，到第 `2` 行之前，不包含 `2`。
- 实际取的是第 `0` 行和第 `1` 行。
- 因为二维数组由三个一维数组组成，索引为 `0, 1, 2`；取 `0` 和 `1` 两个一维数组，即取前两行。
- 在讲师示例中，得到类似 `123` 和 `456` 两行数据。

### 示例二：`arr[:2, 1:]`

- 表达式：`[:2, 1:]`
- 这里出现了逗号：
  - 逗号前 `[:2]` 代表行，即 `0` 轴；
  - 逗号后 `1:` 代表列，即 `1` 轴。
- 行部分：`[:2]` 表示从第 `0` 行到第 `1` 行，不包含 `2`。
- 列部分：`1:` 表示从第 `1` 列到所有列。
- 结果：取第 `0、1` 行中第 `1` 列及之后的数据。
- 若原数组为三行三列 `1~9`，则结果可理解为：
  - 第 `0` 行取第 `1、2` 列：`2, 3`
  - 第 `1` 行取第 `1、2` 列：`5, 6`
  - 即结果类似 `[[2, 3], [5, 6]]`
- 结论：`沿轴切片`就是沿着指定轴方向取子数组；无逗号时默认沿 `0` 轴，有逗号时按行、列顺序继续指定。

## 传入轴号与改变轴顺序

- 示例：将 `0~15` 共 `16` 个数构造成“两块、两行、四列”的三维数组。
- 该数组维度为 `(2, 2, 4)`，对应轴号为 `0, 1, 2`。
- 三维数组中最内层的一维数据对应 `2` 轴；每组四个数是一个一维数据，每个一维数据内部还有独立的索引编号。
- 传入轴号可以改变数组轴的排列顺序，从而改变数组结构。
- 对二维数组而言：
  - 原来的轴顺序是 `(0, 1)`；
  - 把轴顺序改为 `(1, 0)`，就实现了行列互换，也就是转置。
- 讲师演示：原来是 `0` 和 `1`，现在改成 `1` 和 `0`，运行后行变列。
- 轴转置与直接数组转置在二维数组上结果相同，但轴转置强调“按轴顺序变换”，更适合理解多维数组。

## 数组转置与轴转置

### 直接数组转置

- 转置类似 Excel 中的单元格转置：行变列、列变行。
- 讲师口述数字示例：
  - 原数组按 `1 2 3 4 5 6` 理解；
  - 转置后按讲师口述为 `1 3 5 / 2 4 6`，即排列为 `135246`。
- 示例：`24` 个数从 `0~23`，构成四行六列数组，即 `4*6` 的结构。
- 直接转置后，每一行都转成一列，实现行列互换。
- 直接转置方法：在数组后调用转置方法或属性。NumPy 常见写法为 `arr.T` 或 `arr.transpose()`，以讲师演示写法为准；讲师强调方法名要记住，必要时带括号。
- 转置本身不改变元素值，但会改变数组形状和元素排列。

### 轴转置

- 轴转置需要另一个方法，核心是传入轴顺序。
- 对二维四行六列数组：
  - 原轴顺序为 `(0, 1)`；
  - 改为 `(1, 0)` 后，行列互换。
- 常见 NumPy 写法为 `arr.transpose(1, 0)` 或 `arr.transpose((1, 0))`，具体以演示写法为准。
- 运行后同样实现行变列。
- 讲师总结两个操作：
  - 一个是直接数组转置；
  - 一个是轴转置。
- 二维情况下二者结果相同；轴转置的价值在于可以明确指定轴顺序，适用于多维数组。

## 易混点与踩坑记录

- 不要把轴号机械理解成固定的“行、列、纵深”名称；轴号本质上是维度元组索引。
- 三维数组要按嵌套层级看：
  - 最外层块是 `0` 轴；
  - 中间层行是 `1` 轴；
  - 最内层列是 `2` 轴。
- `0` 轴对应最高维，`1` 轴对应下一维，`2` 轴对应最低的一维数据。
- 切片没有逗号时，只有一个参数，默认沿 `0` 轴切；有逗号时才分别指定行、列。
- 切片不包含结束值：`[:2]` 取的是 `0、1`，不包含 `2`。
- 书上“0 行、1 列、2 纵深”的说法容易让三维数组难以理解；按“块、行、列”的嵌套结构理解更直观。
- 直接转置和轴转置在二维上结果相同，不要误以为二者没有区别；轴转置可以指定轴顺序，能用于多维。

## 本课结论

- 轴数等于数组维度数；轴号就是元组索引 `0, 1, 2...`。
- 一维数组只有 `0` 轴。
- 二维数组：行是 `0` 轴，列是 `1` 轴。
- 三维数组按本课理解：块是 `0` 轴，行是 `1` 轴，列是 `2` 轴。
- 沿轴切片先判断参数个数和逗号：
  - 无逗号：默认沿 `0` 轴；
  - 有逗号：按行、列顺序指定；
  - 切片不包含结束值。
- 转置分两类：
  - 直接数组转置：行变列、列变行；
  - 轴转置：传入轴顺序，如把 `(0,1)` 改为 `(1,0)`。
- 重点记住轴号规则、切片规则、直接转置方法和轴转置方法。
