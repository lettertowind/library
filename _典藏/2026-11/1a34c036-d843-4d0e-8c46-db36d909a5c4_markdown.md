# 孙兴华 Python 数据分析：Pandas Excel 文件的拆分与合并（p40 S02E25）

## 1. 课程主题与总体建议

本课讲解如何使用 `pandas` 完成 Excel 文件的拆分与合并，主要包括四类任务：

- 同一文件夹下多个工作簿合并。
- 同一工作簿中多个工作表 `sheet` 合并。
- 一个工作表按某一列拆分成多个工作表。
- 一个工作表按某一列拆分成多个工作簿。

课程中的示例以“理想状态”为主，忽略空行、复杂表头、格式、颜色、合并单元格等特殊情况；实际工作中需要结合 `read_excel`、`to_excel` 的参数进一步处理。

关于工具选择，视频中的观点是：

- 简单操作上，`pandas` 比 `VBA` 更方便。
- 复杂 Excel 操作、格式设置、颜色设置等，`VBA` 可能更方便，因为 `VBA` 是 Excel 原生工具。
- `pandas` 在 Excel 与 PDF 等文件协同处理时可能更友好。
- 总体建议“专业工具做专业的事”：复杂 Excel 格式操作优先考虑 `VBA`，简单批量读写、合并拆分可用 `pandas`。

## 2. 任务一：同一文件夹下多个工作簿合并

### 2.1 需求与默认假设

目标：将一个文件夹下多个 Excel 工作簿合并成一张总表。

视频中默认：

- 每个工作簿中只有一个工作表。
- 每个文件的结构基本相同。
- 先忽略特殊情况，用较少代码完成合并。

### 2.2 实现思路

核心思路是“准备一张空表，然后逐个读取文件并不断连接”：

- 假设有 1、2、3 三个文件。
- 第一次：空表连接 1 号文件。
- 第二次：空表与 1 号文件连接后的总表，再连接 2 号文件。
- 第三次：已经连接 1、2 号文件的总表，再连接 3 号文件。
- 以此类推。

### 2.3 关键步骤与代码逻辑

1\. 导入库  
需要导入 `pandas`，同时因为要读取文件夹下所有文件名，还需要导入 `os`。

2\. 定义路径  
路径指向包含多个 Excel 文件的文件夹，例如 `pandas` 文件夹下的课件 `025` 目录。

3\. 创建空表  
使用 `pd.DataFrame()` 创建空表，例如：

- `合并表 = pd.DataFrame()`

这个空表用于第一次连接。

4\. 获取文件夹下所有文件名  
使用 `os.listdir(路径)` 获取某个文件夹下所有文件和文件夹名称，并返回一个列表。该知识点在 Python 基础篇中讲过。

5\. 使用 `for` 循环遍历文件名  
例如：

- `for 文件名 in os.listdir(路径):`

变量名使用中文“文件名”便于理解。

6\. 读取每个 Excel 文件  
使用 `pd.read_excel(路径 + 文件名)` 读取文件。

注意：

- 路径和文件名都是字符串。
- 两个字符串拼接使用加号 `+`。
- 不要误用 `&` 连接符。

7\. 不断合并  
使用 `pd.concat()` 将当前合并表与新读取的表格连接：

- `合并表 = pd.concat([合并表, 表格])`

每次循环后，合并表都会包含之前已读取的数据。

8\. 打印检查  
使用 `print(合并表)` 查看合并结果。视频中验证三张表可以成功连接。

9\. 写回 Excel  
合并完成后，将结果写入新的 Excel 文件：

- `合并表.to_excel('c:/.../合并.xlsx')`

需要区分：

- `合并表` 只是内存中的变量名。
- 最终输出到哪个盘符、哪个文件夹、哪个文件名，由 `to_excel()` 中的路径决定。

### 2.4 注意事项

- 合并表初始应为空表，否则会多出无关数据。
- 文件路径与文件名拼接使用 `+`。
- 输出文件路径才是真正保存位置，变量名不是文件名。
- 视频中提到索引问题：默认输出可能带索引，可在 `to_excel()` 中设置 `index=False`，或参考第一节课中设置索引的方法。
- 本任务默认每个工作簿只有一个工作表；如果同一工作簿有多个工作表，需要进入下一个任务的处理方式。

## 3. 任务二：同一工作簿中多个工作表合并

### 3.1 读取同一工作簿的全部工作表

如果同一个 Excel 工作簿中有多个 `sheet`，读取时增加参数：

- `pd.read_excel(路径, sheet_name=None)`

其中：

- `sheet_name=None` 表示读取所有工作表。
- 返回结果是一个字典结构，键为工作表名，值为对应的 `DataFrame`。
- 如果工作簿中还有其他工作表，也会一并读取出来。

视频中先打印读取结果，看到多个工作表都被读取出来。打印结果看起来较乱，只是因为字典中包含多个表，主要用于验证读取是否成功。

### 3.2 合并多个工作表的思路

先创建空表：

- `合并表 = pd.DataFrame()`

然后获取所有工作表名称列表。视频中用类似：

- `字段名 = list(数据.keys())`

这里需要注意：`数据.keys()` 得到的是字典的键，也就是多个工作表的名称列表；视频中口述为“字段名”，实际更准确地说是“工作表名列表”。

随后循环工作表名：

- `for 列标签 in 字段名:`
- `新数据 = 数据[列标签]`
- `合并表 = pd.concat([合并表, 新数据])`

也就是：

- 每一次从字典中取出一个工作表的 `DataFrame`。
- 再与已有的合并表进行 `concat`。
- 循环结束后得到所有工作表合并后的总表。

### 3.3 多表头处理

如果 Excel 中有多行表头，需要在 `read_excel()` 中增加 `header` 参数。

例如两行表头：

- `pd.read_excel(路径, sheet_name=None, header=[0, 1])`

说明：

- `header` 默认是第 0 行作为表头。
- `header=[0, 1]` 表示第 0 行和第 1 行都作为表头。
- 如果多表头时不加 `header` 参数，表头可能错乱，出现每行都像表头的情况。
- 视频中使用课件 `025-2` 文件夹演示多表头文件。
- `header` 中写几，就表示把第几行作为表头。

### 3.4 `sheet_name` 参数补充

视频提到 `read_excel()` 的 `sheet_name` 参数可以灵活指定工作表：

- `sheet_name=None`：读取所有工作表，所有表都作为数据返回。
- 可以指定某个工作表名称，例如 `sheet_name='Sheet1'`。
- 也可以指定列表，例如 `sheet_name=[0, 1, 'Sheet5']`，表示选择第 1 页、第 2 页以及名称为 `Sheet5` 的工作表作为数据。
- 视频中还提到可设置类似 `sheet_name=1` 的形式读取指定页；实际使用时要注意 pandas 的工作表索引从 0 开始，建议结合工作表名称确认。

课程说明：`read_excel`、`to_excel` 的详细参数及中文解释已放入笔记，实际使用时可以随时查询，不需要一次性全部记住。

## 4. 任务三：一个工作表拆分成多个工作表

### 4.1 需求说明

示例数据是一个工作表，包含“部门”等列：

- 办公室
- 销售部
- 保洁部
- 实际工作中可能还有更多部门

目标：按照“部门”列，将一个工作表拆分成多个工作表，让每个部门的数据进入对应的工作表。

例如最终在同一个 Excel 文件中生成：

- 办公室工作表
- 销售部工作表
- 保洁部工作表

### 4.2 实现步骤

1\. 定义文件路径  
指定要读取的 Excel 文件路径。

2\. 读取数据  
使用：

- `数据 = pd.read_excel(路径)`

视频中强调这是较理想状态下的示例；实际工作可能遇到空行、表头不规范等问题，需要利用 `read_excel()` 的参数规避，相关参数已整理到笔记。

3\. 获取分割列的唯一值  
按“部门”列拆分时，需要先取得部门列中的唯一值。

由于部门列中会有重复值，例如多个“办公室”、多个“销售部”，因此需要先删除重复值：

- `数据['部门'].drop_duplicates()`

再转换为列表：

- `分割列 = list(数据['部门'].drop_duplicates())`

如果列中本来没有重复值，也可以直接转为列表；但实际数据通常需要先去重。

4\. 创建 `ExcelWriter` 对象  
因为要向同一个 Excel 文件中的不同工作表写入数据，需要使用 `pd.ExcelWriter()`：

- `新数据 = pd.ExcelWriter('c:/孙兴华.xlsx')`

`ExcelWriter` 可以向同一个 Excel 文件中的不同 `sheet` 写入数据。

标准保存 `pandas` 数据到 Excel 的方式是：

- 先创建 `ExcelWriter` 对象。
- 再使用 `DataFrame.to_excel(writer, sheet_name=...)` 写入。
- 最后保存并关闭 writer。

5\. 循环拆分并写入不同工作表  
使用：

- `for i in 分割列:`

每次循环得到一个部门名称，例如“办公室”“销售部”“保洁部”。

然后筛选该部门的数据：

- `数据一 = 数据[数据['部门'] == i]`

注意：比较是否相等要用双等号 `==`，赋值才用单等号 `=`。视频中演示时曾写成 `= i`，随后修正为 `== i`。

再将筛选后的数据写入指定工作表：

- `数据一.to_excel(新数据, sheet_name=i)`

其中：

- `新数据` 是 `ExcelWriter` 对象。
- `sheet_name=i` 表示用当前部门名称作为工作表名。

6\. 保存并关闭 writer  
最后执行：

- `新数据.save()`
- `新数据.close()`

视频运行后，在 C 盘生成了 `孙兴华.xlsx`，打开后可以看到办公室、销售部、保洁部等多个工作表，拆分成功。

### 4.3 注意事项

- 拆分到同一个 Excel 的多个工作表时，必须使用 `ExcelWriter`，否则后续写入可能覆盖前面的内容。
- 比较运算符是 `==`，不要写成赋值号 `=`。
- 索引取消可在 `to_excel()` 中设置 `index=False`，或按第一节课的方法处理。
- 如果 Excel 中有格式、颜色、单元格样式等，`pandas` 处理起来较麻烦；视频建议查阅笔记中的相关代码，必要时使用 `VBA`。
- 新版 pandas 中 `writer.save()` 可能被弃用，实际环境可使用 `writer.close()` 或上下文管理器，按当前 pandas 版本调整。

## 5. 任务四：一个工作表拆分成多个工作簿

### 5.1 与拆分多个工作表的区别

前一个任务是把一个工作表拆分成同一个 Excel 文件中的多个 `sheet`。

本任务是把一个工作表按照“部门”列拆分成多个独立 Excel 工作簿，例如：

- `办公室.xlsx`
- `销售部.xlsx`
- `保洁部.xlsx`
- 其他部门分别生成各自的 `.xlsx` 文件。

### 5.2 实现步骤

1\. 读取数据  
仍然使用 `pd.read_excel(路径)` 读取原工作表。

2\. 获取分割列唯一值  
与上一个任务相同：

- `分割列 = list(数据['部门'].drop_duplicates())`

3\. 循环部门列表  
使用：

- `for i in 分割列:`

4\. 筛选当前部门数据  
使用：

- `数据一 = 数据[数据['部门'] == i]`

同样注意使用双等号 `==`。

5\. 动态生成输出文件路径  
因为每个部门要保存成不同文件，所以输出路径需要动态拼接。

视频示例思路：

- `'c:/' + i + '.xlsx'`

其中 `i` 是当前部门名称，例如“办公室”“销售部”“保洁部”。

6\. 写入独立工作簿  
使用：

- `数据一.to_excel('c:/' + i + '.xlsx')`

可增加 `index=False` 取消索引。

7\. 运行验证  
视频运行后，在 C 盘下生成了办公室、销售部、保洁部等独立 Excel 文件。

### 5.3 注意事项

- 拆分成多个工作簿时，不需要创建 `ExcelWriter` 对象；每个部门直接调用一次 `to_excel()` 写入独立文件即可。
- 文件名通过字符串拼接生成：`路径 + 部门名 + '.xlsx'`。
- 后缀名 `.xlsx` 不能漏掉。
- 索引设置方式与前面相同，可在 `to_excel()` 中设置，也可参考第一节课的索引处理方法。
- 如果不同部门名称中包含特殊字符，实际使用时要考虑文件名合法性问题。

## 6. 核心函数与参数速查

| 函数或参数 | 作用 | 备注 |
|---|---|---|
| `os.listdir(路径)` | 获取文件夹下所有文件和文件夹名称 | 返回列表，常用于遍历多个工作簿 |
| `pd.DataFrame()` | 创建空表 | 合并前先准备空表 |
| `pd.read_excel(路径)` | 读取 Excel 文件 | 默认读取一个工作表 |
| `pd.read_excel(路径, sheet_name=None)` | 读取所有工作表 | 返回字典，键为工作表名 |
| `header=[0, 1]` | 指定多行表头 | 第 0、1 行都作为表头 |
| `pd.concat([表1, 表2])` | 纵向连接多个表 | 用于合并多个文件或多个工作表 |
| `数据.keys()` | 获取字典的键 | 在 `sheet_name=None` 时得到工作表名列表 |
| `数据['部门'].drop_duplicates()` | 删除重复值 | 用于获取唯一部门列表 |
| `list(...)` | 转为列表 | 将唯一值结果转为可遍历列表 |
| `pd.ExcelWriter(路径)` | 创建 Excel 写入对象 | 用于向同一 Excel 的多个工作表写入数据 |
| `DataFrame.to_excel(...)` | 写入 Excel | 可指定 `sheet_name`、`index` 等参数 |
| `writer.save()` | 保存 writer | 视频中使用，新版 pandas 注意版本差异 |
| `writer.close()` | 关闭 writer | 释放资源 |
| `index=False` | 不写入默认索引 | 可作为 `to_excel()` 参数使用 |

## 7. 实践建议与边界说明

- 本课代码是简化版，适合学习基本流程，实际数据可能包含空行、复杂表头、合并单元格、格式、公式、颜色等，需要额外处理。
- 合并多个工作簿时，默认每个工作簿只有一个工作表；若有多个工作表，需要设置 `sheet_name=None` 或指定工作表。
- 合并多个工作表时，打印字典结果看起来乱是正常的，重点是通过 `keys()` 获取工作表名并逐个连接。
- 拆分多个工作表时，关键是 `pd.ExcelWriter()`；拆分多个工作簿时，关键是动态拼接输出文件名。
- 筛选数据时务必使用 `==` 进行比较，避免把条件判断写成赋值。
- 如果只是做简单批量处理，`pandas` 代码短、效率高；如果涉及复杂 Excel 格式操作，建议使用 `VBA` 或结合其他工具。
- `read_excel`、`to_excel` 的参数很多，实际使用时建议查询笔记中的中文说明，结合具体数据情况调整 `header`、`sheet_name`、`index` 等参数。
