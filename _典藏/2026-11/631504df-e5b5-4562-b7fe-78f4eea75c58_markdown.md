# 分层索引与多层索引计算（Pandas）

## 一、课程主题与示例数据

- 本节主题：**分层索引（MultiIndex）** 与 **分层索引计算**。
- 核心目标：
  - 学会设置多层索引。
  - 学会查询多层索引。
  - 理解有序索引与无序索引的差异。
  - 掌握三种创建 MultiIndex 的方式。
  - 使用多层索引完成“总计”计算并横向拼接。

示例数据背景：

- 使用 `pandas` 读取 Excel 文件。
- 通过 `sheet_name` 选择工作表，示例工作表名为“有序”。
- 数据结构类似：
  - 班级：一班、二班、三班。
  - 学号/姓名：a、b、c 等。
  - 分数：由学号对应的数据。
- 层级关系：
  - 班级管理学号。
  - 学号管理分数。
  - 班级是外层索引，学号是内层索引。
- 这种“一层管一层”的结构就是多层索引/分层索引。

## 二、分层索引的设置方式

视频中给出两种常见设置方式，二者等价，可根据习惯选择。

### 方式一：读取 Excel 时直接设置索引列

在 `read_excel` 时使用 `index_col` 指定多列作为索引：

```python
import pandas as pd

data = pd.read_excel(
    "文件路径.xlsx",
    sheet_name="有序",
    index_col=[0, 1]
)
```

- `index_col=[0, 1]` 表示把第 0 列和第 1 列设置为多层行索引。
- 示例效果：
  - 一班管理 a、b、c。
  - 二班管理 a、b、c、4、5、6。
  - 三班管理 a、b、7、8 等。
- 视频作者个人更习惯这种方式，认为写起来更直接。

### 方式二：读取后使用 `set_index`

先正常读取数据，再使用 `set_index` 设置多层索引：

```python
data = pd.read_excel("文件路径.xlsx", sheet_name="有序")
data = data.set_index(["班级", "学号"])
```

- 视频中提到，很多老师更习惯这种写法。
- 两种方法效果一致，选择一种即可。
- 学习时建议知道两种写法，实际使用时按个人习惯选择。

## 三、分层索引的查询

查询多层索引主要使用 `.loc`。

### 基本规则

- `.loc` 的格式一般为：

```python
data.loc[行标签, 列标签]
```

- 多层行索引查询时，行标签通常写成**元组**。
- 元组中：
  - 第一个元素是外层索引/一级索引。
  - 第二个元素是内层索引/二级索引。
- 列标签若选择所有列，可以使用冒号 `:`。

### 查询单个二级标签

例如查询“一班”下“a”的数据：

```python
data.loc[("一班", "a"), :]
```

- 行索引用元组 `("一班", "a")`。
- 列索引用 `:` 表示所有列。
- 也可以省略列部分的逗号冒号，但讲解时建议写全。

### 查询外层索引下的全部数据

例如查询“一班”下所有行：

```python
data.loc[("一班", slice(None)), :]
```

- 多层索引中选择某一外层下的所有内层行时，内层可用 `slice(None)` 表示全部。
- 视频中特别强调：
  - 选择所有列可以用 `:`。
  - 在多层行索引中表示“任意所有行”时，不能简单只写冒号，应使用 `slice(None)` 这类写法。
  - `slice(None)` 在这里相当于“全部”的意思。

### 查询多个标签

如果要在查询中指定多个索引标签，可以继续在元组中写下一层索引，例如：

```python
data.loc[("一班", "a"), :]
```

- 第一个是外标签。
- 第二个是内标签。
- 后边的列部分用于选择列。

## 四、有序索引与无序索引

### 有序索引

示例中的：

- 一班、二班、三班。
- a、b、c 等。

这些索引本身具有自然顺序，可以按顺序排列，因此属于有序索引。

对于有序索引：

- 通常可以直接使用 `.loc` 查询。
- 查询结果较稳定。

### 无序索引

视频中另举了一个例子：

- 外层索引：科目，例如语文、数学。
- 内层索引：得分，例如最高分、最低分。
- 数据含义：
  - 语文最高分、最低分。
  - 数学最高分、最低分。
- 这种索引顺序不一定是排好序的，因此可能属于无序索引。

示例结构：

- 科目是外层索引/第一层索引。
- 得分是第二层索引。
- 科目管理最高分、最低分。

### 检查索引是否有序

视频中使用索引的有序性检查方法判断，例如 `index.is_lexsorted()` 等：

```python
data.index.is_lexsorted()
```

- 返回结果可用于判断多层索引是否处于有序状态。
- 如果结果表示无序，则直接查询可能会报错。
- 视频说明：不是所有无序查询都会报错，但为了安全，建议先排序再查询。

### 无序索引建议先排序

对于无序索引，建议先按索引排序：

```python
data = data.sort_index(level="科目")
```

然后再查询：

```python
data2 = data.loc["语文"]
print(data2)
```

- 排序后再查询可以避免潜在报错。
- 视频中强调：
  - 有序且能自动排好的索引，可以直接查询。
  - 无序索引建议先排序，再进行查询。

## 五、创建 MultiIndex 的三种方式

视频中介绍了三种创建多层索引的方法。

### 方式一：`from_arrays`

使用多个数组/二维数组创建 MultiIndex：

```python
pd.MultiIndex.from_arrays(
    [["a", "a", "b", "b"], [1, 2, 1, 2]],
    names=["x", "y"]
)
```

- `from_arrays` 接收数组形式的数据。
- 示例中外层是 `a、a、b、b`，内层是 `1、2、1、2`。
- 可以通过 `names` 给各层索引命名。
- 视频作者表示这种方式可以使用，但不是最推荐。

### 方式二：`from_tuples`

使用元组列表创建 MultiIndex：

```python
pd.MultiIndex.from_tuples(
    [("a", 1), ("a", 2), ("b", 1), ("b", 2)],
    names=["x", "y"]
)
```

- 每个元组表示一个多层索引组合。
- 元组中小括号左边是高维索引/一级索引，逗号后边是二级索引。
- 也可以通过 `names` 设置索引名称。
- 视频作者表示这种方式同样可以使用，但不是最推荐。

### 方式三：`from_product`（推荐）

使用笛卡尔积方式创建 MultiIndex：

```python
pd.MultiIndex.from_product(
    [["a", "b"], [1, 2]],
    names=["x", "y"]
)
```

- `from_product` 会生成多个一维数组元素之间的笛卡尔积。
- 示例结果等价于：
  - `("a", 1)`
  - `("a", 2)`
  - `("b", 1)`
  - `("b", 2)`
- 视频作者最推荐这种方式。
- 如果对笛卡尔积不熟悉，可以复习 Excel 基础篇、Excel Power Pivot 或 Power BI 基础中的相关内容。

### 索引名称 `names`

- 创建 MultiIndex 时可以直接设置 `names=["x", "y"]`。
- 视频中也提到可以后续设置名称。
- `names` 用于表示各层索引的名称。

## 六、行索引与列索引的创建

多层索引不仅可用于行索引，也可用于列索引。

- 行索引用参数 `index=`。
- 列索引用参数 `columns=`。
- 两者设置方法完全一样，只是用途不同。

示例思路：

```python
index = pd.MultiIndex.from_product(
    [["2023", "2024"], ["1月", "2月"]],
    names=["年", "月"]
)

columns = pd.MultiIndex.from_product(
    [["水果", "蔬菜"], ["香蕉", "苹果"]],
    names=["类别", "品名"]
)

df = pd.DataFrame(
    np.random.rand(4, 4),
    index=index,
    columns=columns
)
```

视频示例中：

- 行索引名称设置为“年”和“月”。
- 列索引涉及“水果”“蔬菜”等分类。
- 使用 `np.random` 生成随机数据。
- 使用 `pd.DataFrame` 创建带有多层行索引和多层列索引的 DataFrame。
- 具体语法可参考 pandas 笔记 3.2。

## 七、案例：分层索引计算总计

### 案例目标

有一张销售表，包含：

- 土豆的销量、毛利。
- 倭瓜的销量、毛利。
- 需要计算总计：
  - 土豆销量 + 倭瓜销量。
  - 土豆毛利 + 倭瓜毛利。
- 在工作统计中，“总计”是常见需求。

### 读取数据

```python
import pandas as pd

path = "销售.xlsx"
data = pd.read_excel(path)
print(data)
```

- 原始 Excel 中存在合并单元格，所以默认读取后显示可能不理想。
- 这不影响后续处理。

### 设置多层表头

需要把 Excel 前两行设置为列的多层表头：

```python
data = pd.read_excel(path, header=[0, 1])
print(data)
print(data.columns)
```

- `header=[0, 1]` 表示将第 0 行和第 1 行作为多层列索引。
- 行索引相关设置使用 `index_col`，具体可参考 pandas 笔记 2.1.2。
- 查看 `data.columns` 后可以看到类似：
  - `("土豆", "销量")`
  - `("土豆", "毛利")`
  - `("倭瓜", "销量")`
  - `("倭瓜", "毛利")`

### 计算总计

先分别取出土豆和倭瓜的数据并相加：

```python
总计 = data["土豆"] + data["倭瓜"]
print(总计)
```

- `data["土豆"]` 得到土豆对应的销量、毛利两列。
- `data["倭瓜"]` 得到倭瓜对应的销量、毛利两列。
- 两者相加，即可得到：
  - 总销量。
  - 总毛利。
- 此时得到的结果，列索引可能是单层的 `销量`、`毛利`。

### 给总计结果构造多层列索引

为了让总计结果与原始多层列索引结构一致，需要把总计结果的列也设置为 MultiIndex：

```python
总计.columns = pd.MultiIndex.from_product(
    [["合计"], 总计.columns]
)
```

- 外层新增“合计”。
- 内层沿用原来的 `总计.columns`，即销量、毛利。
- 这样总计结果的列索引就变成：
  - `("合计", "销量")`
  - `("合计", "毛利")`
- 视频中特别提醒：`from_product` 的参数中要注意列表嵌套，外层要加列表括起来。

### 横向拼接原始数据与总计

使用 `pd.concat` 进行横向拼接：

```python
result = pd.concat([data, 总计], axis=1)
print(result)
```

- `axis=1` 表示横向拼接。
- 拼接后列索引为：
  - 土豆：销量、毛利。
  - 倭瓜：销量、毛利。
  - 合计：销量、毛利。
- 行索引需要能够对齐。
- 本案例中两个二维数据相加能够成功，是因为它们的行索引一致、列索引结构一致。
- 视频中提到，两个一维数据相加可以，两个二维数据相加也可以；关键是索引对齐。
- 横向拼接的详细内容可参考 pandas 笔记 4.3.3。

### 结果说明

拼接后可得到类似结构：

- 土豆：销量、毛利。
- 倭瓜：销量、毛利。
- 合计：总销量、总毛利。

视频中说明：

- 数据计算结果正确。
- 写回 Excel 也没有问题。
- 在 Jupyter/Python 中显示 MultiIndex 列时可能出现错位现象，这是显示层面的问题，不影响最终数据结果。

## 九、本节核心结论

- 多层索引适合表达“外层分类管理内层分类”的数据结构。
- 设置多层索引可在读取时用 `index_col`，也可读取后用 `set_index`。
- 查询多层索引使用 `.loc`，行标签通常写成元组。
- 多层索引中选择全部内层行可使用 `slice(None)`。
- 有序索引可直接查询；无序索引建议先 `sort_index` 再查询。
- 创建 MultiIndex 的三种方式：
  - `from_arrays`
  - `from_tuples`
  - `from_product`（推荐）
- 行列索引都可以使用 MultiIndex，设置方法相同。
- 分层索引计算总计的核心步骤：
  - 分别取出外层分类数据。
  - 相加得到总计。
  - 为总计结果构造 MultiIndex 列。
  - 使用 `pd.concat(..., axis=1)` 横向拼接。
- MultiIndex 在 Jupyter 中可能显示错位，但不影响数据计算和写回 Excel。
