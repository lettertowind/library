## 2. 玫瑰图是什么：原理与关键点

- 玫瑰图的本质：**雷达图的变形**。
- 实现方式：在一个极坐标圆盘上绘制多个柱形图，最后在中间挖一个孔。
- 与雷达图相同的关键问题：**首尾不闭合、封不了口**。
- 雷达图封口方法：把第一个值取出来放到最后，使首尾重合，从而闭合。
- 玫瑰图同样需要处理封口问题：业绩、角度、姓名都要把第一个值补到末尾。
- 颜色处理：
  - 可以用 NumPy 的随机方式生成颜色。
  - 但随机生成的颜色可能不好看。
  - 建议自己配色；笔记中提供了颜色表，包含常用颜色和颜色表颜色。
- 数据准备：
  - 课件数据来自 Power BI 课件。
  - 姓名从 `a` 到 `t`。
  - 业绩为对应数值。
  - 操作前要先按业绩 **降序排序**；排序方法在第一节课讲过，本节不再频繁演示。
  - 数据共 20 条，因此准备 20 种颜色。

## 4. 生成角度

- 玫瑰图需要先确定每个柱子所在的角度。
- 讲师使用 `np.linspace` 生成角度。
- 关键代码：

```python
angles = np.linspace(0, 2*np.pi, len(data['业绩']), False)
```

- 参数说明：
  - 起点为 `0`。
  - 终点为 `2*np.pi`，即 \(2\pi\)，对应一整圈。
  - 数量为 `len(data['业绩'])`，即数据条数。
  - 第四个参数传入 `False`，表示 `endpoint=False`，不包含终点；这样角度按数据点均分，后面再补首值闭合。
- 生成后打印角度检查，视频中打印结果正常。
- 角度数量要与业绩数据数量一致。

## 5. 实例化极坐标并处理闭口

### 5.1 创建极坐标空圆盘

- 使用 `plt.axes(polar=True)` 实例化一个极坐标坐标系：

```python
ax = plt.axes(polar=True)
```

- 先运行 `plt.show()`，可以看到一个空的圆盘。
- 这个空圆盘就是后续绘制玫瑰图的极坐标画布。

### 5.2 使用 `np.concatenate` 补首值闭合

- 需要把业绩、角度、姓名的第一个值追加到末尾。
- 业绩闭口代码示意：

```python
values = np.concatenate((data['业绩'], [data['业绩'][0]]))
```

- 角度闭口代码示意：

```python
angles = np.concatenate((angles, [angles[0]]))
```

- 姓名闭口代码示意：

```python
names = np.concatenate((data['姓名'], [data['姓名'][0]]))
```

### 5.3 重要踩坑：列表不能直接和单个元素连接

- `data['业绩']` 本身是一个列表/序列。
- `data['业绩'][0]` 取出的是单个元素。
- 列表和单个元素不能直接 `concatenate`。
- 必须把第 0 个元素再包进列表中：

```python
[data['业绩'][0]]
```

- 这样两个列表才能连接。
- 视频中检查结果：业绩从 `892` 开始、从 `892` 结束，说明已经连接闭合。
- 角度补首值后，从 `0` 开始、从 `0` 结束，正好绕一圈回来。
- 姓名补首值后，从 `a` 开始、从 `a` 结束，也绕一圈回来。

## 6. 绘制玫瑰图主体柱形图

- 玫瑰图主体本质上是在极坐标中绘制柱形图：

```python
plt.bar(angles, values, width=0.33, color=colors)
```

- 参数解释：
  - `angles`：x 轴位置，在极坐标中表示角度。
  - `values`：y 轴高度，在极坐标中表示业绩数值。
  - `width=0.33`：柱子的宽度；视频中取 `0.33`，宽度可以继续试。
  - `color=colors`：颜色由前面准备的 20 种颜色列表决定。
- 理解重点：
  - 柱形图的 x 轴是角度。
  - 柱形图的 y 轴是业绩。
  - 角度决定柱子在圆周上的位置，业绩决定柱子从中心向外的长度。
- 运行后可得到玫瑰图的雏形。

## 7. 调整极坐标起始方向

- 默认图形看起来可能“趴着”或方向不符合预期。
- 使用 `set_theta_zero_location('N')` 调整 0 度位置：

```python
ax.set_theta_zero_location('N')
```

- 作用：让极坐标的 0 度位置指向正上方 `N`，类似于指南针的上方永远是 `N`。
- 讲师用指南针作比喻：指南针上方指向 `N`；如果上方不是 `N`，那就是假指南针。
- 该设置让图形起始位置变得端正。
- 讲师还提到可用 `set_theta_direction(...)` 调整方向/位置，口述可产生旋转或反向效果；本节课不需要，因此未启用。具体参数以 Matplotlib 文档为准。

## 8. 中间挖孔

- 玫瑰图中间挖孔的方法：在已有柱形图上再叠加绘制一个白色柱形图，用白色覆盖中间区域。
- 代码示意：

```python
plt.bar(angles, height=130, width=0.33, color='white')
```

- 参数解释：
  - `angles`：角度仍然使用前面的角度。
  - `height=130`：固定长度，视频中取 `130`，作为挖孔半径。
  - `width=0.33`：宽度必须与主体柱形图保持一致，否则图形不好看。
  - `color='white'`：用白色覆盖，形成中间空心孔洞效果。
- 如果觉得 `130` 不够，可以自行加大数值。
- 挖孔与主体柱形图的唯一主要区别：主体柱高由业绩决定，挖孔柱高是固定值。

## 9. 关闭坐标轴外框与网格

- 画完后需要关闭极坐标外部的圆圈、刻度、网格等杂乱线条。
- 使用 `plt.gca()` 获取当前坐标轴，再调用 `set_axis_off()`：

```python
plt.gca().set_axis_off()
```

- 作用：关闭坐标轴显示，包括外圈、网格线、刻度等。
- 关闭后图形更干净。
- 关闭坐标轴后，必须通过数据标签告诉读者每种颜色/每个柱子代表谁。

## 10. 添加数据标签

- 使用 `zip` 把角度、业绩、姓名组合起来遍历：

```python
for angle, value, name in zip(angles, values, names):
    plt.text(angle + 0.03, value + 100, str(name))
```

- 参数解释：
  - `angle + 0.03`：角度微调，使标签在角度方向稍微偏移。
  - `value + 100`：业绩方向加上一定距离，使标签显示在柱子外侧。
  - `str(name)`：显示姓名文本。
- 视频中通过 `zip(角度, 业绩, 姓名)` 将三者拼到一起。
- 标签距离可以继续微调：
  - 角度可加 `0.03` 左右微调。
  - 业绩可加 `100` 左右让标签向外延伸。
- 完成后，最简单的玫瑰图就出来了。
- 数据标签的作用：图形关闭坐标轴后，需要说明绿色、黄色等各代表谁，标签能清楚展示每个柱子的姓名。

## 11. 完整代码骨架

以下为按视频讲解顺序整理的代码骨架，变量名按语义整理，实际运行以课件变量名为准：

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 中文显示设置按课件/笔记配置
# plt.rcParams['font.sans-serif'] = ['SimHei']
# plt.rcParams['axes.unicode_minus'] = False

# data：姓名 a-t，业绩数值，已按业绩降序排序
# colors：20 种颜色列表，来自笔记颜色表
# colors = [...]

# 1. 生成角度：不包含终点，后续补首值闭合
angles = np.linspace(0, 2*np.pi, len(data['业绩']), False)

# 2. 闭口处理：把第一个值补到末尾
values = np.concatenate((data['业绩'], [data['业绩'][0]]))
angles = np.concatenate((angles, [angles[0]]))
names = np.concatenate((data['姓名'], [data['姓名'][0]]))

# 3. 实例化极坐标
ax = plt.axes(polar=True)

# 4. 设置 0 度位置在正北/正上方
ax.set_theta_zero_location('N')

# 5. 绘制玫瑰图主体柱形图
plt.bar(angles, values, width=0.33, color=colors)

# 6. 中间挖孔：白色柱形图覆盖，宽度保持一致
plt.bar(angles, height=130, width=0.33, color='white')

# 7. 关闭坐标轴
plt.gca().set_axis_off()

# 8. 添加数据标签
for angle, value, name in zip(angles, values, names):
    plt.text(angle + 0.03, value + 100, str(name))

plt.show()
```

| `np.concatenate(...)` | 连接列表，实现首尾闭合 | 业绩、角度、姓名都把第一个值补到末尾 |
| `[data['业绩'][0]]` | 把单个元素包成列表 | 避免列表与单个元素直接连接报错 |

| `ax.set_theta_zero_location('N')` | 设置 0 度位置在正上方 | 类似指南针 `N` |
