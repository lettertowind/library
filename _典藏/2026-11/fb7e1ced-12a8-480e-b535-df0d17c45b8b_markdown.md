## 1. 数组与矩阵的区别

视频先通过 Excel 演示帮助理解数组的维度，并强调很多初学者容易把“数组”和“矩阵”弄反。

- **一维数组**：一行五列的数据就是一个一维数组，可理解为 `1×5` 的数组。
- **二维数组**：多行多列的数据是二维数组，例如三行三列的数据，形状可看作 `3×3`。
- **三维数组**：可以理解为由多块二维数组组成。例如视频中举例：分成四块，每块是三行两列的二维数组，则可表示为形状 `4×3×2`。
- **四维、五维数组**：不容易直接画图可视化，但在数据层面仍然可以表示和操作。

关于矩阵与数组的关系：

- 二维数组可以看成一个矩阵，很多计算场景下二者是通用或相似的。
- 矩阵可以理解为数组的一个分支；数组的适用范围更广，可以是一维、二维、三维甚至更高维。
- 数组和矩阵在索引方式上有相同点，都可以通过下标方式获取数据。
- 在实际使用建议上：如果数组和矩阵都可以完成任务，优先选择数组，因为数组更灵活、速度更快。
- 很多人把二维数组称为矩阵也可以，但需要注意二者并非完全等同。

学习提示：视频提到，如果对 `range`、列表推导式等 Python 基础不熟悉，应先补充 Python 基础课程，再学习 NumPy 数据分析内容。

## 2. 用 Python 普通方式实现数组相加

视频通过一个例子对比 Python 普通循环方式与 NumPy 方式的差异。目标是生成两个数组并逐元素相加。

设定对 $i=1,2,\dots,n$：

- 数组 $a$ 中每个元素为 $a_i=i^3$，即 $1$ 到 $n$ 的立方。
- 数组 $b$ 中每个元素为 $b_i=i^2$，即 $1$ 到 $n$ 的平方。
- 结果数组 $c$ 中每个元素为 $c_i=a_i+b_i$。

普通 Python 实现思路如下：

- 定义一个函数，形参为 `n`。
- 使用列表推导式生成数组 `a`：对 `range(1, n+1)` 中的每个数取三次方。
- 使用列表推导式生成数组 `b`：对 `range(1, n+1)` 中的每个数取二次方。
- 定义空列表 `c = []`。
- 使用 `for` 循环，通过下标逐项相加，并用 `c.append(a[i] + b[i])` 追加结果。
- 最后返回或打印列表 `c`。

这里需要注意 `range(1, n+1)` 的原因：`range` 的结束位置不包含自身。如果要取从 $1$ 到 $n$，结束位置必须写 `n+1`；如果省略起始位置，则会从 $0$ 开始。

以 `n = 3` 为例：

- `a = [1, 8, 27]`，因为 $1^3=1$，$2^3=8$，$3^3=27$。
- `b = [1, 4, 9]`，因为 $1^2=1$，$2^2=4$，$3^2=9$。
- 逐下标相加：
  - 下标 `0`：`a[0] + b[0] = 1 + 1 = 2`
  - 下标 `1`：`a[1] + b[1] = 8 + 4 = 12`
  - 下标 `2`：`a[2] + b[2] = 27 + 9 = 36`
- 因此结果 `c = [2, 12, 36]`。

视频通过调试查看结果，说明在普通 Python 中完成数组逐元素相加比较麻烦：需要定义函数、生成列表、创建空列表、写 `for` 循环并逐个追加。

## 3. 用 NumPy 实现同样的数组相加

NumPy 方式明显更简洁。首先导入 NumPy，并约定俗成地起别名：

- `import numpy as np`，通常将 NumPy 简写为 `np`。
- Pandas 通常简写为 `pd`。

NumPy 实现思路：

- 定义函数，形参仍为 `n`。
- 使用 `np.arange(1, n+1)` 生成从 $1$ 到 $n$ 的数组。
- 数组 `a` 通过 `np.arange(1, n+1) ** 3` 得到立方数组。
- 数组 `b` 通过 `np.arange(1, n+1) ** 2` 得到平方数组。
- 最后直接 `return a + b`，即可完成逐元素相加。

`np.arange` 与 Python 的 `range` 类似，结束位置不包含自身。若从 $1$ 开始并取到 $n$，需要写成 `np.arange(1, n+1)`；如果从 $0$ 开始，可以省略起始位置；如果不是从 $0$ 开始，则必须指定起始位置。

传入 `n = 3` 时：

- `np.arange(1, 4)` 生成 `[1, 2, 3]`
- 立方后得到 `[1, 8, 27]`
- 平方后得到 `[1, 4, 9]`
- `a + b` 直接得到 `[2, 12, 36]`

因此 NumPy 不需要显式写 `for` 循环，也不需要通过下标逐个追加，而是直接对整个数组进行向量化计算。

## 4. 两种方式的核心差异

- **普通 Python 列表方式**：先循环遍历，再逐个计算、逐个追加，代码较长，步骤较多。
- **NumPy 方式**：直接对数组进行整体运算，代码简短，执行效率高，属于向量化计算。
- 当数据量较小时，差距可能不明显；当数据量增大时，NumPy 的性能优势会更明显。
- 视频提到可以使用计时工具观察耗时，NumPy 在数据量较大时可能节省几倍甚至十几倍时间。

核心结论：

- 二维数组与矩阵在部分场景下可以通用，但数组更通用、更灵活。
- 数组可以通过下标索引获取数据，二维数组可视为矩阵。
- Python 普通循环实现数组逐元素相加比较繁琐。
- NumPy 使用 `np.arange` 生成数组，并通过 `**` 与 `+` 直接完成整体运算，比普通 `for` 循环更简洁高效。
- 本节通过简单示例体验了 NumPy 与普通 `for` 循环的差异，后续开始正式学习 NumPy 数组的建立方法。
