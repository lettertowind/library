## 3. 绘制基础饼图

- 使用 Matplotlib 的饼图函数 `plt.pie()`。
- 视频中绘制饼图时涉及以下要素：
  - 通过 `x=` 指定用于绘制饼图的数值数据；转录中识别为“`px等于数据点第一次`”，可理解为将数据中的某一列数值传给饼图。
  - 通过 `labels=` 指定每个扇区的标签；转录中识别为“`e l e s等于`”以及“数据点姓名”，实际意图是使用姓名列作为标签。
  - 视频中还提到“`top这个元组`”，结合上下文，是在设置与扇区分离相关的元组参数，即 `explode`。
- 为看清楚效果，讲师将其中一块扇区从饼图中心向外分离。
- 分离时，其他扇区的分离距离设为 0，只让目标扇区产生偏移。
- 视频中特别调整了王五对应的扇区，使王五这一块分离出来，以便更清楚地观察效果。
- 绘制后调用 `plt.show()` 显示图形。
- 基础饼图显示正常，说明数据与基础绘图没有问题。

可识别的核心代码结构可整理为：

```python
plt.pie(
    x=...,          # 数值数据，决定各扇区大小
    labels=...,     # 姓名等标签
    explode=...     # 将某一块扇区分离出来，其他块可为 0
)
plt.show()
```

## 4. 添加“3D”效果的关键参数

- 要让饼图显示立体效果，只需要增加一个参数：`shadow=True`。
- 转录中讲师口述为“`c h a d o w` 等于 `true`”，实际 Matplotlib 参数名是 `shadow`。
- `shadow` 参数的含义是控制是否显示阴影。
- `shadow` 的默认值是 `False`，即默认不显示阴影。
- 将 `shadow` 设置为 `True` 后，饼图会增加阴影效果。
- 增加阴影后，视觉上会产生类似 3D 的立体感。
- 讲师强调：它实际上只是增加了一个阴影，并不是真正的三维图形。

核心参数写法：

```python
plt.pie(
    x=...,
    labels=...,
    explode=...,
    shadow=True     # 开启阴影，模拟 3D 立体效果
)
plt.show()
```

## 5. 参数与概念说明

| 概念/参数 | 是什么 | 怎么工作 | 易混点与注意事项 | 使用场景 |
|---|---|---|---|---|
| `plt.pie()` | Matplotlib 中绘制饼图的函数 | 根据传入的数值计算各扇区角度，并按标签显示分类占比 | 和柱状图、折线图函数不同，饼图主要用于表示占比 | 展示分类数据的比例关系 |
| `x=` | 传给饼图的数值数据 | 数值大小决定每个扇区所占比例 | 不是标签；标签应通过 `labels` 设置 | 将数据列传入饼图 |
| `labels=` | 每个扇区的名称标签 | 在饼图各扇区旁显示对应名称 | 与数值参数 `x` 区分；标签本身不决定扇区大小 | 显示姓名、类别等 |
| `explode` | 控制扇区从圆心向外偏移的参数 | 通常传入元组，元组中每个元素对应一个扇区；为 0 表示不分离，非 0 表示向外偏移 | 与 `shadow` 不同：`explode` 控制位置分离，`shadow` 控制阴影 | 突出显示某个扇区，例如让“王五”这一块分离出来 |
| `shadow` | 是否显示阴影的布尔参数 | `False` 为默认值，不显示阴影；`True` 显示阴影 | 只是阴影效果，不是真正的 3D 坐标变换；容易误称为真正 3D | 快速让二维饼图产生立体观感 |
| `plt.show()` | 显示当前绘制的图形 | 调用后展示图像 | 需要在绘图代码之后调用 | 查看饼图最终效果 |

## 6. 视频中的对比与结论

- **Matplotlib 的“3D 饼图”不是真 3D**：它只是通过 `shadow=True` 增加阴影，从而让二维饼图看起来有立体感。
- **与 Excel 的对比**：效果和 Excel 里的 3D 饼图差不多，主要是视觉阴影，不是真正三维空间中的图形。
- **与 C4D 的对比**：和 C4D 等三维软件做出来的效果完全不一样，不能把 Matplotlib 的阴影效果理解为真正三维建模或三维渲染。
- **实现非常简单**：只需要设置 `shadow=True`；默认 `shadow=False` 时不显示阴影。
- **分离扇区用 `explode`**：视频中为了让某一块更明显，使用分离参数将王五对应的扇区向外偏移。
- **参数不必过多**：本节演示遵循“越简单越好”，重点是说明阴影参数的作用。

- 本节补充了上一节课饼图中遗漏的“3D 效果”知识点。
- Matplotlib 饼图的立体效果由 `shadow=True` 实现。
- `shadow` 默认值为 `False`，设置为 `True` 后显示阴影。
- 该效果本质上是阴影，不是真正的 3D。
- 若想让某一块扇区突出，可使用 `explode` 将其从饼图中心分离。
- 最终结论：Matplotlib 饼图的“3D 功能”就是一个阴影参数，效果类似 Excel 的 3D 饼图，而不是 C4D 等软件中的真正三维效果。
