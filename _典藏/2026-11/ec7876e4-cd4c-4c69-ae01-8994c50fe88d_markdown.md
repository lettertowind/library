## 3. 整表替换：`DataFrame.replace`
- 目标示例：把“城八区”替换成“海淀区”。
- 基本写法：
  
      data.replace('城八区', '海淀区')

- 关键点：直接运行 `replace` 不会修改原数据，也不会有明显效果。
- 原因：`replace` 默认返回一个新的对象，而不是直接在原对象上修改。类似 Python 基础篇中讲字符串 `replace` 时留下的问题：直接打印变量名，原字符串没有变化。
- 解决方式一：把返回结果赋值给新对象。
  
      data1 = data.replace('城八区', '海淀区')
      print(data1)

- 解决方式二：使用 Pandas 中学过的 `inplace` 参数，设置为 `True`，表示在原数据上修改。
  
      data.replace('城八区', '海淀区', inplace=True)
      print(data)

- 使用 `inplace=True` 后，不需要再赋值给 `data1`；此时直接修改原数据。
- 整表替换的效果：
  - `data.replace(...)` 会替换整张表中所有列里匹配到的值。
  - 运行后不仅城市2列中的“城八区”会变，城市1等其他列中的“城八区”也会被替换。
- 结论：
  - 如果确实要整表替换，可以直接用 `data.replace(旧值, 新值, inplace=True)`。
  - 如果只想替换某一列，不能直接用整表替换，需要先指定列。

## 4. 指定某一列进行替换
- 目标：只替换“城市2”这一列中的“城八区”，不影响其他列。
- 写法：
  
      data['城市2'].replace('城八区', '海淀区', inplace=True)
      print(data)

- 也可以写成赋值方式：
  
      data['城市2'] = data['城市2'].replace('城八区', '海淀区')
      print(data)

- 关键理解：
  - `data['城市2']` 取出的是这一列，即一个 `Series`。
  - 对这一列调用 `replace`，只处理该列数据。
  - `inplace=True` 表示在原数据上修改。
- 核心模式：
  
      data[列名].replace(旧值, 新值, inplace=True)

- 运行效果：只有“城市2”列中的“城八区”变成“海淀区”，其他列不受影响。

## 5. 多值替换：列表方式与字典方式
- 目标示例：把 `a` 替换成 `20`，把 `b` 替换成 `30`。
- 演示时指定“数值”列，避免影响其他列：
  
      data['数值'].replace(...)

### 5.1 列表方式：旧值列表 + 新值列表
- 写法：
  
      data['数值'].replace(['a', 'b'], [20, 30], inplace=True)
      print(data)

- 效果：
  - `a` 被替换成 `20`。
  - `b` 被替换成 `30`。
- 含义：
  - 第一个列表是旧值列表。
  - 第二个列表是替换值列表。
  - 两个列表按位置一一对应。
- 讲师评价：
  - 这是一种“笨办法”。
  - 个人不推荐用列表方式做多个不同值的替换。
  - 学了 Pandas 之后，建议优先使用更清晰、更高级的写法。

### 5.2 字典方式：推荐用于多个不同值替换
- 写法：
  
      data['数值'].replace({'a': 20, 'b': 30}, inplace=True)
      print(data)

- 也可以先把字典定义在外面，再把字典变量名传给 `replace`：
  
      dic = {'a': 20, 'b': 30}
      data['数值'].replace(dic, inplace=True)
      print(data)

- 字典含义：
  - 字典的 key 是原值。
  - 字典的 value 是替换后的新值。
  - 例如 `'a': 20` 表示把 `a` 替换成 `20`。
- 讲师推荐：
  - 多个不同值替换时，推荐使用字典方式。
  - 字典定义在外面，再传入变量名，代码看起来更清楚。
- 注意：代码中的字符串、字典符号要使用英文半角符号。

## 6. 多个旧值替换为同一个新值时用列表
- 目标示例：把 `a` 和 `b` 都改成 `30`。
- 推荐写法：
  
      data['数值'].replace(['a', 'b'], 30, inplace=True)
      print(data)

- 效果：
  - `a` 变成 `30`。
  - `b` 也变成 `30`。
- 关键区别：
  - 如果多个旧值要替换成多个不同的新值，推荐用字典：
    
        data['数值'].replace({'a': 20, 'b': 30}, inplace=True)

  - 如果多个旧值都要替换成同一个新值，推荐用列表：
    
        data['数值'].replace(['a', 'b'], 30, inplace=True)

- 列表方式中，如果第二个参数写单个值，表示把列表中所有旧值都替换成这个新值；如果第二个参数写列表，则按位置一一对应替换。
- 讲师建议：
  - 多个不同值替换用字典。
  - 多个旧值替换为同一个值用列表。
  - 这是个人推荐，不是强迫，但实际写代码时更清晰。

## 7. 替换某列中的部分内容：`Series.str.replace`
- 目标示例：只替换“城市2”列中的部分字符串，把“城八区”改成“市区”。
- 这里不能直接用普通的 `DataFrame.replace` 做子串替换，而应使用字符串方法 `str.replace`。
- 写法：
  
      data['城市2'] = data['城市2'].str.replace('城八区', '市区')
      print(data)

- 视频中也演示了等价思路：把“城八”替换成“市”，从而让“城八区”变成“市区”：
  
      data['城市2'] = data['城市2'].str.replace('城八', '市')
      print(data)

- 关键点：
  - `str.replace` 是 `Series` 的字符串方法。
  - 它用于替换字符串中的部分内容，即子串替换。
  - 只对指定列生效，不会影响其他列。
  - 适用于字符型列。
- 与 `DataFrame.replace` 的区别：
  - `data.replace(旧值, 新值)` 更偏向整值匹配替换。
  - `data['列'].str.replace(旧子串, 新子串)` 用于替换字符串内部片段。
- 如果忘记用法，可以回到笔记中搜索 `str` 或 `str.replace` 查看。
- 结论：
  - 替换整列中的完整值：用 `data['列'].replace(...)`。
  - 替换列中字符串的一部分：用 `data['列'].str.replace(...)`。

## 8. 正则表达式替换：`regex=True`
- 场景：需要把符合某种模式的内容批量替换，例如把所有大写字母 `A` 到 `Z` 替换成 `88`。
- 如果用列表方式写：
  
      ['a', 'b', 'c', 'd', 'e', 'f', 'g']

  还可以写，但如果要写 26 个字母会非常麻烦。
- 因此可以使用正则表达式。
- 基本写法：
  
      data.replace('[A-Z]', '88', regex=True, inplace=True)
      print(data)

- 参数说明：
  - `'[A-Z]'`：正则表达式，表示匹配所有大写字母 A 到 Z。
  - `'88'`：替换成的新值。
  - `regex=True`：告诉 Pandas 把第一个参数当作正则表达式处理。
  - `inplace=True`：在原数据上修改。
- 如果只想替换 A 到 G，可以使用：
  
      data.replace('[A-G]', '88', regex=True, inplace=True)

- 视频中提到只演示大写字母；如果小写字母也要替换，需要再写对应的小写模式。
- 关键注意点：
  - 使用正则表达式时，一定要把正则写在引号中。
  - 不需要 `import re`，Pandas 的 `replace` 可以直接配合 `regex=True` 使用。
  - 不要只写中括号而不加引号，否则容易被误认为列表或写错。
  - 如果不写 `regex=True`，Pandas 不会把 `'[A-Z]'` 当成正则，而会把它当成普通字符串去查找；数据中通常没有这个字符串，因此不会发生替换。
  - 如果第一个参数不是正则表达式，千万不要加 `regex=True`。
  - `regex=True` 和 `inplace=True` 可以同时使用。
- 参考：讲师提示可查看 Pandas 笔记第 9.2 章，其中介绍过正则相关参数的设置。
- 学习提示：如果需要系统学习正则表达式，可参考爬虫课程前三节的正则表达式内容；可以不学爬虫，但正则表达式值得掌握。

## 9. 关键结论与易混点
- `replace` 默认返回新对象，不修改原数据；要修改原数据需使用 `inplace=True`，或把结果赋值给新变量。
- 整表替换：
  
      data.replace(旧值, 新值, inplace=True)

  会替换所有列中匹配到的值。

- 指定列替换：
  
      data['列名'].replace(旧值, 新值, inplace=True)

  只替换指定列。

- 多个不同值替换，推荐字典：
  
      data['列名'].replace({'旧值1': '新值1', '旧值2': '新值2'}, inplace=True)

- 多个旧值替换成同一个新值，推荐列表：
  
      data['列名'].replace(['旧值1', '旧值2'], 同一个新值, inplace=True)

- 替换字符串中的部分内容，用 `str.replace`：
  
      data['列名'] = data['列名'].str.replace('旧子串', '新子串')

- 正则替换：
  
      data.replace('正则表达式', '新值', regex=True, inplace=True)

- 易混点对比：
  - `DataFrame.replace`：更常用于整值替换或映射替换。
  - `Series.str.replace`：用于字符串列内部的部分内容替换。
  - `regex=True`：只在第一个参数是正则表达式时使用。
  - `inplace=True`：表示在原数据上修改；不写则返回新对象。
- 代码书写注意：字符串、字典、正则表达式中的符号建议使用英文半角符号。
