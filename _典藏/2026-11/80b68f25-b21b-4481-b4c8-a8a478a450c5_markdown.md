# 孙兴华中文讲 Python 数据分析三部曲入门篇：删除重复和提取重复

## 1. 课程目标与数据准备

- 本节课目标：处理数据中的重复值，学习 pandas 中两个核心函数：`drop_duplicates` 删除重复值，`duplicated` 判断/提取重复值。
- 导入 pandas 模块：`import pandas as pd`。
- 准备数据路径：示例使用一个 Excel 文档做测试；实际工作中可能是 csv 文件，只需把读取方式改成 csv，其他操作完全一样。
- 读取数据示例：`tt = pd.read_excel('路径.xlsx')`；如果文件是 csv，则改成 `tt = pd.read_csv('路径.csv')`。
- 打印查看数据：`print(tt)`。
- 示例数据字段：有指定的索引列“序号”，列包括性别、姓名、分数。
- 示例数据中的重复姓名：杨过、小龙女、郭靖。
- 示例数据中的不重复姓名：张三丰、张无忌。

## 2. 回顾取唯一值与频次统计

### 2.1 `unique` 取唯一值

- 在学习 NumPy 时学过 `unique`，它可以直接取出唯一值。
- 讲师一开始忘了指定列，后指定姓名列取唯一值，示例表达式：`tt['姓名'].unique()`。
- `unique` 返回的是唯一值列表。
- 局限：实际中往往需要的不是单纯一个列表，而是希望唯一值仍然带有其他字段，例如仍然带有“分数”等列；这时需要使用 pandas 提供的去重函数。

### 2.2 `value_counts` 统计频次

- 函数名：`value_counts`（视频口述/字幕中可能听起来像其他词，实际 pandas 函数是 `value_counts`）。
- 作用：统计姓名列中每个名字一共出现过几次。
- 示例表达式：`tt['姓名'].value_counts()`。
- 运行结果示例：小龙女 2 次、杨过 2 次、郭靖 2 次、张三丰 1 次、张无忌 1 次。
- 应用场景：例如有一列订单号、一列姓名，可以用它统计某个人一共下过多少次单。
- 与 `unique` 的区别：`unique` 取唯一值列表；`value_counts` 统计每个值出现的频次。

## 3. 两个核心函数与参数

- `drop_duplicates`：删除重复值。
- `duplicated`：判断重复值，也可配合布尔索引提取重复值。
- 讲师说明：两个函数的资料都给出了，没有复杂内容，主要掌握函数名和参数。
- 主要参数如下：
  - `inplace`：是否生成新的数据或直接修改原数据；之前课程已经介绍过很多次，这里不再展开。很多函数都带 `inplace`，`duplicated` 的资料中讲师没有写这个参数也没关系。
  - `subset`：用来指定特定的列，告诉函数要对哪一列进行去重或重复判断；必须把列名告诉函数。视频字幕中可能写成 `subst`，实际 pandas 参数名是 `subset`。
  - `keep`：用来处理重复值的方法，有三个可选参数：
    - `'first'`：默认值，保留第一次出现的值。
    - `'last'`：保留最后一次出现的值。
    - `False`：删除所有重复值，留下没有出现过重复的记录，等于是提取不重复的。
- 易错点：`False` 是布尔值，不要加引号；`'first'`、`'last'` 是字符串，需要加引号。
- 讲师强调：如果只看笔记不听课，可能不知道 `False` 不加引号。

## 4. `drop_duplicates` 去重操作演示

- 默认去重代码：`tt.drop_duplicates(subset='姓名')`。
- 默认 `keep='first'`，即保留第一次出现的值。
- 示例中可观察到保留第一次出现的记录：杨过 90、小龙女 93、郭靖 87 等；后续不重复记录也会保留，转录中出现的 99、387 对应后续分数示例。
- 运行结果确认：默认保存的是第一次出现的值。
- 改为保留最后一次出现的值：`tt.drop_duplicates(subset='姓名', keep='last')`。
- 讲师演示结果变成 89、91、90 等（转录中为“899190”），说明此时保存的是第二次/最后一次出现的值。
- 改为删除所有重复值、只留下没有重复的记录：`tt.drop_duplicates(subset='姓名', keep=False)`。
- 注意：`keep=False` 中的 `False` 不加引号。
- 结果：只保留张三丰、张无忌这类没有出现过重复的记录；pandas 可以一次性提取。
- 讲师补充对比：如果在 Power Query 里做类似操作，需要会 M 函数；M 函数中文书很少。
- 多列去重：如果除姓名列外还有班级列，可以使用 `tt.drop_duplicates(subset=['姓名', '班级'])`，即在 `subset` 中写多个列名并组成列表。
- 多列 `subset` 表示按指定多列的组合来判断重复。

## 5. `duplicated` 判断重复与提取重复

### 5.1 判断整行或指定列是否重复

- 函数：`duplicated`，参数与 `drop_duplicates` 基本一样；讲师没有写 `inplace`，但很多函数都带 `inplace`。
- 不指定列时：`tt.duplicated()`，用于判断有没有重复的行。
- 示例数据行与行之间不存在重复，所以不指定列时没有重复数据；不会因为姓名相同就直接判定整行重复。
- 指定列时：`tt.duplicated(subset='姓名')`，返回布尔值，标记姓名列中哪些行是重复的，即第几个是重复的。
- 也可以写成中括号形式：`tt.duplicated(['姓名'])`。
- 一个参数时加不加中括号都没关系；两种方法效果完全一样。
- 该结果可用于判断某列数据中的重复数据。

### 5.2 提取重复数据

- 本节课最重要的操作之一：提取重复内容。
- 因为涉及切片问题，讲师建议先定义变量保存布尔结果：`dup = tt.duplicated(subset='姓名')`。
- 然后使用布尔索引进行数据切片：`tt[dup]`。
- 原理：`duplicated` 返回 True/False；`tt[dup]` 会提取所有结果为 True 的行，即把所有被判断为重复的数据显示出来。
- 讲师总结：操作就这么简单，所有重复过的数据会显示出来；pandas 在操作这些内容时省时省力。
- 学习这些函数对数据清洗非常有帮助。

## 6. 关键结论与易错点汇总

- `drop_duplicates` 用于删除重复值；`duplicated` 用于判断重复值，并可配合布尔索引提取重复值。
- `unique` 只返回某列的唯一值列表；如果需要保留其他字段，应使用 pandas 的去重函数。
- `value_counts` 用于统计频次，适合统计姓名、订单下单次数等。
- `keep='first'`：保留第一次出现的值，是 `drop_duplicates` 的默认行为。
- `keep='last'`：保留最后一次出现的值。
- `keep=False`：删除所有重复值，只留下没有出现过重复的记录。
- `keep=False` 中的 `False` 不加引号；`'first'`、`'last'` 需要加引号。
- `subset` 用于指定参与去重/重复判断的列；多列时使用列表，例如 `subset=['姓名', '班级']`。
- 视频字幕中出现的 `subst` 是误写/口误，实际 pandas 参数名是 `subset`。
- `duplicated` 不指定 `subset` 时按整行判断重复；指定 `subset` 时按指定列判断重复。
- `duplicated` 返回布尔 Series，配合 `tt[dup]` 可提取重复行。
- pandas 处理重复值和数据清洗非常方便，掌握这些函数对实际数据分析工作很有帮助。
