# Python 数据分析：用 Pandas 实现 Excel 的 VLOOKUP 功能

## 1. 场景与目标

- 视频主题：在 `pandas` 中实现 Excel 的 `VLOOKUP` 功能。
- 数据文件：`vlookup.xlsx`。
- 文件中有两个工作表：
  - `花名册`：包含 `学号`、`姓名`、`班级` 等列。
  - `成绩单`：包含 `学号`、`语文`、`数学`、`英语`、`总分` 等列。
- 目标：以 `花名册` 为标准，根据 `学号` 将 `成绩单` 中的 `总分` 匹配过来。
- 讲师强调：会一个就会十个，核心是根据连接键匹配需要的列。

## 2. 导入库并读取两个工作表

- 因为 `VLOOKUP` 涉及两个工作表，所以需要分别导入两次。
- 使用 `pd.read_excel()` 读取 Excel。
- 使用参数 `sheet_name` 指定工作表名称。
- 读取代码：

```python
import pandas as pd

path = 'vlookup.xlsx'

数据一 = pd.read_excel(path, sheet_name='花名册')
数据二 = pd.read_excel(path, sheet_name='成绩单')

print(数据一)
print(数据二)
```

- `数据一`：读取 `花名册`。
- `数据二`：读取 `成绩单`。
- 讲师说明：打印时显示可能有些串行或错列，但数据本身没有问题。

## 3. 使用 `pd.merge()` 实现 VLOOKUP

- 使用 `pd.merge()` 将两个 DataFrame 连接起来。
- 以 `数据一` 为标准，连接 `数据二`。
- 不能把 `数据二` 全部列都连接进来，只取需要的列。
- 使用 `loc` 选择列：
  - 行使用 `:`，表示所有行都要。
  - 列使用列表指定，只取 `学号` 和 `总分`。
- 选择列表达式：

```python
数据二.loc[:, ['学号', '总分']]
```

- 连接方式：左外连接 `how='left'`。
- 连接键：`on='学号'`。
- 完整代码：

```python
结果 = pd.merge(
    数据一,
    数据二.loc[:, ['学号', '总分']],
    how='left',
    on='学号'
)

print(结果)
```

- 参数说明：
  - 第一个参数：左表 `数据一`，即以 `花名册` 为标准。
  - 第二个参数：右表只保留 `学号` 和 `总分` 两列。
  - `how='left'`：左外连接，保留左表所有记录。
  - `on='学号'`：按 `学号` 进行连接。
- 结果：`花名册` 的全部列保留，`成绩单` 的 `总分` 被匹配到结果中。
- 讲师说明：此时 `总分` 默认在最后一列。

## 4. 调整匹配列的位置

- 需求：把 `总分` 放到指定列位置，例如放到 `学号` 前面，即第 0 列。
- 讲师采用的方法：
  - 先把需要移动的列取出来，保存到变量。
  - 再删除原列。
  - 最后用 `insert()` 插入到指定位置。
- 讲师用“鸡蛋筐”比喻：先复制一个鸡蛋放在外面，删除本体，再把外面的鸡蛋放回指定位置。
- 取出 `总分` 列：

```python
结果总分 = 结果['总分']
```

- 删除原 `总分` 列：

```python
结果 = 结果.drop('总分', axis=1)
```

- 参数说明：
  - `drop('总分', ...)`：删除名为 `总分` 的列。
  - `axis=1`：表示按列方向删除。
- 插入到第 0 列：

```python
结果.insert(0, '总分', 结果总分)
```

- 参数说明：
  - 第一个参数 `0`：插入到第 0 列，即 `学号` 前面。
  - 第二个参数 `'总分'`：新列名称。
  - 第三个参数 `结果总分`：插入的列数据。
- 讲师说明：`DataFrame.insert()` 是原地插入，实际写法为 `结果.insert(...)`，不需要重新赋值。
- 如果想插入到其他位置，只需要修改 `insert()` 的第一个参数：
  - 插入到第 1 列：`结果.insert(1, '总分', 结果总分)`
  - 插入到第 2 列：`结果.insert(2, '总分', 结果总分)`
  - 以此类推。
- 打印结果：

```python
print(结果)
```

- 讲师提示：
  - 如果不懂 `drop` 参数，参考笔记 `10.1`。
  - 如果不懂 `insert`，参考 Python 基础篇 PPT 第 30 页“指定位置新增数据”。

## 5. 将结果写回原 Excel 文件

- 需求：不仅保存为新文件，还要在原表上进行修改并写回。
- 讲师提示：写回原表的方法详见笔记 `19.3`。
- 使用 `pd.ExcelWriter()` 打开原 Excel 文件。
- 使用 `to_excel()` 将结果写回。
- 使用 `writer.save()` 保存。
- 使用 `writer.close()` 关闭。
- 代码：

```python
writer = pd.ExcelWriter(path)

结果.to_excel(writer, index=False)

writer.save()
writer.close()
```

- 参数说明：
  - `pd.ExcelWriter(path)`：打开原 Excel 文件路径，准备写入。
  - `结果.to_excel(writer, index=False)`：将 `结果` 写入 Excel。
  - `index=False`：不写入行索引。
  - `writer.save()`：保存文件。
  - `writer.close()`：关闭写入器。
- 讲师强调：`save()` 和 `close()` 两件事都不能忘。
- 运行后即可将结果写入原表。

## 6. 完整代码汇总

```python
import pandas as pd

path = 'vlookup.xlsx'

数据一 = pd.read_excel(path, sheet_name='花名册')
数据二 = pd.read_excel(path, sheet_name='成绩单')

print(数据一)
print(数据二)

结果 = pd.merge(
    数据一,
    数据二.loc[:, ['学号', '总分']],
    how='left',
    on='学号'
)

print(结果)

结果总分 = 结果['总分']
结果 = 结果.drop('总分', axis=1)
结果.insert(0, '总分', 结果总分)

print(结果)

writer = pd.ExcelWriter(path)
结果.to_excel(writer, index=False)
writer.save()
writer.close()
```

## 7. 关键点与注意事项

- 两个工作表需要分别读取，使用 `sheet_name` 指定工作表。
- `VLOOKUP` 在 `pandas` 中通常用 `pd.merge()` 实现。
- 右表只取需要的列，避免把无关列全部连接进来。
- `loc[:, ['学号', '总分']]` 中：
  - `:` 表示所有行。
  - `['学号', '总分']` 表示只选择这两列。
- 左外连接使用 `how='left'`，保留左表所有记录。
- 连接键使用 `on='学号'`。
- 调整列顺序的三步：
  - 先取出目标列。
  - 使用 `drop(..., axis=1)` 删除原列。
  - 使用 `insert(位置, 列名, 数据)` 插入到指定位置。
- `drop` 删除列时必须指定 `axis=1`。
- `insert()` 第一个参数是列位置，`0` 表示第 0 列。
- 写回原 Excel 使用：
  - `pd.ExcelWriter(path)`
  - `结果.to_excel(writer, index=False)`
  - `writer.save()`
  - `writer.close()`
- `index=False` 用于避免把行索引写入 Excel。

  - `drop` 参数不懂：参考笔记 `10.1`。
  - `insert` 不懂：参考 Python 基础篇 PPT 第 30 页“指定位置新增数据”。
  - 写回原表：参考笔记 `19.3`。
