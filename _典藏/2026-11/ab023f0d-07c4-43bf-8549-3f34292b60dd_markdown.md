## 1. 导入 NumPy 模块
```python
import numpy as np
```

## 2. 使用 np.array 创建数组

### 2.1 配合 range 创建数组
```python
b = np.array(range(1, 6))
print(b)
```
输出示例：
```text
[1 2 3 4 5]
```
- `np.array` 是 NumPy 专门用于创建数组的方法。
- 可以把 `range` 产生的序列转换为 NumPy 数组。
- 视频口述为“从 1 到 5”，输出为 1、2、3、4、5。注意 Python 的 `range` 结束值通常不包含，因此代码中写成 `range(1, 6)` 才能得到 1 到 5。

### 2.2 直接传入列表创建数组
```python
print(np.array([1, 2, 3, 4, 5]))
```
输出示例：
```text
[1 2 3 4 5]
```
- `np.array()` 的括号是方法本身带的括号。
- 里面要写成列表形式，数字之间用英文逗号隔开。
- 这种方法一般较少使用，因为手动写列表比较麻烦；除非需要指定具体数字。

### 2.3 直接传入元组或其他序列
```python
print(np.array((1, 2, 3, 4, 5)))
```
输出示例：
```text
[1 2 3 4 5]
```
- `np.array` 可以接收列表、元组、数组或其他序列。
- 元组使用小括号，例如 `(1, 2, 3, 4, 5)`。
- 传入的数据会被转换为 NumPy 的数组类型。

### 2.4 不指定 dtype 时的自动探测
- 如果创建数组时不指定数据类型，NumPy 会自动探测并给出一个默认类型。
- 例如整数数组可能显示为 `int32` 或 `int64`。
- 自动探测通常可用，但视频提到不排除探测结果与预期不完全一致的可能；需要时可手动指定 `dtype`。

## 3. 使用 np.arange 创建数组
- `np.arange` 可以理解为 Python 内建 `range` 的数组版，返回的是 NumPy 数组。
- 语法形式：`np.arange(start, stop, step)`。
- `start` 默认从 0 开始，`step` 可以省略。
- 视频中口述的 `a range`、`arrange` 实际对应 NumPy 的 `np.arange`。

示例：
```python
print(np.arange(1, 6))
# [1 2 3 4 5]

print(np.arange(1, 10, 2))
# [1 3 5 7 9]

print(np.arange(5))
# [0 1 2 3 4]
```
说明：
- `np.arange(1, 10, 2)` 表示从 1 开始，到 10 之前结束，步长为 2，因此输出 1、3、5、7、9。
- 只传一个数时，例如 `np.arange(5)`，表示从 0 开始，到 5 之前结束，输出 0 到 4。
- `np.array(range(1, 6))` 与 `np.arange(1, 6)` 效果相同。
- 更推荐使用 `np.arange`，因为写法更简单，不需要再写 `array` 和 `range` 的组合。

## 4. 查看数组类型与元素数据类型

### 4.1 使用 dtype 查看数组元素数据类型
```python
a = np.arange(1, 8)
print(a.dtype)
```
输出示例：
```text
int32
```
或：
```text
int64
```
- `dtype` 用于查看数组内部元素的数据类型。
- `int` 表示整数型。
- NumPy 中数据类型很多，常见形式为类型名加位数，例如 `int32`、`int64`、`float32`、`float64`。
- 基础篇暂时不需要深入理解各种位数，了解即可。

### 4.2 使用 type 查看对象类型
```python
print(type(a))
```
输出示例：
```text
<class 'numpy.ndarray'>
```
- `type()` 查看的是对象本身的类型。
- 输出说明该对象是 NumPy 独有的数组类型 `numpy.ndarray`，不是 Python 列表。
- 通过 `type()` 可以确认创建出来的到底是不是 NumPy 数组。

## 5. 指定数组元素的数据类型 dtype
- 创建数组时可以通过 `dtype` 参数指定元素类型。
- 可使用 `dtype=float`、`dtype=np.float32`、`dtype=np.int32`、`dtype=np.int64` 等。

示例：
```python
a = np.arange(1, 8, dtype=float)
print(a)
print(a.dtype)
```
- 输出为浮点型数组，`dtype` 示例为 `float64`。

指定 32 位浮点型：
```python
a = np.arange(1, 8, dtype=np.float32)
print(a.dtype)
# float32
```

指定 64 位整数型：
```python
a = np.arange(1, 8, dtype=np.int64)
print(a.dtype)
# int64
```
说明：
- 可以把数组元素类型指定为 `float32`、`float64`、`int32`、`int64` 等。
- 初期只需要了解如何指定类型，不必掌握所有数据类型细节。

## 6. 数组常用属性
设：
```python
a = np.arange(1, 8)
print(a)
```
输出：
```text
[1 2 3 4 5 6 7]
```

### 6.1 shape：返回数组形状和维度
```python
print(a.shape)
```
输出示例：
```text
(7,)
```
说明：
- 一维数组返回一个数字的元组，例如 `(7,)`，表示有 7 个数据。
- 二维数组会返回两个数字，例如 `(2, 3)`，表示 2 行 3 列。
- 行在前，列在后。
- 三维数组会返回三个数字，例如 `(2, 2, 3)`，可理解为“两块、每块 2 行 3 列”。
- 返回几个数字，通常就是几维数组。

### 6.2 ndim：返回维度数
```python
print(a.ndim)
```
输出示例：
```text
1
```
说明：
- 一维数组返回 1。
- 二维数组返回 2。
- 三维数组返回 3。
- 该属性使用相对较少，因为通过 `shape` 也能判断维度。

### 6.3 size：返回数组中元素总数
```python
print(a.size)
```
输出示例：
```text
7
```
说明：
- `size` 返回数组中所有数据元素的数目。
- 示例数组中有 7 个数字，因此结果为 7。
- 视频中口述为 `sz`，实际对应 `size` 属性。

### 6.4 dtype：返回数组元素数据类型
```python
print(a.dtype)
```
输出示例：
```text
int64
```
说明：
- `dtype` 返回数组内部元素的数据类型。
- 属性写法为：数组变量后加点，再写属性名，例如：
  - `a.shape`
  - `a.ndim`
  - `a.size`
  - `a.dtype`

## 7. 创建全 1 数组 np.ones
- `np.ones(shape)` 用于创建元素全为 1 的数组。

一维数组：
```python
a = np.ones(3)
print(a)
```
输出示例：
```text
[1. 1. 1.]
```
- 传一个数字，表示创建一维数组，数字是多少就输出多少个 1。

二维数组：
```python
print(np.ones((2, 3)))
```
- 输出两行三列、全部为 1 的数组。
- 二维及以上数组需要把形状写成元组，例如 `(2, 3)`、`(3, 3)`。
- 一维数组可以直接写一个数，也可以写成元组 `(3,)`。

参数说明：
- 第一个参数：形状。可以是一个数，也可以是元组。
- 第二个参数：`dtype`，可选，用于指定数据类型；不指定时由 NumPy 决定。
- 第三个参数：`order`，默认是 `C`，表示按 C 语言的内存顺序存储数组元素。基础阶段不需要改动，直接忽略后两个参数即可。

## 8. 创建全 0 数组 np.zeros
- `np.zeros(shape)` 用于创建元素全为 0 的数组。

一维数组：
```python
print(np.zeros(3))
```
输出示例：
```text
[0. 0. 0.]
```

二维数组：
```python
print(np.zeros((3, 3)))
```
- 输出三行三列、全部为 0 的数组。

说明：
- `ones` 表示全部为 1，`zeros` 表示全部为 0。
- 参数规则与 `np.ones` 相同：
  - 一维传一个数。
  - 二维传两个数的元组。
  - 三维传三个数的元组。
  - `dtype` 可选。
  - `order` 默认 `C`，不需要改。

## 9. 创建指定值数组 np.full
- `np.full(shape, fill_value)` 用于创建用指定数字填充的数组。

一维数组：
```python
print(np.full(3, 520))
```
输出示例：
```text
[520 520 520]
```
- 第一个参数表示创建几个元素。
- 第二个参数表示每个元素填充成什么数字。

二维数组：
```python
print(np.full((3, 3), 520))
```
- 输出三行三列、全部为 520 的数组。

说明：
- `np.ones` 的元素全部为 1。
- `np.zeros` 的元素全部为 0。
- `np.full` 的元素全部为指定值。
- 第一个参数仍然是形状：一维传一个数，二维、三维传元组。
- 后面多了一个指定数字参数，用于设置数组元素内容。
- 同样可以指定 `dtype`，`order` 默认 `C`，基础阶段不需要修改。

## 10. 形状参数记忆要点
- 一维数组：可以写一个整数，例如 `np.ones(3)`。
- 二维数组：必须写两个数的元组，例如 `np.ones((2, 3))`。
- 三维数组：必须写三个数的元组，例如 `np.ones((2, 2, 3))`。
- 元组中的数字表示各维度大小；二维时通常为“行、列”。
- 一维数组可以省略元组括号；二维、三维必须使用元组括号。
- 当前阶段先掌握一维数组创建，后续再学习更多多维数组操作。

## 11. 本课小结
- 创建数组的主要方式包括：
  - `np.array(range(...))`
  - `np.array([...])` 或 `np.array((...))`
  - `np.arange(...)`
- 更推荐使用 `np.arange`，写法简单，效果与 `np.array(range(...))` 类似。
- `np.array` 可以接收列表、元组或其他序列，并转换为 NumPy 数组。
- 使用 `dtype` 查看或指定数组元素数据类型。
- 使用 `type()` 查看对象类型，NumPy 数组类型为 `numpy.ndarray`。
- 常用数组属性：
  - `shape`：数组形状和维度。
  - `ndim`：维度数。
  - `size`：元素总数。
  - `dtype`：元素数据类型。
- 创建全 1、全 0、指定值数组分别使用：
  - `np.ones`
  - `np.zeros`
  - `np.full`
- 多维数组的形状通过元组传入；`order` 参数默认 `C`，不需要改动。
