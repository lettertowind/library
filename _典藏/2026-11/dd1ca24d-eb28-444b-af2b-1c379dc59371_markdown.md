## 二、本节目标图形

- 数据示例包含两列：
  - `日期`
  - `金额`
- 示例数据为 12 月 1 日到 12 月 6 日左右的每日盈亏。
- 图形含义：
  - 正数表示盈利；
  - 负数表示亏损；
  - 盈利柱使用红色；
  - 亏损柱使用绿色。
- 瀑布图需要分别处理正数和负数：
  - 当金额 `>= 0` 时，画盈利柱；
  - 当金额 `< 0` 时，画亏损柱。
- 柱形图默认从底部往上画；瀑布图的关键是每根柱子的起始位置要根据前面金额累计变化。
- 实际工作中的数据会更复杂，图形也会比课堂示例更复杂。

## 三、关键函数与参数速查

| 函数 / 对象 | 作用 | 本节用法 |
|---|---|---|
| `import pandas as pd` | 导入 pandas | 处理日期、金额数据 |
| `import numpy as np` | 导入 numpy | 生成位置索引 |
| `import matplotlib.pyplot as plt` | 导入 Matplotlib 绘图模块 | 绘制柱形图、设置刻度、网格 |
| `np.arange(len(数据点.金额))` | 生成 `0,1,2,...` 的位置索引 | 先作为 x 轴位置，最后替换成日期 |
| `plt.bar(x, y, width=0.8, bottom=bottom, color=..., label=...)` | 绘制柱形图 | 分别绘制盈利红柱、亏损绿柱 |
| `bottom += y` | 累计柱子起始高度 | 下一根柱从上一根柱顶部继续 |
| `x += 0.8` | 横向移动一个柱宽 | 柱宽为 `0.8` 时，横向步长也应与柱宽对应 |
| `plt.gca()` | 获取当前坐标轴对象 | 对 y 轴单独设置网格 |
| `ax.yaxis.grid(True, linestyle='--', color=..., alpha=...)` | 设置 y 轴网格线 | 只画 y 轴虚线网格 |
| `plt.xticks(positions, labels, rotation=45)` | 设置 x 轴刻度及标签 | 用日期替换 `0,1,2,...` |
| `pd.to_datetime(...)` | 转换为日期时间类型 | 处理日期列 |
| `strftime('%Y-%m-%d')` | 格式化日期字符串 | 去掉日期后面的 `00:00` 时间 |

## 四、按视频顺序实现瀑布图

### 步骤一：导入库并处理显示环境

- 导入 pandas 库。
- 导入 numpy 库。
- 导入 matplotlib 的可视化模块。
- 设置 Matplotlib 中文字体，解决中文显示问题。
- 设置正负号显示问题，避免负号显示异常。
- 视频中提到“南派库”等口语化/识别误差，按实际代码应理解为 numpy、matplotlib 等相关库。

示意设置：

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei']  # 中文字体，示意
plt.rcParams['axes.unicode_minus'] = False     # 正常显示负号
```

### 步骤二：查看数据

- 打印数据，确认数据结构。
- 视频示例中数据只有两列：
  - 日期；
  - 金额。
- 示例数据比较简单，实际工作中的数据通常不会只有这两列，因此实际绘图会更复杂。

示意：

```python
# 数据点 = ...
# print(数据点)
```

### 步骤三：先生成位置索引，不直接把日期放到 x 轴

- 讲师强调：画图时不要一开始就把日期全部写到 x 轴，这样不方便操作。
- 先使用 `0,1,2,3,...` 的索引作为 x 轴位置。
- 最后通过 `plt.xticks` 一次性把索引替换成日期。
- 通过金额列长度生成索引列表。
- 视频口述为“列表等于 np.arange 数据金额”，意图是按金额列的长度生成 `0` 到 `n-1` 的列表。

示意：

```python
列表 = np.arange(len(数据点.金额))
print(列表)
```

- 视频中还提醒：示例金额是整数，但实际数据金额可能有小数，因此需要设置数据类型，例如转换为浮点数。

示意：

```python
数据点['金额'] = 数据点['金额'].astype(float)
```

### 步骤四：设置累计起点 `bottom`

- 先设置一个常量表示柱子的起始高度，初始值为 `0`。
- 该变量用于控制每根柱子的底部位置。
- 第一根柱子从 0 开始；后续柱子要根据前面累计金额往上移动。

示意：

```python
bottom = 0
```

### 步骤五：循环遍历金额列，取得 x 和 y

- 使用金额列的索引进行循环。
- `x` 取索引列表中的位置值。
- `y` 取当前行的金额值。
- 视频中此处曾出现漏写 `[i]` 的问题，后面修正为类似 `数据点.金额[i]`。

示意：

```python
for i in 数据点.金额.index:
    x = 列表[i]
    y = 数据点.金额[i]
```

- 关键点：
  - `x` 是柱子横向位置；
  - `y` 是柱子高度；
  - `bottom` 是柱子底部起始高度。

### 步骤六：判断盈利与亏损，分别画柱形图

- 判断条件：
  - 当 `数据点.金额[i] >= 0` 时，为盈利；
  - 否则为亏损。
- 盈利柱参数：
  - x 轴位置：`x`
  - y 轴高度：`y`
  - 柱宽：`width=0.8`
  - 起始高度：`bottom=bottom`
  - 颜色：`color='red'`
  - 标签：`label='盈利'`
- 亏损柱参数：
  - 复制盈利分支代码；
  - 修改颜色为绿色：`color='green'`
  - 修改标签为：`label='亏损'`
- `label` 用于图例显示。
- 盈利和亏损通过颜色区分。

示意：

```python
if 数据点.金额[i] >= 0:
    plt.bar(x, y, width=0.8, bottom=bottom, color='red', label='盈利')
else:
    plt.bar(x, y, width=0.8, bottom=bottom, color='green', label='亏损')
```

### 步骤七：累计 `bottom` 和横向位置

- 每画完一根柱子，需要更新下一根柱子的起始高度：
  - `bottom += y`
- 解释：
  - 第一次 `bottom` 是 0；
  - 画完第一根柱后，下一根柱的底部变为第一根柱的高度；
  - 再下一根再继续累加，形成瀑布式阶梯效果。
- 视频中还讲到横向位置移动：
  - 柱宽设置为 `0.8`；
  - 下一根柱子的 x 位置应移动一个柱宽；
  - 因此代码意图是 `x += 0.8`。
- 注意：视频口述中出现“x 加等于 1.8”的口误；结合柱宽 `width=0.8`，实际应理解为横向移动一个柱宽 `0.8`，即 `x += 0.8`。
- 如果下一轮循环重新从索引列表取 `x = 列表[i]`，则该 `x += 0.8` 在最终代码中可能是重复/冗余操作；但从讲师讲解意图看，是为了说明柱距应与柱宽一致。

示意：

```python
bottom += y
x += 0.8
```

### 步骤八：显示基础图形

- 使用 `plt.show()` 显示图形。
- 此时应能看到红绿柱形图，但 x 轴仍是 `0,1,2,...` 索引。
- 日期替换放到后面统一处理。

示意：

```python
plt.show()
```

### 步骤九：单独给 y 轴添加网格线

- 整体画网格线也可以，但本节复习“如何只对 y 轴画网格线”。
- 思路：
  - 先获取当前坐标轴；
  - 再对 y 轴进行操作。
- 获取当前坐标轴：

```python
ax = plt.gca()
```

- 设置 y 轴网格线：

```python
ax.yaxis.grid(True, linestyle='--', color='gray', alpha=0.5)
```

- 参数说明：
  - `True`：开启网格；
  - `linestyle='--'`：使用虚线；
  - `color`：设置颜色；
  - `alpha`：设置透明度。
- 视频中强调：
  - `y` 这个颜色并不是真正的黄色，而是偏“屎黄”的颜色；
  - 如果想要真正的黄色，应使用 `yellow`；
  - `yellow` 更偏金黄色；
  - 颜色表中 `y` 和 `yellow` 不一样，使用时要注意。

### 步骤十：将 x 轴索引替换为日期

- 当前 x 轴显示的是 `0,1,2,3,...`。
- 使用 `plt.xticks` 替换为日期标签。
- 第一个参数是刻度位置，按数据长度生成索引。
- 第二个参数是日期列。
- `rotation=45` 让日期旋转 45 度，避免文字重叠。

示意：

```python
plt.xticks(np.arange(len(数据点.金额)), 数据点.日期, rotation=45)
```

- 运行后 x 轴会显示日期。
- 但直接显示日期时，可能出现“几月几号 00:00”的格式，因为日期中带有时间部分。

### 步骤十一：格式化日期，去掉 `00:00`

- 之前课程专门讲过日期格式处理。
- 需要先把日期转换为日期时间类型，再格式化为字符串。
- 目标格式为年月日，例如 `%Y-%m-%d`。
- 视频中提到“百分号的 y”，并提醒格式字符串需要加引号。
- 处理后再替换 `plt.xticks` 的第二个参数。

示意：

```python
日期 = pd.to_datetime(数据点.日期).dt.strftime('%Y-%m-%d')
plt.xticks(np.arange(len(数据点.金额)), 日期, rotation=45)
```

- 重新运行后，日期刻度变为类似 `2024-12-01` 的形式，不再显示 `00:00`。
- 这就是一个最基本的瀑布图。

## 五、示意完整代码

以下代码按视频讲解逻辑整理，部分颜色、字体和变量名按课程语境示意：

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei']  # 中文字体，示意
plt.rcParams['axes.unicode_minus'] = False     # 正常显示负号

# 数据点 = ...
# print(数据点)

数据点['金额'] = 数据点['金额'].astype(float)

列表 = np.arange(len(数据点.金额))
print(列表)

bottom = 0

for i in 数据点.金额.index:
    x = 列表[i]
    y = 数据点.金额[i]

    if 数据点.金额[i] >= 0:
        plt.bar(x, y, width=0.8, bottom=bottom, color='red', label='盈利')
    else:
        plt.bar(x, y, width=0.8, bottom=bottom, color='green', label='亏损')

    bottom += y
    x += 0.8

ax = plt.gca()
ax.yaxis.grid(True, linestyle='--', color='gray', alpha=0.5)

日期 = pd.to_datetime(数据点.日期).dt.strftime('%Y-%m-%d')
plt.xticks(np.arange(len(数据点.金额)), 日期, rotation=45)

plt.show()
```

## 六、重要结论与避坑清单

- 瀑布图不是简单地把所有柱子都从 0 开始画，而是要用 `bottom` 累计前面柱子的高度。
- 先使用索引 `0,1,2,...` 作为 x 轴位置，最后再用 `plt.xticks` 替换成日期，操作更方便。
- 盈利和亏损要分开判断、分开画：
  - `>= 0`：红色盈利柱；
  - `< 0`：绿色亏损柱。
- `plt.bar` 的核心参数：
  - `x`：横向位置；
  - `y`：柱子高度；
  - `width`：柱宽；
  - `bottom`：柱子底部起始位置；
  - `color`：颜色；
  - `label`：图例标签。
- `bottom += y` 是瀑布图累计效果的关键。
- 柱宽设为 `0.8` 时，横向移动步长应与柱宽对应，即 `x += 0.8`；视频中“1.8”为口误。
- 循环中取金额值时要写完整索引，例如 `数据点.金额[i]`；漏写 `[i]` 会导致取不到当前值。
- 只画 y 轴网格线时，使用：
  - `ax = plt.gca()`
  - `ax.yaxis.grid(True, linestyle='--', color=..., alpha=...)`
- 颜色 `y` 不是真正的黄色，偏“屎黄”；真正黄色用 `yellow`。
- 日期直接显示可能带 `00:00`，应使用 `pd.to_datetime(...).dt.strftime('%Y-%m-%d')` 格式化。
- `rotation=45` 可让日期标签倾斜，减少重叠。
- Matplotlib 官方文档多为英文，遇到复杂图形问题可查官方文档；实际工作图表会比课堂示例复杂。
- Power BI 做图更简单，Python 做图更灵活、更专业，但学习成本更高；应根据实际工作需求选择工具。
