# 孙兴华 Python 数据分析三部曲：Numpy 通用函数笔记

## 1. 本节主题：通用函数（ufunc）

- 本节主要讲解 NumPy 中的**通用函数**，即可以进行快速逐元素数组运算的函数。
- 通用函数的英文通常称为 `ufunc`。
- 它的作用是对 NumPy 数组中的元素进行逐元素操作，也就是对数组里的每一个元素分别执行相同运算。
- 某些简单函数原本只接受一个或多个标量数值，并产生一个或多个标量结果；通用函数则是对这类简单函数进行**向量化封装**，使其能够直接作用于整个数组。
- 视频强调：不需要把 NumPy 中所有通用函数都记住或逐个讲解。实际分析数据时，需要哪个函数就查哪个函数即可。

## 2. 一元通用函数

一元通用函数是指一次主要作用于一个输入数组，并对其中每个元素分别进行计算的通用函数。

视频中列举的典型例子包括：

- `np.sqrt`：返回每个元素的平方根，可理解为计算  
  \[
  \sqrt{x}
  \]
  转录中提到“返回正的平方根”，更准确地说，是返回非负平方根。
- `np.exp`：计算以自然常数 \(e\) 为底的指数函数，即  
  \[
  e^x
  \]
  其中 \(e\) 是自然对数的底数。

视频中提到，这些函数在概率论、统计计算等场景中可能出现，有兴趣可以进一步学习相关内容。

示例理解：

- 先生成一个包含若干整数的数组，例如区间内的若干数。
- 然后对整个数组调用 `np.sqrt`，就会返回一个新数组，其中每个元素都是原数组对应元素的平方根。
- 调用 `np.exp`，则返回每个元素的 \(e^x\) 结果。

学习上不必逐个背诵这些函数，重点理解其“逐元素运算”的机制和调用方式。

## 3. 二元通用函数

二元通用函数是指接受两个数组作为输入，并返回一个数组结果的通用函数。它会对两个数组中对应位置的元素进行逐个比较或逐个运算。

视频中提到的二元通用函数包括：

- `np.add`：逐元素相加。
- `np.maximum`：逐元素比较两个数组，取较大的值。
- `np.minimum`：逐元素比较两个数组，取较小的值。

转录中出现的 “max memo”“事实命”等表述应理解为对 `maximum`、`minimum` 等函数名称的口语或识别误差。

### 逐元素最大值示例

视频中演示了如下思路：

- 生成两个随机数组，记为 `x` 和 `y`。
- 每个数组包含 8 个数，元素范围实际为 `0~7`，即类似 `range(8)` 所对应的 8 个整数。
- 对两个数组使用 `np.maximum(x, y)`。
- 该函数会将 `x` 和 `y` 中对应位置的元素逐个比较：
  - `x[0]` 与 `y[0]` 比较，谁大就取谁；
  - `x[1]` 与 `y[1]` 比较，谁大就取谁；
  - 以此类推。
- 最终返回一个新的数组，其中每个元素都是两个原数组对应位置上的较大值。

可以概括为：

- 对位比较大小；
- 取较大值；
- 生成新的数组；
- 返回逐个元素的最大值结果。

### 逐元素最小值示例

同理，使用 `np.minimum(x, y)` 时：

- 会对两个数组对应位置的元素逐个比较；
- 谁小就取谁；
- 最终生成并返回一个新的数组，其中每个元素都是对应位置上的较小值。

这部分体现了一个重要规律：二元通用函数不是把整个数组汇总成一个最大值或最小值，而是对两个数组的对应元素逐个进行操作。

## 4. 通用函数的学习建议

- 不需要一次性掌握所有通用函数。
- 视频中已经把相关函数列出来，并配有中文解释；实际使用时按需查阅即可。
- 不同岗位对通用函数的需求不同：
  - 科研工作可能更常接触到各种数学运算函数；
  - 销售、人力资源等场景可能很少用到这么多函数。
- 一元通用函数的用法与 Excel 中的函数有相似之处：都是对数据执行某种计算。
- 真正使用时，如果忘记某个函数的具体用法，可以查文档或搜索，例如百度查询其用法。
- 通用函数整体调用方式比较统一：
  - 传入一个数组，得到逐元素运算结果；
  - 传入两个数组，得到对应元素之间的逐元素运算结果。

## 5. 常用函数速查

| 类型 | 函数 | 作用 | 说明 |
|---|---|---|---|
| 一元通用函数 | `np.sqrt` | 计算逐元素平方根 | 对数组每个元素计算 \(\sqrt{x}\) |
| 一元通用函数 | `np.exp` | 计算逐元素指数 | 对数组每个元素计算 \(e^x\) |
| 二元通用函数 | `np.add` | 逐元素相加 | 两个数组对应元素相加 |
| 二元通用函数 | `np.maximum` | 逐元素取最大值 | 两个数组对应位置谁大取谁 |
| 二元通用函数 | `np.minimum` | 逐元素取最小值 | 两个数组对应位置谁小取谁 |

## 6. 关键结论

- 通用函数 `ufunc` 是 NumPy 中用于快速逐元素数组运算的函数。
- 通用函数的本质是对标量函数进行向量化封装，使其可以直接应用于整个数组。
- 一元通用函数对单个数组逐元素计算，例如 `sqrt`、`exp`。
- 二元通用函数对两个数组逐元素计算，例如 `add`、`maximum`、`minimum`。
- `maximum` 和 `minimum` 的核心是“对位比较”：
  - `maximum`：逐元素取较大值；
  - `minimum`：逐元素取较小值。
- 不需要死记所有通用函数，理解机制、按需查阅、会调用即可。
