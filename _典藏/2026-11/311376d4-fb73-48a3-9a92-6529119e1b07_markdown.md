## 三、`replace` 的特殊用法：提取温度数值并转换类型

### 需求

温度列中的数据类似：

- `36℃`

希望去掉“℃”，只保留数值 `36`，并将结果转换成整数类型。

### 操作思路

- 先选中温度列。
- 使用 `.str.replace('℃', '')` 将“℃”替换为空字符串。
- 再使用 `.astype('int64')` 将结果转换为 64 位整数类型。

示例逻辑：

`df['温度'].str.replace('℃', '').astype('int64')`

### 关键点

- 只有先转成字符串格式，才能使用 `.str` 相关字符串替换方法。
- 替换完成后，结果仍然是字符串，需要用 `astype` 转成数值类型。
- 运行后温度列变成 `int64` 类型。
- `astype` 表示类型转换，类似重命名/转换数据类型。
- 数据类型详细内容可参考 Numpy 课程笔记。

## 四、`str.cat`：与指定字符或数据进行拼接

### 作用

`str.cat` 用于将字符串与指定字符、列表或其他序列进行拼接，类似“穿糖葫芦”式连接。

### 基本用法

#### 1. 不传参数直接串联

`df['姓名'].str.cat()`

- 不传参数时，会把姓名列中的所有姓名平行连接成一个长字符串。
- 空值仍需要额外处理。

#### 2. 使用 `sep` 添加分隔符

`df['姓名'].str.cat(sep='、')`

- `sep` 参数用于指定连接符。
- 示例中使用中文顿号 `、`，每个人名之间用顿号分开。

#### 3. 给每个姓名后追加固定内容

需求：每个姓名后都加上“变身”。

思路：额外拼接的数据必须与姓名列等长。

示例逻辑：

`df['姓名'].str.cat(['变身'] * len(df), sep='')`

说明：

- 列表 `['变身'] * len(df)` 的长度必须等于姓名列的行数。
- 如果数量不相等，会报错。
- 视频中先用 `5` 和 `6` 测试，说明必须与行数一致。
- 实际中不需要手动数行数，可使用 `len(df)` 获取行数。
- 若再加分隔符，可通过 `sep` 指定，例如使用某个符号作为分隔。

#### 4. 使用 `na_rep` 处理空值

如果姓名列中存在空值，`cat` 结果中会出现 `NaN`。可通过 `na_rep` 指定空值替换内容。

示例：

`df['姓名'].str.cat(['变身'] * len(df), sep='', na_rep='@')`

- 空值可替换为 `@`。
- 也可写成“没有”“无名”等自定义内容。
- 视频示例中空值处理后显示为类似 `@变身` 的形式。

### `str.cat` 注意点

- 额外拼接的数据必须与目标列等长、数量相等。
- `sep` 用于指定连接符。
- `na_rep` 用于替换空值。
- `cat` 是“连接/拼接”方法，可理解为 concatenate。

## 五、`str.split`：按指定字符拆分字符串

### 作用

将字符串按指定字符拆分成列表。

### 基本表现

`df['状态'].str.split()`

- 使用 `split` 后，状态列会以列表形式显示。
- 空值仍然为空。
- 如果指定分隔字符，则按该字符拆分。

### 按指定字符拆分

示例：状态列中有“满血激活”“零血销毁”等。

`df['状态'].str.split('血')`

结果类似：

- `'满血激活'` → `['满', '激活']`
- 分隔符“血”本身不会出现在结果列表中。
- 与 Python 内置 `split` 的行为一致。

### 参数 `n`

- `str.split` 可指定拆分次数 `n`。
- 默认 `n=-1`，表示全部分离，所有分隔符都参与拆分。
- 如果只想拆分前一个，可传入指定数字，如 `n=1`。
- 示例中“满血激活”只有一个“血”，所以不需要特别指定。

### 参数 `expand=True`

`df['状态'].str.split('血', expand=True)`

- `expand` 默认为 `False`。
- 当 `expand=True` 时，会将拆分后的列表展开成多列。
- 作用类似 Excel 中的“分列”。
- 例如按“血”拆分后，可分成两列。

### `str.rsplit`

- `str.rsplit` 与 `split` 类似，但方向和 `split` 相反。
- `split` 从左向右拆分。
- `rsplit` 从右向左拆分。
- 本课只需了解即可。

## 六、`str.partition`：按指定字符分成三部分

### 作用

`str.partition(pat)` 按指定字符分割字符串，并固定返回三个部分：

- 第一个分隔符之前的内容。
- 分隔符本身。
- 分隔符之后的内容。

### 与 `split` 的区别

- `split` 默认结果中不包含分隔符。
- `partition` 会保留分隔符本身，作为中间元素。

示例逻辑：

`df['状态'].str.partition('血')`

例如“满血激活”可理解为：

- 第一部分：`满`
- 第二部分：`血`
- 第三部分：`激活`

### 多个分隔符时

- 如果字符串中有多个分隔符，`partition` 只按照第一个分隔符进行分割。
- 例如字符串中有多个小写 `b`，用 `b` 分割时只处理第一个 `b`。
- 这一点需要重点记住：`partition` 只按第一个分隔符分割。

### 找不到分隔符时

- 如果指定的分隔符不存在，则返回：
  - 第一部分为原字符串；
  - 第二部分为空；
  - 第三部分为空。
- 如果数据本身为空，结果仍为空。
- 不写分隔符与写一个不存在的分隔符，在视频示例中结果表现类似。

### `str.rpartition`

- `rpartition` 与 `partition` 类似。
- 区别是从右向左查找分隔符。
- `partition` 默认从左到右；`rpartition` 从右到左。

## 七、`str.get`：获取指定位置的字符

### 作用

`str.get(i)` 用于获取字符串中指定位置的单个字符。

示例：

`df['状态'].str.get(2)`

- 索引从 `0` 开始。
- `get(2)` 表示获取第 3 个字符。
- 示例中“满血激活”的索引为：
  - 0：满
  - 1：血
  - 2：激
  - 3：活
- 因此 `get(2)` 得到“激”。

### 注意点

- `get` 只能获取一个字符。
- 参数只能传 `int` 整型，不能传浮点型等其他类型。
- 如果所有位置都越界，则返回 `NaN`，并且整列类型为 `float64`。
- 如果原列中有空值，也可能导致整列显示为 `float64`。

## 八、Pandas 数据类型与空值补充

### 整型变浮点型的原因

- 使用 Pandas 读取 Excel、CSV、数据库表时，原本是整型的列可能变成浮点型。
- 常见原因：该列存在空值。
- 例如原本 Excel 中是 `1`，读入后可能变成 `1.0`。
- 一旦列中有空值，整列的数据类型可能被提升为 `float64`。

### 常见类型说明

- `int32`、`int64`：整数类型。
- `float32`、`float64`：浮点数类型。
- `object`：可理解为字符串型/字符型。
- 普通数值或字符空值：`NaN`。
- 时间类型空值：`NaT`。

### 空值处理提醒

- 如果想将 `NaN` 和 `NaT` 转成空，需要专门处理。
- 视频提到之前课件中介绍过将 `NaN` 和 `NaT` 转为空的方法，可结合笔记使用。

## 九、`str.slice`：获取指定范围的字符

### 作用

`str.slice(start, stop, step)` 类似 Python 切片，用于截取指定范围内的字符。

### 示例说明

- `str.slice(0)`：从索引 0 开始一直到末尾，显示全部字符。
- `str.slice(0, 3)`：从 0 开始，不包含 3，即取索引 0、1、2，共三个字符。
- `str.slice(start, stop, step)` 可设置步长。

### 步长示例

- 设置步长为 2，表示隔一个取一个。
- 例如从索引 0 开始，步长 2，结果取索引 0、2 等。

### 越界情况

- 如果切片范围越界：
  - 原来有字符的位置显示为空字符；
  - 原来本身是 `NaN` 的仍显示为空值。
- 需要注意“空字符”和“空值”的区别。

## 十、`str.slice_replace`：筛选出指定范围后替换

### 作用

`str.slice_replace(start, stop, repl)` 用于截取指定范围，并将该范围替换为指定内容。

### 示例

状态列“满血激活”：

`df['状态'].str.slice_replace(1, 3, '520')`

- 索引 1 到 2 对应“血激”。
- 将“血激”替换成“520”。
- 结果类似：`满520活`。

### 理解方式

- 等价于先使用 `slice(1, 3)` 取出“血激”。
- 再用 `520` 替换这一段。
- 因为本质是替换指定切片范围，所以不支持步长 `step`。

## 十一、`str.join`：用指定字符连接每个字符

### 作用

`str.join(sep)` 将字符串中的每个字符之间用指定字符连接。

示例：

`df['状态'].str.join('a')`

- “满血激活”会在每个字符之间插入 `a`。
- 也可使用 `502` 等字符串作为连接内容。
- 可理解为用“胶水”把每个字符粘起来。

## 十二、`str.contains`：判断是否包含指定字符串

### 作用

`str.contains('血')` 判断每个字符串是否包含指定内容，返回布尔型结果：`True` 或 `False`。

示例：

`df['状态'].str.contains('血')`

- 包含“血”的返回 `True`。
- 不包含的返回 `False`。
- 空值默认为 `NaN`。

### 使用 `na` 参数处理空值

`df['状态'].str.contains('血', na=False)`

- 将空值结果显示为 `False`。
- 也可设置 `na=True`。
- 还可设置 `na='没有'` 等自定义内容。

## 十三、`str.startswith` 与 `str.endswith`：判断开头和结尾

### `startswith`

`df['状态'].str.startswith('满')`

- 判断是否以指定字符开头。
- 示例中“满血激活”返回 `True`。
- “零血销毁”不是以“满”开头，返回 `False`。

### `endswith`

`df['状态'].str.endswith('...')`

- 判断是否以指定内容结尾。
- 将 `startswith` 改为 `endswith` 即可。
- 同样支持 `na` 参数设置空值显示。

## 十四、`str.repeat`：重复字符串

### 作用

`str.repeat(n)` 将每个字符串重复指定次数。

示例：

`df['姓名'].str.repeat(3)`

- 每个姓名重复 3 次。
- 空值可通过 `na` 参数转换。

## 十五、`str.pad`：用指定字符填充到指定宽度

### 作用

`str.pad(width, side='left', fillchar=' ')` 将每个元素填充到指定宽度。

示例：

`df['姓名'].str.pad(5, fillchar='*')`

- 将姓名填充到 5 个字符宽度。
- `fillchar` 指定填充字符。
- `fillchar` 只能是一个字符。

### `side` 参数

- 默认从左侧填充，相当于右对齐。
- `side='right'`：从右侧填充，相当于左对齐。
- `side='both'`：从两端填充，自动尽量平衡，一般优先向左边补，再补右边。

示例：

`df['姓名'].str.pad(5, side='right', fillchar='*')`

`df['姓名'].str.pad(5, side='both', fillchar='*')`

### 相关演变方法

- `str.center(width, fillchar)`：两端填充，相当于 `side='both'`。
- `str.ljust(width, fillchar)`：左对齐，即右侧填充，相当于 `side='right'`。
- `str.rjust(width, fillchar)`：右对齐，即左侧填充，相当于 `side='left'`。

建议：实际使用中记住 `str.pad` 即可，其他方法了解为主，避免记忆负担过重。

## 十六、`str.zfill`：用 0 从左侧填充

### 作用

`str.zfill(width)` 用字符 `0` 从左侧填充到指定宽度。

示例：

`df['姓名'].str.zfill(10)`

- 将姓名用 0 填充到 10 位。
- 只能使用 `0` 填充。
- 只能从左侧填充。

## 十七、`str.encode` 与 `str.decode`：编码和解码转换

### 编码

`df['列名'].str.encode('utf-8')`

- 将字符串编码为指定格式。
- 常用于处理 CSV 文件中文乱码等问题。
- 如果整个文件多为英文，但某一列是中文，可能出现乱码，可尝试转成 `utf-8`。

### 解码

`df['列名'].str.decode('utf-8')`

- 将编码后的内容解码。
- 注意区分：
  - 编码：`encode`
  - 解码：`decode`
- 本部分了解即可，实际遇到转码问题时查阅笔记。

## 十八、`str.strip`、`str.lstrip`、`str.rstrip`：按指定内容去除字符

### `str.strip`

`str.strip(chars)` 按指定内容从字符串两边去除字符。

示例：里程列中有“近距离”“远距离”“中远距离”等值。

`df['里程'].str.strip('中远近离')`

说明：

- 使用“中远近离”这些字符从两端去除。
- 运行后会去除两端所有出现在参数集合中的字符。
- 注意：`strip` 的参数是“字符集合”，不是完整子串。
- 它会不断去除两端属于该集合的字符，直到遇到不在集合中的字符。

### `str.lstrip` 与 `str.rstrip`

- `str.lstrip(chars)`：从左侧去除。
- `str.rstrip(chars)`：从右侧去除。
- `str.strip(chars)`：从两边去除。
