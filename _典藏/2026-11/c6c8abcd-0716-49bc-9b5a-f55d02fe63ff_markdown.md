## 1. 本节定位与问题场景

- 本节课是对上一节课内容的补充，主题是 **Matplotlib 多子图布局调整**。
- 讲师先提出一个常见问题：如果在一张画布（Figure，讲师口述为“布”）上绘制多个子图，布局没有处理好，可能出现：
  - 子图标题与下方 x 轴刻度重叠；
  - 多个子图之间距离过近；
  - 子图距离画布边缘过近或过远。
- 解决思路有两类：
  - 使用自动布局调整；
  - 手动调整画布边距与子图之间的间距。

## 2. 方法一：自动调整布局 `plt.tight_layout()`

- 讲师称这是“最简单的一种方法”，即使用自动调整布局。
- 视频中口述近似为“布点 t i g t t i p 他的 a y o u t”，对应的标准 Matplotlib 写法是：

```python
plt.tight_layout()
```

- 作用：
  - 自动调整子图布局；
  - 使标题、坐标轴刻度、标签等内容尽量不重叠；
  - 讲师强调它“自动进行自动适应”。
- 适用范围：
  - 讲师说“对图也行，对布也可以操作”，即可以对当前图形/画布中的布局进行自动适应。
  - 一般通过 `plt.tight_layout()` 调用即可。
- 使用效果：
  - 如果给子图添加标题，自动调整后标题会自动下移或整体布局自动适配；
  - 标题与 x 轴刻度不容易重叠；
  - 不需要再手动设置很多边距参数。
- 讲师的实际使用习惯：
  - 平时使用自动适应较多；
  - 原因是“比较懒”，能自动适应就自动适应；
  - 真正工作中一般也会用自动适应。

## 3. 方法二：手动调整布局 `plt.subplots_adjust()`

### 3.1 手动调整的对象

- 讲师说明，除了自动调整布局外，还可以手动更改画布中图的前后左右位置和距离。
- 可调整的内容包括：
  - 子图离画布左侧的距离；
  - 子图离画布右侧的距离；
  - 子图离画布顶部的距离；
  - 子图离画布底部的距离；
  - 子图与子图之间的宽度；
  - 子图与子图之间的高度。
- 视频中对应的标准函数是：

```python
plt.subplots_adjust(...)
```

- 转写中出现的近似音“s u b p l bt s”，对应 `subplots_adjust`。

### 3.2 关键参数说明

- `wspace`：
  - 控制子图之间的宽度/水平间距；
  - 也就是多个子图之间“左右方向”的间隔；
  - 视频中讲师设置了一个较小的数值，用于拉开子图之间的水平距离。按演示语境记录为 `wspace=0.5`。
- `hspace`：
  - 控制子图之间的高度/垂直间距；
  - 也就是多个子图之间“上下方向”的间隔；
  - 视频中设置为 `hspace=0.3`。
- `left`：
  - 控制子图区域距离画布左侧的边距；
  - 视频中设置为 `left=0.125`。
- `right`：
  - 控制子图区域右侧边界/右侧距离；
  - 视频中设置为 `right=0.9`。
  - 需要注意：Matplotlib 中 `right` 表示子图区域的右边界位置，通常取 0 到 1 之间的比例值；讲师口述为“右侧距离”。
- `top`：
  - 控制子图区域顶部边界/顶部距离；
  - 视频中讲师明确点到 `top` 参数，但转录内容没有清晰给出具体数值。
  - 笔记中应保留该参数，实际使用时可按需要设置。
- `bottom`：
  - 控制子图区域底部边界/底部距离；
  - 视频中设置为 `bottom=0.1`。
- 参数效果：
  - 讲师强调：这些数值越大，子图之间或子图与边缘之间分得就越开；
  - 可以根据实际图像效果自行调整。

### 3.3 演示代码与步骤

- 讲师先假设要在一张画布上做 `4×4` 子图布局，用来说明布局问题的概念；但实际演示时为了简单，生成的是 `2×2` 子图。
- 讲师说明画布大小不再额外设置，使用默认大小即可。
- 演示流程可整理为标准写法如下：

```python
import matplotlib.pyplot as plt

# 生成画布和 2×2 子图；视频中未额外设置画布大小
fig, axes = plt.subplots(2, 2)

# 手动调整子图布局
plt.subplots_adjust(
    wspace=0.5,   # 子图之间的水平/宽度间距
    hspace=0.3,   # 子图之间的垂直/高度间距
    left=0.125,   # 子图区域左侧边距
    right=0.9,    # 子图区域右侧边界
    # top=...,    # 视频提到 top，但未明确给出数值
    bottom=0.1    # 子图区域底部边距
)

plt.show()
```

- 代码作用逐项说明：
  - `plt.subplots(2, 2)`：生成 2 行 2 列的子图布局；
  - `plt.subplots_adjust(...)`：手动调整子图之间的间距以及子图与画布边缘的距离；
  - `wspace=0.5`：拉开同一行子图之间的水平距离；
  - `hspace=0.3`：拉开上下行子图之间的垂直距离；
  - `left=0.125`：设置左侧边距；
  - `right=0.9`：设置右侧边界；
  - `bottom=0.1`：设置底部边距；
  - `plt.show()`：显示图像。

### 3.4 运行结果与对比

- 加上 `plt.subplots_adjust(...)` 后：
  - 子图之间的距离被明显拉开；
  - 布局按照设置的参数打开、分开；
  - 图像整体不再显得拥挤。
- 如果不写这句手动调整代码：
  - 子图之间的距离会比较近；
  - 容易出现标题、刻度或子图之间拥挤的问题。
- 讲师总结：
  - 手动参数的数值越大，分得越多；
  - 将来如果研究生论文中需要使用图片，并且导师对图片格式、边距、间距有要求，可以按导师要求自行设置；
  - 手动调整的灵活度更高。

## 4. 自动调整与手动调整的选择建议

- 自动调整 `plt.tight_layout()`：
  - 简单、省事；
  - 自动适应布局；
  - 适合日常工作和大多数普通绘图场景；
  - 讲师实际工作中更常用这种方式。
- 手动调整 `plt.subplots_adjust(...)`：
  - 可以精确控制子图间距和画布边距；
  - 适合论文、报告或导师有明确格式要求的场景；
  - 需要自己反复调整数值。
- 讲师给出的实际建议：
  - 一般使用时，把 `plt.subplots_adjust(...)` 注释掉；
  - 改用 `plt.tight_layout()` 即可；
  - 不管图是什么样子，只要自动适应，往图中填标题等内容时，它会自动调整，避免重叠。

## 5. 关键结论与踩坑清单

- 多子图布局出问题时，优先考虑 `plt.tight_layout()` 自动调整。
- 标题与 x 轴刻度重叠时，自动布局可以让标题等元素自动适配，减少重叠。
- 手动调整使用 `plt.subplots_adjust()`，核心参数包括：
  - `wspace`：子图水平间距；
  - `hspace`：子图垂直间距；
  - `left`：左侧边距；
  - `right`：右侧边界；
  - `top`：顶部边界；
  - `bottom`：底部边距。
- 不写手动调整代码时，子图之间可能距离很近。
- 手动参数数值越大，间距通常越大，需要根据实际效果调整。
- 工作中通常使用自动适应布局；论文或特殊格式要求下再使用手动精确调整。
- 如果已经使用 `plt.tight_layout()`，一般不需要再写 `plt.subplots_adjust(...)`，可将后者注释掉。

## 6. 术语与函数速查

- `Figure`：画布/图形对象，讲师口述为“布”。
- `Axes` / 子图：画布中的具体绘图区域。
- `plt.tight_layout()`：自动调整子图布局，减少标题、刻度、标签重叠。
- `plt.subplots_adjust()`：手动调整子图间距与画布边距。
- `wspace`：子图之间的水平/宽度间距。
- `hspace`：子图之间的垂直/高度间距。
- `left`、`right`、`top`、`bottom`：子图区域相对画布的左、右、上、下边界参数。
- 布局调整的核心目标：让多子图排列清晰，标题、刻度、标签不重叠，并满足论文或报告的格式要求。
