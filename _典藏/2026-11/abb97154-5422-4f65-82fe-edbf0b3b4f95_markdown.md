# 数据处理的三板斧：map、apply、applymap

## 1. 课程主题与核心概念

本节课讲解 Pandas 中数据处理常用的“三板斧”：

- `map`
- `apply`
- `applymap`

在操作 DataFrame 时，经常需要逐行、逐列或逐元素处理数据。Pandas 提供的这三个方法可以覆盖绝大多数常见操作。

三者基本定位：

- `map`：主要用于 `Series` 整列映射，可通过字典或函数把原值映射为新值。
- `apply`：既可用于 `Series`，也可用于 `DataFrame`；可对一行、一列或整个表按指定轴执行函数，并支持传入多个参数。
- `applymap`：对 `DataFrame` 中的每个单元格执行指定函数。
- 补充：`replace` 更偏向于“替换值”，适合替换整个表中的某些具体值。

## 3. map：整列映射

### 3.1 使用字典进行映射

需求：把“性别”列中的：

- `男` 映射为 `先生`
- `女` 映射为 `女士`

做法：

- 先定义映射字典，例如：
  - `{'男': '先生', '女': '女士'}`
- 再新建一列“称呼”：
  - `df['称呼'] = df['性别'].map(映射字典)`

执行后，Pandas 会将“性别”列中的每个值逐个作为参数传入字典，得到对应映射值，并按原行位置写入新列。

映射的含义：

- 将对应数据逐个作为参数传入字典或函数中。
- 得到映射后的值。
- 原数据中符合“男”的位置返回“先生”，符合“女”的位置返回“女士”。

### 3.2 使用函数进行映射

`map` 也可以接收函数。

示例思路：

- 定义一个函数，例如 `替换性别(x)`。
- 使用三目表达式判断：
  - 若 `x == '男'`，返回 `先生`
  - 否则返回 `女士`
- 函数中必须使用 `return` 返回结果。
- 然后：
  - `df['称呼'] = df['性别'].map(替换性别)`

效果与字典映射一致。

也可以直接在原列上修改：

- `df['性别'] = df['性别'].map(替换性别)`

Pandas 会取最后一次赋值结果，因此原列会被覆盖修改。

### 3.3 map 与 replace 的区别

`map` 与 `replace` 都可以做某种“替换/映射”，但适用场景不同：

- `map`：
  - 针对整列进行操作。
  - 适合对某一列的所有值进行统一映射。
- `replace`：
  - 更偏向替换具体值。
  - 适合在整个表或指定范围中替换某些值。
  - 例如整个表中很多“孙兴华”，要全部替换成“新华”，使用 `replace` 更方便。

结论：

- 整列映射优先考虑 `map`。
- 具体值替换优先考虑 `replace`。
- 根据实际需求选择，没有一种方法能完全替代另一种。

## 4. apply：面向 Series 与 DataFrame 的灵活处理

`apply` 是使用频率很高的方法，主要分两种情况：

- 对 `Series` 进行数据处理，即针对一行或一列操作。
- 对 `DataFrame` 进行操作，即针对整张表按轴处理。

### 4.1 对 Series 使用 apply

需求示例：语文成绩需要统一加分或减分。

例如定义一个函数：

- 函数名：`修改分数`
- 形参：
  - `x`：接收某一列中的成绩
  - `误差值`：接收需要加或减的分数
- 函数逻辑：
  - `return x + 误差值`

调用方式：

- `df['语文'] = df['语文'].apply(修改分数, args=(5,))`

说明：

- `x` 会接收“语文”列中的每个成绩。
- `args=(5,)` 用于传入第二个参数“误差值”。
- 单个参数时可以使用 `map` 解决；多个参数时优先使用 `apply`。
- 传入单元素元组时必须保留逗号，例如 `(5,)`。
- 如果传 `-5`，则所有成绩减 5 分；如果传 `3`，则加 3 分。

示例理解：

- 原始语文成绩如 `90、62、68`。
- 加 5 分后变为 `95、67、73`。
- 若减 3 分，则第一项由 `90` 变为 `87`。

### 4.2 对 DataFrame 使用 apply 与 axis 概念

对表使用 `apply` 时，必须理解 `axis`。

两个核心概念：

- 行索引 `0、1、2、3、4...` 管的是行，称为行标签，对应 `0` 轴。
- 列名管的是列，称为列标签，对应 `1` 轴。

记忆方式：

- 行标签是 `0` 轴，横向排列。
- 列标签是 `1` 轴，竖向排列。
- 这一点从 NumPy 到 Pandas 一直是重点，必须清楚。

#### axis=0 的情况

当 `axis=0` 时，相当于对某个列执行指定函数。

示例需求：对“语文、数学、英语”三列分别求和。

示例结构：

- `df[['语文', '数学', '英语']].apply(sum, axis=0)`

含义：

- 按列方向执行函数。
- 对“语文”列求和。
- 对“数学”列求和。
- 对“英语”列求和。
- 结果整合后返回。

注意理解：

- `axis=0` 不是把一行的 `90 + 100 + 10` 这样横向相加。
- 而是按行向下汇总，对每一列执行函数。
- 具体是加总、平均还是其他操作，取决于 `apply` 中传入的聚合函数。

#### axis=1 的情况

当 `axis=1` 时，相当于对每一行执行指定函数。

此时：

- 每一行的数据会以一个 `Series` 形式传入函数。
- `Series` 的索引是列名。
- 函数返回的结果会按行整合返回。
- 如果希望有返回值，定义函数时必须写 `return`。

典型场景：根据每行的“身高”和“体重”计算 BMI。

### 4.3 BMI 计算示例

BMI 公式为：

\[
BMI = \frac{\text{体重}}{\text{身高}^{2}}
\]

示例数据中有“身高”和“体重”两列，因此可以计算每个人的 BMI。

定义一个 BMI 函数，思路如下：

- 参数为一行数据，例如 `data`。
- 取出：
  - `身高 = data['身高']`
  - `体重 = data['体重']`
- 计算：
  - `bmi = 体重 / (身高 ** 2)`
- 返回：
  - `return bmi`

然后新建一列：

- `df['BMI指数'] = df.apply(bmi, axis=1)`

为什么使用 `axis=1`：

- 因为 BMI 需要针对每一行同时使用“身高”和“体重”。
- `axis=1` 会把每一行作为一个 `Series` 传入函数。
- 函数按列名取出该行对应的身高、体重并计算。

计算完成后即可查看每个人的 BMI 指数。

### 4.4 apply 使用总结

- `axis=0`：
  - 对每个列执行指定函数。
  - 例如对语文、数学、英语列分别求和。
- `axis=1`：
  - 对每一行执行指定函数。
  - 每行以 `Series` 形式传入，索引为列名。
- 对每个 `Series` 执行的结果会整合在一起返回。
- 函数中需要返回值时必须写 `return`，否则无法得到预期返回结果。
- `DataFrame.apply` 与 `Series.apply` 都能接收更复杂的参数。
- 多参数传入原理一致，可使用 `args`。
- 若需更详细了解 `apply`，应查阅官方文档。

## 5. applymap：逐单元格操作

`applymap` 的用法比较简单：

- 对 `DataFrame` 的每个单元格执行指定函数。
- 用途没有 `apply` 广泛，但在某些场景下很有用。

示例需求：

- 有一个包含 `a、b、c、d、e` 五列的 DataFrame。
- 数据为随机数字。
- 需要把每个数字格式化为保留指定小数位数。

示例思路：

- 使用 `lambda` 表达式。
- 使用格式化字符串，例如保留三位小数：
  - `df.applymap(lambda x: '{:.3f}'.format(x))`
- 若保留两位小数：
  - `df.applymap(lambda x: '{:.2f}'.format(x))`

效果：

- 整数也会显示为带小数点的形式，例如保留三位时显示为 `0.000` 形式。
- 修改格式中的小数位数即可改变保留精度。

`applymap` 不如 `map` 和 `apply` 常用，因此课程中只做简单演示。

## 6. 总结与使用建议

三个方法的核心区别：

- `map`：
  - 主要针对 `Series` 整列映射。
  - 支持字典映射和函数映射。
  - 适合性别转换、分类映射等整列处理。
- `apply`：
  - 可用于 `Series` 和 `DataFrame`。
  - 支持多参数。
  - 通过 `axis=0` 或 `axis=1` 控制按列还是按行处理。
  - 适合成绩加减、按行计算 BMI、按列汇总等复杂操作。
- `applymap`：
  - 对 `DataFrame` 每个单元格执行函数。
  - 适合单元格级格式化，例如统一保留小数位。
- `replace`：
  - 更适合具体值替换。
  - 例如全表中把某个名字统一替换为另一个名字。

实际工作中：

- `map` 和 `apply` 已经足够覆盖大量场景。
- 再加上 `replace`，通常可以解决多数数据处理问题。
- `applymap` 在特定单元格处理场景下有用。
- 学习时一定要理解概念，并主动查阅官方文档；课程内容只是入门，覆盖不到 Pandas 全部内容的 10%。
