# 课程笔记：坐标轴上面的日期格式

## 1. 课程目标与问题场景

- 本课解决 **Matplotlib 坐标轴日期标签格式不满足需求** 的问题。
- 示例数据文件：`12.17.xlsx`（以实际课程文件名为准）。
- 数据内容很简单：
  - 一列日期
  - 一列销售
- 沿用前面课程中已处理的 Pandas 可视化中文显示问题；本课重点不是中文乱码，而是 **日期格式**。
- 默认绘图时，坐标轴上的日期“数据里是什么样子，图上就显示成什么样子”。
- 实际需求可能包括：
  - 日期显示成 `2020年12月1日`
  - 不显示年份，只显示 `12月1号`
  - 使用其他分隔符，例如 `*`
  - 只显示月、日等

这类需求需要通过 **日期格式化** 来解决，而不是直接修改图表的默认显示。

## 2. 先绘制默认折线图观察问题

课程先读取数据并直接作图：

```python
import pandas as pd
import matplotlib.pyplot as plt

data = pd.read_excel('12.17.xlsx')

plt.plot(data['日期'], data['销售'])
plt.show()
```

关键点：

- `plt.plot()` 用于绘制折线图。
- 第一个参数是 x 轴数据，默认直接使用 `data['日期']`。
- 第二个参数是 y 轴数据，即 `data['销售']`。
- `plt.show()` 用于显示图表。
- 运行后观察：x 轴日期标签显示的是原始日期格式，不能直接满足“显示为某年某月某日”或“只显示月日”等要求。

## 3. 使用列表推导式提取日期列

课程回顾了基础篇中的 **列表推导式**。

从数据列中取出日期，示意写法如下：

```python
d = [i for i in data['日期']]
```

说明：

- `d` 是一个列表。
- 列表中的每个元素来自 `data['日期']`。
- 这些元素的类型是 Pandas 中的 `Timestamp` 格式，而不是普通字符串。
- 前面 Pandas 课程中已经讲过 `Timestamp` 类型；本课需要把它转换成指定格式的字符串。

易混点：

- `data['日期']` 是 Pandas 的日期列。
- 用列表推导式取出来后，得到的是由 `Timestamp` 对象组成的 Python 列表。
- 后续格式化操作针对的是这个列表 `d`，不是原始数据列。

## 4. 使用 `strftime()` 格式化日期

### 4.1 核心方法

对 `Timestamp` 对象使用 `strftime()` 方法进行格式化。

示意代码：

```python
d = [i.strftime('%m-%d') for i in d]
```

说明：

- `i` 表示列表 `d` 中的每一个 `Timestamp` 对象。
- `i.strftime(...)` 将时间对象转换为指定格式的字符串。
- `%m-%d` 表示“月-日”格式。
- 格式化后，`d` 中的元素由 `Timestamp` 变成了字符串。

课程中还提到可以写成赋值形式，将格式化结果保存下来继续使用；核心表达式不变：

```python
[i.strftime('%m-%d') for i in d]
```

### 4.2 常用格式符

课程中重点演示了以下格式符：

- `%m`：月份，例如 `12`
- `%d`：日期，例如 `01`
- `%Y`：四位年份，例如 `2020`

示例：

只显示月和日：

```python
d = [i.strftime('%m-%d') for i in d]
```

显示完整年份：

```python
d = [i.strftime('%Y-%m-%d') for i in d]
```

显示中文年月日：

```python
d = [i.strftime('%Y年%m月%d日') for i in d]
```

使用星号作为分隔符：

```python
d = [i.strftime('%m*%d') for i in d]
```

关键结论：

- `strftime()` 内部只需要给出目标格式字符串。
- 格式字符串中可以包含普通字符，例如 `年`、`月`、`日`、`*`、`-`。
- `%Y` 中的 `Y` 是大写，`%m` 和 `%d` 是小写，注意不要写错。
- 本课示例中最终假设只保留“月和日”。

## 5. 用格式化后的日期列表重新绘图

完成日期格式化后，绘图时不再使用原始数据列 `data['日期']`，而是使用新列表 `d`：

```python
plt.plot(d, data['销售'])
plt.show()
```

关键点：

- `plt.plot()` 的第一个参数改为格式化后的日期列表 `d`。
- 第二个参数仍然使用销售数据 `data['销售']`。
- 这样坐标轴上的日期标签就会显示为 `d` 中的字符串格式。
- 课程强调：后续所有针对日期标签的操作，都要使用这个新的日期列表 `d`，而不是原始数据里的日期列。

## 6. 日期标签的旋转与字体设置

### 6.1 旋转日期标签

日期标签文字可能较长，可以旋转 x 轴刻度标签：

```python
plt.xticks(rotation=45)
```

说明：

- `rotation=45` 表示将 x 轴刻度标签旋转 45 度。
- 旋转的是坐标轴刻度文字，不是数据点。
- 日期标签较长或数据较多时，旋转可减少文字重叠。

### 6.2 调整字体大小

课程提到还可以调整字体大小等参数，例如：

```python
plt.xticks(rotation=45, fontsize=10)
```

说明：

- `fontsize` 用于控制刻度标签字体大小。
- 可以与 `rotation` 同时设置。
- 具体字号可根据图表尺寸和数据量调整。

### 6.3 自动适应与避免文字重合

课程最后提到可以设置“自动适应”。

转录中讲师口述近似为 `t i g`，并说明其作用是：

- 让坐标轴或布局自动适应；
- 当数据比较多时，文字容易重合；
- 自动拉宽距离，进行自动适应。

在 Matplotlib 中，常用布局自动调整方式例如：

```python
plt.tight_layout()
```

或日期轴自动格式化/自动旋转方式例如：

```python
fig.autofmt_xdate()
```

注意：

- 视频此处语音识别不够清晰，只明确表达目标是“自动适应/自动视野”，避免标签文字重合。
- 实际编码时应根据当前 Matplotlib 版本和代码上下文选择对应函数。
- 课程核心结论是：数据较多、日期标签拥挤时，不要只靠手动调字号，应结合旋转、字体大小和自动布局来避免重叠。

## 7. 完整操作流程示意

```python
import pandas as pd
import matplotlib.pyplot as plt

data = pd.read_excel('12.17.xlsx')

# 1. 默认绘图，观察原始日期格式
plt.plot(data['日期'], data['销售'])
plt.show()

# 2. 用列表推导式提取 Timestamp 日期
d = [i for i in data['日期']]

# 3. 使用 strftime 格式化日期，例如只保留“月-日”
d = [i.strftime('%m-%d') for i in d]

# 4. 用格式化后的日期列表绘图
plt.plot(d, data['销售'])

# 5. 旋转 x 轴日期标签，避免重叠
plt.xticks(rotation=45)

# 6. 自动调整布局（对应课程中提到的自动适应思路）
plt.tight_layout()

plt.show()
```

如果希望显示为中文年月日，可将格式化步骤改为：

```python
d = [i.strftime('%Y年%m月%d日') for i in d]
```

如果只需要月份和日期，可改为：

```python
d = [i.strftime('%m月%d日') for i in d]
```

## 8. 关键结论与易错点

- 默认情况下，Matplotlib 会按原始数据形式显示 x 轴日期标签。
- 解决日期显示格式问题的关键步骤是：
  - 先从日期列中取出 `Timestamp` 对象；
  - 再使用 `strftime()` 转成目标字符串格式；
  - 最后用格式化后的字符串列表作为 x 轴数据绘图。
- `strftime()` 的格式符要写对：
  - `%Y`：四位年份
  - `%m`：月份
  - `%d`：日期
- 格式字符串中可以加入普通字符，例如 `年`、`月`、`日`、`-`、`*`。
- 绘图时如果已经使用格式化后的列表 `d`，后续坐标轴设置也要针对 `d`，不要混用原始日期列。
- `plt.xticks(rotation=45)` 旋转的是刻度标签文字，不是数据本身。
- 数据较多、标签拥挤时，可结合：
  - 旋转标签；
  - 调整字体大小；
  - 自动布局/自动适应，避免文字重叠。
- 使用字符串日期列表后，x 轴更接近“分类标签”显示方式；它解决的是显示格式问题，不等同于 Matplotlib 原生日期定位器的高级时间轴控制。
