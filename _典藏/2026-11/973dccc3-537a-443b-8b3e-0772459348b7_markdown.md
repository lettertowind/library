## 课程笔记：Pandas 数学统计函数

### 三、核心函数：`describe()`

在 Pandas 中，对数据调用 `describe()` 可以一次性得到数值列的常用统计信息。

典型表达式：

- `df.describe()`

作用：

- 一次性计算并返回多个统计量。
- 自动对数值列进行统计。
- 只计算数值列，不计算姓名等非数值列。
- 在本节成绩表中，会对语文、数学、英语等数值列进行计算。
- 运行后可以直接看到所有数值列的主要统计结果。

### 四、`describe()` 输出字段逐项解释

`describe()` 返回结果中常见字段如下：

- `count`：统计数量。讲师解释为统计这一列里有多少个值。
  - 在 Pandas 中通常统计非空值数量；本节按“该列值的数量”理解。
- `mean`：均值。
- `std`：标准差。
- `min`：最小值。
- `max`：最大值。
- `25%`：\(1/4\) 分位数，即 \(25\%\) 分位数，可记为 \(Q_1\)。
- `50%`：\(1/2\) 分位数，即 \(50\%\) 分位数，可记为 \(Q_2\)，也是中位数。
- `75%`：\(3/4\) 分位数，即 \(75\%\) 分位数，可记为 \(Q_3\)。

相关统计记号可表示为：

- 均值：\(\bar{x}\)
- 标准差：\(\sigma\)
- 分位数：\(Q_1\)、\(Q_2\)、\(Q_3\)
- 协方差：\(\operatorname{Cov}(X,Y)\)
- 相关系数：\(\rho_{X,Y}\)

讲师对使用频率的判断：

- 最大值、最小值、均值等统计量在工作中较常用。
- 标准差、\(1/4\) 分位数、\(1/2\) 分位数、\(3/4\) 分位数等不一定每个人都用得到。
- 用不到并不代表知识无用，而是说明当前工作场景暂时不需要；需要时再研究即可。
- 类比 Excel 公式：正弦、余弦等公式不是每个人都会用，但需要的人会用；用不到时不必强行深究。

### 五、只查看某一列的统计结果

如果不想一次查看所有数值列，可以指定某一列后再调用 `describe()`。

示例：

- `df['语文'].describe()`

作用：

- 只查看“语文”这一列的统计结果。
- 讲师所说的“欺骗方式”，即先通过列选择指定要分析的数据列，再调用统计函数。
- 对几百列的数据集，只关心某一列时，可以指定列名进行查看。

### 六、查看某几列的统计结果

如果要同时查看多列，可以把多个列名放入列表中，用逗号分隔。

示例：

- `df[['语文', '数学']].describe()`
- `df[['语文', '数学', '英语']].describe()`

操作要点：

- 在列表中选择多个列。
- 列名之间使用逗号分隔。
- 再统一调用 `describe()`，即可查看所选多列的统计结果。

### 七、单独查看某个统计量

如果不希望显示完整 `describe()` 表格，只想查看某一个统计量，可以直接在指定列后调用对应统计方法。

查看语文均值：

- `df['语文'].mean()`

查看语文最大值：

- `df['语文'].max()`

讲师说明：

- 想看 `mean`，直接在列后写 `mean`。
- 想看 `max`，直接在列后写 `max`。
- 方差、标准差等函数没有逐一演示，但使用方式相同：在数据对象或指定列后打点，再写函数名。
- 基本用法可以概括为：`对象.函数名()`。
- 对某一列使用统计函数时，就是：`df['列名'].统计函数()`。

### 八、其他数学统计函数速查表

讲师在课件“笔记 12.1”中整理了所有数学统计函数，便于后续查询。常见统计量及 Pandas 常用方法如下：

| 统计量 | Pandas 常用方法 | 说明 |
|---|---|---|
| 个数 | `count()` | 统计数量，通常为非空值数量 |
| 求和 | `sum()` | 对数值求和 |
| 平均 | `mean()` | 平均数；注意不是 `average` |
| 中位数 | `median()` | 排序后位于中间位置的值 |
| 最小值 | `min()` | 最小值 |
| 最大值 | `max()` | 最大值 |
| 众数 | `mode()` | 出现次数最多的值；转录中称为“重数” |
| 乘积 | `prod()` | 所有数值相乘 |
| 方差 | `var()` | 方差 |
| 标准差 | `std()` | 标准差 |
| 分位数 | `quantile()` | 如 \(25\%\)、\(50\%\)、\(75\%\) 分位数 |
| 累最大值 | `cummax()` | 累积最大值 |
| 累最小值 | `cummin()` | 累积最小值 |
| 协方差 | `cov()` | 协方差 \(\operatorname{Cov}(X,Y)\) |
| 相关系数 | `corr()` | 相关系数 \(\rho_{X,Y}\) |

重点记忆：

- 平均数的函数名是 `mean`，不是 Excel 中常见的 `average`。
- 分位数对应 \(25\%\)、\(50\%\)、\(75\%\) 等位置。
- 协方差和相关系数在数据分析岗位中使用较多；分析工作做得越深入，越可能用到。
- 其他函数使用时方法一致：在数据对象后打点，再写函数名。

### 九、关键代码与表达式汇总

数据读取相关：

- Excel 演示：读取 Excel 文件。
- csv 实际应用：使用 `read_csv`。
- 打印数据：读取后打印查看数据内容。

核心统计：

- `df.describe()`：一次性查看所有数值列统计信息。
- `df['语文'].describe()`：查看语文单列统计信息。
- `df[['语文', '数学']].describe()`：查看语文、数学等多列统计信息。
- `df['语文'].mean()`：查看语文均值。
- `df['语文'].max()`：查看语文最大值。
- `df['语文'].var()`：查看语文方差，讲师未演示但用法同类。
- `df['语文'].std()`：查看语文标准差，讲师未演示但用法同类。

统一调用规律：

- 对整个 DataFrame：`df.统计函数()`。
- 对单列：`df['列名'].统计函数()`。
- 对多列：`df[['列名1', '列名2']].统计函数()`。

### 十、本节结论

- 本节最核心的函数是 `describe()`，可一次性得到数值列的数量、均值、标准差、最小值、最大值和分位数等统计信息。
- `describe()` 只统计数值列，不统计姓名等非数值列。
- 可以通过列选择把统计范围限定到单列或多列。
- 如果需要单个统计量，可以直接调用 `mean()`、`max()` 等方法。
- 其他数学统计函数不需要一次性全部记住；知道函数名和用途，工作中需要时查询即可。
- 对统计概念不熟悉时，需要补充概率统计相关知识，例如均值、标准差、分位数、协方差和相关系数。
