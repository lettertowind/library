## 2. 折线图样式：`drawstyle`

### 2.1 `drawstyle` 是什么

- `drawstyle` 是 `plt.plot()` 中用于控制折线连接方式的参数。
- 讲师在绘制折线图时单独加入该参数，用来演示不同阶梯式连线效果。
- 基本用法：

```python
plt.plot(x, y, drawstyle='steps')
```

- 作用：让折线按照阶梯方式连接各个数据点。
- 不加 `drawstyle` 时：折线为默认的普通直线连接。
- 加上 `drawstyle='steps'` 后：折线点按照阶梯方式连接，图形外观明显不同。

### 2.2 折线样式的可选值

讲师说明：折线连接样式加上默认样式，一共有五种；除默认样式外，还有四种阶梯连接方式需要演示。

- 默认样式：`default`
- 阶梯样式：`steps`
- 前置阶梯：`steps-pre`
- 中间阶梯：`steps-mid`
- 后置阶梯：`steps-post`

对应示例形式：

```python
plt.plot(x, y, drawstyle='steps')
plt.plot(x, y, drawstyle='steps-pre')
plt.plot(x, y, drawstyle='steps-mid')
plt.plot(x, y, drawstyle='steps-post')
```

### 2.3 各阶梯样式的对比结论

- 讲师逐个演示这些样式，并指出每一种连接方式不一样。
- 有的样式从上方连接，有的从下方连接，视觉上略有区别。
- 使用时应根据自身需求选择折线样式。
- 讲师明确说：“每一种方式它的连接不一样，这个呢，你根据你自己的需求去用你这个折线的样式。”

### 2.4 易混点：`drawstyle` 与普通线型不同

- 本课所讲的折线“样式”主要指 `drawstyle`，即数据点之间采用何种阶梯连接方式。
- 它与常见的线条虚实样式，如实线、破折线、点划线、虚线、无线条等，不是同一个概念。
- 普通线型更多控制线条外观；`drawstyle` 控制折线在点与点之间的阶梯连接方式。

## 3. 画布样式：查看与设置

### 3.1 画布样式的作用

- 画布样式用于设置图表的整体外观，例如背景风格等。
- 讲师回顾：在前面讲雷达图时已经使用过样式，当时设置的样式疑似为 `ggplot`。
- 本课继续演示如何查看所有可用样式，以及如何设置画布样式。

### 3.2 查看 Matplotlib 所有可用样式

- 先导入可视化库：

```python
import matplotlib.pyplot as plt
```

- 打印所有可用样式：

```python
print(plt.style.available)
```

- 作用：将 Matplotlib 内置的所有样式名称打印出来。
- 讲师说明：打印后可以看到所有样式都列出来了，之后可以从中选择任意一个样式进行设置。

### 3.3 设置画布样式

- 设置样式使用：

```python
plt.style.use('ggplot')
```

- 其中 `'ggplot'` 是样式名称，应来自 `plt.style.available` 打印结果中的某个名称。
- 讲师在视频中寻找并使用了之前雷达图用过的样式，疑似为 `ggplot`。
- 使用方法：把 `plt.style.use()` 括号中的样式名替换成想要的样式名即可。

### 3.4 建立画布并显示

- 建立画布，转录中讲师提到类似 `plt.subplots()` 的操作：

```python
plt.subplots()
```

- 显示图形：

```python
plt.show()
```

- 讲师说明：
  - 上次雷达图是圆形的，本次演示为方形的画布。
  - 画布后边显示的背景与设置的样式一致。
  - 设置画布样式后，图表的整体背景风格会跟随该样式变化。

### 3.5 易混点：画布样式与折线样式

- 画布样式 `plt.style.use()` 是全局图表风格设置，会影响后续图表的整体外观。
- 折线样式 `drawstyle` 只是当前折线图的连接方式设置。
- 两者层级不同：一个是画布/图表整体风格，一个是单条折线的数据点连接外观。

## 5. 本课关键结论与注意事项

- 样式是 Matplotlib 预先准备好的，直接套用即可，不需要自己从零设计。
- 折线图可以通过 `plt.plot()` 的 `drawstyle` 参数设置阶梯连接方式。
- 折线连接样式共涉及默认样式和四种阶梯变体：
  - `default`
  - `steps`
  - `steps-pre`
  - `steps-mid`
  - `steps-post`
- 不同 `drawstyle` 的连线方式不同，需按需求选择。
- 查看画布样式使用：

```python
print(plt.style.available)
```

- 设置画布样式使用：

```python
plt.style.use('样式名')
```

- 设置样式后，画布背景和整体风格会跟随该样式变化。
- 样式名称建议从 `plt.style.available` 或附件预览中复制，避免手动拼写错误。
- 常用颜色、颜色表、16 进制颜色编码、常用标记点、常用连线方式都可以在附件中查找。
- 颜色编码是 16 进制，不是 16 位。
