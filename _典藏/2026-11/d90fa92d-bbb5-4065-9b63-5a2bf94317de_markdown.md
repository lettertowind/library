# pandas 数据替换（p36 S02E21）笔记

## 课程主题

本节讲解 pandas 中的通用数据替换操作。此前学习的缺失值替换只是特殊情况，只能替换缺失值；本节讨论在真实数据分析中更常见的需求：替换整表数据、指定列数据、多个值映射、字符串部分内容替换，以及基于正则表达式的替换。

核心方法：

- `DataFrame.replace()` / `Series.replace()`：按值替换。
- `Series.str.replace()`：按字符串部分内容替换。
- `regex=True`：让 `replace()` 按正则表达式解释模式。
- `inplace=True`：在原数据上直接修改。

## 2. `replace()` 基本用法

需求：把“城八区”替换成“海淀区”。

```python
data.replace('城八区', '海淀区', inplace=True)
print(data)
```

说明：

- `replace(old, new)` 中，第一个参数是旧值，第二个参数是新值。
- 直接调用 `data.replace(...)` 默认会返回一个新对象，不会直接修改原变量。
- 如果只写：

```python
data.replace('城八区', '海淀区')
print(data)
```

原 `data` 不会发生变化。

让替换生效的两种方式：

```python
# 方式一：接收返回的新对象
new_data = data.replace('城八区', '海淀区')
print(new_data)

# 方式二：使用 inplace=True 在原数据上修改
data.replace('城八区', '海淀区', inplace=True)
print(data)
```

注意：

- 如果不指定列，`replace()` 会在整张表中查找并替换。
- 视频示例中，整表替换会同时影响多个列，例如城市相关列中的“城八区”都会被替换。
- 对整表替换时，所有列中出现的旧值都会变化，因此实际使用时要确认替换范围。

## 3. 指定某一列进行替换

如果只想替换“城市2”这一列，而不是整张表，可以先选中该列，再调用 `replace()`。

```python
data['城市2'].replace('城八区', '海淀区', inplace=True)
print(data)
```

说明：

- 这种写法只对 `城市2` 列进行替换。
- 其他列中的相同旧值不会受影响。
- 记忆方式：`data[列名].replace(旧值, 新值, inplace=True)`。
- `inplace=True` 表示在原数据上修改。

也可以使用赋值方式，避免 `inplace` 带来的理解问题：

```python
data['城市2'] = data['城市2'].replace('城八区', '海淀区')
```

## 4. 多值替换：列表方式与字典方式

需求：将数值列中的 `a` 替换成 `20`，`b` 替换成 `30`。

### 4.1 列表方式

```python
data['数值'].replace(['a', 'b'], [20, 30], inplace=True)
print(data)
```

说明：

- 第一个列表是旧值列表。
- 第二个列表是新值列表。
- 两个列表按位置一一对应：`a -> 20`，`b -> 30`。
- 视频中表示这种方法可以使用，但个人不推荐作为首选，因为可读性不如字典，值多时容易写错。

### 4.2 字典方式（推荐）

```python
dic = {'a': 20, 'b': 30}
data['数值'].replace(dic, inplace=True)
print(data)
```

或直接写：

```python
data['数值'].replace({'a': 20, 'b': 30}, inplace=True)
print(data)
```

说明：

- 字典的 key 是原值。
- 字典的 value 是替换后的新值。
- 例如 `'a': 20` 表示把 `a` 替换成 `20`。
- 字典方式更清晰，推荐在多个不同值映射到不同新值时使用。
- 可以把字典单独定义在外部，再把变量名传入 `replace()`，代码更清楚。

### 4.3 多个旧值替换成同一个新值：推荐列表方式

需求：把 `a` 和 `b` 都替换成 `30`。

```python
data['数值'].replace(['a', 'b'], 30, inplace=True)
print(data)
```

说明：

- 当多个旧值都要替换成同一个新值时，列表方式更简洁。
- `['a', 'b']` 表示旧值集合，`30` 表示统一替换成的新值。

选择建议：

- 不同旧值映射到不同新值：推荐字典。
- 多个旧值映射到同一个新值：推荐列表。
- 选择不强制，关键是代码清晰、结果正确。

## 5. 替换列中部分字符串内容：`str.replace()`

前面的 `replace()` 更偏向于“整值替换”。如果要替换某一列中字符串的一部分，可以使用 `Series.str.replace()`。

需求：把 `城市2` 列中的“城八区”改成“市区”。视频中实际演示为把“城八”替换成“市”，从而使“城八区”变成“市区”。

```python
data['城市2'] = data['城市2'].str.replace('城八', '市')
print(data)
```

说明：

- `.str` 用于对字符串类型的 Series 进行字符串操作。
- `.str.replace('城八', '市')` 会把列中所有匹配到的“城八”子串替换成“市”。
- 例如“城八区”会变成“市区”。
- 这是按字符串部分内容替换，不是按整个单元格值替换。
- 如果忘记了 `.str.replace()` 的用法，可以回到 pandas 笔记中搜索 `str` 和 `replace` 复习。

与 `replace()` 的区别：

- `replace('城八区', '海淀区')`：通常按完整值匹配替换。
- `str.replace('城八', '市')`：在字符串内部查找子串并替换。

## 6. 正则表达式替换

如果替换规则复杂，例如把某一范围内的字母统一替换成 `88`，逐个写列表会非常麻烦。此时可以使用正则表达式。

视频口述示例包括：

- 把 `a` 到 `g` 替换成 `88`；
- 后面又提到大写字母 `A` 到 `Z` 的正则字符类。

核心写法如下：

```python
data.replace('[A-Z]', '88', regex=True, inplace=True)
print(data)
```

如果按视频前文口述的 `a` 到 `g` 范围，也可写为：

```python
data.replace('[A-G]', '88', regex=True, inplace=True)
print(data)
```

如果同时需要匹配大小写字母，可以写成：

```python
data.replace('[A-Za-z]', '88', regex=True, inplace=True)
```

说明：

- 正则表达式要写在引号内。
- 不需要额外写 `import re`，直接通过 pandas 的 `replace()` 配合 `regex=True` 使用。
- `[A-Z]` 是正则字符类，表示匹配任意一个大写字母。
- `[A-G]` 表示匹配 `A` 到 `G` 范围内的字符。
- `regex=True` 非常关键：它告诉 pandas 把第一个参数当作正则表达式处理。
- 如果不写 `regex=True`，pandas 会把 `[A-Z]` 当成普通字符串来查找，通常找不到目标内容。
- `inplace=True` 表示直接在原数据上修改。
- 如果传入的模式不是正则表达式，不要随意设置 `regex=True`。
- 视频提到可参考 pandas 笔记第 9.2 章，其中在讲解另一个函数时介绍过 `regex` 参数的设置。
- 复杂替换场景建议学习正则表达式。视频作者的正则表达式内容放在爬虫课程前三节中。

## 7. 常见错误与注意事项

- 直接调用 `replace()` 而不赋值、不设置 `inplace=True`，原数据不会改变。
- 使用 `inplace=True` 后，方法返回 `None`，不能再用变量接收返回结果并期待得到修改后的 DataFrame。
- 整表替换会替换所有列中的匹配值；如果只想改一列，要先选中列。
- 列表替换时，旧值列表和新值列表按位置对应，长度和顺序要写清楚。
- 多个旧值映射到不同新值时，字典方式更直观。
- 多个旧值映射到同一个新值时，列表方式更简洁。
- 字符串部分替换使用 `.str.replace()`。
- 正则替换使用 `replace(..., regex=True)`；不是正则规则时不要加 `regex=True`。

---

## 8. 本节总结

- pandas 通用替换使用 `replace()`。
- `inplace=True` 可原地修改，否则需要接收返回值。
- 指定列替换：`data['列名'].replace(...)`。
- 多值替换可用列表或字典；不同值映射到不同新值推荐字典，多值映射到同一新值推荐列表。
- 字符串部分内容替换使用 `Series.str.replace()`。
- 复杂模式替换使用正则表达式，并设置 `regex=True`。
- 正则表达式可显著简化范围匹配、模式匹配类替换需求。
