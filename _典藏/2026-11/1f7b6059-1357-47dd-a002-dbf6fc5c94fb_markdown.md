# Numpy 通用函数：快速的逐元素数组函数

## 1. 本节定位与学习建议

- 本节内容较短，主题是 **Numpy 通用函数**，即 **快速的逐元素数组函数**。
- 讲师强调：不需要把通用函数全部讲一遍，也不需要全部背下来。
- 课程中已经把相关函数列在资料中；实际做数据分析时，按需查找即可。
- 不同岗位对通用函数的使用频率不同：
  - 科研工作可能会较多使用这些函数；
  - 销售、人力等岗位通常用不到这么多函数；
  - 常见情况是只反复使用其中几个函数。
- 学习方式：需要哪个函数就查哪个函数，重点理解通用函数的用法模式。

## 2. 通用函数的概念

- 通用函数英文为 **ufunc**。
- 定义：通用函数是一种在 **Numpy 数组数据中进行逐元素操作** 的函数。
- 某些简单函数接受一个或多个标量数值，并产生一个或多个标量结果。
- 通用函数本质上是对这些简单函数进行 **向量化封装**，从而可以直接作用于整个数组。
- 按输入数组数量可分为：
  - **一元通用函数**：对一个数组逐元素运算；
  - **二元通用函数**：接受两个数组，并返回一个数组结果。

## 3. 一元通用函数

### 3.1 概念

- 一元通用函数是对单个数组中的每个元素执行相同操作。
- 讲师将一元通用函数与 Excel 函数作类比：使用方法类似，只是 Excel 中较少使用这些数学函数。
- 实际遇到不熟悉的函数时，可以再通过搜索或查文档了解具体用法。

### 3.2 讲师举出的例子

- 返回正平方根：
  \[
  \sqrt{x}
  \]
  对应 Numpy 函数为 `np.sqrt`。
- 返回以 \(e\) 为底的 \(x\) 次方：
  \[
  e^x
  \]
  对应 Numpy 函数为 `np.exp`。
- 讲师说明 `exp` 等内容与概率论有关，有兴趣可以进一步学习概率论。

### 3.3 演示思路

- 先构造一个数组，例如 0 到 9 之间的数，或使用 `range(8)` 产生 0 到 7 共 8 个数。
- 对该数组中的每个元素求正平方根。
- 再对该数组中的每个元素求 \(e^x\)。

可整理为如下演示形式：

- `a = np.arange(8)`：生成 `[0, 1, 2, 3, 4, 5, 6, 7]`，共 8 个数。
- `np.sqrt(a)`：对 `a` 中每个元素求平方根。
- `np.exp(a)`：对 `a` 中每个元素计算 \(e^{a_i}\)。

## 4. 二元通用函数

### 4.1 概念

- 二元通用函数接受两个数组，并返回一个数组结果。
- 讲师在二元通用函数中提到了 `add`、`maximum` 等函数。
- 二元通用函数的关键是：两个数组按位置逐元素进行计算或比较。

### 4.2 `np.maximum`：逐元素取较大值

讲师演示了两个长度相同的随机整数数组：

- 生成两个随机数组，例如范围在 0 到 7 之间的 8 个数：
  - `x = np.random.randint(0, 8, 8)`
  - `y = np.random.randint(0, 8, 8)`
- 使用 `np.maximum(x, y)` 进行逐元素比较。
- 工作方式：
  - `x` 的第 1 个元素与 `y` 的第 1 个元素比较，谁大取谁；
  - `x` 的第 2 个元素与 `y` 的第 2 个元素比较，谁大取谁；
  - 依此类推，生成一个新的数组。
- 数学表达可写为：
  \[
  z_i = \max(x_i, y_i)
  \]
- 讲师强调：`maximum` 是“对位比大小，谁大把谁取出来”，并返回新数组。

### 4.3 `np.minimum`：逐元素取较小值

- 讲师接着验证与 `maximum` 相反的操作，即逐元素取较小值。
- 对应函数为 `np.minimum`。
- 工作方式：
  - 第 1 个元素与第 1 个元素比较，谁小取谁；
  - 第 2 个元素与第 2 个元素比较，谁小取谁；
  - 依此类推，返回逐元素最小值组成的新数组。
- 数学表达可写为：
  \[
  z_i = \min(x_i, y_i)
  \]
- 学习时可“举一反三”：理解了 `maximum`，就能理解 `minimum` 的用法。

### 4.4 `np.add`：逐元素相加

- 讲师在二元通用函数列表中提到了 `add`。
- `add` 属于二元通用函数，表示按位置逐元素相加。
- 本节主要展开演示的是 `maximum` 和 `minimum`，没有对 `add` 做完整演示。

## 5. 一元与二元通用函数对比

| 类型 | 输入 | 输出 | 本节例子 | 工作方式 |
|---|---|---|---|---|
| 一元通用函数 | 一个数组 | 一个数组 | `np.sqrt`、`np.exp` | 对每个元素执行同一个函数 |
| 二元通用函数 | 两个数组 | 一个数组 | `np.maximum`、`np.minimum`、`np.add` | 两个数组按对应位置逐元素计算 |

## 6. 关键结论与注意事项

- 通用函数是 **逐元素操作**，不是只对一个标量操作。
- 通用函数可以看作对普通标量函数的 **向量化封装**。
- 二元通用函数返回的是数组结果，讲师在演示中明确说“生成新的数组”。
- `np.maximum` 与 `np.minimum` 是一对相反操作：
  - `maximum`：逐元素取较大值；
  - `minimum`：逐元素取较小值。
- 通用函数数量很多，不需要全部记忆。
- 实际使用时根据任务需要选择函数；资料中通常有中文解释，且大多数函数用法一致。
- 对不常用函数，用到时再查即可；重点掌握“逐元素数组函数”的概念和调用方式。
