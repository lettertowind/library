## 本节主题

本节讲解 Pandas 中的算术运算与数据对齐问题，核心围绕两类会导致计算结果异常的情况展开：

- 空值 `NaN` 参与算术运算：结果仍为空值，需要填充后计算。
- 分母为 0 产生无穷大 `inf` / `-inf`：`fillna()` 无法直接处理，需要先把无穷大转成空值，再填充或计算。

本节还介绍了 Pandas 的灵活算术方法，如 `add()`、`sub()`、`div()`、`floordiv()`、`mul()`、`pow()` 及其反转方法 `radd()`、`rsub()`、`rdiv()` 等。

## 1. 算术运算的范围与核心问题

### 1.1 算术运算包括什么

视频中列出的 Pandas 算术运算包括：

- 加法
- 减法
- 乘法
- 除法
- 整除
- 幂次方
- 其他扩展算术方法

最常用的是加、减、乘、除。

### 1.2 Pandas 算术运算中的两个核心问题

讲师强调：在任何算术运算中都可能牵扯两个问题，但在 Pandas 中这两个问题更明显。

#### 问题一：分母为 0

NumPy 笔记 `1.3.2` 的“数组计算”部分已经讲过：

- $\frac{0}{0} \rightarrow \text{NaN}$
- $\frac{1}{0} \rightarrow +\infty$，即 `inf`
- $\frac{-1}{0} \rightarrow -\infty$，即 `-inf`

其中：

- `NaN` 表示“不是一个数字”，可以暂时理解为空值。
- `inf` 表示正无穷大。
- `-inf` 表示负无穷大。

#### 问题二：空值与数字进行计算

空值与任何数字进行算术运算，结果仍为空值。

例如：

- $\text{NaN} + 1 = \text{NaN}$
- $1 + \text{NaN} = \text{NaN}$

因此，如果数据中存在空值，直接相加、相减、相除等，结果中会继续出现空值。

## 3. 解决方法一：使用 `fillna()` 将空值替换为 0

### 3.1 思路

如果数据中的问题只是空值，可以先把空值替换成 0，再进行算术运算。

视频中使用的函数是：

- `fillna(0)`

即把空值填充为 0。

### 3.2 对参与运算的列分别填充

示例代码：

- `data["一点"] = data["一点"].fillna(0)`
- `data["二点"] = data["二点"].fillna(0)`

然后再进行运算：

- `result = data["一点"] + data["二点"]`
- `print(result)`

视频中填充后所有位置都可以正常计算，屏幕演示结果包括 `8`、`11` 等。

### 3.3 参考笔记

讲师说明该方法可以回看 Pandas 笔记：

- Pandas 笔记第 `10.3.3`

其中讲解过空值替换相关操作。视频提醒：有些同学上课听完可能忘记，可以课后回看对应笔记。

### 3.4 适用场景

- 数据中的异常只是 `NaN` 空值。
- 希望先把空值统一替换为 0，再进行普通运算符计算。
- 适合简单、直接的数据清洗与计算。

## 4. 解决方法二：使用灵活算术法

### 4.1 什么是灵活算术法

Pandas 提供了一组“灵活算术方法”，可以直接在运算方法中指定缺失值的填充值。

视频中重点演示了加法：

- `data["一点"].add(data["二点"], fill_value=0)`

其中：

- `add()` 表示加法方法。
- `fill_value=0` 表示运算时把空值填充为 0。
- 参数名是 `fill_value`，不是 `value`。

讲师在演示中曾出现口误或写错，随后纠正：正确参数名应为 `fill_value`。

### 4.2 灵活算术方法列表

Pandas 中常见的灵活算术方法包括：

- `add()`：加法
- `sub()`：减法
- `div()`：除法
- `floordiv()`：整除
- `mul()`：乘法
- `pow()`：幂次方

这些方法都可以配合 `fill_value` 参数使用，用于在运算时填充缺失值。

### 4.3 整除的含义

讲师解释“整除”：

- 例如 $5 \div 2$ 本来应得 `2.5`。
- 整除只取整数部分，得到 `2`。

对应 Pandas 方法可记为 `floordiv()`。

### 4.4 反转算术方法

在上述方法前加 `r`，表示反转运算方向。

常见反转方法包括：

- `radd()`：反转加法
- `rsub()`：反转减法
- `rdiv()`：反转除法
- `rfloordiv()`：反转整除
- `rmul()`：反转乘法
- `rpow()`：反转幂次方

讲师解释：

- 普通方法默认是“左边的数据运算右边的数据”。
- 加 `r` 后变成“右边的数据运算左边的数据”。

例如：

- 普通除法：$5 \div 3$
- 反转除法：$3 \div 5$

两者结果不同。

加法、乘法由于满足交换律，反转与否在数值结果上通常没有明显差异；但除法、幂次方等非交换运算，反转后结果会不同。

### 4.5 使用建议

- 需要普通相加时，用 `add()`。
- 需要减、乘、除、整除、幂次方时，把 `add()` 替换为对应方法即可。
- 不要忘记写入 `fill_value=0`。
- 视频强调：灵活算术法“灵活”的地方就在于可以在运算时直接处理空值，不必单独写多行 `fillna()`。

## 5. 无穷大 `inf` 的处理

### 5.1 问题复现

视频中继续使用除法演示：

- `data["一点"].div(data["二点"])`

当分母为 0 时，会出现：

- `inf`：正无穷大
- `-inf`：负无穷大
- `NaN`：$0 \div 0$ 的结果

关键问题：

- `fillna()` 只能替换空值。
- `inf` 不是空值，所以 `fillna()` 无法直接替换 `inf`。
- 必须先想办法把 `inf` 转成空值，再填充或计算。

### 5.2 无穷大示例数据

视频中准备了一张“无穷大表”，用于演示除法中的无穷大问题。示例数据一列大致为：

- `1`
- `-1`
- `0`
- `2`

另一列参与除法，大致为：

- `0`
- `0`
- `0`
- `2`

相除时对应结果为：

- $1 \div 0 \rightarrow +\infty$，即 `inf`
- $-1 \div 0 \rightarrow -\infty$，即 `-inf`
- $0 \div 0 \rightarrow \text{NaN}$
- $2 \div 2 \rightarrow 1$，正常结果

视频中先打印这张表，再执行除法，结果中出现 `inf`、`-inf`、空值以及正常数值。

### 5.3 解决无穷大的设置

讲师提到自己在 2019 年 7 月 15 日从 CSDN 上找到一篇文章，文章给出一个处理方法：把 Pandas 中的无穷大值当作空值处理。

使用的设置是：

- `pd.options.mode.use_inf_as_na = True`

讲师解释其作用：

- 把所有无穷大值转成空值。
- 设置后，`inf`、`-inf` 会被视为 `NaN` / 空值。
- 然后就可以继续使用 `fillna(0)` 或灵活算术法中的 `fill_value=0` 进行计算。

视频建议：

- 不需要特别深入理解这句话的底层实现。
- 遇到无穷大问题时，把这句话复制到导入库的代码下方即可。
- 它是全局设置，放在库调用下方后对整个后续处理生效。

### 5.4 设置后再次计算

设置：

- `pd.options.mode.use_inf_as_na = True`

然后执行除法：

- `data["一点"].div(data["二点"])`

此时原本的 `inf`、`-inf` 会先被转为空值。之后可以再用：

- `.fillna(0)`

把空值替换为 0。

视频演示的链式写法可表示为：

- `result = data["一点"].div(data["二点"]).fillna(0)`
- `print(result)`

如果使用灵活算术法，也可以结合 `fill_value=0` 处理缺失值。

### 5.5 注意点

- `pd.options.mode.use_inf_as_na = True` 是视频录制时使用的旧版 Pandas 写法。
- 新版 Pandas 中该选项可能已经发生变化或被弃用，实际使用时需要根据 Pandas 版本确认。
- 本笔记按视频讲解记录其用途：将 `inf` / `-inf` 视作空值，从而让 `fillna()` 能够继续处理。

## 6. 讲师强调的结论与易错点

### 6.1 空值与无穷大要区分

- `NaN`：空值，可用 `fillna(0)` 处理。
- `inf`：正无穷大，`fillna()` 默认无法直接处理。
- `-inf`：负无穷大，同样不能直接用 `fillna()` 处理。
- 处理 `inf` 的思路：先用 `pd.options.mode.use_inf_as_na = True` 转成空值，再填充。

### 6.2 `fill_value` 参数不要写错

- 正确参数名：`fill_value=0`
- 视频中曾出现口误/写错为 `value`，随后纠正。
- 使用 `add()`、`div()` 等灵活算术方法时，要写 `fill_value=0`。

### 6.3 普通运算符与灵活算术方法的区别

- 普通运算符：`data["一点"] + data["二点"]`
  - 遇到空值继续产生空值。
  - 不能直接指定填充值。
- 灵活算术方法：`data["一点"].add(data["二点"], fill_value=0)`
  - 可以在运算时填充缺失值。
  - 代码更简洁。

### 6.4 反转方法的使用场景

- 加法、乘法满足交换律，反转通常不影响数值结果。
- 除法、幂次方不满足交换律，反转后结果不同。
- 使用 `rdiv()`、`rpow()` 等时要明确“谁除谁”“谁对谁做幂”。

### 6.5 数据对齐的含义

本节标题包含“数据对齐”。Pandas 的算术运算会先按索引/列对齐，再逐元素计算；当对齐后存在缺失位置时，普通运算会产生 `NaN`，灵活算术法可以通过 `fill_value` 填充缺失位置。视频案例主要用两列数据中的空值和无穷大来说明这一计算与填充过程。
