# Pandas 离散化与分箱：`cut` 与 `qcut`

## 1. 离散化与分箱的概念

- **离散化 / 分箱**：把一串连续的数字切成若干段，并判断每个数据落在哪一段。
- 业务中经常出现类似需求：
  - 按分数划分等级：及格、良、中、优。
  - 按年份划分：1950 年以前、1950 年以后。
  - 按年龄段统计用户：0～15 岁、16～30 岁、30～45 岁、45 岁以上。
  - 按参加工作时间划分合同类型等。
- 在 Excel、Power BI 中，类似需求常用 `switch` 函数实现；在 Pandas 中可以用 `cut`、`qcut` 等函数快速完成。
- 分箱在机器学习中也很常见，当前阶段先掌握 Pandas 中的基础操作。
- 大数据场景示例：中国移动用户量可能达到几亿条，若统计不同年龄段人数，用 SQL 也能做，但代码较多；用 Pandas 两三行即可完成。

## 2. 分箱操作的重要前提

- **分箱一定是对一维数据操作**，不要直接对整张表操作。
- 需要先从 `DataFrame` 中提取一行或一列，得到 `Series`，再对该 `Series` 分箱。
- 常见提取方式：`df['某列']`，得到的就是一维 `Series`。
- 如果数据中是生日而不是年份，可以使用时间日期模块，例如通过 `dt.year` 提取年份，得到一维 `Series` 后再分箱。

## 3. 两个核心函数：`cut` 与 `qcut`

### 3.1 `pd.cut`

- 作用：按照**数据的值**或**指定的分界点**，对连续数据进行分箱。
- 示例：按 1950 年以前、1950 年以后划分，就是指定分界点进行分箱。
- 常用参数：
  - 第一个参数 `x`：类数组对象，必须是一维数据。
  - 第二个参数 `bins`：分箱依据，可以是整数序列、尺度、间隔索引等；视频示例中传入的是分界点列表。
  - `labels`：用于给分箱结果设置标签，长度应与箱数一致。
  - `labels=False`：不返回箱子名称，只返回整数指标，也就是每个数据对应的**箱号**。
- 视频中口述的 `levels` 实际应为 `labels`，笔记中按正确参数名 `labels` 记录。
- `cut` 默认区间通常是右闭的，例如分界点为 `[1900, 1950, 2000]` 时，可形成类似 $(1900,1950]$、$(1950,2000]$ 的区间。实际业务中应根据需求设置边界。

### 3.2 `pd.qcut`

- 作用：按照**数据本身的数量 / 分位数**对连续数据进行分组。
- `qcut` 不需要手动指定分界点，只需要指定要分成几个箱子。
- 常用参数：
  - 第一个参数 `x`：要分箱的一维数据。
  - `q`：指定分箱数量，可以是整数，也可以是由分位数组成的数组。
- 视频中用 `q=2` 表示把数据分成两个箱子。
- 结果中每个箱子的数据数量应尽量相同。
- 术语说明：视频中把“每个箱子里的数量相同”称为“等宽”，更常见的术语是**等频分箱**。严格来说，“等宽”通常指每个区间的宽度相同；`qcut` 更准确的理解是按分位数进行等频分箱。

## 4. `pd.cut` 实操：按年份分界点分箱

### 4.1 示例数据与分界点

- 示例数据为年份数据，视频中可见的数据包括 `1992`、`1983`、`1922` 等，共约 5 个数据。
- 目标：按照 1950 年前后划分。
- 视频中设置的分界点示例为：`[1900, 1950, 2000]`。
  - 1900 是 Excel 支持的最小年份，视频用它作为示例下界。
  - 1950 是分界点。
  - 2000 作为示例上界，覆盖示例中的年份数据。
- 这样会形成两个箱子：
  - 第 0 号箱：约 $(1900,1950]$。
  - 第 1 号箱：约 $(1950,2000]$。
- 实际工作中不能机械地使用 1900、1950、2000，而应按照业务逻辑确定分界点。

### 4.2 分箱代码思路

- 先提取一维年份数据：`x = df['年份']`。
- 指定箱子分界点：`bins = [1900, 1950, 2000]`。
- 调用 `pd.cut`：`结果 = pd.cut(x, bins=bins)`。
- 输出结果后，可以看到每个数据被分到哪个区间。
- 示例中：
  - `1992` 在 1950～2000 的箱子里，即 1 号箱。
  - `1983` 在 1950～2000 的箱子里，即 1 号箱。
  - `1922` 在 1900～1950 的箱子里，即 0 号箱。
  - 后续数据同理：有的落在 0 号箱，有的落在 1 号箱。

### 4.3 统计每个箱子里有多少数据

- 分箱结果可以使用值计数函数统计：`pd.value_counts(结果)` 或 `结果.value_counts()`。
- 视频示例中统计结果为：
  - 1950～2000 这个箱子里有 3 个数据。
  - 1900～1950 这个箱子里有 2 个数据。
- 这一步统计的是“每个箱子中有多少条数据”，不是原始数值的计数。

### 4.4 使用 `labels=False` 返回箱号

- 如果希望每个数据返回对应的箱号，而不是返回区间名称，可以在 `pd.cut` 中加入参数 `labels=False`。
- 示例：`结果 = pd.cut(x, bins=bins, labels=False)`。
- 返回结果就是每个数据对应的整数箱号。
- 箱号从 0 开始：
  - 第 0 号箱对应 $(1900,1950]$。
  - 第 1 号箱对应 $(1950,2000]$。
- 示例输出中：
  - 第一个数据 `1992` 在 1 号箱。
  - 第二个数据 `1983` 在 1 号箱。
  - 第三个数据 `1922` 在 0 号箱。
  - 第四个数据在 0 号箱。
  - 第五个数据在 1 号箱。
- 对箱号结果再做 `value_counts`，同样可以统计：
  - 1 号箱有 3 个数据。
  - 0 号箱有 2 个数据。
- 区别：
  - 不设置 `labels=False`：返回具体箱子区间或箱子名称。
  - 设置 `labels=False`：只返回整数箱号，适合后续计算或建模。

### 4.5 给箱子重命名

- 如果不想显示 `1900～1950`、`1950～2000`，而想显示“50年代前”“50年代后”，可以先定义箱子名称列表。
- 示例箱子名称：`箱子名称 = ['50年代前', '50年代后']`。
- 在 `pd.cut` 中通过 `labels=箱子名称` 传入，使结果直接显示业务名称。
- 视频建议：箱子名称最好单独定义成列表，再传给 `labels`，因为实际分析通常不会只有两个箱子；如果只有两个箱子，用简单条件判断也可以，但多箱场景分开写更清晰。
- 重命名后再次使用 `value_counts` 统计，输出可读性更强，例如：
  - `50年代后`：3 个。
  - `50年代前`：2 个。
- 这一步本质上是用 `labels` 参数替换箱子的显示名称。

## 5. `pd.qcut` 实操：等频分箱

### 5.1 操作目标

- 对年份数据不指定具体分界点，而是指定“分成几个箱子”。
- 例如分成两个箱子，希望每个箱子里的数据数量尽量相同。
- 类比：10 个苹果两个人分，每人 5 个，谁也不打架；如果一个人 6 个、一个人 4 个，就不均衡。这里强调每个箱子数据量尽量一致。

### 5.2 代码思路

- 准备一维数据：`x = 年份数据`。
- 调用 `pd.qcut`：`结果 = pd.qcut(x, q=2)`。
- `q=2` 表示分成两个箱子。
- 输出结果后可以看到每个数据被分到哪个分位数区间。
- 使用 `pd.value_counts(结果)` 或 `结果.value_counts()` 查看每个箱子的数量。
- 视频示例中，`qcut` 分箱后每个箱子的数量相同，可以通过计数结果验证。

### 5.3 注意事项

- `qcut` 不需要手动提供 `bins` 分界点，只需要提供 `q` 分箱数量。
- 如果数据量不能被箱子数整除，每个箱子的数量可能不完全一致。
- 使用前应先知道数据总量，例如先计算有多少行，再决定分成几个箱子。
- 分箱数由分析目标决定，例如把用户年龄分成 2 箱、5 箱等。
- 数学上应尽量让数据量能够被分箱数整除，便于得到数量一致的箱子；如果不能整除，也应理解结果可能有轻微差异。

## 6. 关键结论与建议

- **离散化 / 分箱**就是把连续数值切成若干段，并给每个数据标记所属区间或箱号。
- `pd.cut`：按指定分界点/数值区间分箱，适合有明确业务边界的场景。
- `pd.qcut`：按分位数/数据数量分箱，适合希望每个箱子数据量尽量一致的场景。
- 分箱前必须把数据整理成一维 `Series`，不要对整张 `DataFrame` 直接分箱。
- 使用 `labels=False` 可以返回整数箱号，箱号从 0 开始。
- 使用 `labels=箱子名称列表` 可以给箱子设置业务名称。
- 使用 `value_counts()` 可以统计每个箱子的数据量。
- 日期字段可以通过 `dt.year` 提取年份，再对年份进行分箱。
- Excel / Power BI 中的 `switch` 评级逻辑，在 Pandas 中可以用 `cut` 简洁实现。
- 视频中的“等宽”表述应理解为“每个箱子数量相同”的等频分箱；严格术语中，`qcut` 更常被称为等频分箱或基于分位数的分箱。
