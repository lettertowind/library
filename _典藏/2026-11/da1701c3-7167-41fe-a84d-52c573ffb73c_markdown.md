## 视频主题

本视频讲解如何在 **Pandas** 中实现类似 Excel 的 **VLOOKUP** 功能，并进一步介绍如何把匹配得到的列插入到指定位置，以及如何将结果写回原 Excel 文件。

## 1. 数据场景与工作表说明

视频使用一个 Excel 文件进行演示，文件中包含两个工作表：

- **花名册**
  - 字段包括：学号、姓名、班级等。
- **成绩单**
  - 字段包括：学号、语文、数学、英语、总分等。

目标：

- 以 **花名册** 为主表。
- 根据 **学号** 匹配 **成绩单** 中的 **总分**。
- 实现类似 Excel 中 `VLOOKUP` 的效果。

因为两个数据位于不同工作表中，所以需要分别读取两次，并通过 `sheet_name` 指定工作表名称。

示例代码：

```python
import pandas as pd

数据一 = pd.read_excel('vlookup.xlsx', sheet_name='花名册')
数据二 = pd.read_excel('vlookup.xlsx', sheet_name='成绩单')

print(数据一)
print(数据二)
```

说明：

- `数据一` 对应花名册。
- `数据二` 对应成绩单。
- 打印时可能出现显示串行或错列，这只是显示层面的问题，不影响实际数据内容。

## 2. 使用 merge 实现 VLOOKUP

核心思路：

- 以 `数据一` 为主表。
- 连接 `数据二`。
- 但不需要把 `数据二` 的所有列都带过来，只取 **学号** 和 **总分** 两列。
- 使用左外连接 `left`。
- 按 **学号** 进行连接。

示例代码：

```python
结果 = pd.merge(
    数据一,
    数据二.loc[:, ['学号', '总分']],
    how='left',
    on='学号'
)

print(结果)
```

关键点：

- `数据二.loc[:, ['学号', '总分']]`
  - 冒号 `:` 表示行全取。
  - 后面的列表表示只取 `学号` 和 `总分` 两列。
- `how='left'` 表示左外连接。
  - 保留主表 `数据一` 的所有记录。
  - 从 `数据二` 中匹配对应学号的 `总分`。
- `on='学号'` 表示按 `学号` 连接。

这一步相当于：

> 把花名册全部拿出来，同时只从成绩单中拿“学号”和“总分”两列，按学号匹配过去。

执行后，`总分` 默认会出现在结果表的最后面。

## 3. 将指定列插入到任意位置

匹配完成后，`总分` 默认在最后。视频提出一个常见需求：

- 想把 `总分` 放到指定位置，例如放到 `学号` 前面。
- 也可以插到第二列、第三列、第四列等位置。

视频采用的方法是：

- 先把需要移动的列取出来，保存到变量中。
- 再删除原列。
- 最后通过 `insert` 把该列插入到指定位置。

视频中用“鸡蛋筐”作比喻：

- 先把鸡蛋克隆或复制出来。
- 删除原来的鸡蛋。
- 再把复制出来的鸡蛋放到想要的位置。

示例代码：

```python
结果总分 = 结果['总分']

结果 = 结果.drop('总分', axis=1)

结果.insert(0, '总分', 结果总分)

print(结果)
```

关键点：

- `结果总分 = 结果['总分']`
  - 先保存 `总分` 列的数据。
- `结果.drop('总分', axis=1)`
  - 删除原来的 `总分` 列。
  - `axis=1` 表示按列操作。
  - 视频提到，如果不懂 `drop`，可以参考笔记 `10.1`。
- `结果.insert(0, '总分', 结果总分)`
  - 在第 `0` 列位置插入 `总分`。
  - `loc=0` 表示插入到最前面。
  - 如果想插入到其他位置，只需要修改 `loc` 参数。
- `insert` 是原地操作，通常不需要写成 `结果 = 结果.insert(...)`。视频口述中出现了“结果等于结果.insert”，实际使用时建议直接调用 `结果.insert(...)`。

如果想插入到其他列位置，例如第二列，可以调整 `loc`：

```python
结果.insert(1, '总分', 结果总分)
```

视频还提到：

- 如果不知道 `insert` 是什么，可以查看 Python 基础篇 PPT 第 30 页“指定位置新增数据”。

## 4. 将结果写回原 Excel 文件

视频说明：

- 可以使用 `to_excel` 保存成一个新的文件。
- 但实际做 VLOOKUP 时，常常希望直接写回原表。
- 写回原表可以使用 `pd.ExcelWriter`。

示例代码：

```python
writer = pd.ExcelWriter('vlookup.xlsx')

结果.to_excel(writer, index=False)

writer.save()
writer.close()
```

关键点：

- `pd.ExcelWriter('vlookup.xlsx')`
  - 创建 Excel 写入器。
  - 视频特别强调拼写是 `writer`，不是 `waiter`。
- `结果.to_excel(writer, index=False)`
  - 将结果写入 Excel。
  - `index=False` 表示不写入行索引。
- 最后必须调用：
  - `writer.save()`
  - `writer.close()`

视频提到，写回原表的方法可以参考笔记 `19.3`。

## 5. 关键函数与参数总结

- `pd.read_excel(path, sheet_name=...)`
  - 读取 Excel 中指定的工作表。
- `DataFrame.loc[:, ['列1', '列2']]`
  - 选择指定列，行使用 `:` 表示全部。
- `pd.merge(left, right, how='left', on='学号')`
  - 按学号进行左连接，实现 VLOOKUP。
- `DataFrame.drop('列名', axis=1)`
  - 删除指定列。
- `DataFrame.insert(loc, column, value)`
  - 在指定位置插入列。
- `pd.ExcelWriter(path)`
  - 创建 Excel 写入器。
- `DataFrame.to_excel(writer, index=False)`
  - 将数据写入 Excel，且不写行索引。
- `writer.save()`、`writer.close()`
  - 保存并关闭 Excel 写入器。

## 6. 注意事项与结论

- 在 Pandas 中实现 Excel 的 VLOOKUP，可以通过 `merge` 完成。
- 使用 `how='left'` 可以保留主表全部记录。
- 只取需要的列可以减少无关字段，避免把成绩单中的所有列都带入结果。
- 如果要把某一列移动到指定位置，可以采用“取出列 → 删除原列 → 插入指定位置”的方法。
- `insert` 的 `loc` 参数可以控制插入位置，从而把列放到任意位置。
- 如果希望直接修改原 Excel 文件，应使用 `pd.ExcelWriter`，并记得执行 `save()` 和 `close()`。
- 打印时出现列错位或串行，不代表数据本身有问题。
