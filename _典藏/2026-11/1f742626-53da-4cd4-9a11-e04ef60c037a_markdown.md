## 2. 数据的转置

### 2.1 转置场景

示例数据中包含字段：

- 姓名
- 性别
- 语文
- 数学
- 英语

目标是：把原来的行变成列，把原来的列变成行。

### 2.2 推荐方法：借助 NumPy 的矩阵转置

视频中推荐使用 NumPy 中内置的矩阵转置方法，即通过 `.values.T` 对 DataFrame 的值进行转置，再用 `pd.DataFrame` 重新构造表。

核心代码思路如下：

```python
import pandas as pd

数据 = pd.read_excel("文件路径.xlsx")

数据二 = pd.DataFrame(
    数据.values.T,
    index=数据.columns,
    columns=数据.index
)

print(数据二)
```

关键点：

- `数据.values` 取出 DataFrame 的数值部分。
- `.T` 表示矩阵转置。
- `pd.DataFrame(...)` 将转置后的结果重新封装为 DataFrame。
- 转置后需要重新设置行索引和列索引：
  - 新表的 `index` 应等于原表的 `columns`。
  - 新表的 `columns` 应等于原表的 `index`。

也就是说：

```python
index=数据.columns
columns=数据.index
```

这样转置后：

- 原来的行标签变成列标签。
- 原来的列标签变成行标签。
- 原表与转置表在结构上完全对应。

视频中提到，网上转置方法很多，但推荐记住这一种即可。方法本身不唯一，不必强求统一。

## 3. 环比计算

### 3.1 环比的概念

环比通常表示与上一个相邻周期进行比较，例如：

- 本月与上月比较。
- 本周与上周比较。

计算环比时，需要先构造“上期金额”列，再用本期金额与上期金额进行比较。

相关公式：

\[
\text{环比增长额} = \text{本期金额} - \text{上期金额}
\]

\[
\text{环比增长率} = \frac{\text{本期金额} - \text{上期金额}}{\text{上期金额}}
\]

### 3.2 单序列数据计算环比

示例数据包含：

- 日期：1 月到 12 月。
- 销售金额。

计算 2 月环比时，应与 1 月比较；计算 3 月环比时，应与 2 月比较。

视频中的思路是：把销售金额列向下移动一格，使每个月的数据对应到上一个月。

使用 `shift()` 实现：

```python
数据["上期金额"] = 数据["销售金额"].shift(1)
```

`shift(1)` 表示向下移动一位：

- 第 1 行没有上期数据，因此为空。
- 第 2 行对应第 1 行数据。
- 第 3 行对应第 2 行数据。

计算环比增长额：

```python
数据["环比增长额"] = 数据["销售金额"] - 数据["上期金额"]
```

计算环比增长率：

```python
数据["环比增长率"] = 数据["环比增长额"] / 数据["上期金额"]
```

如果需要转换数据类型，可以使用：

```python
数据["上期金额"] = 数据["上期金额"].astype(float)
```

视频提醒：实际工作中的原始数据往往不是已经整理好的月度数据，需要先完成预处理。

### 3.3 环比前的数据整理

如果原始数据包含具体日期，而需要按月计算环比，应先：

- 从日期中提取月份。
- 按月份进行分组聚合。
- 对月份排序。
- 再计算 `shift()` 和环比。

提取月份：

```python
数据["月份"] = 数据["日期"].dt.month
```

按月聚合并排序：

```python
月数据 = (
    数据.groupby("月份", as_index=False)["销售金额"]
      .sum()
      .sort_values("月份")
)
```

计算环比：

```python
月数据["上期金额"] = 月数据["销售金额"].shift(1)
月数据["环比增长额"] = 月数据["销售金额"] - 月数据["上期金额"]
月数据["环比增长率"] = 月数据["环比增长额"] / 月数据["上期金额"]
```

视频中强调：计算环比之前，一定要先把数据整理成“每个月一行”的结构。整理过程中会用到之前学过的：

- 日期提取月份：`dt.month`
- `groupby` 分组聚合
- 排序
- `shift`

### 3.4 多城市分组计算环比

示例数据包含北京、上海两个城市，每个城市都有 1 月到 12 月的数据。此时不能直接把整列 `shift()`，否则可能把上海 1 月与北京 12 月错误对应。

正确思路：

- 按城市分组。
- 在每个城市内部按月份排序。
- 对每个城市组分别计算环比。
- 使用 `groupby(...).apply(...)` 对每个分组调用自定义函数。

自定义函数示例：

```python
def 计算环比(新数据):
    新数据 = 新数据.copy()
    新数据["环比增长额"] = 新数据["金额"] - 新数据["金额"].shift(1)
    新数据["环比增长率"] = 新数据["环比增长额"] / 新数据["金额"].shift(1)
    return 新数据
```

按城市排序并分组应用：

```python
数据二 = (
    数据.sort_values(["城市", "月份"])
      .groupby("城市", group_keys=False)
      .apply(计算环比)
)
```

计算后：

- 每个城市的 1 月没有环比，因为没有上一个月。
- 2 月环比对应 1 月。
- 3 月环比对应 2 月。
- 北京和上海分别独立计算，不会相互串行。

视频中特别说明：先排序、再分组、再调用函数，是为了保证每个城市内部月份顺序正确。计算环比增长额后，如果还需要环比增长率，再除以对应的上期金额即可。

## 4. 同比计算

### 4.1 同比的概念

同比通常表示与去年同一时期进行比较，例如：

- 2019 年金额与 2018 年金额比较。
- 本年同期与上年同期比较。

相关公式：

\[
\text{同比增长额} = \text{本年同期金额} - \text{上年同期金额}
\]

\[
\text{同比增长率} = \frac{\text{本年同期金额} - \text{上年同期金额}}{\text{上年同期金额}}
\]

### 4.2 Excel 中的同比计算思路

视频先用 Excel 数据透视表演示同比思路：

- 插入数据透视表。
- 将“店号”放到行上。
- 将“日期”放到列上。
- 日期只保留“年”，删除季度、日期等层级。
- 将“金额”放到值区域，并进行求和。
- 得到每家店铺 2018 年和 2019 年的金额列。
- 再用 2019 年金额减去 2018 年金额，得到同比增长额。
- 用同比增长额除以 2018 年金额，得到同比增长率。

核心思路是：先按“店号”和“年份”构造交叉表，再在列之间做加减乘除。

### 4.3 用 Pandas 的 `pivot_table` 实现

首先从日期中提取年份：

```python
年 = 数据["日期"].dt.year
```

然后使用 `pd.pivot_table()` 构造数据透视表：

```python
数据二 = pd.pivot_table(
    data=数据,
    index="店号",
    values="金额",
    columns=年,
    aggfunc="sum"
)
```

关键参数说明：

- `index="店号"`：店号作为行索引。
- `values="金额"`：对金额进行透视。
- `columns=年`：年份作为列。
- `aggfunc="sum"`：指定聚合方式为求和。

视频特别提醒：

- `pivot_table` 默认聚合方式可能是平均值，因此必须显式指定 `aggfunc="sum"`。
- 如果 `年` 是一个变量，`columns=年` 不要加引号。
- 如果写成 `columns="年"`，则表示字符串 `"年"`，不是前面定义好的年份变量，容易导致结果错误或报错。

构造完成后，会得到类似下面的结构：

- 行：店号。
- 列：2018 年金额、2019 年金额。
- 值：对应年份的销售金额合计。

### 4.4 计算同比指标

得到 2018 年和 2019 年金额列后，可以直接计算同比增长额和同比增长率。

```python
数据二["同比增长额"] = 数据二[2019] - 数据二[2018]

数据二["同比增长率"] = (
    数据二[2019] - 数据二[2018]
) / 数据二[2018]
```

如果只需要同比金额，不计算比率，则不用除以 2018 年金额。

视频中建议写公式时先把括号写好，避免因为操作较快而漏掉括号或写错列名。

## 5. 读取 Excel 与工作表注意事项

视频中提到，使用 `pd.read_excel()` 读取 Excel 时需要注意参数。

`read_excel()` 的第一个参数是文件路径，第二个参数通常是工作表名称。

例如：

```python
数据 = pd.read_excel("文件路径.xlsx", sheet_name="1")
```

也可以使用位置参数：

```python
数据 = pd.read_excel("文件路径.xlsx", "1")
```

如果写成关键字参数，就是：

```python
数据 = pd.read_excel("文件路径.xlsx", sheet_name="2")
```

视频强调：

- 如果一个 Excel 文件中有多个工作表，需要明确指定对哪个工作表进行操作。
- 如果不指定工作表，可能会导致读取结果不符合预期或报错。
- 工作表名称如果直接作为第二个位置参数传入，可以省略 `sheet_name` 关键字。
- 如果使用了关键字参数，就按关键字参数的形式书写。

## 6. 本节重点与总结

### 6.1 转置

- 推荐使用：`pd.DataFrame(数据.values.T, index=数据.columns, columns=数据.index)`。
- 核心是使用 `.values.T` 进行矩阵转置。
- 转置后要重新设置行索引和列索引。

### 6.2 环比

- 环比是与上一个相邻周期比较。
- 使用 `shift(1)` 构造上期金额。
- 环比增长额：

\[
\text{环比增长额} = \text{本期金额} - \text{上期金额}
\]

- 环比增长率：

\[
\text{环比增长率} = \frac{\text{本期金额} - \text{上期金额}}{\text{上期金额}}
\]

- 多城市数据要先按城市分组、按月份排序，再在组内使用 `shift()`。
- 可使用 `groupby(...).apply(...)` 对每个城市组分别计算。

### 6.3 同比

- 同比是与上年同期比较。
- Excel 中可通过数据透视表按“店号”和“年份”构造交叉表。
- Pandas 中使用 `pd.pivot_table()` 实现同样结构。
- 必须指定 `aggfunc="sum"`，否则默认可能按平均值聚合。
- 年份变量作为 `columns` 时不要加引号。
- 同比增长率：

\[
\text{同比增长率} = \frac{\text{本年同期金额} - \text{上年同期金额}}{\text{上年同期金额}}
\]

### 6.4 常用函数与参数

- `.values.T`：矩阵转置。
- `pd.DataFrame()`：重新构造 DataFrame。
- `.shift(1)`：向下移动一行，用于构造上期数据。
- `.astype()`：转换数据类型。
- `.dt.month`：从日期中提取月份。
- `.dt.year`：从日期中提取年份。
- `groupby()`：分组。
- `apply()`：对每个分组调用函数。
- `sort_values()`：排序。
- `pd.pivot_table()`：构造数据透视表。
- `aggfunc="sum"`：指定求和聚合。
- `pd.read_excel()`：读取 Excel 文件，注意工作表名称参数。

视频最后总结：转置、环比和同比的实现都不复杂，重点是把数据先整理成正确结构，再使用对应的 Pandas 方法进行计算，并希望这些方法能应用到实际工作中。
