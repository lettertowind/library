# 叠加条形图（水平堆积条形图）— Matplotlib 笔记

## 1. 本课目标与核心区别

- 学习绘制叠加条形图，也就是水平方向的堆积条形图。
- 柱形图与条形图并不是简单“倒过来”就完事，堆积方向、坐标轴含义、`height/width` 参数以及文本标签坐标都需要转换。
- 本课沿用上节课“堆积柱形图”的数据资料，数据中至少包含：`姓名`、`语文`、`数学`、`英语`。
- 核心思路：先画第一层“语文”，再以“语文”为起点堆叠“数学”，最后以“语文 + 数学”为起点堆叠“英语”。

## 2. 准备工作：导入库、处理中文、读取数据

- 导入 `pandas` 和 `matplotlib.pyplot`。
- 处理中文字体问题，避免中文标签乱码；具体字体设置沿用上节课内容。
- 打开上节课使用的数据文件，并先运行检查数据是否正常。
- 讲师确认：当前数据与上节课课件完全一样。

示例结构如下，具体文件名与中文字体设置沿用上节课：

```python
import pandas as pd
import matplotlib.pyplot as plt

# 处理中文字体问题（按上节课设置）
# plt.rcParams['font.sans-serif'] = ['SimHei']
# plt.rcParams['axes.unicode_minus'] = False

data = pd.read_csv('上节课使用的数据文件.csv')
```

## 3. 绘制第一条水平条：语文

- 使用函数：`plt.barh`。
- `barh` 表示水平条形图，不能继续用柱形图的 `plt.bar`。
- 讲师强调：最重要的一点是先告诉 Matplotlib“这是条形图”，也就是调用 `plt.barh`；否则方向或参数会出错。
- 第一条条形的起点从横轴 `0` 开始，对应 `left=0`。
- 纵轴位置由 `姓名` 控制，即每个姓名对应一行条形。
- `height=0.5` 控制条带的粗细/高度。
- `width=data.语文` 控制条带的长度。
- 第一条颜色设为 `red`。

位置参数形式可写为：

```python
plt.barh(data.姓名, data.语文, height=0.5, left=0, color='red')
plt.show()
```

等价的清晰关键字写法：

```python
plt.barh(y=data.姓名, width=data.语文, height=0.5, left=0, color='red')
plt.show()
```

参数含义：

| 参数 | 本课设置 | 作用 |
|---|---|---|
| `y` | `data.姓名` | 纵轴类别，决定条形所在行 |
| `width` | `data.语文` | 水平条的长度 |
| `height` | `0.5` | 条带的粗细/高度 |
| `left` | `0` | 水平堆积起点，从横轴 0 开始 |
| `color` | `red` | 条带颜色 |

## 4. 堆叠第二条：数学

- 第二条不能继续从 `0` 开始画，而要从第一条“语文”的末端继续堆叠。
- 起点设置为 `left=data.语文`。
- 纵轴仍由 `data.姓名` 控制，需要再写一次。
- `height` 仍设置为 `0.5`。
- `width` 改为 `data.数学`，即第二条的长度是数学成绩。
- 颜色改为 `green`。
- 画完第二条后运行测试，确认总长度继续向右延伸；讲师观察到此时总长度已被写到约 200 的位置。

代码：

```python
plt.barh(data.姓名, data.数学, height=0.5, left=data.语文, color='green')
plt.show()
```

关键词写法：

```python
plt.barh(y=data.姓名, width=data.数学, height=0.5, left=data.语文, color='green')
```

## 5. 堆叠第三条：英语

- 第三条的起点是前两层之和，即 `data.语文 + data.数学`。
- `left=data.语文 + data.数学`。
- 纵轴仍为 `data.姓名`。
- `height` 仍为 `0.5`。
- `width` 改为 `data.英语`。
- 颜色改为 `blue`。
- 运行后三条水平堆积条形图绘制完成。

代码：

```python
plt.barh(data.姓名, data.英语, height=0.5,
         left=data.语文 + data.数学, color='blue')
plt.show()
```

关键词写法：

```python
plt.barh(y=data.姓名, width=data.英语, height=0.5,
         left=data.语文 + data.数学, color='blue')
```

## 6. 添加数据标签：`plt.text` 的关键踩坑

- 使用 `plt.text` 给每个条形添加数值标签。
- `plt.text` 常用参数顺序为：`x`、`y`、`s`，其中 `s` 是显示文本。
- 讲师先按上节课“堆积柱形图”的坐标思路，用 `x1`、`y1` 去写，结果文字接反，甚至基础图上的文字看不见。
- 原因：从柱形图转为条形图后，坐标轴也发生了转换。
- 柱形图中原来可能是：`x=姓名`、`y=语文`；水平条形图中应转为：`x=语文数值`、`y=姓名`。
- 因此标签坐标也必须“倒过来”：`x` 使用数值列或累计和，`y` 使用姓名/类别。
- 设置文字居中：`ha='center'`、`va='center'`。
- 设置字号：`fontsize=20`。
- 设置颜色：`color='white'`，让白字显示在红色、绿色、蓝色条带内。
- 文字位置还需要微调：讲师用“减 20”的偷懒方法让文字进入条带内部；减 10 或减 20 都可以，按实际效果调整。

### 6.1 第一条标签：语文

先写语文标签：

```python
plt.text(data.语文 - 20, data.姓名, data.语文,
         ha='center', va='center', fontsize=20, color='white')
```

说明：

- `data.语文 - 20`：文本的横坐标，在语文条末端附近向回偏移，使文字落入红色条内。
- `data.姓名`：文本的纵坐标，对应每个姓名所在行。
- `data.语文`：要显示的文本内容。
- `ha='center'`：水平居中。
- `va='center'`：垂直居中。
- `fontsize=20`：字号 20。
- `color='white'`：白色字体。

讲师强调：如果仍按柱形图的 `x1=姓名`、`y1=语文` 写，会出现“接反”的问题；必须将条形图的坐标转换过来。

### 6.2 第二条标签：数学

- 第二个标签对应数学。
- 横坐标应使用前两层累计值：`data.语文 + data.数学`。
- 再做减去偏移量的微调，让文字进入条带内。
- 文本内容为 `data.数学`。
- 其他样式参数与第一条一致。

代码：

```python
plt.text(data.语文 + data.数学 - 20, data.姓名, data.数学,
         ha='center', va='center', fontsize=20, color='white')
```

### 6.3 第三条标签：英语

- 第三个标签对应英语。
- 横坐标使用三层累计值：`data.语文 + data.数学 + data.英语`。
- 同样做偏移微调。
- 文本内容为 `data.英语`。
- 其他样式参数保持一致。

代码：

```python
plt.text(data.语文 + data.数学 + data.英语 - 20, data.姓名, data.英语,
         ha='center', va='center', fontsize=20, color='white')
```

## 7. 完整代码整合

以下按讲师课堂思路整合：先画三层堆积条形图，再添加三层标签，最后显示。

```python
import pandas as pd
import matplotlib.pyplot as plt

# 中文字体设置沿用上节课
# plt.rcParams['font.sans-serif'] = ['SimHei']
# plt.rcParams['axes.unicode_minus'] = False

data = pd.read_csv('上节课使用的数据文件.csv')

# 第一层：语文，从 0 开始
plt.barh(data.姓名, data.语文, height=0.5, left=0, color='red')

# 第二层：数学，从语文末端开始堆叠
plt.barh(data.姓名, data.数学, height=0.5, left=data.语文, color='green')

# 第三层：英语，从语文 + 数学末端开始堆叠
plt.barh(data.姓名, data.英语, height=0.5,
         left=data.语文 + data.数学, color='blue')

# 语文标签
plt.text(data.语文 - 20, data.姓名, data.语文,
         ha='center', va='center', fontsize=20, color='white')

# 数学标签
plt.text(data.语文 + data.数学 - 20, data.姓名, data.数学,
         ha='center', va='center', fontsize=20, color='white')

# 英语标签
plt.text(data.语文 + data.数学 + data.英语 - 20, data.姓名, data.英语,
         ha='center', va='center', fontsize=20, color='white')

plt.show()
```

## 8. 关键结论与易错点

- 叠加条形图使用 `plt.barh`，不是柱形图的 `plt.bar`。
- 水平条形图中：`width` 控制条带长度，`height` 控制条带粗细。
- 堆积起点由 `left` 控制：
  - 第一层：`left=0`
  - 第二层：`left=data.语文`
  - 第三层：`left=data.语文 + data.数学`
- 纵轴类别通常由 `data.姓名` 控制。
- 从柱形图转条形图时，坐标轴要转换，`plt.text` 的 `x`、`y` 也要跟着转换。
- 标签初始按柱形图思路写会出现接反、文字不可见等问题；应改成 `x=数值/累计值`、`y=姓名`。
- 文本标签居中用 `ha='center'`、`va='center'`；字号用 `fontsize=20`；颜色用 `color='white'`。
- 标签位置可用“减 20”的方式微调，减 10 或减 20 都可，属于快速调整方法。
- 建议每增加一层先运行查看堆积位置；确认结构无误后再集中添加标签。
- 讲师最后建议：下课后一定要多练习，尤其是坐标转换和累计起点。
