# DataFrame 数据结构学习笔记

## 一、DataFrame 基本概念

- `DataFrame` 是 Pandas 中的表格型数据结构，可以理解为二维表。
- 每一列可以是不同的数据类型，例如：
  - 数值
  - 字符
  - 布尔值等
- `DataFrame` 同时具有：
  - 行索引：例如视频示例文件中的 `1、2、3、4、5、6、7`，用来定位每一行。
  - 列索引：即字段名、列名，例如表中的各列标题。
- 视频示例中读取表格后，行索引是 `1234567`，列索引是字段名。
- 讲师强调：`DataFrame` 可以看作“由多个 `Series` 组成的一个字典”。
- 创建 `DataFrame` 最常用的方式包括：
  - `read_csv`
  - `read_excel`
  - `read_sql` / MySQL 等文件或数据库读取方式
  - 这些内容在第一节课中已有讲解。
- 本节先创建简单的 `DataFrame` 进行演示，不重复导入 Pandas 库。

## 二、用嵌套列表创建 DataFrame

创建三行三列数据：

```python
data = pd.DataFrame(
    [[1, 2, 3],
     [4, 5, 6],
     [7, 8, 9]],
    columns=['a', 'b', 'c']
)
print(data)
```

说明：

- 外层用一个列表套住三个列表，表示三行三列。
- `columns` 用来指定列名，也就是字段名。
- 视频中列名为 `a、b、c`。
- 打印结果中：
  - 行索引为 `0、1、2`
  - 列索引为 `a、b、c`
  - 数据为 `1 到 9`
- 讲师说明：这里的索引指的是“数据索引”，不包含字段名这个索引。

## 三、DataFrame 取值与 loc、iloc

### 1. 取单列中的某个值

要取 `a` 列第 `0` 行的数据，可以写：

```python
data['a'][0]
```

说明：

- 前面是列，后面是行。
- 视频示例中，`a` 列第 `0` 行取到的是 `1`。
- 因为示例数据 `1 到 9` 没有重复，所以取错时比较容易看出来。

### 2. 使用 loc 按标签取值

```python
data.loc[0, 'a']
```

说明：

- `loc` 根据“行列标签”进行查询。
- 行标签是索引 `0、1、2`。
- 列标签是 `a、b、c`。
- `data.loc[0, 'a']` 表示取第 `0` 行、`a` 列的数据。
- 讲师建议：如果习惯的话，更推荐使用 `loc` 的方式，即“0 行 a 列”，这样更直观。

### 3. 使用 iloc 按位置取值

```python
data.iloc[0, 0]
```

说明：

- `iloc` 根据“行列的数字位置”查询。
- 不管行标签、列标签被设置成什么，位置索引始终不变。
- 三行三列数据的位置始终是：
  - 行位置：`0、1、2`
  - 列位置：`0、1、2`
- `iloc[0, 0]` 始终表示第 `0` 行第 `0` 列的位置。

### 4. loc 与 iloc 的核心区别

- `loc`：使用标签名字查询。
  - 例如 `data.loc[0, 'a']`
  - 行标签是 `0、1、2`，列标签是 `a、b、c`。
- `iloc`：使用数字位置查询。
  - 例如 `data.iloc[0, 0]`
  - 永远按第几行、第几列的位置取数。
- 如果设置了 `index`，`loc` 的写法会改变，而 `iloc` 的位置写法不变。
- 例如把行索引设置成大写 `A、B、C`：

```python
data.index = ['A', 'B', 'C']
```

之后再用 `loc`，就要改成类似：

```python
data.loc['A', 'a']
```

而 `iloc` 仍然写：

```python
data.iloc[0, 0]
```

- 讲师说明：`loc` 与 `iloc` 的详细内容会在“数据查询”那节课中进一步介绍，这里只是演示。

### 5. 查询多列数据

查询多列时，要在中括号里面再套一个列表：

```python
data[['a', 'b']]
```

说明：

- 查询多列一定要使用“中括号里套列表”的形式。
- 例如查询 `a` 列和 `b` 列：

```python
print(data[['a', 'b']])
```

- 只要在列表中提供列名、字段名，就可以拿到指定列。
- 讲师提醒：这一点千万不要弄错。

## 四、用字典创建 DataFrame

使用字典创建 `DataFrame`：

```python
data = {
    '姓名': ['孙兴华', '李小龙', '叶问'],
    '年龄': [20, 80, 127],
    '功夫': ['健身', '截拳道', '咏春']
}

df = pd.DataFrame(data)
print(df)
```

说明：

- 字典中的一个 `key` 对应一列。
- `key` 后面通常跟一个列表，列表里放该列的值。
- 字符型要加引号，数值型不用加引号。
- 示例中：
  - 姓名列对应：孙兴华、李小龙、叶问
  - 年龄列对应：20、80、127
  - 功夫列对应：健身、截拳道、咏春

### 1. 字典创建时的坑

- 字典键值对之后都要有逗号隔开。
- 视频中曾经因为后面没写逗号出现错误，补上逗号后正常。
- 讲师特别提醒：字典键值对之间要用逗号隔开。

### 2. 查看每列数据类型

```python
df.dtypes
```

示例结果：

- 姓名列：`object`
- 年龄列：`int64`
- 功夫列：`object`

说明：

- `dtypes` 用来看每一列的数据类型。
- 字符型列通常显示为 `object`。
- 整数列显示为 `int64`。

### 3. 查看列索引和行索引

查看列名、字段名：

```python
df.columns
```

查看行索引：

```python
df.index
```

说明：

- `columns` 查看列索引，也就是字段名。
- `index` 查看行索引。
- 示例中 `index` 从 `0` 开始，到 `3` 结束，步长为 `1`。
- 讲师提醒：术语上“列索引、字段名、列名”经常混着说，容易把人说晕，这里按字段名理解即可。

## 五、从 DataFrame 中查询 Series

如果只查询一列，例如姓名列：

```python
df['姓名']
```

说明：

- 查询单列会返回一个 `Series`。
- 讲师强调：如果使用 `type` 查看数据类型：

```python
type(df['姓名'])
```

返回的是 Pandas 的 `Series` 类型，例如：

```python
pandas.core.series.Series
```

- 它不会直接告诉你这一列元素的具体数据类型。
- 这一点一定要记住。

### 1. 查询一行数据

使用 `loc` 查询一行：

```python
df.loc[1]
```

说明：

- `loc` 后面要用中括号。
- 视频中如果写成小括号，可能返回内存地址。
- 示例中 `df.loc[1]` 返回索引为 `1` 的那一行，视频示例为：
  - 李小龙
  - 80
  - 截拳道
- 因为索引从 `0` 开始，所以 `1` 对应第二条记录；讲师口述中称为“第一行数据”时，需要结合索引理解。

### 2. 查询指定行和指定列

例如查询索引为 `1` 的那一行的姓名列：

```python
df.loc[1, '姓名']
```

说明：

- `loc[行, 列]` 可以同时指定行和列。
- 视频示例中取到的是“李小龙”。

### 3. 查询多列

```python
df[['姓名', '年龄']]
```

说明：

- 查询多列仍然使用“中括号里套列表”的形式。
- 返回姓名和年龄两列数据。

### 4. 查询多行

查询多行时使用 `loc` 或 `iloc`：

```python
df.loc[0:3]
```

说明：

- 视频中演示取前三行。
- 返回索引 `0、1、2` 三行。
- 讲师解释：
  - 从 `0` 开始
  - 结束值是 `3`，但不包括结束值
  - 步长为 `1`，可以省略
- 讲师提醒：这需要回忆 Python 基础篇中关于切片的知识。
- 视频中也说明：列查询直接用列名；行查询要用 `loc` 或 `iloc`。

## 六、用多个 Series 创建 DataFrame

先创建多个 `Series`：

```python
s1 = pd.Series(['叶问', '李小龙', '孙兴华'],
               index=[1, 2, 3],
               name='姓名')

s2 = pd.Series(['男', '男', '男'],
               index=[1, 2, 3],
               name='性别')

s3 = pd.Series([127, 80, 20],
               index=[1, 2, 3],
               name='年龄')
```

说明：

- 每个 `Series` 都有自己的 `index`。
- 视频中三个 `Series` 的 `index` 都是 `1、2、3`。
- `name` 用来指定该 `Series` 的字段名。

### 1. 使用字典方式组合多个 Series

```python
df = pd.DataFrame({
    s1.name: s1,
    s2.name: s2,
    s3.name: s3
})
print(df)
```

说明：

- 字典的 `key` 使用每个 `Series` 的 `name`。
- 字典的 `value` 使用对应的 `Series` 本身。
- 这样可以把多个 `Series` 组合成一个 `DataFrame`。
- 讲师说明：这种多个 `Series` 组合的方式并不算特别常见，但需要掌握。

### 2. 使用列表方式组合多个 Series

```python
df = pd.DataFrame([s1, s2, s3])
print(df)
```

说明：

- 结果会把行列交换一下顺序。
- 视频中显示为姓名、性别、年龄等作为行方向显示。
- 讲师形容：这样看起来有点像数据透视表，相当于把一维数据转成二维数据的感觉。

### 3. 多个 Series 的索引对齐功能

如果把 `s3` 的索引改成不同值，例如：

```python
s3 = pd.Series([127, 80, 20],
               index=[2, 3, 4],
               name='年龄')

df = pd.DataFrame({
    s1.name: s1,
    s2.name: s2,
    s3.name: s3
})
```

说明：

- `DataFrame` 会自动按索引对齐。
- 索引相同的位置会自动对应。
- 索引 `1` 有姓名和性别数据，但 `s3` 没有索引 `1`，所以年龄位置显示 `NaN`。
- `127` 对应索引 `2`，会自动对齐到索引 `2`。
- `20` 对应索引 `4`，前面没有索引 `4`，因此相关位置显示 `NaN`。
- `NaN` 表示不是一个数字，即缺失值。

## 七、DataFrame 常用方法

讲师强调：这些 `DataFrame` 常用方法很重要，比之前的知识还要重要。

### 1. head：查询前几行

```python
df.head()
```

- 不写参数时，默认查询前五行。

```python
df.head(3)
```

- 写数字 `3` 时，查询前三行。

### 2. tail：查询后几行

```python
df.tail()
```

- 默认查询后五行。

```python
df.tail(3)
```

- 参数写 `3` 时，查询后三行。
- 视频示例中一共有七行数据，`tail()` 会返回后五行。
- 如果指定数字，就返回后几行。

### 3. index：查询行索引

```python
df.index
```

- 查询行索引序列。
- 视频中该知识点在 `Series` 时已经讲过。

### 4. values：查询值

```python
df.values
```

- 查询 `DataFrame` 中的值。
- 视频中该知识点也已讲过。

### 5. shape：查询表的形状

```python
df.shape
```

- 返回表是几行几列。
- 视频示例中返回七行五列。
- 该知识点在 NumPy 中经常使用。

### 6. fillna：填充空值

视频中故意把“赵敏”的年龄清空，读取后显示为 `NaN`。

```python
df.fillna(0)
```

- 将空值填充为 `0`。

```python
df.fillna(1)
```

- 将空值填充为 `1`。
- 讲师强调：`fillna` 只能给空值进行填充，不会修改非空值。

### 7. replace：替换值

例如把“杨过”替换成“孙兴华”：

```python
df.replace('杨过', '孙兴华')
```

说明：

- `replace` 可以把指定值替换成新值。
- 视频中只有一个“杨过”，所以能看到明显变化。
- 讲师说明：无论有几个“杨过”，它都能替换。

### 8. isna：判断是否为空

```python
df.isna()
```

说明：

- 判断数据是否为空。
- 为空的位置显示 `True`。
- 不为空的位置显示 `False`。
- 视频口述为“is no”，实际应理解为 `isna()` / `isnull()` 这一类判空函数。

### 9. notnull：判断是否不为空

```python
df.notnull()
```

说明：

- 判断数据是否“不是空”。
- 不是空的位置显示 `True`。
- 是空的位置显示 `False`。
- 它和 `isna()` 的判断结果正好相反。

### 10. unique：查询唯一值、去重

- 视频提到还需要学习“查询唯一值”的方法。
- 类似 Excel 365 中的 `UNIQUE` 函数。
- Excel 365 新增了该函数，部分旧版本可能没有。
- Pandas 库中也有对应函数。
- 讲师说明：用到这个函数时会再作介绍。

### 11. reset_index：修改或删除原索引

使用 `drop` 参数控制索引处理方式。

删除原索引，生成默认索引：

```python
df.reset_index(drop=True)
```

说明：

- `drop=True` 时，原索引会被删除。
- 同时生成默认索引，例如 `0、1、2、3...`。

不删除原索引，而是把原索引还原成普通列：

```python
df.reset_index(drop=False)
```

说明：

- `drop=False` 时，原索引不会被删除。
- 原索引会被恢复成一个普通列。
- 同时仍然会生成一个默认索引。
- 二者区别：
  - `drop=True`：删除索引。
  - `drop=False`：索引还原成普通列。
- 两种方式都会恢复一个默认索引。

## 八、关键易混点与踩坑总结

- `DataFrame` 是二维表格型数据结构，有行索引和列索引。
- `DataFrame` 可以看作由多个 `Series` 组成的字典。
- `loc` 按标签查询，`iloc` 按位置查询。
- `loc` 的写法是 `loc[行, 列]`，例如 `df.loc[0, 'a']`。
- `iloc` 的写法是 `iloc[行位置, 列位置]`，例如 `df.iloc[0, 0]`。
- 如果修改了 `index`，`loc` 要使用新的标签，`iloc` 的位置不受影响。
- 查询多列必须写成“中括号里套列表”，例如 `df[['姓名', '年龄']]`。
- 字典创建 `DataFrame` 时，字典键值对之后必须有逗号。
- `df.dtypes` 查看每列数据类型，例如 `object`、`int64`。
- `df.columns` 查看列名/字段名，`df.index` 查看行索引。
- 查询单列返回的是 `Series`，`type` 返回 `pandas.core.series.Series`，不是元素类型。
- 查询行用 `loc` / `iloc`；查询列可以直接用列名。
- 多个 `Series` 用列表方式组合时，行列会交换顺序，类似数据透视表。
- 多个 `Series` 组合时具有索引对齐功能，缺失位置显示 `NaN`。
- `head()` 默认前五行，`head(n)` 取前 n 行。
- `tail()` 默认后五行，`tail(n)` 取后 n 行。
- `shape` 返回几行几列，例如七行五列。
- `fillna()` 只能填充空值。
- `replace()` 可以替换所有匹配值。
- `isna()` 与 `notnull()` 判断结果相反。
- `reset_index(drop=True)` 删除原索引；`reset_index(drop=False)` 把原索引还原成普通列。
- 后续将学习 `DataFrame` 的合并操作，包括内连接、左连接、右连接、全外连接等，内容类似 SQL。
