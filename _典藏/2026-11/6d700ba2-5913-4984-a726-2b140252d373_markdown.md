## 1. 逻辑条件作为数组操作

- 课堂首先强调学习方法：学习数组操作时，先把数组打印出来，观察它的形状和内容，再写后续代码；一定要多敲代码。
- 示例数组是 3×3 的二维数组。讲师建议把数组对应到 Excel 表格中理解行和列，避免在 NumPy 中因“行轴、列轴”混乱。
- 课堂示例数组可按口述还原为：

```python
import numpy as np

a = np.array([[1, 3, 6],
              [9, 3, 2],
              [1, 4, 3]])
print(a)
```

- 需求：查看数组中大于 3 的数有哪些。
- 写法：

```python
print(a > 3)
```

- `a > 3` 会把条件作用到数组的每一个元素上，逐元素比较，返回一个与原数组形状相同的布尔数组。
- 课堂上逐个元素解释：
  - `1 > 3`：False
  - `3 > 3`：False，注意“大于 3”不包含等于 3
  - `6 > 3`：True
  - `9 > 3`：True
  - `3 > 3`：False
  - `2 > 3`：False
  - `1 > 3`：False
  - `4 > 3`：True
  - `3 > 3`：False
- 返回结果类似：

```python
[[False False  True]
 [ True False False]
 [False  True False]]
```

- 关键结论：数组和标量做比较运算时，比较是逐元素的；涉及 `>`、`<` 等比较，返回的是 `True/False` 布尔数组。

## 2. 条件替换：`np.where`

- 需求：把大于 3 的数都改成 `520`，不大于 3 的数都改成 `1314`。
- 使用 `np.where`，语法类似 `if/else` 三元条件：

```python
np.where(条件, 条件为真时返回的值, 条件为假时返回的值)
```

- 课堂代码：

```python
print(np.where(a > 3, 520, 1314))
```

- 解释：
  - 当数组元素满足 `a > 3` 时，返回 `520`
  - 否则返回 `1314`
- 注意：`a > 3` 中的“大于”不包含等于，因此 `3` 会被归入“否则”分支，返回 `1314`。
- `np.where` 返回一个新的结果数组，不改变原数组内容；课堂重点是掌握条件、真值返回值、假值返回值三个参数的位置。

## 3. 统计满足条件的个数：布尔数组求和

- 需求：统计数组中大于 3 的个数。
- 课堂写法：

```python
print((a > 3).sum())
```

- 原理：
  - `a > 3` 先得到布尔数组。
  - 布尔数组中 `False` 等价于 `0`，`True` 等价于 `1`，即：

```text
False = 0
True  = 1
```

  - 对布尔数组调用 `.sum()`，相当于把所有的 `True` 累加，得到满足条件的元素个数。
- 课堂示例中布尔数组为“假、假、真、真、假、假、假、真、假”，求和为：

```text
0 + 0 + 1 + 1 + 0 + 0 + 0 + 1 + 0 = 3
```

- 结论：大于 3 的元素一共有 3 个。
- 关键点：统计条件个数时，不要把条件写成普通数值求和；要先得到布尔数组，再对布尔数组求和。

## 4. 布尔值常用方法：`any` 与 `all`

- 课堂讲解两个常用布尔值方法：
  - `any`：检查数组中是否至少有一个 `True`。
  - `all`：检查数组中是否每个值都是 `True`。
- 课堂用一个布尔数组演示，例如：

```python
b = np.array([False, False, True, False])

print(np.any(b))  # True，至少有一个真
print(np.all(b))  # False，不是所有值都为真
```

- 原理：
  - `np.any(b)`：只要数组中存在一个 `True`，就返回 `True`；全是 `False` 才返回 `False`。
  - `np.all(b)`：只有数组中所有元素都是 `True`，才返回 `True`；只要有一个 `False`，就返回 `False`。
- 课堂继续演示：如果把布尔数组全部改成 `True`，则：

```python
b2 = np.array([True, True, True])
print(np.all(b2))  # True
```

- 易混点：
  - `any` 对应“至少一个为真”。
  - `all` 对应“全部为真”。
- 课堂示例结论：
  - 布尔数组“假假真假”中，`any` 返回 `True`，因为存在一个真。
  - 同一个数组 `all` 返回 `False`，因为不是全真。
  - 全部换成真后，`all` 返回 `True`。

## 5. 按值大小排序：`ndarray.sort()`

- 课堂讲解数组排序方法 `sort`，语法可写为：

```python
数组名.sort(axis=..., kind=..., order=...)
```

- 参数说明：
  - `axis`：排序轴。
  - `kind`：排序算法。初级阶段不用管。
  - `order`：字段名，用于结构化数组按字段排序。课堂提供了相关资料，但说明当前阶段不是重点，可以先理解一维数组、二维数组排序。
- 关键结论：`a.sort()` 是原地排序方法，会直接修改原始数组；不需要把结果赋值给新变量。
- 课堂强调：打印 `a` 可以看到原数组已经被排序，而不是 `a.sort()` 返回了一个新数组。

### 5.1 一维数组排序

```python
import numpy as np

a = np.array([3, 1, 2])
a.sort()
print(a)
```

- `a.sort()` 后，原数组从小到大升序排列，结果类似：

```text
[1 2 3]
```

- 结论：
  - 一维数组 `sort()` 默认从小到大排序。
  - 排序修改原始数组。
  - 不需要写成 `a = a.sort()`；课堂明确说“不需要赋值出来”。

### 5.2 二维数组排序与 `axis`

- 课堂另建一个三行三列的二维数组进行演示。
- 轴的概念：
  - 二维数组中，行是 `0` 轴。
  - 列是 `1` 轴。
- 讲师用 Excel 表格辅助说明：二维数组在 NumPy 中看行、列、轴容易混乱，放到 Excel 中按列或按行观察会更直观。
- 课堂口述：二维数组默认按“最后的排序轴”排序，并结合演示结果称其为“按列排序”。这里需要结合 NumPy 的 `axis` 语义理解：
  - `axis=0`：沿行方向跨行处理，可理解为对每一列内部排序。
  - `axis=1`：沿列方向跨列处理，可理解为对每一行内部排序。
  - 默认 `axis=-1` 表示最后一个轴；二维时通常等价于 `axis=1`。
- 为避免课堂口述“按行/按列”与代码轴混淆，建议实际写代码时显式指定 `axis` 验证。例如：

```python
m = np.array([[0, 12, 48],
              [4, 8, 14],
              [7, 1, 19]])

m.sort(axis=0)  # 对每一列内部排序
print(m)

m.sort(axis=1)  # 对每一行内部排序
print(m)
```

- 课堂结论：
  - 二维数组排序必须理解 `axis`。
  - 默认轴、`axis=0`、`axis=1` 的结果不同。
  - 不要只死记“行”或“列”，要结合数组形状和代码运行结果验证。
  - 字段名排序 `order` 和排序算法 `kind` 当前阶段可以先放一放，后面 Pandas 会有更方便的方法。

## 6. 索引排序：`np.argsort`

- `argsort` 的作用不是直接返回排序后的值，而是返回“从小到大排序后的索引/下标”。
- 课堂强调：索引就是下标。
- 一维数组示例：

```python
x = np.array([59, 29, 39])
idx = np.argsort(x)
print(idx)       # [1 2 0]
print(x[idx])    # [29 39 59]
```

- 解释：
  - 原数组 `[59, 29, 39]` 中：
    - 最小值 `29` 的下标是 `1`
    - 中间值 `39` 的下标是 `2`
    - 最大值 `59` 的下标是 `0`
  - 所以升序索引为 `[1, 2, 0]`。
  - 再用 `x[idx]`，相当于拿索引数组去原数组中取值，得到升序结果 `[29, 39, 59]`。
- 关键结论：`np.argsort(x)` 返回的是下标数组；可以用这个下标数组对原数组进行重新取值，实现排序。

### 6.1 降序索引排序

- 课堂降序做法：把排序依据改成负值，再取索引。
- 示例：

```python
print(np.argsort(-x))       # 降序索引
print(x[np.argsort(-x)])    # [59 39 29]
```

- 原理解释：
  - 对原数组取负后，原来最大的数变成最小，`argsort` 升序就会把最大值对应的索引排到前面。
  - 再用这个索引取原数组，就得到从大到小的结果。
- 课堂结论：降序时“把这个值改成一个负的”，索引顺序就倒过来了，最大的放前面，最小的放后面。

### 6.2 二维数组的索引排序

- 课堂也演示了二维数组的 `argsort`，并说明二维索引排序会按轴返回索引。
- 课堂指出：二维数组不能像一维那样简单地把索引塞回去，需要配合行号数组。课堂上使用了类似 `np.arange` 的方式构造行索引，再与 `argsort` 结果配合取值。
- 课堂示意写法：

```python
m = np.array([[3, 1, 2],
              [6, 4, 5]])

idx2 = np.argsort(m, axis=1)
rows = np.arange(m.shape[0])[:, None]
print(idx2)
print(m[rows, idx2])
```

- 课堂态度：这部分“大家只是看一下就可以了，没必要讲太深”，因为 Pandas 中会有更好的方法操作二维表数据。
- 关键结论：
  - 二维 `argsort` 返回同样形状的索引数组。
  - 用二维索引排序取值时要注意行索引和列索引的配合。
  - 初级阶段理解 `argsort` 返回下标、可配合索引取值即可。

## 7. 唯一值：`np.unique`

- 需求：对数组去重，得到唯一值。
- 课堂用中文姓名数组演示：

```python
names = np.array(['孙悟空', '猪八戒', '孙悟空', '沙和尚', '孙悟空', '唐僧'])
print(np.unique(names))
```

- 作用：`np.unique(数组)` 返回数组中的唯一值，即去重结果。
- 课堂提到 Power BI 中经常建立新表、做去重，这里 NumPy 也有对应的去重方法。
- 数字示例：

```python
nums = np.array([1, 3, 5, 1, 3, 5, 6, 7])
print(np.unique(nums))  # [1 3 5 6 7]
```

- 课堂口述结果：唯一值为 `1、3、5、6、7`。
- 关键结论：`np.unique` 用于去重，返回唯一值数组；课堂强调“去虫”即“去重”。

## 8. 成员判断：`np.in1d`

- 作用：检查一个数组中的值是否在另一个数组中出现，返回布尔类型结果。
- 函数写作：

```python
np.in1d(ar1, ar2)
```

- 语义：返回与待检查数组对应的布尔数组，表示相应元素是否出现在另一个数组中。
- 课堂口述的检查结果示例：
  - `6` 在数组中：`True`
  - `0` 不在数组中：`False`
  - `3` 在数组中：`True`
  - `2` 在数组中：`True`
  - `5` 不在数组中：`False`
  - `6` 在数组中：`True`
- 易混点：`in1d` 的参数顺序要结合“待检查的值”和“被检查的集合”理解；返回的是布尔数组，不是直接返回交集值。
- 课堂结论：`np.in1d` 用于判断一个数组的值是否出现在另一个数组中，返回真/假结果。

## 10. 浅拷贝与深拷贝

- 课堂最后强调 NumPy 中数组赋值不能随意写 `a = b`。
- 直接赋值：

```python
a = b
```

- 问题：`a` 和 `b` 会互相影响。修改其中一个，另一个也会变化，因为二者指向同一份数据/内存。
- 切片或视图操作：

```python
a = b[:]
```

- 课堂说明：类似切片、视图操作会创建一个对象 `a`，但 `a` 的数据仍由 `b` 保管，二者数据变化保持一致。
- 推荐写法：需要独立副本时，使用 `copy()`：

```python
a = b.copy()
```

- 这样 `a` 是 `b` 的拷贝，修改 `b` 不会影响 `a`，修改 `a` 也不会影响 `b`。
- 课堂结论：
  - 不建议用 `a = b` 直接赋值数组。
  - 切片/视图可能共享底层数据，修改会互相影响。
  - 要独立数组，一定要加 `.copy()`。
  - 不带 `copy` 时，修改 `b` 可能导致 `a` 的值变化，容易出错。

## 11. 本课结论清单

- 条件运算逐元素执行，`a > 3` 返回同形状布尔数组。
- `False` 可视为 `0`，`True` 可视为 `1`，因此 `(a > 3).sum()` 可统计满足条件的元素个数。
- `np.where(条件, 真值, 假值)` 类似 `if/else`，用于条件替换。
- `np.any` 判断是否至少有一个 `True`；`np.all` 判断是否全部为 `True`。
- `ndarray.sort()` 是原地排序，直接修改原数组；一维默认升序；二维要理解 `axis`。
- 二维数组轴：行是 `0` 轴，列是 `1` 轴；课堂用 Excel 辅助理解，实际代码建议显式写 `axis` 验证。
- `np.argsort` 返回排序后的索引/下标；可用索引对原数组取值实现排序；降序可对值取负后再 `argsort`。
- `np.unique` 用于去重，返回唯一值。
- `np.in1d` 用于判断数组元素是否出现在另一个数组中，返回布尔数组。
- 数组赋值 `a = b` 会让二者互相影响；切片/视图也可能共享数据；需要独立副本时使用 `b.copy()`。
