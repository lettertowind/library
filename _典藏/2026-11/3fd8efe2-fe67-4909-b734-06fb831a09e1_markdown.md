## 3. 添加标题：`plt.title`

### 3.1 基本用法

给当前图添加标题：

```python
plt.title('孙兴华')
```

运行后标题会显示在图形顶部。讲师先演示了最基本的标题文字添加，再进一步讲解样式参数。

### 3.2 标题常用样式参数

在 `plt.title()` 中可设置常用样式：

```python
plt.title('孙兴华', fontsize=20, fontweight='bold', color='red')
```

参数说明：

- `fontsize=20`：设置字号为 20 号。
- `fontweight='bold'`：设置字体加粗。
- `color='red'`：设置字体颜色为红色。

讲师演示时曾出现拼写少字母的情况，修正后标题正常显示为“加粗、20 号、红色”的样式。这里需要注意参数拼写，例如 `fontsize`、`fontweight` 不要写错。

## 4. 创建多个子图并绘制示例

演示完整图标题后，讲师将标题代码注释掉，开始创建子图：

```python
plt.subplot(221)
plt.subplot(222)
plt.subplot(223)
plt.subplot(224)
```

- `221`、`222`、`223`、`224` 表示创建一个 2×2 的子图布局，并分别选中第 1、2、3、4 个子图。
- 运行后画布中出现四个子图区域。

接着在第一个子图中绘制简单示例数据：

```python
x = ['a', 'b', 'c']
y = [1, 2, 3]

plt.plot(x, y, 'o')
```

说明：

- `x = ['a', 'b', 'c']`：x 轴数据。
- `y = [1, 2, 3]`：y 轴数据。
- `'o'`：用圆点标记数据点。
- 运行后三个数据点显示在图中。

进一步设置红色圆点：

```python
plt.plot(x, y, 'ro')
```

- `'r'` 表示红色。
- `'o'` 表示圆点标记。
- 也可以使用 `color='red'` 单独设置颜色；讲师说明两种写法都可以，格式字符串中颜色和标记的组合顺序在演示中没有问题。

再加上连线：

```python
plt.plot(x, y, 'ro-')
```

- `'ro-'` 表示红色、圆点标记，并用线连接。
- 运行后三个红色圆点之间出现连线。

以上三行是逐步演示：先只画点，再改成红色点，最后加点并连线。实际使用时可保留最终需要的那一种写法。

## 5. 设置 x 轴、y 轴标签

在 x 轴上添加标签使用：

```python
plt.xlabel('孙兴华')
```

运行后，x 轴下方显示“孙兴华”。

y 轴标签则把 `xlabel` 改成 `ylabel`：

```python
plt.ylabel('孙兴华')
```

要点：

- `plt.xlabel(...)`：设置当前子图的 x 轴标签。
- `plt.ylabel(...)`：设置当前子图的 y 轴标签。
- 轴标签的设置方式与标题类似，也可以继续设置字体颜色、字号等样式。
- 如果只是单纯设置字体、颜色，可以直接使用对应参数；如果要给标签加背景框，需要使用 `bbox` 字典。

## 6. 给轴标签添加背景框：`bbox`

### 6.1 使用字典传入 `bbox`

讲师强调：加背景框时，`bbox` 要以字典键值对的形式出现。建议单独写一个字典变量，结构更清楚：

```python
bbox = dict(facecolor='yellow', alpha=0.2, pad=50)
plt.xlabel('x轴标签', bbox=bbox)
```

也可以直接在参数中写：

```python
plt.xlabel(
    'x轴标签',
    bbox=dict(facecolor='yellow', alpha=0.2, pad=50)
)
```

其中：

- `bbox=`：设置文本背景框/边框的参数。
- `dict(...)`：构造字典，内部用“键=值”的形式形成键值对。
- 讲师提到基础篇讲过将序列转成字典的方法，这里重点是把 `facecolor`、`alpha`、`pad` 等以键值对形式传给 `bbox`。

### 6.2 `bbox` 中三个参数的含义

- `facecolor='yellow'`：背景框填充色为黄色。
- `alpha=0.2`：设置透明度为 0.2。
- `pad`：控制黄色背景框相对于文字的大小、留白程度。

### 6.3 `pad` 的大小演示

讲师将 `pad` 改成 50 进行演示，可以明显看到黄色背景框变大：

```python
bbox = dict(facecolor='yellow', alpha=0.2, pad=50)
plt.xlabel('x轴标签', bbox=bbox)
```

结论：

- `pad` 用来控制背景框的大小程度。
- 修改 `pad` 可以直观看到框的留白变化。
- 通过“修改参数并运行观察”的方式，比单纯记功能更容易理解参数作用。

## 7. 标题与子图重叠问题

把标题和子图放在一起显示时，讲师发现：

- 标题与上下方子图会发生遮挡。
- 放大窗口后可能稍微好一点，但这只是表面缓解。
- 如果图形内容变大，仍然可能遮挡。

解决方式有两种。

### 7.1 自动适应方法

讲师提到之前学过“自动适应”的方法，一般使用：

```python
plt.tight_layout()
```

特点：

- 自动调整布局，减少标题、轴标签与子图之间的重叠。
- 讲师表示自己一般使用这种自动适应方法。

### 7.2 手动调整边距与间距

也可以手动使用：

```python
plt.subplots_adjust(...)
```

课堂中演示了调整左侧距离、顶部距离、子图水平和垂直间距、底部距离等参数。按视频听写整理的示意为：

```python
plt.subplots_adjust(
    left=0.2,
    top=0.8,
    wspace=0.8,
    hspace=0.8,
    bottom=0.1
)
```

说明：

- `left`：左侧边距，视频中设置为 0.2。
- `top`：顶部边距，视频中围绕 0.8 左右进行调整。
- 与子图水平和垂直间距相关的参数会影响到“垂直高度和水平宽度”的留白，视频中演示值为 0.8 左右。
- `bottom`：底部边距，视频中先试了较大的值，发现底部距离太大，后来改为 0.1。
- 手动调整的具体数值需要根据画布大小、子图数量自行试调。

## 8. 关键结论与易混点

- `plt.title('孙兴华')` 用于给当前图添加标题。
- 标题样式常用参数：`fontsize` 控制字号，`fontweight='bold'` 控制加粗，`color='red'` 控制颜色。
- `plt.xlabel(...)` 设置 x 轴标签，`plt.ylabel(...)` 设置 y 轴标签。
- 轴标签与标题都可以设置字体样式；加背景框则使用 `bbox=dict(...)`。
- `bbox` 是字典参数，常用键包括：
  - `facecolor`：填充色。
  - `alpha`：透明度。
  - `pad`：背景框大小/留白程度。
- `plt.plot(x, y, 'ro-')` 中：
  - `r` 表示红色。
  - `o` 表示圆点标记。
  - `-` 表示连线。
- 标题或标签与子图重叠时：
  - 优先考虑 `plt.tight_layout()` 自动调整。
  - 需要精细控制时使用 `plt.subplots_adjust(...)` 手动调边距和间距。
- 手动调整参数值没有唯一答案，需要根据实际图形自行试调。
- `plt.title` 从对象角度设置的是当前 Axes 标题；在创建多个子图后，添加标题/轴标签要注意当前选中的是哪一个子图。
