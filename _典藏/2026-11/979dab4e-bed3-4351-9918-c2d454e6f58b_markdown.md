# 孙兴华 Python数据分析 Pandas 教程：分组与聚合 groupby 基础

## 1. 本节主题：分组聚合 groupby

- 本节学习 Pandas 中的分组聚合，核心对象是 `groupby`。
- 讲师用 Excel 的 `sumif` 作类比：`sumif` 可以理解为“按条件求和”。
- 但分组聚合不只是求和，还可以求：
  - 平均值
  - 中位数
  - 最大值、最小值
  - 方差、标准差
  - 计数、乘积、第一个值、最后一个值等
- 更准确的类比是 SQL 中的 `GROUP BY`：
  - 根据某个或某些字段分组；
  - 对每个组分别执行聚合运算；
  - 最后得到每个组对应的汇总结果。
- 分组聚合的典型三步：
  - 拆分：把相同分组键的数据放到同一组，例如中国一组、美国一组、日本一组。
  - 应用：对每个组分别求和、求平均、求中位数等。
  - 合并：把各组的计算结果组合成一个新的结果表。
- 在 Pandas 中，`DataFrame` 可以在行方向或列方向进行分组，并将函数应用到各分组，产生新的值。
- Pandas 的 `groupby` 与 SQL 的 `GROUP BY` 思路大同小异，但操作方式不同。

## 2. 常用聚合函数

讲师总结的常用聚合函数如下：

| 函数 | 作用 |
|---|---|
| `count` | 统计分组中非空值的数量 |
| `sum` | 计算非空值的和 |
| `mean` | 求平均值，相当于 Excel 中的 average |
| `median` | 求中位数 |
| `var` | 方差 |
| `std` | 标准差 |
| `max` | 最大值 |
| `min` | 最小值 |
| `prod` | 乘积 |
| `first` | 第一个值 |
| `last` | 最后一个值 |

- 中位数 `median` 的含义：
  - 将数据排序后取中间位置的值；
  - 奇数个数据取正中间；
  - 偶数个数据取中间两个数的平均值：\(\text{median}=\frac{x_{n/2}+x_{n/2+1}}{2}\)。
- 实际工作中最常用的是：
  - 计数 `count`
  - 求和 `sum`
  - 平均 `mean`
  - 最大 `max`、最小 `min`
  - 中位数 `median`
- 方差、标准差更多用于专业分析或特殊场景；普通业务分析中使用频率较低。涉及这些指标时需要概率统计基础。

## 3. 简单分组与聚合：分组聚合案例 1

### 数据说明

- 案例数据包含列：
  - 城市
  - 区域
  - 人数
  - 金额
- 城市列中故意同时写了“北京市”和“北京”，用于模拟真实数据中名称不统一的情况。
- 城市与区域存在对应关系，例如：
  - 北京市下面对应东城区、西城区等；
  - 天津市下面对应南开区、和平区等。
- 数据中城市分组会显示为多个，是因为城市与区域组合后形成了多组，例如北京对应多个区。

### 遍历分组：演示如何拿到各个分组

讲师先用 `for` 循环演示如何遍历分组：

- 按“城市”和“区域”两列分组：

  `for i, j in 数据.groupby(["城市", "区域"]):`

- 循环中打印分组键：

  `print(i)`

- 解释：
  - `i` 是分组键，按多列分组时通常表现为元组；
  - `j` 是该分组对应的子 `DataFrame`；
  - 这样可以观察每个分组由哪些数据组成。
- 讲师强调：
  - 这里只是演示“如何遍历各个分组”；
  - 实际做 Pandas 分组聚合时不推荐这样写 `for` 循环；
  - Pandas 中应尽量避免 `for` 循环，不到万不得已不要使用。
- 这种遍历方式可以用于生成每个分组带表头的分层展示结果，但不是常用写法。

### 基本分组聚合语法

最简单、最常用的分组聚合写法：

- 按城市、区域分组，对人数聚合：

  `数据.groupby(["城市", "区域"])[["人数"]].sum()`

- 同时对人数、金额聚合：

  `数据.groupby(["城市", "区域"])[["人数", "金额"]].sum()`

记忆规则：

- 按谁分组：写在 `groupby()` 的括号里；
- 对谁聚合：写在 `groupby()` 后面的中括号里；
- 用什么方式聚合：写在中括号后面的方法中，例如 `.sum()`。
- 多列分组时，分组键使用列表：
  - `["城市", "区域"]`
- 聚合列也建议统一写成“列表套列表”：
  - `[["人数"]]`
  - `[["人数", "金额"]]`
- 讲师建议统一写列表套列表，原因是：
  - 只聚合一列时，不写内层列表也能运行；
  - 但聚合两列时容易忘记加列表；
  - 统一写成 `[["列名"]]` 可以减少错误。

### 输出显示与导出 Excel

- 在 Jupyter 中直接打印分组聚合结果时，显示可能比较乱。
- 将结果导出到 Excel 后显示正常：

  `数据.groupby(["城市", "区域"])[["人数", "金额"]].sum().to_excel("001.xlsx")`

- 导出后可以看到：
  - 北京市下面对应东城区、西城区；
  - 天津市下面对应南开区、和平区；
  - Excel 中分组层级会自动合并单元格，显示结构更清楚。
- 讲师结论：
  - 这种简单的“分组 + 聚合”写法是大多数人最常用的方式；
  - 对普通数据分析通常够用；
  - 但如果做大数据分析，这种简单方式不够，需要继续学习更复杂的 `agg`、`level`、多层索引等用法。

## 4. 不同列使用不同聚合函数：`agg` 与字典

### 数据说明

第二个案例数据包含：

- 电号：有一位、两位、三位等不同长度的编号；
- 1月
- 2月
- 3月
- 4月

需求：

- 对 1 月这一列计数；
- 对 2 月这一列求和；
- 对 3 月这一列求最大值；
- 对 4 月这一列求平均值。

这种情况需要“不同列使用不同聚合函数”，建议使用字典配合 `agg`。

### 字典 + `agg` 写法

按讲解整理：

- 构造聚合字典：

  `agg_dict = {"1月": "count", "2月": sum, "3月": max, "4月": "mean"}`

- 按电号分组，使用字典聚合：

  `数据.groupby("电号").agg(agg_dict)`

等价写法：

- `数据.groupby("电号").agg({"1月": "count", "2月": sum, "3月": max, "4月": "mean"})`

### 函数是否需要加引号

讲师特别强调 Python 内置函数与 Pandas 方法的区别：

- `sum` 是 Python 内置函数，写入 `agg` 字典时不需要加引号：
  - `"2月": sum`
- `max` 是 Python 内置函数，不需要加引号：
  - `"3月": max`
- `count` 不是 Python 内置函数，而是 Pandas 中的聚合方法，需要加引号：
  - `"1月": "count"`
- `mean` 不是 Python 内置函数，需要加引号：
  - `"4月": "mean"`
- 在编辑器里可以通过颜色变化判断：
  - 写成 `sum`、`max` 后会变色，说明是 Python 内置函数；
  - 写成 `count` 后不变色，说明不是 Python 内置函数，需要加引号写成 `"count"`。
- 这一点是 `agg` 字典写法中的易错点。

### 输出结果理解

- 按电号分组后，各电号会得到对应统计结果。
- 例如 105 店没有重复记录，因此 `count` 结果为 1。
- 如果某个店有多条数据，例如一店有三条数据：
  - `count` 会告诉该组有几条数据；
  - `max` 会取该列三条数据中的最大值；
  - `min` 会取最小值；
  - `sum` 会对三条数据求和。
- 讲师强调：`agg` 是“基于列的聚合”，即指定每一列分别用什么方式聚合。

### `agg` 与 `groupby` 的区别

- `groupby`：主要解决“按行分组”的问题；
- `agg`：主要解决“基于列进行聚合计算”的问题；
- 当分组聚合涉及“不同列使用不同聚合函数”时，应优先考虑 `agg`。
- 简单统一聚合可以直接写：

  `数据.groupby("电号")[["1月"]].sum()`

- 不同列不同函数时使用：

  `数据.groupby("电号").agg(agg_dict)`

## 5. 使用字典做列映射：按月汇总到季度

### 业务场景

- 数据中有 1 月、2 月、3 月、4 月，以后可能还有更多月份。
- 需要把月份汇总为季度。
- 在 VBA、Power BI 中做季度汇总相对麻烦，例如 Power BI 中需要建时间表、写度量值。
- 在 Pandas 中可以直接用字典建立“月份到季度”的映射。

### 月份到季度的映射字典

按业务含义整理：

- 1 月、2 月、3 月属于一季度；
- 4 月、5 月属于二季度；
- 讲师口述时有一处口误，笔记按正确季度关系记录。

示例映射：

- `对应关系 = {"1月": "一季度", "2月": "一季度", "3月": "一季度", "4月": "二季度"}`

如果数据包含 5 月，则应补充：

- `"5月": "二季度"`

讲师说明：

- 他通常会在工作中维护常用映射字典；
- 例如月份对应季度、国家中英文名称对应等；
- 这类字典需要根据自己的单位、语言和数据规范自行总结；
- 不同单位使用的中文、英文、国家名称可能不同，无法提供通用字典。

### 使用 `groupby` 按列映射聚合

按月汇总到季度时，是按“列”进行分组聚合，需要指定 `axis=1`：

- `数据.groupby(对应关系, axis=1).sum()`

也可以使用 `agg`：

- `数据.groupby(对应关系, axis=1).agg("sum")`

说明：

- `axis=1` 表示按列方向操作；
- 字典的作用是把原列名映射到新的分组名，例如 1 月、2 月、3 月映射为“一季度”；
- 聚合后，原 1、2、3 月被合并为“一季度”，4 月对应“二季度”；
- 这样就把月份横向汇总为季度。
- 转录中语音识别为“alex”的地方，应理解为参数 `axis`，而不是 `alex`。

### 索引显示问题与 `index_col`

- 对电号分组求和后，如果结果中没有显示电号，原因是读取数据时没有告诉 Pandas 哪一列是索引。
- 解决方法：读取文件时设置 `index_col`，把电号设置为索引：

  `pd.read_excel("文件.xlsx", index_col="电号")`

或：

  `pd.read_excel("文件.xlsx", index_col=0)`

- 设置后，电号会成为索引，分组聚合结果中就会显示电号。
- 讲师提醒：
  - 分组聚合结果异常时，要检查索引设置；
  - 尤其是后面使用 `level` 按索引层级分组时，索引设置错误会直接导致分组聚合失败或结果不正确。

### 保存 `groupby` 对象的建议

讲师建议：

- 如果后续还要对该分组结果求平均、中位数等，不要每次重新写 `groupby`；
- 可以先保存分组对象，例如：

  `grouped = 数据.groupby("电号")`

- 然后在打印或后续计算时再调用聚合函数：

  `print(grouped.sum())`
  `print(grouped.mean())`
  `print(grouped.median())`

- 个人建议：
  - 如果只是求和，可以直接写 `.sum()`；
  - 如果同一分组要反复做不同聚合，最好先保存 `groupby` 对象，避免重复分组。
- 具体写法可根据实际情况决定。

## 6. 通过函数进行分组

### 场景：按城市名称字数分组

讲师构造了一个场景：

- 城市列中有“北京市”和“北京”；
- “北京市”是三个字，“北京”是两个字；
- 现在要按城市名称的字数长度进行分组聚合，相当于把两个字城市分一组、三个字城市分一组。

这类操作不常用，讲师也不建议作为主要写法，只作介绍。

### 关键前提：先把城市设置为索引

- 使用 `groupby(len)` 按索引标签长度分组时，`len` 会作用于索引。
- 因此必须先把城市列设置为索引，例如读取时：

  `数据 = pd.read_excel("文件.xlsx", index_col="城市")`

或在 DataFrame 上设置：

  `数据 = 数据.set_index("城市")`

- 然后按索引长度分组：

  `数据.groupby(len).sum()`

- 结果会按城市名称长度分组：
  - 两个字城市一组；
  - 三个字城市一组；
  - 分别统计人数、金额等数值列。
- 讲师强调：
  - 使用函数分组时，函数作用在索引上；
  - 一定要把用于分组的字段设置为索引；
  - 否则函数不知道要对谁计算长度，结果会不符合预期。

### 多个条件：按名称长度和指定城市分组

讲师又演示了一个不推荐的写法：

- 先手动指定每个店所在城市，例如构造列表 `s1`；
- `s1` 长度要与数据行数一致；
- 将店铺名称长度 `len` 和城市列表 `s1` 一起作为分组条件：

  `数据.groupby([len, s1]).sum()`

- 含义：
  - 先按店铺名称长度分组；
  - 再按 `s1` 中指定的城市分组；
  - 然后对数值列求和。
- 结果可以区分：
  - 两个字的店铺且在北京的汇总结果；
  - 三个字店铺且在北京的汇总结果；
  - 四个字店铺且在天津的汇总结果等。
- 讲师说明：
  - 这个功能不太实用；
  - 不推荐大家使用；
  - 只需了解即可；
  - 如果对函数比较熟悉，可以在此基础上自行发挥。

## 7. 通过索引层级 `level` 进行分组聚合

### 数据说明

案例数据包含：

- 班级
- 性别
- 语文
- 数学

可以理解为：

- 每个班男生的语文、数学平均分；
- 每个班女生的语文、数学平均分等。

需求：

- 按班级求中位数等聚合结果。

### 设置多层索引

需要使用 `level` 参数按索引层级分组，因此先要把班级、性别设置为索引。

可写成：

- `数据 = pd.read_excel("文件.xlsx", index_col=[0, 1])`

或：

- `数据 = 数据.set_index(["班级", "性别"])`

然后按班级层级求中位数：

- `数据.groupby(level="班级").median()`

说明：

- `level="班级"` 表示按索引中名为“班级”的层级分组；
- 聚合对象是后面的数值列，例如语文、数学；
- 如果有多层索引，`level` 可以直接指定层级名称。
- 讲师在案例中先用 `数据三 = 数据二` 保留数据，再做设置索引、按 `level` 聚合的演示。

### 为什么必须先设置索引

- 使用 `level` 时，Pandas 是从索引层级中取分组依据。
- 如果“班级”“性别”仍作为普通列存在，而不是索引，按 `level="班级"` 分组就无法正确执行。
- 设置索引后：
  - 班级、性别被“提升”为索引层级；
  - 后面的语文、数学保留为数值列；
  - 此时再按班级层级做 `median()`，才能正确按班级聚合。
- 讲师强调：
  - 分组聚合出现问题，尤其是使用 `level` 时，第一要检查索引是否设置正确；
  - 如果要按某个字段的层级分组，该字段必须已经是索引。
- 如果只对某一列聚合，可以显式指定列；
- 如果对所有剩余列聚合，则剩余列必须都是数值列，否则无法计算。

## 8. 多层列索引与按列层级聚合

### 案例数据结构

最后一个案例使用带双层表头的数据：

- 上层表头为季度；
- 下层表头为月份；
- 例如：
  - 一季度包含 1 月、2 月、3 月；
  - 二季度包含 4 月、5 月。

读取时要将两层表头都读入：

- `数据 = pd.read_excel("文件.xlsx", header=[0, 1])`

说明：

- `header=[0, 1]` 表示第 0 行和第 1 行共同作为列索引；
- 读取后得到多层列索引结构。

### 构造多层列索引

讲师设置两个列表：

- `l1`：表示季度层，例如一季度对应 1、2、3 月，二季度对应 4、5 月；
- `l2`：表示月份层，例如 1 月、2 月、3 月、4 月、5 月。

使用数组方式创建多层列索引：

- `数据.columns = pd.MultiIndex.from_arrays([l1, l2], names=["季度", "月份"])`

说明：

- `pd.MultiIndex.from_arrays([l1, l2], names=["季度", "月份"])` 创建多层列索引；
- `names` 参数给两个层级命名：
  - 第一层名为“季度”；
  - 第二层名为“月份”。

### 多层索引三种创建方式与不能使用笛卡尔积的原因

讲师回顾多层索引的三种创建方式：

- 数组方式：一对一对应，例如 a 对 1、a 对 2、b 对 1、b 对 2；
- 元组方式：一对一对应；
- 笛卡尔积方式：例如 a 对应所有的一、二，b 对应所有的一、二。

但本案例不能用笛卡尔积：

- 一季度下面对应 1、2、3 月；
- 二季度下面对应 4、5 月；
- 两个季度下面的子列数量不同；
- 笛卡尔积要求各层级组合数量规则一致；
- 因此这里应使用数组方式或元组方式。
- 讲师指出详细内容可查看笔记 15.2 中多层索引部分。

### 按列层级“季度”聚合

设置好多层列索引后，按季度这一列层级求和：

- `数据.groupby(level="季度", axis=1).sum()`

说明：

- `level="季度"` 指定按列索引中的“季度”层级分组；
- `axis=1` 表示按列方向操作；
- 聚合后，原来的一季度下的 1、2、3 月被横向合并为“一季度”；
- 二季度下的 4、5 月被合并为“二季度”；
- 原月份列在列方向上被汇总。

## 9. 关键结论与踩坑总结

- 分组聚合的核心思想是“拆分—应用—合并”：
  - 先按分组键拆分组；
  - 再对每组应用聚合函数；
  - 最后合并为结果表。
- Pandas 中 `groupby` 类似 SQL 的 `GROUP BY`；Excel 的 `sumif` 只是条件求和，不等于完整的分组聚合。
- 简单分组聚合的常用写法：
  - `数据.groupby(["分组列1", "分组列2"])[["聚合列1", "聚合列2"]].sum()`
- 记忆顺序：
  - `groupby()` 括号里写“按谁分组”；
  - `groupby()` 后面的中括号里写“对谁聚合”；
  - 最后写“怎么聚合”。
- 聚合列建议统一写成列表套列表：
  - `[["人数"]]`
  - `[["人数", "金额"]]`
- Pandas 中尽量避免 `for` 循环；遍历分组只适合演示或特殊处理。
- 不同列使用不同聚合函数时，使用字典 + `agg`：
  - `agg_dict = {"1月": "count", "2月": sum, "3月": max, "4月": "mean"}`
  - `数据.groupby("电号").agg(agg_dict)`
- 函数是否加引号要区分：
  - Python 内置函数 `sum`、`max` 可不加引号；
  - Pandas 聚合字符串 `"count"`、`"mean"` 要加引号。
- `agg` 是基于列的聚合，`groupby` 是分组操作；涉及不同列不同函数时优先使用 `agg`。
- 按列建立映射并聚合时使用 `axis=1`：
  - `数据.groupby(对应关系, axis=1).sum()`
- 如果聚合结果没有显示原编号，检查读取数据时是否设置了索引：
  - `index_col="电号"` 或 `index_col=0`
- 使用 `level` 按索引层级分组前，必须先把对应字段设置为索引：
  - `数据.set_index(["班级", "性别"])`
  - `数据.groupby(level="班级").median()`
- 使用 `level` 时，如果对所有剩余列聚合，必须保证剩余列都是数值列；否则应显式指定聚合列。
- 多层列索引按列层级聚合时使用：
  - `数据.groupby(level="季度", axis=1).sum()`
- 多层列索引构造时，不能用笛卡尔积的情况：
  - 当不同上层分组下的子列数量不一致时，例如一季度有 3 个月、二季度有 2 个月；
  - 应使用 `from_arrays` 或元组方式。
- 讲师建议：
  - 如果只对某一列聚合，最好显式按该列写聚合方式；
  - 如果对后面所有列统一聚合，才建议使用 `level` 标签方式；
  - 本节是 `groupby` 基础部分，下节课会讲进阶和实战演示。
