## 1. 课程回顾与图例使用原则

- 上节课学的是条形图，上上节课学的是柱形图，但之前示例都只有一条数据。
- 只有一条数据时，柱子通常只有一个颜色，不需要加图例；加图例属于多此一举。
- 有两条或多条数据时，必须加图例，否则读者不知道红色、蓝色分别代表什么。
- 分组柱状图用于多条数据对比。例如：
  - 第 1 年成绩用红色柱子表示；
  - 第 2 年成绩用蓝色柱子表示；
  - 通过并排柱子可直观看出第 2 年是否比第 1 年好。
- 商业分析中，多年柱形图通常需要排序：
  - 一般按最后一年、最近一年进行降序排序；
  - 最近一年最高的排在第一位；
  - 之前年份的数据只作为参考；
  - 例如示例中出现北丐、钟辰通、段智兴、黄药师等，即使黄药师前一年最厉害，今年下降后也要按今年数据排序。
- 排序原则的核心：看最近一年的数据，而不是看历史最高年份。

## 2. 数据准备与按第 2 年降序排序

- 示例数据包含三列：
  - 姓名；
  - 第 1 年成绩；
  - 第 2 年成绩。
- 先导入 `pandas` 和可视化库，并处理中文字体显示问题。
- 读取数据文件后，按照第 2 年成绩进行降序排序，并将排序结果应用到原数据上。
- 排序代码思路：
  - `df.sort_values(by='第2年', ascending=False, inplace=True)`
  - `ascending=False` 表示降序；
  - `inplace=True` 表示直接修改原数据。
- 排序后打印数据检查，确认排序正常。
- 中文字体处理常用写法：
  - `plt.rcParams['font.sans-serif'] = ['SimHei']`
  - `plt.rcParams['axes.unicode_minus'] = False`

## 3. 题外话：Series 与列表转换

- 获取姓名列有两种等价写法：
  - `df['姓名']`
  - `df.姓名`
- 二者完全等同，拿到的都是 `Series`。
- `Series` 中包含两个重要部分：
  - 索引；
  - 值。
- 学习 `pandas` 后，绘图不一定需要把 `Series` 转成列表；配合 `numpy` 后通常不需要多此一举。
- 如果确实要把 `Series` 转成列表，可以使用：
  - `df['姓名'].values.tolist()`
  - 或 `df.姓名.values.tolist()`
- 其中：
  - `.values` 取出 `Series` 中的值；
  - `.tolist()` 将值转换为 Python 列表。

## 4. 绘制分组柱状图：两组柱子

- 使用 `plt.bar()` 绘制柱状图。
- 分组柱状图需要画两次：
  - 第一次画第 1 年成绩；
  - 第二次画第 2 年成绩。
- 第一个柱子的关键参数：
  - `x`：柱子的 x 轴位置；
  - `height`：柱子的高度，即第 1 年成绩；
  - `color='red'`：第 1 年使用红色；
  - `width=width`：柱子宽度；
  - `label='第1年'`：图例标签。
- 设置一个宽度变量，例如：
  - `width = 0.3`
- 将宽度抽成变量的原因：
  - 后续两条柱子、刻度位置等会频繁使用宽度；
  - 如果直接写死 `0.3`，将来修改宽度要改很多地方；
  - 使用变量后只需改一次。
- 第二条柱子不能继续使用原来的姓名作为 x 坐标，否则会和第一条柱子重合。
- 正确思路：
  - 使用 `numpy` 生成数值索引；
  - 第一条柱子画在 `x`；
  - 第二条柱子画在 `x + width`；
  - 这样两条柱子并排显示、不重合。
- 生成数值索引：
  - `x = np.arange(len(df.姓名))`
  - `np.arange(5)` 会返回类似 `0, 1, 2, 3, 4` 的数组。
- 为什么不能直接拿姓名加宽度：
  - 姓名是字符串，字符串不能直接加数值 `0.3`；
  - 数值索引可以加宽度，因此要先转成数值索引。
- 第二条柱子关键参数：
  - x 坐标：`x + width`；
  - `height`：第 2 年成绩；
  - `color='blue'`：第 2 年使用蓝色；
  - `width=width`；
  - `label='第2年'`。
- 最后调用 `plt.show()` 显示图形。

## 5. 图例设置

- 两条数据必须显示图例。
- 在两次 `plt.bar()` 中分别写 `label`：
  - `label='第1年'`
  - `label='第2年'`
- 写完后必须调用：
  - `plt.legend()`
- 视频中演示：如果写了 `label` 但不调用 `plt.legend()` 显示图例，会出现报错/异常提示；补上后正常。
- 图例默认位置通常在右上角。
- 如果想改为左上角，可写：
  - `plt.legend(loc='upper left')`
- `loc` 参数用于控制图例位置；后续课程还会继续讲解图例位置设置。

## 6. x 轴刻度旋转与轴对象设置

- 如果人数较多，姓名刻度可能重叠，需要将姓名倾斜 45 度。
- 之前的方法可以旋转，但不能进一步详细设置对齐方式。
- 更详细的设置方法：
  - 先设置刻度位置和标签；
  - 再获取当前坐标轴对象；
  - 对轴对象设置刻度标签旋转角度与对齐方式。
- 代码思路：
  - `plt.xticks(x, df.姓名)`
  - `ax = plt.gca()`
  - `ax.set_xticklabels(df.姓名, rotation=45, ha='center')`
- 参数说明：
  - `plt.gca()`：获取当前坐标轴；
  - `rotation=45`：刻度标签旋转 45 度；
  - `ha='center'`：水平对齐方式为居中，表示以中心旋转；
  - `ha` 是水平对齐相关参数的缩写；
  - 也可以尝试 `left`、`right`，旋转后效果不同。
- 视频中强调：
  - 对轴进行设置时，要把旋转这句话写上；
  - 使用 `set_xticklabels` 设置旋转时，要配合 `rotation` 参数使用；
  - 如果不写，无法实现旋转或详细设置，可能报错。
- 旋转后姓名不再重叠，多条数据时也不会挤在一起。

## 7. 图形边距调整

- 一般图形主要设置左边距和下边距，其他边距可自动安排。
- 获取当前图形：
  - `fig = plt.gcf()`
- 调整子图边距：
  - `fig.subplots_adjust(left=0.1, bottom=0.3)`
- 参数含义：
  - `left=0.1`：图形离左边约 10% 的距离；
  - `bottom=0.3`：图形离下边约 30% 的距离。
- 运行后可看到图形位置发生变化，离左边和下边更远。
- 结论：
  - 对单个轴设置用 `plt.gca()`；
  - 对整个图形设置边距用 `plt.gcf()` 加 `subplots_adjust()`。

## 8. 完整代码骨架

```python
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# 中文字体处理
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 读取数据文件，按实际文件名和格式替换
df = pd.read_excel('数据文件.xlsx')

# 按第 2 年降序排序，并应用到原数据
df.sort_values(by='第2年', ascending=False, inplace=True)
print(df)

# 设置柱子宽度变量
width = 0.3

# 生成数值索引，用于分组柱状图
x = np.arange(len(df.姓名))

# 第一条柱子：第 1 年成绩
plt.bar(x, df['第1年'], color='red', width=width, label='第1年')

# 第二条柱子：第 2 年成绩，x 坐标向右偏移一个柱宽
plt.bar(x + width, df['第2年'], color='blue', width=width, label='第2年')

# 显示图例，默认右上角；左上角可写 loc='upper left'
plt.legend(loc='upper left')

# 设置 x 轴刻度标签
plt.xticks(x, df.姓名)

# 获取当前坐标轴，并设置刻度标签旋转和对齐方式
ax = plt.gca()
ax.set_xticklabels(df.姓名, rotation=45, ha='center')

# 获取当前图形并调整边距
fig = plt.gcf()
fig.subplots_adjust(left=0.1, bottom=0.3)

plt.show()
```

## 9. 关键结论与易错点汇总

- 单条数据柱形图不需要图例；多条数据必须加图例。
- 多年数据排序应优先按最近一年降序排列，历史年份只作参考。
- `Series` 不需要强制转列表；需要时用 `.values.tolist()`。
- 分组柱状图必须画两次 `plt.bar()`。
- 第二条柱子的 x 坐标要偏移 `width`，否则两条柱子会重合。
- 姓名不能直接加 `0.3`，要用 `np.arange(len(...))` 生成数值索引后再偏移。
- 柱宽用变量 `width` 统一管理，避免多处硬编码。
- `label` 写在 `plt.bar()` 中，`plt.legend()` 负责显示图例。
- `plt.legend(loc='upper left')` 可将图例放到左上角。
- 刻度旋转推荐先 `plt.xticks()`，再 `plt.gca().set_xticklabels(..., rotation=45, ha='center')`。
- `ha='center'` 表示以标签中心旋转，也可尝试 `left`、`right`。
- 单轴设置用 `plt.gca()`；整图边距设置用 `plt.gcf()` 和 `subplots_adjust()`。
- `left=0.1`、`bottom=0.3` 分别控制左、下边距。
