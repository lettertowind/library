## 一、课程定位与背景

- 本节主题是**离散化（Discretization）与分箱（Binning）**：把一串连续数字切成若干段。
- 分箱听起来复杂，但实际工作中经常做，类似 Excel、Power BI 中的 `SWITCH` 函数。
- 典型例子：按分数段评级、按年龄段统计用户、按年份划分人群。
- 视频示例：把年份数据按 `1950` 年前后划分，判断哪些人出生于 1950 年以前、哪些在 1950 年以后。
- 实际业务场景：运营商有数亿用户，需要统计 `0~15` 岁、`16~30` 岁、`30~45` 岁、`45` 岁以上各有多少人。
  - 用 SQL 完成需要写一大堆代码。
  - 用 Pandas 完成，两三行即可提取和统计。
- 讲师说明：Pandas 是针对大数据来使用的；机器学习中也会经常对数据进行分箱操作，本课先介绍入门用法。
- 本课分箱操作主要替代 Excel 中的 `SWITCH` 场景，当前阶段相对简单；到机器学习阶段会涉及更多函数和科学技术问题。

## 二、核心函数对比：`pd.cut` 与 `pd.qcut`

- `pd.cut` 和 `pd.qcut` 都可以进行分组分析操作。
- `pd.cut`：按照**数据的值**进行分割，需要指定分界点。
  - 例如按 `1950` 年以前、`1950` 年以后分割。
  - 根据指定的分界点，对一个连续的数据进行分箱操作。
- `pd.qcut`：根据**数据本身的数量**对数据进行分组。
  - 按指定箱子的数量，对连续数据进行分箱处理。
- 视频中讲师把 `qcut` 称为“等宽的分箱处理”，随后解释为**每个箱子里的数量相同**。
  - 术语提示：按常见 Pandas 说法，`qcut` 通常称为**等频分箱**或按分位数分箱；`cut` 按值区间分箱。这里保留视频说法并作区分。
- 分箱一定是对**一维数据**的操作，不能对整张表直接分箱。
  - 一维数据就是 `Series`。
  - 可以从整表中提取一行或一列，例如 `data['某一列']`。

对比表：

| 函数 | 分箱依据 | 关键参数 | 结果特征 | 典型用途 |
|---|---|---|---|---|
| `pd.cut` | 按数据的值、指定分界点 | 第一参数为一维数据；第二参数为分箱边界；`labels` 控制标签 | 返回每个值所属的区间；可用 `labels=False` 返回整数箱号 | 按业务阈值分箱，如年份、年龄、分数段 |
| `pd.qcut` | 按数据本身的数量、指定箱子数量 | 第一参数为一维数据；`q` 指定分箱数量 | 每个箱子的数据数量相同或尽量相同 | 按样本数量均分，如用户分层、数据等分 |

## 三、`pd.cut`：按指定分界点分箱

### 3.1 准备一维数据

- 分箱必须针对一维数据，不能直接对整表操作。
- 提取方式：在数据表后写中括号取某一列，例如 `data['年份']`，得到的就是一个 `Series`。
- 如果原始字段是生日，可用时间日期模块中的 `dt.year` 提取年份：
  - `data['生日'].dt.year`
  - 提取出年份 `Series` 后即可分箱。
- 视频示例的年份数据包括：`1992`、`1983`、`1922` 等。

### 3.2 指定分界点并执行分箱

- 视频示例设置分界点：`[1900, 1950, 2000]`。
- 这样会形成两个箱子：
  - `1900~1950`
  - `1950~2000`
- 讲师说明：`1900` 是 Excel 支持的最小年份，这里只是小案例。
  - 实际工作中不能机械地按 `1900~1950`、`1950~2000` 划分，必须按照业务逻辑确定分界点。
- 代码写法：

`结果 = pd.cut(年份, [1900, 1950, 2000])`

`print(结果)`

- 代码说明：
  - `pd.cut`：调用 Pandas 的 `cut` 函数。
  - 第一个参数 `年份`：要分箱的一维数据。
  - 第二个参数 `[1900, 1950, 2000]`：指定分界点，即分箱依据。
- 输出结果表示每个数据被分到哪个箱子里。
  - `1992` 在 `1950~2000` 这个箱子里。
  - `1983` 在 `1950~2000` 这个箱子里。
  - `1922` 在 `1900~1950` 这个箱子里。
  - 箱子的下标从 0 开始：0 号箱是 `1900~1950`，1 号箱是 `1950~2000`。
- 视频中列举：第一个数值在 1 号箱，第二个数值在 1 号箱，第三个数值在 0 号箱，第四个数值在 0 号箱，第五个数值在 1 号箱。

### 3.3 统计每个箱子的数据数量

- 分箱后，如果想统计每个箱子里有多少条数据，使用 `pd.value_counts`。
- `pd.value_counts` 表示“值的计数”。

代码：

`pd.value_counts(结果)`

- 也可以把分箱结果赋给一个对象，再把变量名传入 `pd.value_counts()`。
- 输出示例：
  - `1950~2000` 这个箱子里有 3 个数据。
  - `1900~1950` 这个箱子里有 2 个数据。

### 3.4 使用 `labels=False` 返回整数箱号

- 默认情况下，`pd.cut` 返回的是箱子区间名称。
- 如果想只返回每个数据对应的整数箱号，添加参数 `labels=False`。
- 视频字幕中的“levels”是口误/字幕误差，实际参数是 `labels`。
- 代码：

`pd.cut(年份, [1900, 1950, 2000], labels=False)`

- 参数说明：
  - `labels`：结果箱的标签。
  - 标签长度必须与结果长度相等。
  - `labels=False` 时，只返回整数指标，也就是箱号。
  - 不写 `labels` 时，直接返回箱子区间。
- 输出结果：
  - 0 号箱对应 `1900~1950`。
  - 1 号箱对应 `1950~2000`。
  - `1992` 在 1 号箱。
  - `1983` 在 1 号箱。
  - `1922` 在 0 号箱。
- 对箱号统计仍使用：

`pd.value_counts(结果)`

- 输出示例：
  - 1 号箱有 3 个数据。
  - 0 号箱有 2 个数据。

### 3.5 使用 `labels=箱子名称` 自定义箱名

- 如果不想显示箱号或区间，而是想显示业务名称，可以给箱子命名。
- 视频示例箱子名称：

`箱子名称 = ['50年代前', '50年代后']`

- 然后将箱子名称传给 `labels`：

`结果 = pd.cut(年份, [1900, 1950, 2000], labels=箱子名称)`

- 代码说明：
  - `labels=箱子名称` 后，结果中显示的是自定义名称。
  - 也可以直接把列表写进 `labels`，但讲师建议分开写，因为实际分析中箱子通常不止两个。
- 统计每个自定义箱子的数量：

`pd.value_counts(结果)`

- 输出示例：
  - `50年代后` 有 3 个数据。
  - `50年代前` 有 2 个数据。
- `labels` 的三种常见用法：
  - 不写 `labels`：返回箱子区间。
  - `labels=False`：只返回整数箱号。
  - `labels=自定义列表`：返回自定义箱名。

## 四、`pd.qcut`：按数量等分箱

- `qcut` 不需要指定箱子边界，只需要指定把数据分成几个箱子。
- 视频中称为“等频分箱/等宽分箱”，并解释为：每个箱子里的数量相同。
- 代码结构：

`结果 = pd.qcut(年份数据, q=箱子数量)`

- 参数说明：
  - 第一个参数 `年份数据`：要分箱的一维数据。
  - `q`：用整数或分类数组成的数组，指定所分箱的数量。
  - 例如分成两个箱子时，可理解为 `q=2`。
- 输出结果会按指定箱子数量对数据进行分箱。
- 从输出结果可以看到每个箱子的数量相同。
- 查询每个箱子的数量仍使用：

`pd.value_counts(结果)`

- 使用前要先明确：
  - 自己有多少条数据，可通过函数计算行数。
  - 要分成几个箱子。
  - 例如 10 个苹果分给 2 个箱子，每个箱子 5 个；分成 5 个箱子，每个箱子 2 个。
- 讲师强调：分箱数量要合理，应该先知道数据总数，再决定箱子数量，避免出现数量分配不合理的情况。
- 术语注意：
  - 视频原话称 `qcut` 为“等宽”，并解释为“每个箱子里的数量相同”。
  - 按常见术语，这更接近“等频分箱”；`cut` 则是按值区间分箱。

## 五、易混点、踩坑与结论

- `cut` 与 `qcut` 的核心区别：
  - `cut` 按数据的值、指定分界点分箱，适合业务阈值明确的场景。
  - `qcut` 按数据本身的数量、指定箱子数量分箱，适合按样本量均分。
- 分箱只能对一维数据操作：
  - 不能对整表直接分箱。
  - 需要先提取某一列，得到 `Series` 后再分箱。
- `labels` 参数易混：
  - 不写 `labels`：返回区间。
  - `labels=False`：返回整数箱号。
  - `labels=列表`：返回自定义箱名。
  - 自定义标签长度必须与结果长度一致。
- 如果只有两个箱子，用 `if` 语句也许能解决；实际分析中通常箱子较多，因此建议把箱子名称列表单独定义。
- 分界点必须按业务逻辑确定：
  - 视频中的 `[1900, 1950, 2000]` 只是演示。
  - 实际工作中应结合年份、年龄、合同类型、用户等级等业务规则划分。
- 有生日字段时，可先用 `dt.year` 提取年份，再对年份 `Series` 分箱。
- 本课的分箱操作相当于替代 Excel 中的 `SWITCH` 函数；机器学习阶段的分箱会更复杂。
