## 1. 导入 Pandas 库与别名 `pd`（00:10–00:50）

- 导入 Pandas 的基础写法：`import pandas`。
- 如果每次都写 `pandas.方法名` 会很麻烦，因此给 Pandas 设置别名。
- 与 NumPy 类似，Pandas 也常用两个字母作为别名：
  - `import pandas as pd`
- `pd` 是约定俗成的写法，不是强制规定：
  - 可以修改别名；
  - 讲师说甚至改成中文“熊猫”也没有关系；
  - 但建议使用通用别名，主要是为了方便书写和阅读。
- 调用形式为：`pd.方法名(...)`。
  - `pd` 代表 Pandas 库；
  - 点号后面的内容代表方法或对象。

## 2. Pandas 常用数据类型与新建文件方法（00:50–01:47）

- Pandas 支持的数据类型很多，但本课常用的是少数几种。
- 常用文件类型：
  - `csv`
  - `txt`
  - `excel`
  - `sql`
- `csv` 和 `txt` 的特点：
  - 都是纯文本文件；
  - 使用逗号分隔符或 table 分隔符保存。
- 讲师口述的新建文件方法：
  - CSV：`pd.to_csv`
  - Excel：`pd.to_excel`
  - SQL：`pd.to_sql`
  - 转录中出现的 “pd.two下划线circle” 是语音识别误差，按 Pandas API 应为 `to_sql`。
- 注意：讲师口述为 `pd.to_csv`、`pd.to_excel`、`pd.to_sql`，实际代码通常写在 DataFrame 对象后面，例如：
  - `data.to_csv(...)`
  - `data.to_excel(...)`
  - `data.to_sql(...)`
- 本课结论：
  - 知道 CSV、Excel、SQL 这三种文件的新建方法就足够了。
  - 像 JSON 等文件也许很常用，但不需要用这种方式在本课中新建。
  - CSV 与 TXT 同属分隔文本文件；本课重点演示 CSV，其他类型大同小异。

## 3. 为什么要在 Python/Pandas 中新建文件：学习基础的重要性（02:02–03:14）

- 有人会问：新建 Excel 文件直接打开 Excel 不是更方便吗？为什么要在 Python 里新建？
- 讲师明确承认：
  - 直接打开 Excel 新建确实更方便；
  - 如果是他自己，也可能不会专门在 Python 里新建一个空白 Excel。
- 但讲师用 VBA 学习经历说明基础学习的必要性：
  - 学 VBA 时，第二节课讲到 `if` 语句，有弹幕留言说“没必要学 VBA，直接在 Excel 里做就可以了”。
  - 如果将来有 100 张表都需要进行 `if` 语句判断：
    - 用 VBA 可以一个 `for` 循环配合 `if` 语句搞定；

- 讲师结论：

## 5. Pandas 两个核心数据结构：DataFrame 与 Series（03:56–05:06）

- 本课先简单介绍两个数据结构，第三节课会正式讲数据结构。
- `pd.DataFrame`：
  - 转录中的 “date from” 是 `DataFrame` 的语音识别误差；
  - 表示一张二维数据表；
  - 有行、有列；
  - 例如一张工作表、三行三列、五行五列，都叫二维数据表。
- `pd.Series`：
  - 转录中的 “serious” 是 `Series` 的语音识别误差；
  - 表示一行或一列的一维数据。
- 重要易混点：
  - `Series` 是一维数据，不是“一维数组”；
  - 一维数组只能说是一行，不能是一列；
  - 一维数据可以是一行，也可以是一列，都叫一维数据。
- 本节为了从简，使用一张表数据，也就是 `DataFrame` 来演示。

## 7. 新建 Excel 的同时写入数据（06:25–08:21）

- 目标：不是在新建后手动填数据，而是在新建文件的同时把数据写入工作表。
- 讲师先删除刚才生成的空白文档，再重新运行程序。
- 写入数据的位置：
  - 数据应写在 DataFrame 中；
  - 也就是写在“表”里，再导出到 Excel 工作表。
- 数据构造方式：使用字典键值对形式。
- 字典规则：
  - 字典的 key（视频称“k值”）作为列名；
  - 字典的 value 用列表表示该列的多个值；
  - 列表元素之间用逗号隔开；
  - 字符串值必须加引号；
  - 数值不需要加引号；
  - 字典的 key 是唯一的，作为列名；
  - value 可以重复，不是唯一的，例如姓名可以重复。
- 视频示例数据：
  - 列名“序号”，值为 `1`、`2`、`3`；
  - 列名“姓名”，值为三个姓名，按转录为“叶问、李小龙、新化”。
- 示意构造代码：`data = pd.DataFrame({"序号": [1, 2, 3], "姓名": ["叶问", "李小龙", "新化"]})`
- 然后导出到 Excel：`data.to_excel(path)`。
- 视频操作：
  - 把字典数据复制/写入 DataFrame；
  - 右键运行；
  - 新建成功；
  - 文件时间为 22.05；
  - 工作表中显示序号 1、2、3，姓名叶问、李小龙、新化，内容没有问题。

## 8. 处理 Excel 默认索引列：使用 `set_index`（08:21–10:17）

- 观察导出结果：
  - Excel 的 A 列多出一个索引列；
  - 该索引列的值从 0 开始；
  - 它不是字典中的业务字段列；
  - 这个默认索引列基本不需要。
- 原因：
  - DataFrame 默认带有索引；
  - 导出 Excel 时默认会把索引一起写入。
- 解决思路：
  - 指定哪一列作为我们的索引列；
  - 例如把“序号”指定为索引列；
  - 这样默认索引列就自然消失。
- 操作前先删除旧文件，回到 PyCharm 修改代码。
- 设置索引的代码：`data = data.set_index("序号")`
- 单词含义：
  - `set`：设置；
  - `index`：索引；
  - `set_index("序号")`：把“序号”字段设置为索引。
- 操作顺序很重要：
  - 先执行 `data = data.set_index("序号")`；
  - 再执行 `data.to_excel(path)`。
- 运行结果：
  - 22.06 重新生成文件；
  - 新文件不再有多余的默认索引列；
  - 内容正常。
- 踩坑结论：
  - 直接 `to_excel` 会带上默认的 0 起始索引列；
  - 如果不需要该默认索引列，可在导出前用 `set_index` 指定业务字段作为索引；
  - 本课采用“将序号设为索引列”的方式解决。

## 关键函数与表达式速查

| 表达式/函数 | 作用 | 说明 |
|---|---|---|
| `import pandas` | 导入 Pandas | 基础导入写法 |

| `pd.to_csv` / `pd.to_excel` / `pd.to_sql` | 讲师口述的导出方法简称 | 实际通常写在 DataFrame 对象后，如 `data.to_csv(...)` |
