本节接上一节字符串方法，继续讲解 Pandas 中 `Series.str` 的字符串处理，并演示正则表达式在 Pandas 字符串操作中的实际用法。正则表达式语法本身不展开，只讲如何在 Pandas 中调用。

## 0. 关键前置：日期列先转字符串

讲师反复强调：对日期型数据调用字符串方法前，必须先转换成字符串。

```python
df['日期'].astype(str).str.find('-')
```

- `.astype(str)` 才是类型转换。
- `.str` 不是转换，而是“字符串方法访问器”，用于调用 `str` 下的方法。
- 日期型数据如果不先 `.astype(str)`，不能直接使用 `.str` 方法。
- 固定流程：`Series.astype(str).str.方法(...)`。

## 1. `Series.str.get_dummies`：按分隔符拆分并生成哑变量

### 1.1 是什么
`Series.str.get_dummies(sep=...)` 可以将一列字符串按指定分隔符拆开，并把拆分后的每个 token 生成一个新的 0/1 指示列，返回 DataFrame。

常见示例数据为距离字段：

```text
近距离
远距离
中距离
中远距离
```

### 1.2 代码与参数
```python
df['距离'].str.get_dummies(sep='距')
```

- `sep='距'`：指定按照字符“距”进行分割。
- 每行原字符串会被拆分成列表。
- 拆分后出现过的 token 成为新列。
- 某行包含该 token 时值为 `1`，不包含时为 `0`。

### 1.3 示例理解
以“近距离”为例，按“距”分割后得到：

```text
['近', '离']
```

因此在结果中：

- “中”列可能为 `0`
- “远”列可能为 `0`
- “离”列为 `1`
- “近”列为 `1`

讲师解释：近距离中没有“中远”，也没有“远”，只有“离”和“近”，所以对应列分别为 0/1。

远距离按“距”分割后为：

```text
['远', '离']
```

因此：

- “远”为 `1`
- “离”为 `1`

中远距离、中距离同理，按分隔符拆分后，每个出现过的 token 在对应列上标记为 1。

### 1.4 用途与注意
- 适合把“一列中带多个标签”的文本展开成多个特征列。
- 讲师评价：这个功能平时可能用不着，但用到时“无可替代”。
- 注意这是 `Series.str.get_dummies`，不是普通的 `pd.get_dummies`。

## 2. 指定部分替换：`str.maketrans` + `str.translate`

### 2.1 目标
把“距离”字段中的“距”和“离”分别替换成指定内容，例如汉语拼音或其他字符。

### 2.2 代码
```python
table = str.maketrans({'距': 'ju', '离': 'li'})
df['距离'].str.translate(table)
```

- `str.maketrans({...})`：创建字符映射表。
- 字典以“原字符 → 替换后内容”的形式表示。
- `Series.str.translate(table)`：按映射表逐字符替换。
- 示例中可以把“距离”两个汉字分别替换成对应的拼音内容。

### 2.3 与 `replace` 的区别
- `str.translate` 是字符级映射，适合多个字符分别替换。
- `replace` 更像子串替换。
- 讲师说这种替换“跟 replace 的替换挺像”，但这里是按指定映射表逐字替换。

## 3. 查找指定字符第一次出现的位置

### 3.1 `str.find`
```python
df['日期'].astype(str).str.find('-')
```

- `str.find(sub)`：查找子串 `sub` 第一次出现的位置。
- 返回位置索引，索引从 `0` 开始。
- 示例日期形如 `2020-05-01`，第一个 `-` 的位置为 `4`：

```text
索引：0 1 2 3 4
字符：2 0 2 0 -
```

因此 `str.find('-')` 返回 `4`。

### 3.2 指定起始位置
```python
df['日期'].astype(str).str.find('-', 5)
```

- 第二个参数表示从哪个索引开始查找。
- 示例中从索引 `5` 开始找，会找到第二个 `-`，位置为 `7`。
- 讲师说明：查找范围可以设置起始值和结束值。

### 3.3 找不到时返回 `-1`
```python
df['日期'].astype(str).str.find('我')
```

如果不存在，返回 `-1`。

### 3.4 相关方法
- `str.rfind(sub)`：从右边开始查找。
- `str.index(sub)`：与 `find` 类似，但找不到会报错。
- `str.rindex(sub)`：从右边开始查找，找不到会报错。

易混点：

| 方法 | 方向 | 找不到时 |
|---|---|---|
| `find` | 从左往右 | 返回 `-1` |
| `rfind` | 从右往左 | 返回 `-1` |
| `index` | 从左往右 | 报错 |
| `rindex` | 从右往左 | 报错 |

## 4. 大小写转换

讲师在字符串收尾部分集中列出以下方法。

### 4.1 `str.lower()`
```python
df['列'].str.lower()
```
将所有英文字符转成小写。

### 4.2 `str.upper()`
```python
df['列'].str.upper()
```
将所有英文字符转成大写。

### 4.3 `str.title()`
```python
df['列'].str.title()
```
将每个单词的首字母变成大写。

### 4.4 `str.capitalize()`
```python
df['列'].str.capitalize()
```
只将整个字符串的第一个字母变成大写，后面字符不按单词首字母处理。

易混：

- `title()`：每个单词首字母都大写。
- `capitalize()`：只把整个字符串的第一个字母大写。

### 4.5 `str.swapcase()`
```python
df['列'].str.swapcase()
```
大小写互换：大写变小写，小写变大写。

## 5. 字符串判断方法

视频后段对字符串判断方法做了收尾串讲，不需要死记，使用时查笔记或视频即可。

### 5.1 字母判断
```python
df['列'].str.isalpha()
```
判断是否全是字母，返回 `True` / `False`。

### 5.2 数字判断
常见数字判断包括：

```python
df['列'].str.isdigit()
df['列'].str.isnumeric()
df['列'].str.isdecimal()
```

讲师强调它们识别范围有差异：

- 有的主要识别 Unicode 数字。
- 有的可以识别数字、罗马数字等更广范围。
- 有的可以识别汉字数字。
- 对普通阿拉伯数字，三种方法通常都可以解决。
- 实际项目中很少在同一列同时混用阿拉伯数字、罗马数字、汉字数字；如果真这样，数据本身的规范性就有问题。
- 技术岗位通常少用汉字数字，一个重要原因是排序不方便。
- 实际使用时应根据数据情况选择，不需要盲目追求最宽范围。

### 5.3 字母或数字判断
```python
df['列'].str.isalnum()
```
判断是否全是字母或数字，返回 `True` / `False`。

### 5.4 空格判断
```python
df['列'].str.isspace()
```
判断是否全是空格。

### 5.5 大小写格式判断
```python
df['列'].str.islower()
df['列'].str.isupper()
df['列'].str.istitle()
```

- `islower()`：是否全是小写。
- `isupper()`：是否全是大写。
- `istitle()`：是否符合标题格式，即每个单词首字母大写、其余小写。

讲师建议：这些方法不用背，记不住很正常，用到时查“孙兴华的笔记”或回看视频。

## 6. 正则表达式在 Pandas 字符串中的使用

讲师说明：本节不系统讲正则表达式语法，只讲如何在 Pandas 字符串方法中使用正则。正则表达式本身建议单独学习，否则后面很多工作做不了。

### 6.1 `str.match`：判断是否匹配某个模式

示例：

```python
df['状态'].str.match('..激', na=False)
```

或明确限定前两位为数字时：

```python
df['状态'].str.match(r'\d{2}激', na=False)
```

- `.` 表示任意字符。
- `{2}` 表示前面的模式重复两次。
- `..激` 表示前两个位置为任意字符，第三个位置为“激”。
- `\d` 表示数字，`\d{2}激` 表示前两位是数字，第三位是“激”。
- 返回布尔值：匹配返回 `True`，不匹配返回 `False`。

`na` 参数：

- `na=False`：将缺失值 NA 的结果转成 `False`。
- 也可以设置为 `True` 或其他指定值，视需求而定。
- 讲师演示了将 NA 转成 `False` 的操作。

易混：

- `str.match` 返回是否匹配。
- `str.extract` 用来提取捕获组内容。

### 6.2 `str.extract`：分组捕获

目标：从日期列中提取年、月、日，或只提取月份、日期。

代码示例：

```python
df['日期'].astype(str).str.extract(r'(\d{4})年(\d{1,2})月(\d{1,2})日')
```

- `()` 表示捕获组。
- `str.extract` 只提取括号中的内容。
- 没有加括号的部分只参与匹配，不会出现在结果中。
- 每个捕获组对应结果中的一列，列顺序按括号出现顺序排列。

例如模式：

```text
\d{4}年(\d{1,2})月(\d{1,2})日
```

其中“年”没有加括号，因此结果只返回“月”和“日”两个捕获组。

如果把“年”也加上括号：

```python
df['日期'].astype(str).str.extract(r'(\d{4})年(\d{1,2})月(\d{1,2})日')
```

则结果会分成三组：年、月、日，可以显示类似：

```text
2020  5  1
2020  5  2
```

如果只想保留“月”，可以只给月份部分加括号，例如：

```python
df['日期'].astype(str).str.extract(r'\d{4}年(\d{1,2})月\d{1,2}日')
```

结果只显示月份对应的数字。

关键点：

- `\d` 表示数字。
- `{4}` 表示四位。
- `{1,2}` 表示一到两位。
- `str.extract` 的返回结果只包含捕获组。
- 日期列操作前仍需先 `.astype(str)`。

### 6.3 `str.replace`：正则替换与反向引用

目标：把中国常见日期格式转换成国外常见顺序，例如把“年月日”顺序改成“日月年”顺序。

代码示例：

```python
df['日期'].astype(str).str.replace(
    r'(\d{4})-(\d{2})-(\d{2})',
    r'\3-\2-\1'
)
```

解释：

- `(\d{4})`：第 1 个捕获组，表示四位年份。
- `(\d{2})`：第 2 个捕获组，表示两位月份。
- `(\d{2})`：第 3 个捕获组，表示两位日期。
- `\1`、`\2`、`\3` 是反向引用，分别代表第 1、2、3 个捕获组。
- 替换串 `r'\3-\2-\1'` 表示把第 3 组放前、第 2 组居中、第 1 组放后，实现倒序。

示例：

```text
2020-05-01  ->  01-05-2020
```

如果想使用其他分隔符，可以把替换串中的 `-` 改成对应字符，例如：

```python
r'\3/\2/\1'
```

关键踩坑：

- 替换串中反斜杠必须使用原始字符串 `r''`。
- 如果不加 `r`，`\1`、`\2`、`\3` 可能被 Python 当作转义字符处理，导致结果不符合预期。
- 讲师演示时强调：需要加 `r` 让反斜杠保留为字面意义。
- 新版 pandas 中，`str.replace` 的正则行为可显式写 `regex=True`；视频中直接使用 `replace` 演示。
- 日期列在操作前仍然必须 `.astype(str)`。

## 7. 本节结论与学习建议

- 字符串方法很多，不需要全部背下来，重要的是知道有什么功能，用到时查笔记或回看视频。
