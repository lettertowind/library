## 1. 课程主题与回顾

- 本节课主题：在 `pandas` 中读取与修改 Excel 文件。
- 回顾上一阶段学习内容：
  - 新建 Excel 文件时使用的方法为 `to_excel`，即方法名中包含下划线：`to_excel`。
  - 本节读取 Excel 文件使用 `read_excel`。
- Excel 文件与 CSV 文件的区别之一：Excel 文件不存在分隔符问题，因此读取时不需要考虑 `sep` 等分隔符参数。
- 讲师强调：设置表头、读取 Excel 的方法不止一种，视频中展示了很多种方法，但本节只讲解并推荐其中最简单的一种；其他方法可以自学。

## 2. 读取 Excel 文件的基本流程

- 导入 `pandas` 库：
  - `import pandas as pd`
- 指定 Excel 文件路径，视频中的路径为：
  - `C:\pandas读取文件.xlsx`
  - 在 Python 中通常可写成原始字符串：`r'C:\pandas读取文件.xlsx'`
- 使用 `pandas` 读取数据：
  - `pd.read_excel(路径)`
- 打印读取结果以便查看：
  - `print(读取结果)`
- 在 IDE 中右键选择 `Run` 运行代码。
- 运行后内容可以成功读取出来。

## 3. 无表头 Excel 的默认读取问题

- 视频中的 Excel 文件本身没有表头。
- 当 Excel 没有表头时，`pandas` 默认会把第一行数据当作表头。
- 原表中第一列本来是索引列，但由于默认读取方式，`pandas` 又自动生成了一列索引，导致显示结果不符合预期。
- 因此需要解决两个问题：
  - 告诉 `pandas` 原文件没有表头。
  - 自定义表头，并指定某一列作为索引列。

## 4. 设置无表头与自定义表头

- 使用 `header` 参数控制表头：
  - `header=None`
- 关键点：
  - `None` 必须大写，不能写成小写 `none`。
  - 如果写成小写 `none`，会出错。
  - 在 IDE 中，正确的大写 `None` 会显示为橘红色，可作为检查提示。
- 使用 `names` 参数自定义表头。
- 视频中最终设置的表头字段为：
  - `['序号', '姓名', '年龄', '手机地址', '入职日期']`
- 转录中曾出现“录制日期”等表述，视频最后实际设置为“入职日期”。
- 读取逻辑可整理为：
  - `df = pd.read_excel(路径, header=None, names=['序号', '姓名', '年龄', '手机地址', '入职日期'])`
- 说明：
  - `header=None`：表示原 Excel 没有表头，不要让第一行数据充当列名。
  - `names=[...]`：手动指定列名，使读取后的 `DataFrame` 具有明确表头。

## 5. 安装 `xlrd` 模块的建议

- 讲师建议先安装 `xlrd` 模块。
- 原因：如果不安装，使用其他读取 Excel 的方法时可能会报错。
- 本节讲解的是最简单的方法，但为了让其他方法也能正常运行，建议预先安装 `xlrd`。
- 注意：转录中该模块名显示不清晰，按上下文应指 `xlrd`。

## 6. 指定索引列

- 使用 `index_col` 参数指定哪一列作为索引列。
- 视频中指定“序号”列作为索引列。
- 读取逻辑可整理为：
  - `df = pd.read_excel(路径, header=None, names=['序号', '姓名', '年龄', '手机地址', '入职日期'], index_col='序号')`
- 作用：
  - `index_col='序号'`：让“序号”列成为 `DataFrame` 的索引，而不是普通数据列。
- 运行后查看结果：表头设置完成，“序号”列成为索引列。

## 7. 将修改后的数据写回 Excel 文件

- 读取并修改数据后，需要把结果写回 Excel。
- 写回使用 `to_excel` 方法：
  - `df.to_excel(路径)`
- 视频中写回到同一个文件路径，即覆盖原 Excel 文件。
- 操作步骤：
  - 先打开原 Excel 文件查看，确认原文件没有被修改，仍然没有表头。
  - 在代码中执行 `df.to_excel(路径)`。
  - 右键 `Run` 运行。
  - 运行成功后再次打开原 Excel 文件。
  - 文件修改时间更新，视频中显示为 `21:04`。
  - 打开后可以看到已经写入“序号”“姓名”“年龄”“手机地址”“入职日期”等表头。
- 注意：
  - `to_excel` 会把当前 `DataFrame` 写入指定路径。
  - 如果路径相同，会覆盖原文件。
  - 写回前应确认路径正确，避免覆盖错误文件。

## 9. 关键函数与参数总结

- `pd.read_excel(路径)`：
  - 读取 Excel 文件并返回 `DataFrame`。
  - 用于从 Excel 导入数据。
- `header=None`：
  - 表示原文件没有表头。
  - 与 `names` 搭配使用，可避免第一行数据被误当作列名。
  - 注意 `None` 首字母大写。
- `names=[...]`：
  - 自定义列名。
  - 视频中设置为 `['序号', '姓名', '年龄', '手机地址', '入职日期']`。
- `index_col='序号'`：
  - 指定“序号”列为索引列。
  - 使该列不再作为普通数据列显示。
- `df.to_excel(路径)`：
  - 将 `DataFrame` 写回 Excel 文件。
  - 可覆盖原文件。
- `import pandas as pd`：
  - 导入 `pandas` 并简写为 `pd`。

## 10. 易混点与踩坑记录

- `header=None` 中的 `None` 必须大写：
  - 正确：`None`
  - 错误：`none`
  - 小写会导致运行出错。
- 无表头 Excel 如果不设置 `header=None`：
  - `pandas` 会默认把第一行数据当作表头。
- 原表第一列本来是索引：
  - 如果不设置 `index_col`，`pandas` 可能自动生成索引列，导致多出一列。
- `read_excel` 与 `to_excel` 方向相反：
  - `read_excel`：Excel → `DataFrame`
  - `to_excel`：`DataFrame` → Excel
- Excel 不需要考虑分隔符：
  - 与 CSV 读取不同，Excel 文件没有分隔符参数问题。
- `to_excel` 写回同一路径会覆盖原文件：
  - 操作前要确认路径和文件名无误。
- 日期列当前显示为日期加时间：
  - 属于后续数据格式处理内容，本节不展开。

## 11. 本节操作结论

- 读取 Excel 的基本命令是 `pd.read_excel`。
- 无表头 Excel 应使用 `header=None`，并用 `names` 自定义列名。
- `None` 必须大写，小写会报错。
- 使用 `index_col` 可以指定索引列，视频中指定“序号”列。
- 修改后的 `DataFrame` 使用 `to_excel` 写回 Excel。
- 写回同一路径会覆盖原文件，运行后原文件表头、索引等会按设置更新。
- 设置表头的方法很多，本节只讲最简单且推荐的一种；建议先安装 `xlrd` 模块，避免其他方法报错。
