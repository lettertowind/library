# Matplotlib 交叉填充与 `fill_between` 课程笔记

## 1. 课程主题与核心结论

- 本节课主题：**交叉填充**，即两条曲线交叉后，对交叉部分分别进行填充。
- 核心函数：`matplotlib.pyplot.fill_between`。
- 核心思路：先准备并绘制两条曲线，再使用 `fill_between` 按 `where` 条件分两次填充，不同条件使用不同颜色。
- 讲师强调：实现很简单，“多了一个参数而已”，关键就是 `where` 参数；填充时 `y1`、`y2` 都要设置。
- 本课只讲“怎么画图”；具体行业应用要结合数据分析知识，后续课程再讲。

## 2. 什么是交叉填充

- 定义：两条曲线发生交叉，把两条曲线之间的区域按交叉区间分别填充。
- 工作方式：用条件判断每一段区间内哪条曲线在上方。例如：
  - `y2 > y1` 时，填充一种颜色；
  - `y2 <= y1` 时，填充另一种颜色。
- 易混点：不是用一次 `fill_between` 同时完成两种颜色，而是按条件分开调用两次。
- 使用场景：讲师没有展开具体行业应用，因为不同行业应用不同；需要结合具体数据分析任务使用。

## 3. 数据准备与绘图顺序

- 使用 `numpy` 生成 x 轴数据。
- 生成两组曲线数据，变量名为 `y1`、`y2`；演示中为两条正弦曲线。
- 讲师提示：实际项目中通常数据来自 `pandas` 导出的 `csv` 或 `excel`，不需要照搬演示中的正弦曲线。
- 创建图形/画布，然后把 `x` 与 `y1`、`x` 与 `y2` 一起绘制到同一张图上。
- 讲师将两条曲线都设置为黑色。
- 运行后打开图形查看效果。

按讲解重建的绘图代码示例：

```
import matplotlib.pyplot as plt

plt.plot(x, y1, color='black')
plt.plot(x, y2, color='black')
```

说明：

- `plt.plot(x, y1, color='black')`：绘制 `x` 与 `y1` 的曲线，并设为黑色。
- `plt.plot(x, y2, color='black')`：绘制 `x` 与 `y2` 的曲线，并设为黑色。
- 讲师演示时在代码环境中打开并运行图形；转录中“pr t点上打开它”近似表示显示图形，可用 `plt.show()` 查看。

## 4. `fill_between` 交叉填充实现

- 函数：`fill_between`。
- 调用时需要给出：
  - `x`：横坐标数据。
  - `y1`：第一条曲线的 y 值，作为填充边界之一。
  - `y2`：第二条曲线的 y 值，作为另一条填充边界。
  - `where`：布尔条件，决定哪些区域参与填充。
  - 颜色参数：讲师口头提到颜色参数，转录近似为 `facecolor`；实际也可用 `color`。
- 讲师明确指出：填充时要分开填。
- 第一段填充：当 `y2` 的数据大于 `y1` 的数据时，填充绿色。
- 第二段填充：否则，即 `y2` 小于等于 `y1` 时，填充红色。

按讲解重建的填充代码示例：

```
plt.fill_between(x, y1, y2, where=(y2 > y1), facecolor='green')
plt.fill_between(x, y1, y2, where=(y2 <= y1), facecolor='red')
plt.show()
```

说明：

- `plt.fill_between(x, y1, y2, where=(y2 > y1), facecolor='green')`：在 `y2 > y1` 的区间内，用绿色填充两条曲线之间的区域。
- `plt.fill_between(x, y1, y2, where=(y2 <= y1), facecolor='red')`：在 `y2 <= y1` 的区间内，用红色填充两条曲线之间的区域。
- `plt.show()`：显示最终图形。运行后可看到两条曲线的交叉区域分别被填充为绿色和红色。

## 5. 关键注意与踩坑

- 先绘制两条曲线，再调用 `fill_between` 做填充。
- `fill_between` 中 `y1`、`y2` 两个边界都要传入，不能只传一条曲线。
- `where` 条件要覆盖所有需要填充的区间；两个条件应互补，避免漏填或重复填充。本案例使用：
  - `where=(y2 > y1)`
  - `where=(y2 <= y1)`
- 颜色要分别指定，否则两段填充无法区分。
- 交叉填充不一定人人用得到；讲师说明用不到可以跳过，用到时实现很简单。
- 演示用的正弦曲线只用于说明；实际应使用 `pandas` 导出的 `csv`、`excel` 等业务数据。
- 本课只讲绘图方法；具体应用需结合行业和数据分析知识，后续课程再讲。
