## 一、数据转置（行列转换）

### 场景说明

- 导入 Pandas 模块并读取指定路径下的文件。
- 读取后的原始数据列包括：`姓名`、`性别`、`语文`、`数学`、`英语`。
- 目标是把原始表的行和列互换：
  - 原来的行标签变成新的列标签。
  - 原来的列标签变成新的行标签。

### 推荐实现方式

讲师指出：网上转置方法很多，但推荐利用 NumPy 内置矩阵转置方法，再应用到 Pandas DataFrame 中。

核心代码：

- `数据二 = pd.DataFrame(数据.values.T, index=数据.columns, columns=数据.index)`

代码解释：

- `pd.DataFrame(...)`：重新构造一个 DataFrame。
- `数据.values`：取出 DataFrame 的底层数组/矩阵数据。
- `.T`：对矩阵做转置。
- `index=数据.columns`：新表的行索引使用原表的列标签。
- `columns=数据.index`：新表的列索引使用原表的行标签。

等价理解：

- 把原表的值转置后，再告诉 Pandas 新表的行标签和列标签分别是什么。
- 转置之后：
  - 原来的行就是现在的列。
  - 现在的列就是原来的行。

示例结构：

- 原表列：`姓名`、`性别`、`语文`、`数学`、`英语`
- 转置后：
  - 这些列名会变成行索引。
  - 原表的行索引会变成新的列名。

### 关键结论

- 推荐记住这一句核心写法：`pd.DataFrame(数据.values.T, index=数据.columns, columns=数据.index)`。
- 后面的 `index`、`columns` 是为了让转置后的表保留正确的行列标签。
- 方法不唯一，讲师说明如果更喜欢其他方式也可以，学习方式不强求。

## 二、环比计算

### 环比是什么

- 环比通常比较的是：
  - 上周与本周。
  - 上月与本月的业务数据。
- 在示例中，数据是一列日期、一列销售金额，日期为 1 月到 12 月。
- 计算 2 月环比，就是拿 2 月销售金额与 1 月销售金额比较。
- 计算 3 月环比，就是拿 3 月销售金额与 2 月销售金额比较。

环比公式：

- 环比增长额：  
  $\text{环比增长额} = \text{本期金额} - \text{上期金额}$
- 环比增长率：  
  $\text{环比增长率} = \frac{\text{本期金额} - \text{上期金额}}{\text{上期金额}}$

### 数据准备思路

如果原始数据不是每个月一行，需要先把数据整理成方便计算环比的结构：

- 先从日期中提取月份：`数据['日期'].dt.month`。
- 再按月份进行分组聚合，例如把同一个月的数据聚合到一起。
- 分组聚合后，只保留后续计算需要的列。
- 整理成类似“月份 + 销售金额”的结构后，再做环比。

讲师强调：

- 先分组聚合。
- 分组聚合之前先提取月份。
- 按月份分组聚合后，只保留需要的数据列。
- 表整理成目标结构后，后面计算环比只需要写两三行代码。

### 读取 Excel 工作表

示例中有多个工作表，例如 `sh1`、`sh2`，其中先操作 `sh1`。

读取 Excel 时：

- 第一个参数是文件所在路径。
- 第二个参数是工作表名。

示例：

- `pd.read_excel(路径, sheet_name='1')`
- 也可以省略关键字，直接写：
  - `pd.read_excel(路径, '1')`

参数说明：

- 直接写 `'1'` 叫位置参数。
- 写成 `sheet_name='1'` 叫关键字参数。
- 第二个参数如果不写关键字，就按位置传给工作表名参数。
- 讲师提醒：Python 基础中讲过位置参数和关键字参数，如果忘了要回头复习。

### 用 `shift()` 构造“上期金额”

讲师演示新增一个辅助列，把销售金额向下移动一行：

- `数据['上月销售金额'] = 数据['销售金额'].shift()`

作用：

- `shift()` 默认把数据向下移动一行。
- 这样 2 月所在行对应上一行就是 1 月金额。
- 3 月所在行对应上一行就是 2 月金额。
- 第一行会变成空值/`NaN`，因为第一个月没有上个月。
- 示例中第一个为空，后面依次出现上月金额。

如果需要转换数据类型，可以使用：

- `数据['销售金额'] = 数据['销售金额'].astype(float)`

说明：

- 使用 `astype(类型)` 可以把列转换为指定类型。
- 示例中可把金额转为数值类型，便于计算。

### 计算环比增长额

计算环比增长额：

- `环比增长额 = 数据['销售金额'] - 数据['上月销售金额']`

或者直接使用 `shift()`：

- `数据['环比增长金额'] = 数据['销售金额'] - 数据['销售金额'].shift()`

讲师说明：

- 计算环比时不一定需要先新建辅助列，可以用变量承接结果。
- 示例中讲师用变量保存计算结果，再新增列 `环比增长金额`。
- 重点是计算顺序：本期销售金额减去上期销售金额。

新增列示例：

- `数据['环比增长金额'] = 数据['销售金额'] - 数据['销售金额'].shift()`

### 计算环比增长率

环比增长率：

- `数据['环比增长率'] = 数据['环比增长金额'] / 数据['上月销售金额']`

或直接写：

- `数据['环比增长率'] = (数据['销售金额'] - 数据['销售金额'].shift()) / 数据['销售金额'].shift()`

公式对应：

- $\text{环比增长率} = \frac{\text{本期金额} - \text{上期金额}}{\text{上期金额}}$

讲师强调：

- 环比增长率就是环比增长额再除以上月金额。
- 这是比较基础的计算。

### 多城市环比：分组后调用自定义函数

示例 `sh2` 中有北京、上海两个城市，每个城市有 1 月到 12 月数据，需要分别计算两个城市的环比。

讲师给出的逻辑：

- 先按城市把北京和上海分开。
- 再按城市和月份排序，让北京 1 月到 12 月、上海 1 月到 12 月按顺序排列。
- 然后再按城市分组。
- 对每个分组调用自定义函数计算环比。

自定义函数示例：

- `def 公式(新数据):`
- `    新数据['环比'] = 新数据['金额'] - 新数据['金额'].shift()`
- `    return 新数据`

说明：

- 函数接收一个分组后的数据 `新数据`。
- 在组内用 `金额` 减去 `金额.shift()`。
- `shift()` 得到组内上一行金额。
- 返回补充了环比列的新数据。
- 计算顺序不能反：是本期金额减去 `shift()` 后的上期金额。

排序和分组调用示例：

- `数据二 = 数据.sort_values(by=['城市', '月份'])`
- `数据二 = 数据二.groupby('城市').apply(公式)`

说明：

- `sort_values(by=['城市', '月份'])`：先按城市、再按月份排序。
- `groupby('城市')`：按城市分组。
- `.apply(公式)`：对每个城市分组调用自定义函数。

结果理解：

- 上海 1 月没有环比，因为 1 月没有上一个月。
- 上海 2 月环比 1 月下降 8。
- 上海 3 月相对 2 月上涨 6。
- 如果要计算环比率，再用环比增长额除以上月金额即可。

### 环比部分关键结论

- 先整理数据：提取月份、分组聚合、保留必要列。
- 用 `shift()` 得到上一行/上期金额。
- 环比增长额 = 本期金额 - 上期金额。
- 环比增长率 = 环比增长额 / 上期金额。
- 多城市场景要先排序，再按城市分组，再用 `apply()` 调用函数。
- 计算方向不能反，必须用本期减上期。

## 三、同比计算

### 同比是什么

- 同比通常是与去年同期比较。
- 同比有很多实现方法，例如可以使用 `diff()` 等函数。
- 讲师说明：其他方法可以自行搜索学习，本节介绍一种简单、贴近 Excel 数据透视表思路的方法。

同比公式：

- 同比增长额：  
  $\text{同比增长额} = \text{本期金额} - \text{去年同期金额}$
- 同比增长率：  
  $\text{同比增长率} = \frac{\text{本期金额} - \text{去年同期金额}}{\text{去年同期金额}}$

### Excel 数据透视表思路

讲师先用 Excel 演示同比计算思路：

- 插入数据透视表。
- 把“电号”放到行上。
- 把“日期”放到列上。
- 日期中只保留“年”，删除季度、日期等层级，只留下 2018、2019 这样的年份。
- 把“金额”放到值区域。
- 聚合方式选择求和。
- 这样可以得到每家店铺 2018 年金额和 2019 年金额。
- 然后用 2019 年金额减 2018 年金额，得到同比增长额。
- 再用同比增长额除以 2018 年金额，得到同比增长率。

对应到 Pandas：

- 也可以用数据透视表 `pd.pivot_table` 实现同样结构。

### Pandas 提取年份

先从日期列中提取年份：

- `年 = 数据['日期'].dt.year`

说明：

- `dt.year` 用于从日期时间列中提取年份。
- 提取出的 `年` 变量后续作为数据透视表的列。

### 使用 `pd.pivot_table` 做数据透视

示例代码：

- `数据二 = pd.pivot_table(数据, index='电号', values='金额', columns=年, aggfunc='sum')`

参数解释：

- `数据`：要做透视的数据表。
- `index='电号'`：行标签使用“电号”，相当于 Excel 中把电号放到行上。
- `values='金额'`：值区域使用金额。
- `columns=年`：列标签使用前面提取的年份变量。
- `aggfunc='sum'`：聚合方式指定为求和。

重要注意：

- `pd.pivot_table` 默认聚合方式可能是平均值，所以必须明确指定 `aggfunc='sum'`。
- `columns=年` 中的 `年` 是变量，不能加引号。
- 如果写成 `columns='年'`，它会被当成字符串，不是变量。
- 透视后得到：
  - 行是电号。
  - 列是 2018、2019 年。
  - 单元格是各店铺对应年份的金额求和。

### 计算同比增长额与增长率

得到数据透视表后，行是电号，列是 2018、2019 年金额。

同比增长额：

- `数据二['同比增长额'] = 数据二[2019] - 数据二[2018]`

同比增长率：

- `数据二['同比增长率'] = (数据二[2019] - 数据二[2018]) / 数据二[2018]`

说明：

- 如果只算同比增长额，不除以 2018 年金额。
- 如果算同比增长率，需要再除以 2018 年金额。
- 如果透视后的列名是字符串类型，则按实际列名写成 `数据二['2019']`、`数据二['2018']`。
- 讲师口述示例结果约为 1.441% 点四五，具体以实际运行结果为准。

### 同比部分踩坑与注意事项

- 如果一个 Excel 文件中有多个工作表，读取时必须指定对哪个工作表进行操作；不指定可能报错或读错表。
- 如果变量被定义为 `年`，在 `pivot_table` 中引用时不要给变量加引号；加引号会变成字符串。
- `pd.pivot_table` 默认聚合方式不是求和，必须加 `aggfunc='sum'`。
- 如果数据透视后出现多余的列/表，可能是工作表选择或数据源不明确导致；可以删除多余工作表，或明确指定目标工作表。
- 做透视表时要沿用 Excel 数据透视表的思路：行放“电号”，列放“年”，值放“金额”，聚合方式为求和。

## 五、课程总结

- 数据转置推荐使用 `pd.DataFrame(数据.values.T, index=数据.columns, columns=数据.index)`，核心是矩阵转置后重新设置行列标签。
- 环比计算的关键是先用 `shift()` 得到上期金额，再用本期金额减上期金额，最后按需除以上期金额得到增长率。
- 多城市环比要先排序，再按城市分组，再用 `apply()` 调用自定义函数。
- 同比计算可以沿用 Excel 数据透视表思路：先提取年份，再用 `pd.pivot_table` 按电号、年份、金额做求和透视，最后用 2019 年金额与 2018 年金额计算同比增长额和增长率。
- 关键注意点：
  - `pd.pivot_table` 默认聚合方式可能不是求和，必须指定 `aggfunc='sum'`。
  - 变量作列名时不要加引号。
  - Excel 有多个工作表时要指定工作表。
  - 计算顺序不能反，务必用本期减上期或本期减去年同期。
- 讲师建议把这些方法多应用到实际工作中。
