## 2. 叠加区域图概念
- 是什么：在折线图中，把一条折线到 x 轴之间区域涂上颜色；再把该折线到下一条折线之间区域涂上另一种颜色，形成类似面积图的叠加效果。
- 怎么工作：为每条折线设置填充区域，核心是确定 x 范围、下限、上限。
- 与折线图对比：折线图主要显示时间趋势和点；叠加区域图还可以显示整体占比/比重，例如在 10~20 区间一眼看出谁占比更大。
- 与普通面积图/折线图易混：普通折线只画线；面积图强调面积；叠加区域图是多区域叠加，颜色会受透明度影响。
- 什么时候用：既要看趋势，又要比较不同类别在整体中的比重时。

## 3. 核心函数 `plt.fill_between`
- 调用形式：`plt.fill_between(x, y1, y2, ...)`
- 参数：
  - 第一个参数：覆盖区域的 x，示例为时间数据（x 轴）。
  - 第二个参数：覆盖下限；示例中为 `0`，表示从 x 轴开始向上覆盖。
  - 第三个参数：覆盖上限；第一条线时为蔬菜线数据；第二条线可设为水果线数据，并把下限改为蔬菜线数据。
  - `facecolor`：填充颜色。
  - `alpha`：透明度，示例为 `0.3`。
- 转写中口述的 `p l t点fill_between` 即 `plt.fill_between`。

## 4. 两条折线的叠加区域操作
### 4.1 第一条区域：x 轴到蔬菜折线
```python
plt.fill_between(时间, 0, 蔬菜数据, facecolor='red', alpha=0.3)
```
- 第一个参数 `时间`：覆盖区域 x 轴。
- 第二个参数 `0`：下限为 0，从 x 轴往上填充。
- 第三个参数 `蔬菜数据`：上限到蔬菜折线停止。
- `facecolor='red'`：填充红色。
- `alpha=0.3`：透明度为 0.3。
- 运行效果：从底部到蔬菜折线之间出现红色区域。

### 4.2 第二条区域：从蔬菜线到水果线
- 若直接复制第一条并只把上限改成水果线，下限仍为 0：
```python
plt.fill_between(时间, 0, 水果数据, facecolor='green', alpha=0.3)
```
- 问题：绿色区域从 0 开始，会和红色区域重叠；两个透明度 30% 的颜色叠加，下面区域变成中间色，类似 Photoshop 两个图层叠加（红色 30% + 绿色 30%）。
- 正确做法：若希望绿色只出现在蔬菜线与水果线之间，把下限改为蔬菜线：
```python
plt.fill_between(时间, 蔬菜数据, 水果数据, facecolor='green', alpha=0.3)
```
- 解释：从蔬菜线开始，到水果线结束，只填充两条线之间的区域。

### 4.3 只保留两条线之间的颜色
- 需求：不要底部到蔬菜线的颜色，只要蔬菜线与水果线之间的颜色。
- 做法：不设置底部区域，把第一条 `fill_between(时间, 0, 蔬菜数据, ...)` 注释掉，只保留第二条：
```python
# plt.fill_between(时间, 0, 蔬菜数据, facecolor='red', alpha=0.3)
plt.fill_between(时间, 蔬菜数据, 水果数据, facecolor='green', alpha=0.3)
```
- 结论：下边不填充、只保留中间部分填充，即可得到两条折线之间的区域色。

## 5. 高亮区域演示
### 5.1 导入库并构造随机数据
```python
import numpy as np
import matplotlib.pyplot as plt

x = np.arange(30)          # 视频口述为 0~29；等价于 np.array(range(30))
y = np.random.rand(30)     # 生成 30 个随机 y 数据
```
- `x`：x 轴数据，0~29。
- `y`：随机 y 数据。
- 说明：numpy 构造数据不熟也没关系，本课重点是 `fill_between` 的用法。

### 5.2 定义需要高亮的区间列表
```python
highlight = [[1, 6], [10, 12], [20, 23], [26, 28]]
```
- 大列表里套若干小列表；每个小列表表示一个高亮区间。
- 示例区间：1~6、10~12、20~23、26~28（口述区间；实际切片边界见下）。

### 5.3 先画红色折线
```python
plt.plot(x, y, 'r')  # 'r' 表示红色
plt.show()
```
- 先画出 x-y 随机折线，此时尚未使用高亮列表。

### 5.4 遍历区间列表并填充高亮
```python
for i in highlight:
    plt.fill_between(
        x[i[0]:i[1]],      # x 区间：i[0] 为起点，i[1] 为终点
        0,                 # 下限：从底部 0 开始
        y[i[0]:i[1]],      # 上限：对应的 y 数据
        facecolor=...,     # 填充颜色，按演示设置
        alpha=...          # 透明度，按演示设置
    )
```
- `for i in highlight`：遍历大列表中的每一个小列表。
- `i[0]`：小列表下标 0，即区间起点。
- `i[1]`：小列表下标 1，即区间终点。
- `x[i[0]:i[1]]`：取对应 x 数据切片，区间为 `$[i[0], i[1])$`。
- `0`：填充下限从 0/底部开始。
- `y[i[0]:i[1]]`：取对应 y 数据作为填充上限。
- `facecolor`：填充颜色；`alpha`：透明度。
- 以第一个区间 `[1, 6]` 为例：`i[0]=1`，`i[1]=6`，代码取 `x[1:6]` 与 `y[1:6]`；按 Python 切片规则右端不包含，实际取下标 1 到 5。讲师口述为“数据 1 到数据 6 之间”的高亮区间，写代码时需注意切片边界。
- 运行后，四个区间会出现高亮区域。

### 5.5 高亮演示组合示意
```python
import numpy as np
import matplotlib.pyplot as plt

x = np.arange(30)
y = np.random.rand(30)
highlight = [[1, 6], [10, 12], [20, 23], [26, 28]]

plt.plot(x, y, 'r')

for i in highlight:
    plt.fill_between(
        x[i[0]:i[1]],
        0,
        y[i[0]:i[1]],
        facecolor='yellow',  # 示意颜色；视频中按演示设置
        alpha=0.3            # 示意透明度；视频中按演示设置
    )

plt.show()
```
- 颜色和透明度为示意值；视频重点是 `fill_between` 的参数顺序、区间切片和遍历方式。

## 6. 易错点与结论
- 第二条区域若从 0 开始，会与第一条区域重叠并混合颜色；若只想填充两条线之间，必须把下限改为下方折线数据。
- 颜色叠加类似图层叠加：`alpha` 透明度会让重叠区域产生中间色。
- 只保留两条线之间颜色时，注释掉底部到第一条线的 `fill_between`，只留中间区域填充。
- 高亮区域依赖列表遍历与下标：`i[0]` 是起点，`i[1]` 是终点，`x[i[0]:i[1]]` 与 `y[i[0]:i[1]]` 必须对应。
- Python 切片右端不包含；口述区间“1 到 6”与代码 `1:6` 的边界要分清。
- 讲师建议：光听没用，多操作几遍；若列表遍历、下标、区间 `i[0]:i[1]` 不明白，需要回看基础篇知识。

## 7. 本课核心记忆
- 叠加区域图核心：`plt.fill_between(x, 下限, 上限, facecolor=..., alpha=...)`。
- 第一条线：下限 `0`，上限第一条折线。
- 第二条线：下限第一条折线，上限第二条折线。
- 只要中间区域：不画底部到第一条线的填充。
- 高亮区间：`for` 遍历区间列表，对每个区间调用 `fill_between`，下限 `0`，上限对应 `y` 切片。
