## 1. 课程目标与核心概念

- 本节主题：在 Matplotlib 中新增“子图”或“子区域”。
- **子图（subplot）**：在一张画布 `Figure` 上按网格划分出多个图，例如一张画布上放“图一”和“图四”。前面课程已经使用过，例如 `fig.add_subplot(...)`。
- **子区域（画中画）**：在一个已经存在的图/轴内部，再套一个小的图/轴。类似 90 年代电视的“画王”功能：主画面中再显示一个小画面。
- 子区域不是“平均线”这类图内元素，而是**另一个轴（Axes）**，例如在主柱状图中再画一个饼图或折线图。
- 本节重点函数：
  - `plt.figure()`：创建画布。
  - `fig.add_subplot(nrows, ncols, index)`：按网格添加子图。
  - `fig.add_axes([left, bottom, width, height])`：按矩形位置添加轴/子区域，可用于画中画。
  - `Axes.bar()`：绘制柱状图。
  - `Axes.plot()`：绘制折线图。
  - `Axes.set_title()`：设置图标题。

## 2. 回顾：使用 `add_subplot` 新增子图

讲师先回顾之前学过的子图添加方法，目标是让大家同时掌握两种方式：`add_subplot` 和后续的 `add_axes`。

- 创建画布：
  - 使用 `plt.figure()` 得到画布对象，通常命名为 `fig`。
  - 课程中导入方式对应常用写法：`import matplotlib.pyplot as plt`。
- 添加“图一”：
  - 使用 `fig.add_subplot(2, 1, 1)`。
  - 参数含义：`2` 表示 2 行，`1` 表示 1 列，最后一个 `1` 表示第 1 个子图。
  - 将返回的轴对象赋给变量，例如 `图一`。
- 在“图一”上绘图：
  - 使用 `图一.bar(数据点)` 绘制柱状图。
- 再添加“图四”：
  - 使用 `fig.add_subplot(2, 2, 4)`。
  - 参数含义：`2` 行、`2` 列、第 `4` 个图，即第二行第二列。
  - 视频中强调“图四”是第二行第二列的第四个图。
- 在“图四”上绘图：
  - 同样调用 `bar` 绘图。
- 讲师演示时出现一个复制代码后未改变量/文字的问题：
  - 两张图都画成功了，但有一处文字没有改成“图四”。
  - 修正后显示正常。
  - 结论：复制绘图代码后，要同步修改变量名、标题等文字，避免沿用前一个图的内容。

示意代码：

```python
import matplotlib.pyplot as plt

fig = plt.figure()

图一 = fig.add_subplot(2, 1, 1)
图一.bar(数据点)          # 绘制柱状图
图一.set_title('销售量')  # 视频中后续为图一设置标题

图四 = fig.add_subplot(2, 2, 4)
图四.bar(数据点)
```

- 这一部分说明：**在一张画布上添加多个子图**的方法已经掌握。
- `add_subplot` 的核心是按“行、列、序号”的网格方式添加图。

## 3. 子区域的概念：画中画

- 讲师用“画王”解释子区域：
  - 90 年代电视中流行“画中画”，即主画面中有一个小区域显示另一个频道。
  - Matplotlib 中的子区域类似：一个图中再套另一个图。
- 示例理解：
  - 假设外面已经有一个主图。
  - 在主图内部再做一个饼图、折线图或其他图。
  - 这就叫“子区域”或“画中画”。
- 实现子区域时会涉及“另一个轴”的问题：
  - 主图本身是一个轴。
  - 内部小图是另一个轴。
  - 必须告诉 Matplotlib：小图相对外部图的位置在哪里。
- 需要确定的小图位置信息：
  - 左边位置：`left`。
  - 下边位置：`bottom`。
  - 自身宽度：`width`。
  - 自身高度：`height`。
- 这四个参数用于确定小图在画布/外部图中的位置和大小。

## 4. 使用 `add_axes` 创建子区域

### 4.1 基本流程

讲师给出的实现逻辑：

- 先创建画布：`fig = plt.figure()`。
- 拿到画布后，先添加一个轴。
- 因为子区域涉及另一个轴，所以要用 `add_axes` 指定轴的位置。
- `add_axes` 接收一个列表，列表中有四个值：
  - `left`：左侧位置。
  - `bottom`：底部位置。
  - `width`：自身宽度。
  - `height`：自身高度。
- 讲师给出的一组示意值：
  - `left = 0.1`
  - `bottom = 0.1`
  - `width = 0.8`
  - `height = 0.8`
- 讲师强调 Python 基础篇学过的赋值方法：
  - `a, b, c, d = [0.1, 0.1, 0.8, 0.8]`
  - 分别对应 `left=0.1`、`bottom=0.1`、`width=0.8`、`height=0.8`。

示意代码：

```python
fig = plt.figure()

图一 = fig.add_axes([0.1, 0.1, 0.8, 0.8])
```

- 这里 `图一` 是通过 `add_axes` 返回的轴对象。
- 后续绘图不再调用 `add_subplot`，而是直接在 `图一` 这个轴上绘图：
  - `图一.bar(数据点)`
- 视频中先运行验证：图一能够正常生成。
- 然后继续画图，也没有问题。

### 4.2 为外部大图设置标题

- 讲师为图一设置标题，标题文字为“销售量”。
- 使用轴对象的标题设置方法，对应代码可写为：

```python
图一.set_title('销售量')
```

- 设置标题后，外部大图与内部小图之间会有位置和显示上的差异，因此需要继续设置内部小图的位置。

## 5. 添加内部小图：图二

### 5.1 再次使用 `add_axes` 指定小图位置

- 在已有“图一”的基础上，再添加“图二”作为内部子区域。
- 方法仍然是使用 `add_axes`，并传入列表形式的位置参数。
- 讲师说明：设置内部子图时，还要设置“子图的位置”。
- 内部小图的位置由以下因素决定：
  - 距外部大图的距离。
  - 距外部大图下边/左边的距离。
  - 小图自身的宽度和高度。
- 讲师在视频中直接复制并调整参数，口述“0.65 就行了”“差不多了”，说明位置参数可以凭视觉感官调整。
- 视频中完整四元组未逐一慢慢念出，笔记中给出示意参数，实际使用时需要根据显示效果微调。

示意代码：

```python
图二 = fig.add_axes([0.65, 0.65, 0.2, 0.2])
```

- 该代码表示在画布偏右上的位置新增一个小轴。
- 实际四元组可按视觉效果调整：
  - 调整 `left`、`bottom` 改变小图位置。
  - 调整 `width`、`height` 改变小图大小。

### 5.2 在内部小图上绘图

- 添加图二后，先不画图，运行查看：
  - 能显示出来一个小图区域。
  - 说明小图位置参数已经生效。
- 然后开始绘图：
  - 使用 `图二.plot(...)` 绘制折线图。
  - 视频中示例数据与“第二毛利率”有关。
- 为图二设置标题：
  - 标题文字为“毛利率”。

示意代码：

```python
图二.plot(数据第二毛利率)
图二.set_title('毛利率')
```

- 运行后效果：
  - 外部大图显示柱状图，标题为“销售量”。
  - 内部小图显示折线图，标题为“毛利率”。
  - 形成“图中套图”的子区域效果。

## 6. 完整示例代码结构

以下代码按视频讲解顺序还原整体逻辑，变量名沿用讲师使用的中文写法；实际项目中可替换为 `ax1`、`ax2` 等英文变量名。

```python
import matplotlib.pyplot as plt

# 1. 创建画布
fig = plt.figure()

# 2. 创建外部大图：使用 add_axes 指定 [left, bottom, width, height]
图一 = fig.add_axes([0.1, 0.1, 0.8, 0.8])

# 3. 在外部大图上绘制柱状图
图一.bar(数据点)

# 4. 为外部大图设置标题
图一.set_title('销售量')

# 5. 在外部大图区域内新增内部小图：画中画
# 示意参数：实际可按视觉感官调整
图二 = fig.add_axes([0.65, 0.65, 0.2, 0.2])

# 6. 在内部小图上绘制折线图
图二.plot(数据第二毛利率)

# 7. 为内部小图设置标题
图二.set_title('毛利率')
```

## 7. 关键注意事项与结论

- `add_subplot` 与 `add_axes` 的用途不同：
  - `add_subplot(nrows, ncols, index)`：按网格添加子图，例如 `2,1,1`、`2,2,4`。
  - `add_axes([left, bottom, width, height])`：按矩形位置添加轴，适合做子区域、画中画。
- `add_axes` 的四个参数必须理解清楚：
  - `left`：左侧位置。
  - `bottom`：底部位置。
  - `width`：宽度。
  - `height`：高度。
- 做套图时，外部大图如果没有显式设置位置、宽高，Matplotlib 可能会给默认值。
- 但内部小图必须明确设置：
  - 距外部图下边的距离。
  - 距外部图左边的距离。
  - 自身宽度。
  - 自身高度。
- 讲师强烈建议的顺序：
  1. 先确定外部大图。
  2. 再确定内部小图。
- 不建议按旧思路“先随便做出一张图，再往图里套”：
  - 这样可能会报错。
  - 当前阶段按讲师给出的逻辑走更稳妥。
- 位置参数不是固定死值，可以反复运行、凭视觉感官调整到合适位置。
- 复制代码时要注意修改变量名和标题文字，否则容易出现“图四仍显示图一文字”的问题。
- 本节最终实现效果：一张主图内嵌套一个小图，主图可画柱状图，小图可画折线图或饼图，从而形成 Matplotlib 的子区域/画中画。
