# Python 双端队列 `deque` 学习笔记

## 摘要

本文档依据视频转录整理，聚焦 Python `collections.deque` 的创建、双端增删、访问修改、旋转与容量限制。转录中出现的“堆”“甲板”“deck”等表述均指 `deque`（double-ended queue，双端队列）。`deque` 可视为栈与队列的一般化，支持从左右两端添加和弹出元素，双端操作性能大致相同（视频标题强调 `O(1)` 双端操作），并具备线程安全与内存高效特性。

## 导入与创建

- 导入方式：`from collections import deque`。
- 类型提示：`from typing import Any`。
- 创建空 deque：`d: deque[Any] = deque()`，打印结果为空的 deque。
- 使用可迭代对象初始化：`d = deque([1, 2, 3])`，打印结果为包含这些数字的 deque。
- 创建时可指定任意所需值或数据类型；变量名可按需调整，并非必须。

## 添加元素

- `append(x)`：在右端添加单个元素。示例：`d.append(4)` 后打印得到包含四个数字的 deque。
- `appendleft(x)`：在左端添加单个元素，这是 deque 相对普通 list 的常用特性。示例：`d.appendleft(5)`。
- `extend(iterable)`：在右端批量扩展元素，接受一个可迭代对象。示例：`d.extend([10, 11, 12])`。
- `extendleft(iterable)`：在左端批量扩展元素，元素插入到 deque 开头。示例：`d.extendleft([13, 14, 15])`。按逐个 `appendleft` 的语义，最终左侧顺序通常与输入顺序相反。

## 删除、弹出与清空

- `pop()`：删除并返回最右端元素。示例：`removed = numbers.pop()` 可取得被删除值并使用该值。
- 空 deque 调用 `pop()` 会报错，因为不能从空 deque 中弹出元素。
- `popleft()`：删除并返回最左端元素。示例：从包含 `1, 2, 3` 的 deque 左端弹出后得到 `1`，deque 剩余 `2, 3`。
- `remove(value)`：删除指定值。示例：`numbers.remove(2)`；若指定值不存在，则触发 `ValueError`。
- `clear()`：清空 deque。示例中所有人离队后，打印结果为空 deque。

## 访问与修改

- 索引访问：`d[2]` 可获取索引为 2 的元素，行为与其他可迭代对象基本一致。
- 不支持切片：对 deque 执行切片会触发 `TypeError`。若需切片，可先转换为支持切片的数据类型，例如 `list(d)[1:3]`。
- `insert(index, value)`：在指定索引处插入元素。示例：将 `George` 插入索引 1 后，其排在第二位。
- `count(value)`：统计某个特定元素在 deque 中出现的次数。示例：统计 `bob` 得到 1 次。
- `reverse()`：原地反转 deque 中元素的顺序。示例：反转为 `Sandra` 在前、`Bob` 在后。

## 旋转 `rotate`

- `rotate(n)` 用于旋转 deque 中的元素；元素到达一端末尾后会被移动到另一端。
- 按视频描述，正数表示从左到右/顺时针旋转；负数表示逆时针旋转。
- 示例：`rotate(-1)` 后 `Bob` 到队尾并重新排队；`rotate(-2)` 表示逆时针旋转两个位置；`rotate(2)` 表示顺时针旋转两个位置。
- 可通过 `clear()` 清空队列，示例中热狗摊关闭后所有人离开，打印为空 deque。

## 容量限制 `maxlen`

- 创建固定容量 deque：`deque(maxlen=4)` 可限制最大长度为 4。
- 当 deque 已满时，继续添加元素会自动从另一端移除旧元素，以维持长度限制。
- `append` 在右端添加时，若已满则左端旧元素被移出；`appendleft` 在左端添加时，若已满则右端旧元素被移出。
- 示例：`guests = deque(maxlen=4)`；添加 `Charlotte` 后保持 4 个元素；再 `append("James")` 后 `Bob` 消失；随后 `appendleft("Bob")` 导致 `James` 被推出；`extend(["Chad", "Karen"])` 批量添加后迫使原有两人离开。
- 无论执行何种添加操作，deque 始终维持最多 4 个元素。

## 结论

- 在 Python 中需要处理栈或队列时，`deque` 是最佳选择之一。
- 其优势包括：双端添加/弹出性能接近、线程安全、内存高效。
- 内存优化效果依场景而定：某些场景下可能带来明显优化，某些场景下与 list 相近；视频未深入展开基准测试。
- 核心 API 覆盖：`append`、`appendleft`、`extend`、`extendleft`、`pop`、`popleft`、`remove`、`insert`、`count`、`reverse`、`rotate`、`clear` 以及 `maxlen`。
