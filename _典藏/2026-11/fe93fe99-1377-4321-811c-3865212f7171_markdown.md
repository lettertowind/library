# Numpy 神奇索引（Fancy Indexing）课程笔记

## 1. 神奇索引概念

- **神奇索引**：使用**整数数组**进行数据索引。
- 索引数组中的每个整数，表示原数组中的下标；返回“对应下标的一组数”。
- 下标从 **0** 开始。
- 与普通索引的关系：普通索引可用标量、切片等；神奇索引把多个下标放进整数数组中，一次取出多个元素。
- 易混点：
  - 这里使用的是**整数数组**，不是布尔数组。
  - 二维数组中，一个索引数组通常表示“行”；两个索引数组时，分别表示“行”和“列”，并按位置一一配对。
  - 两个索引数组不是做笛卡尔积，而是逐项配对取值。

## 2. 一维数组的神奇索引

- 定义一维数组：

  `a = np.array([3, 6, 7, 9, 5, 2, 7])`

- 下标对应关系：

  - `0 -> 3`
  - `1 -> 6`
  - `2 -> 7`
  - `3 -> 9`
  - `4 -> 5`
  - `5 -> 2`
  - `6 -> 7`

- 使用整数索引数组 `[2, 3, 5]`：

  `a[[2, 3, 5]]`

- 取值过程：

  - `a[2] = 7`
  - `a[3] = 9`
  - `a[5] = 2`

- 返回结果：

  `array([7, 9, 2])`

- 注意：讲师口述中的“235”指的是**索引数组/下标**，不是最终取出的元素值；最终元素由原数组 `a` 决定。
- 结论：一维数组中，神奇索引就是按照整数数组中的下标批量取值。

## 3. 二维数组：一个索引数组取整行

- 生成 0~35 共 36 个数，并变为 9 行 4 列：

  `arr = np.arange(36).reshape(9, 4)`

- 课堂中用于分隔输出的代码：

  `print('-' * 30)`

  作用：字符串 `'-'` 乘以 30，会输出 30 个横线；Python 中字符串乘整数表示重复字符串。

- 使用索引数组 `[4, 3, 0, 6]`：

  `arr[[4, 3, 0, 6]]`

- 含义：取第 4 行、第 3 行、第 0 行、第 6 行，每个都是整行。
- 对应结果行：

  - 第 4 行：`[16, 17, 18, 19]`
  - 第 3 行：`[12, 13, 14, 15]`
  - 第 0 行：`[0, 1, 2, 3]`
  - 第 6 行：`[24, 25, 26, 27]`

- 结论：二维数组中只给一个整数索引数组时，默认按行取，返回指定行组成的数组；行号从 0 开始。

## 4. 二维数组：两个索引数组取对应元素

- 生成 0~31 共 32 个数，并变为 8 行 4 列：

  `arr = np.arange(32).reshape(8, 4)`

- 目标：取第一行第 0 列、第五行第 3 列、第七行第 1 列、第二行第 2 列。
- 行索引数组：

  `[1, 5, 7, 2]`

- 列索引数组：

  `[0, 3, 1, 2]`

- 表达式：

  `arr[[1, 5, 7, 2], [0, 3, 1, 2]]`

- 配对过程：

  - 第 1 行第 0 列：`arr[1, 0] = 4`
  - 第 5 行第 3 列：`arr[5, 3] = 23`
  - 第 7 行第 1 列：`arr[7, 1] = 29`
  - 第 2 行第 2 列：`arr[2, 2] = 10`

- 返回结果：

  `array([4, 23, 29, 10])`

- 关键结论：
  - 两个索引数组时，逗号前是行索引，逗号后是列索引。
  - 两个数组按位置一一配对：第 1 个行索引配第 1 个列索引，第 2 个配第 2 个……
  - 不是把行数组和列数组两两组合成矩阵。
  - 这个规则与前面基础索引中“逗号前是行、逗号后是列”的理解一致。

## 5. 二维数组：所有行 + 指定列

- 仍用 36 个数生成 9 行 4 列：

  `arr = np.arange(36).reshape(9, 4)`

- 目标：取所有行的第 1 列和第 2 列，不要第 0 列。
- 写法：

  `arr[:, [1, 2]]`

- 解释：
  - 逗号前的 `:` 表示所有行。
  - 逗号后的 `[1, 2]` 是列索引数组，表示取第 1 列和第 2 列。
  - 第 0 列不取。

- 结果规律：
  - 第 1 列：`1, 5, 9, 13, 17, 21, 25, 29, 33`
  - 第 2 列：`2, 6, 10, 14, 18, 22, 26, 30, 34`
  - 每行取出两列，最终得到 9 行 2 列的结构。

- 结论：神奇索引可与切片组合使用，`:` 负责取全部行，整数数组负责指定列。

## 6. 一维数组配二维索引数组的易混示例

- 生成 0~9：

  `arr = np.arange(10)`

- 生成一个整数索引数组，课堂板书示例按“零二、一三”理解：

  `idx = np.array([[0, 2], [1, 3]])`

- 执行：

  `arr[idx]`

- 现象：取出结果与索引数组数值看起来相同，为：

  `[[0, 2], [1, 3]]`

- 原因：原数组本身就是 `0~9`，用这些下标取出来的值恰好等于下标数值。
- 讲师强调的易混点：
  - 一维数组没有二维数组那种“行索引 + 列索引”的配对概念。
  - 用整数数组索引时，返回结果仍由原数组中被选中的元素组成，形状由索引数组决定。
  - 本例“看起来返回索引本身”是因为原数组值与下标相同，不要误认为神奇索引会返回索引数组。
  - 记忆：能按索引从原数组取值时，取的是原数组元素；一维场景重点看索引数组的形状和下标。

## 7. 拓展：取数组中最大前 n 个数

- 生成 10 个 1~100 之间的随机整数：

  `arr = np.random.randint(1, 100, 10)`

- 获取排序后的下标：

  `idx = arr.argsort()`

- `argsort()` 作用：返回数组排序后的下标数组；默认升序，不直接返回排序后的值。
- 取最大的 3 个下标：

  `idx = arr.argsort()[-3:]`

- 原因：默认升序排序，排序后最后三个下标对应原数组中的最大值。
- 用神奇索引取出最大值：

  `arr[idx]`

- 示例结果：讲师演示中最大三个数为 `85, 89, 91`。
- 讲师说明：
  - 这部分属于拓展知识，涉及尚未系统学习的方法，不要求完全掌握。
  - 需要理解：`argsort()` 得到的是下标，再把下标交给数组，即可用神奇索引取出对应元素。

## 8. 本课结论清单

- 神奇索引使用**整数数组**作为索引。
- 下标从 **0** 开始。
- 一维数组：`a[[i, j, k]]` 取对应下标元素。
- 二维数组只给一个索引数组：按行取整行。
- 二维数组给两个索引数组：行数组和列数组按位置配对取单个元素。
- 取所有行的部分列：`arr[:, [列索引...]]`。
- 两个索引数组不是笛卡尔积，而是逐项配对。
- 返回结果形状通常由索引数组形状决定；二维取整行时还会保留原数组的列维度。
- 用 `argsort()` 可先得到排序下标，再用神奇索引取最大或最小若干元素。
