## 1. 课程主题与背景

- 本节主题：**叠加柱状图 / 堆积柱状图（stacked bar chart）**，也常被口述为“堆积条形图”。
- 图形特点：每个 x 轴分类上只有一根柱子，但柱子由多个数据系列逐层堆叠而成，用来同时观察**总量**和**各层构成**。
- 应用场景：非常常用；例如每个学生的“语文 + 数学 + 英语”总分及单科构成。
- 本课核心难点：**数据标签位置很头疼**。柱子画出来并不难，难在把每层的数值标签放到合适位置。
- 讲师对比 Python 与 Excel/VBA 作图：
  - Excel/VBA 里点几下就能做图，操作方便。
  - Python 做图需要写代码，但适合大数据处理。
  - Pandas 处理大数据时，不管数据多大，可能只显示几行；但画图时可以瞬间出图。
  - Excel 打开 1GB 文档都可能打不开，电脑受不了；Python 更适合这种场合。
  - 结论：工具应用场合不同，不能只比较“点两下方便”。
- 本课目标：用 Matplotlib 的 `plt.bar()` 配合 `bottom` 参数逐层堆叠，并设置 x 轴标签、图例、y 轴范围、网格线和数据标签。

## 3. 第一层柱状图：语文

- 第一条柱状图先画语文。
- 基本代码结构：
  ```python
  plt.bar(x, data['语文'], color='red', label='语文')
  ```
- 参数说明：
  - 第 1 个参数 `x`：x 轴位置，由 `np.arange` 生成。
  - 第 2 个参数 `data['语文']`：柱子的高度，即语文分数。
  - `color`：柱子颜色，讲师强调这是必须设置的参数之一。
  - `label`：图例标签，也是必须设置的参数之一，后续 `plt.legend()` 会使用。
- 运行后第一条柱子可以正常出现，但 x 轴没有姓名标签。
- 设置 x 轴标签：
  ```python
  plt.xticks(x, data['姓名'])
  ```
  - 第 1 个参数是刻度位置 `x`。
  - 第 2 个参数是刻度文本 `data['姓名']`。
  - 作用：把每个柱子的位置对应到学生姓名。
- 讲师强调：
  - 日常作图直接用 NumPy 数组、Pandas Series 或 DataFrame 列即可。
  - 不需要先把数据转成 Python 列表。
  - 网上很多示例先把数据转成列表，是因为示例变量可能本身就是列表，例如 `x`、`y`；真正做数据分析、作图时通常不会多此一举。
- 第一层柱子的起点默认是 0，也就是从 x 轴底部开始。

## 4. 第二层柱状图：数学与 `bottom` 参数

- 第二条柱子画数学。
- 关键参数：`bottom`。
  - `bottom` 表示条形图的**起始位置**，即下一层柱子从哪个高度开始画。
  - 第一层语文从底部 0 开始。
  - 第二层数学不能从 0 开始，而要从语文柱子的顶部开始。
- 代码结构：
  ```python
  plt.bar(x, data['数学'], bottom=data['语文'], color='green', label='数学')
  ```
- 工作方式：
  - 语文考了 80 分，数学考了 50 分，则数学层从语文的 80 分高度处再往上画 50 分。
  - 这样每个学生的柱子总高度会变成“语文 + 数学”。
- 运行后：
  - 总高度范围大致从 0 到 200。
  - 第二层正确叠在语文上方。
- 易混点：
  - 普通柱状图如果不设置 `bottom`，所有系列都从 0 开始，会重叠或并排，不是堆叠。
  - 堆叠柱状图必须让后一层从上一层结束位置开始。
- 第二层标签后续要注意：标签应放在数学层内部，定位时要使用“语文 + 数学”的累计高度。

## 5. 第三层柱状图：英语与累计 `bottom`

- 第三条柱子画英语。
- 英语层要放在“语文 + 数学”的上方，因此 `bottom` 需要写成前两层之和：
  ```python
  plt.bar(x, data['英语'], bottom=data['语文'] + data['数学'], color='blue', label='英语')
  ```
- 参数说明：
  - `data['英语']`：英语层高度。
  - `bottom=data['语文'] + data['数学']`：英语层起始位置为前两层累计高度。
  - `color='blue'`：讲师将第三层设置为蓝色。
  - `label='英语'`：图例标签。
- 运行后：
  - 三种颜色正常显示。
  - 每个柱子的总高度变为“语文 + 数学 + 英语”，范围到 300 左右。
- 结论：
  - 第一层 `bottom` 默认为 0。
  - 第二层 `bottom = 语文`。
  - 第三层 `bottom = 语文 + 数学`。
  - 层数更多时，继续累加前面所有层的高度。

## 6. 图例设置：`plt.legend()`、`loc`、`ncol`

- 三种颜色画完后，需要加图例。
- 基本代码：
  ```python
  plt.legend()
  ```
- 默认效果：
  - 图例通常显示为一列三行。
  - 位置为 Matplotlib 默认位置。
- 讲师希望：
  - 图例居中。
  - 横排显示为“一行三列”，而不是“一列三行”。
- 设置居中：
  ```python
  plt.legend(loc='center', ncol=3)
  ```
- 参数说明：
  - `loc='center'`：图例位置居中。
  - `ncol=3`：图例分为 3 列，从而形成一行三列。
- 讲师补充：
  - 图例位置还可以设置为靠上、靠下、靠左、靠右、左上、右上、居中靠左、居中靠右等。
  - 这些位置单词不认识的可以百度翻译。
  - 字体、字号等也可以另行修改，本课不展开。

## 7. y 轴刻度范围：`plt.ylim()`

- 当前第三层画完后，y 轴刻度大约显示 0 到 300。

- 作用：控制图形显示范围，突出数据区间或留出标签空间。

## 9. 数据标签：`plt.text()` 逐层添加

### 9.1 为什么要加数据标签

- 不加标签时，只能大概看出柱子高度，具体每层是多少不方便。
- 尤其是第二层、第三层，靠肉眼猜不准确。
- 因此需要把每层数值写在柱子内部。

### 9.2 第一层语文标签

- 使用 `for` 循环遍历语文数据，设置 `x1`、`y1`。
- 代码思路：
  ```python
  for x1, y1 in zip(x, data['语文']):
      plt.text(x1, y1, str(y1), color='blue', fontsize=20, ha='center')
  ```
- `plt.text()` 参数说明：
  - 第 1 个参数 `x1`：文本的 x 坐标。
  - 第 2 个参数 `y1`：文本的 y 坐标。
  - 第 3 个参数 `str(y1)`：要显示的文字，把数值转换成字符串。
  - `color`：文字颜色。
  - `fontsize=20`：文字字号。
  - `ha='center'`：水平对齐方式为居中。转录中讲师口述“center”，需要设置到水平居中参数上。
- 初始问题：
  - 如果直接用 `y1` 作为 y 坐标，文字会显示在红色柱子的顶部附近，甚至落到下一层区域。
  - 讲师实际运行后指出，这样会写到绿色层里面，位置不对。
- 调整方法：
  - 把 y 坐标往下减一点，例如：
    ```python
    plt.text(x1, y1 - 10, str(y1), color='y', fontsize=20, ha='center')
    ```
  - 如果还不够，可以再减 20，或继续微调。
  - 这是讲师所说的“偷懒的办法”：不精确计算层高一半，只把坐标下移一点，让文字落在柱子内部。
- 颜色调整：
  - 讲师一开始设置蓝色，觉得不好看，后改为黄色，代码中可写 `color='y'`。
- 精确居中的难点：
  - 若想把每个标签严格放在每层柱子的正中间，需要计算层高的一半。
  - 例如语文层中心可近似为 `y1 / 2`；数学层中心要基于累计高度和数学层高计算。
  - 讲师指出这比较麻烦，本节先用“减偏移量”的偷懒方法，后续再讲更高深方法。

### 9.3 第二层数学标签

- 第二个标签不能只遍历语文数据。
- 因为数学标签要放在数学层内部，定位坐标应基于“语文 + 数学”的累计高度。
- 讲师口述思路：
  - 设置 `x2`、`y2`。
  - 遍历“语文 + 数学”：
    ```python
    for x2, y2 in zip(x, data['语文'] + data['数学']):
        plt.text(x2, y2 - 10, str(data['数学'].iloc[x2]), color='y', fontsize=20, ha='center')
    ```
- 解释：
  - `y2` 是数学层顶部对应的累计高度。
  - `y2 - 10` 是把文字从累计顶部向下移动一点，放进数学层内部。
  - 文本值应显示数学分数，避免把累计总分写到数学层里。
- 注意：
  - 转录中讲师口述变量写作 `y2`、`y3`，若直接写 `str(y2)` 或 `str(y3)`，显示的是累计高度。
  - 从“每层数据标签”的目标看，第二层文本应取数学单科分数，第三层文本应取英语单科分数。
- 运行效果：
  - 标签会放在“语文 + 数学”总长度往下减 10 的位置，即在数学层内部靠近顶部处。

### 9.4 第三层英语标签

- 第三个标签遍历前三层累计高度：
  ```python
  for x3, y3 in zip(x, data['语文'] + data['数学'] + data['英语']):
      plt.text(x3, y3 - 10, str(data['英语'].iloc[x3]), color='y', fontsize=20, ha='center')
  ```
- 解释：
  - `y3` 是英语层顶部对应的总累计高度。
  - `y3 - 10` 将文字下移，放入英语层内部。
  - 文本显示英语分数。
- 讲师总结：
  - 第一个标签最简单。
  - 第二个标签最麻烦，因为要同时考虑累计高度和本层高度。
  - 第三个标签有了第二个的基础就不难。
  - 数据标签位置是叠加柱状图的主要痛点；本节先掌握“累计高度减偏移量”的方法。

## 10. 关键结论与易错点清单

- `bottom` 是堆叠柱状图的核心参数，表示下一层柱子的起始位置，不是柱子高度。
- 第一层语文默认从 0 开始；第二层数学 `bottom=data['语文']`；第三层英语 `bottom=data['语文'] + data['数学']`。
- 如果第二层不设置 `bottom`，数学柱会从 0 开始，无法形成堆叠。
- x 轴没有姓名标签时，用 `plt.xticks(x, data['姓名'])` 设置。
- 日常作图直接用 NumPy 数组或 Pandas 数据即可，不必先转成 Python 列表。
- 图例默认可能是一列三行；要横排一行三列，用 `plt.legend(loc='center', ncol=3)`。
- `plt.ylim([10, 350])` 可以修改 y 轴显示范围。
- `plt.grid()` 用于添加网格线，不需要时注释掉。
- 数据标签用 `plt.text(x, y, s, color=..., fontsize=..., ha='center')`。
- `plt.text()` 的 y 坐标如果直接用柱子顶部累计高度，文字会落在层顶或下一层区域；需要向下减偏移量，如 `-10`、`-20`。
- 精确把标签放在每层中间，需要计算层高的一半，较麻烦；本节采用偷懒的偏移量法。
- 标签文本要显示对应层的单科分数；如果遍历的是累计高度，直接 `str(y2)`/`str(y3)` 会显示累计值，需要注意区分“定位高度”和“显示文本”。
- Python 作图虽然不如 Excel/VBA 点两下方便，但适合大数据处理；Pandas 处理大数据时只显示少量行，但作图速度快，Excel 大文件可能打不开。

## 11. 按讲解还原的完整代码骨架

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 中文字体设置示意，具体字体按课程环境设置
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# data 为包含 姓名、语文、数学、英语 的 DataFrame
print(data)

# 生成 x 轴位置
x = np.arange(len(data))

# 第一层：语文
plt.bar(x, data['语文'], color='red', label='语文')

# 设置 x 轴姓名标签
plt.xticks(x, data['姓名'])

# 第二层：数学，从语文顶部开始堆叠
plt.bar(x, data['数学'], bottom=data['语文'], color='green', label='数学')

# 第三层：英语，从语文+数学顶部开始堆叠
plt.bar(x, data['英语'], bottom=data['语文'] + data['数学'], color='blue', label='英语')

# 图例居中并排成一行三列
plt.legend(loc='center', ncol=3)

# 修改 y 轴显示范围
plt.ylim([10, 350])

# 添加网格线，不需要时注释掉
# plt.grid()

# 第一层语文数据标签
for x1, y1 in zip(x, data['语文']):
    plt.text(x1, y1 - 10, str(y1), color='y', fontsize=20, ha='center')

# 第二层数学数据标签
for x2, y2 in zip(x, data['语文'] + data['数学']):
    plt.text(x2, y2 - 10, str(data['数学'].iloc[x2]), color='y', fontsize=20, ha='center')

# 第三层英语数据标签
for x3, y3 in zip(x, data['语文'] + data['数学'] + data['英语']):
    plt.text(x3, y3 - 10, str(data['英语'].iloc[x3]), color='y', fontsize=20, ha='center')

plt.show()
```
