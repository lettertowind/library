# Pandas 算术运算与数据对齐笔记

## 课程主题

本节学习 pandas 中的算术运算与数据对齐，重点围绕算术运算中容易出现的两个问题展开：

- 参与运算的数据中存在空值，空值会传播，导致结果仍为空值。
- 分母为 0 时会产生 `inf`、`-inf` 或 `NaN`，需要特殊处理。

视频中说明，算术运算包括加减乘除、整除、幂次方等。pandas 中常用的是加减乘除，但其他运算也遵循类似规则。

---

## 算术运算的范围

- 基本运算：加法、减法、乘法、除法。
- 扩展运算：整除、幂次方等。
- 在 pandas 中，算术运算不仅是数值计算，还涉及索引对齐和缺失值处理。
- 如果参与运算的两个对象索引或列不完全一致，未对齐的位置可能产生缺失值，随后按照空值规则传播。

---

## 问题一：空值与 `NaN` 参与计算

### 1. 空值传播现象

在 NumPy 和 pandas 中：

- `NaN` 表示“不是一个数字”，可以暂时理解为空值。
- 空值与数字进行计算时，结果通常仍为空值。

公式示例：

\[
\text{NaN}+1=\text{NaN}
\]

\[
1+\text{NaN}=\text{NaN}
\]

因此，如果一列数据中存在空值，直接与另一列相加时，对应位置的结果仍会是空值。

### 2. 示例现象

视频中读取了一份 Excel 数据，数据使用默认索引，包含两列数据，其中存在空值。

直接进行两列相加时：

- 非空对应位置可以正常相加，例如得到 `8`。
- 空值参与的位置结果为 `NaN` 或空值。
- 因此结果中会出现类似“8、空、空”的情况。

这说明：空值会传播，不能直接忽略。

### 3. 解决方法：使用 `fillna(0)` 填充空值

处理思路：在进行计算前，将空值替换为 `0`。

示例代码：

```python
df["一店"] = df["一店"].fillna(0)
df["二店"] = df["二店"].fillna(0)

result = df["一店"] + df["二店"]
```

处理后再计算，原本为空的参与位置就可以按 `0` 参与运算，得到完整结果。

视频中提到，空值替换相关知识可以参考 pandas 笔记中的空值处理部分。

### 4. 灵活算术法

pandas 提供了灵活算术方法，可以在运算时直接指定缺失值的填充值。

常用方法包括：

| 运算 | 方法 | 反转方法 |
|---|---|---|
| 加法 | `add` | `radd` |
| 减法 | `sub` | `rsub` |
| 乘法 | `mul` | `rmul` |
| 除法 | `div` / `truediv` | `rdiv` / `rtruediv` |
| 整除 | `floordiv` | `rfloordiv` |
| 幂次方 | `pow` | `rpow` |
| 取模（补充） | `mod` | `rmod` |

示例：使用 `add` 并进行空值填充。

```python
result = df["一店"].add(df["二店"], fill_value=0)
```

关键参数是：

```python
fill_value=0
```

它的作用是在参与运算时，将缺失值按 `0` 处理。

注意：视频中口误提到了类似 `valus`、`value` 的写法，实际正确参数名是 `fill_value`。

### 5. 两种处理方式对比

- 方式一：先用 `fillna(0)` 替换空值，再进行普通算术运算。
- 方式二：直接使用 `add`、`sub`、`div` 等灵活算术方法，并设置 `fill_value=0`。

两种方式都可以，实际使用时可任选一种。

## 问题二：分母为 0 与无穷大

### 1. 分母为 0 的三种结果

当分母为 0 时，根据被除数不同，会产生不同结果：

\[
\frac{0}{0}=\text{NaN}
\]

\[
\frac{1}{0}=\text{inf}
\]

\[
\frac{-1}{0}=-\text{inf}
\]

其中：

- `NaN`：不是一个数字，可暂时看作空值。
- `inf`：正无穷大。
- `-inf`：负无穷大。

视频中强调，这个问题在 NumPy 阶段已经讲过，可参考 NumPy 笔记中数组计算相关部分。

### 2. 为什么 `fillna` 不能直接处理 `inf`

`fillna` 主要用于替换空值，例如 `NaN`。

但 `inf` 和 `-inf` 是无穷大，不是空值，因此不能直接用 `fillna` 替换。

示例数据：

| 被除数 | 除数 | 结果 |
|---|---|---|
| `1` | `0` | `inf` |
| `-1` | `0` | `-inf` |
| `0` | `0` | `NaN` |
| `2` | `2` | `1` |

直接进行除法时，结果中会出现 `inf`、`-inf` 和 `NaN`。

### 3. 解决方法：将 `inf` 视为空值

视频中提到，作者参考了 2019 年 CSDN 上的一篇文章，使用 pandas 的选项设置，将无穷大转换为空值。

旧版 pandas 中可使用：

```python
import pandas as pd

pd.options.mode.use_inf_as_na = True
```

该设置的作用是：

- 将 `inf` 和 `-inf` 视为 `NaN` 或空值。
- 这样后续就可以使用 `fillna(0)` 或 `fill_value=0` 处理这些位置。

设置后，再结合空值填充即可计算：

```python
result = df["一店"].div(df["二店"]).fillna(0)
```

或者使用灵活算术方法：

```python
result = df["一店"].div(df["二店"], fill_value=0)
```

注意：如果先设置 `use_inf_as_na`，无穷大已经被视为空值，此时再使用 `fillna(0)` 或 `fill_value=0` 才能生效。

### 4. 处理流程总结

遇到分母为 0 的情况，可按以下流程处理：

- 识别结果中是否出现 `inf`、`-inf` 或 `NaN`。
- 若存在 `inf`，先设置 `pd.options.mode.use_inf_as_na = True`，把无穷大视作空值。
- 再使用 `fillna(0)` 填充空值。
- 或使用灵活算术方法并设置 `fill_value=0`。
- 最后重新执行算术运算，得到可计算、可展示的结果。

## 数据对齐说明

pandas 的算术运算默认会按照索引和列进行对齐。

- 当两个 Series 或 DataFrame 的索引一致时，对应位置直接计算。
- 当索引不完全一致时，未对齐的位置会产生缺失值。
- 缺失值随后按照空值传播规则处理，结果可能为 `NaN`。
- 灵活算术方法中的 `fill_value` 可以用于处理部分缺失值。

本节示例主要体现了两列数据运算时的空值传播与填充处理。更复杂的多层索引和索引计算将在后续课程中展开。

## 关于反转方法 `r`

灵活算术方法中带有 `r` 前缀的方法表示反转操作数顺序，例如：

- `add` 表示左侧对象加右侧对象。
- `radd` 表示右侧对象加左侧对象。
- `div` 表示左侧对象除以右侧对象。
- `rdiv` 表示右侧对象除以左侧对象。

对于加法，左右顺序通常不影响结果；但对于除法、减法、幂次方等运算，顺序不同结果会不同。

例如：

\[
\frac{5}{3}\neq\frac{3}{5}
\]

因此，反转方法在非交换运算中更有意义。

## 本节总结

- pandas 算术运算包括加减乘除、整除、幂次方等。
- 空值 `NaN` 参与计算会传播，结果仍为空值。
- 处理空值可以在计算前使用 `fillna(0)`，也可以在灵活算术方法中使用 `fill_value=0`。
- 分母为 0 时：`0/0` 得到 `NaN`，非零数除以 0 得到 `inf` 或 `-inf`。
- `inf` 不能直接被 `fillna` 替换，需要先通过 pandas 选项将其视作空值：

```python
pd.options.mode.use_inf_as_na = True
```

- 将 `inf` 转为空值后，再使用 `fillna(0)` 或 `fill_value=0` 完成计算。
- 灵活算术方法包括 `add`、`sub`、`mul`、`div`、`floordiv`、`pow` 等，以及对应的 `r` 反转方法。
- 视频中提到的参考位置包括 NumPy 笔记中的数组计算部分，以及 pandas 笔记中的空值处理部分。
