# 孙兴华 Python 数据分析入门：创建数组

## 1. 导入 Numpy 与创建数组的总体思路

- 课程主题：学习创建数组的方法。
- 首先导入 Numpy 模块，课程中使用常见别名 `np`：
  - `import numpy as np`
- 讲师说明创建数组主要有三种方法，并会在后续继续补充 `ones`、`zeros`、`full` 等批量创建数组的方法。
- 创建数组后需要能够判断：
  - 创建出来的到底是不是 Numpy 数组；
  - 数组元素的数据类型是什么；
  - 数组的维度、元素个数等属性是什么。

## 2. 方法一：`np.array()` 配合 `range()` 创建数组

- 使用 `np.array()` 将 `range()` 产生的数据转换成 Numpy 数组。
- 示例逻辑：
  - `b = np.array(range(1, 6))`
  - `print(b)`
  - 输出为 `[1 2 3 4 5]`
- 视频口述为“从 1 到 5”，示例输出为 `1 2 3 4 5`。
- `np.array()` 是 Numpy 中专门用于创建数组的方法之一。
- 讲师说明：`np.array()` 可以把输入的数据转换成 Numpy 数组类型。

## 3. 方法二：直接在 `np.array()` 中写入列表

- 也可以直接把数字写进 `np.array()` 中，但讲师强调这种方法一般不用，因为写起来比较麻烦，除非需要指定具体数字。
- 语法形式：
  - `np.array([1, 2, 3, 4, 5])`
- 注意点：
  - `np.array()` 外层的括号是该方法的括号；
  - 括号内部通常写成列表形式 `[ ]`；
  - 写上需要的数字；
  - 每个数字之间用英文逗号隔开。
- 示例：
  - `b = np.array([1, 2, 3, 4, 5])`
  - `print(b)`
- 讲师结论：可以直接创建，但相比 `np.arange()` 写法更麻烦，不是最推荐的方式。

## 4. 方法三：使用 `np.arange()` 创建数组

- 讲师推荐使用更简单的写法：
  - `np.arange(1, 6)`
- 示例：
  - `b = np.arange(1, 6)`
  - `print(b)`
  - 输出为 `[1 2 3 4 5]`
- `np.arange()` 相当于把 `range()` 和 `np.array()` 组合在一起，直接返回数组。
- 对比：
  - `np.array(range(1, 6))`
  - `np.arange(1, 6)`
  - 两者效果一致，但 `np.arange()` 少写一层 `array`，更简洁。
- 讲师建议：越简单越好，推荐使用 `np.arange()` 创建连续范围数组。

## 5. 查看数组元素类型：`dtype`

- 创建数组后可以查看数组元素的数据类型：
  - `b.dtype`
- 示例中显示数据类型为 `int32`。
- 说明：
  - `int` 表示整数型；
  - Numpy 中数据类型很多，每种类型后面会跟位数；
  - 例如 `int32`、`int64`、`float32`、`float64`；
  - 基础篇暂时不需要深入理解所有数据类型，先了解即可。
- `dtype` 查看的是“数组里边元素的数据类型”。

## 6. 创建数组时指定数据类型 `dtype`

- 可以在创建数组时通过 `dtype` 参数指定元素类型。
- 讲师给出的可选写法包括：
  - `dtype=float`
  - `dtype=np.float32`
  - `dtype=np.int32`
  - `dtype=np.int64`
- 示例：
  - `np.arange(1, 8, dtype=float)`
  - 输出为浮点型小数；
  - 查看类型时显示为 `float64`。
- 再指定为 32 位浮点型：
  - `np.arange(1, 8, dtype=np.float32)`
  - 运行后类型显示为 `float32`。
- 也可以改成整数型，例如：
  - `np.arange(1, 8, dtype=np.int64)`
  - 运行后类型显示为 `int64`。
- 讲师结论：
  - 不指定类型时，Numpy 会自动探测/推断一个默认类型；
  - 自动推断不一定总是符合预期，存在推断错误的可能；
  - 可以手动通过 `dtype` 修改或指定数据类型；
  - 现阶段对数据类型“了解一下即可”，不用完全掌握。

## 7. 判断变量是否为 Numpy 数组：`type()`

- 仅打印数组内容不易判断它到底是列表还是数组，可以使用 `type()` 查看对象类型。
- 示例：
  - `type(b)`
- 输出显示：
  - `<class 'numpy.ndarray'>`
- 说明：
  - `numpy.ndarray` 是 Numpy 独有的数组类型；
  - `dtype` 看的是数组元素类型；
  - `type()` 看的是整个对象的类型。

## 8. `np.array()` 可接收的输入形式

- `np.array()` 可以将输入的数据转换成 Numpy 数组。
- 输入可以是：
  - 列表：`[1, 2, 3, 4, 5]`
  - 元组：`(1, 2, 3, 4, 5)`
  - 数组；
  - 其他序列。
- 元组示例：
  - `np.array((1, 2, 3, 4, 5))`
- 注意：
  - `np.array()` 外层括号是方法自带括号；
  - 内部数据用英文逗号隔开；
  - 列表和元组都可以被转换。
- 如果不指定类型，Numpy 会自动判断输入数据的类型。

## 9. 数组属性：`shape`

- 属性写法：在数组变量后面打点，再写属性名。
- 第一个常用属性是 `shape`，用于返回数组的维度信息，即几行几列。
- 示例：
  - `a.shape`
- 一维数组示例输出：
  - `(7,)`
- 解释：
  - 一个数字表示一维数组；
  - 以元组形式返回；
  - 表示该一维数组有 7 个数据。
- 多维数组：
  - 如果显示两个数字，例如 `(2, 3)`，表示两行三列；
  - 记住“行在前，列在后”；
  - 如果是三维，则可能显示类似“两块、两行、三列”的结构；
  - 本节先以二维、三维概念作预告，后续具体讲解。

## 10. 数组属性：`ndim`

- `ndim` 返回一个数字，表示数组的维度数。
- 示例：
  - `a.ndim`
- 一维数组返回：
  - `1`
- 讲师说明：
  - 知道 `shape` 后一般也能看出维度；
  - `ndim` 使用相对较少；
  - 它直接告诉你这是几维数组。

## 11. 数组属性：`size`

- `size` 返回一个数字，表示数组中所有数据元素的总数。
- 示例：
  - `a.size`
- 若数组中有 7 个数字，返回：
  - `7`
- 含义：统计数组内全部元素个数。

## 12. 数组属性：`dtype`

- `dtype` 返回数组元素的数据类型。
- 示例：
  - `a.dtype`
- 若创建时指定 `dtype=np.int64`，则显示：
  - `int64`
- 本节涉及的核心属性总结：
  - `shape`：数组形状，几行几列；
  - `ndim`：维度数；
  - `size`：元素总个数；
  - `dtype`：元素数据类型。
- 属性使用方式统一为：
  - `数组变量.属性名`

## 13. `np.arange()` 的参数与 `range()` 类比

- `np.arange()` 与 Python 的 `range()` 类似，参数包括：
  - 开始值；
  - 结束值；
  - 步长。
- 示例：
  - `np.arange(1, 10, 2)`
  - 输出为 `[1 3 5 7 9]`
- 解释：
  - 从 1 开始；
  - 到 10 前结束；
  - 步长为 2；
  - 每隔一个取一个，因此得到奇数序列。
- 步长参数可以省略：
  - 默认步长为 1。
- 只传一个数时：
  - `np.arange(5)`
  - 表示从 0 开始，到 5 前结束；
  - 输出为 `[0 1 2 3 4]`。
- 与 `range` 的关系：
  - `np.array(range(5))`
  - `np.arange(5)`
  - 两者结果一致。
- 讲师推荐：直接使用 `np.arange()`，写法更省事。

## 14. 创建全 1 数组：`np.ones()`

- 使用 `np.ones()` 创建元素全为 1 的数组。
- 一维示例：
  - `np.ones(3)`
  - 输出三个 1。
- 传一个数时，表示创建指定长度的一维数组。
- 二维示例：
  - `np.ones((2, 3))`
  - 表示两行三列；
  - 数组内所有元素都是 1。
- 多维时必须使用元组表示形状：
  - 二维写两个数：`(2, 3)`
  - 三维写三个数；
  - 一维可以省略元组括号，直接写一个数。
- 参数说明：
  - 第一个参数是形状 `shape`，可以传一个数或元组；
  - 第二个参数是数据类型 `dtype`；
  - 第三个参数是排序/内存顺序 `order`；
  - `order` 默认是 `C`，按 C 语言方式的数组元素内存存储顺序；
  - 初级阶段不要改动 `order`，直接忽略后两个参数即可。
- 讲师结论：
  - 一维传一个数；
  - 二维传两个数的元组；
  - 三维传三个数的元组；
  - 二维、三维必须写内层括号。

## 15. 创建全 0 数组：`np.zeros()`

- 将 `np.ones()` 改成 `np.zeros()`，即可创建全 0 数组。
- 示例：
  - `np.zeros(3)`
  - 输出三个 0。
- 二维示例：
  - `np.zeros((3, 3))`
  - 输出三行三列全 0 数组。
- 参数规则与 `np.ones()` 相同：
  - 第一个参数是形状；
  - 一维传一个数；
  - 二维传两个数的元组；
  - 三维传三个数的元组；
  - `dtype` 和 `order` 初级阶段可忽略，尤其不要随意改 `order`。

## 16. 创建指定填充值数组：`np.full()`

- `np.ones()` 创建全 1，`np.zeros()` 创建全 0；
- 如果想创建指定数字，例如 520，则使用 `np.full()`。
- 一维示例：
  - `np.full(3, 520)`
  - 表示创建包含三个 520 的数组。
- 二维示例：
  - `np.full((3, 3), 520)`
  - 表示创建三行三列、全部为 520 的数组。
- 参数理解：
  - 第一个参数是形状：一维传一个数，二维传元组，三维传三元组；
  - 第二个参数是要填充的数字；
  - 后续 `dtype`、`order` 等参数与前述数组创建方法类似，初级阶段先忽略。
- 与 `ones`、`zeros` 对比：
  - `np.ones()`：固定填充 1；
  - `np.zeros()`：固定填充 0；
  - `np.full()`：填充任意指定数字；
  - 形状参数的写法一致：一维可省略元组，二维、三维必须使用元组。

## 17. 本节关键结论与易错点

- 创建连续范围数组推荐使用：
  - `np.arange(start, stop, step)`
- `np.arange()` 与 `range()` 类似：
  - 只传一个数时从 0 开始；
  - 结束值通常不包含；
  - 可指定步长。
- `np.array(range(...))` 与 `np.arange(...)` 效果相同，但 `np.arange()` 更简洁。
- `np.array()` 可以直接接收列表、元组、数组或其他序列。
- `dtype` 是数组元素类型；`type()` 是对象整体类型。
- 常见类型：
  - `int32`
  - `int64`
  - `float32`
  - `float64`
- 自动推断类型不保证完全符合预期，可通过 `dtype=` 显式指定。
- 常用数组属性：
  - `shape`：形状，元组形式返回；
  - `ndim`：维度数；
  - `size`：元素总数；
  - `dtype`：元素数据类型。
- 多维形状必须用元组：
  - 一维：`np.ones(3)` 可省略括号；
  - 二维：`np.ones((2, 3))` 必须写元组；
  - 三维：`np.ones((a, b, c))` 必须写元组。
- `order` 默认 `C`，初级阶段不要修改；创建数组时重点关注形状和填充值。
