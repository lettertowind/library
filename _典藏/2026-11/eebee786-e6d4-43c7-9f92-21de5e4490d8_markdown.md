## 2. 按行索引奇偶分组

- 可以按照 DataFrame 的行索引进行分组。
- 取余判断规则：
  - \(\text{index} \bmod 2 = 0\)：偶数行。
  - \(\text{index} \bmod 2 \ne 0\)：奇数行。
- 示例代码形式：

  - `df.groupby(df.index % 2 == 0)[['数学', '语文', '英语']].sum()`

- 说明：
  - `df.index` 表示行索引。
  - `df.index % 2 == 0` 会生成一组 `True/False` 分组键。
  - `True` 对应偶数行，`False` 对应奇数行。
  - 若改为 `df.index % 2 != 0`，奇偶分组结果会反转。
  - 聚合列使用双层列表形式：`[['数学', '语文', '英语']]`，不要写错。

- `groupby` 的核心理解：
  - 先明确“按谁分组”。
  - 再明确“按哪些列聚合”。
  - 最后指定“聚合函数”，例如 `sum()`、`mean()` 等。

## 3. 常用聚合函数与 NA 值注意事项

- 视频整理了常用聚合函数，常用于 `groupby` 后的聚合操作。
- 这些函数大多针对非 `NA` 值进行计算。

| 聚合函数 | 含义 |
|---|---|
| `count` | 分组中非 `NA` 值的数量 |
| `sum` | 非 `NA` 值求和 |
| `mean` | 非 `NA` 值求平均 |
| `median` | 非 `NA` 值的中位数 |
| `std` | 非 `NA` 值的标准差 |
| `var` | 非 `NA` 值的方差 |
| `max` / `min` | 非 `NA` 值的最大值 / 最小值 |
| `prod` | 非 `NA` 值的乘积 |
| `first` / `last` | 第一个 / 最后一个非 `NA` 值 |

- `NA` 值处理提醒：
  - 聚合前应先考虑数据中是否存在 `NA`。
  - 可以使用替换函数处理缺失值，也可以在聚合时指定相关参数。
  - 视频示例数据没有 `NA`，因此没有额外处理。

## 4. 按序号条件分组

- 可以按照 `序号` 列生成的条件进行分组。
- 例如使用 `序号 >= 5` 作为分组条件：

  - `df.groupby(df['序号'] >= 5)[['数学', '语文', '英语']].mean()`

- 结果同样会显示 `True/False` 两组：
  - `True`：满足 `序号 >= 5` 的数据。
  - `False`：不满足条件的数据。
- 视频指出，这种按索引号、简单数值条件或“几个一组”的分组方式在实际工作中使用较少。
- 更常见的是按类别、姓名、班级、日期、小时等业务字段分组。

## 5. 按姓名首字或前两个字分组

### 5.1 按姓氏或姓名第一个字分组

- 中文姓名可以按第一个字进行分组，例如丁、卢、李、张、王、刘等姓氏。
- 示例思路：

  - `df['姓名'].str[0]`

- 说明：
  - `.str` 用于对字符串列进行字符串操作。
  - `[0]` 表示取第一个字符。
  - 分组后仍可对数学、语文、英语成绩求和。

- 示例代码形式：

  - `df.groupby(df['姓名'].str[0])[['数学', '语文', '英语']].sum()`

- 结果理解：
  - 姓丁、姓卢的数据各只有一人，因此显示本人的成绩。
  - 姓李、姓张、姓王等有多人，成绩会按姓氏汇总相加。

### 5.2 按“姓氏 + 第二个字”进行多级分组

- 可以同时按姓名的第一个字和第二个字分组。
- 视频示例中使用两个 Series 组成列表作为分组键：

  - `df.groupby([df['姓名'].str[0], df['姓名'].str[1]])[['数学', '语文', '英语']].sum()`

- 结果示例：
  - 丁 + 智
  - 卢 + 海
  - 张 + 一、张 + 荣
  - 李 + 平、李 + 永、李 + 超
  - 王姓也会按第二个字继续细分

- 注意事项：
  - 视频尝试过切片形式，例如类似 `[1:2]` 的写法，但这类切片不能直接满足“同时取第一个字和第二个字作为两个分组键”的需求。
  - 当前案例中只能分别提取第一个字和第二个字，再放入列表进行分组。
  - 复姓目前无法简单处理，例如“司马”“诸葛”等。视频建议后续可编写小程序或更复杂逻辑解决。

## 6. 按指定班级分组：`isin` 与取反

- 可以只对指定班级进行分组，例如只选择“一班”和“二班”。
- Pandas 中判断某列元素是否在列表中，应使用 `isin()`：

  - `df['班级'].isin(['一班', '二班'])`

- 示例分组：

  - `df.groupby(df['班级'].isin(['一班', '二班']))[['数学', '语文', '英语']].sum()`

- 结果说明：
  - `True`：班级属于指定列表的数据。
  - `False`：班级不属于指定列表的数据。
  - 这样可以快速实现“指定班级”和“非指定班级”的分组统计。

- 重要注意：
  - `isin` 判断该列元素是否在列表中。
  - Pandas 中没有 `isnotin` 这样的函数。
  - 不要写成 `is not in`。
  - 如果需要取反，应在 `isin(...)` 表达式前加波浪号 `~`：

  - `~df['班级'].isin(['一班', '二班'])`

- 取反后的效果：
  - `True` 表示不属于指定班级。
  - `False` 表示属于指定班级。
  - 波浪号 `~` 是在 `isin` 表达式前加，不是在整个 `groupby` 后面随意加。
  - 输入 `~` 时通常使用 `Shift` 加数字键 `1` 前面的键。

## 7. 按日期时间分组（本节重点）

### 7.1 使用 `.dt` 提取年份

- 时间列中包含日期和时间，可以通过 `.dt` 访问器提取时间属性。
- 提取年份：

  - `df['时间'].dt.year`

- 示例分组：

  - `df.groupby(df['时间'].dt.year)[['数学', '语文', '英语']].sum()`

- 结果说明：
  - 示例数据只有 `2020` 年，因此只显示 `2020` 年的汇总。
  - 如果数据中包含 `2018`、`2019`、`2020` 等多个年份，会自动按年份分别汇总。
- `.dt` 是 Pandas 时间日期处理的重要访问器，视频提到已整理时间日期模块资料，可像查词典一样查阅。

### 7.2 使用 `.dt.month` 提取月份

- 提取月份：

  - `df['时间'].dt.month`

- 如果同时按年和月分组，应使用列表形式组织多个分组键：

  - `df.groupby([df['时间'].dt.year, df['时间'].dt.month])[['数学', '语文', '英语']].sum()`

- 示例数据只有 `2020` 年 `5` 月，因此月份分组只显示 `5` 月。
- 如果数据跨多个月，会自动按年月形成多级分组。

### 7.3 使用 `.dt.hour` 提取小时

- 提取小时：

  - `df['时间'].dt.hour`

- 按“年 + 小时”分组示例：

  - `df.groupby([df['时间'].dt.year, df['时间'].dt.hour])[['数学', '语文', '英语']].sum()`

- 结果可显示：
  - `2020` 年 `8` 点
  - `2020` 年 `9` 点
  - `2020` 年 `17` 点
  - `2020` 年 `18` 点
  - 等不同时间段的汇总。

- 业务应用：
  - 订单时间可能包含 `8:05`、`8:06`、`8:07`、`9:05`、`9:06` 等具体时间。
  - 销售部门可以利用 `.dt.hour` 统计不同小时的销售情况。
  - 相比 Excel 中反复分列、筛选、统计，Pandas 处理更简洁。

## 8. 使用 `pipe` 进行分组

- 视频介绍了 Pandas 的 `pipe` 方法，但本节只是初步介绍，后续会有专门课程详细讲解。
- 示例思路：

  - `df.pipe(pd.DataFrame.groupby, '班级').sum()`

- 说明：
  - `pipe` 可以把 DataFrame 传入指定函数。
  - 这里传入 `pd.DataFrame.groupby`，并指定分组字段 `'班级'`。
  - 得到分组对象后，再链式调用 `.sum()` 完成聚合。
- 视频提到 Pandas 中有三个重要方法：
  - `pipe`：表格函数 / 数据框函数。
  - `apply`：行列函数。
  - `map`：元素函数应用。
- 这三个方法都较重要，但本节课只涉及 `pipe` 的简单用法，后续再展开。
