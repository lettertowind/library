## 1. 条件计算与条件替换

### 1.1 将逻辑条件作为数组操作

对数组使用比较运算符，会返回一个与原数组形状相同的布尔数组：

- 条件成立返回 `True`
- 条件不成立返回 `False`

例如对 3×3 数组执行：

```python
a > 3
```

会逐个元素判断是否大于 3。若数组中有元素 `6、9、4`，它们大于 3，对应位置为 `True`；元素 `1、3、2` 等不满足条件的为 `False`。

示例布尔结果可理解为：

```python
[[False, False, True],
 [True,  False, False],
 [False, True,  False]]
```

其中等于 3 的元素不算大于 3，因此返回 `False`。

### 1.2 使用 `np.where` 进行条件替换

`np.where` 类似 Python 中的 `if` 条件判断，语法为：

```python
np.where(condition, x, y)
```

含义：

- 条件为真时取 `x`
- 条件为假时取 `y`

示例：将大于 3 的元素改为 `520`，不大于 3 的元素改为 `1314`：

```python
np.where(a > 3, 520, 1314)
```

即：

- 当 `a > 3` 时返回 `520`
- 否则返回 `1314`

视频中口误说成类似 `while`，实际函数是 `np.where`。

### 1.3 统计满足条件的元素个数

统计数组中大于 3 的个数，可以写成：

```python
(a > 3).sum()
```

原理：

- `a > 3` 返回布尔数组
- 在 NumPy 中，`False = 0`，`True = 1`
- 对布尔数组求和，相当于统计 `True` 的个数

用公式表示：

\[
\text{count} = \sum_i \mathbf{1}[a_i > 3]
\]

其中 \(\mathbf{1}[\cdot]\) 表示条件成立时为 1，否则为 0。

视频示例中，3×3 数组里大于 3 的元素一共有 3 个，因此 `(a > 3).sum()` 的结果为 3。

## 2. 布尔值方法：`any` 与 `all`

NumPy 中常用两个布尔值方法：

### 2.1 `np.any`

`np.any` 用于检查数组中是否**至少有一个** `True`：

```python
np.any(bool_array)
```

- 只要有一个元素为 `True`，结果就是 `True`
- 全部为 `False` 时，结果才是 `False`

示例布尔数组：

```python
[False, False, True, False]
```

因为至少有一个 `True`，所以 `np.any(...)` 返回 `True`。

### 2.2 `np.all`

`np.all` 用于检查数组中是否**所有元素都为** `True`：

```python
np.all(bool_array)
```

- 只有全部元素为 `True`，结果才是 `True`
- 只要有一个 `False`，结果就是 `False`

对于上面的数组 `[False, False, True, False]`，因为存在 `False`，所以 `np.all(...)` 返回 `False`。

如果将数组全部改为 `True`，则 `np.all(...)` 返回 `True`。

## 3. 按值大小排序：`sort`

### 3.1 `sort` 的基本语法

数组排序使用 `sort` 方法，基本形式为：

```python
ndarray.sort(axis=-1, kind=None, order=None)
```

主要参数：

- `axis`：按哪个轴排序
- `kind`：排序算法，初级阶段通常不用管
- `order`：排序字段名，主要用于结构化数组；初级阶段暂不展开

需要注意：`ndarray.sort()` 是**原地排序**，会直接修改原数组，不需要重新赋值。

### 3.2 一维数组排序

对于一维数组：

```python
a.sort()
```

会直接对原数组 `a` 从小到大排序。

示例：

```python
a = np.array([...])
a.sort()
print(a)
```

打印 `a` 后可以看到原数组已经被修改为升序结果。

### 3.3 二维数组排序与 `axis`

视频先打印一个 3×3 的二维数组，再演示按不同轴排序。

二维数组中：

- 行方向可理解为轴 `0`
- 列方向可理解为轴 `1`
- 默认 `axis=-1`，即最后一个轴

在 NumPy 中：

- `axis=0`：按列排序，即每一列内部分别排序
- `axis=1`：按行排序，即每一行内部分别排序
- 默认 `axis=-1` 对二维数组等价于按最后一个轴处理

视频中用 Excel 辅助理解：

- 按列排序：每一列里的数据分别从小到大排列
- 按行排序：每一行里的数据分别从小到大排列

例如按列排序时，第一列内部排序、第二列内部排序、第三列内部排序；按行排序时，第一行内部排序、第二行内部排序、第三行内部排序。

### 3.4 字段名排序

`sort` 的 `order` 参数可用于按字段名排序，主要面向结构化数组。视频中将相关示例附在资料中，说明初级阶段暂时不重要，等掌握一维、二维数组排序后可以自行查看。

## 4. 按索引排序：`argsort`

### 4.1 `argsort` 的作用

`np.argsort` 返回的是**排序后的索引**，不是排序后的元素本身。

例如一维数组：

```python
a = np.array([59, 29, 39])
```

升序排序后的值应为：

```python
[29, 39, 59]
```

对应的原始索引为：

```python
[1, 2, 0]
```

因为：

- 最小值 29 在原数组中的索引是 1
- 39 在原数组中的索引是 2
- 59 在原数组中的索引是 0

所以：

```python
idx = np.argsort(a)
```

得到升序索引。

再用这个索引去取数组元素：

```python
a[np.argsort(a)]
```

得到：

```python
[29, 39, 59]
```

公式表示：

\[
a[\text{np.argsort}(a)]
\]

### 4.2 降序排序

视频中说明，降序可以通过对值取负实现，例如：

```python
a[np.argsort(-a)]
```

这样最大值会排到前面，最小值排到后面。

也可以写成先得到升序索引再反转：

```python
a[np.argsort(a)[::-1]]
```

### 4.3 二维数组的 `argsort`

二维数组也可以使用 `argsort`，返回的是按指定轴排序后的索引数组。

例如：

```python
np.argsort(a, axis=0)
```

表示按列方向返回索引。

视频中演示了用索引进一步得到排序后的二维数组，涉及类似：

```python
np.take_along_axis(a, np.argsort(a, axis=...), axis=...)
```

的思路：先用 `argsort` 得到排序索引，再用 `take_along_axis` 按索引取出对应元素。

这部分视频说明“仅作了解即可”，因为后续 Pandas 中会有更方便的方法处理二维表格排序。

## 5. 唯一值与集合逻辑

### 5.1 使用 `np.unique` 去重

`np.unique` 用于获取数组中的唯一值，即去重。

示例：字符串数组：

```python
姓名 = np.array(['孙悟空', '猪八戒', '孙悟空', '沙和尚', '孙悟空', '唐僧'])
```

使用：

```python
np.unique(姓名)
```

可以得到去重后的唯一姓名。

数值数组也可以去重。例如数组中有多个重复的 1、3、5 等，使用：

```python
np.unique(a)
```

可得到唯一值，如：

```python
[1, 3, 5, 6, 7]
```

视频中提到，这类似 Power BI 中常用的“去重建新表”操作。

注意：`np.unique` 默认会对唯一值结果进行排序。

### 5.2 使用 `np.in1d` 检查元素是否在另一个数组中

`np.in1d` 用于检查一个数组中的元素是否出现在另一个数组中，返回布尔数组。

语法：

```python
np.in1d(ar1, ar2)
```

含义：

- 检查 `ar1` 中的每个元素是否在 `ar2` 中出现
- 返回与 `ar1` 形状一致的布尔数组

公式表示：

\[
\text{np.in1d}(a, b) \rightarrow \{\text{True}, \text{False}\}
\]

示例：

```python
np.in1d(a, [6, 0, 3, 2, 5])
```

会返回一个布尔数组，表示 `a` 中每个元素是否属于列表 `[6, 0, 3, 2, 5]`。

视频中口述时读成类似“i n e d”，实际函数名是 `np.in1d`，其中是数字 `1`。

### 5.3 其他集合逻辑

视频还提到，交集、并集等集合逻辑与 Excel、SQL 中的连接思想类似，例如左连接、右连接、内连接等。掌握当前知识后，可以自行查看相关方法，难度不大。

## 6. 浅拷贝与深拷贝

### 6.1 不推荐直接赋值

在 NumPy 中，不建议直接这样赋值：

```python
a = b
```

因为这样 `a` 和 `b` 指向的是同一份数据，二者会互相影响。修改 `b` 时，`a` 也会变化；修改 `a` 时，`b` 也会变化。

类似地，切片操作通常会创建视图，底层数据仍然共享：

```python
a = b[:]
```

或对二维数组做切片，也可能与原数组共享数据。

### 6.2 推荐使用 `copy` 创建独立副本

如果希望 `a` 是 `b` 的独立副本，应使用：

```python
a = b.copy()
```

这样：

- `a` 和 `b` 数据独立
- 修改 `b` 不会影响 `a`
- 修改 `a` 也不会影响 `b`

视频中强调，这是很容易出错的地方，赋值时一定要判断是否需要 `copy()`。
