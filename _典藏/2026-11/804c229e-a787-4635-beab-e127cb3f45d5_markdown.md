# 课程笔记：Pandas 读取 txt 与 csv 文件

## 课程定位与本节目标

- 本节是 Pandas 课程的第二节课，主题是“如何使用 Pandas 读取文本文件”。
- 重点讲解 `pandas` 读取 `txt`、`csv`、`tsv` 等文本文件的方法。
- 上节课讲的是“新建文件”，使用 `to_csv`；本节讲“读取文件”，使用 `read_csv` 等方法。
- 讲师强调：今天最重要的内容是 `read_csv` 里面的参数，而不是前面演示的若干查看数据方法。

## 1. 文本文件类型与为什么使用 Pandas 读取

- 文本文件包括：
  - `txt` 文本文件
  - `csv` 文件
  - `tsv` 文件
- 这三种文件都是文本文件。
- 文本文件的特点：
  - 一般下载的数据如果是 `txt`、`csv` 等，常以文本形式存储。
  - 字段之间可能使用逗号分隔，也可能使用 `table` 制表符分隔，也可能使用空格分隔等。
- 为什么用 Pandas 读取：
  - 在实际的大数据分析中，`Excel` 文档不适合存储大数据。
  - 大数据通常使用 `txt` 或 `csv` 这样的文件来存储。
  - 数据放到计算机上，一般小则 2G，大的话没有上限。
- 读取和写入的对应关系：
  - 新建文件使用 `to_csv`。
  - 读取文件使用 `read_csv`。

## 2. `read_csv` 与 `read_table` 的区别

Pandas 中读取文本文件常用的两个方法：

- `pd.read_csv`
- `pd.read_table`

两者都可以用来读取 `txt`、`csv` 等文本文件，使用哪个都可以，但默认分隔符不同。

### 2.1 `read_csv` 的默认分隔符

- `read_csv` 默认使用逗号作为分隔符。
- 如果文件本身是逗号分隔，直接使用 `read_csv` 就可以读取。

示例：

```python
import pandas as pd

读取数据 = pd.read_csv(r"文件路径.txt")
读取数据
```

### 2.2 `read_table` 的默认分隔符

- `read_table` 默认对应制表符，也就是 `\t` 作为分隔符。
- 如果文件实际是逗号分隔，却直接使用 `read_table`，它找不到制表符作为分割，就可能把原本的内容原样显示出来。
- 这种情况下需要指定分隔符参数 `sep`。

示例：

```python
读取数据 = pd.read_table(r"文件路径.txt", sep=",")
```

### 2.3 选择建议

讲师给出的选择方式：

- 第一种：默认使用 `read_csv`。
- 第二种：遇到制表符分隔时，使用 `read_table`，并指定制表符是什么。
- 第三种：二者都用，但每次都明确指定分隔符。
- 具体用哪一种看个人习惯。

### 2.4 文件中同时有空格和制表符怎么办

- 如果 `csv` 或 `txt` 文件中既有制表符，又有空格分隔，需要使用正则表达式。
- 在分隔符 `sep` 参数处指定 `\s+`。
- 讲师提到：需要先导入正则模块，即 `import re`。
- 正则表达式含义：
  - `\s` 匹配空白字符，包括换行符、制表符、空格等。
  - `+` 表示一次或者无限次。
  - 因此 `\s+` 可以匹配一个或多个空白字符。
- 如果还有其他复杂情况，需要把正则表达式写得更详细。

示例：

```python
import re
import pandas as pd

读取数据 = pd.read_csv(r"文件路径.txt", sep=r"\s+")
```

讲师补充：正则表达式相关内容可以回看 Python 系列中“跟着孙兴华学习网络爬虫”的前三节课。

## 3. 读取 txt 与 csv 的基础演示

- 讲师先拿 `txt` 做演示，并说明：
  - 在实际大数据分析中，一般不用 `txt` 文件做分析，而更常用 `csv` 文件。
  - 这是个人习惯。
  - `read_csv` 和 `read_table` 都可以读取 `txt`，也可以读取 `csv`，所以不存在只能读某一种格式的问题。
- 后续会讲如何把 `txt` 文件转成 `csv` 文件，只需要两行代码。

基础读取代码形式：

```python
import pandas as pd

读取数据 = pd.read_csv(r"文件路径.txt")
读取数据
```

运行后，原本用逗号分隔的数据会正常显示为表格结构。

如果使用 `read_table` 但不指定分隔符，则可能无法正确分割；指定 `sep=","` 后即可正常读取：

```python
读取数据 = pd.read_table(r"文件路径.txt", sep=",")
```

## 4. 查看数据的基础方法

讲师在讲 `read_csv` 参数之前，先演示了几种查看数据的方法。并说明这些方法不是本节最重要的内容，重点是后面的 `read_csv` 参数。

### 4.1 `head()`：查看前几行

- `读取数据.head()` 默认读取五行数据。
- 因为示例 `csv` 文件没有表头，Pandas 默认会把第一行数据当作表头，所以显示时会在表头下面显示五行数据。
- 如果写成 `读取数据.head(3)`，就显示三行数据；想要几行就在括号里写几行。
- 讲师不推荐把 `head()` 写在 `print` 里面。

示例：

```python
读取数据.head()
读取数据.head(3)
```

不推荐方式的原因：

- 写在 `print` 里面，只是改变打印显示结果，原始数据变量并没有发生变化。
- 如果以后频繁调用读取数据时忘了写 `head()`，可能一次显示全部数据。
- 数据大时可能造成内存压力，甚至死机。
- 更推荐在读取时使用参数 `nrows` 控制读取行数。

### 4.2 `shape`：查看数据形状

- `shape` 用于查看数据是几行几列。
- 示例中显示为 6 行 6 列，但实际数据是 7 行 6 列。
- 原因是第一行数据被 Pandas 当成了表头，没有算作数据行。
- `shape` 返回的是数据部分的行数和列数。

示例：

```python
读取数据.shape
```

### 4.3 `columns`：查看列名

- `columns` 用于显示列名。
- 因为第一行数据被当成表头，所以第一行数据会显示为列名。
- 学完如何人造列名之后，使用 `columns` 就可以显示出人造列名。

示例：

```python
读取数据.columns
```

### 4.4 `index`：查看索引号

- `index` 用于显示索引号。
- 示例中索引从 0 开始，到 6 结束，步长为 1。
- 学过 Python 基础的朋友应该都能理解。

示例：

```python
读取数据.index
```

### 4.5 `dtypes`：查看每一列的数据类型

- 一个表中的数据类型可能多种多样。
- 例如姓名、性别、年龄、手机号码等，每一列的数据类型可能不同。
- 使用 `dtypes` 可以查看每一列的数据类型。

示例：

```python
读取数据.dtypes
```

讲师演示中得到：

- 性别：`object`
- 姓名：`object`
- 年龄：`int64`
- `int64` 表示 64 位整型。
- 这部分内容在 NumPy 课程中已经讲过。

## 5. `read_csv` 的关键参数逐项说明

讲师强调：本节最重要的内容是 `read_csv` 里的参数。

### 5.1 `sep`：指定分隔符

- `sep` 用来指定分隔符。
- 可以是普通分隔符，例如逗号 `,`。
- 也可以是正则表达式。
- 如果文件中既有空格又有 `table` 制表符，就要使用正则表达式，例如 `\s+`。
- 如果有其他复杂情况，需要把正则表达式写得更详细。

示例：

```python
读取数据 = pd.read_csv(r"文件路径.csv", sep=",")
读取数据 = pd.read_csv(r"文件路径.txt", sep=r"\s+")
```

### 5.2 `header`：指定表头行

- `header` 默认值是 `0`，表示第一行作为表头。
- 行号从 0 开始。
- 如果数据没有表头，需要告诉 Pandas 没有表头，使用 `header=None`。
- 只设置 `header=None` 时，Pandas 会自动用 `0、1、2、3、4、5` 这样的数字作为列名。

示例：

```python
读取数据 = pd.read_csv(r"文件路径.csv", header=None)
```

效果：

- 第一行数据不再是表头。
- 表头会显示为 `0、1、2、3、4、5` 等自动编号。

### 5.3 `names`：人造表头

- `names` 用于指定表头怎么写。
- 表头使用列表形式给出。
- 示例数据一共有六列，从 0 到 5，共六列。
- `names` 一般要和 `header=None` 配合使用。
- 讲师强调：
  - 只写 `header` 可以。
  - 只写 `names` 不行。
  - 这两个参数要配合着使用。

示例：

```python
读取数据 = pd.read_csv(
    r"文件路径.csv",
    header=None,
    names=["姓名", "性别", "年龄", "手机", "地址", "入职日期"]
)
```

运行后数据就有了人造表头。

### 5.4 `index_col`：指定索引列

- `index_col` 用来指定某一列作为索引。
- 默认情况下，Pandas 会给我们单独生成一个索引列，从 0 开始一直到 6。
- 如果数据中没有序号列，也可以指定任意一列作为索引。
- 指定一列作为索引：

```python
读取数据 = pd.read_csv(r"文件路径.csv", index_col="入职日期")
```

运行后会把“入职日期”作为索引列。

- 也可以指定多个索引列，只需要把参数值变成列表形式：

```python
读取数据 = pd.read_csv(
    r"文件路径.csv",
    index_col=["姓名", "入职日期"]
)
```

讲师特别强调：

- 索引不是排序，一定不要搞混。
- 学过 Python 基础课程第 18 节“Python 之 MySQL”的内容时，讲过数据库里的索引列关系，可以回去翻阅。

### 5.5 `skiprows`：跳过某几行

- `skiprows` 用于跳过指定行。
- 参数使用列表形式表示。
- 例如不想显示第 2 行和第 3 行的“郭靖、黄蓉”，可以写：

```python
读取数据 = pd.read_csv(r"文件路径.csv", skiprows=[2, 3])
```

- 也可以继续写更多行号，例如 `[2, 3, 5, 6, 7, 8]` 等，只要数据中存在这些行即可。
- 跳过之后：
  - 不只是把第 2、3 行跳过去。
  - 索引号还会连续上，即 `0、1、2、3、4`。
- 这表示“跳过去”，并不是“删除”。
- 删除的话，索引通常不会发生变化；而 `skiprows` 是当这些行不存在，所以索引继续保持连续。

### 5.6 `encoding`：指定文本编码

- 如果 `txt` 文件的编码不是 `UTF-8`，在中国大陆地区的操作系统上可能出现乱码。
- 这种情况下需要指定编码。
- 指定方式：

```python
读取数据 = pd.read_csv(r"文件路径.txt", encoding="utf-8")
```

- 示例文件本身是 `UTF-8` 编码，所以不需要指定。
- 如果文件不是 `UTF-8`，读取时加上 `encoding="utf-8"` 即可。

### 5.7 `nrows`：一次读取指定行数

- `nrows` 用于指定一次读取多少行。
- 例如只读取三行：

```python
读取数据 = pd.read_csv(r"文件路径.csv", nrows=3)
```

- 效果上和 `head(3)` 类似，但写的位置不同。
- 讲师不推荐写在 `print` 里面，而推荐写在 `read_csv` 方法后面。
- 区别：
  - 写在 `print` 里，只是改变打印显示结果。
  - 写在 `read_csv` 的参数里，改变的是“读取数据”这个变量本身。
- 如果只改变打印结果，下面又忘了写限制行数，再次调用变量时可能显示全部数据，数据大时可能死机。
- 因此推荐使用 `nrows` 控制读取行数。

## 6. 将 txt 文件转换为 csv 文件

在实际数据分析中，讲师建议尽可能不要直接用 `txt` 文件分析，而要使用 `csv` 文件。但有时下载或考核拿到的文件就是 `txt`，这时需要转换。

转换只需要两行代码，不包括导入库：

```python
数据 = pd.read_csv(r"文件路径.txt")
数据.to_csv(r"文件路径.csv")
```

操作步骤：

- 先读取 `txt` 文件。
- 再使用 `to_csv` 建一个 `csv` 文件。
- 运行前先删除之前测试用的 `csv` 文件。
- 运行后成功生成 `csv` 文件。

讲师说明：

- 生成后的 `csv` 文件直接打开可能是乱码格式。
- 可以在参数那里重新编码成 `UTF-8`。
- 也可以使用编码格式进行重新编码。
- 关于 `tsv` 文件，讲师没有用案例演示，但操作方法完全一样，没有区别。

## 7. 本节总结与讲师建议

- 本节主要学习如何使用 Pandas 读写 `txt`、`tsv`、`csv` 文件。
- 读取 `txt` 和 `csv` 文件时：
  - 可以使用 `read_csv` 方法。
  - 也可以使用 `read_table` 方法。
- 两者区别：
  - `read_csv` 默认逗号分隔。
  - `read_table` 默认 `\t` 制表符分隔。
- 如果文件中既有空格又有制表符：
  - 使用正则表达式 `\s+` 表示一个或多个空白字符。
- 读取 `csv` 文件时，可以查看：
  - 第几行数据：`head()`，默认五行，不推荐写在 `print` 中。
  - 数据形状：`shape`，查看几行几列。
  - 列名：`columns`。
  - 索引：`index`。
  - 数据类型：`dtypes`。
- 可以自己指定分隔符和列名：
  - 没有表头时，用 `header=None` 告诉 Pandas 没有表头。
  - 用 `names=[...]` 指定人造表头。
  - `header` 和 `names` 一般配合使用。
- 需要转换编码时：
  - 使用 `encoding="utf-8"`。
- 需要指定索引时：
  - 使用 `index_col="列名"`。
  - 多个索引使用列表，例如 `index_col=["姓名", "入职日期"]`。
- 需要从文件开头读取指定行数时：
  - 推荐使用 `nrows`。
  - `nrows=几` 就是一次读几行。
- 不推荐直接使用 `txt` 文件进行大数据分析。
- 推荐转成 `csv` 文件，这是个人习惯，转不转随个人。
- 转换方法就是两行代码：先 `pd.read_csv` 读取 `txt`，再 `数据.to_csv` 保存为 `csv`。
