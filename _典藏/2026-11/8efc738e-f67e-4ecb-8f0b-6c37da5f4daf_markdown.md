# Pandas 数学统计函数学习笔记

## 内容概述

本节课主要学习 pandas 中的数学统计函数，核心函数是 `describe()`。通过它可以一次性得到数值列的数量、均值、标准差、最小值、分位数和最大值等统计信息。其他数学统计函数只需了解用途，实际使用时在对象后通过“点”调用相应函数即可，不必全部记忆。

## 2. 核心函数：`describe()`

### 2.1 基本用法

对 DataFrame 直接调用：

`df.describe()`

运行后会返回数值列的统计摘要。该函数只计算数值列，不会对姓名这类非数值列进行统计。

### 2.2 返回结果各项含义

`describe()` 返回的常见统计量包括：

- `count`：数量统计，统计该列中有多少个值。
- `mean`：均值，即平均值。
- `std`：标准差。
- `min`：最小值。
- `max`：最大值。
- \(25\%\) 分位数，也就是 \(1/4\) 分位数。
- \(50\%\) 分位数，也就是 \(1/2\) 分位数，通常对应中位数。
- \(75\%\) 分位数，也就是 \(3/4\) 分位数。

通过 `describe()` 一次运行，就可以把多个数值列的统计信息全部计算并展示出来，非常方便。

### 2.3 注意事项

- `describe()` 只统计数值列。
- 姓名列不会被计算。
- 语文、数学、英语等数值列会一起输出统计结果。
- 标准差、四分位数等在某些工作场景中可能暂时用不到，但需要时可以直接查表使用。

## 3. 指定列查看统计信息

### 3.1 查看单列统计信息

如果只想查看某一列的统计信息，可以先选取该列，再调用 `describe()`：

`df['语文'].describe()`

这样可以只显示“语文”这一列的统计结果。

### 3.2 查看多列统计信息

如果想查看某几列，可以在列名列表中写多个列名：

`df[['语文', '数学']].describe()`

将来数据可能有几百列时，这种指定列的方式非常有用，可以只看自己关心的列。

### 3.3 查看单个统计量

如果不想显示 `describe()` 的全部结果，只想查看某个统计量，可以直接在列后调用对应函数。例如查看语文均值：

`df['语文'].mean()`

查看语文最大值：

`df['语文'].max()`

查看方差、标准差等也采用同样方式：

`df['语文'].var()`

`df['语文'].std()`

核心用法是：在 DataFrame 或 Series 后面打一个点，再写函数名。

## 4. 数学统计函数汇总

视频中整理了一张数学统计函数表，常见函数如下：

| 统计功能 | pandas 函数 | 说明 |
|---|---|---|
| 个数 | `count` | 统计数量 |
| 求和 | `sum` | 计算总和 |
| 平均 | `mean` | 平均值，注意不是 `average` |
| 中位数 | `median` | 中位数 |
| 最小值 | `min` | 最小值 |
| 最大值 | `max` | 最大值 |
| 众数 | `mode` | 出现次数最多的值，视频中称为“重数” |
| 乘积 | `prod` | 连乘结果 |
| 方差 | `var` | 方差 |
| 标准差 | `std` | 标准差 |
| 分位数 | `quantile` | 可分位数统计 |
| 累最大值 | `cummax` | 累积最大值 |
| 累最小值 | `cummin` | 累积最小值 |
| 协方差 | `cov` | 协方差 |
| 相关系数 | `corr` | 相关系数 |

补充说明：

- 平均值在 pandas 中使用 `mean`，不是 Excel 中常见的 `average`。
- 协方差 `cov` 和相关系数 `corr` 在数据分析岗位中使用较多。
- 如果暂时用不到某些函数，不必强行记忆；真正需要时查表即可。
- 这些函数的使用方法都很简单：在 DataFrame 或 Series 后打点，再写函数名。

## 5. 学习建议与结论

- 本节课重点掌握 `describe()`，它能一次性输出数值列的核心统计信息。
- 记住 `describe()` 只统计数值列，不会统计姓名等非数值列。
- 可以通过列选择控制统计范围：单列使用 `df['列名']`，多列使用 `df[['列1', '列2']]`。
- 查看某个具体统计量时，直接在列后调用函数，例如 `df['语文'].mean()`、`df['语文'].max()`。
- Excel 演示数据在实际工作中可以替换为 CSV，读取时改用 `read_csv`。
- 其他数学统计函数不要求全部记住，知道用途并会查表即可。
- 协方差、相关系数、分位数等内容需要一定的概率统计基础；遇到不熟悉的概念时，应复习概率统计相关知识。
