# Pandas 入门：数据类型与新建文件

## 课程定位

- 这是 Pandas 系列的第一节课，主题是 **数据类型与如何新建文件**。
- 本节课主要学习：
  - 如何导入 Pandas 库。
  - Pandas 常用数据类型及对应文件格式。
  - 如何在 Python 中使用 Pandas 新建 Excel、CSV 等文件。
  - 简单认识 `DataFrame` 与 `Series`。
- 数据结构更详细的讲解安排在后续第三节，本节课只做简单引入。

## 导入 Pandas 库

- 导入方式：

```python
import pandas as pd
```

- `pd` 是 Pandas 的常用别名，属于约定俗成的写法。
- 使用别名的目的：避免每次都写 `pandas.xxx`，减少重复输入。
- 别名可以修改，例如改成其他名称甚至中文也可以，但建议遵循通用习惯，使用 `pd`。
- 这与 NumPy 通常使用 `np` 作为别名类似。

## 常见数据类型与新建文件方法

Pandas 支持的数据类型很多，但课程中强调常用类型主要有以下几种：

| 文件类型 | 常见方法 | 说明 |
|---|---|---|
| CSV | `to_csv` | 逗号分隔的纯文本文件 |
| TXT | `to_csv` 等方法类似 | 可用逗号或 Tab 等分隔符保存的纯文本文件 |
| Excel | `to_excel` | Excel 表格文件，如 `.xlsx` |
| SQL | `to_sql` | 写入 SQL 数据库时使用 |

需要注意：

- 视频中口述为 `pd.to_csv`、`pd.to_excel`、`pd.to_sql`，实际演示时是在 `DataFrame` 数据对象上调用方法，例如 `data.to_excel(path)`。
- 转录中的 `pd.two下划线circle` 属于识别误差，按技术含义应为 `to_sql`。
- 掌握 `to_csv`、`to_excel`、`to_sql` 这三种文件新建/写出方法基本足够。
- JSON 等文件虽然也常用，但不需要通过这种方式重点学习新建。
- 其他文件格式与 Excel、CSV 的写法大同小异，通常只需修改方法名和文件后缀。

## DataFrame 与 Series 的简单区别

- `DataFrame`：
  - 表示一张 **二维数据表**。
  - 有行有列。
  - 类似一张工作表，例如三行三列、五行五列的数据表。
- `Series`：
  - 表示 **一维数据**。
  - 可以是一行，也可以是一列。
  - 需要注意：它是一维数据，不等同于“一维数组”的严格概念。
- 本节课以 `DataFrame` 为主，使用一张简单的二维表进行演示。

## 新建 Excel 文件演示

### 准备保存路径

- 新建文件前先确定保存位置，可以先把路径保存到变量中。
- 示例中路径类似：

```python
path = r"C:\pandas\孙兴华.xlsx"
```

- 将路径写入变量的好处：
  - 后续频繁调用时不用反复写长路径。
  - 修改保存位置时更方便。
- 也可以不使用路径变量，直接把路径字符串写在 `to_excel` 方法中。

### 新建空白 Excel 文件

- 使用 `DataFrame` 调用 `to_excel` 方法即可生成 Excel 文件：

```python
import pandas as pd

path = r"C:\pandas\孙兴华.xlsx"

data = pd.DataFrame()
data.to_excel(path)
```

- 运行后程序提示成功，并在指定目录生成一个空白 Excel 文件。
- 演示中生成的文件时间显示为当前时间，例如约 22:02。
- 这说明 Pandas 可以新建 Excel 文件；如果不写入数据，文件内容为空。

### 新建文件时同时写入数据

如果要新建文件的同时写入数据，需要先构造 `DataFrame` 数据，再调用 `to_excel`。

视频中使用 **字典** 的方式构造数据：

```python
data = pd.DataFrame({
    "序号": [1, 2, 3],
    "姓名": ["叶问", "李小龙", "新化"]
})
```

说明：

- 字典以键值对形式出现。
- 字典的键表示列名，例如 `"序号"`、`"姓名"`。
- 字典的值通常使用列表，表示这一列各行的数据。
- 数值类型不需要加引号，例如 `1, 2, 3`。
- 字符串类型需要加引号，例如 `"叶问"`、`"李小龙"`。
- 键名应唯一，表示列名；列表中的值可以重复。

将数据写入 Excel：

```python
data.to_excel(path)
```

运行后生成包含序号、姓名数据的 Excel 文件。

## 默认索引列问题与 `set_index`

直接使用 `to_excel` 写出一张表时，Excel 中可能出现一个额外的索引列：

- 默认索引从 `0` 开始，例如 `0, 1, 2`。
- 该列不是原始字段，而是 `DataFrame` 自带的默认索引。
- 通常这个默认索引列不是业务数据中需要的。

视频中的处理方式：将业务字段设置为索引列，从而取消默认索引列。

```python
data = data.set_index("序号")
```

说明：

- `set` 表示设置。
- `index` 表示索引。
- `set_index("序号")` 表示把“序号”列设置为索引。
- 设置后，默认的 `0, 1, 2` 索引列不再作为额外列出现。
- 视频中通过重新运行代码，生成的 Excel 文件显示正常。

完整示例：

```python
import pandas as pd

path = r"C:\pandas\孙兴华.xlsx"

data = pd.DataFrame({
    "序号": [1, 2, 3],
    "姓名": ["叶问", "李小龙", "新化"]
})

data = data.set_index("序号")
data.to_excel(path)
```

## 新建 CSV 文件演示

- CSV 文件与 Excel 文件的创建方式类似。
- 只需把 `to_excel` 改为 `to_csv`，并将文件后缀改为 `.csv`。
- 示例：

```python
path = r"C:\pandas\孙兴华.csv"

data.to_csv(path)
```

- 运行后会在指定目录生成 `.csv` 文件。
- 演示中生成时间约为 22:07。
- CSV 文件本质上是纯文本文件，使用逗号分隔数据。
- 打开后可以看到序号、姓名等数据内容。
- 例如数据会以类似逗号分隔的形式保存：

```text
序号,姓名
1,叶问
2,李小龙
3,新化
```

- 如果创建 TXT 或 SQL 文件，思路类似：
  - CSV：`to_csv`
  - Excel：`to_excel`
  - SQL：`to_sql`
- 视频只重点演示 CSV，其他格式只需修改方法名和文件名后缀即可。

## 关于“为什么要在 Python 中新建 Excel”的理解

视频中提到一个常见疑问：既然可以直接打开 Excel 新建文件，为什么还要在 Python 中操作？

核心原因是批量处理和自动化场景：

- 单张表手动新建可能更方便。
- 但如果有大量表、需要循环处理、需要条件判断时，代码效率远高于手动复制粘贴。
- 视频用 VBA 中的 `if` 语句和大量表格处理举例说明：如果未来有 100 张表需要判断处理，可以用 `for` 循环配合 `if` 语句完成；手动在 Excel 中操作则需要重复大量复制粘贴。
- 因此学习 Pandas 应从基础操作开始，不能因为简单场景下“看起来没必要”就跳过基础内容。
