## 课程主题
本课讲解 Pandas 的连接查询之 `concat`，属于 Pandas 数据合并与重塑的最后一个重点内容。核心是理解 `concat` 如何沿着轴连接多个对象，并掌握常用参数与典型应用场景。

## NumPy 轴概念回顾
- 在 NumPy 中，一维数组只有一行数据，对应一个零轴。
- 二维数组中：
  - `axis=0` 表示行方向，即纵向。
  - `axis=1` 表示列方向，即横向。
- 示例：`np.arange(9).reshape(3,3)` 生成 3 行 3 列数组，值为 0 到 8。
- `np.concatenate([a, a], axis=1)` 表示按列方向合并，得到横向拼接结果。
- `np.concatenate([a, a], axis=0)` 表示按行方向合并，得到纵向堆叠结果。
- 课程强调：使用 `concat` 前必须搞清楚轴，`axis=0` 是行、`axis=1` 是列，否则后续内容容易混淆。

## Pandas concat 基础用法
- 示例数据一：`Series` 值为 `[0,1,2]`，索引为 `['a','b','c']`。
- 示例数据二：`Series` 值为 `[3,4]`，索引为 `['d','e']`。
- 使用 `pd.concat([数据一, 数据二])` 时，默认沿着 `axis=0` 进行行方向连接。
- 默认效果相当于把第二个 `Series` 直接放到第一个下面，并保留各自索引。
- 如果设置 `axis=1`，则进行横向连接。由于两个 `Series` 的索引不同，行索引无法完全对齐，因此会出现 `NaN` 空值。
- `sort` 参数默认是 `True`，Pandas 默认会按索引排序；如果不希望自动排序，可将其设为 `False`。本节重点不是排序，而是数据合并与重塑。
- 课程建议：相比直接用较弱的 `join` 方法，更推荐使用 `concat` 这类参数更多、应用范围更广的方法。

## 相同字段表的首尾相连
- 示例中有三张表 `df1`、`df2`、`df3`。
- 三张表字段相同，均为 `a`、`b`、`c`、`d`。
- 索引分别为：
  - `df1`：`0` 到 `3`
  - `df2`：`4` 到 `7`
  - `df3`：`8` 到 `11`
- 这种表适合使用默认的 `pd.concat([df1, df2, df3])` 进行首尾连接，即纵向堆叠。
- 多张表连接时，可以把表放入列表中，再传给 `concat`。
- 建议先把列表赋值给变量，例如 `frames = [df1, df2, df3]`，再写 `pd.concat(frames)`。这样后续修改列表或复用时更方便，也便于排查问题。
- 基本形式：`pd.concat([df1, df2, df3])`，默认按 `axis=0` 纵向连接。

## 使用 keys 增加层次索引标识来源
- 多个表首尾相连后，默认结果无法直接看出某行数据来自哪张原始表。
- 可通过 `keys` 参数增加层次索引，用于标识数据来源。
- 示例：`pd.concat([df1, df2, df3], keys=['x','y','z'])`。
- 也可以写成表名，例如“表一、表二、表三”或实际业务表名。
- 添加 `keys` 后，便于后续按来源表筛选数据。
- `keys` 的顺序与传入表列表的顺序对应：第一个 key 对应第一张表，第二个 key 对应第二张表，依此类推。

## 横向拼接与行对齐
- `concat` 的另一类常见用法是横向拼接，即设置 `axis=1`。
- 横向拼接不是简单并排，而是按照行索引进行对齐。
- 示例中一张表索引为 `0、1、2、3`，另一张表的数据涉及 `2、3、6、7` 等索引。按索引对齐后：
  - 共同索引位置的数据会合并到同一行。
  - 某张表没有的索引位置会产生空值。
  - 重复或对齐上的索引按索引匹配处理。
- `axis=1` 表示沿列轴扩展，但实际逻辑是行索引对齐。
- 课程提醒：不要把“列轴”与“行对齐”混淆。`axis=1` 是列方向拼接，但对齐依据是行索引。

## join 参数：inner 与 outer
- `concat` 中的 `join` 参数用于控制对齐方式。
- `join='inner'`：内连接，得到两个表的交集，只保留共同索引。
- 示例：`pd.concat([df1, df4], axis=1, join='inner')`，横向拼接两张表并取交集。
- 如果两张表共同索引是 `2` 和 `3`，则结果只保留索引 `2、3` 对应的数据。
- `join='outer'`：全外连接，得到并集，保留所有索引，缺失处填 `NaN`。
- 注意：这里的 `join` 是 `concat` 的参数，不要与 Pandas 的 `join` 方法混淆。

## join_axes：指定对齐基准轴
- 视频中称为 `join_axis`，实际对应旧版 Pandas 参数 `join_axes`。
- 该参数用于指定根据哪个轴对数据，即以某张表的索引为基准进行对齐。
- 示例：`pd.concat([df1, df4], axis=1, join_axes=df1.index)`。
- 含义：以 `df1` 的索引为基准，保留 `df1` 的轴，然后把另一张表的数据按该索引匹配过来。
- 效果类似 Excel 中的 `VLOOKUP`：
  - `df1` 中存在的索引会保留。
  - 另一张表有对应索引的数据则拼接过来。
  - 另一张表没有的索引位置为空。
  - `df1` 中没有的索引不会被保留。
- 课程用“飞过来”的比喻说明按基准表索引取数。

## append 方法追加数据
- `append` 不是 `concat` 的方法，而是 `Series` 和 `DataFrame` 的方法，但可以放在连接查询中一起理解。
- `append` 表示追加，通常把数据追加到表的下方，并按照列进行对齐。
- 示例：`数据一.append(数据二)`。
- 效果与 `concat` 默认的纵向连接方式相近。
- 在 Excel 的 Power Query 中，类似“追加查询”，即把数据往底下追加；但课程提醒不要抬杠，二者并非完全一样，只是类比。
- 实际使用中，`append` 和 `concat` 默认方式都可以，取决于个人习惯。

## ignore_index 忽略原索引
- 使用 `append` 或 `concat` 时，如果不想保留原索引，可以设置 `ignore_index=True`。
- 该参数会忽略原来的索引，按照合并后的顺序从上到下生成新的连续索引。
- 示例场景：把一列数据或一行数据追加到表中，不关心原索引，只希望直接形成新表。
- 写法示例：`df1.append(s2, ignore_index=True)`。
- 设置后可直接把数据追加过去，并生成新的索引。
- 课程强调：遇到“竖着的数据想倒成横向/追加到表中”的情况，加一个 `ignore_index=True` 即可，非常简单。

## 忽略索引的 concat
- `concat` 也可以设置 `ignore_index=True`，实现无视原索引的合并。
- 合并时不再沿用原索引，而是根据合并后的数据顺序生成新的索引。
- 合并仍会按列字段进行对齐。
- 示例：一张表字段为 `a、b、c、d`，另一张表字段为 `b、d、f`。
  - `a` 在第二张表中没有，则对应位置为空。
  - `b` 有则匹配过来。
  - `c` 在第二张表中没有，则为空。
  - `d`、`f` 按字段对齐。
  - 第一张表没有 `f`，因此 `f` 在旧表对应位置为空。
- 关键点：`ignore_index=True` 只影响索引，不改变按列名对齐的规则。

## 传入字典增加分组键
- 除了用 `keys` 列表标识来源，还可以向 `concat` 传入字典来增加分组键。
- 示例：先构造字典 `{'x': df1, 'y': df2, 'z': df3}`，再传给 `concat`。
- 字典的 key 作为分组标识，字典的 value 作为要合并的表。
- 最终效果与使用 `keys=['x','y','z']` 基本相同。
- 这种方式便于表达“哪张表对应哪个来源名称”。

## 在 DataFrame 中加入新的行
- `append` 可以把 `Series` 或字典作为新行追加到 `DataFrame` 中。
- 示例：已有 `df1`，字段为 `a、b、c、d`；另有新数据以 `Series` 或字典表示，字段为 `a、b、c、x、y`。
- 实际工作中数据通常是现成的，只需要读取文件并存入变量，不一定手工新建表。
- 课程提醒：前面先讲如何新建文件、读取文件，再讲数据操作，是因为实际工作中的数据通常来自读取，而不是手工构造。
- 追加多列数据时，可以把新数据构造成字典或读取为 `Series`/`DataFrame`，再用 `append` 追加。
- 示例：`df1.append(s2, ignore_index=True)`，其中 `s2` 可以是 `pd.Series` 构造的数据。
- 设置 `ignore_index=True` 后，忽略原索引，直接按顺序生成新索引。

## 字段不同的表合并
- 两张表字段不完全相同时，也可以纵向合并。
- 无效值或缺失字段会自动用 `NaN` 表示。
- 示例：`df1` 字段为 `a、b、c、d`；新数据字段为 `a、b、c、x、y`。
- 追加后：
  - `a、b、c` 在新旧数据中都有，正常对齐。
  - `d` 对新数据为空。
  - `x、y` 对旧数据为空。
- 可使用字典建立新行，再通过 `append` 追加，并设置 `ignore_index=True`。
- 实际工作中可直接读取另一张表，然后进行追加合并。

## 总结：concat、merge 与 join
- `concat`：沿着一条轴将多个对象连接在一起，核心是轴 `axis`。
- `merge`：根据一个或多个键（通常是字段名）将不同的 `DataFrame` 连接起来。
- `join`：涉及交集与并集关系，例如 `inner`、`outer`。
- 工作中大多数情况下使用的是 `concat`，其次是 `merge`。
- 课程不建议优先使用较弱的 `join` 方法；既然使用 Pandas 做数据分析，应优先掌握 `concat` 和 `merge` 等更常用的方式。
- 使用 `concat` 的关键是分清轴：
  - `axis=0`：纵向、首尾相连。
  - `axis=1`：横向、按行索引对齐。
- 常用参数包括：`axis`、`keys`、`join`、`join_axes`（旧版）、`ignore_index`、`sort`。
- 对字段不同的表合并时，缺失字段自动填充 `NaN`；需要重新生成索引时使用 `ignore_index=True`。
