## 2. 回顾 NumPy 的 `concatenate` 与 `axis`

### 2.1 构造 NumPy 数组

```python
import numpy as np

a = np.arange(9).reshape(3, 3)
print(a)
```

- `np.arange(9)` 生成 `0` 到 `8`，不包含结束值 `9`，步长为 `1`。
- `.reshape(3, 3)` 将其变为 `3×3` 的二维数组。
- 结果形式为：

```text
[[0 1 2]
 [3 4 5]
 [6 7 8]]
```

### 2.2 `axis` 的含义

- 一维数组只有一行数据，只有一个 `0` 轴，方向为从左向右。
- 二维数组有两个轴：
  - `axis=0`：行方向。
  - `axis=1`：列方向。
- 讲师反复强调：**零轴是行，一轴是列**。后面 Pandas 的 `concat` 也依赖轴，必须搞清楚，否则后续无法学。

### 2.3 `np.concatenate` 按列合并

```python
np.concatenate([a, a], axis=1)
```

- `axis=1` 表示按列方向合并。
- 两个 `3×3` 数组合并后变成 `3×6`，可以理解为两个数组并排拼接成更多列。

### 2.4 `np.concatenate` 按行合并

```python
np.concatenate([a, a], axis=0)
```

- `axis=0` 表示按行方向合并。
- 两个 `3×3` 数组上下堆叠，变成 `6×3`。
- 这一部分为后面理解 Pandas `concat` 的 `axis=0` 与 `axis=1` 做铺垫。

## 3. Pandas `concat` 基础用法与默认行为

### 3.1 构造 Series 示例

```python
import pandas as pd

s1 = pd.Series([0, 1, 2], index=['a', 'b', 'c'])
s2 = pd.Series([3, 4], index=['d', 'e'])
```

- `s1`：索引为 `a、b、c`，值为 `0、1、2`。
- `s2`：索引为 `d、e`，值为 `3、4`。
- 讲师用 `print` 打印两个数据，帮助理解索引不同情况下的连接结果。

### 3.2 默认连接：`axis=0`，纵向首尾相接

```python
pd.concat([s1, s2])
```

- `pd.concat` 默认 `axis=0`。
- 默认行为相当于行连接、纵向连接，把第二个数据放到第一个数据下面。
- 可以类比 Excel 中把两张表上下拼接。
- 讲师解释：默认情况下 `concat` 就是把两个表格“直接拿过来放到下面”，按 `axis=0` 进行重塑合并。

### 3.3 改为横向连接：`axis=1`

```python
pd.concat([s1, s2], axis=1)
```

- `axis=1` 表示按列方向拼接，横向连接。
- 横向拼接时根据索引对齐。
- 因为 `s1` 的索引是 `a、b、c`，`s2` 的索引是 `d、e`，索引不完全一致，所以没有对应值的位置会出现空值。
- 讲师解释：`d、e` 在原来的零轴上没有对应项，在一轴方向上有数据；因此横向拼接后会出现空缺，而不是简单把值横着接过去。

## 4. `sort` 参数与排序说明

- 讲师提到 `sort` 参数，视频中发音近似“short”。
- 按视频所用版本说明：`sort=True` 是默认值，Pandas 默认会按照 `index` 排序。
- 如果不希望它自动排序，可以设置 `sort=False`，再用之前学过的排序方法自行排序。
- 本节重点是列数据合并与重塑，讲师暂不展开排序问题。

## 5. 常用应用一：相同字段表首尾相连

### 5.1 示例设定

```python
# 假设有三张表
# df1 索引 0~3，字段 a b c d
# df2 索引 4~7，字段 a b c d
# df3 索引 8~11，字段 a b c d
```

- 三张表的字段相同，都是 `a、b、c、d`。
- 目标是把三张表首尾连接在一起。

### 5.2 基本写法

```python
frames = [df1, df2, df3]
pd.concat(frames)
```

- 默认 `axis=0`，因此三张表纵向堆叠。
- 也可以直接写成：

```python
pd.concat([df1, df2, df3])
```

### 5.3 讲师建议：先把列表赋给变量

```python
frames = [df1, df2, df3]
result = pd.concat(frames)
```

- 讲师建议把要连接的表先放进一个列表变量中，再传给 `concat`。
- 原因：
  - 后续需要修改表列表时，只改变量即可，不用到处找 `concat`。
  - 这个列表将来可能还被其他方法或函数复用。
  - 多写几行没问题，便于后期排查问题。
- 这是 `concat` 最基本的用法。

## 6. 常用应用二：`keys` 增加层次索引，标识数据来源

### 6.1 问题背景

- 默认把三张表首尾相连后，结果中不会直接显示每条数据来自哪张表。
- 如果想知道数据来自 `df1`、`df2` 还是 `df3`，可以使用 `keys` 参数。

### 6.2 使用 `keys` 参数

```python
pd.concat(frames, keys=['x', 'y', 'z'])
```

- `keys` 后接一个列表。
- 有几张表，就写几个键。
- 第一个键对应第一张表，第二个键对应第二张表，第三个键对应第三张表。
- 键可以写 `x、y、z`，也可以写“表一、表二、表三”，或者直接写真实表名。
- 作用：在连接结果中增加一层索引，标识数据来自哪张表，方便后续筛选和分析。

## 7. 横向拼接表与行对齐

### 7.1 横向拼接使用 `axis=1`

```python
pd.concat([df1, df4], axis=1)
```

- `axis=1` 表示横向拼接。
- 横向拼接时，不是把表放到下面，而是把列并排拼在一起。
- 拼接时按行索引进行对齐。

### 7.2 行对齐的含义

- 假设 `df1` 的索引为 `0、1、2、3`。
- 另一张表的数据索引可能为 `2、3、6、7`。
- 横向拼接时：
  - 索引 `2、3` 两边都有，直接对齐拼在一起。
  - 索引 `6、7` 在 `df1` 中没有，则 `df1` 对应位置为空值。
  - 索引 `0、1` 在另一张表中没有，则另一张表对应位置为空值。
- 讲师强调：`axis=1` 指的是列轴，但横向拼接表现出来是按行索引对齐，不要把“行对齐”和“轴方向”弄混。

## 8. `join` 参数：内连接与外连接

### 8.1 `join='inner'`：交集/内连接

```python
pd.concat([df1, df4], axis=1, join='inner')
```

- `join='inner'` 得到两个表索引的交集。
- 只有两边都存在的索引才会保留。
- 视频示例中两边共同索引为 `2、3`，因此只保留 `2、3` 对应的数据。
- 这就是内连接。

### 8.2 `join='outer'`：全外连接/并集

- `join='outer'` 得到全外连接，也就是并集。
- 两边所有索引都保留，缺失位置补空值。
- 讲师提醒：这里的 `join` 是 `concat` 的参数，不要与 `DataFrame.join` 方法混淆。

## 9. `join_axes` 参数：指定按哪个轴对齐

### 9.1 参数含义

```python
pd.concat([df1, df4], axis=1, join_axes=[df1.index])
```

- `join_axes` 用于指定根据哪个轴来对齐数据。
- 传入 `[df1.index]` 表示以 `df1` 的索引为基准。
- 结果会保留 `df1` 的索引，然后把 `df4` 中能对应上的值拼过来。
- `df1` 中没有的索引不会保留；`df1` 有而 `df4` 没有的位置为空值。

### 9.2 与 VLOOKUP 的类比

- 讲师把这个过程类比为 Excel 的 `VLOOKUP`：
  - 以一张表为基准。
  - 到另一张表中查找对应值。
  - 找到就拼过来，找不到就为空。
- 注意：`join_axes` 是视频所用旧版 Pandas 中的参数，新版 Pandas 可能已移除或不推荐使用，学习时理解其对齐思想即可。

## 10. `append` 方法：追加数据

### 10.1 `append` 的基本作用

```python
s1.append(s2)
```

- `append` 不是 `concat` 的函数，而是 `Series` 和 `DataFrame` 的方法。
- 作用是追加，相当于把第二个数据追加到第一个数据下面。
- 默认会按列进行对齐，类似纵向追加。
- 实现效果与 `pd.concat` 默认 `axis=0` 的方式差不多。
- 讲师说：用 `concat` 还是 `append` 看个人习惯，但 `append` 本身也值得了解。

### 10.2 与 Excel Power Query 的类比

- 讲师把 `append` 类比为 Excel Power Query 中的“追加查询”。
- 追加查询就是把数据往底下追加。
- 但讲师提醒：只是打比方，不是完全一样，不要抬杠。

## 11. `ignore_index=True`：无视原索引

### 11.1 问题背景

- 两张表原来的索引可能不同。
- 如果直接连接，Pandas 会保留原索引，导致结果索引不连续或重复。
- 可以加参数 `ignore_index=True`，忽略原来的索引，生成新的连续索引。

### 11.2 写法

```python
pd.concat([df1, df2], ignore_index=True)
```

或在使用 `append` 时：

```python
df1.append(df2, ignore_index=True)
```

- `ignore_index=True` 表示合并时无视原索引。
- 新结果会按照当前顺序从上到下生成新索引。
- 同时仍然根据列字段对齐，不是按原索引对齐。
- 只在一侧存在的列字段会补空值。
- 讲师示例说明：两张表索引即使不同，也可以直接追加；索引不再参与对齐，列字段相同的地方直接归并。

## 12. 合并同时增加区分数据组的键

### 12.1 使用 `keys` 参数

```python
frames = [df1, df2, df3]
pd.concat(frames, keys=['x', 'y', 'z'])
```

- 作用与前面讲 `keys` 一样。
- 给不同来源的数据增加分组键，方便知道数据来自哪张表。

### 12.2 传入字典实现同样效果

```python
frames = {
    'x': df1,
    'y': df2,
    'z': df3
}
pd.concat(frames)
```

- 先建立字典：
  - 字典的 `key` 是表名或分组名。
  - 字典的 `value` 是对应的 DataFrame。
- 把字典直接传给 `pd.concat`，字典的 `key` 会自动成为层次索引/分组键。
- 效果与使用 `keys=['x', 'y', 'z']` 基本一致。

## 13. 在 DataFrame 中加入新的行

### 13.1 用 `Series` 构造一行数据

```python
s2 = pd.Series([值1, 值2, 值3, 值4], index=['a', 'b', 'c', 'd'])
df1.append(s2, ignore_index=True)
```

- `s2` 的索引设置为 `a、b、c、d`，与 `df1` 的列名对应。
- `df1.append(s2, ignore_index=True)` 会把 `s2` 作为新的一行追加到 `df1` 中。
- `ignore_index=True` 表示忽略原索引，生成新的索引。
- 讲师说明：实际工作中通常不是手工新建这张表，而是直接读取现成文件或数据表，把读取结果存入变量即可。前面先讲新建文件、读取文件，是因为读取数据和后续处理是连贯的。

## 14. 表格字段不同的表合并

### 14.1 问题背景

- 两张表的字段不完全一样，但仍需要合并。
- 例如 `df1` 有字段 `a、b、c、d`，另一张表有字段 `a、b、c、x、y`。
- 希望把第二张表追加到第一张表下面，无效值用 `NaN` 表示。

### 14.2 写法

```python
df1.append(df2, ignore_index=True)
```

或：

```python
pd.concat([df1, df2], ignore_index=True)
```

- `ignore_index=True` 忽略原索引，按列字段对齐。
- 结果会取两边字段的并集。
- 相同字段的数据上下归并。
- 只在一张表中存在的字段，在另一张表对应位置补 `NaN`。
- 视频示例中：
  - `a` 列的数据 `1` 和 `5` 归并。
  - `b` 列的数据 `2` 和 `6` 归并。
  - `c` 列的数据 `3` 和 `7` 归并。
  - `d` 在第二张表中没有，因此为空。
  - `x`、`y` 在第一张表中没有，因此第一张表对应位置为空。
- 讲师强调：实际工作中肯定会遇到字段不同的表合并，核心就是按列字段对齐，缺失值自动补空。

## 15. 总结：`concat`、`merge`、`join` 的选型

### 15.1 `concat`

- `concat` 可以沿着一条轴将多个对象连接在一起。
- 它与轴关系密切，必须理解 `axis=0` 和 `axis=1`。
- 常用于：
  - 相同字段表纵向首尾相接。
  - 横向拼接表并按索引对齐。
  - 通过 `keys` 增加来源标识。
  - 通过 `ignore_index=True` 重新生成索引。

### 15.2 `merge`

- `merge` 根据一个或多个键将不同的 DataFrame 进行连接。
- 这里的“键”通常指字段名。
- 适合按某个共同字段连接不同表，类似 SQL 中的连接查询。

### 15.3 `join`

- 视频最后把 `join` 作为另一类连接方式总结，并提到它与交集、并集有关。
- 讲师建议：
  - 工作中大多数情况优先使用 `concat`。
  - 其次使用 `merge`。
  - 不推荐优先使用 `join`，认为 `join` 相对弱一些。
- 需要区分：
  - `concat` 的参数 `join='inner'/'outer'` 控制交集/并集。
  - `DataFrame.join` 是另一种基于索引的连接方法。
  - 不要把两者混为一谈。

## 16. 易混点与踩坑清单

- `axis=0` 是行方向，`axis=1` 是列方向。二维数据中必须牢记：零轴是行，一轴是列。
- `pd.concat` 默认 `axis=0`，表现为纵向首尾相接。
- `axis=1` 横向拼接时按行索引对齐，索引不一致会产生空值。
- `join='inner'` 取索引交集，`join='outer'` 取并集。
- `join_axes` 是旧版参数，用于指定以哪个轴为对齐基准；新版 Pandas 学习时以理解思想为主。
- `sort` 控制是否按索引排序；讲师按视频版本说明默认 `sort=True`，不想排序可设 `sort=False`。
- `ignore_index=True` 与 `sort` 不是一个概念：前者忽略原索引并重新编号，后者控制排序。
- `keys` 列表长度应与表数量一致，顺序决定分组键与表的对应关系。
- `append` 是 Series/DataFrame 的方法，效果类似 `concat` 默认纵向追加；新版 Pandas 中可优先用 `concat` 替代。
- 字段不同的表合并时，结果按列字段取并集，缺失位置自动补 `NaN`。
- 实际工作中数据通常是读取现成文件，不必手工新建所有表；会读取文件并存入变量是关键。
