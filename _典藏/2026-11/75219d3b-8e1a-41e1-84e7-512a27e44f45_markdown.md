# Python 数据分析筛选笔记：Pandas 筛选专题

## 1. 课程定位与前置说明

- 本节主题：**筛选**。老师强调筛选“很重要、很简单、还好玩”。
- CSV 文件不涉及一个文件内有多张工作表的问题。
- Excel 文件可能存在一个工作簿包含多个工作表的情况。
- 不需要先用 VBA 把多张工作表拆成多个工作簿，Pandas 读取时通过参数即可指定工作表。
- 一般实际工作中较少直接打开多张表逐一处理；更常见的是先使用多表连接、重塑等方式合并数据，再进行筛选。相关连接、重塑内容在之前的课程中已经讲过，建议多复习。
- 写筛选条件时，建议先把条件赋值给变量，保持代码整洁；当条件变多时尤其重要。

## 2. 读取 Excel 多工作表：sheet_name 参数

导入 Pandas：

```python
import pandas as pd
```

设置文件路径并读取 Excel：

```python
path = 'C:/.../筛选.xlsx'
数据 = pd.read_excel(path)
```

设置序号为索引：

```python
数据 = 数据.set_index('序号')
```

指定工作表：

```python
数据 = pd.read_excel(path, sheet_name=1)
```

- `sheet_name` 可以理解为工作表名称或工作表索引。
- 视频示例中工作表名称是 `1`，因此也可以写：

```python
数据 = pd.read_excel(path, sheet_name='1')
```

- 如果指定不存在的工作表，例如写成不存在的 `sheet3`，运行会报错，提示找不到该表。
- 如果要读取名为 `11` 的工作表，可以写：

```python
数据 = pd.read_excel(path, sheet_name='11')
```

- 关键点：一个 Excel 工作簿中有多张表时，用 `sheet_name` 选择要操作的那张表即可。

## 3. 按行位置筛选：loc

最简单的筛选：按索引/行号筛选某几行。

示例：筛选序号中第 2 行到第 4 行。

```python
结果 = 数据.loc[2:4]
```

说明：

- `loc` 使用**中括号** `[]`。
- 视频强调：筛选后需要把结果赋值给一个新的变量或对象。
- 如果只写：

```python
数据.loc[2:4]
```

然后直接查看原 `数据`，原数据不会按预期改变。
- 需要先定义变量、赋值，再运行查看：

```python
筛选结果 = 数据.loc[2:4]
```

- `loc` 后使用中括号；而 `query` 等其他方法通常使用小括号 `()`，不要混淆。

## 4. 按列值筛选单条件

目标：筛选性别为“男”的所有记录。

推荐写法：先定义条件，再用条件筛选数据。

```python
条件 = 数据['性别'] == '男'
结果 = 数据[条件]
```

解释：

- 从 Excel 或 CSV 读取出来的数据是 `DataFrame`，是一张二维数据表。
- `数据['性别']` 取出的是一列，类型为 `Series`。
- `数据['性别'] == '男'` 会生成一个布尔条件。
- `数据[条件]` 根据条件筛选出所有满足条件的行。

视频中也演示了直接写条件的方式，但不推荐：

```python
数据[数据['性别'] == '男']
```

原因：现在只有一个条件还好，条件多了以后代码会很长、很乱。建议把条件单独赋值给变量。

## 5. 多条件筛选：query 方法

目标：筛选“性别为男”且“总分大于等于 150”的记录。

示例数据中：

- 王松：总分 162
- 陆海军：总分 153
- 王刚：总分 142，不满足总分条件，会被过滤掉

使用 `query`：

```python
条件 = "性别 == '男' and 总分 >= 150"
结果 = 数据.query(条件)
```

说明：

- `query` 可以接收一个字符串，通过字符串进行查询。
- 类似 SQL 的写法，可以使用 `and`、`or`、`in` 等。
- 不需要反复写 `数据['某列'] == ...`，条件多时更方便。

引号规则：

- 外层字符串用双引号，内层字符串用单引号：
  
```python
条件 = "性别 == '男' and 总分 >= 150"
```

- 或者外层用单引号，内层用双引号。关键是内外引号不能冲突。
- 这是 Python 基础课中字符串引号嵌套的知识点。

不推荐但可行的写法：

```python
条件 = (数据['性别'] == '男') & (数据['总分'] >= 150)
结果 = 数据[条件]
```

视频建议：条件少时两种都可以；条件多时 `query` 更清晰。

## 6. query 支持 in：筛选多个指定值

目标：筛选姓名是“李萍萍”或“王刚”的记录。

```python
条件 = "姓名 in ['李萍萍', '王刚']"
结果 = 数据.query(条件)
```

说明：

- `query` 支持类似 SQL 的 `in` 语法。
- 需要给字段名，并告诉它包含哪些值。
- 其他字段也可以同理使用。
- 注意单引号和双引号问题。

类似 SQL：

```sql
店铺编号 in (1, 3, 5, 7)
```

Pandas 的 `query` 也能达到类似筛选效果。

## 7. 字符串开头、结尾筛选：startswith / endswith

目标：筛选姓名以“王”开头的记录。

```python
条件 = 数据['姓名'].str.startswith('王')
结果 = 数据[条件]
```

目标：筛选姓名以“松”结尾的记录。

```python
条件 = 数据['姓名'].str.endswith('松')
结果 = 数据[条件]
```

说明：

- 做开头、结尾匹配时，通常先指定字符串列，并加上 `.str`。
- `startswith` 表示以某内容开头。
- `endswith` 表示以某内容结尾。
- 参数可以是一个字符、两个字符、三个字符等。
- 例如查询地址以“北京市”开头，可以写：

```python
条件 = 数据['地址'].str.startswith('北京市')
```

- 视频强调：`startswith`、`endswith` 前要写 `.str`，表示按字符串类型处理。

## 8. 字符串包含筛选：contains

目标：筛选地址中包含“信阳市”的记录。

问题背景：

- 有的地址写成“河南省信阳市”；
- 有的地址只写“信阳市”；
- 此时用 `startswith('信阳市')` 不行，因为“河南省信阳市”不是以“信阳市”开头。
- 应该使用“包含”来查询。

示例：

```python
条件 = 数据['地址'].str.contains('信阳市')
结果 = 数据[条件]
```

说明：

- `contains` 表示包含某字符串。
- 写法是 `数据['地址'].str.contains('信阳市')`。
- 这样无论地址前面有没有“河南省”，只要包含“信阳市”就能筛选出来。

## 9. contains 配合正则表达式

目标：筛选地址中包含 a 座、b 座、c 座的记录，且大小写都包括。

数据中可能出现：

- 大写 A 座
- 小写 a 座
- 大写 C 座
- 小写 c 座
- B 座、F 座等

如果只写 `contains('a')`，默认区分大小写，可能漏掉大写 A。

使用正则表达式表示 a、b、c 三个字母：

```python
条件 = 数据['地址'].str.contains('[a-cA-C]')
结果 = 数据[条件]
```

或者使用 `case=False` 忽略大小写：

```python
条件 = 数据['地址'].str.contains('[a-c]', case=False)
结果 = 数据[条件]
```

说明：

- `contains` 的第一个参数可以是字符串，也可以是正则表达式。
- 正则中 `[a-c]` 表示 a 到 c 之间的字符。
- 如果希望大小写都匹配，可以写成 `[a-cA-C]`，或者使用 `case=False`。
- `case` 参数默认是 `True`，表示区分大小写；改为 `False` 表示不区分大小写。
- 视频中老师认为：既然要使用正则表达式，不如直接学好正则表达式，直接把大小写范围写出来，不必过度依赖 `case` 参数。
- 正则表达式学习建议：作者 B 站 Python 爬虫教程前三节讲过正则表达式；正则在 Python、Pandas、VBA 等语言中都有用。

## 10. 复习 query：数值范围 + 类别条件

目标：筛选语文分数在 60 到 100 之间、且性别为女的记录。

```python
条件 = "语文 >= 60 and 语文 <= 100 and 性别 == '女'"
结果 = 数据.query(条件)
```

说明：

- `query` 中可以用 `and` 连接多个条件。
- 数值范围条件直接写比较表达式。
- 类别条件注意字符串引号。
- 这是对 `query` 的复习；后续还会继续加深。

## 11. 日期筛选的基础：日期处理“三步曲”

日期筛选是大数据分析中的常见需求，例如：

- 查询某一年、某年某月的数据；
- 查询某年之后、某年之前的数据；
- 查询某个日期区间的数据；
- 查询日期范围并叠加性别等其他条件。

直接使用日期索引进行筛选时，视频总结为“日期三部曲”。

### 11.1 第一步：将日期设置为索引

例如将出生日期设置为索引：

```python
数据 = 数据.set_index('出生日期')
```

设置后，可以直接用年份、年月进行索引筛选，例如：

```python
数据['1989']
数据['1983-10']
```

### 11.2 第二步：将日期列转换为日期格式

需要将出生日期转换为 `datetime` 日期型格式。

常见写法：

```python
数据['出生日期'] = pd.to_datetime(数据['出生日期'])
```

如果出生日期已经设置为索引，也可以转换索引：

```python
数据.index = pd.to_datetime(数据.index)
```

视频强调：必须转换日期格式，否则日期筛选可能无法正常工作。

### 11.3 第三步：使用 truncate 前先排序

当使用 `truncate` 截取日期区间时，需要先对日期索引排序。

```python
数据 = 数据.sort_values('出生日期')
```

如果出生日期已经是索引，也可以使用：

```python
数据 = 数据.sort_index()
```

视频强调：使用 `truncate` 时，如果日期索引没有排序，函数不能正常使用。

## 12. 按年份、年月直接筛选

将出生日期设置为索引并转换为日期格式后，可以直接按年份筛选。

查询 1989 年的数据：

```python
数据['1989']
```

或：

```python
数据.loc['1989']
```

查询 1983 年 10 月的数据：

```python
数据['1983-10']
```

视频建议：大数据场景下，查询后加 `.head()` 查看前五条，避免一次性输出过多数据导致内存压力或机器卡死。

```python
数据['1989'].head()
```

示例中课件数据很少，不加 `.head()` 也没问题；但处理 CSV、TXT 等大数据时应养成习惯。

## 13. truncate：截取某个日期之前或之后的数据

`truncate` 是 `DataFrame` 中的函数，用于获取某个日期之前或之后的时间区间数据，或截取两个日期之间的数据。

使用前注意：

- 日期索引必须先排序；
- 参数包括 `before`、`after`、`axis`、`copy` 等；
- 这些参数不是必须同时使用，而是按需使用；
- `copy` 等参数暂时不用重点掌握。

示例：

```python
数据2 = 数据.sort_values('出生日期')
```

查询 1980 年以后的数据：

```python
数据2.truncate(before='1980')
```

查询 1990 年 12 月以前的数据：

```python
数据2.truncate(after='1990-12')
```

查询 1990 年 2 月以后的数据：

```python
数据2.truncate(before='1990-02')
```

查询 1984 年 1 月 1 日以前的数据：

```python
数据2.truncate(after='1984-01-01')
```

查询 1984 年 1 月 1 日以后的数据：

```python
数据2.truncate(before='1984-01-01')
```

说明：

- `before` 和 `after` 用来指定截取边界；
- 视频强调：只要日期索引排序完成，这些日期区间筛选都可以正常使用；
- 如果记不住，就每次把“日期三部曲”写全：设置索引、转日期格式、排序。

## 14. 使用 loc 获取指定日期区间

除了 `truncate`，也可以直接用索引切片获取日期区间。

查询 1983 年到 1990 年的所有数据：

```python
数据['1983':'1990']
```

查询 1983 年某月到某月的数据：

```python
数据['1983-01':'1983-12']
```

查询 1980 年某月到 1990 年某月的数据：

```python
数据['1980-01':'1990-12']
```

说明：

- 日期区间中间用冒号 `:`；
- 与 `loc` 切片类似，包含边界；
- 前提仍然是日期已经设置为索引，并转换为日期格式。

## 15. query 实现日期范围 + 其他条件

目标：筛选 1980 年到 1990 年之间出生、且性别为男的记录。

使用 `query` 的写法：

```python
条件 = "@数据.出生日期.dt.year > 1980 and @数据.出生日期.dt.year < 1990 and 性别 == '男'"
结果 = 数据.query(条件)
```

解释：

- `@数据` 表示引用外部变量 `数据`；
- `.出生日期` 表示取出生日期列；
- `.dt.year` 表示取日期中的年份；
- `query` 可以识别这种字符串条件；
- 条件中日期范围与性别条件用 `and` 连接。

重要注意事项：

- 使用 `query` 将日期条件写在字符串里时，**不要把出生日期设置为索引**。
- 此时索引应为默认索引，或设置为序号。
- 如果出生日期仍然是索引，`query` 日期条件会报错。
- 视频演示：先把出生日期设为索引，运行 `query` 报错；把索引改回序号/默认索引后运行成功。
- 此时数据是否排序影响不大；`query` 方式下排序可有可无。

关于 `and` 的位置：

- 日期条件之间先用 `and` 连接；
- 再与性别这种字符型条件连接；
- 不要把日期条件和字符型条件混在一起导致类型不匹配；
- 写条件时要保证每个比较表达式的类型完整。

## 16. 日期时间扩展

视频最后提到：

- 如果日期字段中包含具体时间，可以写成：

```text
YYYY-MM-DD HH:MM:SS
```

- 时间采用 24 小时制，例如：
  - 9 点几分几秒；
  - 16 点几分几秒。
- 大数据查询时建议加上 `.head()`，每次只查看前五条，避免机器死机。

## 17. 本节筛选知识点总结

- 多工作表读取：`pd.read_excel(path, sheet_name=...)`。
- 按行筛选：`数据.loc[2:4]`，注意赋值给新变量。
- 单条件筛选：`条件 = 数据['性别'] == '男'`，再 `数据[条件]`。
- 多条件筛选：`query`，如 `"性别 == '男' and 总分 >= 150"`。
- `query` 支持 `in`，如 `"姓名 in ['李萍萍', '王刚']"`。
- 字符串开头：`.str.startswith('王')`。
- 字符串结尾：`.str.endswith('松')`。
- 字符串包含：`.str.contains('信阳市')`。
- 正则表达式筛选：`.str.contains('[a-cA-C]')` 或配合 `case=False`。
- `case=True` 默认区分大小写；`case=False` 忽略大小写。
- 数值范围 + 类别条件：`query("语文 >= 60 and 语文 <= 100 and 性别 == '女'")`。
- 日期筛选三部曲：
  1. 将日期设置为索引；
  2. 将日期转换为日期格式；
  3. 使用 `truncate` 前先排序。
- 按年份、年月直接筛选：`数据['1989']`、`数据['1983-10']`。
- 日期区间：`数据['1983':'1990']`。
- `truncate(before=..., after=...)` 可截取日期范围。
- 使用 `query` 写日期条件时，不要把日期设为索引，索引改为默认或序号。
- 大数据查询建议加 `.head()`，避免内存压力。
- 条件变量化、引号嵌套、正则表达式是写好 Pandas 筛选的重要基础。
