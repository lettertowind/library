# 孙兴华 Python 数据分析入门：Numpy 与 for 循环的区别

本节先厘清“数组”和“矩阵”的关系，再用同一个数组逐元素相加的例子，对比普通 Python 列表 + `for` 循环与 NumPy 的写法差异。

## 1. 数组与矩阵的区别

### 1.1 引入：数组和矩阵容易混淆

- 讲师指出：很多人在学习数据分析时，会把“数组”和“矩阵”弄反。
- 先用 Excel 文档做直观演示：用单元格区域表示不同维度的数组。

### 1.2 Excel 演示数组维度

- 一行五列的数据区域：讲师称其为一个数组，并说明这是“一行五列的数组”。
- 三行三列的数据区域：讲师称其为二维数组。
- 讲师表述中有一处容易混淆：先展示一行五列数组，随后说“刚才我们是一个一维数组，现在这是一个三行三列的二维数组”。严格按 NumPy 概念，一维数组通常是一行数据 `shape=(n,)`，二维数组才有行、列两个维度；二维数组可写成若干行若干列。
- 三维数组的直观理解：
  - 三维数组可以分成若干“块”。
  - 每一块本身是一个二维数组。
  - 讲师举例：三维数组分成四块，每一块是三行两列的二维数组。
  - 这些块叠在一起构成三维数组。
- 四维、五维数组：
  - 讲师表示四维、五维不方便用图形直观画出来。
  - 但可以在数据层面表示出来。

### 1.3 数组与矩阵的关系总结

- 矩阵可以看成数组的一个分支。
- 很多时候数组和矩阵可以通用。
- 如果两者可以通用，讲师建议选择数组，不要选择矩阵。
- 选择数组的原因：
  - 数组更灵活。
  - 数组速度快。
- 很多人把二维数组翻译成“矩阵”，这个说法也没有问题，因为二者有相同点。
- 数组和矩阵的相同点：
  - 索引方式相同。
  - 都可以通过下标方式取出数据。
- 数组与矩阵的区别：
  - 数组是更一般的概念，可以是一维、二维、三维甚至更高维。
  - 二维数组可以看成矩阵，但数组不一定都是矩阵。
  - 矩阵更贴近线性代数语境；通用数据运算优先使用数组。

## 2. 普通 Python 列表 + for 循环实现数组相加

### 2.1 任务目标

计算从 1 到 n 的数字立方数组 `a`，以及从 1 到 n 的数字平方数组 `b`，再逐元素相加得到 `c`。

即：

- `a` 中每个元素为 \(i^3\)；
- `b` 中每个元素为 \(i^2\)；
- `c` 中第 `i` 个元素为 `a[i] + b[i]`。

### 2.2 普通 Python 写法步骤

- 定义函数，并给函数一个形参 `n`。
- 使用列表推导式生成数组 `a`：

`a = [i ** 3 for i in range(1, n + 1)]`

- 解释 `range(1, n + 1)`：
  - `range` 的结束值不包含自身。
  - 如果从 1 开始，要取到 `n`，必须写成 `n + 1`。
  - 如果省略起始位置，则默认从 0 开始。
  - 这里遍历 1 到 n，每个 `i` 都取三次方 \(i^3\)。
- 使用列表推导式生成数组 `b`：

`b = [i ** 2 for i in range(1, n + 1)]`

- `b` 中每个元素都是对应数字的平方 \(i^2\)。
- 建立空列表用于存放结果：

`c = []`

- 使用 `for` 循环逐下标相加：

`for i in range(n):`

`c.append(a[i] + b[i])`

- `c.append(...)` 是列表方法，用于向列表末尾追加元素。
- `a[i] + b[i]` 表示取两个列表同一下标位置的元素相加。
- 这里的 `range(n)` 产生 `0` 到 `n-1`，正好作为 `a`、`b` 的下标。
- 最后 `c` 中得到逐元素相加结果。

### 2.3 示例：n = 3

- `range(1, 4)` 得到 `1, 2, 3`。
- `a` 为立方数组：

`a = [1 ** 3, 2 ** 3, 3 ** 3] = [1, 8, 27]`

- `b` 为平方数组：

`b = [1 ** 2, 2 ** 2, 3 ** 2] = [1, 4, 9]`

- 逐下标相加：
  - 下标 0：`a[0] + b[0] = 1 + 1 = 2`
  - 下标 1：`a[1] + b[1] = 8 + 4 = 12`
  - 下标 2：`a[2] + b[2] = 27 + 9 = 36`
- 最终结果：

`c = [2, 12, 36]`

- 讲师通过 debug 查看结果，说明结果正确。转录中“22 36”应理解为结果 `2, 12, 36` 的连读。

### 2.4 普通 Python 写法的结论

- 在 Python 中做数组逐元素运算比较麻烦。
- 需要：
  - 定义函数；
  - 使用列表推导式生成数组；
  - 建立空列表；
  - 写 `for` 循环；
  - 使用 `append` 逐项追加。
- 普通 Python 的执行过程是先循环遍历，再逐个计算。

## 3. NumPy 实现同样的数组相加

### 3.1 导入 NumPy

- 导入模块：

`import numpy as np`

- 约定俗成给 NumPy 起别名 `np`，方便后续写方法。
- Pandas 通常约定别名为 `pd`。
- 也可以写完整名称，但一般使用短别名。

### 3.2 NumPy 写法步骤

- 定义函数，形参仍为 `n`。
- 使用 `np.arange` 生成数组并直接做幂运算：

`a = np.arange(1, n + 1) ** 3`

- `np.arange` 与 Python 的 `range` 类似。
- 默认从 0 开始。
- 结束位置不包含自身。
- 如果要从 1 取到 n，必须写成 `n + 1`。
- `** 3` 表示对数组中的每个元素取三次方。
- 生成平方数组：

`b = np.arange(1, n + 1) ** 2`

- `** 2` 表示对数组中的每个元素取二次方。
- 返回两个数组相加的结果：

`return a + b`

- NumPy 中 `a + b` 表示两个数组逐元素相加。
- 打印结果：

`print(数组相加(3))`

- 讲师说明：一般学习时可以先赋值给变量再 `print`，这里为了省事直接打印函数返回值。

### 3.3 示例：传入 n = 3

- 形参 `n = 3` 传入函数。
- `np.arange(1, 4)` 生成数组：

`[1, 2, 3]`

- `a` 对每个元素取三次方：

`a = [1, 8, 27]`

- `b` 对每个元素取二次方：

`b = [1, 4, 9]`

- `return a + b` 返回：

`[2, 12, 36]`

- 与普通 Python 列表 + `for` 循环得到的结果一致。

### 3.4 NumPy 与普通 Python 的关键区别

- 普通 Python：
  - 先进行循环遍历；
  - 再逐个元素计算；
  - 需要显式写 `for` 循环和 `append`。
- NumPy：
  - 直接对整个数组进行计算；
  - 不需要显式写 Python 层 `for` 循环；
  - 属于向量化计算。
- 性能差异：
  - NumPy 可以节省大量时间。
  - 数据量越大，差异越明显。
  - 有时可能节省几倍甚至十几倍时间。
- 讲师提到可以用时间模块（如 `time.time()`）观察两种写法的耗时差异。

## 4. 易混点与注意事项

- `range` 和 `np.arange` 的参数规则相似：
  - 结束值不包含自身；
  - 从 1 开始取到 n 时必须写 `n + 1`；
  - 省略起始值时默认从 0 开始。
- 列表推导式中的 `i ** 3` 和 `i ** 2` 是普通 Python 的幂运算。
- NumPy 中的 `np.arange(...) ** 3` 是对整个数组逐元素取三次方。
- `a + b` 在 NumPy 数组中是逐元素相加，不是矩阵乘法。
- 二维数组可以看成矩阵，但数组是更一般的概念。
- 数组和矩阵的索引方式相同，都可以通过下标取数据。
- 三维数组可以理解为多个二维数组按“块”叠起来；四维、五维不容易可视化，但可以在数据结构中表示。
- 在数组和矩阵可通用时，讲师建议优先使用数组，因为更灵活、速度更快。

## 5. 本节结论与过渡

- 本节先明确了数组与矩阵的关系：矩阵是数组的一个分支，二维数组可近似看作矩阵，但数组更通用。
- 通过同一个“立方数组 + 平方数组”的例子，展示了普通 Python 列表 + `for` 循环写法的繁琐。
- NumPy 使用 `np.arange`、数组幂运算和 `a + b` 就能直接完成逐元素计算。
- NumPy 的核心优势之一是直接计算、避免 Python 层循环，从而提升效率。
