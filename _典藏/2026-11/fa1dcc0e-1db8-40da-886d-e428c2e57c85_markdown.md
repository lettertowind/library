## 1. 课程定位与核心概念

- 本节主题：Numpy 的**布尔索引**。
- 前置知识：上节课已经讲完**基础索引和切片**。
- “布尔”二字的含义：真和假、对和错，对应 `True` / `False`。
- 布尔索引的核心：先用条件运算生成一个布尔数组，再把这个布尔数组作为下标，用来筛选数据或进行条件赋值。
- 与普通索引/切片的区别：
  - 普通索引/切片：按位置、范围取数据。
  - 布尔索引：按条件结果取数据，条件为 `True` 的位置保留，为 `False` 的位置排除。
- 常见用途：
  - 筛选大于某个值的元素。
  - 条件赋值。
  - 数组零一化。
  - 二维数组局部条件替换。
  - 多个条件组合筛选。

## 2. 一维数组布尔索引基础

- 先创建一个一维数组，视频中该数组为 `0~9` 共十个数，可理解为：
  - `arr = np.arange(10)`
- 目标：返回大于 5 的数字。

步骤一：先做条件筛选变量。

- 条件表达式：
  - `mask = arr > 5`
- 打印 `mask` 后，返回的是一个布尔数组。
- 视频解释：
  - 条件为“大于 5”。
  - 数组中大于 5 的数有 4 个。
  - 凡是不符合条件的位置为 `False`。
  - 凡是符合条件的位置为 `True`。
- 对 `0~9` 来说，大于 5 的是 `6、7、8、9`，因此对应位置为 `True`，其余为 `False`。

步骤二：把布尔数组作为数组下标。

- 写法：
  - `arr[mask]`
  - 或直接写：`arr[arr > 5]`
- 运行结果：
  - 提取出 `6、7、8、9`。
- 关键结论：
  - 布尔数组作为下标时，`True` 对应位置的元素会被提取出来。
  - `False` 对应位置的元素会被丢弃。
  - 布尔索引既可以直接写条件，也可以先保存为变量再使用。

## 3. 一维数组进阶：零一化

- 目标：把数组中大于 5 的数字变成 `1`，小于等于 5 的数字变成 `0`。
- 视频中先口述“小于 5 的变成 0”，随后明确纠正为“小于等于 5 的变成 0”。
- 操作逻辑：
  - 用条件生成布尔数组。
  - 把条件作为切片/索引条件进行赋值。
  - 符合小值条件的位置赋值为 `0`。
  - 符合大值条件的位置赋值为 `1`。
- 等价写法可理解为：
  - `arr[arr <= 5] = 0`
  - `arr[arr > 5] = 1`
- 运行后数组中原来的数字全部变为 `0` 或 `1`，完成零一化。
- 视频说明：
  - 当前先理解“布尔索引如何参与赋值”。
  - 零一化有什么用途，后面在几十道题的实例分析中会再讲。
  - 现在需要先理解这些操作机制，才能应用到后续数据分析中。

## 4. 实例二：条件自增量操作

- 目标：给数组中大于 5 的元素都加上 `520`。
- 视频强调的运算符：
  - `+=`
  - `a += b` 等价于 `a = a + b`，即自身等于自身加上某个值。
- 条件自增量的写法可理解为：
  - `arr[arr > 5] += 520`
- 如果不想使用 `+=`，也可以写成等价形式：
  - `arr[arr > 5] = arr[arr > 5] + 520`
- 注意：这里不是对整个数组所有元素加 `520`，而是只对满足 `arr > 5` 的元素加 `520`。
- 运行结果：
  - 只有大于 5 的数字增加了 `520`。
  - 其他数字保持不变。
- 关键结论：
  - 布尔索引不仅能放在读取语句中，也能放在赋值语句左侧。
  - 通过布尔条件可以精确修改数组中满足条件的元素。

## 5. 二维数组中的布尔索引

- 视频继续用二维数组演示布尔索引。
- 视频口述该二维数组与 `1~24`、列数有关，用于展示二维数组的条件筛选。
- 目标：筛选数组中大于 10 的数字。
- 条件表达式：
  - `mask = arr2 > 10`
- 打印 `mask` 后，返回一个与二维数组形状相同的布尔数组：
  - 不大于 10 的位置显示 `False`。
  - 大于 10 的位置显示 `True`。
- 使用布尔数组作为下标：
  - `arr2[mask]`
  - 或 `arr2[arr2 > 10]`
- 视频观察结果：
  - 满足条件的元素被提取出来。
  - 最终返回的是一个**一维数组**。
- 关键结论：
  - 二维数组使用布尔索引时，是对数组中的每个元素逐个判断。
  - 所有 `True` 位置上的元素会被取出，并组合成一维结果。
  - 因此二维布尔索引的结果不保持原来的二维形状，而是被提取为一维数组。

## 6. 二维数组局部赋值：第三列大于 5 替换为 520

- 目标：把“所有行第三列”中大于 5 的元素替换成 `520`。
- 先打印原二维数组，并配合分隔线观察结果。
- 列索引说明：
  - Python 索引从 `0` 开始。
  - 第三列的索引是 `2`。
  - 视频中明确提到 `0、1、2`，第三列即索引 `2`。
- 取出所有行的第三列：
  - `arr2[:, 2]`
- 视频先打印所有行第三列，确认取到的列值正确。
- 目标条件：
  - `arr2[:, 2] > 5`
- 错误/踩坑操作：
  - 如果直接写类似 `arr2[arr2[:, 2] > 5] = 520`，会把“第三列大于 5 的整行”都替换成 `520`。
  - 视频观察到的现象：并不是只替换第三列中大于 5 的那几个数，而是把整个数组中符合该行条件的整行内容都改掉了。
  - 原因：`arr2[:, 2] > 5` 得到的是一个“行条件”，`arr2[行条件]` 选中的是整行；对整行赋值就会修改多个元素，而不是只修改第三列。
- 正确思路：使用**二次切片**。
  - 第一步：先做筛选条件，即判断第三列哪些元素大于 5。
  - 第二步：在数组上先把所有行的第三列切出来。
  - 第三步：再把筛选条件应用到第三列切片上。
  - 第四步：对筛选出的局部元素赋值。
- 正确写法可理解为：
  - `arr2[:, 2][arr2[:, 2] > 5] = 520`
- 简单情形对比：
  - 如果只是把第三列整列替换为 `520`，不需要条件：
    - `arr2[:, 2] = 520`
  - 如果只替换第三列中满足条件的元素，则必须使用二次切片：
    - `arr2[:, 2][arr2[:, 2] > 5] = 520`
- 关键结论：
  - 二维数组做局部条件替换时，要明确“先定位局部切片，再在局部切片上应用条件”。
  - 不要直接在整个二维数组上用行条件赋值，否则会选中整行。
  - 视频提醒：这部分比较绕，需要多看几遍。

## 7. 三行三列数组的布尔筛选练习

- 建立一个三行三列的数组，并打印原数组。
- 目标：筛出数组中大于 25 的元素。
- 条件表达式：
  - `mask = arr3 > 25`
- 打印布尔结果，视频观察到：
  - 有两个 `False`。
  - 有三个 `True`。
  - 后面也都是 `False`。
  - 说明数组中有三个元素满足“大于 25”。
- 将布尔数组作为下标：
  - `arr3[mask]`
  - 或 `arr3[arr3 > 25]`
- 提取结果：
  - 所有大于 25 的元素被取出。
  - 结果为一维数组。
- 关键结论：
  - 一维、二维数组的布尔索引逻辑一致：条件产生布尔数组，`True` 位置被选中。
  - 二维数组筛选后通常返回一维结果。

## 8. 条件组合：偶数或者小于 7

- 建立 `0~9` 的一维数组。
- 目标：找出“是偶数或者小于 7”的元素。
- 视频强调：
  - Python 中的逻辑“或”可以用一条竖线 `|` 表示。
  - 这一点在 Python 基础课中已经讲过。
  - 组合条件时，每个条件应使用括号括起来，避免优先级问题。
- 条件一：判断偶数。
  - 写法：`arr % 2 == 0`
  - 解释：数组元素对 2 取余，余数为 0 时说明是偶数。
- 条件二：判断小于 7。
  - 写法：`arr < 7`
- 组合条件：
  - `mask = (arr % 2 == 0) | (arr < 7)`
- 打印 `mask`：
  - 返回布尔数组。
  - `True` 表示满足“偶数”或“小于 7”中的至少一个条件。
- 使用条件作为下标提取：
  - `arr[mask]`
- 结果解释：
  - 小于 7 的元素都会出来。
  - 大于 7 的元素中，只保留偶数，奇数不要。
  - 换句话说：满足“小于 7”或“是偶数”二者之一即可。
- 关键结论：
  - 多个布尔条件组合使用 `|` 表示“或”。
  - 每个条件建议加括号。
  - 布尔索引可以处理复合条件筛选。

## 9. 本节总结与易混点

- 布尔索引的本质：
  - 条件表达式产生布尔数组。
  - `True` 表示选中，`False` 表示不选中。
- 读取数据：
  - `arr[arr > 5]`
  - `arr2[arr2 > 10]`
- 条件赋值：
  - `arr[arr > 5] = 1`
  - `arr[arr <= 5] = 0`
  - `arr[arr > 5] += 520`
- 一维数组：
  - 布尔索引直接提取满足条件的元素。
- 二维数组：
  - 按元素判断，`True` 位置被取出。
  - 结果通常是一维数组。
- 易混点：二维局部赋值。
  - `arr2[arr2[:, 2] > 5] = 520` 这类写法会选中整行。
  - 正确局部替换应使用二次切片：
    - `arr2[:, 2][arr2[:, 2] > 5] = 520`
- 零一化：
  - 大于 5 变 `1`，小于等于 5 变 `0`。
- 条件组合：
  - 使用 `|` 表示“或”。
  - 例如：`(arr % 2 == 0) | (arr < 7)`。
- 讲师建议：
  - 二维局部条件替换比较绕，应多看几遍。
  - 当前先理解布尔索引的工作机制，后续实例分析和数据分析中会继续使用。
