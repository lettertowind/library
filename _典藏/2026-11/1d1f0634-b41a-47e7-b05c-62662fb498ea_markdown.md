# Matplotlib 散点图课程笔记

## 一、课程引入：散点图的作用与延伸

- 本节主题是散点图（scatter plot）。
- 散点图本身很简单，但如果深入研究会很复杂。
- 散点图可以进一步做成气泡图，并可演变出很多图表形式。
- 散点图主要体现两个变量之间的关系与分布。
- 讲师举例：
  - 想查看一个城市或班级中人群的“身高—体重”情况。
  - 观察平均身高、平均体重大概在什么范围。
  - 观察是否存在区域性组合，例如：
    - 身高特别矮但特别胖；
    - 特别胖但特别矮；
    - 特别胖但特别高；
    - 特别高又特别瘦。
  - 有散点图时可以很直观地看到这些分布和异常区域。
- 散点图有 x 轴和 y 轴，两个变量分别放在 x 轴、y 轴上。

## 二、绘制前查看数据：Pandas 显示设置

- 查看数据时发现：
  - 数据中有 `NaN`，表示空值。
  - “性别”列后面带有三个点，说明列没有被完整显示。
  - 原始数据列很多，Pandas 默认没有显示全部列。
- 想显示全部列时，使用：
  - `pd.options.display.max_columns = None`
- 运行后可以显示全部列。
  - 显示全部列后，Pandas 会把较长的一行拆成多段展示。
  - 转录中提到数据列很多，统计到大约 48 列；例如包含 19、20~29、39~44 等分段显示。
- 想显示全部行时，把 `max_columns` 改成 `max_rows`：
  - `pd.options.display.max_rows = None`
- 讲师特别提醒：
  - 如果数据量很大，不要设置显示全部列或全部行。
  - 如果数据有几万行、几十万行，强制全部显示会先把大量数据展开，浪费 Pandas 的性能优势。
  - Pandas 的设计是“用到什么再读什么/显示什么”，不应为了查看而全部展开。
  - 这里设置 `None` 只是演示如何显示所有列、所有行。
- 演示结束后取消该设置，因为后续只需要查看“身高”“体重”等少量列，观察趋势即可。

## 三、使用 `plt.scatter` 绘制基础散点图

- Matplotlib 中绘制散点图的方法：
  - `plt.scatter(x, y)`
- 散点图需要提供 x 轴和 y 轴数据。
- 示例中使用身高、体重数据：
  - 可以把身高放在 x 轴，体重放在 y 轴；
  - 也可以把体重放在 x 轴，身高放在 y 轴。
  - 讲师强调：x 轴、y 轴没有绝对规定，应根据业务性质和个人分析目的决定。
- 基本调用思路：
  - `plt.scatter(身高数据, 体重数据)`
  - 然后使用 `plt.show()` 显示图表。
- 运行后散点图出现。
  - 因为课件数据只有七八行，所以图上点很少。
  - 点少不是绘图错误，而是数据量少。
- 散点图可用于观察身高、体重之间的分布趋势和异常组合。

## 四、`plt.scatter` 关键参数详解

### 1\. 点大小参数 `s`

- `s` 用于控制散点/气泡的大小。
- 可以让点的大小与第三个变量相关。
- 示例思路：
  - `plt.scatter(身高, 体重, s=身高)`
  - 身高越高，点/气泡越大；
  - 身高越矮，点/气泡越小。
- 也可以根据业务需要设置为 `s=体重`，让体重越大点越大。
- 讲师说明：
  - 散点图加上大小映射后，可以演变成气泡图。
  - 课件数据较简单，看起来身高高的人体重也相对重。
  - 但实际普查数据不一定如此：
    - 有人身高不高但体重较重；
    - 有人身高很高但体重较轻。
  - 讲师自嘲自己身高约 1 米 98，但体重只有 100 多斤，用来说明身高和体重不一定完全正相关。

### 2\. 颜色参数 `c`

- `c` 用于设置点的颜色。
- 可以直接设置固定颜色，例如：
  - `plt.scatter(x, y, c='red')`
  - 所有点都会变成红色。
- 也可以让颜色与数据相关，例如：
  - `plt.scatter(x, y, c=身高)`
  - 颜色由身高数据决定，不同身高对应不同颜色。
- 讲师演示中，将身高数据传给 `c` 后，点的颜色出现差异。
- 当颜色由数值数据映射时，需要颜色条说明颜色对应的数值范围。

### 3\. 颜色条 `plt.colorbar()`

- 当 `c` 传入数值数组时，应添加颜色条：
  - `plt.colorbar()`
- 作用：
  - 告诉读者什么颜色对应什么数值；
  - 例如哪种颜色代表身高较矮，哪种颜色代表身高较高。
- 讲师演示中：
  - 颜色较深的一端代表身高较矮；
  - 颜色较浅/较上方颜色代表身高较高。
- `colorbar` 是数值颜色映射的重要辅助说明。

### 4\. 标记形状参数 `marker`

- `marker` 用于设置散点的标记形状。
- 示例：
  - `marker='o'`：使用圆圈表示点；
  - `marker='x'`：使用叉号表示点。
- 讲师说明：
  - 散点图的 `marker` 与折线图中的标记点用法类似。
  - 可以先关注标记点形状来进行设置。
- 转录中出现的 `m2k` 应理解为 `marker` 参数。

### 5\. 封闭标记的线宽参数 `linewidths`

- 如果使用封闭式标记，例如 `marker='o'`，可以设置标记边缘线宽。
- 示例：
  - `linewidths=20`
- 作用：
  - 控制标记中心到边缘的宽度/边缘线宽。
  - 设置较大时可以明显看到圆圈边缘变粗。
- 讲师说明：
  - 这个参数一般较少使用；
  - 但在某些需要强调标记边缘的场景下可以设置。

### 6\. 透明度参数 `alpha`

- `alpha` 用于设置点的透明度。
- 示例：
  - `alpha=0.5`
- 作用：
  - 降低点的透明度；
  - 当点较密集或重叠时，可以用透明度观察重叠情况。
- `alpha` 通常取值范围在 0 到 1 之间。

### 7\. 基础参数组合示例

- 固定颜色：
  - `plt.scatter(x, y, c='red')`
- 大小映射：
  - `plt.scatter(x, y, s=身高)`
- 颜色映射并显示颜色条：
  - `plt.scatter(x, y, c=身高)`
  - `plt.colorbar()`
- 标记形状：
  - `plt.scatter(x, y, marker='o')`
  - `plt.scatter(x, y, marker='x')`
- 标记线宽：
  - `plt.scatter(x, y, marker='o', linewidths=20)`
- 透明度：
  - `plt.scatter(x, y, alpha=0.5)`

## 五、NumPy 随机数综合案例：绘制 500 个随机散点

- 讲师通过一个 NumPy 随机数案例复习 NumPy，并综合练习散点图参数。
- 导入库：
  - `import numpy as np`
  - `import matplotlib.pyplot as plt`
- 生成 x 轴随机数据：
  - `x = np.random.rand(500)`
- 生成 y 轴随机数据：
  - `y = np.random.rand(500)`
- `np.random.rand(500)` 的作用：
  - 返回 500 个在 `[0, 1)` 区间内均匀分布的随机样本。
- 设置点大小：
  - 示例思路：`s = x * 50`
  - 让点大小与 x 数据相关，并通过乘以 50 放大差异。
- 设置颜色：
  - 讲师使用求反正切值的方法生成颜色。
  - 转录中记为 `c t a n`，常见实现思路为 `c = np.arctan2(y, x)`。
  - 该颜色不是固定颜色，而是根据数据计算出的数值颜色。
  - 讲师说明：这个反正切值生成颜色的方法不必死记，工作中可能用不到；如果以后用到，会进行更深入研究。
- 绘图调用：
  - `plt.scatter(x, y, s=大小, c=颜色)`
  - `plt.colorbar()`
  - `plt.show()`
- 结果：
  - 图中生成 500 个随机散点。
  - 可以观察点的位置分布以及颜色区分。
  - 同时复习了 NumPy 随机数生成和 Matplotlib 散点图参数。
- 讲师再次强调：
  - x 轴和 y 轴可以交换，没有唯一答案。
  - 应根据业务性质决定哪个变量放 x 轴、哪个变量放 y 轴。
  - 点大小 `s`、颜色 `c` 都可用于表达额外信息。

## 六、易混点、踩坑点与结论汇总

- `pd.options.display.max_columns = None` 用于显示全部列。
- `pd.options.display.max_rows = None` 用于显示全部行。
- 数据量大时不要随意使用 `None` 显示全部数据，否则会破坏 Pandas 的性能优势。
- `plt.scatter(x, y)` 是散点图的基本调用形式。
- x 轴、y 轴变量可以互换，应结合业务含义决定。
- `s` 控制点/气泡大小，不是线宽。
- `c` 可以设置固定颜色，也可以设置数值数组进行颜色映射。
- 使用数值颜色映射时，应配合 `plt.colorbar()` 显示颜色条。
- `marker` 控制点的形状，例如 `'o'`、`'x'`。
- `linewidths` 用于封闭标记的边缘线宽，讲师表示一般较少使用。
- `alpha` 控制透明度，适合处理重叠点或强调密度。
- 散点点很少不一定是绘制失败，可能只是数据量少。
- 散点图可以只分析两个变量，也可以通过 `s`、`c` 等参数叠加更多维度信息，演变成气泡图等图表。
