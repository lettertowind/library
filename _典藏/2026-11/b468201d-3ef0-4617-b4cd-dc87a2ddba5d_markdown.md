## 课程主题：在 Pandas 中读取与修改 Excel 文件

本节课程主要讲解如何使用 `pandas` 读取 Excel 文件，并处理 Excel 文件没有表头的情况；同时演示如何设置自定义表头、指定索引列，以及如何将修改后的数据写回原 Excel 文件。

## 1. 读取 Excel 文件

- 首先导入 `pandas` 库，通常写法为 `import pandas as pd`。
- 回忆上一节内容：新建或写入 Excel 文件时使用的是 `to_excel` 方法。
- 读取 Excel 文件使用的方法是 `read_excel`。
- 需要先准备 Excel 文件的路径，例如视频中使用的路径类似：`C:\pandas读取文件.xlsx`。
- 基本流程：
  - 导入 `pandas`。
  - 指定 Excel 文件路径。
  - 调用 `pd.read_excel(路径)` 读取数据。
  - 使用 `print` 打印读取内容。
  - 运行程序后，可以看到 Excel 中的数据已经被成功读取出来。

## 2. Excel 文件没有表头时的处理

- 视频中的 Excel 文件本身没有表头。
- 当直接使用 `read_excel` 读取时，`pandas` 默认会把第一行数据当作表头。
- 由于原表第一列本来是索引列，直接读取后 `pandas` 又会自动生成一个新的索引列，导致数据结构不符合预期。
- Excel 文件不存在像 CSV 那样的分隔符问题，因此不需要考虑分隔符参数。
- 处理无表头文件时，需要设置参数 `header=None`，表示文件中没有表头。
- 设置表头时，参数名必须使用大写形式；如果参数大小写写错，可能会报错或无法正确识别。例如 `header` 应保持正确拼写和大小写。

## 3. 设置自定义表头

- 使用 `names` 参数为无表头数据设置自定义列名。
- 视频中最终设置的列名包括：
  - `序号`
  - `姓名`
  - `年龄`
  - `手机`
  - `地址`
  - `入职日期`
- 读取时可组合使用：
  - `header=None`：表示原文件没有表头。
  - `names=[...]`：指定自定义表头。
  - `index_col='序号'` 或指定序号列：将“序号”列设置为索引列。
- 设置索引后，读取结果中的“序号”列会作为行索引，而不再作为普通数据列显示。
- 视频强调：操作方法不止一种，但本节课只讲解最简单、推荐的一种方法。
- 建议先安装 `xlrd` 模块，否则在使用某些读取 Excel 的方法时可能会报错。转录中提到的模块名可能为 `xlrd`，用于支持 Excel 文件读取。

## 4. 将修改后的数据写回 Excel 文件

- 读取并修改数据后，可以将数据重新写回 Excel 文件。
- 写回使用的方法是 `to_excel`。
- 操作思路：
  - 先读取 Excel 数据。
  - 设置表头和索引。
  - 调用 `df.to_excel(原路径)` 将数据写回原文件。
- 视频中直接写回原 Excel 文件路径，因此会覆盖原文件内容。
- 运行程序后，再次打开原 Excel 文件，可以看到：
  - 已经增加了表头。
  - 有“序号”列。
  - 有“姓名”“年龄”“手机”“地址”“入职日期”等字段。
  - 原先没有表头的数据被重新整理成带表头、带索引的表格结构。

## 5. 日期格式问题与后续说明

- 写回 Excel 后，日期列可能显示为“日期 + 时间”形式。
- 视频说明：当前阶段还没有学习数据格式转换，因此暂时不处理日期格式。
- 后续学习数据格式相关内容时，会讲解如何将日期转换为纯日期类型。
- 数据分析过程中会经常与日期、时间、文本、数值等不同类型的数据打交道，因此这些格式处理会在后续课程中展开。

## 6. 本节关键结论

- 读取 Excel 文件使用 `pandas.read_excel()`。
- 写入 Excel 文件使用 `DataFrame.to_excel()`。
- 无表头 Excel 文件应设置 `header=None`。
- 自定义列名使用 `names` 参数。
- 指定某一列作为索引使用 `index_col` 参数。
- 参数名需要注意大小写，避免因拼写或大小写错误导致报错。
- 可以将处理后的数据直接写回原路径，从而修改原 Excel 文件。
- 日期格式问题暂不处理，留待后续数据格式课程讲解。
