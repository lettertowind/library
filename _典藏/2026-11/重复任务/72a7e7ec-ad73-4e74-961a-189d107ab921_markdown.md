# 用 Obsidian 打造自进化知识系统

## 核心架构

- **图书馆**：Obsidian 仓库，存放原始资料与整理后的知识。
- **管理规则**：`AGENTS.md` 定义 AI 如何读取、提炼、分类、关联、更新知识。
- **管理员**：Agent（视频以 WorkBody 演示，也可用 Claude、Codex 等），按规则整理、问答、维护系统。
- **运转闭环**：收藏素材 → Agent 摄入拆分 → 存入知识库并关联 → 调用问答 → 优质答案沉淀 → 定期体检 → 持续生长。

## 系统搭建

- 在 Obsidian 新建仓库，例如“大梁的第二大脑”。
- 让 Agent 打开该仓库文件夹作为工作空间。
- 参考 Karpathy 的相关方法论，或使用优化版中文规则，让 Agent 自动生成知识库结构。
- 核心目录与文件：
  - **原始资料/Raw**：待摄入的文章、视频、文档等。
  - **AGENTS.md**：AI 操作规则。
  - **Wiki/知识库**：概念、实体、资料摘要、分析、目录、日志、综述、报告等。
  - **已摄入**：存放处理过的原始资料，避免重复摄入。
- 建议给 Agent 完全访问权限，模型可选 DeepSeek。

## 获取素材

### 网页与视频

- 安装 **Obsidian Web Clipper**（Chrome 插件）。
- 在插件设置中将保管库设为 Obsidian 仓库名。
- 在 Default 模板中，将“笔记位置”改为原始资料文件夹。
- 浏览文章或视频时点击插件，即可一键保存到 Obsidian。
- 视频保存为在线播放链接，并附带带时间戳字幕；不占本地空间，离线可看逐字稿。

### 本地资料

- 将 Word、数据等文件直接交给 Agent，要求转换为 Markdown 并放入知识库。
- Agent 会依据 `AGENTS.md` 自动放入指定目录，例如原始资料文件夹。

## 摄入知识

- 在知识库工作空间中，对 Agent 输入“**摄入素材**”。
- Agent 自动执行：
  - 读取原始资料；
  - 提炼概念、实体、核心摘要；
  - 分类存储；
  - 更新知识目录、操作日志与知识库综述；
  - 建立知识间链接；
  - 将已处理素材移入“已摄入”。
- Obsidian 关系图谱会显示知识点之间的关联，形成知识网络。

## 调用知识

- 在知识库空间直接向 Agent 提问。
- 回答基于已摄入资料，质量更高且可追溯。
- 优质回答会自动沉淀到知识库的“分析”文件夹，并与相关知识点建立关联，成为新的知识养料。

## 知识库体检

- 对 Agent 输入“**体检**”。
- Agent 自动检查关联缺失、观点冲突、事实不符、信息矛盾等问题，并尝试修复。
- 生成修复报告；无法决策时询问用户。

## 自动化闭环

使用 Agent 的定时任务功能，将手动环节自动化：

- **自动摄入素材**：每周日 09:00，提示词“摄入素材”，工作空间选择知识库。
- **自动体检**：每周日 11:00，提示词“体检”。
- **可选自动收集素材**：例如每周六 23:00，提示词写明行业与关注点，如新模型、Agent 产品、AI 企业融资/上市新闻等。
- 形成闭环：周六自动收集 → 周日自动摄入 → 周日自动体检 → 随时调用。

## 关键结论

- 知识存储重要，但更重要的是**精准调用与知识关联**。
- `AGENTS.md` 是系统核心，Agent 在工作目录中会遵循规则自动处理。
- 该系统可扩展到项目管理、客户关系、团队管理、业务信息管理等领域。
- AI 不只是替代手脚，更应成为个人的“超级大脑”和智力延伸。
