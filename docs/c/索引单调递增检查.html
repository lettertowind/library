索引单调递增检查

is_monotonic_increasing · 索引有序性 · is_monotonic

data.index.is_monotonic_increasing 返回布尔值，用来判断索引是否已按升序排好。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：Index.is_monotonic_increasing（只读属性，不加括号）；旧版别名 index.is_monotonic 已废弃，不要再用。

参数：无

示例：

import pandas as pd

idx = pd.MultiIndex.from_tuples([("b", 1), ("a", 2), ("a", 1)])
s = pd.Series([10, 20, 30], index=idx)

print(s.index.is_monotonic_increasing)  # False
print(s.sort_index().index.is_monotonic_increasing)  # True

# 重复索引不影响单调性判断
dup = pd.Index([1, 1, 2, 3])
print(dup.is_monotonic_increasing)  # True

无序时先 s.sort_index(level=...) 排好，再做切片或 loc 范围查询。

解释

对多层索引做切片或范围查询时，pandas 要求索引有序；无序索引会报 UnsortedIndexError 或返回不可靠结果。该属性只做检查，不修改数据，返回 True 时可以直接查询，返回 False 时先 sort_index 排序再查。

有什么用

  • 切片/范围查询前确认索引是否有序
  • 排查多层索引查询结果异常或报错的原因

关键要点

  • 返回 True/False，是只读属性，不改变数据
  • 无序索引做切片可能报 UnsortedIndexError
  • 无序时用 sort_index(level=...) 排好再查
  • 对多层索引判断的是整体字典序，从最外层开始比较

边界与易混淆

只判断是否升序，不判断索引是否唯一；存在重复索引也可能返回 True。
