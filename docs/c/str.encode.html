str.encode

encode · 编码转换

把字符串按指定格式编码为字节的方法。

目录

解释

str.encode('utf-8') 将字符串编码为指定字符集，常用于处理 CSV 中文乱码问题。与 str.decode 配对使用，一编一解。

有什么用

  • 处理中文乱码
  • 把文本转为字节流

关键要点

  • 参数为编码格式，如 utf-8
  • 与 decode 方向相反
  • 本课了解即可，遇到转码问题再查

边界与易混淆

编码与解码必须配对，格式不一致会乱码或报错。

encode 和 decode 的方向区别是什么？
encode 把字符串编码为字节，decode 把字节解码回字符串。
