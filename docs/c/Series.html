Series

pd.Series · 一维数据结构

Pandas 的一维数据结构，由索引和数据值两部分组成。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

Series 是 Pandas 最基础的数据结构，可以表示一行或一列数据。它由 index（索引）和 values（数据值）构成，默认索引是从 0 开始的整数。多个 Series 可以组成 DataFrame。

有什么用

  • 表示单行或单列数据
  • 作为 DataFrame 的组成单元
  • 快速创建和查询一维数据

关键要点

  • Series 是一维数据，由索引 index 和数据 values 组成
  • 默认索引从 0 开始，步长为 1，结束值不包含
  • 类名 Series 首字母必须大写
  • 单独看 Series 无法确定是行还是列，加入 DataFrame 后才确定
  • 多键查询返回的仍是 Series 类型

边界与易混淆

Series 是一维的，不能直接表示多行多列；二维数据需用 DataFrame。

Series 由哪两部分组成？默认索引是什么样的？
由索引 index 和数据 values 组成；默认索引是从 0 开始的整数，步长 1，结束值不包含。
为什么说单独一个 Series 无法确定是行还是列？
因为 Series 本身只是一维序列，只有加入 DataFrame 后，根据加入方式才确定它成为一行或一列。
