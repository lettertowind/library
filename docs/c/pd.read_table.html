pd.read_table

read_table

Pandas 读取文本文件的函数，默认以制表符 \t 分隔。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

read_table 与 read_csv 功能一致，唯一区别是默认分隔符为制表符，适合 tsv 或 tab 分隔文件。读逗号分隔文件时需显式传 sep=','。

有什么用

  • 读取 tsv 或 tab 分隔文本
  • 与 read_csv 按习惯二选一

关键要点

  • 默认 sep='\t'
  • 读逗号文件必须手动 sep=','
  • 与 read_csv 无文件类型限制差异

边界与易混淆

容易误以为 read_table 只能读 tsv，其实任何分隔文本都能读，只是默认分隔符不同。
