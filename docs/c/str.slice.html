str.slice

slice · 字符串切片

按起止范围和步长截取字符串片段的方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

str.slice(start, stop, step) 类似 Python 切片，从 start 到 stop（不含 stop）截取字符，可设置步长。越界位置显示为空字符，原值为 NaN 的仍为空值。

有什么用

  • 截取字符串前几位
  • 隔位取字符
  • 按固定位置提取编码片段

关键要点

  • stop 位置不包含在结果中
  • 支持 step 步长
  • 越界显示空字符，不是 NaN
  • 空字符与空值要区分

边界与易混淆

不支持替换；需要替换切片范围时用 str.slice_replace。

str.slice(0, 3) 取的是哪几个索引？
索引 0、1、2，共三个字符，不包含 3。
切片越界时结果是什么？
越界位置显示为空字符，原值为 NaN 的仍为空值。
