取所有行的指定列

数组[: · [列索引]] · 列子集抽取 · d[: · [1 · 2]]

用冒号取全部行、用整数数组取指定列，得到列子集。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

写法 d[:, [1,2]] 中逗号前的冒号表示所有行，逗号后的整数数组表示要保留的列。它等价于连续切片 d[:, 1:3]，但列可以不连续，适合从表格数据中抽取指定列。

有什么用

  • 从二维数组或表格中抽取指定列
  • 选取不连续的若干列

关键要点

  • 冒号 : 表示取该维全部
  • 列索引数组可以任意指定、不必连续
  • d[:, 1:3] 是连续列时的等价写法
  • 第 0 列不取时结果只保留第 1、2 列

边界与易混淆

列索引数组与切片混用时要分清哪边是行、哪边是列。

关联

  • 神奇索引上位概念
  • Numpy 切片对比项
