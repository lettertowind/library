权重 · weights · parameters

模型内部大量可调节的数字，模型学到的知识和能力都存在其中。

解释

参数也叫权重，可以理解成模型内部一个个可调节的旋钮。训练的过程就是不断微调这些数字，让模型预测得更准。模型名字后的 7B、70B 指的就是参数数量，B 代表十亿。

有什么用

  • 判断模型规模
  • 估算本地部署所需显存

关键要点

  • 7B 表示 70 亿参数，70B 表示 700 亿
  • 参数越多通常能力越强但成本越高
  • 一个参数通常占 2 个字节
  • 70B 模型权重约需 140GB 显存

边界与易混淆

参数多不等于效果好，还取决于训练数据质量和后训练。
