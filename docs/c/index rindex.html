index rindex

str.index · str.rindex

与 find 类似但找不到目标时会抛出异常的查找方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

index 从左往右、rindex 从右往左查找子串位置。与 find 的唯一关键差异是找不到时报错而非返回 -1，适合'必须存在'的断言场景。

有什么用

  • 确定子串一定存在时定位位置
  • 需要失败即报错的校验

关键要点

  • index 从左往右，rindex 从右往左
  • 找不到时抛异常
  • 与 find/rfind 形成容错与严格的对比

边界与易混淆

数据脏、可能缺失时用 find 更安全。
