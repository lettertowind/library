str.get

get · 取指定位置字符

获取字符串中指定索引位置的单个字符的方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

str.get(i) 按索引取出每个字符串的第 i 个字符，索引从 0 开始。参数只能是整型；越界或原值为空时返回 NaN，并可能导致整列变成 float64。

有什么用

  • 提取固定位置的字符，如首字母
  • 从编码字符串中取某一位

关键要点

  • 索引从 0 开始
  • 参数只能传 int，不能传浮点
  • 越界返回 NaN，整列可能变 float64
  • 原列有空值时也可能导致 float64

边界与易混淆

只能取单个字符，不能取范围；取范围要用 str.slice。

自测

点开看答案，先自己想一想

str.get(2) 取的是第几个字符？
第 3 个字符，因为索引从 0 开始。
为什么 str.get 之后整列可能变成 float64？
因为越界或空值位置返回 NaN，整列被提升为浮点型。
