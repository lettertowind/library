join_axes 参数

join_axes · join_axis · 对齐基准轴

旧版 Pandas 中 concat 的参数，指定以某个对象的索引为对齐基准。

目录

解释

join_axes 用于横向拼接时，以指定对象的索引为基准，将其他对象的数据按该索引匹配过来，效果类似 Excel 的 VLOOKUP。该参数在新版 Pandas 中已被移除，可用 merge 或 reindex 替代。

有什么用

  • 需要以某张表的索引为基准进行横向对齐时
  • 旧版 Pandas 代码维护

关键要点

  • 以指定索引为基准，保留基准索引，匹配其他表数据
  • 效果类似 VLOOKUP：基准表有的索引保留，没有的不保留
  • 新版 Pandas 已弃用，建议用 merge 或 reindex 替代

边界与易混淆

仅适用于旧版 Pandas；新版应使用 merge(how='left') 或 reindex 实现相同效果。

关联

自测

点开看答案，先自己想一想

join_axes=df1.index 在横向拼接时起什么作用？
以 df1 的索引为基准，只保留 df1 中存在的索引，其他表按此索引匹配数据。

### 补充 · 2026-11-17

传入 [df1.index] 时，结果只保留 df1 的索引，把另一张表能对上的值拼过来，对不上则补 NaN，思路类似 Excel 的 VLOOKUP 以左表为基准。新版 Pandas 已移除该参数。

- 参数值是索引对象组成的列表，如 [df1.index]

- 基准表有的索引全保留，另一表缺失位置补 NaN

- 等价于 VLOOKUP 式匹配，也等价于左连接思路

pd.concat([df1, df4], axis=1, join_axes=[df1.index]) 的结果行由谁决定？
完全由 df1 的索引决定，df4 只贡献能对上的值。
新版 Pandas 里用什么替代 join_axes 的“以左表为准”？
merge(how='left') 或在 concat 后按基准表的索引 reindex。
