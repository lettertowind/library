姓名首字分组

str[0] 分组 · 按姓氏分组 · 字符串位置取值分组

用 str[0] 取姓名第一个字符作为分组键，实现按姓氏汇总。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：df.groupby(df['姓名'].str[0])[列].聚合函数()

参数：

  • df['姓名'].str[0]：分组键，用 .str 访问器按下标取字符串首字（即姓氏），返回 Series
  • [df['姓名'].str[0], df['姓名'].str[1]]：传入列表即多级分组，str[1] 取第二个字符；不要用切片 str[1:2] 代替 str[1]
  • [列]：分组后选取要聚合的数值列
  • 末尾聚合函数：如 .sum()、.mean()、.count()，按需替换

示例：

import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '张六', '李七'],
    '成绩': [90, 85, 78, 92, 88]
})

# 按姓氏（首字）分组求和
print(df.groupby(df['姓名'].str[0])['成绩'].sum())
# 姓名
# 张    182
# 李    173
# 王     78
# Name: 成绩, dtype: int64

# 按首字 + 第二字多级分组
print(df.groupby([df['姓名'].str[0], df['姓名'].str[1]])['成绩'].sum())
# 姓名  姓名
# 张   三      90
#     六      92
# 李   七      88
#     四      85
# 王   五      78
# Name: 成绩, dtype: int64

解释

字符串列经 .str 访问器可用下标取字符，str[0] 取首字即姓氏。把该 Series 传给 groupby 就能按姓氏聚合，是「从字段中派生分组维度」的典型手法。

有什么用

  • 按姓氏汇总成绩或订单
  • 从编码中提取前缀分组
  • 按姓名首字+第二字多级细分

关键要点

  • df['姓名'].str[0] 取第一个字符作为分组键
  • 多级细分用 [df['姓名'].str[0], df['姓名'].str[1]]
  • 切片 [1:2] 不能同时产出两个独立分组键
  • 复姓（司马、诸葛）无法用单字规则简单处理

边界与易混淆

只适用于字符位置固定的场景；复姓或变长前缀需额外逻辑。

如何按姓名第一个字和第二个字同时分组？
df.groupby([df['姓名'].str[0], df['姓名'].str[1]])[...].sum()。
为什么 str[1:2] 切片不能替代 str[1] 作为第二个分组键？
切片返回的是子串序列，不能与首字键并列形成两个独立层级。

### 补充 · 2026-11-17

思路是把字符串列切成更粗的维度，再交给 groupby 做聚合。常见做法是只取首字按姓氏分组，或同时取 str[0] 和 str[1] 组成多键分组，把同姓但名字第二字不同的人进一步拆开。

- 单键写法：groupby(data['姓名'].str[0])。

- 多键写法：groupby([data['姓名'].str[0], data['姓名'].str[1]])。

- 取两个字符建议分开取，切片范围的写法在该场景下不稳定。

想把同姓的人再按名字第二个字细分，怎么写？
groupby([df['姓名'].str[0], df['姓名'].str[1]]) 后再聚合。
