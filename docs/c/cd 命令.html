cd 命令

cd · change directory · 进入目录

DOS/命令行中用于切换当前工作目录的命令。

目录
解释有什么用关键要点关联自测出处

解释

格式为 cd 路径，把命令行当前所在目录切换到指定文件夹。安装库前需 cd 到 pip3.exe 所在目录，否则系统找不到 pip 命令。

有什么用

  • 切换到 pip3.exe 所在目录
  • 在命令行中定位工作路径

关键要点

  • 格式：cd 空格 + 目标路径
  • 路径必须替换为本机真实路径
  • 跨盘符需先切换盘符再 cd

关联

  • cmd 命令行上位概念
  • pip前置知识

### 补充 · 2026-11-17

命令行的所有相对操作都以「当前目录」为基准，cd 就是改变这个基准。本课用它进入 pip3.exe 所在文件夹，使 pip 命令能被找到并执行。

- 写法：cd 空格 路径，路径含空格时需加引号

- 路径因每人 Python 安装位置不同而异，需自行查找 pip3.exe

- 默认安装时容易忘记装在哪，可用文件搜索定位 pip3.exe

为什么 cd 到了 pip3.exe 目录后 pip 就能用，而 cd 到别处又不行？
因为命令行会优先在当前目录查找可执行文件；pip 目录未加入 PATH，所以只有身处该目录时才能按名字调用。
