cd 命令

cd · change directory · 进入目录

DOS/命令行中用于切换当前工作目录的命令。

目录
解释有什么用关键要点关联自测出处

解释

格式为 cd 路径，把命令行当前所在目录切换到指定文件夹。安装库前需 cd 到 pip3.exe 所在目录，否则系统找不到 pip 命令。

有什么用

  • 切换到 pip3.exe 所在目录
  • 在命令行中定位工作路径

关键要点

  • 格式：cd 空格 + 目标路径
  • 路径必须替换为本机真实路径
  • 跨盘符需先切换盘符再 cd

关联

  • cmd 命令行上位概念
  • pip前置知识
