默认索引列

RangeIndex · 0 · 1 · 2 索引 · 默认行号

DataFrame 自带的从 0 开始的整数行号，不是业务字段。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

新建 DataFrame 时 Pandas 自动分配 0、1、2… 的行索引。写出到 Excel/CSV 时它默认会被当作一列输出，造成表格里多出一列无意义数字，通常需要处理掉。

有什么用

  • 理解导出文件为何多一列数字
  • 决定是否保留或替换索引

关键要点

  • 默认从 0 开始递增，与业务数据无关
  • to_excel/to_csv 默认会把它写成一列
  • 可用 set_index 换成业务字段
  • 也可在写出时用 index=False 关闭

边界与易混淆

它是索引不是列，用列名访问不到，需用 df.index。

关联

  • set_index对比项
  • DataFrame.to_excel组合使用
  • DataFrame上位概念

自测

点开看答案，先自己想一想

为什么导出的 Excel 第一列是 0、1、2？
因为 DataFrame 默认带整数行索引，写出时被当作一列输出。
除了 set_index，还有什么办法让导出时不出现这列？
在 to_excel/to_csv 中设置 index=False。
