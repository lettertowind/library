slice(None)

slice(None) · 全部切片 · 任意所有行

在多层索引查询中表示某一层取全部标签的切片写法。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：df.loc[(外层标签, slice(None)), :]

参数：

  • slice(None)：Python 内置切片对象，起止和步长都取 None，语义等价于 [:]，即在该索引层取全部标签
  • 作为 .loc 行标签元组中的一个元素使用，第几个元素对应第几层索引
  • slice(None) 也可以省略不写；但只写一个外层标签也能选出全部内层行，只是可读性较弱

示例：

import pandas as pd

idx = pd.MultiIndex.from_tuples(
    [('一班', 1), ('一班', 2), ('二班', 1)],
    names=['班级', '学号'])
df = pd.DataFrame({'分数': [90, 85, 78]}, index=idx)

print(df.loc[('一班', slice(None)), :])
#       分数
# 班级 学号
# 一班 1    90
#     2    85

解释

多层索引用 .loc 查询时，若想选外层索引下的所有内层行，内层不能简单写冒号，而要用 slice(None) 表示“全部”。它等价于 Python 切片中的 [:] 语义。

有什么用

  • 查询某个外层索引下的全部内层行
  • 多层索引中表达“任意”标签

关键要点

  • slice(None) 表示该层取全部
  • 多层行索引中不能只用冒号表示全部内层
  • 常与元组形式的行标签配合使用

边界与易混淆

只在多层索引的 .loc 元组查询中有此特殊要求，单层索引直接用冒号即可。
