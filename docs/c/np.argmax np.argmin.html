np.argmax np.argmin

argmax · argmin · 最大值下标 · 最小值下标

返回最大值或最小值所在的位置下标，而非数值本身。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

argmax/argmin 解决“最大值在哪”的问题。二维数组不指定 axis 时返回展平后的下标，与行优先遍历顺序有关；指定 axis 则返回沿该轴的下标数组。

有什么用

  • 定位极值位置
  • 找销量最高的商品序号

关键要点

  • 返回的是下标不是值
  • 二维数组默认返回展平后的下标
  • 展平顺序为行优先，下标与行列需换算
  • 可配合 axis 按行或按列找极值位置

边界与易混淆

二维数组直接取到的下标是一维展平下标，不能直接当行列坐标用。

关联

  • np.bincount组合使用

自测

点开看答案，先自己想一想

3x3 数组最大值在第 2 行第 1 列，np.argmax 返回什么？
返回展平下标 3（行优先：0,1,2 为第一行，3 为第二行第一列）。
argmax 和 max 的区别是什么？
max 返回值，argmax 返回该值所在的下标。
