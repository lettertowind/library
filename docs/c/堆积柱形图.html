堆积柱形图

堆叠柱形图 · stacked bar · plt.bar 堆叠

把多个分项在竖直方向首尾堆叠的柱形图，用 bottom 控制起点

解释

与叠加条形图结构相同、方向不同：类别在 x 轴，数值在 y 轴，堆叠起点由 bottom 而不是 left 控制。它是本课叠加条形图的原型，两者之间需要做坐标轴与参数的转换。

有什么用

  • 纵向比较各类别总量与构成
  • 类别数量不多、标签较短时

关键要点

  • 用 plt.bar，堆叠起点参数是 bottom 而非 left
  • 第一层 bottom=0，之后逐层累加
  • 转成条形图时，bar 换 barh、bottom 换 left、x/y 互换
  • 标签坐标也要随之互换，这是最常见的踩坑点

边界与易混淆

与叠加条形图仅方向不同，不要误以为改个角度就能直接沿用全部参数。

关联

  • 叠加条形图对比项
  • 柱形图上位概念
  • left 参数对比项

### 补充 · 2026-11-17

每个 x 位置只有一根柱，柱子被切成若干颜色段，总高度是各系列之和。适合看「每人总分多少、各科各占多少」这类总量加结构的问题。实现靠多次调用 plt.bar 并用 bottom 逐层抬升。

- 多次调用 plt.bar，每层都必须设 color 和 label，否则无法区分也无法出图例

- 第一层默认从 0 起，后面每层 bottom 取前面各层高度之和

- x 轴位置用 np.arange(len(data)) 生成，再用 plt.xticks 换成姓名等类别名

堆叠柱形图相比普通柱形图多回答了哪个问题？
各系列加总后的总量是多少、总量内部由哪些部分构成
