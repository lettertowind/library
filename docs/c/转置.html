转置

Transpose · arr.T · transpose

改变数组轴顺序的操作，二维数组转置即行列互换，元素值不变。

用法

语法：arr.T / arr.transpose(*axes) 参数：

  • arr：待转置的 NumPy 数组，一维数组的 .T 返回其自身视图，形状不变
  • axes：可选，整数或整数元组，指定新的轴顺序；省略时默认将轴顺序整体反转，二维即交换 0 轴与 1 轴
  • 传入 axes=(1,0) 等价于二维数组的 .T；也可写成 arr.transpose(1,0)

示例：

import numpy as np

a = np.arange(6).reshape(2, 3)
print(a.shape)        # (2, 3)
print(a.T.shape)      # (3, 2)
print(a.T)            # [[0 3] [1 4] [2 5]]
print(a.transpose(1, 0).shape)  # (3, 2)

b = np.arange(24).reshape(2, 3, 4)
print(b.shape)              # (2, 3, 4)
print(b.transpose(1, 0, 2).shape)  # (3, 2, 4)，只交换 0 轴与 1 轴

解释

二维数组原轴顺序为 (0,1)，转置后变为 (1,0)，形状由 (m,n) 变为 (n,m)。常用 arr.T 属性或 arr.transpose() 方法完成；轴转置可传入新的轴顺序元组。

有什么用

  • 行列互换，调整数据排布
  • 改变高维数组的轴顺序以适配后续运算

关键要点

  • 转置改变轴顺序和元素排布，不改变元素值
  • 二维数组转置后形状由 (m,n) 变为 (n,m)
  • arr.T 是最常用的二维转置属性
  • arr.transpose((1,0)) 通过传入轴顺序实现轴转置

边界与易混淆

转置与 reshape 都能改变形状，但转置是通过交换轴顺序实现，reshape 是按新形状重新排布元素。

### 补充 · 2026-11-17

直接数组转置类似 Excel 的单元格转置：行变列、列变行。它不改变元素值，但会改变数组形状和元素排列；二维 4 行 6 列数组转置后变成 6 行 4 列。

- 二维转置效果是行变列、列变行。

- NumPy 常用 arr.T 或 arr.transpose() 实现直接转置。

- 转置不改变元素值，但改变数组形状和元素排列。

一个 4 行 6 列的二维数组直接转置后形状是什么？
变成 6 行 4 列。
转置会改变数组中的元素值吗？
不会改变元素值，但会改变数组形状和元素排列顺序。
