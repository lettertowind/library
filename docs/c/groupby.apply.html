groupby.apply

分组应用 · groupby(...).apply(...)

按分组对每个子表调用自定义函数并合并结果。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

当每组需要多步操作（如组内排序后 shift 再算环比）时，用 groupby(...).apply(函数) 把整段逻辑封装进函数，对每个城市独立执行，避免跨组串行。

有什么用

  • 多城市分别计算环比
  • 每组需要多列多步处理的场景

关键要点

  • 先 sort_values 排序再 groupby，保证组内顺序
  • group_keys=False 可避免多出分组索引层
  • 函数内先 copy() 避免修改原数据告警
  • 适合组内多步逻辑，单步聚合用 agg 更快

边界与易混淆

性能低于向量化操作；仅当组内逻辑复杂时才用。

关联

  • shift组合使用
  • 环比组合使用

自测

点开看答案，先自己想一想

为什么多城市算环比要先排序再分组再 apply？
排序保证每个城市内部月份顺序正确，分组保证各城市独立 shift 不串行。
