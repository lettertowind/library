str.rsplit

rsplit · 从右拆分

从右向左按指定字符拆分字符串的方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

str.rsplit 与 str.split 行为类似，但拆分方向相反：split 从左往右，rsplit 从右往左。当只拆分有限次数时，两者结果不同。

有什么用

  • 需要保留左侧内容、只拆分右侧部分时
  • 处理路径或层级字符串

关键要点

  • 方向与 split 相反，从右向左
  • 同样支持 n 和 expand 参数
  • 本课只需了解，不要求熟练

边界与易混淆

与 split 的差异只在限制拆分次数时明显；全拆分时结果相同。

什么情况下 rsplit 和 split 结果会不同？
