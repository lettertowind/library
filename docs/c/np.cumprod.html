np.cumprod

cumprod · 累计积

从首元素开始逐步累乘，返回展平后等长的一维数组。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

np.cumprod 与 cumsum 对称，返回每一步的累计乘积。首项若为 0，后续所有累计积都为 0，因此演示时首项不能设为 0。

有什么用

  • 计算复利式累计增长
  • 观察连乘过程

关键要点

  • 返回长度等于元素总数的一维数组
  • 首项为 0 会导致后续全部为 0
  • 二维数组按展平顺序累乘

边界与易混淆

数值增长极快，容易溢出，业务中使用场景有限。
