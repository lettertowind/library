str.cat

cat · 字符串拼接 · concatenate

将 Series 中字符串与指定字符或等长序列拼接的方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

str.cat 用于把一列字符串与另一列、列表或固定字符连接起来，类似“穿糖葫芦”。不传参时把整列所有值首尾相连成一个长字符串；传参时可逐行拼接，但额外数据必须与目标列等长。

有什么用

  • 把多个姓名合并成一个长文本
  • 给每行数据追加固定后缀
  • 按分隔符拼接多列内容

关键要点

  • 不传参时整列平行连接成一个字符串
  • sep 参数指定连接符
  • 额外拼接数据必须与目标列等长
  • na_rep 参数替换空值，避免结果出现 NaN

边界与易混淆

逐行拼接时额外数据长度必须等于行数，否则报错；空值需用 na_rep 显式处理。

关联

自测

点开看答案，先自己想一想

df['姓名'].str.cat(['变身']*len(df), sep='') 中为什么必须乘 len(df)？
因为逐行拼接要求额外数据与姓名列等长，长度不等会报错。
str.cat 不传任何参数时结果是什么？
把整列所有字符串首尾相连成一个长字符串。
