样本与特征

行是样本、列是特征 · sample and feature

二维数据表中每一行是一个样本，每一列是该样本的一个特征。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

把二维数组对应到现实数据表：行是观测对象（如一笔订单），列是属性（如单价、销量）。理解这个映射才能正确选择 axis 做按样本或按特征的统计。

有什么用

  • 理解数据表结构
  • 决定统计沿哪个轴进行

关键要点

  • 行 = 一个样本/一条记录
  • 列 = 样本的一个特征/字段
  • 按特征标准化通常沿 0 轴处理

边界与易混淆

不同量纲的特征不能直接比较，需先标准化。

关联

  • axis 参数前置知识
  • 标准化组合使用

对数据表按列求均值，应该用 axis 等于几？
axis=0，跨行汇总得到每列均值。

### 补充 · 2026-11-17

这是把数组或表格映射到现实数据的通用视角：行对应一次观测，列对应一个可测量的属性。不同特征往往量纲不同、不能直接比较，需要标准化后才能一起分析。

- 行＝一条样本/一条记录，列＝一个特征/字段

- 特征之间量纲不同，直接比大小没有意义

- 特征可组合出新指标，如单价×数量＝销售金额

对「每个学生一行、语文/数学/英语各一列」的成绩表按列标准化，聚合统计量应沿哪个轴算？
axis=0，即沿行方向聚合，得到每一列的均值和标准差。
