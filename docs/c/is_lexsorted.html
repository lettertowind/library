is_lexsorted

index.is_lexsorted · 索引有序性检查

检查多层索引是否按字典序排好序的方法。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：df.index.is_lexsorted()（Index 对象的方法，返回布尔值）

参数：无。对当前索引检查是否已按字典序（升序）排列。

示例：

import pandas as pd

s = pd.Series([10, 20, 30], index=["a", "b", "c"])
# 旧版用 index.is_lexsorted()，pandas 2.1 起已移除
print(s.index.is_monotonic_increasing)    # True，索引已按字典序排列

s2 = pd.Series([1, 2, 3], index=["c", "a", "b"])
print(s2.index.is_monotonic_increasing)   # False，索引乱序

s2 = s2.sort_index()             # 先排序再查询更稳妥
print(s2.index.is_monotonic_increasing)   # True

解释

is_lexsorted 返回布尔值，用于判断 MultiIndex 是否处于有序状态。无序索引直接查询可能报错，因此查询前可用它检查，必要时先 sort_index 排序。

有什么用

  • 查询前检查多层索引是否有序
  • 判断是否需要先排序

关键要点

  • 返回 True 表示索引已按字典序排列
  • 无序索引直接查询可能报错
  • 检查后可配合 sort_index 先排序再查询

边界与易混淆

不是所有无序查询都会报错，但为安全起见建议先排序。
