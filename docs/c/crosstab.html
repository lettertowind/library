crosstab

pd.crosstab · 交叉表

按行、列两个维度统计频数的交叉计数表。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

crosstab 可以看作 pivot_table 的计数特例，默认就是计数，不需要指定 aggfunc。index 指定行分组条件（可传列表形成多层），columns 指定统计对象，margins=True 可加小计总计。适合统计记录条数、订单笔数、出现频次。

有什么用

  • 统计每月每区域各部门的记录条数
  • 频数分布、列联表分析

关键要点

  • 核心记忆：交叉表就是计数
  • index 传列表可实现多条件行分组
  • columns 指定被计数的对象列
  • 默认计数，无需写 aggfunc
  • 结果数字是记录条数，不一定是人数

边界与易混淆

需要求和、平均等非计数聚合时应改用 pivot_table。

关联

  • pivot_table上位概念
