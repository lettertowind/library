np.add

add · 逐元素相加

对两个数组对应位置元素逐元素相加的二元通用函数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

np.add 接收两个数组，返回对应元素相加后的新数组，等价于 x + y 的向量化形式。它是二元通用函数中最基础的运算。

有什么用

  • 两个数组逐元素求和
  • 向量化替代循环加法

关键要点

  • 逐元素相加，返回同形状数组
  • 等价于 x + y
  • 属于二元通用函数

边界与易混淆

两数组形状需可广播，否则报错。

关联

  • 二元通用函数上位概念
