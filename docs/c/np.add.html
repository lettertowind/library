np.add

add · 逐元素相加

对两个数组对应位置元素逐元素相加的二元通用函数。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：np.add(x1, x2, out=None)

参数：

  • x1：第一个输入数组或标量，参与逐元素相加
  • x2：第二个输入数组或标量，形状需与 x1 可广播，否则报错
  • out：可选，用于存放结果的数组；不传则返回一个新数组

示例：

import numpy as np

x = np.array([1, 2, 3])
y = np.array([10, 20, 30])
print(np.add(x, y))            # [11 22 33]
print(np.add(x, y) == x + y)   # [ True  True  True]

# 标量参与时会广播到每个元素
print(np.add(x, 100))          # [101 102 103]

# 二维与一维广播
a = np.array([[1, 2, 3], [4, 5, 6]])
print(np.add(a, x))            # [[ 2  4  6]
                               #  [ 5  7  9]]

解释

np.add 接收两个数组，返回对应元素相加后的新数组，等价于 x + y 的向量化形式。它是二元通用函数中最基础的运算。

有什么用

  • 两个数组逐元素求和
  • 向量化替代循环加法

关键要点

  • 逐元素相加，返回同形状数组
  • 等价于 x + y
  • 属于二元通用函数

边界与易混淆

两数组形状需可广播，否则报错。

关联

  • 二元通用函数上位概念

### 补充 · 2026-11-17

np.add 是最基础的二元通用函数，等价于数组的 + 运算，但暴露为函数形式后可作为参数传递、指定输出缓冲等。它是理解「逐元素」最直观的例子。

- 按位置逐元素相加，返回新数组

- 等同于 x + y 的运算符写法

- 属于二元通用函数，输入两个数组

np.add(x, y) 和 np.sum(x) 各自返回什么？
add 返回与 x、y 同形状的逐位相加结果；sum 返回 x 所有元素之和这一个标量。
