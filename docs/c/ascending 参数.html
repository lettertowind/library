ascending 参数

ascending · 升序降序参数 · 排序方向

控制排序方向是升序还是降序的布尔参数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

ascending=True 为升序（默认），False 为降序。多字段排序时可传列表，为每个字段分别指定方向。

有什么用

  • 单字段控制升降序
  • 多字段为每列分别指定方向

关键要点

  • 默认 True，即升序
  • False 表示降序
  • 多字段时写列表，与 by 顺序一一对应
  • sort_index 也支持该参数

边界与易混淆

多字段时若只写单个布尔值，会对所有字段统一生效，而非分别指定。

关联

  • sort_values上位概念
  • by 参数组合使用

语文降序，语文相同时数学升序

### 补充 · 2026-11-17

ascending 决定升序还是降序。单字段排序时传一个布尔值即可；多字段排序时必须传与 by 等长的布尔列表，每个位置对应一个字段的方向，例如 [False, True, False] 表示语文降序、数学升序、英语降序。

- 默认 True 为升序，降序要显式写 ascending=False

- 多字段排序时传列表，长度与 by 一致、顺序一一对应

- 列表顺序错位会导致某一列方向和预期相反

by=['语文','数学']、ascending=[False,True]，数学列内部是升序还是降序？
在语文成绩相同的组内，数学升序。
