ascending 参数

ascending · 升序降序参数 · 排序方向

控制排序方向是升序还是降序的布尔参数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

ascending=True 为升序（默认），False 为降序。多字段排序时可传列表，为每个字段分别指定方向。

有什么用

  • 单字段控制升降序
  • 多字段为每列分别指定方向

关键要点

  • 默认 True，即升序
  • False 表示降序
  • 多字段时写列表，与 by 顺序一一对应
  • sort_index 也支持该参数

边界与易混淆

多字段时若只写单个布尔值，会对所有字段统一生效，而非分别指定。

关联

  • sort_values上位概念
  • by 参数组合使用
