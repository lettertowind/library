import pandas as pd

导入 Pandas · pd 别名

导入 Pandas 库并约定以 pd 作为简写别名的标准写法。

解释

用 import ... as ... 给库起短别名，避免每次写完整包名。pd 是社区通用约定，与 NumPy 用 np 类似；别名技术上可改，但遵循惯例便于协作。

有什么用

  • 任何使用 Pandas 的脚本开头
  • 统一团队代码风格

关键要点

  • 标准写法是 import pandas as pd
  • 别名可自定义，但建议用 pd
  • 与 import numpy as np 是同类约定
  • 别名只为少打字，不改变功能

边界与易混淆

别名随意改会导致代码可读性下降、与他人代码不一致。

关联

  • DataFrame前置知识
  • Series前置知识
