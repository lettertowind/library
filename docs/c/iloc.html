iloc

df.iloc · 位置索引

按行列的整数位置查询 DataFrame 元素的索引器。

目录

解释

iloc 完全基于数据的位置编号（从 0 开始）取数，语法为 df.iloc[行位置, 列位置]。无论索引标签被改成什么，位置编号始终不变，适合按第几行第几列取数。

有什么用

  • 按第几行第几列取数
  • 索引标签混乱时仍能稳定定位

关键要点

  • 语法 df.iloc[行位置, 列位置]
  • 位置始终从 0 开始，与标签无关
  • 切片时不包含结束位置
  • 常用于循环或按序号取数

边界与易混淆

易与 loc 混淆；位置是物理顺序，数据排序变化后同一位置对应内容会变。

关联

  • loc对比项
  • DataFrame上位概念

自测

点开看答案，先自己想一想

df 的 index 被设为 ['A','B','C']，df.iloc[0,0] 取到的是什么？
第 0 行第 0 列的数据，即物理位置第一行第一列，与标签无关。
为什么说 iloc 比 loc 更适合按序号批量取数？
因为 iloc 只认从 0 开始的位置编号，不受索引标签改动影响。
