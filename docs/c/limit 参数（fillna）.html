limit 参数（fillna）

limit · 填充数量限制 · fillna limit

fillna 中限制每个填充方向最多填充的缺失值个数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

limit=n 表示沿填充方向最多只填 n 个空值，之后的空值保持原样。常用于只补最近几个空缺、避免过度填充的场景。

有什么用

  • 只补少量连续空缺
  • 控制填充范围避免失真

关键要点

  • limit 控制的是填充个数
  • 超出 limit 的空值保持为空
  • 需与 ffill/bfill 方向填充配合使用
  • 可类比 MySQL 中 limit 控制条数

边界与易混淆

limit 也适用于 fillna(常量填充)，用来限制每段连续空值最多填几个。

关联

  • fillna上位概念

自测

点开看答案，先自己想一想

df.ffill(limit=2) 的效果是什么？
每个连续空缺段最多向下填 2 个值，其余保持为空。
limit 限制的是填充方向还是填充总数？
限制每个填充方向上的填充个数。

### 补充 · 2026-11-17

当一段连续缺失很长时，全部按同一方向填充可能失真，limit 可以只填前若干个空值，剩下的继续保持为空。例如 data.bfill(limit=2) 只会填两个空值。

- limit=2 表示这次填充最多处理 2 个空值

- 超出限制的空值保持原样，不会被填充

- 通常与 ffill/bfill 方向填充搭配使用

连续 5 个空值执行 df.bfill(limit=2) 后是什么结果？
只有 2 个空值被下方有效值填充，剩下 3 个仍为空。
