栈与队列

stack and queue · LIFO/FIFO · 后进先出与先进先出

栈是后进先出、队列是先进先出的两种基本线性数据结构。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

栈只在同一端进出（LIFO），典型如函数调用栈、撤销操作；队列一端进另一端出（FIFO），典型如任务排队、消息缓冲。deque 两端都能进出，是二者的泛化：换一组方法就能在两种行为间切换。

有什么用

  • 理解为什么需要双端队列而不是只用 list
  • 选择合适的数据结构解决取用顺序问题

关键要点

  • 栈：append + pop；队列：append + popleft，用 deque 只需换方法
  • list 尾部增删是 O(1)，可当栈；但头部插入删除是 O(n)，当队列不合适
  • deque 双端皆为 O(1)，是同时支持两种语义的容器

边界与易混淆

队列若需要阻塞等待与多线程协作，应使用 queue.Queue 而非裸 deque。
