str.extract

extract · 分组捕获 · 捕获组提取

用正则括号分组从字符串中提取目标内容为多列的方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

Series.str.extract(pattern) 只提取正则中括号（捕获组）内的内容，每个括号对应一列结果。常用于从日期等复合字符串中拆出年、月、日。

有什么用

  • 从日期列拆出年月日
  • 从复合文本中抽取字段

关键要点

  • 只有括号内的内容会被提取
  • 每个捕获组对应一列
  • 日期列需先 .astype(str)
  • 正则需匹配实际分隔符（- 或 年月日）

边界与易混淆

不匹配的行对应位置为 NaN；模式写错会整列提取失败。

关联

  • str.match对比项

自测

点开看答案，先自己想一想

正则 (\d{4})-(\d{2})-(\d{2}) 用 extract 会得到几列？
三列，分别是年、月、日。
如果只给月份加括号，extract 结果是什么？
只提取月份一列。
