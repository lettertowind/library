str.startswith

startswith · 开头判断

判断字符串是否以指定内容开头的方法。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：Series.str.startswith(pat, na=None) 参数：

  • pat：要匹配的前缀，字符串或字符串元组
  • na：遇到缺失值（NaN）时返回的值，默认 None 表示缺失值位置仍返回 NaN

示例：

import pandas as pd
s = pd.Series(['满100减20', '满200减50', '新人券', None])
print(s.str.startswith('满'))
# 0     True
# 1     True
# 2    False
# 3      NaN
# dtype: bool
print(s.str.startswith('满', na=False))
# 0     True
# 1     True
# 2    False
# 3    False
# dtype: bool
print(s[s.str.startswith('满', na=False)])
# 0    满100减20
# 1    满200减50
# dtype: object

解释

str.startswith('满') 对每个元素判断是否以指定字符开头，返回布尔值。与 str.endswith 配对使用，同样支持 na 参数处理空值。

有什么用

  • 筛选以某前缀开头的记录
  • 按开头字符分类数据

关键要点

  • 返回布尔值
  • 支持 na 参数处理空值
  • 与 endswith 方向相反

边界与易混淆

只判断开头，不判断包含；判断包含用 str.contains。

关联

  • str.endswith对比项
  • str.contains对比项
  • Series.str 访问器上位概念
