解释

API Key 标识调用者身份并用于计费，一旦泄露他人可冒用你的额度。它必须保密，不能写进公开代码或分享。

有什么用

  • 程序调用模型 API 时做身份认证
  • 按调用者计费

关键要点

  • 用于识别身份和计费
  • 相当于账号密码，不能泄露
  • 费用按实际 Token 用量结算
