np.average

average · 加权平均 · weights

按权重计算加权平均，权重通过 weights 参数传入。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

np.average 在普通平均基础上引入权重，公式为 Σ(w·x)/Σw。当各数据重要性不同（如不同占比的科目成绩）时，加权平均比算术平均更合理。

有什么用

  • 计算加权成绩、加权评分
  • 不同占比数据的综合平均

关键要点

  • weights 参数传入各元素权重
  • 公式为权重乘积之和除以权重之和
  • 不传 weights 时退化为算术平均

边界与易混淆

权重之和不必为 1，函数会自动除以权重总和。

关联

  • np.mean对比项
  • 加权平均上位概念
