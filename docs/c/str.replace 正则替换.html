str.replace 正则替换

str.replace · 反向引用 · regex=True

用正则模式和反向引用对字符串做复杂替换与格式重排的方法。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：Series.str.replace(pat, repl, regex=True)

参数：

  • pat：用于匹配的模式；传入正则时，其中可包含捕获组 (\d{4}) 等。
  • repl：替换成的字符串；在正则模式下，可用 \1、\2 等反向引用捕获组，建议写成原始字符串 r'...'。
  • regex：是否把 pat 按正则表达式解释；pandas 2.x 默认就是 True，做普通子串替换时需显式传 False。
  • n：最多替换前 n 处，默认 -1 表示全部替换。
  • flags：正则标志，如 re.IGNORECASE（需 import re）。

示例：

import pandas as pd

s = pd.Series(['2020-05-01', '2021-12-31'])
# 正则捕获组 + 反向引用重排日期：年-月-日 -> 日-月-年
out = s.str.replace(r'(\d{4})-(\d{2})-(\d{2})', r'\3-\2-\1', regex=True)
print(out.tolist())   # ['01-05-2020', '31-12-2021']

# 普通子串替换：匹配粒度是字符串内部，不是整个单元格
d = pd.Series(['城八区', '海淀区'])
print(d.str.replace('城八', '市', regex=False).tolist())  # ['市区', '海淀区']

解释

Series.str.replace(pattern, repl, regex=True) 支持正则捕获组，替换串中的 \1、\2、\3 是反向引用，代表第 1、2、3 个捕获组。可实现日期格式从'年-月-日'重排为'日-月-年'。

有什么用

  • 日期格式重排
  • 复杂文本模式替换

关键要点

  • \1、\2、\3 是反向引用
  • 替换串建议用原始字符串 r'...'
  • 需显式设置 regex=True
  • 日期列先 .astype(str)

边界与易混淆

普通字符串替换不需要 regex=True；反向引用只在正则模式下生效。

r'\3-\2-\1'，配合模式 r'(\d{4})-(\d{2})-(\d{2})'。

### 补充 · 2026-11-17

Series.str.replace(pat, repl) 在列中每个字符串内部查找匹配的子串并替换，例如把“城八区”中的“城八”换成“市”得到“市区”。它解决的是字符串部分内容替换，而不是整值替换。

- 必须通过 .str 访问器调用，只适用于字符串类型 Series

- 按子串匹配，不是按整个单元格值匹配

- 与 replace() 的区别在于匹配粒度：子串 vs 整值

要把“城八区”变成“市区”，用 replace('城八区','市区') 和 str.replace('城八','市') 有什么区别？
前者要求整个单元格值等于“城八区”才替换；后者在字符串内部查找子串“城八”并替换，结果同样得到“市区”，但匹配粒度不同。

捕获组负责「记下来」，反向引用负责「再用一次」。在 str.replace 的替换串里写 \3-\2-\1，就能把捕获到的三段按新顺序拼回去，从而把 2020-05-01 变成 01-05-2020。它是正则替换能重排字段、复制片段的关键机制。

- 编号对应捕获组左括号出现的顺序，从 1 开始

- 替换串必须写成原始字符串 r''，否则 \1 被 Python 当转义处理

- 只改替换串不改模式，即可换分隔符（如 \3/\2/\1）

把 2020-05-01 改成 01-05-2020，模式与替换串分别怎么写？
模式 r'(\d{4})-(\d{2})-(\d{2})'，替换串 r'\3-\2-\1'。
如果替换串写成 '\3-\2-\1'（不加 r）会出现什么问题？
反斜杠先被 Python 当转义字符处理，得到的不再是分组引用，替换结果不符合预期。

### 补充 · 2026-11-17

Series 上替换字符串内部片段或正则匹配内容的字符串方法

- 写法：data['列'].str.replace(旧子串, 新子串)。

- 只处理被选中的 Series/列，不影响其他列。

- 适合子串替换，不是整表整值替换。

- 结果通常赋回原列：data['列'] = data['列'].str.replace(...)。

- 与 DataFrame.replace 的整值匹配形成对比。
