布尔条件分组

布尔 Series 分组 · 条件分组 · True/False 分组

把布尔判断结果直接当分组键，将数据切成 True 与 False 两组再聚合。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：df.groupby(by=布尔Series) 参数：

  • by：分组键，传入与 df 行索引对齐的布尔 Series（如 df['序号'] >= 5），结果得到 True / False 两组。
  • as_index：取默认值 True 时，组名会作为结果的索引；设为 False 时，组名会保留为普通列。
  • sort：取默认值 True，组名按 False、True 排序；设为 False 可保留首次出现顺序。

示例：

import pandas as pd

df = pd.DataFrame({'序号': [3, 5, 8, 2], '得分': [60, 70, 90, 50]})
print(df.groupby(df['序号'] >= 5)['得分'].sum().to_dict())
# {False: 110, True: 160}

print(df.groupby(~(df['序号'] >= 5))['得分'].sum().to_dict())
# {False: 160, True: 110}

解释

任何返回布尔 Series 的表达式都能塞进 groupby，例如 data.index % 2 == 0 或 data['序号'] >= 5。结果会得到 True / False 两行统计，适合作“达标 vs 未达标”“某集合内 vs 集合外”的对比。

有什么用

  • 按阈值快速对比两拨数据（如序号 >= 5 与 < 5）
  • 配合 isin 做“指定范围内 vs 范围外”的汇总

关键要点

  • 结果只有两组，组名就是 True / False。
  • 条件取反可写 != 或在表达式前加 ~，分组结果互换。
  • 阈值分组要明确边界，避免 >=5 与 <=5 在 5 处重叠。
  • 实际工作中这种按序号阈值切分的用法不多，了解即可。

边界与易混淆

只适合二分类对比；要细分多档应改用 cut/qcut 或多键分组。
