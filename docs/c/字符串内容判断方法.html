字符串内容判断方法

isalpha · isdigit · isalnum · isspace · islower · istitle

一组判断字符串内容类型（字母/数字/空白等）并返回布尔值的方法。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：Series.str.isalpha()、Series.str.isdigit()、Series.str.isalnum()、Series.str.isspace()、Series.str.islower()、Series.str.istitle()（纯 Python 字符串可直接用 'abc'.isalpha()）。 参数：无 示例：

import pandas as pd

s = pd.Series(['Python', '123', 'pandas 2', '  ', 'Data Science', '42abc'])
print(s.str.isalpha().tolist())   # [True, False, False, False, False, False]
print(s.str.isdigit().tolist())   # [False, True, False, False, False, False]
print(s.str.isalnum().tolist())   # [True, True, False, False, False, True]
print(s.str.isspace().tolist())   # [False, False, False, True, False, False]
print(s.str.islower().tolist())   # [False, False, True, False, False, True]
print(s.str.istitle().tolist())   # [True, False, False, False, True, False]
print(s[s.str.isalnum()].tolist())  # ['Python', '123', '42abc']

解释

isalpha 判断全字母，isdigit 判断全数字，isalnum 判断全字母或数字，isspace 判断全空白，islower 判断全小写，istitle 判断标题格式。不同方法对 Unicode 数字、罗马数字、汉字数字识别能力不同。

有什么用

  • 数据质量校验
  • 筛选符合内容类型的行

关键要点

  • 均返回 True/False
  • isdigit 等对数字体系的识别范围不同
  • 实际项目很少混用多种数字体系
  • 不必死记，用时查阅

边界与易混淆

对汉字数字、罗马数字的识别因方法而异，需按数据实际情况选择。

### 补充 · 2026-11-17

这类方法回答「这串字符是什么成分」：是否全字母、全数字、字母数字混合、全空格、全大写等。常用来给脏数据打标记、事后筛出异常行。三种数字判断的识别范围不同，是主要易混点。

- isdecimal 最严格，只认十进制数字字符

- isdigit 比 isdecimal 宽，还能识别部分上标数字

- isnumeric 范围最广，可识别汉字数字、罗马数字

某列既有 '123' 又有 '一二三'，想都判为数字该用哪个方法？为什么实际项目里不建议这样做？
用 isnumeric（范围最广，含汉字数字）。但一列混用两种数字形态说明数据本身不规范，汉字数字还不便排序，应先统一清洗。
isdecimal 和 isdigit 对普通数字 '5' 的结果一样吗？差别体现在哪？
对 '5' 都为 True；差别在更宽字符上，如带上标或特殊数字字形时 isdigit 为 True 而 isdecimal 为 False。
