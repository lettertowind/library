主次坐标轴

双坐标轴 · 双 y 轴 · twin axis · 主次坐标

在同一图表中用两套纵轴分别表示量纲差异大的两组数据。

解释

当柱形表示销量（几千几万）、折线表示毛利率（零点几）时，共用一根纵轴会让小数值序列被压扁。主次坐标轴让左右纵轴各自适配一组数据，图表才可读。

有什么用

  • 销量柱形图叠加毛利率折线
  • 同一图上展示量级悬殊的两个指标

关键要点

  • 使用前提是两组数据量级或量纲差异明显
  • 平均线、阈值线等参考线不需要次坐标
  • 主坐标给柱形、次坐标给折线是常见搭配
  • 不要为视觉好看滥用双轴，容易误导读者

边界与易混淆

双轴图可能让读者误读两组数据的相关性，需在图例或标注中说明各自对应哪根轴。

什么情况下需要主次坐标轴？
两组数据量级差异大（如销量几千、毛利率零点几），共用一根纵轴无法同时看清时
给柱形图加销售量平均线需要次坐标轴吗？
不需要，平均线与销售量同量纲，直接画在同一坐标轴即可

### 补充 · 2026-11-17

用 ax2 = ax1.twinx() 基于已有坐标轴生成一个新的 y 轴，两者共享同一条 x 轴、各自独立设置范围、标签和刻度格式。这是组合图的技术基础：柱形图看左轴，折线图看右轴。若想共享 y 轴而新增 x 轴，则用 twiny()。

- ax2 = ax1.twinx()：共享 x 轴，新增右侧 y 轴

- twiny()：共享 y 轴，新增上方/下方 x 轴

- 左右轴标签要分别设置 set_ylabel，做到一边一个

twinx() 和 twiny() 的区别是什么？
twinx 共享 x 轴、新增一条 y 轴；twiny 共享 y 轴、新增一条 x 轴。
双 y 轴图里为什么左右各要写一个 set_ylabel？
两根轴各自代表不同指标，标签必须分别说明其含义，否则读者分不清哪条线看哪根轴。
