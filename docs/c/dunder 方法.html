解释

例如 __add__ 定义 + 的行为，__mul__ 定义 * 的行为。没有定义时，自定义对象不能直接相加/相乘。它让对象接入 Python 的内置语法和协议。

有什么用

  • 让自定义对象支持 +、*、| 等操作符
  • 自定义打印和开发者表示

关键要点

  • 前后各两个下划线
  • 由操作符或内置函数触发
  • __add__ 对应 +，__mul__ 对应 *
  • 可返回字符串、对象或其他实例

边界与易混淆

不要随意发明 dunder 名称；应使用 Python 规定的方法名。
