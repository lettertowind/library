多键连接

复合键连接 · on 列表 · multiple keys · 多字段连接

用多个字段组成联合键做连接，所有键字段都相等才算匹配。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：pd.merge(left, right, on=['键1', '键2'], how='inner') 参数：

  • left / right：要连接的两个 DataFrame
  • on：键名列表，如 ['姓名', '班级']；只有所有键字段的值都相等时才视为匹配
  • how：连接方式，'inner'（默认）/'left'/'right'/'outer'
  • suffixes：两个表有同名列时给列名加的后缀，默认 ('_x', '_y')

示例：

import pandas as pd

d1 = pd.DataFrame({'姓名': ['张三', '王五', '张三'], '班级': ['一班', '一班', '二班'], '分数': [80, 90, 70]})
d2 = pd.DataFrame({'姓名': ['张三', '张三', '王五'], '班级': ['一班', '二班', '一班'], '分数': [85, 75, 95]})
print(pd.merge(d1, d2, on=['姓名', '班级']))          # 三行：张三一班、王五一班、张三二班
print(pd.merge(d1, d2, on=['姓名', '班级'], how='outer'))  # 全外连接，无匹配处为 NaN

解释

单个字段无法唯一定位记录时（例如同名不同班的学生），把多个字段名放进 on 的列表里，pandas 会要求这些字段同时相等才认为匹配。它的连接方式仍由 how 决定，默认还是内连接。

有什么用

  • 单字段有重复、需要多字段才能唯一确定记录时
  • 业务上天然按「主体 + 类别/时间」对齐的两张表

关键要点

  • 写法为 on=['姓名', '班级']，多个键名放进列表
  • 匹配条件是列表中所有字段同时相等
  • 不写 how 时仍默认内连接，可继续指定 left/right/outer
  • 键组合仍可能不唯一，结果行数会按匹配数展开

边界与易混淆

多键只改变匹配条件，不改变连接类型；不要把 on 列表与 how 混用成一句话。
