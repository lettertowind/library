字典

dict · 键值对 · {}

Python 内置的键值对容器，用大括号书写，键与值之间用冒号、各项之间用逗号。

解释

字典表达「名称→值」的映射关系，如 {"姓名": "孙兴华", "性别": "男"}。它的键天然带标签语义，所以可以直接喂给 pd.Series() 或 pd.DataFrame()，让键自动变成索引或列名。

有什么用

  • 描述一条带字段名的记录
  • 直接作为 pd.Series() 的入参生成带标签的一维数据

关键要点

  • 键与值之间用冒号，键值对之间用逗号，标点写错会直接报错
  • 键必须唯一，值可以是任意类型
  • 传给 pd.Series() 时键变索引、值变数据

边界与易混淆

字典的键无序（旧版本）但 Series 会保留其给出顺序；键重复会在建表时覆盖或报错。
