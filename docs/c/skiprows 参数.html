skiprows 参数

skiprows · 跳过行

读取时跳过指定行号的参数，被跳过的行不进入结果。

目录

解释

skiprows 接收行号列表，读取时直接忽略这些行。与删除不同：跳过是读取阶段忽略，结果索引会重新连续排列；删除则原索引不变。

有什么用

  • 跳过文件中的说明行或脏数据行
  • 读取时排除不需要的记录

关键要点

  • 传行号列表如 [2,3]
  • 跳过不是删除，结果索引重新连续
  • 行号从 0 开始

边界与易混淆

skiprows 与 drop 删除不同：前者读取时忽略，后者对已读数据操作且保留原索引。

### 补充 · 2026-11-17

当 Excel 上方有空行或无关说明行时，直接读取会把空行读成 NaN、表头错位。skiprows 跳过这些行，让真正的列名行成为表头。

- 行号从 0 开始计数，注意与 Excel 行号差 1

- 要保留列名行作为表头，跳过行数应到列名行之前

- 跳过太少会把列名行当数据，跳过太多会丢数据

数据实际从第 9 行开始、第 8 行是列名，skiprows 应该写几？
写 8，跳过前 8 行，让第 9 行（列名行）成为表头。
