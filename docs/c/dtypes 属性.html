解释

dtypes 显示各列类型，如 object 表示字符串类、int64 表示 64 位整型。用于读取后检查类型是否符合预期，为后续计算和转换做准备。

有什么用

  • 检查各列数据类型
  • 发现类型异常如数字被读成 object

关键要点

  • object 通常对应字符串
  • int64 为 64 位整型
  • 不同列类型可不同

边界与易混淆

dtypes 是属性；单列类型可用 data['列'].dtype 查看。

关联

  • DataFrame上位概念
  • astype(str)组合使用
