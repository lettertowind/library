空值传播

NaN 传播 · 缺失值传播 · NaN propagation

NaN 参与算术运算时结果仍为 NaN 的现象。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

在 NumPy 和 Pandas 中，任何数与 NaN 做加减乘除，结果都是 NaN。因此一列中存在空值时直接与另一列相加，对应位置结果仍为空，需要先填充或使用灵活算术方法。

有什么用

  • 两列数据运算前判断是否需要处理空值
  • 解释运算结果中出现空值的原因

关键要点

  • NaN + 1 = NaN，1 + NaN = NaN
  • 空值位置的结果不会自动跳过
  • 解决方式：fillna(0) 或 fill_value=0
  • 索引未对齐产生的缺失值同样按此规则传播

边界与易混淆

空值传播只针对 NaN；inf 不是空值，不适用 fillna。

关联

  • NaN上位概念
  • fillna对比项
  • 灵活算术方法对比项
