pipe

DataFrame.pipe · 管道方法 · 表格函数

把 DataFrame 作为第一个参数传入指定函数，实现链式调用。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

pipe 让「函数式」操作也能接入 Pandas 的链式写法。它把当前对象传给任意函数，适合把自定义函数或 groupby 这类类方法串进流水线。

有什么用

  • 链式调用中插入自定义函数
  • 把 groupby 等类方法接入管道
  • 提高多步处理的可读性

关键要点

  • df.pipe(pd.DataFrame.groupby, '班级').sum() 等价于 df.groupby('班级').sum()
  • pipe 传的是整个 DataFrame，apply 传的是行或列，map 传的是元素
  • 适合把复杂处理拆成可复用的函数步骤
  • 后续可接 .sum() 等聚合完成链式调用

边界与易混淆

简单操作直接用方法链更直观；pipe 的价值在接入外部函数时体现。

关联

  • groupby组合使用
  • apply对比项
  • map对比项

自测

点开看答案，先自己想一想

pipe、apply、map 三者的作用对象分别是什么？
pipe 作用于整个 DataFrame，apply 作用于行/列，map 作用于单个元素。
df.pipe(pd.DataFrame.groupby, '班级').sum() 等价于什么？
df.groupby('班级').sum()。
