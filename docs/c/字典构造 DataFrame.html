字典构造 DataFrame

dict 建表 · pd.DataFrame(dict)

用字典的键作列名、值作列数据来创建 DataFrame 的写法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

pd.DataFrame({...}) 接收字典时，键自动成为列名，值（通常是列表）成为该列各行数据。这是手工造小表最直观的方式，数值不加引号、字符串加引号。

有什么用

  • 快速构造演示或测试用的小型二维表
  • 把已有字典数据转成表格

关键要点

  • 键是列名，值通常是列表表示一列数据
  • 数值不加引号，字符串必须加引号
  • 键名应唯一，列表内的值可以重复
  • 各列列表长度应一致，否则会补缺失值

边界与易混淆

只适合小数据量手工构造，大批量数据应从文件读取。

关联

自测

点开看答案，先自己想一想

pd.DataFrame({'序号':[1,2],'姓名':['叶问','李小龙']}) 生成的表有几列几行？
两列（序号、姓名）两行。
如果字典里两个列表长度不同会怎样？
Pandas 会按最长列对齐，短列缺失位置补 NaN。
