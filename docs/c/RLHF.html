RLHF

人类反馈强化学习 · Reinforcement Learning from Human Feedback

用人类对回答的评分作为奖励信号来调整模型参数的强化学习方法。

目录
解释有什么用关键要点关联自测出处

解释

RLHF 是后训练中强化学习的一种形式，打分来自人而非自动指标。模型生成回答后由人评分，再按分数调整参数，使其更倾向给出人类认可的回答。

有什么用

  • 让模型回答更符合人类偏好
  • 提升回答的有用性和安全性

关键要点

  • 属于后训练中的强化学习环节
  • 奖励信号来自人类评分
  • 与自动打分相对

关联

  • 后训练上位概念
