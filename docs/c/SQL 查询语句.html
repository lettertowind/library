解释

SQL 是访问关系型数据库的标准语言，MySQL、SQL Server、SQLite 等都支持。数据分析中取数几乎都靠 SQL，因此它是读数据库的前置能力。

有什么用

  • 从数据库表中筛选、聚合数据
  • 作为 read_sql 的查询输入

关键要点

  • SQL 语句在不同数据库间基本通用
  • 最常用形式是 select * from 表名
  • 是数据分析的必备基础能力
  • 写进 read_sql 前需保证语法正确

边界与易混淆

各数据库方言存在差异，复杂函数不一定完全通用。
