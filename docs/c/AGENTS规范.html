AGENTS.md

AGENTS.md · agent.md · 管理规则文件

写给 AI Agent 的规则文件，规定知识库如何摄入、分类、关联、体检。

解释

AGENTS.md 是整套系统的核心规则层，把“拿到资料后怎么思考、怎么拆分、怎么存、怎么更新目录、怎么记录日志”写成明文规则。有了它，用户只需说“摄入素材”“体检”这类短指令，Agent 就能按规则执行。

有什么用

  • 约束 Agent 处理知识库的行为
  • 把复杂提示词固化为规则
  • 让不同 Agent 遵循同一套流程

关键要点

  • 规则文件而非提示词模板
  • 决定摄入、分类、摘要、关联、体检行为
  • 使短指令即可驱动复杂流程
  • 换 Agent 只要在同一工作目录仍生效

边界与易混淆

规则文件必须放在 Agent 的工作空间内才生效；工作空间选错则规则不起作用。

自测

点开看答案，先自己想一想

为什么有了 AGENTS.md 后，摄入素材只需输入四个字？
因为摄入的完整规则已写在 AGENTS.md 中，Agent 读取规则后自行执行拆分、分类、摘要、关联等步骤，无需在提示词里重复。
AGENTS.md 和普通提示词的区别是什么？
提示词是一次性输入，AGENTS.md 是持久化在工作空间的规则文件，每次任务都会被 Agent 读取并遵循。
