str.repeat

repeat · 字符串重复

把每个字符串重复指定次数的方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

str.repeat(n) 将每个元素重复 n 次，返回重复后的字符串。空值可通过 na 参数转换。

有什么用

  • 生成重复文本
  • 构造测试数据

关键要点

  • 参数为重复次数
  • 支持 na 参数处理空值
  • 作用于每个元素内部

边界与易混淆

与 DataFrame 层面的重复行操作不同，repeat 只重复字符串内容。

关联

  • Series.str 访问器上位概念
