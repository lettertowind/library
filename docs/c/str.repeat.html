str.repeat

repeat · 字符串重复

把每个字符串重复指定次数的方法。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：Series.str.repeat(repeats)

参数：

  • repeats：每个字符串重复的次数，整数；也可传入与 Series 等长的整数列表，逐个元素指定次数
  • 空值默认返回 NaN，需要填充时可先用 fillna() 处理，或用 str.repeat(n) 配合 fillna('')

示例：

import pandas as pd

s = pd.Series(['张三', 'ab', '数据分析', None])
out = s.str.repeat(3)
print(out)
# 0    张三张三张三
# 1    ababab
# 2    数据分析数据分析数据分析
# 3    None
# dtype: object

# 按元素指定不同次数
print(s.str.repeat([1, 2, 3, 1]))
# 0       张三
# 1       abab
# 2    数据分析数据分析数据分析
# 3     None
# dtype: object

# 空值填充后再重复
print(s.fillna('空').str.repeat(2))
# 0          张三张三
# 1          abab
# 2    数据分析数据分析数据分析数据分析
# 3            空空
# dtype: object

解释

str.repeat(n) 将每个元素重复 n 次，返回重复后的字符串。空值可通过 na 参数转换。

有什么用

  • 生成重复文本
  • 构造测试数据

关键要点

  • 参数为重复次数
  • 支持 na 参数处理空值
  • 作用于每个元素内部

边界与易混淆

与 DataFrame 层面的重复行操作不同，repeat 只重复字符串内容。

关联
