解释

raw 是所有文章、视频、报告、本地文档进入系统的第一站。Agent 摄入后会把文件移到“已摄入”子文件夹，避免重复处理。它是素材与知识之间的缓冲区。

有什么用

  • 统一收集待处理素材
  • 作为 Agent 摄入的输入源

关键要点

  • 所有原始素材先放入 raw
  • 摄入后移入已摄入子文件夹
  • 避免同一资料被重复摄入
  • Web Clipper 应配置保存到此

边界与易混淆

raw 里是未处理素材，不是知识；知识在 wiki 中。
