分组柱形图

簇状柱形图 · grouped bar chart · 并排柱形图 · x + 柱宽偏移

同一分类下多组柱子并排显示的柱形图，靠 x 坐标错开避免重叠

解释

要对比多个系列（如第 1 年 vs 第 2 年）时，把每组柱子在同一分类位置上横向偏移一个柱宽依次排开。偏移量通常等于柱宽，第二组画在 x+0.3，第三组画在 x+0.6。

有什么用

  • 多系列同一维度的数值对比
  • 需要并排展示两年/多组的柱形图

关键要点

  • 第 n 组柱子坐标写作 x + n*柱宽，柱宽本例为 0.3
  • 柱子的绘制坐标和标签坐标必须用同一个偏移量
  • 标签忘了加偏移，就会和上一组标签叠在一起
  • 与堆叠柱形图的区别：并排比高度，堆叠比累计

边界与易混淆

组数多或柱宽大时会拥挤，需缩小柱宽或改用堆叠图、折线图，否则可读性急剧下降。

自测

点开看答案，先自己想一想

柱宽 0.3，第二组柱子的数据标签 x 坐标该写什么？
x + 0.3，与第二组柱子本身的绘制位置保持一致
为什么两组柱子的标签都写 x 会发生重叠？
两组标签落在同一个 x 坐标上，只是 y 值不同，视觉上就叠在一起了
