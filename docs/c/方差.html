方差

Variance · Var(X) · σ²

各数据与均值之差的平方的平均值，衡量数据离散程度。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

方差是描述数据分布离散程度的核心统计量，数值越大说明数据越分散。它与标准差互为平方关系，是标准差计算的基础。

有什么用

  • 描述数据波动大小
  • 作为标准差、协方差等统计量的计算基础

关键要点

  • 方差 = 标准差的平方（σ² = Var(X)）
  • 计算时对偏差取平方，避免正负抵消
  • 单位是原数据单位的平方，解释性不如标准差直观
  • 易与标准差说反，需重点核对公式

边界与易混淆

方差单位是原单位的平方，实际描述波动时常用标准差；不要与标准差混用。

关联

  • 标准差对比项

自测

点开看答案，先自己想一想

已知一组数据的标准差为 4，其方差是多少？
16（方差 = 标准差² = 4²）
为什么方差计算要对偏差取平方而不是取绝对值？
平方可消除正负号并放大较大偏差，且便于后续求导与代数运算，是标准差的定义基础。

### 补充 · 2026-11-17

方差越大说明数据越分散。Pandas 中用 var() 计算，describe() 不直接输出方差但输出其平方根标准差。

- 单位是原数据单位的平方

- Pandas 用 df['列'].var() 计算

- 与标准差互为平方关系

两组数据均值相同，方差分别为 2 和 20，哪组更稳定？
方差为 2 的那组，数值更集中、波动更小。

方差用各数据点与均值之差的平方和取平均，来刻画数据的波动大小。因为做了平方，它的单位是原数据单位的平方，所以与原始数据没有直接可比性。它与标准差互为平方、开平方的关系：Var(X)=σ²，σ=√Var(X)。

- 正确关系：方差 = 标准差的平方（讲师的视频口误在此更正，04:51）

- 不能反过来说「标准差是方差的平方」，标准差是方差的开平方

- 方差的单位是原数据单位的平方，不能直接用于解释数据幅度

某组数据的标准差是 3，方差是多少？
9（方差 = 标准差²）
为什么不能直接拿方差去和原始数据的均值比大小？
方差的单位是原数据单位的平方，量纲不同，必须开平方转成标准差才能与原始数据在同一量纲下比较。
