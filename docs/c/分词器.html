分词器

Tokenizer · tokenizer

把原始文字切成 Token 并映射为词表编号的组件。

解释

分词器是文字进入模型前的第一道处理环节。它把文字切成小块，每块对应词表里的一个编号。切分规则不是人工设定，而是从大量文本中统计得出：经常一起出现的字会被合并成一块。

有什么用

  • 理解模型为何对字符级任务不敏感
  • 估算文本的 Token 消耗

关键要点

  • 切分规则由统计学习得到，非人工规则
  • 常见词合并为一块，生僻字拆成多块
  • 英文单词也经常被拆开
  • 每个模型的分词器各不相同

关联

  • Token下位概念
