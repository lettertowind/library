lambda 表达式

匿名函数 · lambda

用一行写出无名函数的语法，形式为 lambda 参数: 返回值。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

lambda 用于定义临时的小函数，常作为参数直接传给 apply、map 等。它省去 def 定义再传名的步骤，适合逻辑只有一句的场景。在 pandas 中常用于条件赋值，如 lambda x: 5 if x != '汉' else 0。

有什么用

  • apply 中写简短变换
  • 条件判断赋值
  • 临时函数传参

关键要点

  • 语法：lambda 参数: 表达式
  • 只能写单个表达式，不能写多行语句
  • 常与 apply / map 组合
  • 三元写法可做条件分支：x if 条件 else y

边界与易混淆

逻辑复杂时应改用 def 具名函数，可读性更好。

关联

  • apply组合使用
  • map组合使用

自测

点开看答案，先自己想一想

lambda x: 5 if x != '汉' else 0 对汉族返回什么？
返回 0，因为条件 x != '汉' 不成立。
