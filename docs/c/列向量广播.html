列向量广播

reshape(-1 · 1) · 列方向广播 · 列向量

用 reshape(-1,1) 把一维数组转为 (m,1) 列向量，使其沿列方向广播到二维数组。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：arr.reshape(-1, 1)（先转列向量，再与 (m, n) 数组运算） 参数：

  • -1：行数交给 NumPy 自动推断，一维长度 m 时得到 m 行
  • 1：列数固定为 1，得到形状 (m, 1)

示例：

import numpy as np

a = np.arange(1, 7).reshape(2, 3)   # (2, 3) 二维数组
row = np.array([10, 20, 30])        # 长度 3，对应列数，可直接按行广播
col = np.array([10, 20])            # 长度 2，对应行数，需 reshape 成列向量

print(a + row)                      # 每一行都加 [10,20,30]
# [[11 22 33]
#  [14 25 36]]

print(col.reshape(-1, 1) + a)       # 列向量广播：第 0 行加 10，第 1 行加 20
# [[11 12 13]
#  [23 24 25]]

# a + col 会报 ValueError：长度 2 对不上列数 3，必须先 reshape

解释

默认一维数组与二维数组运算时，一维数组长度对应列数，按行广播。若希望一维数组按列方向（每行对应一个值）参与运算，需要先将其 reshape 为 (m,1) 的列向量，再与 (m,n) 的二维数组计算。

有什么用

  • 需要按行方向对每行施加不同标量时
  • 二维数组与一维数组按列广播

关键要点

  • reshape(-1,1) 中 -1 表示自动推断行数
  • 结果形状为 (m,1)，与 (m,n) 数组广播
  • 不转换则默认按行广播（长度对应列数）

边界与易混淆

仅适用于一维数组需要按列方向广播的场景；若直接使用一维数组，NumPy 会按行广播。

如何让长度为 m 的一维数组与 (m,n) 二维数组按列方向逐行运算？
先将一维数组 reshape(-1,1) 转为 (m,1) 列向量，再与二维数组运算。

### 补充 · 2026-11-17

当二维数组与 (n,1) 的列向量计算时，列向量会横向扩展成与数组相同的列数，再逐元素计算。注意 (n,) 是一维行向量，(n,1) 才是二维列向量。

- 列向量形状为 (n,1)，是二维数组

- 与 (n,m) 运算时横向复制到 m 列

- 每一列都使用同一列向量值

np.array([[1],[2]]) 的 shape 是什么？
(2,1)，二维列向量。
列向量 (2,1) 与 (2,5) 运算时如何扩展？
横向复制成 (2,5)，每列使用同一列值。
