reset_index

df.reset_index · 重置索引

将 DataFrame 索引重置为默认 0,1,2… 的方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

reset_index() 生成新的默认整数索引，关键参数 drop 决定原索引的去留：drop=True 直接丢弃原索引，drop=False 把原索引降为普通列保留下来。

有什么用

  • 索引混乱时恢复默认序号
  • 把原索引当普通列保留分析

关键要点

  • drop=True：删除原索引
  • drop=False：原索引转为普通列
  • 默认 drop=False
  • 常与 set_index 配对使用

边界与易混淆

drop=False 会多出一列，可能影响后续列数统计；与 set_index 方向相反，勿混。

关联

  • set_index对比项
  • DataFrame上位概念

自测

点开看答案，先自己想一想

reset_index(drop=True) 和 drop=False 的结果差在哪？
drop=True 丢弃原索引只留新默认索引；drop=False 把原索引保留为普通列。
什么情况下你会选 drop=False？
当原索引本身有信息价值、需要作为一列继续参与分析时。
