解释

tail(n) 查看表格最后 n 行，默认 n=5。它与 head 对称，常用于快速检查数据尾部是否有异常或确认数据末尾内容。

有什么用

  • 快速预览数据末尾
  • 检查追加数据是否正确

关键要点

  • 默认返回后 5 行
  • tail(n) 返回后 n 行
  • 与 head 对称使用
  • 返回的是新 DataFrame，不改原表

边界与易混淆

只做预览，不改变数据；行数不足 n 时返回全部行。

关联

  • head()对比项
  • DataFrame上位概念
