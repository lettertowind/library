条件赋值

布尔赋值 · 按条件修改 · masked assignment

用布尔索引定位满足条件的元素，再对其赋新值或自增。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

条件赋值把布尔索引放在等号左边，只修改 True 位置的元素。常见形式有直接赋值（arr[arr > 5] = 1）和自增（arr[arr > 5] += 520）。它避免了循环逐个判断。

有什么用

  • 零一化处理
  • 只给满足条件的元素加值
  • 按列条件替换

关键要点

  • 写法：arr[条件] = 新值
  • 自增写法：arr[条件] += 值，等价于 arr[条件] = arr[条件] + 值
  • 只影响 True 位置，其余不变
  • 二维按列赋值要先切列再条件赋值

边界与易混淆

对二维数组直接写 arr2d[arr2d > 5] = 520 会作用于全数组，不是单列；需先取列或用行列联合索引。

关联

  • 布尔索引上位概念
  • 布尔索引筛选对比项

自测

点开看答案，先自己想一想

arr[arr > 5] += 520 和 arr[arr > 5] = arr[arr > 5] + 520 是否等价？
等价，前者是后者的简写形式，都只对大于 5 的元素加 520。

### 补充 · 2026-11-17

条件赋值把布尔索引和赋值结合：df.loc[条件, 列] = 值，只改满足条件的行。若目标列不存在，Pandas 会自动新建该列。

- 语法为 df.loc[条件, 列标签] = 值

- 只修改满足条件的行，其余行不变

- 目标列不存在时自动新建

如何用一行代码把语文>=60 的行的'及格'列设为'是'？
df.loc[df['语文']>=60, '及格'] = '是'。
