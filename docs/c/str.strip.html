str.strip

strip · 去除两端字符

按字符集合从字符串两端去除字符的方法。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：Series.str.strip(to_strip=None)

参数：

  • to_strip：要移除的字符集合。每个字符单独判断，不是整段子串；两端的字符只要出现在这个集合里，就会被反复去掉，直到遇到集合外的字符为止。None 表示去空白符。

示例：

import pandas as pd

s = pd.Series(['中远距离', '  距离  ', '离离原上草'])
print(s.str.strip('中远近离').tolist())
# ['距离', '  距离  ', '原上草']
print(s.str.lstrip('中远近离').tolist())   # 只去左侧
# ['距离', '  距离  ', '原上草']
print(s.str.strip().tolist())              # 不传参 = 去空白
# ['中远距离', '距离', '离离原上草']

解释

str.strip(chars) 从两端不断去除属于 chars 集合的字符，直到遇到不在集合中的字符。参数是字符集合而非完整子串，这是最容易误解的地方。

有什么用

  • 清理“中远近离”这类前后缀
  • 去除多余符号

关键要点

  • 参数是字符集合，不是完整子串
  • 会反复去除直到遇到集合外字符
  • lstrip 只去左侧，rstrip 只去右侧

边界与易混淆

不能按完整子串去除；需要按子串去除时用 str.replace。

“距离”，两端属于该字符集合的字符都被去除。

### 补充 · 2026-11-17

参数被理解为“字符的集合”而不是完整子串：两端只要出现集合里的字符就删掉，直到遇到不在集合里的字符为止。所以中间的字符不会被误删，只影响两端。

- 参数是字符集合，不是子串匹配

- 如 strip('中远近离') 会保留中间的“距”，因为参数里没有“距”

- 空值处理后仍为空值，不会报错

"近距离".strip("中远近离") 的结果是什么？
“距”——两端的“近”“离”被删，中间的“距”不在字符集合里所以保留
为什么说 strip 不能用来去掉某个完整词？
它按单个字符集合删除，词里的字符会被逐个剥掉，而不是整体匹配
