find rfind

str.find · str.rfind · 查找字符位置

返回子串首次出现位置的字符串方法，找不到返回 -1。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

find 从左往右查找，rfind 从右往左查找，均可指定起始和结束位置。找不到时返回 -1 而不报错，适合需要容错判断的场景。

有什么用

  • 定位日期中横杠的位置
  • 判断子串是否存在

关键要点

  • 索引从 0 开始
  • 可指定起始/结束位置控制查找范围
  • 找不到返回 -1，不报错
  • rfind 从右往左找

边界与易混淆

与 index/rindex 区别：后者找不到会抛异常。

关联

  • index rindex对比项
  • Series.str 访问器上位概念

自测

点开看答案，先自己想一想

'2020-05-01' 中 str.find('-', 5) 返回什么？
返回 7，即第二个横杠的位置。
find 找不到目标时返回什么？
返回 -1。
