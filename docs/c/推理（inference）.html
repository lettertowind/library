推理（inference）

inference · 模型推理

用训练好的参数计算一次并生成回答的过程，与训练相对。

解释

推理指训练完成后，你每发一次消息，模型就用训练好的参数计算一次并生成回答。训练是造模型，推理是用模型。它与「推理（reasoning）」中文同名但含义完全不同。

有什么用

  • 理解 API 调用成本来源
  • 区分训练与使用阶段

关键要点

  • 训练是造模型，推理是用模型
  • 每次对话都触发一次推理
  • 推理成本按 Token 计费

边界与易混淆

易与「推理（reasoning，思考过程）」混淆，两者中文同名但无关。
