知识截止

knowledge cutoff · 知识截止日期

模型训练数据收集到的日期，之后的事它不知道。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

模型知识来自训练数据，数据收集到哪一天，它就只知道那一天之前的事。问它之后发生的事，它要么不知道，要么可能编造。

有什么用

  • 判断模型能否回答时效性问题
  • 决定是否需要联网或 RAG

关键要点

  • 由训练数据收集日期决定
  • 截止日期之后的事它不知道或会编
  • 时效性问题需联网或 RAG 补充

边界与易混淆

知识截止与幻觉不同：前者是「不知道」，后者是「编得像」。
