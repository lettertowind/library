系统提示词

System Prompt · system prompt

产品方写在对话最前面、用户通常看不到的提示词。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

系统提示词规定 AI 的身份、说话风格、行为规则、能用哪些工具。同一个模型换一段系统提示词就能变成客服、翻译或编程助手。很多产品也允许用户写自己的系统提示词，如 ChatGPT 自定义指令、项目目录下的 AGENTS.md。

有什么用

  • 设定 AI 角色与行为规则
  • 避免每次重复强调要求

关键要点

  • 由产品方写在对话最前面
  • 规定身份、风格、规则、可用工具
  • 用户也可自定义（自定义指令、AGENTS.md）
  • 中途修改会导致缓存失效

边界与易混淆

系统提示词与用户提示词是两段不同的内容。

关联

  • 提示词对比项
  • AGENTS组合使用
  • 缓存组合使用
