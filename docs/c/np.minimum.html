np.minimum

minimum · 逐元素最小值

对两个数组对应位置逐元素取较小值的二元通用函数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

np.minimum 接收两个数组，逐位置比较，谁小取谁，返回新数组。与 np.maximum 对称，用于按位取小或上限截断。

有什么用

  • 按位取两列数据的较小值
  • 实现上限截断（如不超过某值）

关键要点

  • 逐元素比较，取较小值
  • 返回同形状新数组
  • 不汇总为单个最小值

边界与易混淆

与 np.min 不同：np.min 返回整体最小值标量。

关联

  • 二元通用函数上位概念
  • np.maximum对比项
  • np.max np.min对比项
