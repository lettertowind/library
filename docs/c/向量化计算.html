向量化计算

vectorization · 向量化运算

对整个数组直接做整体运算，替代显式循环逐元素处理。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

向量化让 a + b 直接完成逐元素相加，无需 for 循环和下标追加。底层由编译好的 C 代码执行，代码更短、速度更快。

有什么用

  • 数组逐元素运算
  • 替代 Python for 循环提升性能

关键要点

  • 写法上省去 for 循环和 append
  • 数据量越大，相对普通循环的优势越明显
  • 是 NumPy 高效的核心原因之一
  • 可与通用函数、广播机制组合使用

边界与易混淆

小数据量时性能差距不明显，不必为微小数据强行改写。

关联

  • 通用函数组合使用
  • 广播机制组合使用
  • np.arange前置知识

自测

点开看答案，先自己想一想

为什么 NumPy 的 a + b 比 Python 的 for 循环逐项相加快？
因为它在底层用编译代码对整个数组整体运算，避免了 Python 层的循环开销。
数据量很小时，向量化的优势是否明显？
不明显，数据量增大后优势才突出。
