str.partition

partition · 三分拆分

按第一个分隔符把字符串拆成“前、分隔符、后”三部分的方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

str.partition 固定返回三个部分：分隔符之前的内容、分隔符本身、分隔符之后的内容。与 split 不同，它保留分隔符，且只按第一个分隔符分割。

有什么用

  • 需要保留分隔符本身时
  • 把字符串拆成前缀、标记、后缀三段

关键要点

  • 固定返回三部分，保留分隔符
  • 只按第一个分隔符分割
  • 分隔符不存在时返回原字符串和两个空串
  • rpartition 从右向左查找分隔符

边界与易混淆

多个分隔符时只处理第一个；找不到分隔符不会报错，而是返回原串加两个空值。

自测

点开看答案，先自己想一想

str.partition 和 str.split 对分隔符的处理有什么本质区别？
partition 保留分隔符作为中间部分，split 不保留分隔符。
字符串中有多个分隔符时 partition 怎么处理？
只按第一个分隔符分割，其余部分整体归入第三部分。
