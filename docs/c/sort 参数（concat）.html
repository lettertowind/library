sort 参数（concat）

sort · sort=True · 排序参数

concat 中控制是否按索引排序的参数，默认为 True。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

当 concat 沿 axis=1 横向拼接时，sort 参数决定结果是否按索引排序。默认 True 会自动排序索引；设为 False 则保持原顺序。该参数在数据合并中不是重点，但了解可避免意外排序。

有什么用

  • 控制横向拼接后索引是否自动排序
  • 需要保持原始索引顺序时设为 False

关键要点

  • 默认 True，自动按索引排序
  • 设为 False 保持原索引顺序
  • 主要影响 axis=1 横向拼接的结果

边界与易混淆

sort 参数只影响索引排序，不影响数据内容。

关联
