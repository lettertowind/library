向量数据库

Vector Database · vector DB

专门存储向量并能快速找出最接近向量的数据库。

解释

向量数据库为高维向量建立索引，支持按相似度快速检索。RAG 把文档片段向量存进去，提问时用它找出最相关的几段。

有什么用

  • RAG 的片段存储与检索
  • 大规模语义搜索

关键要点

  • 核心能力是近似最近邻快速检索
  • 存的是向量，不是原始文本
  • 是 RAG 流程中的存储与检索环节

边界与易混淆

普通关系型数据库不适合做高维向量相似检索。
