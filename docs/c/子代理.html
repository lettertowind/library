子代理

Subagent · sub-agent

主 Agent 拆分出的、拥有独立上下文的从属代理，只把结论交回主 Agent。

目录
解释有什么用关键要点关联自测出处

解释

任务越复杂上下文越长，模型表现会下降。子代理让主 Agent 把大任务拆成子任务分派出去，每个子代理有独立上下文，处理完只交回结论，主 Agent 的上下文就不会被塞满。

有什么用

  • 拆分大任务以控制上下文长度
  • 并行处理多个独立子任务

关键要点

  • 每个子代理有独立上下文
  • 只把结论交回主 Agent
  • 目的是避免主上下文被塞满
