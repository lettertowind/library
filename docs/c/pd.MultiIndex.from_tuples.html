pd.MultiIndex.from_tuples

from_tuples · 元组创建 MultiIndex

用元组列表创建多层索引的方法。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：pd.MultiIndex.from_tuples(tuples, sortorder=None, names=None) 参数：

  • tuples：由元组组成的列表，每个元组对应一个索引组合，元组内元素按顺序对应各层
  • names：列表，给各层索引命名，长度需与索引层数一致
  • sortorder：整数，指定索引排序的层级；一般留空即可

示例：

import pandas as pd

mi = pd.MultiIndex.from_tuples(
    [("a", 1), ("a", 2), ("b", 1), ("b", 2)],
    names=["x", "y"]
)
print(mi)
# MultiIndex([('a', 1), ('a', 2), ('b', 1), ('b', 2)], names=['x', 'y'])

s = pd.Series([10, 20, 30, 40], index=mi)
print(s.loc[("a", 1)])  # 10

解释

from_tuples 接收一个元组列表，每个元组表示一个多层索引组合，元组内元素依次对应各层。它适合手工列举索引组合的场景。

有什么用

  • 手工列举多层索引组合
  • 从元组数据构造 MultiIndex

关键要点

  • 每个元组代表一个索引组合
  • 元组内元素顺序对应各层顺序
  • 可用 names 给各层命名

边界与易混淆

组合较多时手写元组繁琐，此时更适合用 from_product。
