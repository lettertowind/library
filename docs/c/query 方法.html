query 方法

df.query · query · 字符串查询

用字符串表达式筛选 DataFrame 行的方法，语法接近 SQL。

解释

query 接收一个字符串条件，内部解析列名和比较表达式，避免反复写 数据['列']。支持 and/or/in 等 SQL 风格语法，条件多时比布尔索引更清晰。

有什么用

  • 多条件组合筛选
  • 用 in 匹配多个指定值
  • 日期范围叠加类别条件

关键要点

  • 条件写成字符串，外层双引号内层单引号避免冲突
  • 支持 and、or、in 等 SQL 风格语法
  • 引用外部变量用 @变量名
  • 日期条件写在 query 里时不要把日期设为索引
  • 条件多时比布尔索引可读性更好

边界与易混淆

条件少时布尔索引同样可行；日期列若设为索引会导致 query 日期条件报错。

关联

  • 布尔索引筛选对比项
  • 数据筛选上位概念

自测

query 中要引用外部变量 数据，字符串里应该怎么写？
用 @数据 引用外部变量。
为什么用 query 写日期条件时不能把出生日期设为索引？
日期作为索引时 query 无法按列名解析日期条件，会报错；应保持默认索引或序号索引。
