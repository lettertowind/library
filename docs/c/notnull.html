notnull

notnull() · 判断非空

判断数据是否不为空，返回布尔值（非空为 True）。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：DataFrame.notnull() / Series.notnull() 参数：无 示例：

import pandas as pd
import numpy as np

df = pd.DataFrame({'姓名': ['张三', '李四', '王五'], '分数': [90, np.nan, 75]})
print(df.notnull())
#    姓名   分数
# 0  True  True
# 1  True  False
# 2  True  True

print(df[df['分数'].notnull()])
#    姓名    分数
# 0  张三  90.0
# 2  王五  75.0

print(df['分数'].notnull().sum())  # 2

解释

notnull() 与 isnull() 相反，非空值返回 True，空值返回 False。用于筛选非空数据或确认数据完整性。

有什么用

  • 筛选非空数据
  • 确认数据完整性

关键要点

  • 非空返回 True，空返回 False
  • 与 isnull() 结果相反

边界与易混淆

只判断是否非空，不处理空值；填充空值需用 fillna() 等。
