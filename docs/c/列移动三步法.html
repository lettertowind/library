列移动三步法

取出-删除-插入 · 调整列位置 · 鸡蛋筐法

先把目标列存到变量，drop 原列，再用 insert 插到目标位置。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：s = df['列名'] → df = df.drop('列名', axis=1) → df.insert(loc, '列名', s) 参数：

  • loc：插入位置的下标（从 0 开始），0 表示插到最左，len(df.columns) 表示插到最右
  • column：新列的名字，可与原列名相同
  • value：要插入的数据，这里传入事先保存的 Series；传入 Series 时按索引对齐
  • allow_duplicates：是否允许插入同名列，默认 False
  • drop 的 axis：必须写 axis=1（或 columns=）才是删列，写 axis=0 是删行

示例：

import pandas as pd

df = pd.DataFrame({'姓名': ['张三', '李四'], '语文': [90, 85], '数学': [88, 92]})
print(df.columns.tolist())   # ['姓名', '语文', '数学']

s = df['姓名']                # 第一步：取出
df = df.drop('姓名', axis=1)  # 第二步：删除（axis=1 才是删列）
df.insert(2, '姓名', s)       # 第三步：插到索引 2 的位置
print(df.columns.tolist())   # ['语文', '数学', '姓名']

# 等价写法：列名列表重排（列很多时更简洁）
df2 = df[['姓名', '语文', '数学']]
print(df2.columns.tolist())   # ['姓名', '语文', '数学']

解释

Pandas 没有直接「移动列」的 API，常用做法是取出该列 Series、删除原列、再 insert 到指定位置。视频用「鸡蛋筐」比喻：先复制鸡蛋、扔掉原位置、再放到想要的位置。

有什么用

  • merge 后把新列放到指定位置
  • 整理输出表的列顺序

关键要点

  • 先 s = df['列'] 保存数据，再 df.drop('列', axis=1)
  • drop 必须带 axis=1 才是删列
  • insert 的 loc 决定最终位置
  • 也可用列名列表重排 df[新顺序] 达到同样效果

边界与易混淆

列很多时用列名列表重排更简洁；三步法适合只动一两列。
