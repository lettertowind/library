列范围切片

列切片 · loc 列区间

在 loc 的列位置用冒号连接起止列名，取出连续多列。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：df.loc[行索引, '起始列名':'结束列名'] 参数：

  • 第一个参数（行位置）：行标签或切片，取全部行写 :；也可写 0:2 之类的行标签区间
  • 第二个参数（列位置）：用英文冒号连接起止列名的字符串切片，起止两列都包含
  • 列切片只能取原表中连续的列；不连续的多列要改用列表 ['语文', '英语']，此时结果顺序按列表中的顺序排列

示例：

import pandas as pd

df = pd.DataFrame({
    '语文': [90, 85, 78],
    '数学': [88, 92, 80],
    '英语': [95, 70, 86],
    '物理': [76, 88, 91],
})

print(df.loc[:, '语文':'英语'])       # 取语文、数学、英语三列，按原表顺序
#    语文  数学  英语
# 0  90  88  95
# 1  85  92  70
# 2  78  80  86

print(df.loc[0:1, '数学':'物理'])     # 行、列同时切片
#    数学  英语  物理
# 0  88  95  76
# 1  92  70  88

print(df.loc[:, ['英语', '语文']])    # 对比：列表多列，顺序可自定义
#    英语  语文
# 0  95  90
# 1  70  85
# 2  86  78

解释

df.loc[行, '语文':'英语'] 会取出从语文到英语的连续列。结果列顺序按原表列顺序排列，而不是按书写顺序。

有什么用

  • 一次取连续多个科目列
  • 按原表列顺序截取字段段

关键要点

  • 列范围用英文冒号连接起止列名
  • 结果按原表列顺序排列
  • 起止列都包含在结果内
  • 与列表多列查询不同，列表可自定义顺序

边界与易混淆

列范围切片要求列在原表中连续；不连续的多列要用列表传入。
