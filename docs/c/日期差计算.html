日期差计算

日期相减 · 间隔天数计算 · Date Difference

两个日期列直接相减得到时间差，再取出整数天数。

用法

语法：结束日期列 - 起始日期列 → 返回 Timedelta 序列，再取 .dt.days 得整数 参数：

  • 无（这是运算符，不是函数，两列须同为 datetime 类型，字符串需先 pd.to_datetime）
  • .dt.days：Timedelta 序列取整数天数；单个 Timedelta 值用 .days

示例：

import pandas as pd

df = pd.DataFrame({"起始": pd.to_datetime(["2024-01-01", "2024-02-01"]),
                   "结束": pd.to_datetime(["2024-01-08", "2024-03-01"])})
df["间隔"] = df["结束"] - df["起始"]   # 整列按行相减，得到 Timedelta
df["天数"] = df["间隔"].dt.days        # 旧写法 .apply(lambda x: x.days) 等价
print(df["间隔"].dtype)                # timedelta64[ns]
print(df["天数"].tolist())             # [7, 29]
print(df["天数"].sum())                # 36

解释

Pandas 中不需要任何公式函数，直接用「结束日期 - 起始日期」即可按行逐条算出间隔，结果是一个 Timedelta 对象。要得到能参与运算的整数天数，需要取它的 .days 属性（apply(lambda x: x.days) 或 .dt.days）。

有什么用

  • 计算保质期、账龄、项目周期等间隔天数
  • 替代 Excel 的 DATEDIF 公式

关键要点

  • 整列相减自动按行对齐，不需要写 for 循环
  • 结果是 Timedelta，显示 7 days 中的 days 表示类型，并非单位
  • 用 .apply(lambda x: x.days) 转成纯整数天数
  • 当天算不算属业务逻辑，含首日则结果再加 1
  • 相减的两列必须是 datetime 类型，字符串要先转换

边界与易混淆

只对日期时间类型有效；若列是字符串，相减会报错或得到意外结果，需先 pd.to_datetime 转换。
