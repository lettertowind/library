大语言模型

LLM · 大模型 · Large Language Model

以预测下一个 Token 为核心任务、在海量文本上训练出的语言模型。

目录

解释

大语言模型是生成式 AI 中最重要的一类，专门处理语言。它的核心能力只有一个：根据前面的文字预测下一个字最可能是什么，逐字生成整段回答。ChatGPT、DeepSeek、豆包、Kimi 背后都是大模型。

有什么用

  • 理解各类 AI 产品的能力来源
  • 判断一个 AI 产品属于哪一层技术

关键要点

  • 核心机制是逐 Token 预测下一个词
  • 训练中习得语言规律、世界知识和一定推理能力
  • 「大」体现在训练文本量和参数数量
  • 是生成式 AI 的一个子类

边界与易混淆

大模型不等于 AI 产品，产品会在模型外叠加界面、联网、文件上传等功能。

为什么大模型能生成一整段连贯的话？
它每次只预测下一个 Token，把预测结果接回输入再预测下一个，循环生成整段内容。
大模型和 ChatGPT 是什么关系？
大模型是底层模型，ChatGPT 是基于模型构建的产品，产品额外加了界面、联网等功能。

### 补充 · 2026-11-17

大模型核心能力只有一个：根据前面的文字预测下一个字最可能是什么，逐字生成整段话。之所以「大」，是因为读过的文字多、内部参数多。ChatGPT、DeepSeek、豆包、Kimi 背后都是大模型。

- 核心机制是预测下一个 Token

- 回答是逐字生成的

- 「大」体现在数据量和参数量

大模型生成一段回答的基本机制是什么？
根据前文预测下一个 Token，逐个生成直到结束。
为什么大模型能预测得准？
训练时读过海量文字，学到了语言规律、世界知识和一定推理能力。
