相关系数

corr · Correlation · 皮尔逊相关系数

标准化后的协方差，取值 -1 到 1，衡量线性相关强度。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

相关系数消除了量纲影响，绝对值越接近 1 线性关系越强。Pandas 中用 corr() 计算，数据分析岗位常用。

有什么用

  • 筛选与目标变量相关的特征
  • 判断两列是否存在线性关系

关键要点

  • 取值 -1 到 1
  • Pandas 用 corr() 计算
  • 只反映线性关系

边界与易混淆

相关系数为 0 不代表无关系，可能存在非线性关系。

关联

  • 协方差上位概念
