列表推导式

list comprehension · 推导式

用一行表达式从可迭代对象生成列表的 Python 语法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

如 [i**3 for i in range(1, n+1)] 生成立方列表。视频用它演示普通 Python 方式构造数组，与 NumPy 向量化形成对比。

有什么用

  • 快速构造列表
  • 作为 NumPy 向量化的对照写法

关键要点

  • 语法：[表达式 for 变量 in 可迭代对象]
  • 比 for + append 更简洁
  • 仍是 Python 层循环，大数据量不如向量化
  • 是学习 NumPy 前应掌握的 Python 基础

边界与易混淆

数据量大时性能不如 NumPy 向量化。

关联

  • 向量化计算对比项
  • np.arange对比项
