日期筛选三部曲

日期三部曲 · 日期处理三步曲

Pandas 日期筛选的固定三步：设日期为索引、转日期格式、排序。

目录

用法

语法：df.set_index('日期') 接着 df.index = pd.to_datetime(df.index)，再 df.sort_index()（三步都完成后，才能按日期切片或 truncate） 参数：

  • set_index('日期')：把日期列设为行索引，是第一步
  • pd.to_datetime(df.index)：把字符串索引转成 datetime64；必须把结果赋值回索引，否则不生效
  • sort_index()：按日期索引升序排列，loc 切片和 truncate 都依赖索引有序
  • loc['2020'] / loc['2020-03']：索引转成日期后，按年、年月直接筛选
  • truncate(before, after)：截取起止日期之间的连续区间，两端都包含

示例：

import pandas as pd
df = pd.DataFrame({'日期': ['2020-03-05', '2020-01-10', '2020-03-20', '2019-12-01'],
                   '销售额': [120, 90, 150, 60]})
df = df.set_index('日期')                  # ① 设日期为索引
df.index = pd.to_datetime(df.index)       # ② 转日期格式（必须赋值回去）
df = df.sort_index()                      # ③ 按索引排序
print(df.loc['2020'].shape[0])            # 3
print(df.loc['2020-03', '销售额'].tolist())  # [120, 150]
print(df.truncate('2020-01-01', '2020-03-10')['销售额'].tolist())  # [90, 120]

解释

日期筛选前需完成三步准备：把日期列设为索引，用 pd.to_datetime 转为日期格式，再对索引排序。完成后才能用年份、年月直接索引或 truncate 截取区间。

有什么用

  • 按年份/年月筛选
  • 用 truncate 截取日期区间
  • 用 loc 切片取日期区间

关键要点

  • 第一步：set_index 把日期设为索引
  • 第二步：pd.to_datetime 转日期格式
  • 第三步：sort_index 或 sort_values 排序
  • 记不住就每次把三步写全
  • query 写日期条件时反而不能设日期为索引

边界与易混淆

仅适用于基于索引的日期筛选；用 query 写日期条件时不适用，需保持默认索引。

自测

点开看答案，先自己想一想

日期筛选三部曲是哪三步？
设日期为索引、转 datetime 格式、排序索引。
为什么 query 日期条件与三部曲冲突？
三部曲要求日期设为索引，而 query 日期条件要求日期是普通列，二者不能同时满足。

### 补充 · 2026-11-17

Pandas 里日期能否被正确筛选，取决于日期是不是真正的日期类型、是不是索引、顺序是否有序。这三步是所有日期筛选方式共同的准备动作，做完之后才能用索引切片、truncate 或 query。

- 三步：set_index 设日期索引 → pd.to_datetime 转类型 → sort_index 排序。

- 按日期索引直接查询：设索引、转类型即可。

- 用 truncate：在三步基础上必须先排序。

为什么用 query 筛日期时反而不能设日期索引？
query 表达式按列名取数，日期一旦变成索引就不再是列，条件里引用会报错。
三种日期筛选方式对排序的要求有何不同？
索引切片和 truncate 依赖索引有序，需要排序；query 用布尔条件逐行判断，不需要排序。
