日期筛选三部曲

日期三部曲 · 日期处理三步曲

Pandas 日期筛选的固定三步：设日期为索引、转日期格式、排序。

解释

日期筛选前需完成三步准备：把日期列设为索引，用 pd.to_datetime 转为日期格式，再对索引排序。完成后才能用年份、年月直接索引或 truncate 截取区间。

有什么用

  • 按年份/年月筛选
  • 用 truncate 截取日期区间
  • 用 loc 切片取日期区间

关键要点

  • 第一步：set_index 把日期设为索引
  • 第二步：pd.to_datetime 转日期格式
  • 第三步：sort_index 或 sort_values 排序
  • 记不住就每次把三步写全
  • query 写日期条件时反而不能设日期为索引

边界与易混淆

仅适用于基于索引的日期筛选；用 query 写日期条件时不适用，需保持默认索引。

关联

  • truncate前置知识

日期筛选三部曲是哪三步？
设日期为索引、转 datetime 格式、排序索引。
为什么 query 日期条件与三部曲冲突？
三部曲要求日期设为索引，而 query 日期条件要求日期是普通列，二者不能同时满足。
