Obsidian

黑曜石笔记

基于本地 Markdown 文件夹的笔记软件，用于搭建个人知识仓库。

目录

解释

Obsidian 以本地文件夹为仓库，笔记就是 Markdown 文件，因此 AI Agent 可以直接读写同一文件夹来操作知识库。它提供文件列表、关系图谱等界面，把知识网络可视化。

有什么用

  • 搭建本地知识仓库
  • 可视化知识关联
  • 作为 AI Agent 的工作目录

关键要点

  • 仓库本质是电脑里的普通文件夹
  • 笔记为本地 Markdown 文件
  • 关系图谱自动展示知识点关联
  • 可与 AI Agent 共享同一工作空间

边界与易混淆

Obsidian 只是载体，不负责摄入和整理；规则与整理由 AGENTS.md 和 AI Agent 完成。
