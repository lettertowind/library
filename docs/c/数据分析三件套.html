数据分析三件套

pandas numpy xlrd · 数据分析环境依赖 · 三库组合

Python 数据分析入门必备的三个库：pandas 做表格处理、numpy 做数值计算、xlrd 读 Excel。

解释

pandas 提供 DataFrame 等表格结构，numpy 提供高效数组与数学函数，xlrd 负责解析 .xls 文件供 pandas 读取。三者构成课程后续所有操作的最小可运行环境，缺一不可。

有什么用

  • 搭建数据分析学习/工作环境
  • 排查「代码没错但跑不起来」的缺库问题

关键要点

  • pandas 依赖 numpy，安装 pandas 时通常会自动带上 numpy
  • xlrd 只在需要读旧版 .xls 时才用得上
  • 三者都通过 pip 安装，安装顺序不影响结果
  • 装完必须逐个 import 验证，而不是只看安装日志

边界与易混淆

这是入门最小集；实际项目还会涉及 openpyxl（.xlsx）、matplotlib 等，别把三件套当成完整技术栈。

关联
