suffixes 参数

suffixes · 同名列后缀 · suffixes=(_l · _r)

merge 中为左右表同名列添加后缀以区分来源的参数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

当两表存在除连接键外的同名列时，合并后会出现重名列难以区分。suffixes 接收一个二元组，分别给左表和右表的同名列加后缀。

有什么用

  • 合并后区分同名列来源
  • 避免重名列歧义

关键要点

  • 接收二元组，第一个给左表，第二个给右表
  • 后缀内容可自定义，常用 _l / _r
  • 只作用于同名列，连接键列不受影响
  • 不设置时默认后缀为 _x / _y

边界与易混淆

只处理同名列冲突；若列名本就不同则不会加后缀。

关联

自测

点开看答案，先自己想一想

两表都有列 v，merge 后想区分来源该怎么写？
加参数 suffixes=('_l','_r')，得到 v_l 和 v_r。
suffixes 会影响连接键列名吗？
不会，只作用于同名的非连接键列。

### 补充 · 2026-11-17

连接后若两表有非键的同名列（如都叫「分数」），Pandas 自动加后缀区分来源：_x 来自左表，_y 来自右表。可用 suffixes 自定义成更易读的名字。

- 默认后缀为 ('_x','_y')，_x 对应左表

- 只对非连接键的同名列生效

- 可传元组自定义，如 suffixes=('_左','_右')

结果里出现「分数_x」和「分数_y」，分别来自哪张表？
_x 来自左表，_y 来自右表。
