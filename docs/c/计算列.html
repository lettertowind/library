计算列

Calculated Column · 列间计算

用整列参与运算直接生成新列的思路，类似 SQL/Power BI 的计算列。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

计算列指不逐单元格操作，而是把一列当作整体与另一列或标量运算，结果赋给新列。pandas 中写法如 数据['销售金额'] = 数据['单价'] * 数据['销售数量']，底层是向量化运算。它解决的是 Excel 下拉填充式的重复劳动问题。

有什么用

  • 单价×数量算金额
  • 整列加减乘除标量
  • 派生新指标列

关键要点

  • 整列运算自动按索引对齐，无需循环
  • 列可与另一列或标量直接运算
  • 思路对应 Power Query / Power BI / SQL 计算列
  • 结果列直接赋值即新增列

边界与易混淆

只对整列生效；若只想算部分行需配合 for 循环或布尔索引，不能直接整列算。

关联

  • Series组合使用
  • 索引对齐前置知识
  • apply对比项

为什么 pandas 里算销售金额不需要写 for 循环？
因为整列运算走向量化，自动对每个元素逐行计算并按索引对齐。
计算列思路和 Excel 下拉填充的本质区别是什么？
计算列是整列一次性运算，Excel 下拉是逐单元格复制公式。
