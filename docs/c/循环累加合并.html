循环累加合并

空表累加 · 累计 concat · merged = pd.concat([merged · table])

先建空 DataFrame，再在循环中用 concat 不断把新表接到累计表上，汇总多份数据。

用法

语法：pd.concat(objs, axis=0, ignore_index=False, keys=None) 参数：

  • objs：待拼接的 DataFrame 列表，循环累加时写作 [merged, table]
  • axis：拼接方向，默认 0 按行追加；循环累加合并通常保持默认
  • ignore_index：为 True 时重建 0..n-1 连续索引，避免累计表索引重复
  • keys：给各来源加一层标签生成多层索引；循环累加一般不用

示例：

import pandas as pd

tables = [pd.DataFrame({'城市': ['北京'], '销量': [10]}),
          pd.DataFrame({'城市': ['上海'], '销量': [20]})]

merged = pd.DataFrame()
for table in tables:
    merged = pd.concat([merged, table], ignore_index=True)

print(merged)
#    城市  销量
# 0  北京  10
# 1  上海  20

解释

合并同一文件夹下多个工作簿，或多 sheet 时，套路是先 merged = pd.DataFrame()，每读一份就 merged = pd.concat([merged, table]) 覆盖自己。思路是“总表 + 新表 → 新总表”滚雪球。

有什么用

  • 合并一个文件夹下的多个 Excel 工作簿
  • 合并一个工作簿内的多个 sheet
  • 分批读取数据的汇总

关键要点

  • 空表直接 pd.DataFrame()，不必先建空 Excel 再读
  • 必须自赋值 merged = pd.concat([merged, table])，否则白算
  • 各来源列名要一致，否则合并后出现大片 NaN
  • 循环内反复 concat 会整表拷贝，量大时先收集到 list 再拼一次

边界与易混淆

只适合来源结构一致、总量不大的场景；列不一致或数据量巨大时应改用 append 到列表后一次性 concat。
