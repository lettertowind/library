encoding 参数

encoding · 编码参数 · encoding=utf-8

读写文件时指定字符编码的参数，常用 utf-8 解决乱码。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

文件保存编码与读取编码不一致时会出现乱码，尤其中国大陆系统默认编码非 utf-8。读取时传 encoding='utf-8'，写出时 to_csv 也可指定。

有什么用

  • 解决中文乱码
  • 统一读写编码

关键要点

  • 读取与写出都可指定 encoding
  • 中文乱码常见原因是编码不匹配
  • utf-8 是常用统一编码

边界与易混淆

编码需与文件实际保存编码一致，猜错仍会乱码。

关联

  • pd.read_csv组合使用
  • DataFrame.to_excel对比项
