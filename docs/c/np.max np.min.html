np.max np.min

max · min · 最大值 · 最小值

返回数组中的最大值或最小值，可指定 axis。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：np.max(a, axis=None) / np.min(a, axis=None) 参数：

  • a：输入数组（array_like），被求极值的数据。
  • axis：默认为 None，返回整个数组的全局极值；axis=0 返回每列极值，axis=1 返回每行极值。
  • 注意：数组含 NaN 时结果为 NaN，需改用 np.nanmax / np.nanmin。

示例：

import numpy as np

A = np.array([[3, 1, 4, 1],
              [5, 9, 2, 6],
              [5, 3, 5, 8]])

print(np.max(A))            # 9
print(np.min(A))            # 1
print(np.max(A, axis=0))    # [5 9 5 8]  每列最大值
print(np.max(A, axis=1))    # [4 9 8]    每行最大值
print(np.min(A, axis=1))    # [1 2 3]    每行最小值
print(np.argmax(A))         # 5          展平后的最大值下标

配合 argmax / argmin 可同时拿到极值及其位置。

解释

np.max 和 np.min 是全局极值函数，不指定 axis 时返回整个数组的极值；指定 axis 时返回沿该轴的一维结果。与 argmax/argmin 配合可同时拿到值和位置。

有什么用

  • 找极值
  • 按行或按列取最大最小

关键要点

  • 不指定 axis 返回全局极值
  • axis=0 返回每列极值，axis=1 返回每行极值
  • 与 argmax/argmin 配合定位极值

边界与易混淆

含 NaN 时结果可能为 NaN，需要 nanmax 等变体处理。
