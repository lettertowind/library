二次切片

先切列再筛选 · 两步索引 · chained indexing

先切出目标列，再在该列上做布尔筛选和赋值的两步操作。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

二次切片用于二维数组按列条件赋值：第一步 arr2d[:, 2] 取出第三列，第二步在该列上生成条件并赋值。也可用行列联合索引 arr2d[col > 5, 2] = 520 一步完成。

有什么用

  • 只修改某一列中满足条件的元素
  • 避免全数组条件赋值误改其他列

关键要点

  • 第一步：切出目标列，如 arr2d[:, 2]
  • 第二步：在该列上生成布尔条件并赋值
  • 等价写法：arr2d[col > 5, 2] = 520
  • 关键是明确“哪一列”和“哪些行满足条件”

边界与易混淆

链式写法 arr2d[:, 2][col > 5] = 520 在 Numpy 中通常可行，但在 Pandas 中可能触发链式赋值警告，需注意场景。

关联

  • 布尔索引上位概念
  • 条件赋值组合使用
  • Numpy 切片前置知识

col = arr2d[:, 2]; arr2d[:, 2][col > 5] = 520，或 arr2d[arr2d[:, 2] > 5, 2] = 520。
