Numpy 二维数组

ndarray 二维 · 矩阵

用 np.array 创建、按行和列组织数据的二维数据结构。

目录

解释

二维数组是 Numpy 处理表格型数据的核心结构，用行索引和列索引定位元素。可类比 Excel 的 offset 函数，按行偏移、列偏移定位区域。

有什么用

  • 表示表格型/矩阵型数据
  • 作为索引与切片的操作对象

关键要点

  • 用 np.array 嵌套列表创建
  • 定位思想是“先行后列”
  • 可类比 Excel offset 的行列偏移
  • 取单列后结果退化为一维数组

边界与易混淆

二维索引规则建立在一维索引与切片之上，一维不熟应先补 Python 基础。

### 补充 · 2026-11-17

二维数组常被称作矩阵或行列式，但它的本质是“数组中的数组”：外层数组的每个元素本身又是一个一维数组。因此创建方式仍是 np.array，只是把若干一维数组作为元素嵌套放进外层数组。它的元素总数等于行数乘列数。

- 本质是数组中的数组，不是独立的矩阵类型

- 创建用嵌套列表：np.array([[0,1,2],[3,4,5]])

- 元素总数 = 行数 × 列数，2×3 的数组有 6 个元素

为什么说二维数组的本质是“数组中的数组”？
因为外层数组的每个元素都是一个一维数组，展开后才显示成行列表格。
一个 4 行 5 列的二维数组共有多少元素？依据是什么？
20 个；二维数组元素数 = 行数 × 列数。

二维数组可理解为表格或矩阵，构造时传入嵌套列表。行索引和列索引都从 0 开始，取单个元素时先写行、后写列。

- 用 np.array() 传入嵌套列表构造

- 示例为 4 行 5 列

- 索引格式 A[行, 列]，先写行后写列

二维数组 A[0, 0] 表示哪个位置？
第 0 行第 0 列，即左上角第一个元素。
二维数组的索引 A[行, 列] 中，逗号前和逗号后分别代表什么？
逗号前代表行索引，逗号后代表列索引。
