解释

用 class 关键字定义，规定实例创建时如何初始化，以及实例可以调用哪些方法。类本身不是具体对象，而是生产对象的模板。类名通常用 PascalCase。

有什么用

  • 需要批量创建同类对象时
  • 把相关数据和功能集中管理时

关键要点

  • 用 class 关键字定义
  • 类名用 PascalCase，如 Microwave
  • 类名后加括号才创建实例
  • 类中可定义 __init__ 和实例方法

边界与易混淆

空类可以实例化但没有实际功能；类与实例的数据不要混淆。
