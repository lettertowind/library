日期范围查询

日期切片 · loc 日期区间

在 loc 中用英文冒号连接起止日期，取出该区间内的记录。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：df.loc['起始日期':'结束日期'] 参数：

  • '起始日期'：区间左端点，字符串格式需与索引一致（如 '1983-10-27'），包含该端点
  • '结束日期'：区间右端点，同样包含该端点
  • 两端用英文冒号 : 连接，缺省一端表示不设该侧边界（如 '1990':）

示例：

import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '赵六'],
    '出生日期': ['1983-10-27', '1988-05-01', '1990-12-31', '1995-03-15']
})
df['出生日期'] = pd.to_datetime(df['出生日期'])
df = df.set_index('出生日期')

print(df.loc['1983-10-27':'1990-12-31'])
#             姓名
# 出生日期
# 1983-10-27  张三
# 1988-05-01  李四
# 1990-12-31  王五

print(df.loc['1990':])          # 只给起始，取 1990 年及以后
#             姓名
# 出生日期
# 1990-12-31  王五
# 1995-03-15  赵六

解释

把日期设为索引后，df.loc['起始日期':'结束日期'] 可取出区间内实际存在的记录。它属于范围切片，比逐个列日期更高效。

有什么用

  • 取某几年间的所有记录
  • 按时间段统计成绩

关键要点

  • 前提是日期已设为索引
  • 冒号必须是英文冒号
  • 返回表中实际存在的区间内记录
  • 区间跨多年时更接近筛选思路

边界与易混淆

日期字符串格式要与数据中一致，否则可能查不到或报错。

自测
