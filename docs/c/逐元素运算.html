逐元素运算

element-wise operation · elementwise · 逐元素相加 · 对应位置运算

两个数组按对应位置元素逐一计算，得到同形状的新数组，而不是矩阵乘法。

解释

NumPy 数组的 +、-、*、** 等运算符默认按位置逐个作用于元素，所以 a + b 得到的是每个下标位置之和。它让整表批量计算不再需要手写循环，是向量化计算最直观的体现。前提是参与运算的数组形状一致，或者满足广播规则。

有什么用

  • 把两列数据整列相加/相乘
  • 对整列数据统一做幂、开方等变换
  • 替代 Python 列表 + for 循环的逐项处理

关键要点

  • a + b 返回同形状数组，每个元素为两数组同位置元素之和
  • np.arange(1, n+1) ** 3 是对每个元素取三次方，不是整体幂
  • 参与运算的数组形状需一致，否则触发广播或直接报错
  • 与矩阵乘法区分：矩阵乘法要用 @ 或 np.dot，不是 +/*

边界与易混淆

数组的 * 是逐元素相乘而非矩阵乘法；np.matrix 类型中 * 才表示矩阵乘法，两种类型混用极易出错。

自测

点开看答案，先自己想一想

a = [1,2,3]、b = [4,5,6] 转成 NumPy 数组后 a * b 得到什么？
[4, 10, 18]，逐元素相乘；不是内积 32，也不是矩阵乘法。
为什么 np.arange(1,4) ** 2 不需要写 for 循环？
幂运算符作用在数组上时按逐元素运算执行，整个数组一次性算完。
