WorkBuddy

视频演示所用的 AI Agent 工具，可操作本地文件夹并设定时任务。

解释

WorkBuddy 在本系统中担任图书馆管理员，用户选择 Obsidian 仓库文件夹作为工作空间后，它按 AGENTS.md 规则摄入素材、回答问题、体检知识库。它也支持定时任务实现自动化。

有什么用

  • 摄入素材
  • 知识库问答
  • 创建定时任务

关键要点

  • 以本地文件夹为工作空间
  • 支持选择不同模型
  • 内置定时任务功能
  • 可被豆包、Codex 等替代

边界与易混淆

只是 Agent 的一种实现，换成其他 Agent 只要工作空间和规则一致，效果类似。

关联

  • AI Agent上位概念
  • 定时任务组合使用
  • AGENTS.md前置知识
