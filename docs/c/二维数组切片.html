二维数组切片

A[行切片 · 列切片] · 二维切片 · 子数组切片

对二维数组的行和列分别用切片，取出矩形子数组。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：A[行切片, 列切片]，即 A[start:stop, start:stop]，行、列两个维度都遵循左闭右开规则 参数：

  • 行切片：逗号前，形如 start:stop，取行索引区间 [start, stop)；只写 : 表示取所有行
  • 列切片：逗号后，形如 start:stop，取列索引区间 [start, stop)；只写 : 表示取所有列
  • start：起始位置，省略时默认从头开始；可为负，-1 指最后一行/列
  • stop：结束位置，本身不被包含，省略时默认取到末尾
  • 只写一个切片 A[start:stop] 时仅作用于行，列默认全取
  • 本节只用默认步长 1，不涉及布尔索引、花式索引和复杂步长

示例：

import numpy as np

A = np.arange(20).reshape(4, 5)
print(A[0:2, 2:4])    # [[2 3]
                      #  [7 8]]
print(A[:, 2])        # [ 2  7 12 17]
print(A[0:-1].shape)  # (3, 5)

解释

格式为 A[行切片, 列切片]，两个维度都遵循左闭右开规则。A[0:2, 2:4] 取行索引 0、1 和列索引 2、3，得到 2×2 子数组。

有什么用

  • 取二维数组的矩形子区域
  • 按行区间和列区间批量提取数据

关键要点

  • 格式为 A[行切片, 列切片]
  • 逗号前是行切片，逗号后是列切片
  • 行列切片都包含开始、不包含结束
  • A[0:2, 2:4] 结果为 [[2,3],[7,8]]
  • A[0:-1] 只做行切片，取除最后一行外的所有行

边界与易混淆

本节只讲基础步长切片；不涉及布尔索引、花式索引和复杂步长。
