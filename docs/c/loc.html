loc

df.loc · 标签索引

按行、列标签查询 DataFrame 元素的索引器。

解释

loc 使用行列的标签（名称）定位数据，语法为 df.loc[行标签, 列标签]。它不关心数据在内存中的位置，只认索引标签，因此设置自定义索引后仍可用原标签查询。

有什么用

  • 按行名/列名精确取数
  • 按标签切片取多行多列

关键要点

  • 语法 df.loc[行标签, 列标签]
  • 标签可以是默认 0,1,2 或自定义索引
  • 切片时通常包含结束标签（与 iloc 不同）
  • 单行查询返回 Series

边界与易混淆

易与 iloc 混淆：loc 认标签，iloc 认位置；索引被重置后原标签可能失效。

自测

点开看答案，先自己想一想

df 的 index 被设为 ['A','B','C']，df.loc[0] 还能取到第一行吗？
不能，loc 按标签查询，此时标签是 A/B/C，应使用 df.loc['A']。
loc 和 iloc 最本质的区别是什么？
loc 按标签（名称）定位，iloc 按从 0 开始的整数位置定位。

### 补充 · 2026-11-17

loc 是 Pandas 中基于标签的索引方式，行和列都写标签名而不是位置数字。它既能做精确查询，也能做范围切片和条件筛选，还能配合条件赋值新建列。

- loc 后必须用中括号 []，不能写小括号

- 行、列都可用列表传入多个标签，顺序按列表显示

- 范围切片用英文冒号，列范围按原表列顺序排列

df.loc['1983-10-27', ['语文','数学']] 返回什么？
返回该日期这一行中语文和数学两列的数据，列顺序按列表写的顺序。
为什么用日期做 loc 查询前要先 set_index('出生日期')？
因为 loc 按行标签定位，只有把日期设为索引，日期字符串才能作为行标签被查到。
