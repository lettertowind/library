Obsidian Web Clipper

Web Clipper · 网页剪藏插件

Chrome 插件，一键把网页文章或视频保存为 Obsidian 本地 Markdown 笔记。

解释

它解决素材收集环节：点击插件即可抓取标题、链接、日期、标签、正文和图片链接，保存为本地 Markdown。收藏视频时保存在线播放链接和带时间戳字幕，不占本地视频空间。

有什么用

  • 一键收藏网页文章
  • 收藏视频及逐字稿
  • 把素材直接存入 raw 文件夹

关键要点

  • 默认保存到 clippings 文件夹
  • 可改保管库和笔记位置到 raw
  • 保管库名称需回车确认有效
  • 视频只存链接和字幕不占空间

边界与易混淆

只负责收集，不做拆分和关联；保存路径需手动配置，否则素材进不了 raw。

关联

  • Obsidian组合使用
  • raw 原始资料组合使用

自测

点开看答案，先自己想一想

为什么要把 Web Clipper 的保存路径改到 raw？
因为系统流程要求原始素材先进入 raw 文件夹，Agent 才能按 AGENTS.md 规则统一摄入；默认的 clippings 不在流程内。
收藏视频时为什么不会占用大量本地空间？
因为它保存的是在线播放链接和带时间戳的字幕文本，视频本身不下载到本地。
