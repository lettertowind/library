瀑布图

Waterfall Chart · 瀑布图 · 阶梯图

每根柱子从前面各项累计值处起步的柱形图，用来展示增减如何累积成总量。

目录

解释

普通柱形图的柱子都从 0 起画，瀑布图则把当前柱子的底部放在此前所有项的累计值上，于是正数向上加、负数向下减，整体呈阶梯式瀑布。它能直观看出“每一步怎么走到最终结果”，常用于财务盈亏、收入构成、库存或用户数变化归因。

有什么用

  • 展示逐日/逐月盈亏如何累积
  • 拆解收入、成本的增减项
  • 追踪数量类指标的阶段性变化

关键要点

  • 核心是累计起点：每画完一根柱执行 bottom += y
  • 正负分开画：金额 >= 0 用红柱，< 0 用绿柱
  • 横坐标先用 0,1,2… 位置索引，最后用 plt.xticks 换成日期
  • 柱宽 width=0.8 时，横向步长也应对应 0.8
  • Power BI 拖拽即可生成，Python 更灵活但代码较绕

边界与易混淆

与堆积柱形图不同：堆积图一根柱子里有多段，瀑布图一根柱子只有一段，靠起点错位形成阶梯。

关联

  • bottom 参数（plt.bar 堆叠起始位置）组合使用
  • 柱形图上位概念
  • 数值索引替代字符串类别轴组合使用
  • Power BI对比项

为什么瀑布图要把正负金额分成两个分支画？
因为亏损柱要向下延伸，颜色和视觉语义都不同，且 bottom 累计方向相反。
