坐标轴翻转

invert_xaxis · invert_yaxis · 轴反向 · axis inversion

用 invert_xaxis()/invert_yaxis() 把某条轴的显示方向由小到大改为大到小。

解释

默认坐标轴数值从 0 递增到 1，翻转后变成从 1 递减到 0。它只改变显示方向，不动数据本身，适合表达「越大越靠下」「排名靠前在上」这类视觉习惯。可以直接链式写成 plt.gca().invert_yaxis()。

有什么用

  • 希望 y 轴从上往下递增，例如排名、深度、优先级
  • 让视觉方向符合特定阅读或表达习惯

关键要点

  • invert_xaxis() 管 x 轴，invert_yaxis() 管 y 轴，不可混用
  • 可写 plt.gca().invert_yaxis() 省去先定义 ax
  • 只影响显示方向，DataFrame 里的数值不变
  • 对同一轴重复调用会来回翻转（每次取反）

边界与易混淆

与「修改数据」完全不同：翻转不改变数据内容，也不改变刻度间隔，只改轴的方向。

关联

  • plt.gca 与 plt.gcf组合使用
