sep 参数

sep · 分隔符参数 · delimiter

read_csv/read_table 中指定字段分隔符的参数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

sep 决定 Pandas 如何切分每行文本。可传单个字符如 ','、'\t'，也可传正则表达式如 r'\s+' 处理混合空白分隔。分隔符选错会导致整行被当成一列。

有什么用

  • 匹配文件实际分隔方式
  • 处理空格与制表符混合的复杂文本

关键要点

  • read_csv 默认 ','，read_table 默认 '\t'
  • sep=r'\s+' 匹配一个或多个空白字符
  • 正则分隔符可处理混合分隔场景

边界与易混淆

正则分隔符需注意转义与性能；简单固定分隔符优先用普通字符。
