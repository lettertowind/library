Numpy 数组形状

shape · 形状元组 · 数组 shape

描述数组每个维度长度的元组。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

如 (2,5) 表示两行五列，(5,) 表示一维五元素，(3,4,2) 表示三块四行两列。广播判断和 reshape 都以形状元组为依据。

有什么用

  • 查看数组是几维、每维多长
  • 判断两个数组能否广播
  • 确定 reshape 的目标形状

关键要点

  • 一维数组形状形如 (n,)，不是 (1,n)
  • 二维数组形状为 (行数,列数)
  • 三维数组形状为 (块数,行数,列数)
  • reshape 参数就是目标形状

边界与易混淆

(5,) 是一维数组，(1,5) 是二维数组；两者形状不同。
