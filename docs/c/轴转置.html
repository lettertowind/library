轴转置

轴转置 · transpose 轴顺序 · 轴顺序重排

通过向 transpose 传入新的轴顺序元组，重新排列数组各轴的位置。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

原轴顺序可看作元组 (0,1) 或 (0,1,2)，传入新顺序元组即可按新顺序重排轴。二维数组将 (0,1) 改为 (1,0) 即行列转置；三维数组可改为任意轴顺序。

有什么用

  • 高维数组调整轴顺序
  • 二维数组行列互换的底层实现

关键要点

  • 原轴顺序是元组，如 (0,1) 或 (0,1,2)
  • 传入新轴顺序元组即可重排轴
  • 二维数组 (0,1)→(1,0) 即行列转置
  • 三维数组可按需改变轴排列，如 (2,0,1)

边界与易混淆

轴转置只改变轴的排列顺序，不改变元素值；传入的轴顺序必须是原轴编号的一个排列。

关联

  • 转置上位概念

自测

点开看答案，先自己想一想

对三维数组，transpose((2,0,1)) 表示什么？
表示新数组的 0 轴对应原 2 轴，1 轴对应原 0 轴，2 轴对应原 1 轴。
轴转置和 arr.T 对二维数组的结果有何关系？
对二维数组，轴转置 (1,0) 与 arr.T 效果一致。
