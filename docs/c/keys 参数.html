keys 参数

keys · 层次索引标识 · 来源标识

concat 中用于为每个连接对象添加层次索引标签的参数。

目录

解释

keys 参数接收一个列表，列表元素与传入 concat 的对象顺序一一对应，生成外层索引以标识数据来源。添加后可通过外层索引筛选特定来源的数据，也便于后续分组分析。

有什么用

  • 合并多张表时标识每行数据来自哪张表
  • 为后续按来源筛选或分组提供依据

关键要点

  • keys 列表顺序与传入对象顺序对应
  • 生成 MultiIndex 的外层索引
  • 可用字典替代 keys 列表，字典 key 作为分组标识
  • 便于按来源表筛选数据

边界与易混淆

keys 只增加索引层级，不改变数据内容；与 ignore_index=True 同时使用时，keys 仍会保留外层索引。
