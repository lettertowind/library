环比

MoM · 环比增长 · 环比增长率

本期与上一个相邻周期比较的增长指标。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

环比衡量相邻周期的变化，如本月对上月、本周对上周。计算时先用 shift(1) 构造上期金额列，再用本期减上期得增长额，除以得上期得增长率。

有什么用

  • 月度/周度销售趋势分析
  • 需要看短期波动的经营指标

关键要点

  • 环比 = 与上一个相邻周期比
  • 环比增长额 = 本期 - 上期
  • 环比增长率 = (本期-上期)/上期
  • 首期没有上期数据，结果为空

边界与易混淆

易与同比混淆：环比看相邻周期，同比看去年同期。

环比对应 2 月；同比对应去年 3 月。

### 补充 · 2026-11-17

环比通常比较本月与上月、本周与上周。计算时用 shift() 取上一期金额，再用本期减上期得到增长额，增长额除以上期得到增长率。第一行没有上期，所以环比为空或 NaN。

- 环比增长额 = 本期金额 - 上期金额

- 环比增长率 = (本期 - 上期) / 上期

- shift() 默认向下移一行，首行变 NaN

用 shift() 计算环比时，第一行为什么是空值？
第一行没有上一期数据，shift 后为 NaN。
