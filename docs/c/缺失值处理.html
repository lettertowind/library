缺失值处理

Missing Value Handling · 空值处理 · NaN 处理

对数据中缺失/空值进行查看、删除、填充的一整套操作流程。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

缺失值是真实数据中普遍存在的问题，Pandas 把处理流程归纳为三步：先查看缺失值分布，再决定删除还是填充。删除适合缺失比例高且无保留价值的数据，填充适合需要保留样本但补全信息的场景。

有什么用

  • 数据清洗的第一步
  • 决定样本取舍或补全策略

关键要点

  • 三步走：查看（isna/notna）→ 删除（dropna）→ 填充（fillna）
  • 缺失值不等于空值，本节先按空值理解
  • 删除与填充的选择取决于缺失比例和业务含义
  • Pandas 批量处理比 Excel/VBA 高效得多

边界与易混淆

本节只覆盖空值层面，缺失值的高级形态（如占位符、异常编码）后续再讲。

关联

  • isnull组合使用
  • dropna 参数（透视表）对比项
  • fillna组合使用
  • NaN上位概念

自测

点开看答案，先自己想一想

拿到一份含空值的表，你会按什么顺序决定删除还是填充？
先查看缺失分布与比例，缺失比例过高且无业务价值的行列删除，需要保留样本的列用合适策略填充。
为什么说缺失值不等于空值？
空值只是缺失值的一种表现形式，缺失值还可能以占位符、异常编码等形式出现。
