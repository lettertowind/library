解释

NumPy 的标准导入写法，np 是社区通用别名，便于后续调用 np.arange、np.array 等。Pandas 对应简写为 pd。

有什么用

  • 使用 NumPy 前的第一步
  • 统一代码风格便于阅读

关键要点

  • 标准写法：import numpy as np
  • np 是约定俗成的别名，不是强制
  • Pandas 对应简写为 pd
  • 导入后才能调用 np.arange 等函数

关联

  • pip3 install numpy前置知识
  • import pandas as pd对比项
