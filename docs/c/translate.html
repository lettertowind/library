translate

str.translate · 字符映射替换

按 maketrans 生成的映射表逐字符替换字符串内容的方法。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：Series.str.translate(table) 参数：

  • table：映射表，通常用 str.maketrans() 生成（也可传字典），逐字符查找并替换为目标内容；值设为 None 表示删除该字符。

示例：

import pandas as pd

table = str.maketrans({'距': 'ju', '离': 'li'})   # 字符级映射表
s = pd.Series(['距离', '远距离测量'])
print(s.str.translate(table).tolist())
# ['juli', '远juli测量']

table2 = str.maketrans({' ': None})              # 值设为 None 即删除该字符
print(pd.Series(['a b', 'c d']).str.translate(table2).tolist())
# ['ab', 'cd']

解释

Series.str.translate(table) 按映射表把字符串中的指定字符逐个替换为目标内容，未列出的字符保持不变。比 replace 更适合建立字符级映射关系。

有什么用

  • 把'距离'中的'距''离'替换成拼音
  • 字符级批量替换

关键要点

  • 依赖 maketrans 生成的映射表
  • 逐字符替换，未指定字符不变
  • 与 replace 类似但更偏字符映射

边界与易混淆

整段字符串或复杂模式替换应使用 replace 或正则替换。
