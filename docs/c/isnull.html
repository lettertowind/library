isnull

isnull() · 判断空值

判断数据是否为空值，返回布尔值（空为 True）。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

isnull() 对每个元素判断是否为空，空值返回 True，非空返回 False。常用于发现缺失值，Pandas 中空值常用 NaN 表示。

有什么用

  • 检测缺失值
  • 数据清洗前排查空值

关键要点

  • 空值返回 True，非空返回 False
  • 常与 NaN 缺失值配合使用
  • 与 notnull() 结果相反

边界与易混淆

只判断是否为空，不统计数量；统计可用 sum() 配合。

关联

  • notnull对比项
  • Series组合使用
