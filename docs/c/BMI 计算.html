BMI 计算

BMI · 身体质量指数 · 体重身高指数

用体重除以身高平方得到的身体质量指数，衡量体重与身高比例。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

BMI = 体重 / 身高²，是数据分析中按行跨列计算的典型示例：同一行的身高与体重两列参与运算，正好演示 apply(axis=1) 的用法。

有什么用

  • 按行用两列数据算出新指标列
  • 演示 DataFrame 行级计算

关键要点

  • 公式为体重除以身高的平方
  • 需要同一行多列，必须 axis=1
  • 函数内按列名取身高、体重
  • 结果赋给新列 df['BMI指数']

边界与易混淆

身高单位需与公式一致（如米），若用厘米需先换算，否则结果失真。

关联

  • apply组合使用
  • axis 参数前置知识

为什么 BMI 示例能说明 axis=1 的作用？
