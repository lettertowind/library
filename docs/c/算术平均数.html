算术平均数

平均数 · 均值 · mean · average

所有数值求和后除以个数，用来描述数据的中心位置。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

最常见的集中趋势指标，计算简单，但对极端值极其敏感。数据分布偏斜时（如工资、收入），少数极大值会把平均数拉高，使它不能代表多数个体的真实水平。

有什么用

  • 数据分布接近对称、没有明显离群点时描述中心水平
  • 作为方差、标准差、标准化等后续计算的基准

关键要点

  • 公式：x̄ = Σxᵢ / n
  • 易被极端值拉偏，所以「平均工资」常高于多数人的实际收入
  • 分布偏斜或存在离群点时，应改用中位数
  • NumPy 中 arr.mean() / np.mean()，二维不带 axis 时是全局平均

边界与易混淆

不适合偏态分布或含明显离群点的数据；分类数据（如水果种类）无法求平均。

自测

点开看答案，先自己想一想

为什么大家常说「给平均工资拉后腿」？
少数高收入者把平均数拉高，多数普通人的收入低于平均数。
什么情况下求平均数会给出误导结论？
数据存在极端值或分布明显偏斜时，例如公司高管与基层员工的薪酬。
