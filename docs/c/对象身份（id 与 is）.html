对象身份（id 与 is）

id() · is 运算符 · identity · 身份与相等

id 是对象在内存中的身份标识，is 判断两个名字是否指向同一对象。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

赋值 l2 = l1 会让两个名字共享同一个对象，此时 is 为 True；分别创建内容相同的两个列表时 is 为 False，但 == 为 True。身份回答「是不是同一个」，相等回答「值一不一样」。

有什么用

  • 判断两个变量是否指向同一对象
  • 与 None 做比较（is None）
  • 理解可变对象的别名共享问题

关键要点

  • is 比较 id，== 比较值，两者不可混用
  • 与 None、True、False 比较要用 is
  • 小整数和短字符串会被复用，is 可能意外为 True，不可依赖
  • 别名共享可变对象时，改一个另一个也跟着变

边界与易混淆

id 值在对象销毁后可能被复用，不能当作长期唯一编号保存；判断值相等永远用 ==。

自测

点开看答案，先自己想一想

l1 = [1,2,3]；l2 = [1,2,3]，l1 == l2 与 l1 is l2 分别是什么？
True 和 False：值相等，但它们是两个不同对象。
为什么判断空值推荐 x is None 而不是 x == None？
None 是单例，is 直接比身份更快更准确，也避免自定义 __eq__ 干扰。
