asyncawait 异步语法

async · await · 异步函数 · 协程语法

用 async def 定义协程、用 await 等待异步结果，实现单线程并发。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

async def 声明的函数调用后返回协程对象，需事件循环运行。await 用于等待可等待对象完成并取结果，常用于 IO 密集任务。它不是多线程，也不会自动并行 CPU 计算。

有什么用

  • 网络请求、数据库访问等 IO 并发
  • 用 asyncio 组织异步任务
  • 避免阻塞事件循环

关键要点

  • async def 定义协程函数
  • await 等待可等待对象
  • 需 asyncio 等事件循环运行
  • 适合 IO 密集而非 CPU 密集
  • 阻塞调用会卡住事件循环

边界与易混淆

async/await 不等于多线程或多进程；CPU 密集任务仍需并行方案。
