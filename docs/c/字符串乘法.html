字符串乘法

- * 30 · str * int · 重复字符串

Python 中字符串乘以整数会重复该字符串若干次。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

表达式 '-' * 30 会生成 30 个横线组成的字符串，常用来打印分隔线。它是 Python 运算符重载的典型例子，列表也支持类似的重复操作。

有什么用

  • 打印分隔横线
  • 快速生成重复字符的填充串

关键要点

  • 字符串 * 整数 = 重复该字符串
  • print('-' * 30) 输出 30 个横线
  • 列表也支持 * 整数 重复

边界与易混淆

整数需为非负；与字符串拼接 + 不同，* 是重复而非连接两个不同字符串。

关联
