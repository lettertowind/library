case 参数

case · case=False · 大小写敏感参数

str.contains 等字符串方法中控制是否区分大小写的布尔参数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

case 默认 True 表示区分大小写，设为 False 则忽略大小写。配合正则使用时也可直接在正则里写出大小写范围，而不依赖 case。

有什么用

  • contains 忽略大小写匹配
  • 正则筛选时控制大小写

关键要点

  • 默认 case=True，区分大小写
  • case=False 忽略大小写
  • 用正则时可直接写 [a-cA-C] 代替 case=False

边界与易混淆

只对支持该参数的字符串方法有效，不是所有 str 方法都有 case 参数。

关联

  • str.contains组合使用
  • 正则表达式对比项

自测

contains('[a-c]', case=False) 能匹配大写 A 吗？
能，case=False 忽略大小写，a-c 同时匹配 A-C。
