面向对象编程

OOP · Object-Oriented Programming

用类和对象组织代码的编程范式。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

把数据和操作数据的方法封装进对象，以对象为基本单位设计程序。它通过蓝图（类）批量创建实例，减少重复代码。核心价值是复用、封装和清晰的组织结构。

有什么用

  • 设计多个同类对象时
  • 需要把数据和行为绑定在一起时

关键要点

  • 以类作为对象的蓝图
  • 以对象/实例承载具体数据
  • 方法定义对象能做什么
  • 新实例复用同一套行为

边界与易混淆

不是 Python 独有；函数式编程也能组织代码，OOP 只是范式之一。

关联

  • 类下位概念
  • 对象（实例）下位概念
