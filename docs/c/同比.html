同比

YoY · 同比增长 · 同比增长率

本期与去年同一时期比较的增长指标。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

同比消除季节性影响，衡量年度同期变化。做法是先按年份构造交叉表（Excel 数据透视表或 pivot_table），再用本年列减上年列得增长额，除以上年列得增长率。

有什么用

  • 年度经营对比
  • 消除季节波动的趋势判断

关键要点

  • 同比 = 与去年同一时期比
  • 同比增长额 = 本年同期 - 上年同期
  • 同比增长率 = (本年-上年)/上年
  • 需要先按年份把数据展开成列

边界与易混淆

需要至少两年同期数据；只有一年数据无法计算同比。

关联

  • 环比对比项
  • pivot_table组合使用

自测

点开看答案，先自己想一想

为什么算同比前要先按年份构造交叉表？
因为同比需要本年与上年两列并排，才能做列间减法与除法。

### 补充 · 2026-11-17

同比常比较今年某月与去年同月。Pandas 可先 dt.year 提取年份，再用 pivot_table 按行（如电号）、列（年份）、值（金额）做求和透视，最后用本期年份列减去年份列。增长率再除以去年同期金额。

- 同比增长额 = 本期金额 - 去年同期金额

- 同比增长率 = (本期 - 去年同期) / 去年同期

- 先用 dt.year 提取年份作为透视列

用 pivot_table 做同比透视时，为什么必须写 aggfunc='sum'？
因为默认聚合方式可能不是求和，不指定会得到错误金额。
