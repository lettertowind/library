np.prod

prod · 求积

对数组所有元素求乘积，可指定 axis。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

np.prod 把元素逐个相乘，不指定 axis 时返回全部元素的乘积。与 sum 结构对称，但乘积对 0 敏感，任一元素为 0 结果即为 0。

有什么用

  • 计算连乘积、概率连乘
  • 按轴求积

关键要点

  • 不指定 axis 时返回全局乘积
  • 任一元素为 0 则全局结果为 0
  • 支持 axis 参数按行或按列求积

边界与易混淆

元素多且值大时容易溢出，实际业务中较少直接对整表求积。

关联

  • np.sum对比项
  • np.cumprod对比项
