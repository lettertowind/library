axis 参数

axis · 轴 · 轴向

指定聚合运算沿哪个方向进行的参数，0 轴为行，1 轴为列。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

axis 决定 sum、mean、max 等函数是跨行汇总还是行内汇总。0 轴代表行方向，跨行按位置相加得到每列结果；1 轴代表列方向，行内横向相加得到每行结果。

有什么用

  • 控制按行或按列聚合
  • 理解二维数组统计结果形状

关键要点

  • 0 轴代表行，1 轴代表列
  • axis=0 跨行汇总，结果长度等于列数
  • axis=1 行内汇总，结果长度等于行数
  • 不指定 axis 时通常对全部元素运算

边界与易混淆

“0 轴是行”指汇总方向沿行，不是结果按行排列，初学最容易记反。

关联

  • np.sum组合使用
  • np.mean组合使用

自测

点开看答案，先自己想一想

np.sum(A, axis=1) 的结果长度等于行数还是列数？
等于行数，因为每行内部汇总得到一个值。
为什么说 axis=0 的结果看起来像每列的和？
因为跨行按位置相加，每个位置对应一列。

### 补充 · 2026-11-17

轴的数量等于数组维度数：一维数组只有 0 轴，二维数组有 0 轴（行）和 1 轴（列），三维数组有 0 轴（块）、1 轴（行）、2 轴（列）。理解轴的关键是先看数组维度，再看索引顺序。

- 轴编号从 0 开始，与 shape 元组索引对应

- 一维数组只有 0 轴；二维数组 0 轴为行、1 轴为列

- 三维数组 0 轴为块、1 轴为行、2 轴为列

一个 shape 为 (4, 3, 2) 的三维数组，1 轴对应什么方向？
1 轴对应每块内部的行方向，即三行。
为什么说轴编号与 shape 元组索引一一对应？
因为 shape 元组中第 i 个元素表示第 i 个轴的长度，轴编号就是元组索引。

在 Pandas 中行索引对应 0 轴、列名对应 1 轴。apply 等函数用 axis 决定把每一列还是每一行作为整体传入。理解 axis 是掌握 DataFrame 聚合与行级计算的前提。

- 行标签是 0 轴，列标签是 1 轴

- axis=0 对每列执行，axis=1 对每行执行

- axis=0 不是把一行横向相加

df.apply(sum, axis=0) 得到的是什么？
每一列的和，即按列向下汇总。
行索引和列名分别对应哪个轴？
行索引对应 0 轴，列名对应 1 轴。

axis 决定函数作用的方向。在 DataFrame.apply 中，axis=0（默认）把每一列当作一个 Series 处理，axis=1 把每一行当作一个 Series 处理。记忆口诀：零轴看列，一轴看行。

- axis=0 按列操作（默认）

- axis=1 按行操作

- 对列计算通常不用改轴，对行计算必须 axis=1

想对 DataFrame 的每一行套函数，axis 应设多少？
axis=1。
为什么说“零轴看列，一轴看行”？
axis=0 时函数把每列当一个 Series 处理，axis=1 时把每行当一个 Series 处理。

在排序中，axis=0（默认）表示按列值对行排序；axis=1 表示按行值对列排序。按行或行索引排序时必须设为 1。

- 默认 axis=0，按列值排行

- axis=1 时按行值排序列顺序

- 按行索引排序时 by 写行索引名并设 axis=1

想按某一行索引对列顺序排序，axis 要设成多少？
axis=1

axis 是 NumPy 与 Pandas 中控制运算方向的公共参数：在 ndarray 聚合中 axis=0 沿行方向、axis=1 沿列方向。在 Matplotlib 的 plt.grid 中它含义不同，用于选择只作用于 x 轴还是 y 轴的网格线。

- NumPy/Pandas 中 axis=0 沿行、axis=1 沿列

- plt.grid 中 axis='x' 是竖直网格线，axis='y' 是横向网格线

- plt.grid 省略 axis 时两个方向同时生效

plt.grid(axis='x') 加的是横线还是竖线？为什么？
竖线，因为线由 x 轴各刻度位置向上延伸，按所属轴命名。
NumPy 里 axis=1 和 plt.grid 里 axis='x' 是同一含义吗？
不是，前者指沿列方向运算，后者指网格线归属 x 轴。

行标签 0、1、2… 对应零轴 axis=0，运算「一行一行向下走」；列标签对应一轴 axis=1，运算「竖着走」即横向跨列。在 apply 中 axis=0 表示对每一列执行函数，axis=1 表示对每一行执行函数。

- axis=0 对应行标签方向，逐行向下累加，结果是每列的汇总

- axis=1 对应列标签方向，把一行数据横着组合，结果是每行的结果

- apply 中 axis=0 对每列调用函数，axis=1 对每行调用函数

df[["语文","数学"]].apply(sum, axis=0) 是把每行的三科相加吗？
不是，是每列各自逐行向下累加，得到每列总分
想按人计算跨列公式（如 BMI），axis 应取几？
axis=1，因为需要把同一行的身高和体重放在一起

- 出处：孙兴华中文讲Python数据分析三部曲入门篇 Numpy教程 Pandas教程 Matplotlib教程 p45 S02E30.数据处理的三板斧 · 2026-11-17

所有数学统计函数都带 axis 参数，用来决定是行与行之间聚合，还是列与列之间聚合。不指定时是全局计算，指定后结果维度会减少一维，处理二维数据时很容易搞混方向。

- 0 轴代表行，1 轴代表列

- axis=0：行与行对应位置相加，结果每个元素对应一列

- axis=1：每行内部各列相加，结果每个元素对应一行

arr2.sum(axis=1) 得到的是什么？
每一行内部各列元素之和，结果是长度等于行数的一维数组。
为什么说 axis=0 得到的是「每一列的结果」？
因为它把多行同一位置的数相加，压缩掉了行维度，剩下的每个元素对应一列。

- 出处：孙兴华中文讲Python数据分析三部曲入门篇 Numpy教程 Pandas教程 Matplotlib教程 p13 S01E12.数学和统计方法 · 2026-11-17

轴不是抽象方向，而是高维数组每一层嵌套结构的编号。数组有几个维度就有几个轴，轴号依次为 0、1、2……，0 轴对应最高维/最外层，末轴对应最内层的一维数据。

- 轴数等于数组维度数，一维只有 0 轴，二维有 0、1 轴。

- 二维数组通常行是 0 轴、列是 1 轴。

- 三维数组可按嵌套层级理解：块是 0 轴、行是 1 轴、列是 2 轴。

一个 shape 为 (4, 3, 2) 的三维数组有几个轴？分别可怎么理解？
有 3 个轴：0 轴是块（4 块），1 轴是行（每块 3 行），2 轴是列（每块 2 列）。
为什么说“轴号就是维度元组索引”？
因为数组维度元组有几项，就有几个轴号，依次为 0、1、2……，轴号对应元组中该维的位置。

在 DataFrame.apply 里，默认 axis=0 表示逐列传入 Series，必须显式写 axis=1 才会逐行传入。因此「对某一行做平方」如果没写 axis=1，结果表不会有任何变化。

- 默认 axis=0：沿列操作，回调拿到一列

- axis=1：沿行操作，回调拿到一行

- 对列计算不必改轴；对行计算必须显式指定 axis=1

想用 DataFrame.apply 把第一行平方，为什么结果没变化？
默认 axis=0 是按列处理，需加 axis=1 才按行处理。

### 补充 · 2026-11-17

用 0 表示行方向、1 表示列方向的操作轴参数。

- axis=0 为默认值，表示行方向

- axis=1 表示列方向，删列必写

- 写错轴会触发 KeyError（按行找不到该列名）

- Numpy 的 axis 方向含义与此一致，可迁移理解
