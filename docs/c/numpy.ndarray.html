numpy.ndarray

ndarray · NumPy 数组类型

NumPy 的核心多维数组对象类型，所有创建函数最终都返回它。

目录

用法

语法：np.ndarray(shape, dtype=float, order='C') 参数：

  • shape：整数或整数元组，指定各维度的长度，如 (2, 3)
  • dtype：数组元素的数据类型，默认 float（即 float64），也可写 np.int32、np.float32 等
  • order：内存布局，'C' 为行优先（默认），'F' 为列优先

示例：

import numpy as np

a = np.ndarray(shape=(2, 3), dtype=np.int32)
print(type(a))                          # <class 'numpy.ndarray'>
print(a.shape, a.ndim, a.size, a.dtype) # (2, 3) 2 6 int32

b = np.array([1, 2, 3])
print(type(b) is np.ndarray)            # True

解释

ndarray 是 NumPy 独有的数组数据结构，支持向量化运算和高效内存存储。用 type() 查看数组对象会得到 <class 'numpy.ndarray'>，可用来确认结果不是 Python 列表。

有什么用

  • 确认创建结果是否为 NumPy 数组
  • 理解 NumPy 所有运算的数据载体

关键要点

  • type(a) 输出 <class 'numpy.ndarray'>
  • 与 Python list 是不同对象类型
  • np.array、np.arange、np.ones 等均返回 ndarray
  • 支持 shape/ndim/size/dtype 等属性

边界与易混淆

ndarray 不是 list，很多 list 方法（如 append）在数组上行为不同或不存在。
