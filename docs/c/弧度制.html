弧度制

radian · 弧度 · π=180° · np.pi

用弧长与半径之比度量角度的方式，π 弧度等于 180 度。

解释

Matplotlib 所有极坐标角度都按弧度解释，所以画常见角度时要换成 π 的倍数。记住 π = 180° 这一条，就能推导出 45°、135°、270° 等常用写法。

有什么用

  • 把习惯的角度换算成 Matplotlib 能接受的极角
  • 构造 theta 数组（先写 π 的倍数再统一乘 np.pi）

关键要点

  • π = 180°，2π = 360°，π/2 = 90°
  • 常用：0.25π=45°、0.75π=135°、1.5π=270°
  • NumPy 中 π 取 np.pi（3.1415926…）
  • 不必关心 0.25π 算出的 0.785 具体值，知道它代表 45° 即可

边界与易混淆

别把角度直接当弧度传入；弧度值也不必手工算成小数，写成 x * np.pi 更可读。

把 135° 写成 matplotlib 能用的极角，应怎么写？
0.75 * np.pi（因为 π=180°，135/180=0.75）。
“不需要关心 0.25π≈0.785”这句话的实用含义是什么？
代码里直接用 0.25*np.pi 表达 45° 即可，靠几何含义理解角度，不必做小数换算。
