on 参数

on · 连接键参数 · on=[k1 · k2]

merge 中指定用于对齐合并的同名列的参数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

on 告诉 merge 用哪一列（或多列）作为连接键，要求左右表都存在该列名。它相当于 Excel VLOOKUP 中用来匹配的那个共同字段。

有什么用

  • 指定单列连接键
  • 用多列列表做复合键连接

关键要点

  • 左右表必须存在同名同义的列
  • 支持单列字符串或多列列表
  • 多列时按组合键整体匹配
  • 列名不同时需改用 left_on/right_on
  • join 的 on 语义不同，常是左表列对右表索引

边界与易混淆

on 只适用于同名列；join 的 on 是左表列匹配右表索引，两者不可混用。

自测

点开看答案，先自己想一想

左右表连接字段名不同（左 k1、右 key1），还能用 on 吗？
不能，应改用 left_on='k1', right_on='key1'。
on=['k1','k2'] 表示什么？
用 k1 和 k2 两列的组合作为复合连接键。

### 补充 · 2026-11-17

当两个表的连接键列名相同时用 on 指定；传列表即多键连接，要求所有键同时相等才算匹配。列名不同则改用 left_on/right_on。

- on='姓名' 为单键连接

- on=['姓名','班级'] 为多键连接，需全部键相等

- 同名列存在时 Pandas 可自动识别，但显式写更清楚

两表都有姓名和班级列，只想「姓名+班级」同时相同才匹配，怎么写？
pd.merge(a, b, on=['姓名','班级'])。
