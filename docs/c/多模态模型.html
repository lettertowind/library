多模态模型

multimodal model · 多模态

能同时理解和处理文字、图片、声音等多种信息形式的模型。

目录
解释有什么用关键要点关联自测出处

解释

文字、图片、声音、视频是信息的不同形式，在 AI 里叫不同的模态。多模态模型能同时理解多种模态。图片会被切成小方块并转换成 Token，与文字 Token 一起处理，因此图片同样占用 Token。

有什么用

  • 读取截图中的表格
  • 分析图表和视频内容
  • 语音交互

关键要点

  • 图片切成小方块后转为 Token
  • 图片越大占用 Token 越多
  • 语音侧涉及 ASR 和 TTS

关联

  • Token前置知识
  • ASR组合使用
  • TTS组合使用
  • 扩散模型对比项
