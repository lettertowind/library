str.decode

decode · 解码转换

把编码后的字节按指定格式解码为字符串的方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

str.decode('utf-8') 将字节内容按指定字符集还原为字符串，是 str.encode 的逆操作。常用于读取乱码数据后还原。

有什么用

  • 还原编码后的文本
  • 修复乱码列

关键要点

  • 参数为解码格式
  • 与 encode 配对使用
  • 格式不匹配会乱码或报错

边界与易混淆

解码格式必须与编码格式一致。

关联

  • str.encode对比项
  • Series.str 访问器上位概念
