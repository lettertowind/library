浅拷贝与深拷贝

copy · 视图 · view vs copy · 独立副本

直接赋值和切片共享底层数据（浅拷贝），copy() 才创建独立副本。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

在 NumPy 中 a = b 或 a = b[:] 往往让两者共享同一份数据，改一个另一个也变。用 b.copy() 得到深拷贝，两者互不影响。这是极易出错的地方。

有什么用

  • 需要独立修改数组而不影响原数组时
  • 避免切片视图带来的意外联动

关键要点

  • a = b 是同一份数据的两个名字
  • 切片通常返回视图，仍共享数据
  • b.copy() 创建独立副本
  • 赋值前先判断是否需要 copy

边界与易混淆

视图省内存但易引发联动 bug；深拷贝安全但占内存。

关联

  • numpy.ndarray上位概念
  • Numpy 切片前置知识

自测

点开看答案，先自己想一想

a = b[:] 之后修改 b，a 会变吗？
会，切片是视图，共享底层数据。
怎样让两个数组完全独立？
用 b.copy() 创建深拷贝。
