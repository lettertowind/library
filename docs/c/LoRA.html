LoRA

低秩适配 · Low-Rank Adaptation

冻结原模型参数、只额外训练一小部分新参数的低成本微调方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

LoRA 不动原来的参数，只训练少量新增参数，成本远低于全参数微调。AI 绘画里常见的风格模型很多就是用 LoRA 训练的。

有什么用

  • 低成本微调
  • 训练风格模型

关键要点

  • 原参数不动，只训练一小部分新参数
  • 成本比完整微调低得多
  • AI 绘画的风格模型常用它训练

边界与易混淆

LoRA 仍是微调的一种，不用于补充实时更新的知识。
