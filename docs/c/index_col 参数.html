index_col 参数

index_col · 指定索引列

读取时指定某列作为行索引的参数，可传单列名或列表。

解释

index_col 把文件中的某列设为 DataFrame 行索引，传列表则形成多级索引。索引是行标签，不是排序结果，两者不要混淆。

有什么用

  • 用业务字段作行标签
  • 构建多级索引便于分组查询

关键要点

  • 可传单列名或列名列表
  • 列表形式生成多级索引
  • 索引不是排序

边界与易混淆

索引与排序是不同概念；索引列默认不再作为普通数据列出现。

自测

点开看答案，先自己想一想

index_col=['姓名','入职日期'] 会产生什么结构？
以姓名和入职日期为层级的多级索引。

### 补充 · 2026-11-17

index_col='序号' 让该列在读取阶段就成为索引，不再作为普通数据列出现，等价于读入后再 set_index，但少一步且不产生多余列。

- 可传列名或列位置序号

- 设置后该列从数据列中消失，成为行索引

- 与 header=None + names 组合可一次读成目标结构

index_col 和读入后 set_index 有什么实质差别？
结果基本一致，index_col 在读取阶段完成，少一次操作且不会先产生一列冗余数据。
