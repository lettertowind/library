多字段排序

multi-column sort · sort_values 多列排序 · by 列表排序 · 多列排序

用 by 和 ascending 列表按优先级依次对多个字段排序。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：DataFrame.sort_values(by, ascending=True, inplace=False)

参数：

  • by：字段名列表，如 ['语文','数学']，列表顺序即排序优先级
  • ascending：布尔值或布尔列表；传列表时长度与 by 一一对应，False 为降序
  • inplace：默认 False 返回新表；设为 True 在原表上修改，返回 None

示例：

import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '赵六'],
    '语文': [90, 90, 85, 90],
    '数学': [70, 95, 88, 82],
})

res = df.sort_values(by=['语文', '数学'], ascending=[False, True])
print(res)
#    姓名  语文  数学
# 0  张三  90  70
# 3  赵六  90  82
# 1  李四  90  95
# 2  王五  85  88
# 数学列看似乱序，是因为它只在语文成绩相同的组内升序

解释

多字段排序仍是 sort_values 的用法，只是把 by 写成字段名列表、ascending 写成对应的布尔列表。它不是让每一列同时保持全局升序或降序，而是按列表顺序逐级比较：前一个字段决定主要顺序，后一个字段只在前一个字段取值相同的组内起作用。

有什么用

  • 按语文、数学、英语多个成绩字段依次排序
  • 需要先按大类再按小类排序的报表场景

关键要点

  • by 写成 ['字段1','字段2']，不能只写一个字符串，否则只是单字段排序
  • ascending 也必须是列表，长度与 by 一一对应，如 [False, True, False]
  • 排序优先级从左到右，后面的字段只在前一字段相同（或同一层级）时才影响结果
  • 结果中某列看似乱序是正常的，因为它受更高优先级字段约束
  • inplace 的作用与单字段排序完全一致

边界与易混淆

字段越多排序开销越大；若把 ascending 写成单个布尔值而非列表，会导致结果与预期不符。

自测

点开看答案，先自己想一想

按 by=['语文','数学']、ascending=[False,True] 排序后，数学列里出现了较小的值排在中间，是不是排序失败了？
不是。数学只在语文成绩相同的组内升序，整体顺序由语文降序主导。
如果 by 传了三个字段，ascending 只写 [False] 会发生什么？
长度不匹配会报错；ascending 必须与 by 中字段一一对应。
