条件变量化

条件赋值给变量 · 条件先定义

把筛选条件先赋值给变量再用于筛选的写法习惯。

目录
用法解释有什么用关键要点关联自测出处

用法

语法：条件 = 数据['列'] == '值' → 结果 = 数据[条件]（query 写法：q = '列 > 值' → 数据.query(q)） 参数：

  • 条件：自定义变量名，存放布尔 Series，命名建议体现业务含义（如 cond_male）
  • 数据['列'] == '值'：可换成 >、>=、<、isin([...]) 等任意布尔表达式
  • &、|、~：多条件组合，每个条件必须用括号包住
  • q：query 字符串变量，内部直接用列名，无需 数据['列'] 前缀

示例：

import pandas as pd

df = pd.DataFrame({'姓名': ['张三', '李四', '王五', '赵六'],
                   '性别': ['男', '女', '男', '女'],
                   '成绩': [88, 92, 75, 96]})

cond = df['性别'] == '男'        # 先写条件
cond2 = df['成绩'] >= 80         # 条件多时变量化优势明显
print(df[cond & cond2]['姓名'].tolist())
# ['张三']

q = '成绩 >= 90'                 # query 同样可先把字符串条件赋给变量
print(df.query(q)['姓名'].tolist())
# ['李四', '赵六']

解释

把布尔条件或 query 字符串先存到变量里，再传给数据做筛选，代码更整洁、易调试。条件变多时尤其重要，避免一行里堆叠大量表达式。

有什么用

  • 单条件筛选
  • 多条件筛选
  • 代码可读性维护

关键要点

  • 先写 条件 = 数据['性别'] == '男'
  • 再写 结果 = 数据[条件]
  • 条件多时变量化优势明显
  • query 同样可先把字符串条件赋给变量

关联

  • 布尔索引筛选组合使用
  • query 方法组合使用
