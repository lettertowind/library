雷达图

Radar Chart · 蜘蛛图 · spider chart

把多个维度画在极坐标射线上并用折线连接闭合的多变量对比图。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

雷达图每个维度对应一条从圆心出发的射线，在各射线上按取值取点后连成折线；要形成完整多边形，同样需要把第一个值补到末尾来闭合首尾。玫瑰图就是沿用这套极坐标思路，只是把折线换成柱形。

有什么用

  • 多维度能力/指标对比（如选手能力、产品评分）
  • 讲解极坐标绘图时的入门图形

关键要点

  • 各维度角度均分，首尾需补第一个值闭合
  • 维度过多会显得杂乱，一般控制在 5-8 个
  • 与玫瑰图区别：折线成面 vs 柱形成圈

边界与易混淆

多边形面积受维度顺序影响，不宜直接用面积比较优劣。

关联

  • 玫瑰图下位概念
  • 极坐标系（polar）组合使用
  • 首尾闭合（封口）前置知识

雷达图与玫瑰图在实现上的共同难点是什么？
两者都在极坐标上作图，都需要把第一个值补到末尾才能让图形首尾闭合。

### 补充 · 2026-11-17

雷达图把每个科目/维度铺在圆周上的一个角度，分数决定该方向的半径长度，连线后形成多边形，面积与形状直观反映对象的强弱结构。绘制需要先闭合数据、生成角度、极坐标绘图、填充、设标签五个步骤。

- 数据准备：分数与科目序列末尾都要追加首项做闭合

- 角度：np.linspace(0, 2π, len(科目), endpoint=False) 再闭合首角度

- 绘图：fig.add_subplot(111, polar=True) + ax.plot/ax.fill

为什么雷达图最多只放 3 个对象？
多个半透明多边形与线条叠加后颜色互相污染，轮廓难以分辨，失去对比价值。
两人的科目列表可以各用各的吗？
不可以，维度必须一致，科目列表取任意一个人的即可，顺序也要与分数一一对应。

雷达图本质就是极坐标上的多点连线：每个维度占一个极角，数值大小表现为极径，按顺序用线连起来即为多边形。要在 Matplotlib 中手绘，需要先在数组末尾重复首点的角度和极径让图形闭合。

- 维度数 = 极角数组长度 = 极径数组长度

- 用 '-' 把各点按数组顺序连线，形成多边形轮廓

- Matplotlib 不会自动闭合，必须在数组末尾重复首点的 θ 与 r

为什么 plt.polar(theta, r, 'o-') 画出来的多边形少了一条边？
Matplotlib 只按数组顺序连接相邻点，末点不会自动连回首点；需在 theta 和 r 数组末尾各追加首个点的值。
一个五维雷达图，theta 和 r 数组至少要几个元素？
要闭合就得 6 个：5 个维度点 + 重复的首点。
