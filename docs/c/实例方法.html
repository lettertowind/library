实例方法

method · 成员方法 · 实例方法

定义在类中、以 self 为第一个参数、作用于实例的函数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

实例方法让对象拥有行为，例如打开、关闭、运行微波炉。方法内部通过 self 读写该实例的数据。调用时用对象点号，如 smeg.turn_on()。

有什么用

  • 给对象增加行为
  • 封装对实例属性的操作和校验

关键要点

  • 第一个参数通常是 self
  • 调用时不需要手动传 self
  • 通过 self 访问实例属性
  • 可加入状态校验避免非法操作

边界与易混淆

实例方法与普通函数不同：它依赖实例数据；不要与类方法/静态方法混淆。

smeg.turn_on() 为什么不需要写成 smeg.turn_on(smeg)？
Python 调用实例方法时会自动把 smeg 作为 self 传入。
