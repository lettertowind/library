解释

DataFrame 的日常处理大量是「逐值、逐列、逐行」的重复运算，这三个方法分别对应整列逐值映射、按行或按列调用函数、整表逐单元格处理。掌握它们的选型规则，就能覆盖绝大多数行列级转换需求，配合 replace 完成值替换。

有什么用

  • 数据清洗、字段转换、特征计算时快速选方法
  • 判断某个需求该用哪一个方法而不是乱试

关键要点

  • map 只作用于 Series，做整列逐值映射
  • apply 作用于 Series 或 DataFrame，可按 axis 决定行/列方向，且能带额外参数
  • applymap 只作用于 DataFrame，逐单元格执行
  • 具体值替换需求交给 replace，不要用 map 硬套整表
  • 实际工作常用组合是 map + apply + replace

边界与易混淆

没有哪个方法能覆盖所有场景，选型依据是「操作对象是整列、整行、单个单元格还是具体值」。
