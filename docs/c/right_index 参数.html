right_index 参数

right_index · right_index=True · 索引连接

merge 中设为 True 时用右表索引作为连接键的参数，默认 False。

目录

解释

当右表已把姓名等设为索引时，不必先 reset_index 还原成列，直接 right_index=True 就能用左表的列去匹配右表索引。对大数据表尤其省事。

有什么用

  • 右表以业务主键为索引时直接连接
  • 避免对大表做索引还原操作

关键要点

  • 默认 False，需手工设为 True
  • 常与 left_on 搭配：左表列连右表索引
  • 对称地有 left_index=True，用左表索引做键
  • 连接方式仍由 how 控制，默认内连接

边界与易混淆

索引连接不要求键列同名；若两侧都用索引则同时设 left_index 和 right_index。

右表已用姓名做索引，左表姓名在普通列，如何内连接？
pd.merge(left, right, left_on='姓名', right_index=True)。

### 补充 · 2026-11-17

当右表的键恰好是它的行索引时，不必先把索引 reset 成普通列，直接 left_on='姓名', right_index=True 即可完成列对索引的连接。这在数据量大、改索引代价高时尤其方便。

- 默认值为 False，必须显式写成 True 才生效

- 与 left_on='列名' 搭配，表示左表列连右表索引

- 连接方式仍由 how 控制，默认为内连接

右表连接键在索引上，为什么不一定非要用 reset_index 转成列？
因为可以用 right_index=True 直接把右表索引当键连接，避免对大数据量重排索引的额外开销。
