拆分—应用—合并

split-apply-combine · 拆分应用合并 · 分组聚合范式

分组聚合的通用范式：按分组键拆分数据，对每组独立计算，再把结果合并成表。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

这是 groupby 背后的执行模型，理解了它就能预判任何分组聚合代码的输出形状：结果行数等于唯一分组键组合数，列数等于被聚合列数。它也是 Pandas、SQL GROUP BY、Excel 透视表三者共享的思维框架。

有什么用

  • 理解 groupby 的执行流程
  • 预判聚合结果的行列结构
  • 在 Pandas / SQL / 透视表之间迁移写法

关键要点

  • 拆分：按分组键把一张表切成若干子表
  • 应用：对每个子表独立计算聚合或变换函数
  • 合并：把各组结果按分组键重新拼成结果表
  • 输出行数 = 唯一分组键组合数，列数 = 聚合列数
  • 同一范式在 SQL 里是 GROUP BY，在 Excel 里近似透视表而非 SUMIF

边界与易混淆

只描述“分组后聚合”的路径；若需要把组内计算结果广播回原表，属于 transform/apply 的范畴。
