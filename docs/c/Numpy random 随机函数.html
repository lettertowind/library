解释

np.random 提供生成随机数、随机整数、随机抽样、打乱顺序等功能，常用于模拟数据、初始化参数和随机划分数据集。本节按“了解即可”处理，知道其用途即可。

有什么用

  • 生成模拟数据
  • 随机抽样与打乱数据
  • 机器学习参数初始化

关键要点

  • 属于 Numpy 的随机数子模块 np.random
  • 可生成随机数、随机整数、随机抽样、随机排列
  • 本节定位为“了解即可”，不要求深入掌握
  • 常配合随机种子保证结果可复现
