函数作为一等对象

first-class function · 函数式编程 · 函数作为参数传递

函数能像普通值一样被赋给变量、当参数传入、被返回，是 apply 存在的前提。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

Python 里函数本身就是对象，所以 len、np.square 或自定义的涨价函数都能直接当参数交给别的函数。apply 正是接收一个函数对象，再自动对每个元素、每行或每列调用它，因此 apply(涨价)、apply(len)、apply(np.square) 都成立。

有什么用

  • 理解 apply / agg / map 为什么能直接传函数名
  • 把清洗逻辑封装成函数重复复用

关键要点

  • 传函数名不带括号；带括号会先执行，把返回值传进去
  • 库函数要带前缀如 np.square，内置函数如 len 直接写
  • 自定义函数可用 def 或 lambda，两者对 apply 等价

边界与易混淆

误写成 apply(涨价()) 会先求值再传参，通常直接报错或结果错误

关联

  • apply前置知识
  • lambda 表达式组合使用

自测

apply(涨价) 与 apply(涨价()) 的区别是什么？
前者把函数对象交给 apply 逐个调用；后者先执行涨价()，传进去的是它的返回值。
