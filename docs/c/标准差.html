标准差

Standard Deviation · σ

方差的算术平方根，与原数据同单位，衡量数据离散程度。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

标准差是方差开平方的结果，单位与原始数据一致，因此比方差更直观地表示数据波动幅度。它是描述性统计中最常用的离散指标。

有什么用

  • 描述数据波动幅度
  • 配合均值做数据分布概览

关键要点

  • 标准差 = 方差的平方根（σ = √Var(X)）
  • 与原始数据同单位，解释性优于方差
  • 数值越大表示数据越分散
  • 易与方差说反，需核对公式

边界与易混淆

标准差对极端值敏感；不要与方差混淆，二者是平方与开平方的关系。

关联

  • 方差对比项

自测

点开看答案，先自己想一想

已知方差为 25，标准差是多少？
5（标准差 = √方差 = √25）
为什么实际报告中更常用标准差而不是方差？
标准差与原数据同单位，数值大小可直接对应数据波动幅度，解释更直观。

### 补充 · 2026-11-17

标准差把方差开方后回到原单位，更直观。Pandas 中 std() 计算，describe() 结果中的 std 行即标准差。

- 等于方差的平方根

- describe() 输出中的 std 行

- 与均值同量纲，便于解释

describe() 结果里 std 那一行代表什么？
该列数据的标准差，衡量数值围绕均值的波动大小。

标准差由方差开平方得到（σ=√Var(X)），把量纲还原成与原始数据一致，因此更直观地表示数据相对均值的典型偏离幅度。在 Numpy/Pandas 中调用 std() 得到的就是标准差，再平方即得方差。

- 标准差 = √方差；标准差平方即得方差（先有标准差，平方得到方差）

- 单位与原始数据一致，所以解释离散程度时比方差更直观

- 样本标准差 s = √s²，对应样本方差 s²

已算出方差为 25，标准差是多少？
5（对方差开平方）
向非技术同事说明数据波动时，为什么优先用标准差而不是方差？
标准差与原始数据同量纲，能直观对应「平均偏离均值多少」；方差的量纲是平方后的结果，不直观。
