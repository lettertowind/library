二元通用函数

binary ufunc · 双目通用函数

接收两个数组、对对应位置元素逐个运算的通用函数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

二元通用函数输入两个数组，按位置一一配对运算，返回同形状新数组。如 np.add 逐元素相加、np.maximum 逐元素取大、np.minimum 逐元素取小。它不把数组汇总成一个极值，而是对位比较。

有什么用

  • 两个数组逐元素相加或比较
  • 按位取两列数据的较大/较小值

关键要点

  • 输入两个数组，输出同形状数组
  • np.add 逐元素相加
  • np.maximum 逐元素取较大值
  • np.minimum 逐元素取较小值
  • 核心是「对位比较」，不是整体汇总

边界与易混淆

易误以为 np.maximum 返回整个数组的最大值；返回整体最大值的是 np.max。

关联

  • 通用函数上位概念
  • 一元通用函数对比项
  • np.max np.min对比项

自测

点开看答案，先自己想一想

np.maximum(x, y) 与 np.max(x) 有何不同？
np.maximum 对 x、y 对应位置逐元素取较大值，返回数组；np.max(x) 把 x 整体汇总成一个最大值标量。
x=[1,5]、y=[3,2]，np.minimum(x,y) 结果是什么？
[1, 2]，逐位置取较小值。
