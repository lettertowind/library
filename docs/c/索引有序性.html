索引有序性

索引单调性 · is_monotonic_increasing · 有序索引与无序索引

索引标签是否按升序单调排列的性质。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

它决定 MultiIndex 能否被 loc 稳定定位。有序索引可直接按层级查询；无序索引建议先用 sort_index(level=...) 排序再查。is_monotonic_increasing 可快速检查是否单调递增。

有什么用

  • 判断多层索引能否直接 loc 查询
  • 决定查询前是否要先按层级排序

关键要点

  • data.index.is_monotonic_increasing 返回 True 表示升序有序。
  • 有序索引可直接 loc 查询，无序索引可能报错。
  • 无序时推荐 sort_index(level=...) 先排序再查询。
  • 并非所有无序索引都会报错，排序后查询更安全。

边界与易混淆

有序性针对索引标签排列，不是数据值大小；sort_index 按索引排序，sort_values 按值排序。

自测

点开看答案，先自己想一想

为什么无序的 MultiIndex 建议先 sort_index(level=...) 再 loc 查询？
排序后该层索引单调，loc 能稳定定位；无序直接查可能报错或结果不符合预期。
is_monotonic_increasing 返回 False 一定意味着不能查询吗？
不一定，但说明索引非单调递增，直接 loc 有风险，排序后查询更安全。
