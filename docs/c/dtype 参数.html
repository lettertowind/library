dtype 参数

dtype · 数据类型参数 · 元素数据类型

创建数组时用于指定或查看元素数据类型的参数/属性，如 int32、float64。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

dtype 既可作为创建函数的参数（dtype=float、dtype=np.int32）指定元素类型，也可作为数组属性（a.dtype）查看当前类型。不指定时 NumPy 自动探测，整数可能得到 int32 或 int64。

有什么用

  • 控制数组元素是整数还是浮点、多少位
  • 查看已有数组的元素类型

关键要点

  • 作为参数：np.arange(1,8,dtype=float)
  • 作为属性：a.dtype 返回元素类型
  • 常见形式为类型名加位数：int32、int64、float32、float64
  • 不指定时自动探测，结果可能与预期不完全一致

边界与易混淆

dtype 描述元素类型，type(a) 描述对象类型（numpy.ndarray），两者不要混淆。

关联

  • np.array组合使用
  • shape 属性对比项

自测

点开看答案，先自己想一想

a.dtype 和 type(a) 分别返回什么？
a.dtype 返回元素数据类型（如 int64）；type(a) 返回对象类型 <class 'numpy.ndarray'>。

### 补充 · 2026-11-17

不写 dtype 时 NumPy 会根据输入内容自动推断元素类型，推断结果不一定符合预期，因此可以在 np.array、np.arange、np.ones 等创建函数里用 dtype= 明确指定。同一个名字也可以作为属性 a.dtype 用来查看已有数组的元素类型。

- 常见写法：dtype=float、dtype=np.float32、dtype=np.int32、dtype=np.int64

- dtype=float 在 NumPy 中最终落为 float64

- 不指定时自动推断，可能推断错，可手动覆盖

np.arange(1,8) 默认是整数还是浮点？想得到 float32 该怎么办？
默认是整数；要写 np.arange(1,8,dtype=np.float32)。
a.dtype 和 type(a) 分别返回什么？
a.dtype 返回元素类型如 int64；type(a) 返回整体类型 numpy.ndarray。
