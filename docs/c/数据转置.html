数据转置

Transpose · 行列转换 · .values.T

把 DataFrame 的行与列互换，行标签变列标签、列标签变行标签。

解释

转置用于把宽表变长表或调整数据朝向。Pandas 中推荐用 数据.values.T 取出 NumPy 矩阵转置，再用 pd.DataFrame 重新封装，并把 index 设为原 columns、columns 设为原 index，保证结构完全对应。

有什么用

  • 需要行列互换的报表整理
  • 把字段名变成行、把记录变成列的场景

关键要点

  • 核心是 .values.T 做矩阵转置
  • 转置后必须重设 index 与 columns，否则标签错位
  • index=原columns、columns=原index 是标准写法
  • 实现方法不唯一，记住一种稳定写法即可

边界与易混淆

只转置数值部分，原索引与列名需手动重新指定；不是简单的 df.T 一行了事。

关联

  • Numpy 二维数组前置知识
  • DataFrame组合使用

自测

点开看答案，先自己想一想

为什么转置后要写 index=数据.columns、columns=数据.index？
因为 .values.T 只转了数值，不转标签；不重设会导致行列标签与原表不对应。
