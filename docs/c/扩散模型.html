扩散模型

Diffusion Model · diffusion model

通过逐步去噪从随机噪点生成图像视频的模型。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

扩散模型是 AI 画图、做视频主要使用的模型。训练时先给清晰图片逐步加噪直到变成随机雪花，再让模型学习反向去噪恢复原图。生成时从纯噪点开始一步步去噪，文字描述在每一步引导去噪方向。

有什么用

  • 文生图、图生图
  • 文生视频、图生视频
  • 数字人生成

关键要点

  • 训练学加噪的反过程（去噪）
  • 生成从纯噪点开始逐步去噪
  • 文字提示在每一步引导方向
  • 与 Transformer 是不同技术路线

边界与易混淆

扩散模型擅长图像视频生成，语言生成主要用 Transformer 类模型。
