range 结束位置不含自身

range 左闭右开 · range(1 · n+1)

range 的结束参数不包含在序列内，取到 n 需写 n+1。

目录
解释有什么用关键要点关联自测出处

解释

range(1, n+1) 才能取到 1 到 n。省略起始位置默认从 0 开始。np.arange 遵循同样的左闭右开规则。

有什么用

  • 写循环边界
  • 生成 1 到 n 的序列

关键要点

  • 左闭右开：包含起始，不包含结束
  • 取 1 到 n 必须写 n+1
  • 省略起始默认从 0 开始
  • np.arange 同样适用此规则

关联

  • np.arange组合使用
  • 列表推导式组合使用
