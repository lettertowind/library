np.all

all · 全部为真

判断数组中是否所有元素都为 True，返回单个布尔值。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

np.all 对布尔数组做“与”归约：全部为 True 才返回 True，只要有一个 False 就返回 False。常用于校验“是否全部满足条件”。

有什么用

  • 校验是否所有元素都满足条件
  • 配合条件表达式做全称检查

关键要点

  • 全部 True 才为 True
  • 任一 False 即为 False
  • 可传 axis 按轴归约
  • 与 np.any 互为对偶

边界与易混淆

空数组上 np.all 返回 True，容易反直觉。

关联

  • np.any对比项
  • 布尔数组前置知识
