正则表达式

regex · 正则 · Regular Expression

用特定语法描述字符串模式、用于匹配/提取/替换的文本处理工具。

解释

正则表达式通过元字符（\d、{2}、括号分组等）描述文本模式，广泛用于匹配、提取和替换。Pandas 的 match/extract/replace 都建立在正则之上，不掌握正则则文本处理能力受限。

有什么用

  • 文本模式匹配与筛选
  • 分组提取字段
  • 复杂格式替换

关键要点

  • \d 表示数字，{n} 表示重复次数
  • 括号表示捕获组
  • 反向引用 \1、\2 引用捕获组
  • Python、VBA、Excel 中均可用

边界与易混淆

Pandas 课程只讲如何在字符串方法中使用正则，不系统讲正则本身，需先学 Python 正则基础。

关联

  • str.match上位概念
  • str.extract上位概念
  • str.replace 正则替换上位概念

自测

点开看答案，先自己想一想

正则中 (\d{4}) 的括号作用是什么？
表示捕获组，extract 时只提取括号内内容，replace 时可用 \1 反向引用。
为什么说不学正则 Pandas 文本处理会受限？
match/extract/replace 的复杂用法都依赖正则模式与捕获组。

### 补充 · 2026-11-17

正则表达式通过字符类、范围、量词等语法描述一类字符串，如 [A-Z] 表示任意大写字母、[A-G] 表示 A 到 G 范围。在 pandas 替换中配合 regex=True 可大幅简化范围匹配和模式匹配类替换。

- [A-Z] 匹配任意大写字母，[A-G] 匹配 A 到 G 范围

- [A-Za-z] 同时匹配大小写字母

- 正则要写在引号内作为字符串传入

要匹配任意一个大写字母或小写字母，正则字符类怎么写？
[A-Za-z]
