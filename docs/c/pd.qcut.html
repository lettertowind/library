pd.qcut

qcut · 等频分箱 · 分位数分箱

按分位数把一维数据分箱，使各箱数据量尽量相等。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：pd.qcut(x, q, labels=None, retbins=False, precision=3, duplicates='raise')

参数：

  • x：要分箱的一维数据（Series 或数组）
  • q：整数表示箱数（如 q=2），或分位数数组（如 [0, 0.5, 1]）
  • labels：各箱名称列表，长度需与箱数一致；设为 False 时返回整数箱号
  • retbins：为 True 时额外返回各箱边界数组
  • precision：箱边界保留的小数位数
  • duplicates：边界重复时的处理，'raise' 报错、'drop' 去重

示例：

import pandas as pd

s = pd.Series([10, 20, 30, 40, 50, 60])
print(pd.qcut(s, q=3, labels=False).tolist())
# [0, 0, 1, 1, 2, 2]

bins = pd.qcut(s, q=3, retbins=True)[1]
print(bins.round(1))
# [10.  26.7 43.3 60. ]

解释

qcut 不需要手动指定分界点，只需给出箱数 q，按数据分布的分位数切分。适合希望每个箱子样本量均衡的场景。

有什么用

  • 用户分层使各组人数均衡
  • 建模前按分位数离散化

关键要点

  • q 可为整数箱数，也可为分位数数组
  • q=2 表示分成两个箱子，各箱数量尽量相同
  • 数据量不能被箱数整除时，各箱数量可能略有差异
  • 使用前应先知道数据总量再决定箱数

边界与易混淆

qcut 是等频分箱，不是等宽分箱；等宽指区间宽度相同，二者易混淆。

qcut 与 cut 的核心区别是什么？
cut 按指定分界点（值区间）分箱，qcut 按分位数分箱使各箱数据量尽量相等。
为什么 qcut 分箱后各箱数量可能不完全一致？
当数据总量不能被箱数整除时，按分位数切分会产生轻微数量差异。

### 补充 · 2026-11-17

等频分箱按数据分位数切分，保证各箱样本量均衡，与按区间宽度切分的等宽分箱相对。qcut 实现的就是等频分箱。

- 等频 = 每箱数量相同；等宽 = 每箱区间宽度相同

- qcut 属于等频分箱

- 数据量不能被箱数整除时各箱数量略有差异

等频分箱与等宽分箱的区别是什么？
等频分箱保证每箱数据量相同，等宽分箱保证每箱区间宽度相同。

qcut 不需要给分界点，只要告诉它分成几个箱子（q 参数），它会按数据分布切分，让每个箱子里的样本数量相同或尽量相同。适合按样本量均分的场景，如用户分层、数据等分。结果同样可用 value_counts 查看各箱数量。

- 关键参数 q 指定箱子数量，而不是分界点

- 每箱数据条数相同或尽量相同，故称等频分箱

- 使用前应先知道数据总条数，再决定分几箱

1000 条用户数据用 q=4 分箱，每箱大约多少条？若要按「高价值用户」的消费额阈值分组，该用哪个函数？
每箱约 250 条；按阈值分组应用 cut 并给定分界点。
