pd.qcut

qcut · 等频分箱 · 分位数分箱

按分位数把一维数据分箱，使各箱数据量尽量相等。

解释

qcut 不需要手动指定分界点，只需给出箱数 q，按数据分布的分位数切分。适合希望每个箱子样本量均衡的场景。

有什么用

  • 用户分层使各组人数均衡
  • 建模前按分位数离散化

关键要点

  • q 可为整数箱数，也可为分位数数组
  • q=2 表示分成两个箱子，各箱数量尽量相同
  • 数据量不能被箱数整除时，各箱数量可能略有差异
  • 使用前应先知道数据总量再决定箱数

边界与易混淆

qcut 是等频分箱，不是等宽分箱；等宽指区间宽度相同，二者易混淆。

点开看答案，先自己想一想

qcut 与 cut 的核心区别是什么？
cut 按指定分界点（值区间）分箱，qcut 按分位数分箱使各箱数据量尽量相等。
为什么 qcut 分箱后各箱数量可能不完全一致？
当数据总量不能被箱数整除时，按分位数切分会产生轻微数量差异。

### 补充 · 2026-11-17

等频分箱按数据分位数切分，保证各箱样本量均衡，与按区间宽度切分的等宽分箱相对。qcut 实现的就是等频分箱。

- 等频 = 每箱数量相同；等宽 = 每箱区间宽度相同

- qcut 属于等频分箱

- 数据量不能被箱数整除时各箱数量略有差异

等频分箱与等宽分箱的区别是什么？
等频分箱保证每箱数据量相同，等宽分箱保证每箱区间宽度相同。
