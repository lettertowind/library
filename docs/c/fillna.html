fillna

df.fillna · 空值填充

将 DataFrame 中的缺失值替换为指定值的方法。

目录

解释

fillna(value) 扫描所有 NaN 位置并填入给定值，非空值保持不变。它是数据清洗中最常用的缺失值处理手段之一，可填 0、均值或指定常量。

有什么用

  • 清洗含缺失值的数据
  • 为后续计算补齐空值

关键要点

  • 只填充 NaN，不改动非空值
  • 可填任意常量，如 0、1、均值
  • 默认返回新对象，不修改原表
  • 常与 isnull 配合先检查再填充

边界与易混淆

填充值选择不当会引入偏差；需要原地修改时要加 inplace=True。

自测

点开看答案，先自己想一想

df.fillna(0) 会把非空值也改成 0 吗？
不会，只填充 NaN 位置，非空值保持不变。
填充缺失值前为什么要先用 isnull 检查？
先确认缺失分布和比例，才能决定填什么值、是否值得填。

### 补充 · 2026-11-17

fillna() 支持三种主要填充方式：传常量统一填充、传字典按列填充不同值、用 method 参数以前值或后值填充。配合 axis 可改变填充方向，limit 限制填充数量。

- 传常量：所有空值填同一个值

- 传字典：按列指定不同填充值

- method='ffill'/'pad' 用前值，'bfill'/'backfill' 用后值

不同列要填不同值，fillna 怎么传参？
传字典，如 df.fillna({'语文':0.1,'数学':0.2})。
fillna(method='bfill') 和 ffill 有什么区别？
bfill 用后面的有效值向上填充，ffill 用前面的有效值向下填充。
