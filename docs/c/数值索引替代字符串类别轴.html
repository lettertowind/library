数值索引替代字符串类别轴

plt.xticks 替换刻度标签 · xticks · 类别轴数值化

x 轴先用 0、1、2 等数值坐标绘图，再用 plt.xticks 换成类别名称。

解释

直接用 'a'、'b'、'c' 当 x 坐标时，无法对坐标做加减运算，注释文字的位置只能靠 y 方向调整。改成数值索引后，横坐标可以自由微调（如 1 改成 1.1），画完再把刻度文字替换成“张三、李四”等真实类别名，兼顾可读性与可控性。

有什么用

  • 需要精确偏移文本或图形元素时
  • 类别名称较长、想后置统一替换刻度文字时

关键要点

  • 用 np.arange(3) 生成数值索引作为 x 坐标
  • plt.xticks(x, ['a','b','c']) 把数值刻度换成类别名
  • 数值坐标支持加减乘除，文本位置可精细微调
  • 后期替换标签比一开始就写死类别字符串更灵活

边界与易混淆

Matplotlib 本身能把字符串类别自动映射为 0、1、2，所以只画图没问题；痛点仅在于需要数值级微调时。

为什么把 x 轴改成数值索引后，注释文字更好调位置？
数值坐标可以做加减运算（如 1 改为 1.1），而字符串类别 'b' 无法直接加偏移量。

### 补充 · 2026-11-17

Matplotlib 的 x 轴本质是数值轴，直接用姓名这类字符串无法定位柱子。所以先用 np.arange(len(data)) 造出等距坐标，画完再把这些坐标的刻度文字换成姓名，视觉上就成了类别轴。

- plt.xticks(x, data['姓名']) 两个参数：刻度位置 + 刻度文字

- 不设置时 x 轴只显示 0,1,2… 数字，看不出是哪个学生

- 坐标可直接用 NumPy 数组或 Pandas Series，不必先转成 Python 列表

为什么柱形图的 x 轴不能直接传姓名列表？
x 轴是数值轴，位置需要数值坐标，所以要先生成下标再用 plt.xticks 把刻度文字换成姓名

### 补充 · 2026-11-17

画图时先用 0,1,2… 数字位置作 x 轴，最后再用 plt.xticks 统一替换成业务标签的做法。

- 位置列表用 np.arange(len(列)) 生成，与数据行一一对应

- plt.xticks(位置列表, 标签列表) 两个参数长度必须一致

- rotation=45 让长标签倾斜，避免文字重叠

- 标签含时间时先用 pd.to_datetime().dt.strftime('%Y-%m-%d') 去掉 00:00

- 标签列表可以是 Series，不必先转成 list
