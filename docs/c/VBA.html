VBA

Visual Basic for Applications · Excel 宏

Excel 内置的宏编程语言，用于自动化 Excel 操作。

解释

VBA 是 Excel 原生工具，能直接操作单元格格式、颜色、合并单元格等对象模型。视频观点是：简单批量读写用 pandas 更短，复杂格式操作 VBA 更方便。

有什么用

  • 设置单元格格式和颜色
  • 处理合并单元格等复杂结构
  • Excel 内部自动化

关键要点

  • Excel 原生，格式与样式控制强
  • 简单批量读写不如 pandas 简洁
  • 与 pandas 是场景互补而非替代
  • 原则：专业工具做专业的事

边界与易混淆

跨 Excel 与 PDF 等文件协同处理时不如 pandas 灵活；维护成本较高。

关联

  • Pandas Excel 合并拆分对比项
