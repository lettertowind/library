答案沉淀

知识回流 · 答案存回知识库

把 AI 问答产生的优质结论存回知识库并建立关联的机制。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

每次调用知识库回答问题后，AI 会把问题、结论和内容生成 Markdown 文档存入“分析”文件夹，并自动与相关知识建立联系。这样调用本身也在生产新知识，是知识库自生长的关键。

有什么用

  • 把问答结论转为可复用知识
  • 让知识库随使用增长

关键要点

  • 问答结果自动存为 Markdown
  • 存入分析文件夹
  • 自动与相关知识建立关联
  • 调用即生产，形成自生长

边界与易混淆

只有优质结论值得沉淀；低质量回答回流会污染知识库。

为什么说答案沉淀让知识库“自生长”？
因为每次调用产生的结论都会回流为新知识并建立关联，知识库在使用中不断增厚，而非只靠外部素材输入。
