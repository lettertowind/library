np.where

where · 条件替换函数

按条件从两个候选值中逐元素选取，返回同形状新数组。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：np.where(condition, x, y)

参数：

  • condition：布尔数组（或可广播为布尔值的表达式，如 a > 3），作为逐元素判断的条件
  • x：条件为 True 时取的候选值，可以是标量，也可以是数组（可广播）
  • y：条件为 False 时取的候选值，可以是标量，也可以是数组（可广播）

示例：

import numpy as np

a = np.array([[1, 3, 6],
              [9, 4, 2],
              [3, 8, 5]])

# 条件为真取 520，为假取 1314
print(np.where(a > 3, 520, 1314))
# [[1314 1314  520]
#  [ 520  520 1314]
#  [1314  520  520]]

# 返回新数组，原数组不变
print(a)
# [[1 3 6]
#  [9 4 2]
#  [3 8 5]]

解释

np.where(condition, x, y) 等价于向量化的 if-else：条件为真取 x，为假取 y。它不修改原数组，而是返回新数组，适合批量条件替换。

有什么用

  • 按条件批量替换数组元素
  • 把布尔条件转成两档取值

关键要点

  • 语法为 np.where(条件, 真值, 假值)
  • 返回新数组，原数组不变
  • 条件通常是布尔数组，如 a > 3
  • 与布尔赋值不同，它是取值而非就地修改

边界与易混淆

只支持两分支；多分支需嵌套 where 或改用 np.select。

关联
