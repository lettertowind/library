多表头

MultiIndex 表头 · 多级列索引 · 多行表头

表的前连续多行共同充当列名，读取后形成多级列索引的表结构。

解释

Excel 报表常把大类放一行、子类放另一行，形成两行表头。pandas 默认只把第 0 行当列名，第二行会变成一条数据，导致列名错乱。用 header 指定多行后，列名会被组织成 MultiIndex。

有什么用

  • 读取带上下级分类的两行表头报表
  • 读取带单位行或合并单元格标题的 Excel

关键要点

  • pandas 中第一行是第 0 行，默认表头就是第 0 行
  • 几行表头就把 header 设到几，如 header=[0, 1]
  • 不设 header，第二行表头会混进数据行，列名错乱
  • 多表头取列需按层级索引，必要时先拍平层级

边界与易混淆

多表头只解决“列名怎么读”，不解决合并单元格造成的缺失值问题，那属于预处理范畴。
