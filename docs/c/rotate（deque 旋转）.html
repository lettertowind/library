rotate（deque 旋转）

rotate · 旋转队列 · 循环位移

把 deque 中所有元素整体循环移动 n 位，移出端的元素从另一端补回。

解释

rotate(n) 对队列做首尾相接的轮转：正数向右（顺时针）旋转，负数向左（逆时针）旋转。它是原地操作，只改变元素顺序，不改变长度。常用于轮转调度、循环队列和重复轮流处理等场景。

有什么用

  • 轮流调度任务或玩家顺序
  • 实现循环缓冲区、密码学移位类演示

关键要点

  • 正数向右旋转，末尾元素移到队首；负数向左旋转，队首元素移到队尾
  • rotate(2) 与 rotate(-2) 方向相反，旋转量大于长度时按取模循环
  • 原地修改，返回 None，不要写成 d = d.rotate(1)

边界与易混淆

rotate 只做顺序轮转，不做排序；对空队列或 rotate(0) 无效果。
