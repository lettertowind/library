神奇索引

Fancy Indexing · 花式索引 · 整数数组索引

用整数数组而非单个整数或切片来选取数组元素。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

神奇索引把一组下标放进数组里，一次性取出多个任意位置的元素。它不要求下标连续，适合从数组中“点菜式”抽取数据，返回结果的形状由索引数组决定。

有什么用

  • 从数组中按任意下标批量取数
  • 配合 argsort 取出排序后前 n 个元素的原值

关键要点

  • 索引对象是整数数组，不是单个整数或连续切片
  • 一维数组 a[[2,3,5]] 取出下标 2、3、5 的元素
  • 二维只给一个索引数组时默认按行取整行
  • 二维给两个索引数组时行列按位置一一配对，不是笛卡尔积
  • 返回结果形状与索引数组形状一致

边界与易混淆

与切片不同，神奇索引不能表达连续区间；二维双索引数组是配对取点，不是取子矩阵。

关联

自测

点开看答案，先自己想一想

a = np.array([3,6,7,9,5,2,7])，a[[2,3,5]] 返回什么？
[7, 9, 2]
二维数组 c[[1,5,7,2],[0,3,1,2]] 取的是哪几个元素？是笛卡尔积吗？
取 (1,0)、(5,3)、(7,1)、(2,2) 四个元素，按位置配对，不是笛卡尔积。
