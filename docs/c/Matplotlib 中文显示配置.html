Matplotlib 中文显示配置

中文字体 · font.sans-serif · 中文乱码、中文报错

配置中文字体后才能在图表的标题、标签、注释中正常显示汉字。

解释

Matplotlib 默认字体不含中文字形，直接写中文会出现方框、乱码或报错。解决办法是在绘图前指定一个系统中存在的中文字体（常见做法是设置 sans-serif 字体列表并关闭负号特殊字符）。课程本节为不打断节奏，先用英文缩写 'sxh' 代替中文。

有什么用

  • 图表标题、坐标轴标签、注释文字使用中文时
  • 交付给中文读者看的分析报告图

关键要点

  • 默认字体不含中文，中文文本会显示方框或直接报错
  • 字体设置应放在绘图前，全局生效
  • 除字体外还要处理坐标轴负号的显示问题
  • 临时绕过办法：注释先用英文或拼音缩写

边界与易混淆

本节只提到问题未展开具体配置，字体名还依赖操作系统已安装的字体，跨平台代码不一定通用。
