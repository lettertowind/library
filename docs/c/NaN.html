NaN

Not a Number · 缺失值

Pandas 中表示缺失值或非数字值的特殊标记。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

NaN 是 Not a Number 的缩写，在数据分析中常作为缺失值处理。Pandas 读取数据时，空单元格常被识别为 NaN，可用 isnull() 检测。

有什么用

  • 表示缺失数据
  • 配合 isnull()/notnull() 检测空值

关键要点

  • NaN 表示 Not a Number，即非数字
  • 在数据分析中常作为缺失值
  • 可用 isnull() 判断是否为 NaN

边界与易混淆

NaN 是浮点类型，与 None 不同；比较时不能用 == 判断。

关联

  • isnull组合使用
  • notnull组合使用
