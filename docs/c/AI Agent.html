AI Agent

智能体 · Agent

能读取规则、操作文件并多步执行任务的 AI 程序。

解释

AI Agent 不只是对话，它能选定工作空间、读写文件、按规则完成摄入、整理、体检等连续操作。在本系统中它扮演“图书馆管理员”，把规则落到实际文件操作上。

有什么用

  • 自动整理知识库
  • 批量处理本地文档
  • 执行定时任务

关键要点

  • 能操作工作空间内的文件
  • 按规则文件多步执行任务
  • 可配置模型与定时任务
  • 工作空间选择比模型选择更关键

边界与易混淆

Agent 只能操作其工作空间内的文件；未选中知识库文件夹时无法按规则处理。

为什么说工作空间选择比模型选择更关键？
因为 Agent 只能操作工作空间内的文件，选错文件夹就无法读写知识库，规则再强也无从执行；模型只影响处理质量。

### 补充 · 2026-11-17

Agent 的核心是一个循环：思考下一步、调用工具执行、观察结果、再决定下一步，直到完成任务。与聊天的一问一答不同，你给它目标，它自己决定步骤。

- 核心循环：思考→调用工具→观察结果→再决策

- 步骤由模型自己定，工作流由人定

- 公式：Agent = 模型 + Harness

Agent 和工作流最本质的区别是什么？
工作流步骤由人预先规定，Agent 的步骤由模型自己决定。
