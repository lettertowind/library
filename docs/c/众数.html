众数

mode · 出现次数最多的数

一组数据中出现次数最多的数值。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

众数体现“多数人的选择”，适合分类偏好类问题，如统计全班喜欢的水果并按众数采购。它不能由平均数或中位数替代。

有什么用

  • 统计最受欢迎的选项
  • 分类数据的集中趋势

关键要点

  • 出现次数最多的值即为众数
  • 可能不唯一，也可能不存在
  • 适合偏好、投票类场景

边界与易混淆

连续型数据直接求众数意义不大，通常先分箱。

### 补充 · 2026-11-17

众数适用于分类数据或离散数值，反映最常见的取值。Pandas 中用 mode() 获取，可能返回多个值。

- Pandas 用 mode() 计算

- 可能有多个众数

- 对分类数据也适用

一组数据 [1,2,2,3,3,4] 的众数是什么？
2 和 3，都出现两次，属于多众数。

众数用于描述出现频率最高的取值，特别适合分类数据和投票式问题——这类数据既不能求平均，也不适合求中位数。NumPy 没有现成的众数函数，Pandas 的 mode() 一行就能算。

- 统计对象是出现次数，不是数值大小

- 分类数据优先用众数，而不是平均数或中位数

- NumPy 无直接函数：只能 bincount + argmax 凑，且限非负整数一维

班级调查大家爱吃什么水果，该用哪个统计量？
众数——答案是最多人选的那一项，求平均或中位数都没有意义。
为什么讲师建议众数交给 Pandas 而不是 NumPy？
NumPy 无现成函数，bincount 组合只适用非负整数一维；Pandas 一行 mode() 即可支持一维和二维。
