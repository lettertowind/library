子区域（画中画）

inset axes · 画中画 · 嵌套子图 · 子区域

在一个已有坐标轴内部再嵌入一个小坐标轴，形成图中套图。

目录

解释

子区域本质是另一个 Axes，可独立绘图、设置标题，常用于主图旁补充局部细节或展示不同图表。它的位置和大小由相对画布的矩形四元组决定。

有什么用

  • 主图内嵌小折线图或饼图
  • 局部放大或补充辅助指标

关键要点

  • 子区域不是图内元素（如平均线），而是独立 Axes。
  • 常用 fig.add_axes([left, bottom, width, height]) 创建。
  • 四元组是相对画布的 0–1 比例坐标。
  • 先确定外部大图，再确定内部小图，避免报错。

边界与易混淆

与子图不同，子区域不占网格、可以重叠；位置参数需按视觉效果反复微调。

关联

  • fig.add_axes（按矩形添加轴）组合使用
  • 子图（subplot）对比项
  • figure 与 axes（画布与子图）上位概念
  • 面向对象绘图接口（Axes 方法）组合使用

子区域用什么函数创建？四个参数分别是什么含义？
fig.add_axes([left, bottom, width, height])，分别是左、下、宽、高，均为相对画布的比例。
为什么子区域需要另一个 Axes？
因为它是一个独立绘图区域，有自己的坐标轴和绘图方法，并不是主图里的一个普通元素。
