unique

np.unique · 取唯一值

返回数组中的唯一值，通常为数组形式。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

np.unique 对一列数据取出所有不重复的值，只返回该列本身，不保留其他字段。它适合快速看有哪些取值，但去重后想保留完整行信息时不如 Pandas 的 drop_duplicates 方便。

有什么用

  • 快速查看某列有哪些不同取值
  • 统计前先了解字段取值集合

关键要点

  • 返回结果是数组或列表形式
  • 只返回该列唯一值，不保留其他字段
  • 与 drop_duplicates 相比丢失行上下文

边界与易混淆

需要去重后保留完整字段（如分数、班级）时应改用 drop_duplicates，而不是 unique。

为什么分析中取唯一姓名时更常用 drop_duplicates 而不是 np.unique？
np.unique 只返回姓名本身，丢失分数等其他字段；drop_duplicates 去重后保留完整行信息。

### 补充 · 2026-11-17

np.unique 对数组去重，输出每个值只出现一次的新数组。默认会排序，因此结果顺序不是首次出现顺序。

- 默认对唯一值排序

- 对字符串数组同样适用

- 类似 Power BI 的去重建新表

np.unique 的结果默认是原始出现顺序吗？
不是，默认会排序。
