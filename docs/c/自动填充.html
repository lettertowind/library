自动填充

AutoFill · 数据填充 · 序列填充

按规律批量生成并填入缺失数据的操作，如序号递增、文本循环、日期递增。

目录
用法解释有什么用关键要点边界与易混淆关联自测出处

用法

语法：df.at[i, '列名'] = 表达式（在 for i in df.index: 循环内逐行赋值） 参数：

  • i：来自 df.index 的行标签，循环变量；规律都写成它的表达式
  • '列名'：要填充的目标列，需先用 df['列名'] = '' 建好空列
  • 表达式：i+1（序号递增）、i%2（奇偶循环）、start + pd.Timedelta(days=i)（日期递增）

示例：

import pandas as pd

df = pd.DataFrame({'姓名': ['张三', '李四', '王五', '赵六']})
df['序号'] = ''
df['性别'] = ''
df['日期'] = ''
df['日期'] = df['日期'].astype(str)   # 先统一为 str，避免类型报错

start = pd.Timestamp('2024-01-01')
for i in df.index:
    df.at[i, '序号'] = str(i + 1)                     # 序号递增：1,2,3,4
    df.at[i, '性别'] = '男' if i % 2 == 0 else '女'    # 奇偶循环填充
    df.at[i, '日期'] = str(start + pd.Timedelta(days=i))  # 按天递增

print(df)
#    姓名 序号 性别         日期
# 0  张三  1  男  2024-01-01
# 1  李四  2  女  2024-01-02
# 2  王五  3  男  2024-01-03
# 3  赵六  4  女  2024-01-04

解释

自动填充是把 Excel 中下拉拖拽生成序列的直觉操作，用代码在整列上按行索引规律批量赋值。它解决的是手工逐格填写效率低、易出错的问题，核心是找到行索引与目标值之间的数学关系。

有什么用

  • 批量生成序号列
  • 按奇偶循环填充性别等分类值
  • 按天/月/年递增填充日期列

关键要点

  • 填充前先把相关列统一设为 str，避免类型报错
  • 用 for i in data.index 遍历，用 at[i] 按位置赋值
  • 规律要能写成 i 的表达式，如 i+1、i%2、timedelta(days=i)
  • set_index 必须放在循环之后，否则循环变量会变成序号值

边界与易混淆

小规模 Excel 办公自动化用 VBA、Power Query 更简单；pandas 自动填充更适合大数据 CSV/TXT。

关联

  • .at 索引器组合使用
  • set_index组合使用
  • Timedelta组合使用

自测

点开看答案，先自己想一想

为什么自动填充前要把序号、性别、日期列都设成字符串类型？
避免数值型与文本/日期混填时出现浮点显示或类型报错，保证后续判断和赋值稳定。
如果先把序号列 set_index 再进 for 循环，会发生什么？
循环变量 i 变成序号列的值而非 0,1,2…，i+1、i%2 等规律全部错位甚至报错。

### 补充 · 2026-11-17

读取文件后，对空的序号、性别、日期列用 for 循环配合 .at 逐格赋值，把 Excel「下拉填充」的逻辑用代码表达。读取函数换成 read_csv 或 read_excel、写回换成 to_csv 或 to_excel 即可，填充主体逻辑不变。

- 核心是 for 循环 + .at 定位单元格逐格写入

- Excel 与 CSV 只换读写函数，填充逻辑完全复用

- 性别类规律列用 i % 2 配合条件表达式生成

把同一个填充脚本从处理 xlsx 改成处理 csv，哪些部分必须改、哪些不用改？
只需把 read_excel 改成 read_csv、to_excel 改成 to_csv（可能补 sep 参数），循环填充部分不用改。
