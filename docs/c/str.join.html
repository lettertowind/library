str.join

join · 字符连接

用指定字符连接字符串中每个字符的方法。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

str.join(sep) 在字符串的每个字符之间插入指定内容，像用胶水把字符粘起来。与 str.cat 不同，它作用于单个字符串内部的字符之间。

有什么用

  • 给字符之间插入分隔符
  • 格式化输出字符串

关键要点

  • 作用于字符串内部每个字符之间
  • 参数是连接符
  • 与 str.cat 的拼接对象不同

边界与易混淆

易与 str.cat 混淆：cat 拼接多个字符串，join 连接单个字符串内部的字符。

关联

自测

点开看答案，先自己想一想

str.join('a') 对“满血激活”的结果是什么？
“满a血a激a活”，每个字符之间插入 a。
str.join 和 str.cat 的核心区别是什么？
join 连接单个字符串内部的字符，cat 拼接多个字符串或序列。
