温度

temperature · 采样温度

控制模型选词随机程度的参数，温度低更稳定、温度高更多样。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

温度是挑选下一个 Token 时可调整的设置。温度低时模型几乎总选概率最高的字，回答稳定保守；温度高时更多选择概率较低的字，回答更有变化也更容易出错。

有什么用

  • 写代码、查资料时调低温度
  • 写故事、想创意时调高温度

关键要点

  • 低温适合需要准确和一致性的任务
  • 高温适合需要多样性和创意的任务
  • 高温会增加出错概率

边界与易混淆

温度只影响采样随机性，不改变模型本身的知识和能力。

关联

  • 大语言模型上位概念
  • Token前置知识

为什么写代码时建议用低温？
低温让模型倾向选择概率最高、最确定的 Token，输出更稳定、更少随意发挥。
