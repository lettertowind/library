set（集合）

set · set() · 集合类型 · 去重

无序、不重复元素的容器，可从任意可迭代对象构造。

目录

解释

set() 建空集合，set(可迭代对象) 把其元素去重后装入。成员判断是哈希实现的，比列表快得多，因此常用于去重和存在性检查。

有什么用

  • 列表去重
  • 快速判断元素是否存在
  • 集合运算（交并差）

关键要点

  • {} 是空字典，空集合必须写 set()
  • 元素唯一，重复自动去掉
  • 元素必须可哈希，列表不能放进去

边界与易混淆

无序，不能靠下标取值；需要保序去重时可用 dict.fromkeys。
