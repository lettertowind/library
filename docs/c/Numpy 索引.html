Numpy 索引

Indexing · 下标

用下标从数组中取出单个元素或整行/整列的操作。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

索引是 Numpy 最基础的取值方式，一维用 a[i]，二维用 A[行, 列]。索引从 0 开始，负索引从末尾倒数。只写一个索引时二维数组取整行。

有什么用

  • 从数组中定位单个元素
  • 取出整行或整列数据

关键要点

  • 索引从 0 开始计数，-1 表示最后一个
  • 二维索引格式为 A[行索引, 列索引]，先行后列
  • 二维只写一个索引 A[2] 取整行
  • A[:, 2] 用冒号取所有行、单列，结果为一维数组

边界与易混淆

索引取单个值或整行/整列；取连续多个值要用切片，两者常被混为一谈。

关联

  • Numpy 切片对比项
  • Numpy 二维数组上位概念

自测

点开看答案，先自己想一想

二维数组 A 有 4 行 5 列，A[-1, 2] 取的是哪个元素？
最后一行、列索引 2 的元素，即第 3 行第 2 列的值 17。
A[:, 2] 和 A[2] 的结果形状有什么区别？
A[:, 2] 取所有行的第 2 列，结果是一维数组；A[2] 取第 2 行整行，结果是一维数组（该行所有列）。

### 补充 · 2026-11-17

同一件事在不同教材里叫法不同：Python 基础书多称“下标”，数据分析类书多称“索引”，两者完全等价。索引从 0 开始计数，是切片、条件筛选、双索引等所有取数操作的基础。

- “下标”与“索引”是同一概念的不同叫法

- 下标从 0 开始，第 1 个元素的下标是 0

- 索引是切片与条件筛选的基础

教材里说“下标”和“索引”，指的是同一个东西吗？
是。Python 类教材多叫下标，数据分析类书籍多叫索引，含义完全相同。

- 出处：孙兴华中文讲Python数据分析三部曲入门篇 Numpy教程 Pandas教程 Matplotlib教程 p05 S01E04.多维数组 · 2026-11-17

NumPy 索引从 0 开始计数，一维数组写作 a[i]，二维数组写作 A[行, 列]。它用于精确定位一个值，区别于一次取多个值的切片。

- 下标从 0 开始，不是从 1 开始

- 一维索引格式为 a[i]

- 二维索引格式为 A[行索引, 列索引]

一维数组 a 中元素 5 的索引是 5 还是 4？
索引是 5，因为下标从 0 开始，a[5] 取到第 6 个元素 5。
二维数组 A 中 A[2] 取到的是什么？
取行索引为 2 的整行所有列。
