Numpy 索引

Indexing · 下标

用下标从数组中取出单个元素或整行/整列的操作。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

索引是 Numpy 最基础的取值方式，一维用 a[i]，二维用 A[行, 列]。索引从 0 开始，负索引从末尾倒数。只写一个索引时二维数组取整行。

有什么用

  • 从数组中定位单个元素
  • 取出整行或整列数据

关键要点

  • 索引从 0 开始计数，-1 表示最后一个
  • 二维索引格式为 A[行索引, 列索引]，先行后列
  • 二维只写一个索引 A[2] 取整行
  • A[:, 2] 用冒号取所有行、单列，结果为一维数组

边界与易混淆

索引取单个值或整行/整列；取连续多个值要用切片，两者常被混为一谈。

关联

  • Numpy 切片对比项
  • Numpy 二维数组上位概念

自测

点开看答案，先自己想一想

二维数组 A 有 4 行 5 列，A[-1, 2] 取的是哪个元素？
最后一行、列索引 2 的元素，即第 3 行第 2 列的值 17。
A[:, 2] 和 A[2] 的结果形状有什么区别？
A[:, 2] 取所有行的第 2 列，结果是一维数组；A[2] 取第 2 行整行，结果是一维数组（该行所有列）。
