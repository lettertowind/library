解释

多智能体让多个 Agent 各担一部分职责协作完成任务。Agent 之间需要统一沟通方式，A2A 协议就是为此设计的。

有什么用

  • 复杂任务的多角色协作
  • 需要分工与通信的 Agent 系统

关键要点

  • 多个 Agent 分工合作
  • Agent 间通信可用 A2A 协议
