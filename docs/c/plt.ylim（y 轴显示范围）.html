plt.ylim（y 轴显示范围）

ylim · plt.ylim() · y 轴刻度范围 · 设置 y 轴范围

设置 y 轴显示区间的函数，接收 [下限, 上限]，只改变可视范围不改数据。

解释

堆叠后柱子变高，默认刻度可能贴边，标签容易被裁掉。用 plt.ylim([10, 350]) 可以把显示区间整体调整，既留白给数据标签，也能放大某段区间看差异。对应的 x 轴版本是 plt.xlim。

有什么用

  • 为柱子顶部的数据标签留出空间
  • 放大或压缩某段取值区间以便观察差异

关键要点

  • 本课写法为传入列表 plt.ylim([10, 350])，下限 10、上限 350
  • 只影响画布显示范围，不修改原始数据
  • 堆叠后总高约 300，范围要按最大累计值来定，别把顶层切掉
  • 调整 y 轴范围后，标签偏移量（如 -10）的视觉效果会随之变化，需要重新微调

边界与易混淆

设得过小会把超出部分裁掉，看起来像数据缺失；与 plt.axis 一次性设置 xy 范围功能有重叠。

关联

  • 堆积柱形图组合使用
  • plt.text 数据标签组合使用

plt.ylim([10, 350]) 会改变柱子对应的数据值吗？
不会，只改变 y 轴的显示区间，数据本身不变

### 补充 · 2026-11-17

传 (下限, 上限) 可整体限定 y 轴范围；也可只用具名参数 bottom、top 单独调一侧。数据被截断时把上限调大即可完整显示。与 ax.set_xlim 成对使用，或用 ax.axis 一次设完四边界。

- ax.set_ylim(0, 30) 同时设下限与上限

- ax.set_ylim(bottom=-10) 只调下限，上限自动

- 数据看不全时通常是上限太小，调大即可

折线图上半部分被切掉，最直接的修法？
调用 ax.set_ylim 把上限调大（如改为 30）。
ax.set_ylim(bottom=-10) 与 ax.set_ylim(-10, 30) 的区别？
前者只改下限、上限自动，后者同时锁定上下限。

- 出处：孙兴华中文讲Python数据分析三部曲入门篇 Numpy教程 Pandas教程 Matplotlib教程 p68 S03E19.坐标轴【下】 · 2026-11-17

可用 plt.ylim([下, 上]) 或 ax.set_ylim([下, 上])，参数接受列表或元组。它有两个典型用途：一是给图例、数据标签留出顶部空间（如数据上限 12000 时设为 12500），二是把百分比副轴规范到 0~1 或 0~100。

- 写法可用列表 [0, 12500] 或元组

- 在原数据上限基础上多加一档（如 +500）即可给图例留白

- 范围必须与刻度格式器、数据尺度三者一致

数据 y 最大值约 12000，想让图例不贴顶，ylim 一般怎么设？
设成 [0, 12500]，在数据上限之上多留一小段空白。
为什么同一张图里 ylim 要和 formatter 一起考虑？
formatter 决定值怎么显示，ylim 决定值显示到哪，两者尺度不一致会让百分比或数值完全对不上。

- 出处：孙兴华中文讲Python数据分析三部曲入门篇 Numpy教程 Pandas教程 Matplotlib教程 p62 S03E13.组合图：柱形图+折线图 · 2026-11-17

不设范围时 Matplotlib 自动贴合数据，雷达图会出现 0 起点不为 0、各方向比例失真的问题。固定为 0～100 后，各维度的长度才有可比性。

- 写法：ax.set_ylim(0, 100) 或 plt.ylim(0, 100)

- 雷达图应固定从 0 起，否则面积比例失真

- 极坐标中它控制的是半径方向，不是垂直方向

雷达图的 ylim 从 40 开始设到 100，会有什么问题？
分数低的维度被压缩、高分段被放大，形状对比失真，读者会高估差异。

- 出处：孙兴华中文讲Python数据分析三部曲入门篇 Numpy教程 Pandas教程 Matplotlib教程 p71 S03E22.雷达图 · 2026-11-17

直角坐标下它控制 y 轴上下限；切换到极坐标后，纵向对应半径方向，所以 plt.ylim(0, 100) 限制的是极径而不是极角。它决定径向刻度环的显示区间。

- 参数为 (下限, 上限)，如 plt.ylim(0, 100)

- 极坐标下它控制极径范围，与极角无关

- 下限设为 0 时零点落在极点

极坐标图里想让最外圈到 100，应该调哪个函数？
plt.ylim(0, 100)，它设置的是极径范围。
