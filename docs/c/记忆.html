记忆

Memory · AI 记忆

产品帮你跨对话保存、并在新对话里自动放回上下文的信息。

解释

模型本身没有记忆，每次对话都是全新开始。「记忆」是产品层面的功能：产品从对话里提取值得长期保留的信息（职业、偏好、经常提的要求），单独保存；新对话开始时，再自动放进上下文开头。

有什么用

  • 免去每次重复交代背景和偏好
  • 让 AI 助手随使用时间越来越贴合你
  • 分清「模型能力」和「产品功能」

关键要点

  • 记忆属于产品，不属于模型
  • 流程：提取值得保留的信息 → 单独存储 → 新对话时注入上下文
  • 和上下文的区别：上下文是本次对话看得见的内容，结束即失效
  • 模型本身始终不记得任何事

边界与易混淆

记忆不等于 上下文窗口，也不等于缓存：窗口限制一次能看多少，缓存省的是重复计算，只有记忆是跨对话保存信息。三者都常被笼统称作「模型记住了」。

记忆和上下文窗口有什么区别？
上下文是本次对话里能看到的全部内容，结束就失效；记忆是产品跨对话保存的信息，每次新对话重新注入。
