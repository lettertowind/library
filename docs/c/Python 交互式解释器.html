解释

在命令行输入 python 即可进入，输入一行执行一行、立刻看到结果。它最适合做安装验证和小片段测试，不适合写多行逻辑（缩进和修改都麻烦）。视频中讲师口中的“编译器”实际就是这种交互环境。

有什么用

  • 验证某个包是否安装成功
  • 快速试验一句代码的输出结果

关键要点

  • 输入 import numpy 无报错 = 安装成功
  • 一行一执行，适合验证，不适合写长脚本
  • 输入 exit() 或 Ctrl+Z 回车可退出
  • 长代码应写到 .py 文件或用 IDE 运行

边界与易混淆

只适合零散验证；不能保存、难以修改，别把正式代码写在里面。

怎样用交互环境确认 NumPy 装好了？
进入交互环境执行 import numpy，没有报错即成功；报错说明没装好，需重装。
为什么不建议在交互式解释器里写完整的分析脚本？
它不保存历史文件、修改和调试困难，逻辑一长就难以维护，应写成 .py 文件。
