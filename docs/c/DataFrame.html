DataFrame

df · 二维数据表

Pandas 的二维数据结构，表示多行多列的数据表。

解释

DataFrame 是 Pandas 中用于处理表格数据的核心结构，可以看作由多个 Series 组成。编程中常简写为 df。它支持按列排序、空值判断等操作。

有什么用

  • 处理 Excel 等表格数据
  • 多行多列数据的分析与操作

关键要点

  • DataFrame 是二维数据表，表示多行多列
  • 可以由多个 Series 组成
  • 编程中常简写为 df
  • 按某列排序用 df.sort_values(by='列名')

边界与易混淆

DataFrame 是二维的，更高维数据需用 Panel 或其他结构（已不推荐）。
