内连接与外连接

inner join / outer join · 交集连接与并集连接

内连接只保留两边都匹配的行，外连接保留两边所有行、缺的一侧补空。

解释

本质是集合运算：inner 取交集，outer 取并集。concat 里用 join='inner'/'outer' 控制，merge 里用 how= 参数控制，SQL 里对应 INNER JOIN / FULL OUTER JOIN。

有什么用

  • 只想要两表都有的记录时用内连接
  • 要保留全部主体记录、缺的补空时用外连接

关键要点

  • inner = 交集，只留两边都存在的索引/键
  • outer = 并集，缺的一侧填 NaN，通常是默认值
  • concat 用 join 参数，merge 用 how 参数
  • 选错连接方式会导致数据悄悄变少或变多

边界与易混淆

concat 的 join 参数只控制对齐方式，不涉及键匹配；按键匹配的对齐要走 merge。

关联
