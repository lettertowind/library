np.sqrt

sqrt · 平方根函数

对数组每个元素计算非负平方根的一元通用函数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

np.sqrt 接收一个数组，返回同形状数组，每个元素为原元素的平方根。它是典型的一元通用函数，常用于数值变换和统计计算。

有什么用

  • 对数据做开方变换
  • 标准差等统计公式中的开方步骤

关键要点

  • 逐元素计算平方根
  • 返回非负平方根
  • 输入输出形状一致

边界与易混淆

负数输入会得到 nan 并告警，需先处理负值。

关联

  • 一元通用函数上位概念

np.sqrt 对含负数的数组会怎样？
