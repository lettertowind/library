regex 参数

regex=True · 正则替换参数 · regex

replace() 中控制是否把模式按正则表达式解释的开关参数。

目录
解释有什么用关键要点边界与易混淆关联自测出处

解释

设置 regex=True 后，replace() 的第一个参数被当作正则表达式处理，可用字符类、范围等模式批量匹配，例如 '[A-Z]' 匹配任意大写字母。不设置时 pandas 把模式当普通字符串查找。

有什么用

  • 按字符范围或模式批量替换
  • 复杂匹配规则下替代冗长的列表枚举

关键要点

  • regex=True 时第一个参数按正则解释
  • 不写 regex=True，'[A-Z]' 会被当普通字符串，通常匹配不到
  • 不需要额外 import re，直接配合 replace() 使用
  • 模式不是正则时不要随意开启 regex=True

边界与易混淆

只影响 replace() 对模式的解释方式，不改变替换目标范围（整表还是单列仍由调用对象决定）。

关联

  • replace组合使用

### 补充 · 2026-11-17

让 replace 将第一参数按正则表达式而非普通字符串解析

- 正则表达式要写在引号内，如 '[A-Z]'。

- Pandas 的 replace 可直接用，不需要 import re。

- 不写 regex=True 时按普通字符串查找，不会正则匹配。

- 第一参数不是正则表达式时，不要加 regex=True。

- 可与 inplace=True 同时使用。
