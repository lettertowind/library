怎么用这条地图

全量：三季依次看完，约 19.5 小时，是完整体系。

精简主干（约 11 小时）——目标是能上手处理真实数据，不追求把每个函数都过一遍：

  • Numpy：p4–p10 必看（创建数组、多维数组、数组计算、索引切片、布尔索引、神奇索引、轴与转置），p13–p14 看数学统计与排序。p11 random 作者自己标了「了解即可」，p12 通用函数可快进。
  • Pandas：p20–p24 数据结构与连接查询是地基，必须看；p28–p29 查询与筛选、p31 缺失值、p41–p43 分组聚合与透视表，这五集是处理真实表格的核心；p45–p46「三板斧」和环比同比是收尾实战。文件读取 p17–p19 按自己数据来源挑一集看（csv / Excel / MySQL）即可。p16 新建文件、p25–p27 自动填充、p30 删除、p32–p40 统计与字符串等，遇到再用查表方式回看。
  • Matplotlib：p48–p54 柱状/条形/饼图、p56–p66 折线/子图/组合图/散点/直方图，覆盖日常九成场景；p67–p79 坐标轴细节、雷达图、瀑布图、玫瑰图等属进阶美化，按需挑看。

踩坑提醒：

  • 这套课录制于 2020–2021 年（简介里提到「等待 2021 年」），安装环节（p2、p15）的包版本与现在差别较大，装环境别照抄版本号，直接 pip install numpy pandas matplotlib openpyxl 装最新版即可。
  • p27「数据排序」标题带「【已修证】」、p55 与 p61 带「[补充]」，都是作者后来补录的短集，看到正片对应处顺手补看即可。
  • 作者原话定位是「入门」：本课讲的是库的用法，不涉及算法与统计原理，真正的分析能力还要靠业务问题和数据结构功底。
