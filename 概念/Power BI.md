# Power BI

> 别名：PowerBI、微软 BI 工具

**微软出品的拖拽式商业智能工具，不写代码就能做报表和图表。**

## 解释

连上数据源后把字段拖进图表槽位即可出图，瀑布图、仪表盘都是内置图形，几分钟能完成 Python 需要几十行代码的效果。适合常规办公分析；自定义样式和海量数据/算法类需求仍要回到 Python。

## 有什么用

- 日常经营报表、月度复盘可视化
- SQL 取数后的快速出图与分享

## 关键要点

- 拖拽式操作，瀑布图等标准图形内置可用
- 与 SQL 组合是职场最常见的数据分析技术栈
- 学习成本远低于 Matplotlib，但样式与逻辑自由度有限
- 复杂算法、超大数据量、非标准图形仍需 Python 补充

## 边界与易混淆

不适合需要自定义图形结构或算法建模的场景，也不擅长处理超出其数据模型承载量的原始数据。
