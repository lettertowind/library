# 取所有行的指定列

> 别名：数组[:, [列索引]]、列子集抽取、d[:, [1,2]]

**用冒号取全部行、用整数数组取指定列，得到列子集。**

## 用法
**语法**：`d[:, [列索引1, 列索引2, ...]]`
**参数**：
- `:`（逗号前）：表示取该维全部，这里指所有行
- `[列索引...]`（逗号后）：一个整数数组（或列表），指定要保留的列，列的顺序和是否连续都可以任意指定
- `d`：二维 numpy 数组，行数不限

**示例**：
```python
import numpy as np

d = np.arange(36).reshape(9, 4)
print(d[:, [1, 2]])     # 取所有行的第 1、2 列，结果为 9 行 2 列
# [[ 1  2]
#  [ 5  6]
#  [ 9 10]
#  [13 14]
#  [17 18]
#  [21 22]
#  [25 26]
#  [29 30]
#  [33 34]]
print(d[:, 1:3])        # 连续列时，切片写法与上面等价
# 输出与 d[:, [1, 2]] 相同
print(d[:, [2, 0]])     # 列索引可以不连续、可以乱序
# [[ 2  0]
#  [ 6  4]
#  ...（共 9 行）]
```
注意：逗号前是行、逗号后是列，不要混用。

## 解释

写法 d[:, [1,2]] 中逗号前的冒号表示所有行，逗号后的整数数组表示要保留的列。它等价于连续切片 d[:, 1:3]，但列可以不连续，适合从表格数据中抽取指定列。

## 有什么用

- 从二维数组或表格中抽取指定列
- 选取不连续的若干列

## 关键要点

- 冒号 : 表示取该维全部
- 列索引数组可以任意指定、不必连续
- d[:, 1:3] 是连续列时的等价写法
- 第 0 列不取时结果只保留第 1、2 列

## 边界与易混淆

列索引数组与切片混用时要分清哪边是行、哪边是列。
