# 柱形图

> 别名：柱状图、Bar Chart、plt.bar

**用长条长度比较各类别数值大小的图表，长条间留有空隙。**

## 解释

柱形图横轴是互不相干的类别，如一班、二班、张三、李四，长度表示该类别对应的频数或数值。它是条形图竖放的形式，横放即条形图。宽度只是样式，可以随意调粗细而不影响读数，这与直方图按组距决定宽度完全不同。

## 有什么用

- 比较不同班级、不同产品、不同人员的数值大小
- 展示类别计数结果（value_counts 后直接画）

## 关键要点

- 横轴是孤立类别，长条之间有明显空隙以示区分
- 主要靠长条长度读取数值，宽度可随意设置
- 竖放叫柱形图，横放叫条形图，本质相同
- 与直方图的差别在数据性质：类别 vs 连续区间

## 边界与易混淆

连续数值想看分布形态时应改用直方图，硬切成类别柱形图会丢失分布信息。

## 关联

- [[直方图]] — 对比项

## 自测

要展示“一班 45 人、二班 38 人”，为什么不该用直方图？::班级是彼此独立的类别而非连续区间，直方图要求横轴是连续等距的分箱。


### 补充 · 2026-11-17

Matplotlib 中由 plt.bar() 绘制，横轴为类别、纵轴为数值。通过控制位置、高度、颜色、宽度等参数支持单系列与多系列（分组、堆积）等多种形态。

- plt.bar(x, height, width, color, label) 核心五参数
- x 为柱子位置（建议数值索引），height 为柱高即数据值
- width 控制柱宽，分组柱需按其做位置偏移
plt.bar 的 height 参数放什么？::放每根柱子对应的数值（如某年的成绩序列），决定柱高。
- 出处：[孙兴华中文讲Python数据分析三部曲入门篇 Numpy教程 Pandas教程 Matplotlib教程 p50 S03E03.分组柱状图](https://www.bilibili.com/video/BV1ji4y157uB?p=50) · 2026-11-17

plt.bar(x, y) 第一个参数是 x 轴的类别（如姓名），第二个是 y 轴的数值（如分数）。它只是把图形构造出来，还要 plt.show() 才会显示。柱形图参数很多，基础形式之外可通过 label、width 等逐项修饰。

- 最简写法：plt.bar(数据.姓名, 数据.分数)
- x 传类别、y 传数值，顺序错会画出怪图
- 加 label='成绩' 后再调用 plt.legend() 才出图例
plt.bar 的 x 传数值、y 传类别名，会出现什么结果？::类别名无法按数值比例定位，坐标轴取值异常甚至报错，柱子排布毫无意义——参数顺序必须 x=类别、y=数值。
- 出处：[孙兴华中文讲Python数据分析三部曲入门篇 Numpy教程 Pandas教程 Matplotlib教程 p48 S03E01.柱状图](https://www.bilibili.com/video/BV1ji4y157uB?p=48) · 2026-11-17

柱形图以类别为横轴、数值为柱高，适合比较不同类别的总量。在 Matplotlib 中用 plt.bar 绘制，并可叠加平均线等参考线增强解读。

- plt.bar(x, height) 中 x 为类别、height 为柱高数值
- color 设柱子颜色，label 为图例提供文本
- alpha=0.6 可让红色变粉，叠加参考线更清晰
plt.bar 中 height 参数对应什么？::每根柱子的高度，即该类别的数值大小
- 出处：[孙兴华中文讲Python数据分析三部曲入门篇 Numpy教程 Pandas教程 Matplotlib教程 p57 S03E09.平均线](https://www.bilibili.com/video/BV1ji4y157uB?p=57) · 2026-11-17

横轴放分类（如班级），纵轴放数值（如销售量），适合比较不同类别之间的量级差异。label 参数为图例提供文字，alpha 控制透明度，让图形在多子图环境中更易读。

- plt.bar(x, y) 中 x 为分类、y 为数值
- label 设置图例标签，便于读者识别
- alpha 调透明度，柱体重叠时尤其有用
同一张画布上第 4 个子图画柱形图，第 3 个子图画折线图，代码该怎么摆？::在 ax3 = fig.add_subplot(223) 后写 plt.plot(...)，在 ax4 = fig.add_subplot(224) 后写 plt.bar(...)。
- 出处：[孙兴华中文讲Python数据分析三部曲入门篇 Numpy教程 Pandas教程 Matplotlib教程 p58 S03E10.画布和子图](https://www.bilibili.com/video/BV1ji4y157uB?p=58) · 2026-11-17

plt.bar(x, y) 在指定位置画柱子，高度对应数值。通过 width、bottom、color、label 等参数可扩展出堆积图、瀑布图、分组图等变体，是分类数据对比的基础图形。

- 核心参数：x 位置、y 高度、width 柱宽、bottom 起点、color 颜色、label 图例名
- width 控制柱宽，也决定相邻柱的合理间距
- label 只对图例生效，同一语义的柱子可重复传同一 label
想在同一个坐标系里画红绿两组柱子，需要调用几次 plt.bar？::每个分组各调一次，颜色和 label 分开传，Matplotlib 会自动叠加在同一坐标轴。
- 出处：[孙兴华中文讲Python数据分析三部曲入门篇 Numpy教程 Pandas教程 Matplotlib教程 p77 S03E28.瀑布图](https://www.bilibili.com/video/BV1ji4y157uB?p=77) · 2026-11-17


### 补充 · 2026-11-17

用矩形柱高度表示各类别数值大小的统计图。

- Axes 对象也有 bar 方法，可在指定轴上绘图。
- 在子图/子区域中用 ax.bar 可避免画错位置。
- 常与折线图组合：主图柱形图、小图折线图。
- 可通过 bottom、left 等参数实现堆叠或水平条形图。
