# 横向排序

> 别名：axis=1 排序、按行排序、行方向排序、sort_values axis=1

**用 sort_values 指定 axis=1，按某一行标签的值对该行的各列重新排序。**

## 用法
**语法**：`DataFrame.sort_values(by, axis=0, ascending=True, inplace=False, na_position='last')`
**参数**：
- `by`：排序依据；横向排序时写行标签（索引值），不是列名
- `axis`：默认 0 按列纵向排序；横向排序须显式写 `axis=1`（pandas 2.1 起已弃用，见示例）
- `ascending`：`True` 升序、`False` 降序，也可传布尔列表
- `inplace`：是否原地修改，默认 `False` 返回新对象
- `na_position`：缺失值放 `'first'` 或 `'last'`
**示例**：
```python
import pandas as pd
df = pd.DataFrame({'数学': [90, 80], '语文': [70, 95], '英语': [85, 60]}, index=['小明', '小红'])
# 旧版写法：pandas 2.1 起 axis=1 已弃用，会触发 FutureWarning
old = df.sort_values(by='小明', axis=1, ascending=False)
print(old.columns.tolist())  # ['数学', '英语', '语文']
# 推荐写法：先转置排序再转回
new = df.T.sort_values(by='小明', ascending=False).T
print(new.columns.tolist())  # ['数学', '英语', '语文']
```

## 解释

常规排序是 axis=0，按列字段给行排序；当需要针对某一行数据做横向比较时，把 axis 设为 1，并用 by 指定该行的行标签，Pandas 会按这一行各列的值调整列的先后顺序。例如某行值为 4、6、2，降序后列顺序变为 6、4、2。

## 有什么用

- 按某一行的数值对列重新排列，如按某项指标给各科目/各月份列排序
- 数据探索时临时查看某行的横向大小顺序

## 关键要点

- 必须显式写 axis=1，默认 axis=0 会对列做纵向排序
- 此时 by 里写的是行索引/行标签，而不是列名
- ascending、inplace 的用法与常规排序相同
- 这种排序在实际分析中很少用，普通二维表字段排序用不到
- 排错时依次检查：by 是否写行标签、axis 是否已改为 1、ascending 是否符合预期

## 边界与易混淆

易与「axis=1 按列分组聚合」混淆：两者都用 axis=1，但一个是排序语境、一个是 groupby 语境，不要套用同一套 by 含义。
