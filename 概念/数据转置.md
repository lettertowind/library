# 数据转置

> 别名：Transpose、行列转换、.values.T

**把 DataFrame 的行与列互换，行标签变列标签、列标签变行标签。**


## 用法
**语法**：`pd.DataFrame(df.values.T, index=df.columns, columns=df.index)`（教材标准写法）；现代等价写法：`df.T`
**参数**：
- `data`：二维数组或 DataFrame，传 `df.values.T`，即只转置数值部分
- `index`：新表的行标签，必须传原表的 `columns`，否则标签错位
- `columns`：新表的列标签，必须传原表的 `index`
- `df.T`：无参数，行列标签与数值一并互换，是上面写法的等价简写
**示例**：
```python
import pandas as pd

df = pd.DataFrame([[80, 90], [70, 85]],
                  index=['语文', '数学'], columns=['张三', '李四'])
print(df)
#       张三  李四
# 语文   80  90
# 数学   70  85

# 旧版写法（课程 2020 年讲法）：.values.T 只转数值，标签手工重设
t = pd.DataFrame(df.values.T, index=df.columns, columns=df.index)
print(t)
#       语文  数学
# 张三   80  70
# 李四   90  85

# 现推荐写法：df.T 自动互换行列标签，结果一致
print(df.T.equals(t))  # True
```

## 解释

转置用于把宽表变长表或调整数据朝向。Pandas 中推荐用 数据.values.T 取出 NumPy 矩阵转置，再用 pd.DataFrame 重新封装，并把 index 设为原 columns、columns 设为原 index，保证结构完全对应。

## 有什么用

- 需要行列互换的报表整理
- 把字段名变成行、把记录变成列的场景

## 关键要点

- 核心是 .values.T 做矩阵转置
- 转置后必须重设 index 与 columns，否则标签错位
- index=原columns、columns=原index 是标准写法
- 实现方法不唯一，记住一种稳定写法即可

## 边界与易混淆

只转置数值部分，原索引与列名需手动重新指定；不是简单的 df.T 一行了事。

为什么转置后要写 index=数据.columns、columns=数据.index？::因为 .values.T 只转了数值，不转标签；不重设会导致行列标签与原表不对应。
