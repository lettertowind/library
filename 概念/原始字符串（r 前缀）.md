# 原始字符串（r 前缀）

> 别名：raw string、r''、r 字符串

**加 r 前缀的字符串，反斜杠不被转义，按字面保留。**

## 解释

普通字符串里 \n、\1 这类组合会被 Python 提前解释成特殊字符，而正则恰恰要用大量反斜杠表达元字符和引用。加 r 后字符串内容原样保留，交给正则引擎去解释，所以写正则模式和替换串时都习惯加 r。

## 有什么用

- 书写正则模式字符串
- 书写含分组引用的替换串
- 表示 Windows 文件路径

## 关键要点

- r'\d' 表示「反斜杠 + d」两个字符，而非转义序列
- 正则模式与替换串都建议加 r，避免二次转义
- 不加 r 时 \1、\d 可能提前被 Python 解析，导致匹配或替换失效
- r 只影响转义解析，不改变字符串本身的含义

## 边界与易混淆

r 字符串不能以奇数个反斜杠结尾；它也不改变字符串里其他内容的语义，只是禁用反斜杠转义。

## 自测

为什么 str.replace(r'(\d{4})', r'\1年') 里两个字符串都加了 r？::不加 r 时反斜杠会被 Python 先行转义，模式里的 \d 和替换串里的 \1 都失去原本含义。
r'\\d' 和 '\d' 在正则里是同一个意思吗？::不是。r'\\d' 是反斜杠加 d（数字元字符）；'\d' 中反斜杠后接 d 无特殊转义，内容虽也是 \d，但遇到 \1、\n 这类就会出错，故应统一加 r。
