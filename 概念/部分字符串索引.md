# 部分字符串索引

> 别名：Partial String Indexing、日期字符串筛选

**在 DatetimeIndex 上用字符串（年、年月或区间）直接筛选数据。**

## 用法
**语法**：`df.loc['1983']` / `df.loc['1983-10']` / `df.loc['1983':'1990']`（索引须为 DatetimeIndex）
**参数**：
- `'1989'`：只写年份，筛选该年的全部数据
- `'1983-10'`：年-月，筛选该月的全部数据
- `'1983':'1990'`：冒号切片，筛选闭区间内的数据（含两端）
- 结果是切片视图还是副本由场景决定，建议用变量接收后再复用，大数据量时加上 `.head()`
**示例**：
```python
import pandas as pd

idx = pd.date_range('1983-01-01', '1985-12-31', freq='D')
df = pd.DataFrame({'v': range(len(idx))}, index=idx)

print(len(df.loc['1984']))        # 366（1984 是闰年）
print(len(df.loc['1984-10']))     # 31
print(len(df.loc['1983':'1984'])) # 731

# 普通索引不支持这种写法
df2 = df.reset_index()
# df2['1983']  # KeyError：非 DatetimeIndex 无法部分匹配
```

## 解释

利用日期索引的解析能力，无需显式比较日期。例如 数据['1989'] 取某年，数据['1983':'1990'] 取区间。

## 有什么用

- 快速按年份或月份筛选
- 按日期区间切片

## 关键要点

- 需先将日期列设为 DatetimeIndex
- 区间用冒号，如 数据['1983':'1990']
- 大数据查询后加 .head() 避免卡顿
- 结果需用变量接收才能复用

## 边界与易混淆

只适用于 DatetimeIndex；普通索引不支持这种字符串部分匹配。
