# 路径变量

> 别名：path 变量、保存路径

**把文件保存路径存进变量，避免反复书写长路径。**

## 解释

路径字符串往往很长，一个脚本里可能多处用到。写成 path = r"C:\pandas\孙兴华.xlsx" 这样的变量后，改保存位置只需改一处；前面的 r 表示原生字符串，避免反斜杠被当成转义符。

## 有什么用

- 同一路径在多个导出调用中重复出现
- 需要临时切换保存目录时

## 关键要点

- 路径建议加 r 前缀，避免 \ 被当作转义符
- 变量名随意，path 只是习惯写法
- 路径也可直接硬编码进导出方法，只是不便修改
- 换文件类型时，路径变量里的后缀要一并改

## 边界与易混淆

只是书写层面的便利，不保证写入成功；目录不存在或没有权限时导出仍会失败
