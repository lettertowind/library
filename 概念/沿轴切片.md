# 沿轴切片

> 别名：沿轴切片、axis slicing、多维切片

**在 NumPy 数组切片时，用逗号分隔的参数依次对应 0 轴、1 轴等，实现沿指定轴取子数组。**

## 解释

无逗号时只有一个参数，默认沿 0 轴切片；有逗号时第一个参数对应 0 轴，第二个参数对应 1 轴，依次类推。切片和索引一样不包含结束值。

## 有什么用

- 从多维数组中按行、列或更高维度截取部分数据
- 配合轴概念进行精确的数据选取

## 关键要点

- 无逗号：一个参数，默认沿 0 轴切片
- 有逗号：第一个参数对应 0 轴，第二个对应 1 轴，依次类推
- 切片不包含结束值
- arr[:2] 取前两行；arr[:2, 1:] 取前两行的第 1 列到最后一列

## 边界与易混淆

切片参数与轴顺序严格对应，不能随意调换；高维数组需要按轴顺序写全或使用省略号。

为什么 arr[:2] 只沿 0 轴切片？::因为没有逗号，只有一个参数，默认沿 0 轴切片。
