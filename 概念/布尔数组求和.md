# 布尔数组求和

> 别名：条件计数、(a>3).sum()、True 求和、布尔掩码求和

**对布尔数组求 sum，用 True=1、False=0 的规则统计满足条件的元素个数。**

## 用法
**语法**：`(条件).sum()`，也可写成 `np.sum(条件)`
**参数**：
- 条件：由比较运算（如 `a > 3`）得到、与原数组形状相同的布尔数组
- `axis`：按轴求和，得到的结果是沿该轴满足条件的计数；文档未说明时，默认统计全部元素
- `keepdims`：是否保留原数组的维度，默认 `False`

**示例**：
```python
import numpy as np

a = np.array([[1, 5, 2],
              [7, 3, 9]])

bool_arr = a > 3
print(bool_arr)
# [[False  True False]
#  [ True False  True]]

print(bool_arr.sum())   # 3，True 的个数
print(a[a > 3].sum())   # 21，条件命中的元素值之和，与上一行含义不同
print((a > 3).sum(axis=1))  # [1 2]，按行统计
```

## 解释

先用比较运算得到与原数组同形状的布尔数组，再对它求和，即可得到满足条件的元素数量。它是「条件计数」的标准写法，避免写循环逐个判断。

## 有什么用

- 统计数组中大于某阈值的元素个数
- 统计缺失、异常值、命中规则的数据量

## 关键要点

- False 等价 0、True 等价 1，求和结果就是 True 的个数
- 必须先得到布尔数组再 .sum()，直接对数值条件求和是错的
- 写法固定为 (条件).sum()，条件可以是 a > 3 之类
- 常与 np.any / np.all 配合：先判断有没有，再统计有多少

## 边界与易混淆

只统计个数；若要求和满足条件元素的值本身，应写 a[a > 3].sum()。
