# 通用函数

> 别名：ufunc、Universal Function、逐元素函数

**对数组逐元素执行运算的向量化函数。**

## 解释

通用函数（ufunc）是 NumPy 中对标量函数做向量化封装后的函数，能直接作用于整个数组，对每个元素分别计算。它解决的是「不想写循环、又要对整数组做同一运算」的问题，是 NumPy 向量化计算的基础机制。

## 有什么用

- 对数组做批量数学运算
- 替代 Python 循环提升性能

## 关键要点

- 本质是标量函数的向量化封装
- 按元素逐个运算，不汇总整个数组
- 分一元（单数组）和二元（双数组）两类
- 调用方式统一：传数组得逐元素结果
- 不必背全，按需查阅即可

## 边界与易混淆

易与聚合函数（np.sum、np.max）混淆：聚合函数把数组汇总成一个值，通用函数保持数组形状逐元素运算。

## 自测

np.sqrt 和 np.sum 对数组的作用有什么本质区别？::np.sqrt 是通用函数，逐元素返回同形状数组；np.sum 是聚合函数，把整个数组汇总成一个标量。
为什么说通用函数是「向量化封装」？::因为它把原本只接受标量的简单函数包装成能直接接收整个数组、内部逐元素执行的形式，避免显式循环。
