# 条件赋值

> 别名：布尔赋值、按条件修改、masked assignment

**用布尔索引定位满足条件的元素，再对其赋新值或自增。**

## 用法
**语法**：`arr[条件] = 新值`　或　`arr[条件] += 值`（布尔索引放等号左边，只改 True 位置）
**参数**：
- `arr`：被修改的 ndarray，原地修改、不返回新数组；二维按列改时先用 `arr2d[:, 列号]` 切出目标列
- `条件`：与 `arr`（或所切列）同形状的布尔数组，通常由 `arr > 5`、`arr % 2 == 0` 等比较生成；多条件用 `&`、`|` 且每个条件加括号
- `新值`：标量，或与 True 位置数量匹配的数组；`+=` 形式写要累加的数值，等价于 `arr[条件] = arr[条件] + 值`
**示例**：
```python
import numpy as np

arr = np.array([3, 7, 1, 9, 5])
arr[arr > 5] = 0            # 直接赋值
print(arr)                  # [3 0 1 0 5]

arr2 = np.array([3, 7, 1, 9, 5])
arr2[arr2 > 5] += 520       # 自增，只影响 True 位置
print(arr2)                 # [  3 527   1 529   5]

arr2d = np.array([[1, 6], [7, 2]])
arr2d[arr2d[:, 1] > 5, 1] = 0   # 只改第 1 列里满足条件的行
print(arr2d)                # [[1 0] [7 2]]
```

## 解释

条件赋值把布尔索引放在等号左边，只修改 True 位置的元素。常见形式有直接赋值（arr[arr > 5] = 1）和自增（arr[arr > 5] += 520）。它避免了循环逐个判断。

## 有什么用

- 零一化处理
- 只给满足条件的元素加值
- 按列条件替换

## 关键要点

- 写法：arr[条件] = 新值
- 自增写法：arr[条件] += 值，等价于 arr[条件] = arr[条件] + 值
- 只影响 True 位置，其余不变
- 二维按列赋值要先切列再条件赋值

## 边界与易混淆

对二维数组直接写 arr2d[arr2d > 5] = 520 会作用于全数组，不是单列；需先取列或用行列联合索引。

arr[arr > 5] += 520 和 arr[arr > 5] = arr[arr > 5] + 520 是否等价？::等价，前者是后者的简写形式，都只对大于 5 的元素加 520。


### 补充 · 2026-11-17

条件赋值把布尔索引和赋值结合：df.loc[条件, 列] = 值，只改满足条件的行。若目标列不存在，Pandas 会自动新建该列。

- 语法为 df.loc[条件, 列标签] = 值
- 只修改满足条件的行，其余行不变
- 目标列不存在时自动新建
如何用一行代码把语文>=60 的行的'及格'列设为'是'？::df.loc[df['语文']>=60, '及格'] = '是'。

典型形态是 df.loc[条件, 列名] = 值：条件负责选行，列名指定目标列。若该列名原本不存在，Pandas 会自动创建这一列，因此一条赋值语句就完成了「新建列 + 分类填充」，比逐行 if 循环快得多。

- 写法为 df.loc[行条件, '列名'] = 值，不必写 if
- 目标列不存在时会自动新建列
- 多个分支需要多条语句，每条对应一个条件
执行 数据.loc[数据['性别'] == '男', '称呼'] = '先生' 时，原表并没有「称呼」列，会发生什么？::Pandas 会新建「称呼」列，只把性别为男的行填成「先生」，其余行为 NaN，再由第二条语句补成「女士」。

布尔索引不只用于取值，还能定位要写入的位置。arr[arr > 5] = 1 表示仅对大于 5 的元素写入 1，其余元素保持不变。配合增强赋值 += 还能做「满足条件的元素各自加上某个值」的条件自增量。

- 条件写在中括号里，等号右侧的值只写入 True 位置
- arr[arr > 5] += 520 等价于 arr[arr > 5] = arr[arr > 5] + 520
- += 是增强赋值，a += b 即 a = a + b
arr = np.arange(10)，执行 arr[arr % 2 == 1] *= 10 后，数组变成什么？::奇数位元素被乘以 10，偶数位不变，结果为 [0, 10, 2, 30, 4, 50, 6, 70, 8, 90]。
