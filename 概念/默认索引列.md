# 默认索引列

> 别名：RangeIndex、0,1,2 索引、默认行号

**DataFrame 自带的从 0 开始的整数行号，不是业务字段。**

## 解释

新建 DataFrame 时 Pandas 自动分配 0、1、2… 的行索引。写出到 Excel/CSV 时它默认会被当作一列输出，造成表格里多出一列无意义数字，通常需要处理掉。

## 有什么用

- 理解导出文件为何多一列数字
- 决定是否保留或替换索引

## 关键要点

- 默认从 0 开始递增，与业务数据无关
- to_excel/to_csv 默认会把它写成一列
- 可用 set_index 换成业务字段
- 也可在写出时用 index=False 关闭

## 边界与易混淆

它是索引不是列，用列名访问不到，需用 df.index。

### 补充 · 2026-11-17

不指定 index 时 pandas 会自动补一列 0、1、2… 的索引，本质与 Python 的 range 规则一致：左闭右开。4 个元素的 Series 索引是 0、1、2、3，讲到「4」其实到「3」为止。

- 从 0 开始，步长为 1
- 结束值不包含在内（4 个元素到 3 为止）
- 只写 .index 就能看到当前索引类型与取值
一个有 7 个元素的 Series 默认索引最大是多少？::6（0 到 6，结束值不含在内）。

DataFrame 创建时若未指定索引，会自动生成一列 0、1、2… 的行号。它是结构层面的定位工具，不是业务字段，因此导出到 Excel/CSV 时默认会被写进第一列，常显得多余。

- 默认索引从 0 开始递增，与业务数据无关
- to_excel/to_csv 默认会把索引一起写出
- 多数业务表格不需要这一列
导出的 Excel 第一列出现 0、1、2，这是数据出错了吗？::不是。那是 DataFrame 的默认索引被一并写入了，导出前 set_index 或关闭索引即可。
