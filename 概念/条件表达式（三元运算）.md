# 条件表达式（三元运算）

> 别名：三元运算符、conditional expression、A if 条件 else B

**Python 中一行内按条件二选一取值的表达式。**

## 解释

写法是「值1 if 条件 else 值2」：条件为真取前面的值，为假取后面的值。它等价于四行的 if-else 赋值，可以直接写在等号右侧，做规律列的批量生成时很省事。

## 有什么用

- 按索引奇偶生成男女交替值
- 简单二选一赋值，避免写多行 if

## 关键要点

- 语法顺序是「值1 if 条件 else 值2」，条件夹在中间
- else 分支不可省略，否则语法错误
- 只能包表达式，不能包语句（如 print、赋值）
- 嵌套超过两层就改用 if-elif，可读性更好

## 边界与易混淆

只适合简单二选一；多分支或带副作用的逻辑用普通 if 语句。

## 自测

数据['性别'].at[i] = '男' if i % 2 == 0 else '女'，当 i 等于 3 时该单元格写入什么？::写入 '女'，因为 3 % 2 = 1 不满足条件。


### 补充 · 2026-11-17

写法是「值1 if 条件 else 值2」：条件成立取值1，否则取值2。它最常和 lambda 组合，塞进 apply 里做逐元素的条件赋值，例如民族不等于「汉」加 5 分、否则加 0 分。等价于 Excel 里的 IF(条件, 值1, 值2)。

- 语法为 值1 if 条件 else 值2，else 分支必须写
- 典型写法：lambda x: 5 if x != '汉' else 0
- 等价于 Excel 的 IF 函数，可互相翻译
数据['加分'] = 数据['民族'].apply(lambda x: 5 if x != '汉' else 0)，某人是汉族时该行返回什么？::0，条件不成立走 else 分支。
