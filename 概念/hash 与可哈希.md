# hash 与可哈希

> 别名：hash()、hashable、可哈希对象、哈希值

**把对象映射为整数摘要；只有不可变且值稳定的对象才可哈希。**

## 解释

哈希值是字典键、集合元素快速定位的基础：先算哈希找到槽位，再用 == 确认。list、set、dict 等可变对象不可哈希，字符串、数字、元组、frozenset 可哈希。

## 有什么用

- 判断对象能否作为 dict 键或 set 元素
- 自定义类实现 __hash__ 与 __eq__
- 理解字典查找为何快

## 关键要点

- 相等的对象哈希值必须相等，反之不成立
- frozenset 可哈希，普通 set 不可哈希
- 自定义类默认按 id 哈希，重写 __eq__ 后须同步重写 __hash__
- 可变对象不可哈希，以免元素变化后哈希表定位失效

## 边界与易混淆

哈希值不等于对象身份或内存地址；字符串哈希在不同进程/重启后可能变化，不能持久化存储。

## 自测

为什么 list 不能作为字典的键？::列表可变、不可哈希；内容改变会导致哈希定位失效，破坏字典结构。
tuple 一定可哈希吗？::不一定，元组内若含有 list 等不可哈希元素，整个元组也不可哈希。
