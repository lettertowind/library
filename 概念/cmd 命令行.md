# cmd 命令行

> 别名：命令提示符、cmd、命令行窗口

**Windows 系统自带的文本命令交互界面，用于执行 DOS 风格命令。**

## 解释

通过 Win+R 输入 cmd 打开，可在其中执行 cd、pip 等命令。数据分析入门阶段常用它来安装库、启动 Python 解释器。

## 有什么用

- 执行 pip 安装命令
- 进入目录、启动 Python

## 关键要点

- Win+R 输入 cmd 快速打开
- cd 命令用于切换当前目录
- 路径需替换为本机真实路径

## 关联

- [[pip]] — 组合使用

## 自测

在 cmd 中如何进入 D 盘的 Python 目录？::先输入 D: 切换盘符，再 cd 到具体路径。
