# 布尔分组键

> 别名：boolean group key、条件分组键、True/False 分组

**把一组 True/False 布尔序列直接作为 groupby 的分组依据，得到两组聚合结果。**

## 解释

groupby 的分组键不一定是列名，任何与行等长的序列都可以当键。布尔序列会把数据切成 True 组和 False 组，常用于「满足条件 vs 不满足条件」的对比统计。

## 有什么用

- 按行索引奇偶分组
- 按数值阈值分组
- 按是否属于指定类别分组

## 关键要点

- df.index % 2 == 0 生成偶数行为 True 的布尔键
- df['序号'] >= 5 生成条件布尔键，结果分 True/False 两组
- 布尔键常与 isin 组合，实现「指定类别 vs 其他」对比
- 聚合列要用双层列表 [['数学','语文','英语']]

## 边界与易混淆

只适合二分对比；多类别分组应直接用类别列或 isin 配合多键。

## 自测

df.groupby(df.index % 2 == 0) 会得到几组？分别代表什么？::两组：True 为偶数行，False 为奇数行。
为什么布尔分组键必须与行数等长？::因为 groupby 要按行逐条判断归属，长度不一致无法对齐。
