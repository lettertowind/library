# 负索引

> 别名：negative index

**用负数从数组末尾倒数定位元素的索引方式，-1 表示最后一个。**

## 解释

负索引让取末尾元素无需知道数组长度。在切片中 -1 作为结束位置时同样不包含，因此 A[0:-1] 取的是除最后一行外的所有行。

## 有什么用

- 快速取末尾元素或末尾行
- 切片中排除末尾若干项

## 关键要点

- -1 表示最后一个元素或最后一行
- 负索引在切片中同样遵循不包含结束位置
- A[0:-1] 排除最后一行
- A[-1, 2] 取最后一行第 2 列

## 边界与易混淆

负索引与正索引混用时，要确认切片方向与包含规则，容易算错边界。

## 自测

A[0:-1] 为什么不包含最后一行？::因为切片不包含结束位置，-1 作为结束位置本身不被取到，所以排除最后一行。


### 补充 · 2026-11-17

负索引在 Python 和 NumPy 中通用。二维数组中 A[-1, 2] 表示最后一行、列索引 2 的元素；A[-1] 表示最后一行所有列。

- -1 表示最后一个元素或最后一行
- A[-1, 2] 取最后一行、列索引 2
- A[-1] 取最后一行整行
A 为 4 行 5 列数组，A[-1, 2] 取的是哪个元素？::最后一行、列索引 2 的元素，示例中为 17。
A[0:-1] 会包含最后一行吗？::不会，切片结束位置 -1 本身不被包含。
