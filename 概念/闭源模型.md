# 闭源模型

> 别名：closed-source model、闭源

**不公开权重、只能通过官方产品或接口使用的模型。**

## 解释

闭源模型不公开权重文件，用户只能通过官方产品或 API 接口使用，例如 GPT、Claude、Gemini。与开源模型相对。

## 有什么用

- 判断模型能否本地部署
- 评估数据是否离开本地

## 关键要点

- 权重不公开，只能通过产品或接口使用
- 典型如 GPT、Claude、Gemini
- 数据需上传到服务商
