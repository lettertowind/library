# 灵活算术方法

> 别名：flexible arithmetic、add/sub/mul/div、算术方法家族

**Pandas 提供的 add/sub/mul/div 等方法，可在运算时直接指定缺失值填充。**

## 用法
**语法**：`Series.add(other, fill_value=None)` / `DataFrame.sub(other, fill_value=None)`，同族方法还有 `mul`、`div`、`floordiv`、`pow`、`mod`，带 `r` 前缀的是反转版本（如 `rsub`）

**参数**：
- `other`：参与运算的另一个 Series、DataFrame 或标量
- `fill_value`：运算前用来填充缺失值（NaN）的值；只对 NaN 生效，对 inf 无效
- `axis`：仅当 `other` 是 Series 或 DataFrame 时用于对齐的轴，取 `0` 或 `1`（也可写 `'index'` 或 `'columns'`）

**示例**：
```python
import pandas as pd
import numpy as np

df = pd.DataFrame({'A': [1, np.nan, 3], 'B': [4, 5, np.nan]})

# 灵活算术方法：缺失值按 0 参与运算
print(df['A'].add(df['B'], fill_value=0).tolist())   # [5.0, 5.0, 3.0]

# 等价写法：先 fillna 再普通相加
print((df['A'].fillna(0) + df['B'].fillna(0)).tolist())  # [5.0, 5.0, 3.0]

# inf 不是缺失值，fill_value 无法处理
s = pd.Series([1.0, np.nan])
print(s.div(pd.Series([0.0, 2.0]), fill_value=0).tolist())  # [inf, 0.0]
```

## 解释

普通 + - * / 运算符遇到缺失值会传播 NaN，而灵活算术方法允许通过 fill_value 参数在运算时把缺失值当作指定值处理，避免先 fillna 再运算的两步操作。

## 有什么用

- 两列数据存在空值需要相加/相除时
- 希望一步完成运算与缺失值填充

## 关键要点

- 覆盖 add/sub/mul/div/floordiv/pow/mod 等运算
- 核心参数 fill_value 指定缺失值替代值
- 与 fillna 后再运算效果等价，可任选其一
- 每个方法都有对应的 r 前缀反转版本

## 边界与易混淆

fill_value 只处理参与运算对象中的缺失值，不能处理 inf；inf 需先转为 NaN。

为什么灵活算术方法不能直接解决 inf 问题？::因为 inf 不是缺失值，fill_value 只对 NaN 生效，需先用 use_inf_as_na 把 inf 转为 NaN。


### 补充 · 2026-11-17

运算符 + - * / 无法指定缺失值怎么处理，灵活算术方法把运算变成一个带参数的函数调用，缺失值在计算过程中就被填掉。家族成员与运算符一一对应，换方法名即可换运算，写法统一。

- add / sub / mul / div / floordiv / pow 对应加减乘除、整除、幂
- 每个方法都接受 fill_value 参数，运算时补缺失位置
- 整除 floordiv 只取整数部分，5÷2 得 2 而非 2.5
要求两列相除且缺失值按 0 参与计算，用灵活算术方法怎么写？关键参数叫什么？::data.a.div(data.b, fill_value=0)，关键参数是 fill_value。
floordiv 和 div 对 5÷2 分别返回什么？::div 返回 2.5，floordiv 返回 2（只取整数部分）。
