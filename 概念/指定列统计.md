# 指定列统计

> 别名：列选择后统计、df[['列1','列2']].describe()

**先选取单列或多列再调用统计函数，控制统计范围。**

## 用法
**语法**：`df['列名'].describe()` / `df[['列1', '列2']].describe()`

**参数**：
- `describe()` 本身无必填参数；常用 `include='all'`（含非数值列）、`percentiles=[.25, .5, .75]`（自定义分位点）
- 选列时：单列传字符串 `df['语文']`，多列传列表 `df[['语文', '数学']]`（双层方括号）
- 选列后可接 `mean()`、`sum()`、`count()` 等任意统计函数

**示例**：
```python
import pandas as pd

df = pd.DataFrame({'语文': [88, 92, 75], '数学': [95, 78, 84], '姓名': ['张三', '李四', '王五']})
print(df[['语文', '数学']].describe())
#             语文         数学
# count   3.000000   3.000000
# mean   85.000000  85.666667
# std     8.888194   8.504901
# min    75.000000  78.000000
# 25%    81.500000  81.000000
# 50%    88.000000  84.000000
# 75%    90.000000  89.500000
# max    92.000000  95.000000

print(df['语文'].mean())   # 85.0
```

## 解释

面对几百列的数据表，先选列再统计可以只看关心的字段。单列用 df['列名']，多列用 df[['列1','列2']]。

## 有什么用

- 宽表只统计部分数值列
- 对比指定几列的统计摘要

## 关键要点

- 单列：df['语文'].describe()
- 多列：df[['语文','数学']].describe()
- 多列需双层方括号
- 选列后可接任意统计函数

## 边界与易混淆

列名拼写错误会直接报 KeyError。
