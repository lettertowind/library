# 环比

> 别名：MoM、环比增长、环比增长率

**本期与上一个相邻周期比较的增长指标。**

## 解释

环比衡量相邻周期的变化，如本月对上月、本周对上周。计算时先用 shift(1) 构造上期金额列，再用本期减上期得增长额，除以得上期得增长率。

## 有什么用

- 月度/周度销售趋势分析
- 需要看短期波动的经营指标

## 关键要点

- 环比 = 与上一个相邻周期比
- 环比增长额 = 本期 - 上期
- 环比增长率 = (本期-上期)/上期
- 首期没有上期数据，结果为空

## 边界与易混淆

易与同比混淆：环比看相邻周期，同比看去年同期。

## 自测

3 月环比对应哪个月？同比又对应哪个月？::环比对应 2 月；同比对应去年 3 月。
