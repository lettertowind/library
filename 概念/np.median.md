# np.median

> 别名：median、中位数

**排序后取中间位置的值，偶数个取中间两数平均。**

## 用法
**语法**：`np.median(a, axis=None, out=None, overwrite_input=False, keepdims=False)`
**参数**：
- `a`：输入数组或类数组，即要计算中位数的数据；内部先排序再取中间位置
- `axis`：沿哪个轴计算，默认 `None` 表示先展平再算整体中位数；`axis=0` 按列、`axis=1` 按行
- `out`：可选，用来存放结果的输出数组
- `overwrite_input`：为 `True` 时允许覆盖输入数组以节省内存，此时原数组会被修改
- `keepdims`：为 `True` 时保留被约简的维度，结果在该位置为 1
**示例**：
```python
import numpy as np

a = np.array([1, 2, 3, 3, 3, 4, 5, 6])
print(np.median(a))                # 3.0  偶数个，中间两个 3 平均仍是 3
print(np.median([1, 2, 3, 100]))   # 2.5  极端值 100 不影响中位数

b = np.array([[1, 2, 3], [10, 20, 30]])
print(np.median(b, axis=0))        # [ 5.5 11.  16.5]  按列
print(np.median(b, axis=1))        # [ 2. 20.]         按行
```

## 解释

np.median 先排序再取中间值，因此不受极端值影响。奇数个数据取正中间，偶数个取中间两个的平均。适合收入、房价等偏态分布。

## 有什么用

- 偏态数据的中心水平
- 存在极端值时的稳健统计

## 关键要点

- 必须先排序再取中间
- 奇数个取中间一个，偶数个取中间两个平均
- 对极端值不敏感，比平均数稳健

## 边界与易混淆

中位数不反映整体总量，也不体现多数人选择，后者要用众数。

## 自测

数据 [1,2,3,3,3,4,5,6] 的中位数是多少？::3，排序后中间两个都是 3，平均仍为 3。
中位数为什么比平均数抗极端值？::它只看位置不看数值大小，极端值再大也只占一个位置。


### 补充 · 2026-11-17

中位数不受极端值影响，常用于收入、房价等偏态分布数据的中心位置描述。Pandas 中用 median() 或 describe() 的 50% 行获取。

- 等于 50% 分位数
- 对极端值稳健
- 与均值差距大说明分布偏斜
某公司薪资均值远高于中位数，说明什么？::分布右偏，少数高薪拉高了均值，大多数员工薪资低于均值。

中位数不是直接取数组中间位置的元素，而是必须先排序。奇数个取最中间那个，偶数个取中间两个的平均。由于只看位置不看数值大小，少数极端值不会把它拉偏。

- 必须先排序，再取中间值，排序方向不影响结果
- 奇数个取中间一个，偶数个取中间两个相加除以 2
- 对极端值稳健，是平均数的替代方案
数组有 6 个元素，中位数怎么取？::排序后取第 3、第 4 个元素相加除以 2，而不是直接取任意中间元素。
