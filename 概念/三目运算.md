# 三目运算

> 别名：条件表达式、三元表达式、a if cond else b

**Python 中一行内根据条件返回两个值之一的表达式：a if 条件 else b。**

## 解释

三目运算把 if-else 压缩成表达式，适合在赋值语句里按条件选值。自动填充性别时用它按 i%2 的奇偶直接给出“男”或“女”。

## 有什么用

- 按条件给列赋值
- 循环内简洁地二选一
- 替代简单 if-else 赋值

## 关键要点

- 语法：值1 if 条件 else 值2
- 条件成立取值1，否则取值2
- 可嵌套但可读性会下降
- 适合简单二选一，复杂分支仍用 if-else

## 边界与易混淆

嵌套多层三目运算可读性差，不要滥用。

## 自测

'男' if i % 2 == 0 else '女' 在 i=3 时返回什么？::返回“女”，因为 3%2=1 不为 0，条件不成立走 else 分支。
