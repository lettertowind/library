# .at 索引器

> 别名：at、DataFrame.at、按标签取单值

**按行、列标签精确访问单个单元格值的方法。**

## 用法
**语法**：`DataFrame.at[行标签, 列标签]`；`Series.at[标签]`
**参数**：
- `行标签`：索引标签值（不是位置序号）；MultiIndex 时传元组
- `列标签`：列名；仅 DataFrame 需要
- 返回值：单个标量；也可直接赋值修改该单元格
**示例**：
```python
import pandas as pd

df = pd.DataFrame({'数学': [90, 85], '语文': [88, 92]}, index=['小明', '小红'])
print(df.at['小明', '数学'])   # 90
df.at['小红', '语文'] = 95
print(df.loc['小红', '语文'])  # 95
# df.at['小红', ['语文']] 会报错：.at 只接受单值，不支持列表/切片，切片要用 .loc
```

## 解释

.at[行标签, 列标签] 用于读取或赋值单个标量，比 loc 更快，专为单值访问设计。在只计算指定行的 for 循环中，用它逐格读写。

## 有什么用

- for 循环中逐行计算指定行
- 精确读写单个单元格

## 关键要点

- 语法：数据.at[行标签, 列标签]
- 只用于单值，不支持切片
- 比 loc 单值访问更快
- 配合 for 循环可只算部分行

## 边界与易混淆

只接受标签不接受位置；批量操作应改用整列运算或 loc。

### 补充 · 2026-11-17

数据.at[0, '序号'] 精确落到某行某列，比先切列再切行更快。对已取出的单列 Series，可只写一个位置：数据['序号'].at[i] = i + 1，这是逐格填充的写法。

- DataFrame 上写 .at[行标签, 列名]，Series 上只写 .at[标签]
- 按标签而非位置定位，默认整数索引时下标与标签恰好一致
- 既可读也可写，赋值直接改原数据
把“序号”设为索引后，原来的 数据.at[0,'性别'] 还能取到第一行吗？::不一定，.at 按标签定位，索引变成 1、2…… 后标签 0 就不存在了

数据['单价'].at[1] 取行标签为 1 的单价。它常与 for i in range(起, 止) 搭配，只对指定行做计算，例如只算序号 1、2 两行的金额；跳着算再叠加 if 判断奇数或范围。

- 数据['单价'].at[i] 按行标签取一个值，不是位置序号
- 若用 set_index 把序号设为索引，标签即业务序号
- 常配 for i in range(1, 3) 只遍历前两行
数据['单价'].at[2] 中的 2 指什么？::行标签为 2 的那一行，而不是第二行的位置。
