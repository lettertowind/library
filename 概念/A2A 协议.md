# A2A 协议

> 别名：Agent2Agent、A2A

**谷歌 2025 年 4 月发布的、用于 Agent 与 Agent 之间通信的协议。**

## 解释

A2A 专门规定 Agent 之间的沟通方式。与 MCP 分工明确：MCP 连接 Agent 和工具，A2A 连接 Agent 和 Agent。

## 有什么用

- 多智能体系统中的 Agent 间通信

## 关键要点

- 谷歌 2025 年 4 月发布
- 专用于 Agent 与 Agent 通信
- MCP 连工具，A2A 连 Agent

## 边界与易混淆

不要与 MCP 混淆：两者连接对象不同。
