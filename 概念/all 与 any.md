# all 与 any

> 别名：all()、any()、全真判断、存在真值

**对可迭代对象做「全部为真」或「至少一个为真」的聚合判断。**

## 解释

all 遍历元素，遇到第一个假值立刻返回 False；any 遇到第一个真值立刻返回 True。两者都建立在真值判断之上，常配合生成器表达式做批量条件校验。

## 有什么用

- 投票、勾选等全票/任意票校验
- 批量数据合法性检查
- 判断是否存在满足条件的元素

## 关键要点

- all([]) 为 True，any([]) 为 False，因为空集合的默认结论不同
- 都是短路求值，得出结果就停止遍历
- 直接传生成器表达式，不必先建列表
- NumPy 中对应 np.all / np.any，按轴聚合

## 边界与易混淆

只看真值不看数值大小；对一次性迭代器使用会消耗掉它。

## 自测

all([]) 和 any([]) 分别返回什么？::True 和 False：空集合被认为「没有反例」与「没有正例」。
投票列表 voters=[1,1,0,1]，如何一句判断是否全票通过？::all(voters)，因为存在 0（假值）会立即返回 False。
