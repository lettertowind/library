# 数据合并与重塑

> 别名：merge and reshape、连接查询、数据合并、数据重塑

**把多份数据按行、列或连接键重新组织成一张新表的总称。**

## 解释

学过 SQL 的人会把它对应到“连接查询”。它包含三类操作：按连接键匹配合并（merge）、按索引横向拼接（join）、按行或列直接堆叠拼接（concat），广义上还包括长宽表转换等结构重塑。

## 有什么用

- 多张来源表需要整合成一张分析宽表时
- 把分散在不同文件、不同工作簿的同结构数据汇总时

## 关键要点

- 按连接键匹配用 merge，语义最接近 SQL 的 join
- 按索引横向拼接用 join，行为简单但限制多
- 按行或列直接堆叠用 concat，不涉及键匹配
- 重塑还包括行列转置、长宽表转换等结构层面的调整

## 边界与易混淆

merge/join 负责“横向拼字段”，concat 负责“纵向堆行”，选错工具会出现大量 NaN 或重复行。

## 自测

把三家门店格式相同的销售表上下堆成一张表，属于合并还是重塑？用哪个函数？::属于合并类，用 concat 按行拼接，不需要连接键。
为什么说 merge 比 join 更接近 SQL 的连接语义？::merge 用 on 直接指定两张表共有的列做匹配；join 默认按索引对齐，on 的含义是把右表索引对齐到左表的某一列。
