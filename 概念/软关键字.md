# 软关键字

> 别名：soft keywords、soft keyword

**只在特定语法上下文中当关键字、其他位置可作标识符的关键字。**

## 解释

Python 3.12 的软关键字有 _、case、match、type。它们为模式匹配、类型别名等新语法服务，同时尽量不破坏旧代码命名。滥用会造成可读性下降，如 match match。

## 有什么用

- 理解 match/case 与 type 别名语法
- 判断某个名字能否作变量名

## 关键要点

- 3.12 软关键字：_、case、match、type
- type 自 3.12 起成为软关键字
- 可在非关键字位置作变量名
- 软关键字可读性风险较高
- 普通关键字与软关键字规则不同

## 边界与易混淆

软关键字不是弱关键字，其关键字含义仍严格由语法位置决定。
