# Numpy 多维数组

> 别名：多维数组、ndarray 多维、n 维数组

**以数组为元素的数组，按维度层层嵌套，可表示矩阵乃至更高维数据。**

## 解释

一维数组元素是数字；二维数组元素是一维数组，可理解为矩阵；三维数组元素是二维数组，即「几块几行几列」。维度越高，嵌套越深，但本质都是 ndarray。

## 有什么用

- 表示表格、图像、批量样本等结构化数据
- 理解 shape/ndim/size 等属性的前提

## 关键要点

- 二维数组 = 数组中的数组，可理解为矩阵或行列式
- 三维数组 = 多块二维数组，按「块 × 行 × 列」理解
- 元素总数 size = 各维度长度之积，如 2×3×3=18
- 维度数 ndim 等于 shape 元组的长度

## 边界与易混淆

「下标」与「索引」只是不同教材叫法，本质相同，不要当成两个概念。

### 补充 · 2026-11-17

多维数组不是抽象概念，可以用“块—行—列”的方式理解：形状 (2,3,3) 表示 2 块、每块 3 行 3 列的二维数组。判断几维只需要数 shape 里数字的个数，元素总数则是各维度大小相乘。现阶段不必深究高维索引，先建立“几块、每块几行几列”的空间感即可。

- 三维数组 = 若干块二维数组，shape 第一位是块数
- 维度数 = shape 中数字的个数，(2,3,3) 是三维，(3,3) 是二维
- 元素总数 = 各维度大小相乘，如 2×3×3 = 18
np.zeros((4,3,2)) 是几维数组？一共有多少元素？每个“块”多大？::三维；共 4×3×2 = 24 个元素；每块是 3 行 2 列的二维数组。
看到一个数组的 shape 是 (5,6)，你能确定它是几维、多少元素吗？::二维（shape 里两个数字），元素数 5×6 = 30。

二维数组有行和列两个维度，三维数组则可理解为若干块二维数组叠在一起。维度越高越难用图形直观展示，但在数据结构层面依然可以正常存储和运算。理解多维的关键是记住“维度 = 定位元素所需的下标个数”。

- 三维数组可看作多个二维数组（块）叠起来，每块本身是二维数组
- 如分成 4 块、每块 3 行 2 列的二维数组，整体即为三维
- 四维、五维难以画图，但数据层面仍可表示
一个三维数组，要定位其中某个元素需要几个下标？::三个：块、行、列（或等价的三个维度位置）。
为什么四维、五维数组画不出来却仍然能用？::多维只是 shape 的描述方式，底层仍是一维连续内存，计算不受可视化限制。
