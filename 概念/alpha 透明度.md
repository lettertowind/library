# alpha 透明度

> 别名：alpha、透明度参数、透明度

**控制图形元素不透明程度的参数，取值 0 到 1。**

## 解释

alpha=0 表示完全透明，alpha=1 表示完全不透明。数据点或柱子重叠较多时，降低 alpha 能看清重叠密度，比不透明配色更容易读。它不只用于柱形图，散点、填充区域、文本背景等图形元素都支持。

## 有什么用

- 柱子或散点大量重叠时提升可读性
- 让辅助元素（标注、背景）不喧宾夺主

## 关键要点

- 取值范围 0~1，越接近 0 越透明
- 重叠数据多时用低 alpha 能看出分布密度
- 柱形图、散点图、文本背景等处通用
- 颜色由 color 决定，透明度由 alpha 单独控制

## 边界与易混淆

和颜色本身无关：改 alpha 不改变色相，只改变不透明程度。

两组柱形图想叠在同一位置并同时看清，应该调哪个参数？::alpha，把两组柱子设为半透明即可看到重叠部分。


### 补充 · 2026-11-17

在区域填充和叠加图中，alpha 用来避免上层颜色完全遮住下层内容。取值 0.3 表示 30% 不透明度，多个半透明区域重叠时颜色会叠加混合，类似 Photoshop 两个图层叠加。

- 取值范围 0~1，常用 0.3 这类中间值做区域填充
- 两个 30% 透明度的区域重叠会混出中间色
- 只调整透明度不改变数据，只影响视觉层次
为什么叠加区域图里常用 alpha=0.3 而不是 1？::让下层折线与区域仍可见，重叠处形成层次色；alpha=1 会把下方内容完全遮住。
