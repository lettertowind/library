# 列顺序调整

> 别名：移动列位置、调整列顺序、取列-删列-插列三步法、鸡蛋筐法

**把某列挪到指定位置的三步法：先取出该列，再删除原列，最后用 insert 插回。**

## 用法
**语法**：`DataFrame.insert(loc, column, value, allow_duplicates=<no_default>)`；`DataFrame.drop(labels=None, *, axis=0, index=None, columns=None, level=None, inplace=False, errors='raise')`
**参数**：
- `loc`：插入位置序号，0 表示最前，取值范围为 0 到 `len(df.columns)`，越界会报错。
- `column`：新列名，默认不允许与已有列重名。
- `value`：列数据，可传 Series、数组或标量；三步法中取出的 Series 可直接传入。
- `allow_duplicates`：是否允许重复列名，默认 False，一般不写。
- `labels`：要删除的行标签或列标签；三步法中传原列名。
- `axis`：删除方向，删列写 `axis=1`；现代写法更推荐直接用 `columns=`。
- `columns`：直接指定要删除的列，等价于 `labels=列名, axis=1`。
- `inplace`：是否原地修改，默认 False；`insert` 本身是原地修改，不要写成赋值。
**示例**：
```python
import pandas as pd

df = pd.DataFrame({'姓名': ['张三', '李四'], '总分': [90, 85], '班级': ['一班', '二班']})
print(df.columns.tolist())  # ['姓名', '总分', '班级']

总分 = df['总分']
df = df.drop(columns='总分')  # 旧版也可写 df.drop('总分', axis=1)
df.insert(1, '总分', 总分)
print(df.columns.tolist())  # ['姓名', '总分', '班级']
print(df.to_dict('list'))  # {'姓名': ['张三', '李四'], '总分': [90, 85], '班级': ['一班', '二班']}
```

## 解释

Pandas 没有直接「移动列」的 API，最直观的做法是：结果总分 = df['总分'] 先拿到这一列（相当于复制一颗鸡蛋出来），df.drop('总分', axis=1) 删掉原列，最后 df.insert(0, '总分', 结果总分) 插到目标位置。三步都基于同一份数据，只是列的位置变了。讲师用「鸡蛋筐」比喻这三步，便于记忆。

## 有什么用

- merge 后把匹配来的列放到期望的列位置
- 整理导出的报表列顺序

## 关键要点

- 第一步取列会得到一个 Series，插入时可直接作为列数据
- 删除原列必须带 axis=1，否则会按行删除并报错
- insert 的第一个参数是目标列序号，0 表示插到最前面
- insert 是原地修改，不要写成 结果 = 结果.insert(...)
- 插入位置越界会报错，取 0 到 len(df.columns) 之间的值

## 边界与易混淆

三步法只改变列的位置，不改变列名与数据；若只是想重排全部列，直接 df[['列1','列2',...]] 一次性重选更简洁。
