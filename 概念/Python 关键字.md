# Python 关键字

> 别名：keyword、保留字、Python keywords

**Python 中具有特殊语法含义、不能随便用作标识符的单词。**

## 解释

Python 3.12 共 35 个普通关键字和 4 个软关键字。普通关键字是保留字，不能作变量名；软关键字只在特定语法位置生效。理解关键字体系有助于读语法、避免命名冲突。

## 有什么用

- 判断变量名是否合法
- 系统学习 Python 语法结构

## 关键要点

- 3.12 有 35 个普通关键字
- 另有 4 个软关键字：_、case、match、type
- 普通关键字不可作变量名
- 软关键字可兼作标识符
- 版本差异：type 在 3.12 才成为软关键字

## 边界与易混淆

关键字列表随 Python 版本变化，旧资料可能少 type、match、case。
