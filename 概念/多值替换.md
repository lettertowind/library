# 多值替换

> 别名：列表替换、字典替换、批量值映射

**用列表或字典一次把多个旧值替换成对应新值的写法。**

## 用法
**语法**：`Series.replace(to_replace=None, value=None, inplace=False)`
**参数**：
- `to_replace`：要替换的旧值，可传标量、列表或字典（字典时 value 可省略）
- `value`：新值，列表方式下与 `to_replace` 按位置一一对应；传单个标量表示多旧值映射同一新值
- `inplace`：是否原地修改，默认 `False` 返回新对象
**示例**：
```python
import pandas as pd

data = pd.DataFrame({'等级': ['a', 'b', 'c', 'a']})

# 列表方式：新旧列表按位置对应
print(data['等级'].replace(['a', 'b'], [20, 30]).tolist())
# [20, 30, 'c', 20]

# 字典方式：映射清晰，推荐
print(data['等级'].replace({'a': 20, 'b': 30}).tolist())
# [20, 30, 'c', 20]

# 多旧值映射同一新值
print(data['等级'].replace(['a', 'b'], 30).tolist())
# [30, 30, 'c', 30]
```

## 解释

replace 支持传入旧值列表与新值列表（按位置一一对应），或传入字典（key 为旧值、value 为新值）。列表适合多旧值映射同一新值，字典适合不同旧值映射不同新值。

## 有什么用

- 一列中多个分类值批量改成新值
- 编码映射（如 a→20、b→30）

## 关键要点

- 列表方式：replace(['a','b'], [20,30]) 按位置对应
- 字典方式：replace({'a':20,'b':30}) 映射清晰，推荐
- 多旧值映射同一新值：replace(['a','b'], 30) 更简洁
- 列表方式值多时容易写错顺序，可读性差

## 边界与易混淆

列表方式要求新旧列表长度和顺序严格对应，否则映射错乱。

一次将多个旧值按映射关系替换为新值的操作

- 列表方式：旧值列表与替换值列表按位置一一对应。
