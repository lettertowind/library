# 轴转置

> 别名：轴转置、transpose 轴顺序、轴顺序重排

**通过向 transpose 传入新的轴顺序元组，重新排列数组各轴的位置。**

## 用法
**语法**：`ndarray.transpose(*axes)` 或 `numpy.transpose(a, axes=None)`
**参数**：
- `axes`：新轴顺序，通常传入元组，如 `(1,0)`、`(2,0,1)`；必须是原轴编号的一个排列
- 不传 `axes`：默认反转轴顺序，二维时等价于 `arr.T`
- `a`：`numpy.transpose` 的输入数组
**示例**：
```python
import numpy as np

a = np.arange(24).reshape(4, 6)
b = a.transpose((1, 0))
print(a.shape)  # (4, 6)
print(b.shape)  # (6, 4)
print(b[0, 0])  # 0
print(b[0, 1])  # 6

c = np.arange(16).reshape(2, 2, 4)
d = c.transpose((2, 0, 1))
print(d.shape)  # (4, 2, 2)
```

## 解释

原轴顺序可看作元组 (0,1) 或 (0,1,2)，传入新顺序元组即可按新顺序重排轴。二维数组将 (0,1) 改为 (1,0) 即行列转置；三维数组可改为任意轴顺序。

## 有什么用

- 高维数组调整轴顺序
- 二维数组行列互换的底层实现

## 关键要点

- 原轴顺序是元组，如 (0,1) 或 (0,1,2)
- 传入新轴顺序元组即可重排轴
- 二维数组 (0,1)→(1,0) 即行列转置
- 三维数组可按需改变轴排列，如 (2,0,1)

## 边界与易混淆

轴转置只改变轴的排列顺序，不改变元素值；传入的轴顺序必须是原轴编号的一个排列。

## 自测

对三维数组，transpose((2,0,1)) 表示什么？::表示新数组的 0 轴对应原 2 轴，1 轴对应原 0 轴，2 轴对应原 1 轴。
轴转置和 arr.T 对二维数组的结果有何关系？::对二维数组，轴转置 (1,0) 与 arr.T 效果一致。


### 补充 · 2026-11-17

轴转置的核心是给出新的轴排列顺序，例如二维数组原轴顺序 (0, 1) 改为 (1, 0) 就实现行列互换。二维时它与直接转置结果相同，但轴转置能明确指定多维数组的维度顺序。

- 参数是目标轴顺序，如二维传入 (1, 0)。
- 二维 transpose(1, 0) 与 arr.T 结果相同。
- 多维可指定任意轴排列，如三维 (2, 0, 1)。
三维数组原轴顺序为 (0, 1, 2)，想变成 (2, 0, 1)，应传入什么轴顺序？::传入 (2, 0, 1)，即调用类似 arr.transpose(2, 0, 1)。
二维数组上轴转置和直接转置有什么区别？::二维上结果相同；区别在于轴转置显式指定轴顺序，更适合推广到多维数组。
