# 多条件组合

> 别名：复合条件、按位与或、& | 组合条件

**用 & 表示且、| 表示或，把多个布尔条件组合成一个掩码。**

## 用法

**语法**：`(cond1) & (cond2)` 或 `(cond1) | (cond2)`，其中 `cond1`、`cond2` 这两个条件表达式分别用括号括起来；组合后生成一个布尔掩码，再传给 `arr[mask]` 进行筛选

**参数**：
- 左操作数：任意一个逐元素比较表达式，例如 `arr % 2 == 0`，必须用小括号括起来
- 右操作数：另一个逐元素比较表达式，例如 `arr < 7`，同样必须用小括号括起来
- `&`：表示“且”，两个条件的对应结果都为 True，结果才为 True
- `|`：表示“或”，只要任一条件的对应结果为 True，结果就为 True
- 注意：`&`、`|` 是按位运算符，如果直接作用于整数数组，会得到按位结果，而不是逻辑结果，所以两侧必须是布尔数组

**示例**：
```python
import numpy as np

arr = np.arange(10)
mask = (arr % 2 == 0) | (arr < 7)   # 偶数 或 小于7
print(mask)
# [ True  True  True  True  True  True  True False  True False]
print(arr[mask])
# [0 1 2 3 4 5 6 8]

print(arr[(arr % 2 == 0) & (arr < 7)])   # 偶数 且 小于7
# [0 2 4 6]
```

## 解释

Numpy 中多条件不能直接用 Python 的 and/or，要用按位运算符 & 和 |，并且每个条件要加括号避免优先级错误。例如 (arr % 2 == 0) | (arr < 7)。

## 有什么用

- 筛选满足任一条件的元素
- 筛选同时满足多个条件的元素

## 关键要点

- 且用 &，或用 |
- 不要用 Python 的 and / or
- 每个条件加括号，防止优先级错误
- 示例：(arr % 2 == 0) | (arr < 7)

## 边界与易混淆

& 和 | 是按位运算符，对布尔数组逐元素运算；对整数数组直接使用会得到按位结果而非逻辑结果。
