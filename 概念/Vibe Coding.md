# Vibe Coding

> 别名：氛围编程、vibe coding

**用自然语言描述需求、让 Agent 写代码并运行修改的编程方式。**

## 解释

Vibe Coding 让不懂编程的人用自然语言描述功能，由 Agent 编写、运行、修改代码，人只看结果提意见。它大幅降低做软件门槛，但稳定可靠的产品仍需懂代码的人把关。

## 有什么用

- 非程序员快速做出原型
- 用自然语言驱动 Agent 写代码

## 关键要点

- Andrej Karpathy 2025 年 2 月提出
- 被柯林斯词典选为 2025 年度词汇
- 降低门槛，但可靠产品仍需懂代码的人把关

## 边界与易混淆

适合原型和轻量需求，不等于可以完全不懂代码做生产级产品。
