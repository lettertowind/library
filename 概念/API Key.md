# API Key

> 别名：密钥、API 密钥

**调用 API 时用来识别身份和计费的密钥，相当于账号密码。**

## 解释

API Key 标识调用者身份并用于计费，一旦泄露他人可冒用你的额度。它必须保密，不能写进公开代码或分享。

## 有什么用

- 程序调用模型 API 时做身份认证
- 按调用者计费

## 关键要点

- 用于识别身份和计费
- 相当于账号密码，不能泄露
- 费用按实际 Token 用量结算

API Key 泄露会有什么后果？::他人可冒用你的身份调用 API，费用记在你账上。
