# Numpy 二维数组双索引

> 别名：行列配对索引、c[[行],[列]]、逗号前是行逗号后是列

**用两个整数数组分别指定行和列，按位置一一配对取元素。**

## 用法
**语法**：`c[行索引数组, 列索引数组]`
**参数**：
- `行索引数组` 逗号前的整数索引序列（list 或 np.array），指定要取的行号
- `列索引数组` 逗号后的整数索引序列，指定要取的列号
- 两个索引数组长度必须一致，第 i 个行号与第 i 个列号配成一个坐标，返回一维数组
- 若只写一个索引数组 `c[[1,5]]`，则默认取这些行的全部列
**示例**：
```python
import numpy as np

c = np.arange(32).reshape(8, 4)   # 8 行 4 列，值为 0~31
print(c[[1, 5, 7, 2], [0, 3, 1, 2]])
# [ 4 23 29 10]   即 (1,0)=4、(5,3)=23、(7,1)=29、(2,2)=10
print(c[[1, 5, 7, 2], [0, 3, 1, 2]].shape)
# (4,)            只取 4 个散点，不是 4×4 的子矩阵
print(c[[1, 5]])   # 只给行索引，取整行
# [[ 4  5  6  7]
#  [20 21 22 23]]
```

## 解释

在二维数组中写 c[行索引数组, 列索引数组]，Numpy 会把第 i 个行下标与第 i 个列下标配成坐标取一个元素，结果是一维数组。它取的是若干散点，而不是行与列的笛卡尔积子矩阵。

## 有什么用

- 按坐标批量抽取二维数组中的散点
- 从表格中取指定行列交叉处的值

## 关键要点

- 逗号前是行索引，逗号后是列索引
- 两个索引数组长度应一致，按位置配对
- 结果不是笛卡尔积，不构成子矩阵
- 只给一个索引数组时默认取整行

## 边界与易混淆

易与“行索引 × 列索引的笛卡尔积”混淆；要取子矩阵应使用切片或 ix_。

### 补充 · 2026-11-17

当行索引和列索引都是数组时，NumPy 按位置配对取值，结果形状与索引数组一致。它是实现「按行排序后回取元素」等操作的基础，常与 argsort 搭配。

- m[rows, cols] 中两个索引数组按位置一一配对
- rows 常用 np.arange(m.shape[0])[:, None] 构造成列向量
- 索引数组形状需可广播，否则会报错或取错
m[rows, idx] 中 rows 为什么要写成 (n, 1) 的列向量形式？::为了让行索引与 argsort 返回的 (n, k) 索引数组按广播规则配对，保证取到的是同一行的元素。
二维 argsort 的结果能像一维那样直接用 m[idx] 取排序值吗？::不能，会按行取整行而不是按位置配对，必须同时提供行索引数组。

逗号前是行索引数组，逗号后是列索引数组，第 i 个行索引与第 i 个列索引配成一个坐标，取该坐标上的单个元素。结果是一维数组，长度等于索引数组长度，而不是行列组合出的矩阵。

- 逗号前为行索引，逗号后为列索引，与基础索引理解一致
- 配对规则：第 1 个行配第 1 个列，第 2 个配第 2 个
- 两个索引数组长度需相同，否则报错
arr = np.arange(32).reshape(8,4)，arr[[1,5,7,2],[0,3,1,2]] 的结果是什么？::array([4, 23, 29, 10])，即 arr[1,0]、arr[5,3]、arr[7,1]、arr[2,2] 按顺序配对取到的值
