# 地板除与取余（ 与 %）

> 别名：//、%、整除与取模、floor division 与 modulo

**// 求向下取整的商，% 求余数，两者配合把总量拆成“进位”和“余量”。**

## 解释

处理月份累加这类问题时，30 // 12 = 2 直接得到整年数，30 % 12 = 6 得到剩余月数，一步拆清进位与余数，不用写一堆 if。

## 有什么用

- 月份/时间进位换算
- 奇偶判断（i % 2）做交替填充

## 关键要点

- a == (a // b) * b + a % b 恒成立，可用来验算
- 对正数 // 就是去掉小数部分，对负数则是向下取整
- i % 2 == 0 判偶数，是做“男/女”交替填充的常用写法
- 先用 // 求整进位、再用 % 求余，是进位逻辑的通用套路

## 边界与易混淆

负数场景下 // 与 int() 截断结果不同，容易算错，别混用。
