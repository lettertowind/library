# 降序排序

> 别名：argsort 取负、np.argsort(-x)、倒序排列

**把数组元素取负后再调用 argsort，使最大值排到最前，从而得到从大到小的排列。**

## 用法
**语法**：`x[np.argsort(-x)]`
**参数**：
- `x`：要降序排列的一维或多维数值型数组，必须支持取负运算（int、float 等），字符串数组不适用
- `-x`：取负后，原最大值变成最小值，`argsort` 返回的升序索引即原数组的降序顺序
- `np.argsort(...)`：返回从小到大排序后的原下标数组，默认使用快速排序
- `[::-1]`：非数值数组的替代方案，即 `x[np.argsort(x)[::-1]]`，直接反转升序索引

**示例**：
```python
import numpy as np

x = np.array([3, 1, 7, 5])
print(np.argsort(-x))      # [2 3 0 1]
print(x[np.argsort(-x)])   # [7 5 3 1]

# 非数值数组改用索引反转
s = np.array(['b', 'd', 'a'])
print(s[np.argsort(s)[::-1]])  # ['d' 'b' 'a']
```

## 解释

argsort 本身只提供升序，取负后原来的最大值变成最小值，升序索引就等价于原数组的降序顺序；再用该索引回取原数组即可。这是 NumPy 中最常用的降序技巧。

## 有什么用

- 需要从大到小排列数值时
- 排行榜、Top-N 取值等场景

## 关键要点

- x[np.argsort(-x)] 一步得到降序数组
- 原理是取负改变了元素间的大小关系，索引顺序自然反转
- 只适用于数值型数组，字符串无法取负
- 也可用 np.argsort(x)[::-1] 反转索引，但取负法更直观

## 边界与易混淆

非数值数组不能取负；此时改用索引反转。
