# API

> 别名：应用程序编程接口、Application Programming Interface

**软件与软件之间互相调用的通道。**

## 解释

API 让一个程序把请求发给另一个程序并拿回结果。调用大模型 API 时，程序把输入发给模型、取回输出，全程自动完成，按 Token 用量计费。

## 有什么用

- 程序化调用大模型
- 把 AI 能力集成进自己的应用

## 关键要点

- 是给程序用的接口，不是给人用的产品
- 按实际使用的 Token 计费，用多少付多少
- 网页版/App、会员订阅、API 是三种不同使用方式

## 边界与易混淆

API 与 MCP 不同：API 是各软件自己的接口，格式各异；MCP 统一了 AI 连接工具的方式。
