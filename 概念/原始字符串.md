# 原始字符串

> 别名：raw string、r 前缀字符串、r'' 写法

**加 r 前缀的字符串字面量，其中的反斜杠不再触发转义。**

## 解释

Windows 路径满是反斜杠，普通字符串里 \n、\t、\U 会被解释成转义序列，导致路径读不出来甚至报错。写成 r'C:\pandas读取文件.xlsx' 就能原样保留每个字符。

## 有什么用

- 书写 Windows 文件路径
- 书写正则表达式

## 关键要点

- 前缀 r 或 R，如 r'C:\data\a.xlsx'
- 反斜杠不再被解析为 \n、\t、\U 等转义
- 替代方案：写双反斜杠或直接改用正斜杠
- 末尾不能以奇数个反斜杠结尾

## 边界与易混淆

原始字符串不能以单个反斜杠结尾，这种路径要改用正斜杠或双反斜杠。

## 自测

路径字符串 'C:\pandas\x01.xlsx' 为什么可能出错，加 r 前缀后就好了？::普通字符串里 \x01 会被当作十六进制转义解析，加 r 后反斜杠原样保留。
