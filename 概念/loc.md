# loc

> 别名：df.loc、标签索引

**按行、列标签查询 DataFrame 元素的索引器。**

## 用法
**语法**：`df.loc[行标签, 列标签]`
**参数**：
- `行标签`：单个标签、标签列表或标签切片；切片包含结束标签，如 `df.loc["A":"B"]`
- `列标签`：写法同行标签，传列表时结果按列表顺序排列；省略则取全部列
- `布尔序列`：行位置传布尔 Series 做条件筛选，如 `df.loc[df["语文"] > 85]`
**示例**：
```python
import pandas as pd

df = pd.DataFrame(
    {"语文": [90, 85, 88], "数学": [95, 92, 78]},
    index=["A", "B", "C"],
)
print(df.loc["A", "语文"])  # 90
print(df.loc["A":"B", ["数学", "语文"]])
#    数学  语文
# A  95  90
# B  92  85
print(df.loc["B":, "数学"].tolist())  # [92, 78]
```

## 解释

loc 使用行列的标签（名称）定位数据，语法为 df.loc[行标签, 列标签]。它不关心数据在内存中的位置，只认索引标签，因此设置自定义索引后仍可用原标签查询。

## 有什么用

- 按行名/列名精确取数
- 按标签切片取多行多列

## 关键要点

- 语法 df.loc[行标签, 列标签]
- 标签可以是默认 0,1,2 或自定义索引
- 切片时通常包含结束标签（与 iloc 不同）
- 单行查询返回 Series

## 边界与易混淆

易与 iloc 混淆：loc 认标签，iloc 认位置；索引被重置后原标签可能失效。

loc 和 iloc 最本质的区别是什么？::loc 按标签（名称）定位，iloc 按从 0 开始的整数位置定位。


### 补充 · 2026-11-17

loc 是 Pandas 中基于标签的索引方式，行和列都写标签名而不是位置数字。它既能做精确查询，也能做范围切片和条件筛选，还能配合条件赋值新建列。

- loc 后必须用中括号 []，不能写小括号
- 行、列都可用列表传入多个标签，顺序按列表显示
- 范围切片用英文冒号，列范围按原表列顺序排列
df.loc['1983-10-27', ['语文','数学']] 返回什么？::返回该日期这一行中语文和数学两列的数据，列顺序按列表写的顺序。
为什么用日期做 loc 查询前要先 set_index('出生日期')？::因为 loc 按行标签定位，只有把日期设为索引，日期字符串才能作为行标签被查到。

loc 用标签（不是位置）定位，方括号里逗号前是行、逗号后是列。行或列位置写冒号表示「全都要」，写列表表示「只要这几项」。在 merge 场景里最常见的用法是 df.loc[:, ['学号','总分']]，即所有行、只留两列，用来裁剪参与合并的右表。

- 冒号 : 表示该维度全选，loc[:, [...]] 即所有行的指定列
- 列选择传列表返回 DataFrame，传单个字符串返回 Series
- loc 按标签，iloc 按位置，两者不要混用
df.loc[:, ['学号','总分']] 中的冒号代表什么？::代表行维度全选，即保留所有行。
loc 和 iloc 在切片上的关键差异是什么？::loc 的切片包含右端点（按标签），iloc 的切片不包含右端点（按位置）。

loc 是 Pandas 中基于标签（而不是位置）的取数入口：第一个参数定位行，第二个参数定位列。行和列都可以传单个标签、标签列表或标签区间，因此一套写法能覆盖单值查询、多列查询和区间切片。它还支持在条件定位后进行赋值，是 Pandas 里最常用的取数工具。

- 语法为 df.loc[行标签, 列标签]，必须用中括号，不能用小括号
- 行列传列表可取多行多列，列顺序由列表决定，可任意排列
- 传 '开始':'结束' 做标签区间切片，包含两端
为什么 df.loc['1983-10-27':'1990-12-31', '语文':'英语'] 中列的顺序不能自己调整成「英语、数学、语文」？::冒号切片是标签区间，按数据中列的实际存储顺序截取；要自定义列顺序必须改用标签列表 ['英语','数学','语文']。
df.loc[条件] 与 df.loc[条件, :] 结果一样，为什么说后者才是完整写法？::loc 的设计是两个参数：行和列。省略第二参数只是默认取全部列，显式写 : 表达「所有列」，语义完整且不易误解。

loc[行标签, 列标签] 用行列的名字定位数据，是唯一能同时指定行和列的直观写法。必须用中括号。标签切片时包含结束标签，这是与 iloc 最关键的行为差异。

- 写法固定为 df.loc[行, 列]，如 df.loc[0, 'a']
- df.loc[1] 只给行时返回一行 Series
- 标签切片包含结束标签，loc[0:3] 取到 0、1、2、3 四行
把 index 改成 ['A','B','C'] 后，取第一行第一列用 loc 怎么写？::df.loc['A', 'a']
df.loc[0:3] 与 df.iloc[0:3] 各返回多少行？::loc 是标签闭区间，返回 0~3 共 4 行；iloc 的位置切片不含结束位，返回 0、1、2 共 3 行

loc 完全基于标签定位，不认位置序号。多层行索引时，一个元组(

- 多层行索引定位写元组，如 data.loc[("一班", "a")]
- 列方向取全部可以写冒号 :
- 行内层取全部不能写 :，要用 slice(None)
在两层行索引中取「一班」下的所有行、所有列，怎么写？::data.loc[("一班", slice(None)), :]，内层不能直接用冒号。
