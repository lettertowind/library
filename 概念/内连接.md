# 内连接

> 别名：inner join、inner、交集连接

**只保留两表连接键都存在的行，结果等于两表键的交集。**

## 解释

SQL join 和 pandas merge 都支持的连接方式，也是 merge 的默认方式。它按共有字段把两张表对齐，键只在一侧出现的记录会被直接丢弃。对多端左表做匹配时，右表的值会被重复带出，所以结果行数可能多于任一单表。

## 有什么用

- 按 id、姓名等共有字段匹配两表数据
- 只关心两表都有的记录时

## 关键要点

- merge 不写 how 时默认就是内连接
- 只保留连接键在两表中都出现的行，非共有键的行被丢弃
- 左表一个键匹配右表多行时，结果按匹配数展开
- 同名共有列做内连接时 on 与 how='inner' 都可省略

## 边界与易混淆

与左连接的区别在于是否保留左表独有记录：内连接直接丢弃，左连接保留并填 NaN。

## 自测

左表 6 行、右表 3 行，按姓名做内连接，结果一定是 6 行吗？::不一定。不匹配的左表行会被丢弃，一对多匹配又会增加行数，结果行数由匹配关系决定。
什么情况下 pd.merge(a, b) 与 pd.merge(a, b, on='姓名', how='inner') 结果完全相同？::两表存在同名共有列、且连接方式为内连接时——这两者恰好是默认行为，因此结果一致。
