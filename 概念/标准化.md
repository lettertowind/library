# 标准化

> 别名：z-score、Z 标准化、Standardization

**用（x−均值）/标准差把不同量纲的数据变换到同一尺度。**

## 解释

标准化消除量纲差异，使单价和销量这类不可比的字段能放在一起分析。公式为 z=(x−μ)/σ，通常沿 0 轴对每个特征分别处理。

## 有什么用

- 多特征量纲统一
- 后续聚类、回归等建模前的预处理

## 关键要点

- 公式为 (x−均值)/标准差
- 沿 0 轴对每个特征分别标准化
- 消除量纲，使特征可比

## 边界与易混淆

标准化不改变分布形状，非正态数据未必适用；对异常值也敏感。
