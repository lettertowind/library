# 内省（dir 与 help）

> 别名：dir()、help()、introspection、自省

**在运行时查看对象的属性、方法与文档的能力。**

## 解释

dir 列出对象可用的名称（模块的成员、类型和实例的属性方法），help 打印文档字符串与函数签名。二者是探索陌生库最快的方式，比翻文档更快定位要用的函数。

## 有什么用

- 探索第三方库有哪些接口
- 查函数参数与用法说明
- 查看自己写的函数的文档

## 关键要点

- dir() 无参时返回当前作用域的名称列表
- help() 进入交互式帮助，按 q 退出
- 函数下方第一段字符串即文档字符串，会被 help 展示
- IDE 的悬停提示与 help 用的是同一份文档

## 边界与易混淆

dir 只给名称不解释用途；对无文档字符串的对象 help 信息非常有限。

## 自测

想快速知道某模块里有哪些函数，用什么？::dir(模块) 列出名称，再 help(名称) 看具体文档。
为什么写函数时值得加文档字符串？::help() 和 IDE 提示都直接读取它，是给别人和自己看的第一手说明。
