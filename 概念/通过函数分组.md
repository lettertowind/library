# 通过函数分组

> 别名：groupby(len)、函数作为分组键、函数分组

**把函数作为 groupby 的分组键，对索引值逐个调用函数并按返回值分组。**

## 用法

**语法**：`DataFrame.groupby(by=None, level=None, sort=True)`

**参数**：
- `by`：分组键；传入函数时，会对每个索引值逐个调用该函数，并按函数的返回值分组（函数作用于索引值而非列值）
- `level`：按多级索引的指定层级分组；用函数分组时一般不用
- `sort`：是否对分组键排序，默认 `True`

**示例**：
```python
import pandas as pd

df = pd.DataFrame({"销售额": [100, 200, 50, 80]},
                  index=["北京", "乌鲁木齐", "上海", "广州"])
print(df.groupby(len)["销售额"].sum())   # 按城市名长度分组
# 2    230
# 4    200
# Name: 销售额, dtype: int64
```

## 解释

groupby(len) 会按索引字符串长度分组，效果类似把连续值离散分箱。也可把函数与列表组合成多条件分组。视频明确说这属于了解性内容，实际工作不常用。

## 有什么用

- 按名称长度等派生规则分组
- 函数 + 列表做多条件分组
- 理解分组键的灵活性

## 关键要点

- 前提是把分组依据设为索引，如 index_col='城市'
- df.groupby(len).sum() 按城市名长度分组
- 可组合：df.groupby([len, s1]).sum()
- 思路类似连续值离散分箱
- 不常用，基础阶段了解即可

## 边界与易混淆

函数作用于索引值而非列值；函数返回值种类过多时分组会碎片化，结果难解读。

## 自测

df.groupby(len).sum() 中 len 作用在什么上？::作用在索引值上，按索引字符串长度分组。
函数分组和 pd.cut 分箱的共同思路是什么？::都是把原始值按规则映射到类别再汇总。


### 补充 · 2026-11-17

例如 groupby(len) 按索引标签长度分组。函数作用在索引上，所以必须先把目标字段设为索引，否则结果会不符合预期。

- groupby(len) 通常按索引标签长度分组
- 分组字段必须先 set_index 或 index_col 设为索引
- 可与列表组合多个条件，如 groupby([len, s1])
直接对含城市普通列的 DataFrame 写 groupby(len)，len 作用在什么上？::作用在索引标签上；若城市只是普通列，需先设为索引。
