# 分组对象复用

> 别名：保存 groupby 对象、复用分组结果

**先把 groupby 结果存为变量，再多次调用不同聚合函数，避免重复分组。**

## 用法
**语法**：`g = df.groupby(by)` → `g.sum()` / `g.mean()` / `g.agg([...])`
**参数**：
- `by`：分组依据，列名、列名列表、Series 或数组均可；多列用列表传入
- 分组对象本身无参数，聚合方法沿用各函数自己的参数，如 `mean(numeric_only=True)`
- `agg(func)`：一次传入多个函数名列表，等价于多次调用聚合方法，但只分组一次
**示例**：
```python
import pandas as pd

df = pd.DataFrame({
    "city": ["北京", "北京", "上海", "上海"],
    "sales": [10, 20, 30, 40],
})

g = df.groupby("city")          # 先保存分组对象
print(g.sum())                  # 复用：求和
print(g.mean())                 # 复用：求均值
print(g.agg(["sum", "mean"]))   # 等价写法，一次输出多种统计量
# 输出（sum）:      sales
# city
# 上海        70
# 北京        30
# 输出（mean）:     sales
# city
# 上海        35
# 北京        15
```
> 注：分组对象依赖原数据，修改 `df` 后需重新 `groupby`。

## 解释

如果只求和，直接 .sum() 即可；若还要平均、中位数等多种聚合，先 g = df.groupby(...) 保存分组对象，再分别 g.sum()、g.mean()，可省去重复分组的开销。

## 有什么用

- 同一分组做多种统计
- 提升多次聚合的效率
- 让代码结构更清晰

## 关键要点

- 单一聚合直接链式调用 .sum()
- 多种聚合先保存分组对象再分别调用
- 避免对同一数据反复 groupby
- 可配合 agg 一次输出多种统计量

## 边界与易混淆

分组对象依赖原数据，原 DataFrame 被修改后复用可能得到非预期结果。
