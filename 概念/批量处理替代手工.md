# 批量处理替代手工

> 别名：自动化处理、for 循环批处理

**用代码循环和条件判断替代在 Excel 中重复手工操作的做法。**

## 解释

单张表手工新建更快，但当表数量多、需要循环和条件判断时，代码效率远高于复制粘贴。这是学习 Pandas 等工具的根本动机，也是 VBA 与 Python 共同的自动化思路。

## 有什么用

- 上百张表的合并、拆分、条件处理
- 重复性报表生成

## 关键要点

- 单表手工更快，多表代码更快
- for 循环配合 if 可处理大量表
- 手工复制粘贴易错且不可复用
- 基础操作看似没必要，实为自动化前提

## 边界与易混淆

一次性、极少量任务用代码反而增加成本。

只有一张表要新建，用 Python 一定比手动好吗？::不一定，单表手动可能更快；代码优势体现在多表、循环和条件判断场景。
