# 展平顺序

> 别名：行优先顺序、C order、flatten 顺序、展平索引

**二维数组按行优先逐行读成一维时的元素排列次序。**

## 解释

NumPy 中很多聚合函数（argmax、cumsum、cumprod）在不指定 axis 时，会先把二维数组按行优先展平成一维再计算。因此返回的是展平后的位置序号，而不是行列坐标，需要自己换算。

## 有什么用

- 理解二维数组 argmax / cumsum 的返回值
- 把展平下标还原成行列坐标

## 关键要点

- 行优先：先第一行从左到右，再第二行，依此类推
- 二维 argmax 返回展平下标，用 divmod(idx, 列数) 还原行列
- 展平后 cumsum / cumprod 的结果是一维数组，形状不再与原来一致
- 与指定 axis 的聚合成对比：指定轴时结果保留另一维

## 边界与易混淆

一旦指定 axis，就沿该轴计算，不再展平，返回结果的形状也随之改变。

## 自测

对一个 3 行 4 列的数组求 argmax 得到 7，这个最大值在第几行第几列（从 0 开始）？::第 1 行第 3 列：7 // 4 = 1，7 % 4 = 3。
为什么二维数组的 cumsum 结果长度是 12 而不是 3×4？::因为它先按行优先展平成一维再累计，返回的是一维数组。
