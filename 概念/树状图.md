# 树状图

> 别名：Treemap、矩形树图、矩形树状图

**用矩形面积大小表示各类别数值大小的分类数据图表。**

## 解释

树状图把整体拆成若干矩形块，每块面积与其代表的数值成正比，颜色和标签用来区分类别。它能在一屏内同时表达“有哪些类别”和“量级对比、占比构成”，比饼图更能容纳较多类别。

## 有什么用

- 展示各分类的销售额、销量与占比构成
- 展示层级数据中母公司、子品牌的构成比例

## 关键要点

- 矩形面积编码数值大小，标签和颜色编码类别
- 类别过多时块内文字拥挤，需要调字号、边框和配色
- 适合看占比与量级对比，不适合看时间趋势
- Python 画静态图用 squarify，Power BI 版支持交互下钻

## 边界与易混淆

面积相近时人眼难以精确区分大小；无法表达数值的精确差异和变化过程，需要精确对比时应改用条形图。
