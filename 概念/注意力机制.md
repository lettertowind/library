# 注意力机制

> 别名：Attention、attention mechanism

**预测当前 Token 时回头评估前文各 Token 相关性并重点参考的机制。**

## 解释

注意力机制是 Transformer 的核心。预测下一个 Token 时，模型会回头看前面所有 Token，判断哪些和当前最相关并重点参考。例如读到「她」时，注意力会集中在「小红」上。

## 有什么用

- 理解模型如何利用上下文
- 解释长文本中信息定位问题

## 关键要点

- 对前文所有 Token 计算相关性
- 相关性高的 Token 权重更大
- 是 Transformer 的核心组件

## 边界与易混淆

上下文越长，中间部分获得的注意力越弱，关键信息放开头或结尾更易被利用。

## 关联

## 自测

为什么关键信息放在长上下文中间容易被忽略？::注意力对中间部分的关注较弱，开头和结尾的信息更容易被模型用上。
