# 布尔数组求和计数

> 别名：(a>3).sum()、条件计数、True 计数

**对布尔数组求和，利用 True=1、False=0 统计满足条件的元素个数。**

## 用法
**语法**：`(条件).sum(axis=None, dtype=None, keepdims=False)`
**参数**：
- `axis`：指定沿哪个轴求和；默认 `None` 统计整个数组，传 `0` 或 `1` 可按列或按行计数
- `dtype`：指定累加结果的类型；布尔数组默认会累加成整数
- `keepdims`：是否保留被求和的维度，默认为 `False`
**示例**：
```python
import numpy as np

a = np.array([[1, 5, 2], [7, 3, 9]])

print((a > 3).sum())             # 3
print((a > 3).sum(axis=0))       # [1 1 1]
print((a > 3).sum(axis=1))       # [1 2]
print(np.sum(a > 3, axis=0))     # [1 1 1]，等价写法
```

## 解释

比较运算先生成布尔数组，再对其调用 sum，就把计数问题转成了求和问题。这是 NumPy 里统计满足条件元素个数的标准写法。

## 有什么用

- 统计数组中大于某阈值的元素个数
- 统计满足任意条件的元素数量

## 关键要点

- 写法为 (条件).sum()
- 依赖 True=1、False=0 的隐式转换
- 等价于对指示函数求和
- 比 Python 循环计数快得多

## 边界与易混淆

统计的是元素个数；若要按轴统计需传 axis。
