# 分组柱状图

> 别名：Grouped Bar Chart、并排柱状图、多系列柱状图、plt.bar 多次调用

**把多组数据以并排柱子画在同一类别位置上的柱状图，用于跨组对比。**

## 解释

每个类别下不是一根柱子，而是每组数据各一根，并排显示。实现方式是多次调用 plt.bar()，每条柱子的 x 坐标依次偏移一个柱宽；因此 x 必须是数值索引而非字符串类别名。

## 有什么用

- 多个年份/多个产品的同一指标横向对比
- 展示变化趋势与组间差距（如今年 vs 去年）

## 关键要点

- 有 N 组数据就调用 N 次 plt.bar()，第 n 条柱的 x 偏移 n×width
- x 用 np.arange(len(df)) 生成数值索引，字符串无法直接加 width
- 柱宽抽成变量 width（如 0.3），改一处即可全局生效，避免硬编码
- 每次 bar 各写 label，最后必须调用 plt.legend() 才显示图例
- 多年数据通常按最近一年降序排序，历史年份只作参考

## 边界与易混淆

组数或类别过多时并排柱会拥挤难读，可改用折线图或热力图；类别名较长时更适合横向条形图。

## 自测

为什么第二条柱子的 x 不能写成 df['姓名'] + width？::姓名是字符串，字符串不能与数值 width 相加，必须先用 np.arange 生成数值索引再偏移。
分组柱状图里把柱宽写成 0.3 而不是变量 width，会带来什么麻烦？::x 偏移、刻度等多处都要同步改动，容易漏改导致柱子位置错位。
