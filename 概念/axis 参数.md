# axis 参数

> 别名：axis、轴、轴向

**指定聚合运算沿哪个方向进行的参数，0 轴为行，1 轴为列。**

## 解释

axis 决定 sum、mean、max 等函数是跨行汇总还是行内汇总。0 轴代表行方向，跨行按位置相加得到每列结果；1 轴代表列方向，行内横向相加得到每行结果。

## 有什么用

- 控制按行或按列聚合
- 理解二维数组统计结果形状

## 关键要点

- 0 轴代表行，1 轴代表列
- axis=0 跨行汇总，结果长度等于列数
- axis=1 行内汇总，结果长度等于行数
- 不指定 axis 时通常对全部元素运算

## 边界与易混淆

“0 轴是行”指汇总方向沿行，不是结果按行排列，初学最容易记反。

## 关联

- [[np.sum]] — 组合使用
- [[np.mean]] — 组合使用

## 自测

np.sum(A, axis=1) 的结果长度等于行数还是列数？::等于行数，因为每行内部汇总得到一个值。
为什么说 axis=0 的结果看起来像每列的和？::因为跨行按位置相加，每个位置对应一列。


### 补充 · 2026-11-17

轴的数量等于数组维度数：一维数组只有 0 轴，二维数组有 0 轴（行）和 1 轴（列），三维数组有 0 轴（块）、1 轴（行）、2 轴（列）。理解轴的关键是先看数组维度，再看索引顺序。

- 轴编号从 0 开始，与 shape 元组索引对应
- 一维数组只有 0 轴；二维数组 0 轴为行、1 轴为列
- 三维数组 0 轴为块、1 轴为行、2 轴为列
一个 shape 为 (4, 3, 2) 的三维数组，1 轴对应什么方向？::1 轴对应每块内部的行方向，即三行。
为什么说轴编号与 shape 元组索引一一对应？::因为 shape 元组中第 i 个元素表示第 i 个轴的长度，轴编号就是元组索引。

在 Pandas 中行索引对应 0 轴、列名对应 1 轴。apply 等函数用 axis 决定把每一列还是每一行作为整体传入。理解 axis 是掌握 DataFrame 聚合与行级计算的前提。

- 行标签是 0 轴，列标签是 1 轴
- axis=0 对每列执行，axis=1 对每行执行
- axis=0 不是把一行横向相加
df.apply(sum, axis=0) 得到的是什么？::每一列的和，即按列向下汇总。
行索引和列名分别对应哪个轴？::行索引对应 0 轴，列名对应 1 轴。

axis 决定函数作用的方向。在 DataFrame.apply 中，axis=0（默认）把每一列当作一个 Series 处理，axis=1 把每一行当作一个 Series 处理。记忆口诀：零轴看列，一轴看行。

- axis=0 按列操作（默认）
- axis=1 按行操作
- 对列计算通常不用改轴，对行计算必须 axis=1
想对 DataFrame 的每一行套函数，axis 应设多少？::axis=1。
为什么说“零轴看列，一轴看行”？::axis=0 时函数把每列当一个 Series 处理，axis=1 时把每行当一个 Series 处理。

在排序中，axis=0（默认）表示按列值对行排序；axis=1 表示按行值对列排序。按行或行索引排序时必须设为 1。

- 默认 axis=0，按列值排行
- axis=1 时按行值排序列顺序
- 按行索引排序时 by 写行索引名并设 axis=1
想按某一行索引对列顺序排序，axis 要设成多少？::axis=1
