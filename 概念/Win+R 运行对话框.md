# Win+R 运行对话框

> 别名：运行窗口、Windows + R、运行命令框

**Windows 中按 Win+R 唤出的快速启动框，输入程序名即可打开对应程序。**

## 解释

它是 Windows 自带的程序快速启动入口，比在开始菜单里找图标更快。输入 cmd、notepad、calc 等系统可识别的程序名，回车即可运行。在本课中它是打开命令行窗口的前置步骤。

## 有什么用

- 快速打开命令行、记事本等系统程序
- 避免在开始菜单逐层查找

## 关键要点

- 快捷键为 Windows 键 + R，弹出「运行」对话框
- 输入 cmd 后点确定即可打开命令行窗口
- 输入的是程序名或命令名，不是文件完整路径时依赖系统 PATH 查找
- 打不开时多半是键盘 Win 键被锁定或被系统策略禁用

## 边界与易混淆

它只是启动入口，不负责安装或配置；能启动什么取决于系统已注册的命令与 PATH。

## 自测

为什么在「运行」框里输入 cmd 就能打开命令行，而输入某个未注册的软件名却打不开？::因为运行框按系统 PATH 中的可执行程序查找，cmd 位于系统目录已在 PATH 中，未注册的程序找不到。
