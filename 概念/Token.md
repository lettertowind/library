# Token

> 别名：词元、词块

**模型处理文字时的最小单位，由分词器切分并映射为词表编号。**

## 解释

模型只能处理数字，文字进入模型前要先经分词器切成小块，每块对应词表里的一个编号，这一小块就是 Token。切分方式从大量文本统计而来，常见词可能一块就够，生僻字可能被拆成多块。

## 有什么用

- 理解模型计费方式
- 估算上下文容量和生成速度
- 解释 AI 在字符级任务上的失误

## 关键要点

- 一个 Token 不一定等于一个字
- 词表通常有十几万个 Token
- 价格、速度、上下文容量都按 Token 计算
- 输出 Token 通常比输入 Token 更贵
- DeepSeek 换算：1 个中文字符约 0.6 Token

## 边界与易混淆

不同模型分词器不同，汉字与 Token 的换算比例没有统一答案。

## 自测

为什么 AI 常答错 strawberry 里有几个 r？::模型看到的是几个 Token 而不是单个字母，它无法直接访问字符级信息。
为什么输出 Token 比输入 Token 贵会影响使用策略？::因为生成内容越多成本越高，长回答、深度思考都会显著增加费用。
