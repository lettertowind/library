# 多键分组

> 别名：列表分组键、groupby 多列、多级分组

**把多个 Series 或列名放进列表传给 groupby，按组合键形成多级分组。**


## 用法
**语法**：`df.groupby([key1, key2, ...])`
**参数**：
- `by`：分组键的列表，元素可以是列名、Series 或布尔序列，顺序即 MultiIndex 的层级顺序
- `as_index`：默认为 True，分组键成为结果的行索引；设为 False 则还原为普通列
- `sort`：默认为 True，对分组键排序
- `dropna`：默认为 True，键中含 NaN 的行会被丢弃

**示例**：
```python
import pandas as pd

df = pd.DataFrame({
    '时间': pd.to_datetime(['2020-01-05 09:00', '2020-01-05 21:00',
                          '2020-02-06 09:00', '2020-02-06 21:00']),
    '数学': [80, 90, 70, 85],
})
# 键的顺序决定层级：年在外、月在里
r = df.groupby([df['时间'].dt.year, df['时间'].dt.month])[['数学']].sum()
print(r)
#             数学
# 时间 时间
# 2020 1      170
#      2      155
print(type(r.index).__name__)   # MultiIndex
print(r.loc[(2020, 2), '数学'])  # 155
```

## 解释

当需要按「年+月」「姓+名第二字」这类组合维度统计时，把多个键放进列表即可。结果索引是 MultiIndex，可逐层下钻查看。

## 有什么用

- 按年月统计
- 按年+小时统计销售
- 按姓名首字+第二字细分

## 关键要点

- df.groupby([df['时间'].dt.year, df['时间'].dt.month]) 形成年月两级索引
- 键可以是列名、Series 或布尔序列的混合
- 结果索引为 MultiIndex，可用 loc 逐层取数
- 键的顺序决定索引层级顺序

## 边界与易混淆

键越多结果越稀疏；切片写法 [1:2] 不能直接生成两个独立分组键。

### 补充 · 2026-11-17

当单一维度不够细时，把多个 Series 装进列表传给 groupby，就会按它们的组合分组，结果呈现为层次化索引。例如同时按姓氏首字和第二个字分组，或同时按年份和小时分组统计。

- 语法是把多个键放进列表：groupby([key1, key2])。
- 结果索引是多层索引，可用 reset_index 还原成普通列。
- 键的先后顺序决定层次顺序，靠前的在外层。
groupby([df['时间'].dt.year, df['时间'].dt.hour]) 得到的结果索引有几层？::两层，先年、后小时。
