# 零一化

> 别名：0-1 化、二值化、binaryzation

**按条件把数组元素统一转成 0 或 1 的二值处理。**

## 用法

**语法**：`arr[arr > 阈值] = 1`；`arr[arr <= 阈值] = 0`（两步布尔索引赋值，非函数调用）

**参数**：
- `arr`：待处理的 numpy 数组，原地修改
- 阈值：比较用的临界值，按需替换
- 第一步的条件 `arr > 阈值`：决定哪些位置置 1
- 第二步的条件 `arr <= 阈值`：必须与第一步互补，覆盖剩余全部位置，否则会漏改

**示例**：
```python
import numpy as np

arr = np.array([1, 3, 5, 6, 8, 9])
arr[arr > 5] = 1   # 大于 5 的置 1
arr[arr <= 5] = 0  # 其余置 0
print(arr)  # 输出 [0 0 0 1 1 1]
print(np.unique(arr))  # 输出 [0 1]，结果只含 0 和 1
```

## 解释

零一化用布尔索引分两步赋值：满足条件的设为 1，不满足的设为 0。常用于数据分析中把连续值转成二值标记，后续实例题会反复用到。

## 有什么用

- 把大于阈值的元素标为 1、其余为 0
- 数据预处理中的二值标记

## 关键要点

- 写法：arr[arr > 5] = 1; arr[arr <= 5] = 0
- 本质是两次条件赋值
- 结果只含 0 和 1 两种值
- 数据分析实例中常用作预处理

## 边界与易混淆

两步赋值顺序要注意：先设 1 再设 0 时，第二步条件要覆盖剩余位置，否则可能漏改。

### 补充 · 2026-11-17

用两条条件赋值即可完成：满足低值条件的置 0，满足高值条件的置 1。结果数组中只剩 0 和 1，便于后续做计数、标记或作为模型输入特征。

- 典型写法：arr[arr <= 5] = 0 与 arr[arr > 5] = 1
- 边界要闭合无遗漏：<=5 归 0，>5 归 1，正好覆盖全部元素
- 两条语句有先后顺序，先置 0 再置 1 不影响结果
要把大于 5 的变 1、其余变 0，如果只写 arr[arr > 5] = 1 会有什么问题？::只有大于 5 的位置被改成 1，其余位置仍是原来的数字，没有变成 0，还需要再补一条 arr[arr <= 5] = 0。
