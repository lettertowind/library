# 雷达图首尾闭合

> 别名：首尾闭合、闭合处理、闭合雷达图、close the loop

**把序列首项追加到末尾，使雷达图折线首尾相接成环的处理。**

## 解释

极坐标折线按数据点顺序连接，默认不会回到起点，画出来是开口的。需要给角度、分数、科目三个序列的末尾各追加自己的第一项，且三者长度保持一致，才能围成完整的多边形。

## 有什么用

- 绘制雷达图前准备数据
- 任何需要闭合轮廓的极坐标绘图

## 关键要点

- 用 np.concatenate((arr, [arr[0]])) 把首项接到末尾
- 角度、分数、科目三个序列都要闭合，且长度必须相同
- 读取数据时设 index_col='姓名'，才能用 a02[0] 稳定取到本人第一项
- 也可用 Python 列表拼接或切片实现，np.concatenate 只是顺带练习 NumPy

## 边界与易混淆

只适用于环形/闭合图形；普通折线图不需闭合，闭合后反而多出一条回连的首段。
