# 大小写转换方法

> 别名：lower、upper、title、capitalize、swapcase

**一组把字符串按不同规则转换大小写的字符串方法。**

## 用法
**语法**：`Series.str.lower()`、`Series.str.upper()`、`Series.str.title()`、`Series.str.capitalize()`、`Series.str.swapcase()`

**参数**：均无参数（Series.str 访问器方法，逐元素作用于字符串）。
- `lower()`：全部转小写
- `upper()`：全部转大写
- `title()`：每个单词首字母大写，其余小写
- `capitalize()`：仅整段首字符大写，其余小写
- `swapcase()`：大小写互换

**示例**：
```python
import pandas as pd

s = pd.Series(['hello world', 'Python 数据分析'])
print(s.str.title().tolist())       # ['Hello World', 'Python 数据分析']
print(s.str.capitalize().tolist())  # ['Hello world', 'Python 数据分析']
print(s.str.upper().tolist())       # ['HELLO WORLD', 'PYTHON 数据分析']
print(s.str.swapcase().tolist())    # ['HELLO WORLD', 'pYTHON 数据分析']
```

## 解释

lower/upper 整体转小写/大写；title 把每个单词首字母大写；capitalize 只把整段首字符大写并把其余转小写；swapcase 大小写互换。

## 有什么用

- 统一文本大小写便于匹配
- 格式化标题

## 关键要点

- title 处理每个单词首字母
- capitalize 只处理整段首字符
- swapcase 大小写互换
- lower/upper 整体转换

## 边界与易混淆

title 与 capitalize 最易混淆：前者按单词，后者按整段。
