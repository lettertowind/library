# API 中转站

> 别名：中转站、API 代理

**第三方转卖官方 API 的服务，价格通常更低但有风险。**

## 解释

中转站把官方 API 转卖给用户，价格常更低。但你无法确认它背后真正调用的是不是你所选的模型，且你发送的所有内容都会经过它的服务器。

## 有什么用

- 低成本获取模型 API 调用

## 关键要点

- 价格通常低于官方
- 无法确认背后真实调用的模型
- 所有发送内容都经过第三方服务器

## 边界与易混淆

涉及敏感数据时不宜使用中转站。
