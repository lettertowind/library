# 任务

帮我从零安装一套个人知识工作流。最终效果：

```
我把手机上的 B站 分享链接发给你
        ↓
你下载字幕/转写 → 大模型整理成笔记
        ↓
从笔记里拆出概念卡片，写进我的 Obsidian 知识库
        ↓
生成静态网站，推送到 GitHub Pages
        ↓
我在手机上打开网址就能看，并复习卡片
```

安装完成后，我应该只需要发链接，剩下的全部由你完成。

# 工作方式（必须遵守）

1. **先探测再动手**。逐项检查本机已有什么，已存在的不要重复安装或覆盖。
2. **分阶段推进**。每个阶段结束必须验证通过，再进入下一阶段。失败就停下报告，不要带着错误往下装。
3. **区分执行权**。凡是需要我本人操作的事（建仓库、开 Pages、填密钥、授权登录），不要假装你能代劳。明确列出步骤，等我确认完成后再继续。
4. **不要泄露凭证**。任何 API Key、Cookie、Token 都不能写进会被提交到 Git 的文件，也不能出现在日志里。写配置前先确认该文件在 `.gitignore` 中。
5. **路径要写成绝对路径**。这个项目大量脚本依赖固定路径，相对路径会出各种诡异问题。

在动手前，一次性问清楚：

1. **GitHub 用户名**，以及打算用的**仓库名**。提醒我：GitHub 免费账户的私有仓库不支持 Pages，所以这个仓库必须是 Public；仓库内容会被所有人看到。

# 阶段 2：部署 BiliNote（源码方式）

项目：<https://github.com/JefferyHcool/BiliNote>

## 2.1 克隆

GitHub 直连可能有证书吊销检查问题，克隆时加参数：

```bash
git -c http.sslVerify=false -c http.schannelCheckRevoke=false clone --depth 1 https://github.com/JefferyHcool/BiliNote.git
```

## 2.2 后端

```bash
cd BiliNote/backend
python -m venv .venv
./.venv/Scripts/python -m pip install --upgrade pip -r requirements.txt
```

注意：

- 如果 pip 卡在代理上，用 `env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy ...` 清除代理变量再装。
- 国内镜像源（清华等）在部分机器上拿不到索引，这时换官方源 `-i https://pypi.org/simple`。
- 启动若报 `ModuleNotFoundError: No module named 'pkg_resources'`，是 setuptools 新版移除了它，降级到 `setuptools<81`。

## 2.3 前端

```bash
cd BiliNote/BillNote_frontend
pnpm install
```

如果报 `ERR_PNPM_IGNORED_BUILDS`，补一个 `.npmrc`：

```
onlyBuiltDependencies[]=esbuild
onlyBuiltDependencies[]=core-js
```

然后 `pnpm rebuild esbuild`，用 `./node_modules/.bin/vite --version` 验证。

## 2.4 配置 `.env`

根目录和 `backend/` 各放一份 `.env`（从 `.env.example` 复制）。关键项：

```
NOTE_OUTPUT_DIR=<知识库路径>/_在编
HF_ENDPOINT=https://hf-mirror.com
FFMPEG_BIN_PATH=<ffmpeg 可执行文件所在目录>
```

**`FFMPEG_BIN_PATH` 必须是目录，不是 exe 路径。** 填错会在下载后报 `unable to obtain file audio codec with ffprobe`。

如果系统没装 ffmpeg，Windows 上可用 `winget install Gyan.FFmpeg`，然后到 `C:\Users\<用户>\AppData\Local\Microsoft\WinGet\Packages\` 下找到 bin 目录。

## 2.5 whisper 模型（可选但建议）

默认从 huggingface.co 下载，国内常被 TLS 挡。更稳的做法：

1. 从 `https://hf-mirror.com/Systran/faster-whisper-tiny/resolve/main/` 下载 `model.bin`、`tokenizer.json`、`vocabulary.txt`、`config.json`
2. 放到 `BiliNote/backend/models/whisper/faster-whisper-tiny/`
3. 在 `BiliNote/backend/config/whisper_models.json` 把它注册成本地路径（参考项目里的格式）

注意：`.env` 是在程序启动后才加载的，`huggingface_hub` 在 import 阶段就固定了地址，所以写 `HF_ENDPOINT` 到 `.env` 往往不生效。上面的本地文件法最可靠。

## 2.6 启动脚本

写三个 bat，都用**纯 ASCII 内容**（中文注释在 GBK 环境会被错误解析，把后面的 `set` 语句截断）：

- `start_bilinote.bat`：设镜像变量 → 调起下面两个子脚本 → 延时开浏览器
- `backend_run.bat`：跑 `main.py`，末尾 `pause`，崩了能看到报错
- `frontend_run.bat`：跑 `pnpm dev`，末尾 `pause`

本机实测发现这台机器的 cmd 不认 `start /D` 语法，所以采用「主脚本调两个子脚本名」的写法，不要用 `start /D`。

## 2.7 启动验证

```bash
curl http://127.0.0.1:8483/api/sys_health
```

必须看到 `backend ok`、`ffmpeg ok`、`db ok` 才算通过。

## 2.8 大模型配置

在 BiliNote 界面里，或者数据库 `BiliNote/backend/bili_note.db` 的 `providers` 表里，配置一个可用的供应商。

**DeepSeek 的 `base_url` 必须是 `https://api.deepseek.com/v1`**。写成 `platform.deepseek.com` 会被 Cloudflare 拦截，返回 "Request Blocked"。

需要我提供 API Key，我不会自己生成。配完后用 `curl` 带这个 key 请求 `/v1/models` 验证返回 200。

# 阶段 3：（可选）编译桌面版

如果我希望有独立窗口而不是浏览器，走这一步。纯网页形态也可以跳过。

1. 装 Rust：`rustup-init`，用 `rsproxy.cn` 镜像，target 选 `x86_64-pc-windows-msvc`
2. 配置 `~/.cargo/config.toml` 的 crates 镜像
3. 用 PyInstaller 把后端打包成 sidecar：

```bash
./.venv/Scripts/pyinstaller.exe --name BiliNoteBackend --paths . \
  --distpath ../BillNote_frontend/src-tauri/bin --workpath build \
  --add-data "app/db/builtin_providers.json;." --add-data ".env;." main.py
```

4. 产物重命名为 `BiliNoteBackend-x86_64-pc-windows-msvc.exe`
5. `pnpm tauri build --no-bundle`
6. `--no-bundle` 不会自动复制 sidecar，手动把 bin 目录内容复制到 `src-tauri/target/release/`
7. Tauri 运行时找的是**不带 triple 后缀**的名字，所以还要复制一份 `BiliNoteBackend.exe`
8. PyInstaller 打包后模型目录变成 `%APPDATA%\BiliNote\models\whisper`，把模型复制过去，并在 `desktop/config/whisper_models.json` 注册成本地路径
9. 整理出干净的 `desktop/` 目录：`BiliNote.exe`、`BiliNoteBackend.exe`、`_internal/`、`config/`。`_internal` 不能删也不能拆

# 阶段 4：建立知识库

位置用阶段 0 确认的路径，例如 `D:\知识库`。

## 4.1 目录

```
知识库/
  AGENTS.md          规则中枢，任何 Agent 打开这个库都会先读它
  概念/              概念卡片，一张一页，平铺
  分析/              问答沉淀、综述
  MOC/               领域地图，自动生成
  _在编/             BiliNote 输出落点
  _典藏/             原始素材按月归档
  _废弃/             下架或合并掉的卡片
  _馆务/             所有脚本、配置、日志
  首页.md / 概念索引.md
```

## 4.2 卡片格式（这是整套系统的契约，不要随意改）

概念卡 frontmatter 固定七字段：

```
term / aliases / kind / domain / tags / created / updated
```

`aliases` 和 `tags` 是**行内列表** `[a, b]`，要能处理 `["AGENTS.md", agent.md, 别名]` 这种混合引号写法。

正文固定七个小节，顺序固定：

```
## 解释 → ## 有什么用 → ## 关键要点 → ## 边界与易混淆 → ## 关联 → ## 自测 → ## 出处
```

`## 自测` 里每行是 `问题::答案`，这是 Obsidian 间隔重复插件的语法，网站要渲染成可展开的折叠块。

`## 关联` 里每行是 `- [[概念名]] — 关系`，关系词固定五种：上位概念、下位概念、前置知识、对比项、组合使用。

## 4.3 需要的脚本（放在 `_馆务/`）

按职责实现，细节可参考现成实现：<https://github.com/lettertowind/library> 的 `_馆务/` 目录。可以直接读取里面的源码作为模板，把路径和账号换成我的。

| 脚本 | 职责 | 要点 |
|---|---|---|
| `curator.py` | 从 `_在编` 的笔记抽概念、写卡片 | 同一概念再出现时只在旧卡末尾追加 `### 补充 · 日期`；支持 `--dry-run`；同名匹配顺序：文件名 → term → aliases |
| `maintain.py` | 体检/合并/下架/问答/综述/重建索引 | 体检只出报告不改库；合并要把 `[[旧名]]` 全库改成 `[[主名]]`；下架是移到 `_废弃` 不是物理删除 |
| `watcher.py` | 后台监听 `_在编`，新文件静止 25 秒自动处理 | 每 7 天自动生成一次体检报告，只报告不改 |
| `site.py` | 生成静态网站到 `docs/` | 见阶段 5 |
| `sync.py` | git 提交并推送 | 无改动时不提交；推送失败要给出明确原因 |
| `pipeline.py` | 串起整条链路 | 见阶段 6 |

配置放在 `_馆务/config.json`，同时提供 `config.example.json` 模板。**`config.json` 必须写进 `.gitignore`**，因为它含 API Key。

## 4.4 AGENTS.md

写在库根，内容至少包括：目录职责、卡片格式契约、四个标准操作（摄入/体检/问答/合并下架）、硬性规则、禁止事项、脚本清单。关键规则：

- 双链可以指向不存在的卡片，允许待建链接
- 同名即合并，匹配顺序：文件名 → term → aliases
- 一个概念一张卡，观点和论述写进要点，不单独建卡
- 不要在 `首页.md`、`概念索引.md`、`MOC/` 里手写内容，会被脚本覆盖

## 4.5 Obsidian 插件

在 `.obsidian/plugins/` 下装两个：

- `obsidian-spaced-repetition`：复习卡片
- `obsidian-shellcommands`：在 Obsidian 内触发脚本

GitHub 直连下载通常不通，用 `https://ghfast.top/https://github.com/...` 镜像。

在 `.obsidian/community-plugins.json` 里启用它们。

## 4.6 索引

由脚本生成 `首页.md`、`概念索引.md`、`MOC/*.md`。**不要手改**，它们会被覆盖。

# 阶段 5：GitHub Pages 网站

## 5.1 网站生成器 `site.py`

技术选型：**纯标准库 Python**，不引任何第三方包。理由：卡片只用得到标题、列表、加粗、引用、段落、双链、`::` 六种语法，手写渲染器即可完全覆盖，且不会因为某个 venv 坏了导致发布链路断掉。

输出到 `docs/`：

```
docs/
  index.html        首页：搜索框、领域卡、最近更新、全部概念
  c/<概念名>.html   概念卡页
  a/<分析名>.html   分析页
  d/<领域>.html     领域页
  assets/style.css  样式，单文件，手机优先
  assets/app.js     搜索 + 暗色切换
  search.json       本地搜索索引
  .nojekyll
```

必须处理的几个坑：

1. **链接解析五级**：文件名 stem → term → alias → MOC stem → 根目录 md stem。典型陷阱：`[[AGENTS.md]]` 指向的是 `概念/AGENTS规范.md`（靠 alias），`[[AGENTS]]` 指向根目录 `AGENTS.md`，`[[知识管理]]` 指向 `MOC/知识管理.md`。未命中渲染成灰色待建链接，不要 404
2. **磁盘文件名保留中文**，链接里用百分号编码。不要转拼音，会破坏与双链的一致性
3. **代码块和行内代码里的 `[[...]]` 不能被当双链解析**。实现时先把行内代码替换成占位符，最后再还原
4. **按 `## ` 切分章节时要跳过围栏代码块内部**，否则 AGENTS.md 里的卡片模板会被当成真标题
5. **`### 补充 · 日期`** 当前可能没有，但二次摄入必然出现，渲染器现在就要支持 H3
6. **CSS/JS 要加内容哈希版本号**（`style.css?v=xxxx`），否则 GitHub Pages 的 10 分钟缓存会让你更新样式后看不到变化
7. 页脚显示精确到分钟的更新时间，方便判断是否看到旧版本

自检要求：遍历所有页面里的内部链接，逐个核对目标文件存在；统计双链断链数，必须为 0。

# 阶段 6：打通链路 `pipeline.py`

这是核心。输入一个 B站 手机分享链接，输出是更新好的网站。

## 6.1 步骤

1. 从分享文本里提取链接，还原成 `https://www.bilibili.com/video/BVxxx`。要支持 `b23.tv` 短链（跟随重定向）、`m.bilibili.com` 手机版、带 `?share_source=` 等参数的文本
2. 检查 BiliNote 后端是否在跑；没跑就自动拉起源码后端（用 `DETACHED_PROCESS`，不依赖桌面窗口），最多等 2 分钟
3. `POST /api/generate_note`，参数：`video_url`、`platform: "bilibili"`、`quality: "fast"`、`link: true`、`model_name`、`provider_id`、`style: "detailed"`、`format: []`、`extras: ""`
4. 轮询 `GET /api/task_status/{task_id}`，状态枚举：`PENDING/PARSING/DOWNLOADING/TRANSCRIBING/SUMMARIZING/FORMATTING/SAVING/SUCCESS/FAILED`。失败要把 message 显示出来，不要只说「失败」
5. 任务成功后从 `_在编` 找到新生成的 markdown
6. 依次跑 `curator.py` → `site.py` → `sync.py`
7. 最后告诉我网站地址，并提示约 30 秒后生效

## 6.2 参数

支持 `--dry-run`（只解析链接和检查环境）、`--note-only`（只生成笔记）、`--no-publish`（不推 GitHub）、`--model xxx`。

再写一个 `处理链接.bat`，让我可以双击后粘贴链接。

| 症状 | 根因 | 解法 |
|---|---|---|
| `CRYPT_E_NO_REVOCATION_CHECK` | 本机证书吊销检查失败 | git 加 `http.sslVerify=false`；curl 加 `--ssl-revoke-best-effort` |
| pip 装不上包 | 代理干扰或镜像源索引缺失 | 清代理变量，换官方 PyPI |
| `No module named 'pkg_resources'` | setuptools ≥81 移除该模块 | 降到 `<81` |
| `ERR_PNPM_IGNORED_BUILDS` | pnpm 拦截 esbuild 构建脚本 | `.npmrc` 声明 `onlyBuiltDependencies` |
| `Request Blocked` HTML | base_url 用了 `platform.deepseek.com` | 改成 `api.deepseek.com/v1` |
| `unable to obtain file audio codec with ffprobe` | `FFMPEG_BIN_PATH` 没填或填成了 exe 路径 | 填 ffmpeg 所在的**目录** |
| whisper 模型下载失败 | `.env` 加载晚于 huggingface_hub 的 import | 用镜像手动下载到本地路径并注册 |
| 桌面版报 `os error 2` | Tauri 找的是不带 triple 后缀的 sidecar 名 | 补一份 `BiliNoteBackend.exe` |
| 桌面版提示模型未下载 | PyInstaller 后模型目录变成 `%APPDATA%` | 复制模型过去并写 `config/whisper_models.json` |
| bat 报 `'n' 不是内部或外部命令` | 中文注释在 GBK 下被误解析 | bat 内容全部改成纯 ASCII |
| `start /D` 报语法不正确 | 某些机器 cmd 不支持 | 拆成独立子脚本，主脚本按名字调用 |
| 站点所有 CSS/JS 404 | 全局前缀设置时机晚于正文渲染 | 在渲染每页之前设置前缀，不要只在 `page()` 里设 |
| 文件名变成 `%E7%AC%AC...html` | 把 URL 编码当成了磁盘文件名 | 磁盘用中文名，只有 href 用编码 |
| 代码块里的 `[[示例]]` 变成链接 | 没识别围栏代码块与行内代码 | 先保护行内代码；切章节时跳过代码块 |
| 手机看到旧内容 | GitHub Pages 的 HTML 缓存 600 秒 | 下拉刷新；CSS/JS 加版本号；页脚显示更新时间 |
