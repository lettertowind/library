# Python 关键字系统笔记

## 摘要

本笔记依据视频内容，系统整理 Python 3.12 中的关键字体系。材料指出，Python 3.12 中共有 39 个关键字相关项，包括 35 个普通关键字与 4 个软关键字（soft keywords）。软关键字在特定语法上下文中具有关键字含义，在其他上下文中仍可作为变量名或标识符使用。

版本差异需注意：

- Python 3.12 之前，`type` 不被视为软关键字，因此相关统计会少一个。
- `case` 与 `match` 属于较新版本引入的语法，旧版本可能不存在。
- 普通关键字不可用作变量名；软关键字可同时作为变量名和语法关键字使用。

## 一、普通关键字

### 1. 常量与布尔逻辑

- **False**：布尔假值，是 Python 的两个布尔状态之一。其底层整数常量为 0，即 \(False \equiv 0\)。示例：`has_money = False`，打印 `False`，打印 `int(False)` 得到 `0`。

- **None**：表示值的缺失。函数无返回值、数据库查询无结果、可选值未设置时常见。示例：`selected_user = None`。判断值是否为 `None` 时，推荐使用 `is None` 或 `is not None`，而不是直接使用值比较。

- **True**：布尔真值，其底层整数常量为 1，即 \(True \equiv 1\)。示例：`has_money = True`。由于 `True` 是整数 1 的常量表示，`True + True` 的结果为 \(2\)。

- **and**：逻辑与。仅当两个或多个条件均为真时，整体条件成立。示例：`c > b and c > a`；注册条件示例：姓名长度大于 0 且年龄大于 18。

- **or**：逻辑或。只要任一条件为真，整体条件成立。示例：`c > a or a == b`。若 `c > a` 为真，即使 `a == b` 为假，表达式仍为真。

- **not**：逻辑非。可用于否定布尔表达式或成员检查。示例：`bob not in names`；可选值判断中常写作 `if selected_user is not None:`。

### 2. 别名、断言与异步

- **as**：为模块、函数、对象或上下文管理器起别名。示例：`import math as m`；`from random import randint as ri`；`with open("text.txt") as file:`。使用别名可简化引用。

- **assert**：断言，用于声明程序继续执行前必须满足的条件。若条件不成立，则抛出 `AssertionError`。示例：断言数据库对象存在；断言 `n < limit`。断言适用于内部前置条件检查，不宜替代正式的用户输入验证与异常处理。

- **async**：定义异步函数或异步上下文。示例：`async def main():`。异步函数需要在事件循环中运行，通常结合 `asyncio` 使用。

- **await**：在异步函数中等待可等待对象完成并获取结果。示例：创建多个异步任务后，在打印结果前 `await` 这些任务，以确保结果已生成。

### 3. 控制流

- **break**：提前退出当前循环。示例：`for i in range(10): if i == 5: break`，循环在 `i == 5` 时终止，因此输出不会超过 4。

- **continue**：跳过当前迭代中剩余代码，直接进入下一次迭代。示例：遍历姓名列表，遇到 `bob` 时 `continue`，因此不会对 `bob` 执行后续的问候打印。

- **elif**：即 `else if`，用于多分支条件判断的中间层。示例：根据天气是否为雨天、阴天、晴天等分别执行不同分支。

- **else**：当 `if`/`elif` 条件均不满足时执行，也可与异常处理、循环等结构配合。示例：天气条件均不匹配时输出默认信息。

- **for**：用于遍历可迭代对象。示例：`for element in elements:`，对列表中的每个元素执行代码块。

- **if**：根据布尔表达式结果决定是否执行代码块。示例：`if age > 100:`，条件为真时执行分支。

- **while**：条件循环。示例：模拟连接过程，每轮打印已连接秒数并递增 `i`，当 `i == 3` 时断开连接；也可用 `while True` 创建无限循环，但需设计退出条件。

### 4. 类、函数、作用域与生成器

- **class**：定义类，提供对象的蓝图。示例：`class Person:`，类中可定义姓名等属性与行为。

- **def**：定义函数。示例：`def get_time():`。函数名后跟参数列表，函数体缩进定义。

- **del**：删除对象引用。示例：`name = 10`，随后 `del name`，再次引用 `name` 会触发 `NameError`。`del` 删除的是名称绑定，而非必然立即释放底层对象。

- **global**：在函数或类中声明引用全局命名空间中的变量。示例：全局定义 `name = "bob"`，函数内使用 `global name` 后将其改为 `"james"`，调用函数后全局 `name` 变为 `"james"`。应谨慎使用，避免隐式修改全局状态。

- **lambda**：创建匿名函数。示例：`lambda x: x * 2`。常见于高阶函数参数中，可避免为一次性逻辑单独定义函数。示例：对列表 `[1, 2, 3, 4]` 中每个元素应用乘以 2 的 lambda，得到翻倍结果。

- **nonlocal**：在嵌套函数中声明引用外层函数的局部变量。示例：外层函数定义 `item = "candle"`，内层函数使用 `nonlocal item` 后可修改外层变量。与 `global` 的区别在于作用域层级不同。应谨慎使用。

- **return**：从函数中返回值。示例：`return datetime.now().strftime(...)` 返回当前日期时间字符串。Python 函数默认返回 `None`，即使未显式写出 `return`。

- **yield**：创建生成器。生成器函数通过 `yield` 逐个产生值。示例：生成限制范围内的数字；使用 `next()` 逐个取值；生成器是耗尽的，已产生的值会从生成器中消失，剩余值可用 `list()` 收集。

### 5. 异常处理

- **except**：捕获异常并处理。示例：`except ValueError as e:`，捕获 `ValueError` 并将其命名为 `e`，随后执行错误处理逻辑。

- **finally**：无论 `try` 与 `except` 中发生什么，`finally` 块都会执行。适用于资源清理、关闭连接等必须执行的收尾操作。

- **raise**：手动引发异常。示例：`raise ValueError(...)`。可在检测到非法状态时主动抛出异常，交由上层处理。

- **try**：包裹可能引发异常的代码。示例：尝试执行 `1_000_000 / 0`，该代码会触发除零错误；通过 `try` 与 `except` 捕获异常，可避免程序直接崩溃。

### 6. 导入、迭代、成员与身份

- **from**：从模块中导入特定功能。示例：`from random import randint`，随后可直接使用 `randint`。

- **import**：导入模块或包。示例：`import random`，随后使用 `random.random()` 获取随机浮点数。

- **in**：有两种常见用途。其一，在 `for` 循环中表示迭代：`for name in names:`；其二，进行成员资格检查：`if "bob" in names:`。否定形式为 `not in`。

- **is**：比较对象身份，即比较内存地址或对象 `id`，而非比较值。示例：`apple` 与 `other_apple` 指向同一对象时，`apple is other_apple` 为真；新建 `banana` 对象则为假。可通过 `id()` 验证。值比较应使用 `==`。

### 7. 占位与上下文管理

- **pass**：语法占位符。当函数、类或循环体暂时不能为空时使用。示例：`def foo(): pass`。也可使用省略号 `...` 作为占位，选择取决于可读性偏好。

- **with**：使用上下文管理器管理资源。示例：`with open("text.txt", "r") as file:`。`with` 块结束时会自动关闭文件，减少显式 `try`/`except`/`finally` 的资源清理负担。

## 二、软关键字

软关键字在特定上下文中作为关键字使用，同时也可作为变量名或标识符使用。

- **_（下划线）**：常见用途包括表示不关心的变量，例如 `for _ in range(3): print("hello")`；在类中用于双下划线方法（dunder methods）命名，如 `__init__`；在模式匹配中可作为通配模式。也可作为普通变量名。

- **case**：用于 `match`/`case` 模式匹配语句的分支定义。示例：根据 `weather` 的值匹配 `"rain"`、`"cloudy"` 等分支。作为软关键字，它也可用作变量名，但应避免制造歧义。

- **match**：用于模式匹配语句。示例：`match weather:`，随后用 `case` 分支匹配不同模式。模式匹配还可结合条件守卫与结构化模式，例如同时检查天气类型与严重性。软关键字允许其作为变量名，甚至可出现 `match match` 这类语法上可行但可读性差的写法。

- **type**：自 Python 3.12 起成为软关键字，用于定义类型别名。示例：`type IntOrStr = int | str`。该类型别名可供静态类型检查器使用，以判断变量是否符合预期类型；若不符合，静态检查器会给出警告。该机制不是运行时强制类型检查。Python 3.12 之前，`type` 不计入软关键字。

## 三、实践要点与常见误区

- 普通关键字是保留字，不能作为变量名、函数名或类名；软关键字仅在特定语法位置具有关键字含义。
- `assert` 适合内部前置条件检查，不应替代面向用户的输入验证与正式异常处理。
- `global` 与 `nonlocal` 会修改外层作用域状态，应明确设计意图并谨慎使用。
- `is` 用于身份判断，尤其推荐用于 `None` 判断；一般值比较应使用 `==`。
- `with` 可自动管理资源关闭，优于手动编写复杂的 `try`/`except`/`finally`。
- 生成器通过 `yield` 逐个产生值，具有一次性与耗尽特性；使用 `next()` 与 `list()` 时需注意剩余元素。
- `async`/`await` 需与事件循环配合，通常通过 `asyncio` 运行异步主函数。
- 模式匹配中的 `match`、`case` 与通配符 `_` 可组合使用；软关键字的灵活性可能导致可读性下降，应避免刻意混淆。
