# Python 内置函数学习笔记

说明：视频标题为“49 个内置函数”，转录口播中存在编号跳号或口误；以下按视频实际讲解的函数名整理。示例保留视频中的主要用法，并对明显口误或不符合 Python 实际行为之处作必要校正。

## abs：绝对值

- 作用：返回数字的绝对值。
- 示例：
  - `n = 1.25`，`abs(n)` 返回 `1.25`。
  - `n2 = -10`，`abs(n2)` 返回 `10`。
  - `n3 = 3 + 4j`，`abs(n3)` 返回 `5`。
- 复数绝对值公式：
  \[
  |3+4j|=\sqrt{3^2+4^2}=5
  \]
- 说明：复数绝对值更偏数学用途。

## all：全真判断

- 作用：判断可迭代对象中的所有元素是否都为真值。
- 规则：
  - 所有元素为真时返回 `True`。
  - 存在任意假值（如 `0`、`False`、空值）时返回 `False`。
- 示例：以投票列表中的 `1` 表示赞成、`0` 表示反对；若列表中包含 `0`，`all(voters)` 返回 `False`。

## any：至少一个为真

- 作用：判断可迭代对象中是否至少有一个元素为真值。
- 规则：
  - 至少一个元素为真时返回 `True`。
  - 所有元素均为假时返回 `False`。
- 与 `all` 的关系：`any` 检查“存在真值”，`all` 检查“全为真值”。

## ascii：可打印表示

- 作用：返回对象的可打印表示，并将非 ASCII 字符替换为转义序列。
- 示例：
  - `ascii("Björn")` 会将非 ASCII 字符转义。
  - 可对字符串列表使用，如 `ascii(["ö", "Ω", "¥"])`，返回每个字符的转义表示。
  - 也可传入单个字符，如 `ascii("¥")`。
- 说明：输出适合调试和显示不可见或非 ASCII 字符。

## bin：二进制表示

- 作用：将整数转换为二进制字符串表示。
- 示例：
  - `bin(1000)` 返回 `'0b1111101000'`。
  - 支持负数与 `0`，如 `bin(-5)`、`bin(0)`。
- 说明：返回值以 `0b` 开头。

## bool：布尔转换

- 作用：将对象转换为布尔值。
- 常见规则：
  - 非空字符串为 `True`，空字符串 `""` 为 `False`。
  - 非零数字为 `True`，`0` 为 `False`。
  - `None` 为 `False`。
  - 空列表 `[]` 为 `False`，非空列表如 `[1, 2, 3]` 为 `True`。
- 示例：
  - `bool("bob")` → `True`
  - `bool("")` → `False`
  - `bool(0)` → `False`
  - `bool(None)` → `False`

## callable：可调用检查

- 作用：检查对象是否可调用，即能否在对象后使用括号 `()`。
- 示例：
  - `my_object = "bob"`，`callable(my_object)` 返回 `False`。
  - 函数 `greet`，`callable(greet)` 返回 `True`。
  - `callable(print)` 返回 `True`。
- 用途：在调用对象前动态检查其是否可调用。

## chr：Unicode 码点转字符

- 作用：将整数 Unicode 码点转换为对应字符。
- 示例：
  - `chr(65)` 返回 `'A'`。
  - `chr(67)` 返回 `'C'`。
  - `chr(69)` 返回 `'E'`。
  - `chr(5000)` 返回对应 Unicode 字符。
- 说明：与 `ord` 互为逆操作。

## complex：复数构造

- 作用：创建复数对象。
- 示例：
  - `complex()` 返回 `0j`。
  - `complex(5)` 返回 `5+0j`。
  - `complex(6, 1)` 返回 `6+1j`。
  - `complex("7+2j")` 可解析字符串形式的复数。
- 注意：字符串中不能包含多余空格，如 `"7 + 2j"` 会报错。

## dict：字典构造

- 作用：创建字典，或将可迭代对象转换为字典。
- 示例：
  - `dict()` 返回空字典 `{}`。
  - `{}` 也可创建空字典。
  - `dict(a=1, b=2)` 返回 `{'a': 1, 'b': 2}`。
  - `dict([("a", 1), ("b", 2)])` 返回 `{'a': 1, 'b': 2}`。
- 规则：传入的可迭代对象中，每个元素应包含键和值两个部分。

## dir：作用域与属性列表

- 作用：返回当前作用域中的名称列表，或返回对象的属性/方法列表。
- 示例：
  - `dir()` 返回当前作用域中的名称。
  - `dir(json)` 返回 `json` 模块的属性与方法，如 `dumps`、`loads`。
  - `dir(int)` 返回 `int` 类型的属性与方法。
  - `dir("hello")` 返回字符串相关方法。
- 用途：探索模块、类型和对象的可用接口。

## divmod：商与余数

- 作用：同时返回整除商和余数，返回值为二元组 `(quotient, remainder)`。
- 示例：
  - `divmod(7, 4)` 返回 `(1, 3)`。
  - `divmod(3, 2)` 返回 `(1, 1)`。
  - `divmod(3.5, 1.5)` 返回 `(2.0, 0.5)`。
- 数学关系：
  \[
  7 = 4 \times 1 + 3
  \]
  \[
  3.5 = 1.5 \times 2 + 0.5
  \]

## enumerate：枚举

- 作用：为可迭代对象中的元素附加索引，返回 `enumerate` 对象。
- 示例：
  - `list(enumerate(["Agnetha", "Björn", "Benny", "Anni-Frid"]))`
  - 返回类似 `[(0, "Agnetha"), (1, "Björn"), ...]`。
- 常用写法：
  ```python
  for i, member in enumerate(abba):
      print(i, member)
  ```
- 参数：可通过 `start` 指定索引起始值，如 `enumerate(abba, start=1)`。
- 注意：`enumerate` 对象是迭代器，遍历一次后会耗尽。

## eval：表达式求值

- 作用：执行字符串形式的 Python 表达式，并返回结果。
- 示例：
  - `eval("10 + 30 * 2")` 返回 `70`。
  - 可用于简单计算器场景。
- 错误示例：`eval("x y")` 会触发 `NameError`。
- 安全警告：不要对用户输入、随机输入或不可信来源使用 `eval`，否则可能执行危险代码。

## exec：执行代码块

- 作用：执行字符串形式的 Python 代码，可执行多行完整代码。
- 示例：
  ```python
  source = """
  a = 10
  b = 20
  print(a + b)
  for i in range(3):
      print("xx for loop", i)
  """
  exec(source)
  ```
- 返回值：`exec` 返回 `None`。
- 注意：`exec` 中定义的变量会进入当前作用域；例如执行后 `a` 可被访问。
- 安全警告：不要对不可信来源或用户输入使用 `exec`。

## filter：过滤

- 作用：根据函数返回值过滤可迭代对象，返回 `filter` 对象。
- 示例：
  ```python
  names = ["james", "john", "jam", "bob"]

  def starts_with_j(name):
      return name[0].lower() == "j"

  filtered = filter(starts_with_j, names)
  print(list(filtered))
  ```
- 输出：`['james', 'john', 'jam']`。
- Lambda 写法：
  ```python
  list(filter(lambda n: n[0].lower() == "j", names))
  ```
- 说明：`filter` 返回内存高效的迭代器，通常需转换为 `list` 查看结果。

## float：浮点数构造

- 作用：创建浮点数，或将兼容对象转换为浮点数。
- 示例：
  - `float()` 返回 `0.0`。
  - `float("10.5")` 返回 `10.5`。
  - `float(True)` 返回 `1.0`。
  - `float(None)` 会触发 `TypeError`。
- 说明：数据类型构造函数无参数时，通常返回该类型的空值或默认值。

## frozenset：不可变集合

- 作用：创建不可变集合。
- 示例：
  - `fs = frozenset({1, 2, 3})`。
  - `hash(fs)` 可正常计算哈希值。
- 特点：
  - 不可修改，不能添加或删除元素。
  - 可哈希，因此可作为字典键或集合元素。
- 对比：普通 `set` 不可哈希，`hash({1, 2, 3})` 会触发异常。

## globals：全局命名空间

- 作用：返回当前全局作用域中的变量字典。
- 示例：
  - `globals()` 返回全局变量，如 `__name__`、`__doc__`、`__package__`。
  - 定义 `x = 10` 后，`globals()` 中会出现 `x`。
- 说明：只反映全局作用域中的名称。

## locals：局部命名空间

- 作用：返回当前局部作用域中的变量字典。
- 在全局作用域中使用时，`locals()` 与 `globals()` 类似。
- 在函数内部：
  ```python
  def sample_function():
      channel = "random"
      x = 1
      y = 2
      print(locals())
  ```
- 输出：函数内部的局部变量，如 `channel`、`x`、`y`。
- 说明：函数内部的局部变量不会出现在全局作用域中；`globals()` 在函数内部仍返回全局变量。

## hash：哈希值

- 作用：返回对象的哈希值，结果为整数。
- 示例：
  - `hash(frozenset({1, 2, 3}))`。
  - `hash("brown")`。
  - `hash((1, 2, 3))`。
- 限制：只有可哈希对象才能使用 `hash`；普通 `set`、`list` 等可变对象不可哈希。

## help：帮助信息

- 作用：查看函数、模块、类型或自定义对象的帮助文档。
- 用法：
  - `help()` 启动交互式帮助控制台，输入 `q` 退出。
  - `help(print)` 返回 `print` 的文档与签名。
  - `help(hello)` 返回自定义函数的文档字符串。
- 示例文档字符串：
  ```python
  def hello(name: str):
      """根据用户提供的名字向用户问好。"""
      print(f"Hello {name}")
  ```
- 说明：适合快速查看函数作用；在 IDE 中悬停通常也能看到类似信息。

## id：对象身份

- 作用：返回对象的身份标识，通常是整数。
- 示例：
  - `id(user)`、`id(number)`。
  - `l1 = [1, 2, 3]`，`l2 = l1`，则 `id(l1) == id(l2)`。
- 身份与相等：
  - `is` 检查身份，即是否为同一对象。
  - `==` 检查值是否相等。
  - `l1 = [1, 2, 3]`，`l2 = [1, 2, 3]`：`l1 == l2` 为 `True`，`l1 is l2` 为 `False`。
  - `l2 = l1`：`l1 is l2` 为 `True`，因为二者是同一对象的别名。

## int：整数构造

- 作用：创建整数，或将兼容对象转换为整数。
- 示例：
  - `int()` 返回 `0`。
  - `int(1.9)` 返回 `1`。
  - `int(1.4)` 返回 `1`。
  - `int("4")` 返回 `4`。
- 说明：对浮点数转换时表现为向零截断；对正数而言与向下取整结果一致。

## isinstance：实例类型检查

- 作用：检查对象是否为指定类型或指定类型元组中的实例。
- 示例：
  - `isinstance(10, int)` 返回 `True`。
  - `isinstance("s", int)` 返回 `False`。
  - `isinstance(text, (str, int))` 检查是否为字符串或整数。
- 应用：
  ```python
  user_input = (1, 2, 3)
  if isinstance(user_input, (tuple, set, list)):
      print("tuple/set/list")
  else:
      print("unknown type")
  ```
- 说明：`input()` 通常返回字符串；若需要数值，应显式转换并检查。

## issubclass：子类检查

- 作用：检查一个类是否为另一个类的子类。
- 示例：
  ```python
  class Parent:
      pass

  class Child(Parent):
      pass
  ```
  - `issubclass(Child, Parent)` 返回 `True`。
  - `issubclass(Parent, Child)` 返回 `False`。
- 内置类型示例：
  - `issubclass(bool, int)` 返回 `True`。
  - `issubclass(int, bool)` 返回 `False`。

## iter：创建迭代器

- 作用：从可迭代对象创建迭代器。
- 示例：
  ```python
  queue = [1, 2, 3]
  my_iterator = iter(queue)
  ```
- 使用：
  - `next(my_iterator)` 依次返回 `1`、`2`、`3`。
  - 再次调用会触发 `StopIteration`。
  - `list(my_iterator)` 可查看剩余元素，但会耗尽迭代器。

## len：长度

- 作用：返回对象的长度或元素个数。
- 示例：
  - `len("hello")` 返回 `5`。
  - `len(["cup", "apple", "plant"])` 返回 `3`。
- 说明：字符串长度包括空格和标点；列表长度按元素个数计算。

## list：列表构造

- 作用：创建列表，或将可迭代对象转换为列表。
- 示例：
  - `list()` 返回 `[]`。
  - `list("abcdefghi")` 返回每个字符组成的列表。
  - `list((1, 5))` 返回 `[1, 5]`。
- 说明：可将字符串、元组、集合、迭代器等转换为列表。

## map：映射

- 作用：将函数应用于可迭代对象中的每个元素，返回 `map` 对象。
- 示例：
  ```python
  def squared(n: int) -> int:
      return n * n

  result = map(squared, [1, 2, 3])
  print(list(result))
  ```
- 输出：`[1, 4, 9]`。
- Lambda 示例：
  ```python
  list(map(lambda s: s.upper(), ["bob", "sandra"]))
  ```
- 输出：`['BOB', 'SANDRA']`。
- 说明：`map` 返回内存高效的迭代器，通常转换为 `list` 查看结果。

## max：最大值

- 作用：返回可迭代对象中的最大值，或返回多个参数中的最大值。
- 示例：
  - `max([99, 10, 4, 100, 25, 45])` 返回 `100`。
  - `max(["bob", "james", "steven"], key=len)` 返回 `"steven"`。
- `key` 参数：指定比较依据；例如以字符串长度为比较标准。
- Lambda 写法：
  ```python
  max(names, key=lambda name: len(name))
  ```

## min：最小值

- 作用：返回可迭代对象中的最小值，或返回多个参数中的最小值。
- 示例：
  - `min([99, 10, 4, 100, 25, 45])` 返回 `4`。
  - `min(["bob", "james", "steven"], key=len)` 返回 `"bob"`。
- 说明：`min` 与 `max` 的参数形式基本对称。

## next：获取下一个值

- 作用：从迭代器或生成器中获取下一个值。
- 示例：
  ```python
  my_iter = iter(range(3))
  print(next(my_iter))  # 0
  print(next(my_iter))  # 1
  print(next(my_iter))  # 2
  ```
- 注意：迭代器耗尽后继续调用 `next` 会触发 `StopIteration`。
- 可通过 `list(my_iter)` 查看剩余元素，但该操作会消耗迭代器。

## open：文件打开

- 作用：打开文件并返回文件对象，用于读写文件流。
- 示例：
  ```python
  file = "secret.txt"
  with open(file, "r") as f:
      print(f.read())
  ```
- 说明：
  - `"r"` 为读取模式，也是默认模式。
  - 使用 `with` 可确保文件在代码块结束后自动关闭。
  - 文件内容可通过 `read()` 读取。

## ord：字符转 Unicode 码点

- 作用：返回单个字符的 Unicode 码点整数。
- 示例：
  - `ord("A")` 返回 `65`。
  - `ord("Ω")` 返回对应 Unicode 码点。
- 说明：`ord` 是 `chr` 的逆操作；名称来源于 ordinals。

## pow：幂运算

- 作用：计算幂，也可进行带模幂运算。
- 语法：`pow(base, exp, mod=None)`。
- 示例：
  - `pow(2, 3)` 返回 `8`。
  - `pow(5, 2)` 返回 `25`。
  - `pow(5, 2, 3)` 返回 `1`，即计算 \(5^2 \bmod 3\)。
- 数学表示：
  \[
  2^3 = 8
  \]
  \[
  5^2 \bmod 3 = 1
  \]
- 说明：第三个参数用于模幂运算，适合数学计算和密码学相关场景。

## print：输出

- 作用：将对象输出到控制台。
- 示例：
  - `print("hello world")`。
  - `print(1, 2, 3, sep=",")` 输出 `1,2,3`。
  - `print(*people, sep=",", end=".")` 可解包列表并指定分隔符与结束符。
- 常用参数：
  - `sep`：多个参数之间的分隔符，默认空格。
  - `end`：输出结束符，默认 `\n`。
- 注意：修改 `end` 后可能影响后续输出换行，应谨慎使用。

## range：范围对象

- 作用：创建整数范围对象，常用于循环。
- 形式：
  - `range(stop)`：从 `0` 到 `stop-1`。
  - `range(start, stop)`：从 `start` 到 `stop-1`。
  - `range(start, stop, step)`：按步长生成。
- 示例：
  - `range(10)` 生成 `0` 到 `9`。
  - `range(5, 10)` 生成 `5` 到 `9`。
  - `range(0, 10, 2)` 生成 `0, 2, 4, 6, 8`。
  - `range(10, 0, -1)` 生成 `10` 到 `1`。
- 注意：`range(10, 0)` 为空，因为默认步长为正，需要负步长才能倒序。

## repr：开发者表示

- 作用：返回对象的官方或开发者友好的字符串表示。
- 示例：
  - `repr(10)` 返回 `'10'`。
  - `repr("Bob")` 返回 `"'Bob'"`，字符串表示中包含引号。
- 说明：`repr` 更关注可调试性；对字符串而言，输出通常会保留引号。

## reversed：反转迭代器

- 作用：返回反转后的迭代器。
- 示例：
  ```python
  seq = [1, 2, 3, 4, 5]
  r = reversed(seq)
  print(list(r))
  ```
- 输出：`[5, 4, 3, 2, 1]`。
- 说明：
  - `reversed` 返回反转迭代器，内存效率较高。
  - 也可使用切片 `seq[::-1]` 得到反转列表。

## round：四舍五入

- 作用：对数字进行指定小数位数的舍入。
- 示例：
  - `round(1.23456, 3)` 返回约 `1.235`。
  - `round(x, 0)` 保留零位小数。
  - 不传第二个参数时，通常返回整数。
  - 负的 `ndigits` 可对整数部分舍入，如 `round(49, -1)` 返回 `50`。
  - `round(12345, -3)` 返回 `12000`。
- 说明：`ndigits` 可为正数、零或负数，分别控制小数位、整数位和高位舍入。

## set：集合构造

- 作用：创建集合，或将可迭代对象转换为集合。
- 示例：
  - `set()` 返回空集合。
  - `{}` 创建的是空字典，不是空集合。
  - `set([1, 1, 2, 3, 2, 3, 3])` 返回 `{1, 2, 3}`。
- 特点：
  - 集合不能包含重复元素。
  - 可用于从列表中去除重复项。

## slice：切片对象

- 作用：创建可复用的切片对象。
- 语法：`slice(start, stop, step)`。
- 示例：
  ```python
  nums = [1, 2, 3, 4, 5, 6, 7, 8, 9]
  step_two = slice(None, None, 2)
  print(nums[step_two])
  ```
- 等价于：`nums[::2]`。
- 其他示例：
  - `rev = slice(None, None, -1)` 可用于反转。
  - `first_five = slice(0, 5)` 可获取前五个元素。
- 优点：若同一类切片在代码中多次使用，只需在一个地方维护切片对象。

## sorted：排序

- 作用：对可迭代对象进行排序，返回新的排序列表。
- 示例：
  - `sorted([1, 5, 3, 4])` 返回 `[1, 3, 4, 5]`。
  - `sorted(names, key=len)` 按字符串长度排序。
  - `sorted(names, key=len, reverse=True)` 按长度降序排序。
- 说明：
  - 不传 `key` 时，字符串通常按字符编码顺序排序。
  - `sorted` 返回新列表，不修改原可迭代对象。

## str：字符串构造

- 作用：创建字符串，或将其他数据类型转换为字符串。
- 示例：
  - `str()` 返回空字符串 `""`。
  - `str(True)` 返回 `"True"`。
  - `str(None)` 返回 `"None"`。
  - `str(100)` 返回 `"100"`。
- 扩展：
  - `str(None).upper()` 返回 `"NONE"`。
  - `repr(str())` 返回 `"''"`，可显示空字符串的表示形式。
- 说明：转换后可使用字符串方法进行进一步处理。

## sum：求和

- 作用：对可迭代对象中的元素求和。
- 示例：
  - `sum([1, 2, 3])` 返回 `6`。
  - `sum([1, 2, 3], 10)` 返回 `16`。
  - `sum([], 1_000_000)` 返回 `1_000_000`。
- 参数：可提供起始值 `start`，默认从 `0` 开始。
- 说明：若可迭代对象为空，则返回起始值。

## tuple：元组构造

- 作用：创建元组，或将可迭代对象转换为元组。
- 示例：
  - `tuple()` 返回空元组 `()`。
  - `tuple([1.5, 5.0])` 返回 `(1.5, 5.0)`。
- 特点：元组不可变，适合表示不应改变的数据，如坐标。
- 说明：可将列表转换为元组以表达不可变语义。

## type：类型查看

- 作用：返回对象的类型。
- 示例：
  - `type(10)` 返回 `int`。
  - `type("Bob")` 返回 `str`。
  - `type(True)` 返回 `bool`。
  - `type([1, 2, 3])` 返回 `list`。
  - `type(set())` 返回 `set`。
- 说明：可用于检查对象实际类型；与 `isinstance` 相比，`type` 更严格，不自动考虑继承关系。

## zip：并行压缩

- 作用：将多个可迭代对象中的元素按位置打包为元组，返回迭代器。
- 示例：
  ```python
  a = ["a", "b", "c"]
  b = [1, 2, 3, 4]
  c = [True, False, True]

  zipped = zip(a, b, c)
  print(list(zipped))
  ```
- 输出：
  ```python
  [('a', 1, True), ('b', 2, False), ('c', 3, True)]
  ```
- 注意：
  - `zip` 只压缩到最短可迭代对象的长度；上例中的 `4` 被忽略。
  - 若使用 `strict=True`，当可迭代对象长度不一致时会抛出异常。
- 说明：`zip` 常用于并行遍历多个序列。
